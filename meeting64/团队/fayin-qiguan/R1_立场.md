## 0. 一句话立场（先给结论）

**路线 C 不该是首选。** 它最内生、也最重（全量 8–15 人日），但可测增量被两件事压住：
① **10ms 帧栅格**把 C 独有的线索（除阻瞬态 1–3ms、面积动态）挡在外面；② 诊断已证**部位谱不是缺口**。
因此我把 1 天原型只押在一件能区分 C 与 A 的事上：**几何导出的亚帧爆破瞬态**。它若拿不到增量 ⇒ C 判死，省 8–15 人日。
排序建议：**A（最便宜、0.5–1 人日，先量残余头寸）→ C 的 1 天探针（条件）→ B（最后）**。

## 1. 路线一句话（输入 → 中间表示 → 波形）

- **输入**：`音韵_v5` 音素段（声母方式/部位/韵母目标）+ `韵律_v7/v8` 的时长·F0·重音 + 声线 14 维（不动）。
- **中间表示**：**时变声道面积 A(x,t)**（34 段×5mm，0.17 m 管）+ 鼻支路面积 A_n(t) + 声门源；收紧点 `(x_c, A_c(t))` 由音素段给出，10ms 一帧、**爆破处亚帧 1–3ms**。
- **波形**：A(x,t) → ABCD 传输线级联（黏热损耗 + 唇辐射 Z_rad）→ 噪声段由「源在收紧点 + 前腔响应」生成；浊音段仍走 v7 级联 F1–F5。
- 与现行对比：v7/v8 的中间表示是**每音素一条 (Fc,BW) 频带 + F1–F5 目标表**（`[源码]` `音韵_v5.声母[*].频带/轨迹`）；C 换成一个几何对象 + 一个声传输方程。

## 2. 依据：正对哪个错误类，比目标表多出哪些**可测**线索

**引 4 条实测**
1. §1.2：涉声母 77.8%；p 100%(3/3)、f 100%(6/6)、b 67%(8/12)；混淆 t→sh/b/c、b→f、z→sh/s/c ⇒ **靶区是声母方式/除阻**，不是字符歧义（同音字仅 1.9%）。
2. §1.3 Q3：s/sh/x 谱重心 6620/3338/4914 Hz、d′34–75、三分类 100% ⇒ **部位谱不是缺口**（§7 排 #7）；真缺口是「擦 vs 同部位塞擦」Δ重心 11.1–42.0 Hz、与「送气塞 VOT」p/t/k 谱重心 3264/3286/2852 Hz（几乎同）。
3. §1.3 Q3：爆破帧 p 5586 / t 3808 / k 2386 Hz 与文献方向**相反**（唇释放应低频主导、龈应最高）⇒ 现行「1 帧带通爆破」的谱更像 10ms 网格伪迹，而非物理量。
4. §1.4/§1.5：13 个单维全中性，c03 筛选 −0.027→留出 +0.056、c13 去双缩放 +0.066；真人→合成 CER 0.667–0.818 ⇒ 「幅度/时长/频带/保真」这类**可手调连续量已穷尽**，且不是 ASR 苛刻。

**比 F1–F5 目标表多出的可测线索（只有 4 条）**
- **① 部位→前腔长度→谱重心（可测，但无 CER 头寸）**：`[实测 探针]` 部位→前腔→ABCD×唇辐射×文献源谱（`原型/探针_前腔共振.py`）：预测 s/x/sh = **5247/4497/4460** vs 实测 **6620/4914/3338**；**P1 排序 PASS、P2 量级中位误差 0.21 PASS、P3 单标量标定 β=0.86 PASS**（β≈1 ⇒ 基本无拟合）。代价：x/sh 只差 37 Hz（脆）；**理想源下三音全塌到 12.2–12.7 kHz** ⇒ 必须带一个经验源谱；唇齿 f 预注册为模型缺口（9649 vs 3708）。
- **② 方式→时间演化（唯一独占）**：塞擦 `A_c(t)` 自闭合释放、擦音 `A_c` 恒定 ⇒ 摩擦段谱心随时间**上扫**；现行引擎摩擦段频带全程常数（`[源码]` 一帧一个 `噪带`），无此量。且亚帧释放沿（1–3ms）在 10ms 栅格上**不可表达**。
- **③ 几何→零极点（可测，但 A 也能做）**：鼻支路面积直接给反谐振。`[源码]` v8.1 参数 `鼻增益=0.0`、`鼻极Hz=250/鼻零Hz=1000` 为**全局单值** ⇒ 无法区分 -n/-ng（诊断：鼻尾类错误 0.49–0.51）。但 A 只需按韵尾逐帧给零位（数值已由 meeting62 发声生理注册），比 C 便宜两个量级。
- **④ 协同发音**：面积空间插值 vs 现在 F1–F5 空间插值（`终点=轨+(目−轨)×0.30`）；§1.3 表明部位信息在 VOT 段被抹掉后只剩「1 帧爆破 + CV 过渡」，所以过渡斜率是第二靶，但它是**慢线索**，A 的 `终点混合` 常数已能覆盖大半。

## 4. 预期与反证（先定后跑）

- **预期 ΔCER**：点估计 **−0.01**，区间 **[−0.025, +0.005]**。上界推导：送气塞相关错误 ~12/213 ≈ 0.056 CER，折半再打折。**大概率不过双门槛**（−0.03/−0.02）。
- **失败判据**（任一成立即判 C 失败，不许事后改）：
  1. 筛选 ΔCER > −0.03 或 留出 ΔCER > −0.02；
  2. 相对 **A-手调臂** 的 Δ ≤ 0（几何没有超出「调一组常数」的能力 ⇒ 8–15 人日不值得）；
  3. 类别级：p/t/k+b/d/g 错误率相对下降 <15%（说明爆破谱不是它们的错因）；
  4. 纯 DSP 门不过：几何爆破谱排序不是「龈>软腭>唇」，或浊音帧出现任何一位不同（破 C14）。
- 已过的前置：探针 P1/P2/P3 PASS；f（唇齿）预注册为模型缺口，**本原型不碰 f**。

## 5. 成本 / 风险 / 铁律 / 音色 / 回退 / 人日（诚实：它最重）

- **人日**：本条原型 **1 天**；全量 **8–15 人日**（面积库 44 音素×3 角色标定 ≈4、含损耗+时变滤波器 ≈3、亚帧帧栅格改造 ≈3、鼻/唇齿支路 ≈2、回归+判据 ≈2）。
- **铁律**：C1/C9/C10 —— 纯 numpy/scipy 解析式，无模型/无权重/无网络；C13 —— 显式种子+纯函数，两趟逐位同；C14 —— 全新增，浊音逐位同作护栏。
- **音色**：原型零改动（浊音道逐位同）。**全量版有真实风险**：C 以「声道长度/面积」参数化，必然与 `共振峰缩放 s∈[0.75,1.25]` 打架——c13 已证「对音韵目标保真 ≈ 更差」，且三角色差异（`[1.1,1.1,1.1]` vs `[1.1,1.044,1.044]`）会被几何抹平 ⇒ 「不改音色」在 C 的全量形态下**很难同时成立**。
- **可回退**：新文件+开关；不采纳即删目录，v8.1 基线一字不动。
- **风险排序**：① 10ms 栅格吃掉 C 的主要线索（最致命）；② A 可等效替代（1 个常数 vs 一套模型）；③ lossless 管在 44.1k 必须外加黏热损耗与源谱两个经验模块（探针已量化：无源谱时预测全塌高频端）；④ 唇齿/鼻支路必须另建模。
- **为什么值得用最大工作量换**：**现在不值得**。C 买的是「可扩展物理层」（新音素/新角色/唱歌/情感外显都挂得上），不是本轮 CER；本轮只该买「它到底有没有增量」这个 1 天答案。

## 6. 反对另外两条路线（各 ≤3 行）

- **反对 A（补 Klatt）——但它仍是首选，只是因为它便宜**：A 的 4 项里 3 项本仓已有半成品（`[源码]` v7 可选④鼻零极点、v8 爆破带收紧表、v7 `tl`），0.5–1 人日可 A/B，能最快量出「还剩多少头寸」。
  反它的理由：A 的自由度**正是 c01–c14 已证伪的那类手调连续常数**，筛选集过拟合风险最高（c03 是活样本）；且 A 与 C 在爆破带上重叠，A 先跑会把 C 的增量顶掉——这恰好是 C 该被压后的理由。
- **反对 B（谱声库）**：来源是本仓参考录音统计 ⇒ 音色来源从「14 维参数」变成「录音谱包络」，与「不动音色/先会说再模仿」直接冲突；拼接单元=新的外挂边界（C10 灰区），本仓零证据、零量具。
  若三条都要排：**A（0.5–1 人日）→ C 探针（1 人日，条件性）→ B（无当期头寸）**。
