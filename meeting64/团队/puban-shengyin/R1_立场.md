## ① 路线一句话（输入 → 中间表示 → 波形）

| 格 | 内容 |
|---|---|
| 输入 | 文本，或 meeting62 `亚版本`：音节 =｛声母, 韵母, 韵尾, 声调, 时长, 音高, 声线引用｝（契约已存在） |
| 中间表示 | **谱包络单元序列**：每音节按「部位 × 方式」拆 1–3 段（塞闭静音 / 爆破 / VOT / 摩擦），每段一个「单元」＝ **64 带 log 能量包络 ＋ 时长期望 ＋ 电平 ＋ 与邻段的插值权重**；单元表由 `音韵_v5.声母` 的（部位, 方式, 频带, 爆破带, VOT）**规则确定性生成**，只用已固化参考统计的 1 个全局标量（谱倾斜）定标整体明暗 |
| 波形 | 浊段＝`引擎_v7` 原生（声门源 × F1–F5）**逐位不变**；噪段＝同种子白噪 × 单元包络（FFT 重叠相加）＋ 段间包络对数域插值 ＋ 10 ms 交叉渐变；两段直接拼接成 wav |

一句话：**不改「怎么发声」，改「辅音谱包络用什么基表示」**——从「1–2 个谐振器参数」换成「每音素每阶段一整条带能量包络」。

## ② 依据：为什么它能修「声母部位/方式」与整体清晰度

1. **§1.2 的承重面**：涉及声母的操作 **77.8%**（f 100%、p 100%、s 100%、j/q 83%、b/h 67%；软腭 66.7%/唇 62.2%/硬腭 52.4%），而我的只读实测显示噪声段只占时间轴 **21.8%**（1038/4755 帧）⇒ 单位时间错误密度极高，**改动范围小、杠杆大**，且不碰占 78% 的浊段音色。
2. **§1.3 的「擦 vs 同部位塞擦」不是 DSP 事故，是构造上的同参数**（本轮新读源码得到）：`音韵_v5.声母` 里 **s/z/c 三母的频带与爆破带逐字相同 (6800,2200)**；sh/ch/zh 全为 (3300,1500)；x/j/q 全为 (5000,1900)。引擎_v7 噪分支要么用**一个**二阶谐振器（Fc,BW），要么用 F1–F3 三极点（`引擎_v7.py:287–306`）⇒ 同部位擦音与塞擦**在表示层就无法给出不同的谱形**，只有时长/塞闭/幅可差。这恰好解释了 §1.4「c06/c07/c10/c14 等全局旋钮全中性」是**必然**：全局标量只能同时缩放两者，永远造不出「形状差」。包络单元把自由度从 1–2 个参数升到 64 带，**按方式给不同斜率/零点**（擦音稳态宽带；塞擦＝瞬态爆破＋带限摩擦），擦-塞擦缺口才有解。
3. **§1.3 的「送气塞部位」同理**：`韵律_v9._声母` 送气段调用 `_噪声过渡(..., 噪形=1, 噪带=None, ...)` ⇒ 复用 CV 过渡的 F1–F3 三极点 ＋ 0.18 白噪底，部位信息只挤在 F1–F3 位置上，故实测 p/t/k VOT 谱重心几乎同（2512–3515 Hz）。单元表示里 VOT 段可直接给「按部位的重心/斜率」（唇低、龈高、软腭中低且宽），部位不再依附于过渡。
4. **§1.5 的校准**：真人能转写的内容，合成版 CER 仍 **0.667–0.818** ⇒ 0.53 不是 ASR 苛刻，是合成音的音段谱保真不够。ASR 判字靠的正是段内宽带谱；**谱包络保真**与它的判据同向。
5. **§1.4 的反证被尊重**：c13 修「双重缩放」反而 +0.066 ⇒「对 `音韵` 共振峰目标保真」与「对 ASR 可懂」不同向。B 不追求共振峰目标保真，而把**ASR 看得见的那层（谱包络）**当直接表示——这是换基，不是换目标值，也不是新旋钮。
6. **m→l ×11** 亦落在同一条：鼻音需要「低频重心 + ~1 kHz 谱谷（鼻零点）」，这是一个包络单元；v7 的鼻零极点默认关闭、c11 用标量增益试过更差，说明缺的仍是**形状**而非幅度。
7. **与 meeting62 谱管线既有实测的增量**：`证据_谱管线.md` 的实测只有 f0 比 0.9984–1.0023（音符定音高）、两趟 wav sha 逐位同、1 个 5 音节样本（3.6 s 谱 / 3.79 s 出声），**没有一条关于音段清晰度或 ASR**；它改的是「谁驱动 f0/时长」，渲染仍走 `引擎_v6` 的谐波＋单谐振器噪声支路。B 复用其 `亚版本` 契约与 `谱韵律`，在**下游新增包络单元层** ⇒ 增量全部落在「音素 → 谱包络 → 波形」这一段，与谱驱动那段正交、可叠加。

## ④ 预期 ΔCER 与失败判据（先定后跑）

- **预期**：筛选 ΔCER = **−0.03 ± 0.03**（区间 −0.06…0.00，点估 **−0.04**）；留出 ΔCER = **−0.02 ± 0.03**（点估 −0.035）。我认为**通过双门槛的概率 40–50%**——理由写死在这里：18 样本在 0.02–0.03 量级分辨力不足（c03 假胜即证），且噪声段只占 21.8% 时长，收益上限受限于「ASR 是否真吃这一段谱形」。
- **失败判据（任一成立即判 B 失败/不采纳）**：
  1. 筛选 Δ ≥ −0.01 **且** 留出 Δ ≥ 0 ⇒ 「谱包络表示」假设被否证（不是样本量问题）。
  2. 筛选 ≤ −0.03 但留出 Δ ≥ −0.01 ⇒ **不可迁移**（c03 同形陷阱），不采纳、不复评合并。
  3. 机制检查不过（重心差 < 150 Hz 或 d′ < 1.5 或 cos < 0.90）⇒ **实现失败**，先修实现、不进 ASR。
  4. `w=0` 不能逐位恢复 v9 ⇒ 可回退性失败，不采纳。
  5. 两趟 wav sha 不同 ⇒ C13 失败，不采纳。
  6. 只有 f/p 等少数声母错误下降、总 CER 不动 ⇒ 判「覆盖不足」，B 降级为局部补丁而非表示层路线。
- **加分项（不作门槛）**：m→l 次数 11 → ≤5；z/c→sh/s 类混淆下降；逐声母错误率 f/p/s 从 100% 降到 ≤50%。

## ⑤ 成本 / 风险 / 铁律（重点：C10「参考录音只作参考、不作器官」怎么守）

**C10 的 4 条操作化守法（可审计、可证伪）**：
1. **参考录音只在离线、只以已冻结标量进入**：取 `meeting61/产物/指标/拟合44_*.json` 的 `参考统计`（共振峰均值/谱倾斜）中 **1 个全局标量**；**生成路径运行期读入音频 = 0、权重 = 0**（沿用 `审计_零外挂.py` 的 A/B/C 三断言，并加运行期 `open/wave.open` 计数断言 = 0）。参考音频本身在生成期**不存在于进程内**。
2. **单元表不含任何录音时序列**：只有 21 声母 × 阶段的 64 维规则包络，每一维都能从 `音韵_v5.声母` 逐行手算复核（可逆、可查、可复现）；**参考统计不参与逐音素参数选择**（一参与就是「参考作器官」）——只做全局明暗定标 1 次。
3. **must-fail「回放冒充」**：ref44 与同内容合成输出的包络相关须 **≤ 0.5**（meeting58 G5 同口径）⇒ 证明不是克隆、不是把参考当声源。
4. **先例与边界**：meeting62 `声线覆盖层_v7` 已在运行期从同一批「已固化参考统计」派生 2 维（共振峰缩放/谱倾斜），v7 判据 **32/33 PASS**（含真人准入门 11/11、must-fail 全过）；B 只多 1 个标量，**不扩大口子**。若审计出现任何音频读入 ⇒ 直接判 C10 违规、作废。

**其余铁律**：C1（FFT 带增益不是序列/注意力架构，禁词命中须 0）｜C13（白噪源统一由 `种子` 派生，单元表无随机，两趟逐位同）｜C14（纯新增 2 件、旧件只读 import、`w=0` 逐位同）。
**是否改音色**：**否**。浊段（元音 + 浊声母）波形逐位不变，14 维声线/克隆路径零改动；噪段只换谱包络、不动声道模型。护栏＝meeting58「同文本声线分类 1.0」保持（改后需复跑该臂，不得掉下 0.9）。
**人日**：**1.0**（单元表规则 0.4 + 渲染/拼接 0.4 + 双集接线与机制读数 0.2）；ASR 仪器另计、不计入。
**风险**：① 单元若照抄 `音韵_v5.频带` 会退化成现状——必须按 §1.3 缺口**主动加大部位/方式间的谱形分离**；② 「更像参考谱形」≠「更可懂」，只能由 ASR 判；③ 送气/擦音电平若同时被抬高会触发 c07/c10 的「更差」老坑 ⇒ **只改谱形、锁定 RMS/峰值与 v9 同级**。
**回退**：删 2 个新件即回 v9；或 `w=0` 权重仍逐位同，无需回滚既有件。

## ⑥ 反对另外两条路线

- **反 A（补 Klatt，≤3 行）**：A 在**共享**噪声支路上加并联极点/零点，等于用谐振器基去逼近 B 直接给的包络，且 21 个声母要逐个标定新增参数；§1.4 已实测该样本量下单维 A/B 分辨力不足（c03 −0.027→+0.056 反弹），A 的收益会以十几轮单维才可判、成本高而判据弱。更关键：A 不改「同部位擦音/塞擦共用参数」的结构（s/z/c 仍同频带），就修不了 §1.3 的擦-塞擦缺口。
- **反 C（发音器官模型，≤3 行）**：C 需要「面积函数 → 传递函数」与协同发音动力学，仓内既无该实现也无标定数据，1 天内出不了可量化原型，无法与 A/B 同日同量具比数；而它的可测出口最终仍是「谱包络像不像」——B 已直接落在出口上。C 更适合作为 B 之后的**参数来源**（用面积函数生成单元表），不是本轮竞品。
