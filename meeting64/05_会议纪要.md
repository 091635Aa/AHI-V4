## 0. 会议结论（Lead 收口，见 §4）

1. **「在同一表示里继续调参」= 关掉。** 16 个单维/组合条件（13 预注册 + 2 追加 + 1 组合）**没有一个**同时过「筛选 Δ≤−0.03 且 留出 Δ≤−0.02」；且**方向一致：凡把音段拉长/放大，CER 都变差**。
2. **「参数化、零外挂、内生」这个方向本身没错；错的是目标函数与方法**：本轮两次「按声学教科书修保真」都让 ASR **变差**（c13 双重共振峰修正 **+0.066**、c16/c17 放宽鼻尾借帧 **+0.076/+0.129**）⇒ **ASR CER 已不能单独当「听清楚」的判据**。
3. **下一步不是换架构，而是先补「人耳锚点」**：请所有者对 v8.1 的 6 句 × 3 角色做一次 0–4 分可懂度盲评（`产物/听测/` 待生）+ 与 ASR 转写对照；**在拿到人耳锚点之前，不再开新的表示层工程**。
4. **表示层只开 1 个最小原型（A 路线，≤1 人日）**，且必须**先过 DSP 声学门，再花 ASR 双集**；C 路线**不做**（C 席自己也不推荐）；B 路线**押后**（C10 边界 + 无仓内证据）。
5. **v8.1 保持交付基线**（0.5292 / 判据 29/30），零改动。

## 2. 三席立场摘要（原文见 `团队/*/R1_立场.md`）

### 席 A · `klatt-buqi`（补齐 Klatt：噪声支路「部位带」）
- **路线**：不改「怎么发声」，把噪声支路接成 Klatt 摩擦源——**部位谐振（p900/k1900/t3800，取自 `爆破带`）× 零点压掉 0.22 平直旁通 → 逐帧滑向元音 F2 → 辐射补偿（1/f²）**，让写进去的部位带真的到波形。
- **关键新实测**（`实施/试_VOT部位谱.py`）：① 现行 VOT 谱重心 p/t/k = **3314/3202/2898**（极差 416Hz）；撤辐射后仍 1389/1591/1786 ⇒ 部位对比在辐射前就不存在；② **帧层显式给 `噪带=爆破带` 后**，去辐射重心 = **1276/1527/1996（单调 p<k<t）**，但**经现有辐射变成 6824/3655/3740（非单调）** ⇒ 是「0.22 平直旁通 + 一阶差分 + 逐帧 RMS 归一」把带压坏——**A 的可量化抓手**。
- **最小原型**：新增 `引擎_v8_噪声支路.py`（开关默认关 = 与 v7 sha256 逐位同）+ `韵律_v10.py`（只给 p/t/k VOT 写噪带轨迹）+ `闸门_声学.py`；**先过声学门（p<k<t 单调且极差≥800Hz、s/sh/x 不退化）再跑双集**。
- **自估**：筛选 Δ 点估 −0.02，P(过筛选)≈0.30，P(双集可迁移)≈0.15；**完整 A 到 CER≤0.45 只给 ≤10%，最可能 0.50–0.52**。
- **失败判据（先定）**：声学门两次不过=实现失败；门过但 Δ>−0.01=原型失败；**门过且 Δ>0 ⇒「缺部位谱线索」被证伪 ⇒ A 关掉**；筛选过但留出不过=不可迁移。

### 席 B · `puban-shengyin`（谱_亚版本_声库：谱包络单元）
- **路线**：浊段走 `引擎_v7` **逐位不变**；只把**噪段**从「1–2 个谐振器参数」换成「**每音素每阶段 64 带 log 能量包络单元**」（按 `音韵_v5` 部位/方式规则确定性生成，FFT OLA + 段间插值 + 10ms 渐变）。
- **关键新读码发现**：擦↔塞擦缺口是**构造性**的——`音韵_v5` 里 **s/z/c 的频带与爆破带逐字同 (6800,2200)**；sh/zh/ch (3300,1500)；x/j/q (5000,1900) ⇒ 引擎噪声支路只有 1–2 个二阶谐振器，**表示层就无法给出「形状差」**。这解释了 12 个全局旋钮全中性是**必然**。
- **最小原型**：`谱包络单元_声库.py`（`韵律_v9` 子类覆写 `说()`，与量具工厂兼容；`w=0` 与 v9 逐位同）+ `实验_B_双集.py`；新层估 +5–15ms/句。
- **自估**：筛选 −0.03±0.03、留出 −0.02±0.03；**P(双门槛) 40–50%**；C10 守法 4 条（参考录音只在离线、只以 1 个冻结标量进入、运行期读音频=0、回放冒充 must-fail ≤0.5）。

### 席 C · `fayin-qiguan`（发音器官模型）
- **路线**：时变声道面积 A(x,t)（34段×5mm）+ 鼻支路面积 + ABCD 传输线 → 噪声由「源在收紧点 + 前腔响应」生成；浊音仍走 v7。
- **关键实测**（`原型/探针_前腔共振.py`）：几何+文献源谱预测 s/x/sh = **5247/4497/4460** vs 实测 6620/4914/3338；P1 排序 PASS、P2 中位误差 0.21 PASS、P3 单标量 β=0.86 PASS；但理想源下三音全塌 12.2–12.7kHz、x/sh 只差 37Hz、唇齿 f 失配 9649 vs 3708（预注册模型缺口）。
- **结论（自己说的）**：**C 不该是首选**——10ms 帧栅格吃掉 C 独有的亚帧线索；部位谱已证不是缺口；全量 8–15 人日。
- **自估**：1 天原型 ΔCER 点 −0.01、区间 [−0.025,+0.005]，**大概率不过门槛**；失败判据先定（门槛不过 / 相对 A-手调臂 Δ≤0 / p/t/k+b/d/g 类错降<15%）。
- **排序建议**：**A（0.5–1 人日，先量残余头寸）→ C 探针（条件性）→ B（最后）**。

1. 调参/加幅度的路已死（16 条件全负）。
2. 「对音韵目标保真」≠「对 ASR 可懂」（c13/c16/c17 三次同向反证）。

## 4. Lead 收口（裁决）

> 依据：`00_分析` §0/§6（判定=回去开会）＋ 三席立场 ＋ 本轮 16 条件负结果。

1. **判定**：按所有者给的规则「没有可迁移增益 ⇒ 回去开会」，**开会结论 = 关掉「同表示调参」**。
2. **但方向不换**：C1/C10/C13 下的参数化内生路线**继续保留**；换的是**层**与**方法**（先声学门、后 ASR 双集；不再手调连续常数）。
3. **只开一个最小原型：A 路线**（≤1 人日），验收分两级：
   - **第 1 级（不花 ASR）**：`闸门_声学.py` —— p/t/k VOT 谱重心 **p<k<t 单调且极差≥800Hz**；s/sh/x 三分类 **≥90%**；`开关关` sha256 与 v7 逐位同；两趟逐位同。
   - **第 2 级（过门才跑）**：筛选 18 样本 Δ≤−0.03 → 留出 18 样本 Δ≤−0.02 → 两趟/sham/音节率/峰值。
   - **判死条款（先定）**：门过但筛选 Δ>−0.01 ⇒ A 停；门过且 Δ>0 ⇒ 「缺部位谱线索」被证伪，A 关掉、转讨论 B（且必须先做 C10 边界审计）。
4. **C 不做**：C 席自己判定不该首选；其探针结论（几何排序 PASS、f/齿音是模型缺口、10ms 栅格吃掉亚帧线索）登记进证据，不作路线。
5. **B 押后**：B 的 64 带包络是 A 的「升级同接口」；先等 A 的第 1 级结果。若 A 门过但 CER 不动，再开 B；B 开工前先交「C10 4 条守法」的独立审计脚本（运行期读音频=0 计数断言）。
6. **人耳锚点 = 前置条件**：在 A 的第 2 级之前，所有者先听 v8.1（6 句×3 角色）给可懂度评分；若人耳评分与 ASR CER **不一致**（很可能），则下一轮的目标函数改为「人耳评分（主）+ ASR（辅）」。
