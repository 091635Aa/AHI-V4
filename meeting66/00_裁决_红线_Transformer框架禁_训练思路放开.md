## 2. 允许 / 不允许（本轮执行口径）

| 项 | 是否允许 | 说明 |
|---|---|---|
| 从零训练**非 Transformer** 神经网络（Conv1D/GRU/MLP，无 attention/无自注意力主干） | **允许** | 可用 torch 训练与推理；含生成路径（发声） |
| 深度学习的**训练思路**（反向传播、梯度下降、自监督、强化/进化、蒸馏） | **允许** | 但「蒸馏/教师」若来自外部模型，须登记为外部仪器，且生成路径只落本仓自产参数 |
| 自训练权重（本仓数据训练出的 `.pt`）进入生成路径 | **允许** | 这是本项目"内生"的产物；须登记数据来源/架构/种子/sha256 |
| 第三方**预训练**权重（含"只用于初始化"） | **仍不允许**（须所有者逐案签字） | C10 精神：外挂模型不当器官；本轮不给口子 |
| **Transformer 架构**（attention/自注意力主干、Transformer block、其预训练权重、第三方推理栈） | **仍禁止** | 这就是"禁止这个框架的应用" |
| 外部模型当**判据门/器官**（含 ASR 进生成路径） | **仍不允许** | ASR 只作**离线评估仪器**（meeting63 §5 / meeting65 L1a 口径），登记后可用 |
| 外部模型当**离线裁判/伪标签源** | **灰区，本轮不用** | 本轮数据已有所有者自备标注（`asr_opt` 训练清单），无需 ASR 伪标签；如要，须逐案登记 |
