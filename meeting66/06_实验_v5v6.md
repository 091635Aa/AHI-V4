# meeting66 · 06 实验 v5/v6 —— 自条件（上一帧输入）：拟合突破，但推理曝光偏差

> 2026-10-20 ｜ 只新增 `meeting66/`（C14）｜ ASR = 离线外部仪器（只评估）
> 承接 `05_实验_v3v4.md`：v3/v4 证明「喂更多 phoneme 上下文+加时长」都拟合不了（train loss 平台 0.48）。
> 本轮换思路：**把前 K 帧声学帧作为输入**（不引入 attention/Transformer，仍是纯 Conv）。

---

## 1. v5 架构（自条件，teacher forcing）

| 项 | 值 |
|---|---|
| 输入 | 音节音素嵌入 + 帧级 10 维特征 + **前 K=2 帧归一化 mel**（训练用真值，t<k 补 0） |
| 输出 | 当前帧 log-mel [T,80] |
| 参数 | 1,506,464（1.5M）；无 attention/Transformer/预训练 |
| 训练 | v3 数据（2.7h）；20 分钟预算；525 轮；train loss **0.676→0.015**，val **0.457→0.0179**，最佳 **0.01252@506** |
| 训练/验证损失 | 相比 v2a 的 0.813 / v3 的 0.48 **下降 30–60 倍** ⇒ 「拟合不了」的根因确认是**输入缺声学上下文** |

## 2. v5 推理（迭代自条件，3 pass）—— 失败：退化重复

`[实测]` 推理时 prev 只能来自模型自己：先 `prev=0` 得粗 mel → `prev=shift(粗)` 再跑 → 共 3 轮。
双集 ASR：

| 集 | v5 CER | v8.1 SpeakerA | v2a（旧最佳） |
|---|---|---|---|
| 历史 6 句 | **1.0271** | 0.5853 | 0.9386 |
| 留出 6 句 | **1.0331** | 0.6893 | 0.9476 |

转写几乎全是 **「嗯 的 没 有 没 有 …」「没 有 意 有」** 的**退化重复**（每句两趟一致）。
⇒ **典型曝光偏差（exposure bias）**：训练时 prev 是真值，推理时 prev 是模型自己的平滑输出；
自条件回路把「平滑」放大成退化重复。**teacher forcing 的拟合优势在推理端没有兑现。**

## 3. v6：计划采样（scheduled sampling）—— 有效改善

- 训练时以 p=0.5 把「真值 prev」替换为「模型自己（无 prev）的粗输出 prev」，让模型学会**修正自己的粗输出**；
- `[实测]` 1.5M、上一帧数 2、v3 数据、18 分钟、441 轮；train 0.843→0.365，val 0.534→0.046（最佳 0.0407@423）；C13 两趟逐位同、审计命中 0。
- **双集 CER（新最佳）**：

| 集 | v6 CER | v2a（旧最佳） | v8.1 SpeakerA | Δ vs v2a |
|---|---|---|---|---|
| 历史 6 句 | **0.8865** | 0.9386 | 0.5853 | **−0.052** |
| 留出 6 句 | **0.8534** | 0.9476 | 0.6893 | **−0.094** |

- 转写开始出现**真实词**：S10「追着我我们一起去爬山」（真值「这个周末我们一起去爬山」）、S6「请问是啥时年吗？」等；不再全是「没有没有」。**S10 CER 0.4615 已低于 v8.1 同句**。

## 4. v7 / v8 迭代精炼：**负结果**（v6 仍是最佳）

目标：把 2 轮迭代写进训练图（第 1 轮 prev=0 → 第 2 轮 prev=第 1 轮输出，可导），让训练与推理（3 轮）一致。

| 版本 | 做法 | 结果 |
|---|---|---|
| v7 | **从零**迭代训练（2 轮图内） | 70 轮 val 仍 **0.90**（v6 同期 0.11）⇒ 从零学不动，提前停 |
| v8 | **从 v6 微调**、损失只算末轮 | val 从 0.059（v6）→ **0.33** 退化（只优化末轮把第 1 轮带偏）⇒ 停 |
| v8b | 从 v6 微调、**两轮都算损失**、lr 5e-5 | val 从 0.050 → **0.28** 仍退化，最佳@1（即 v6 本身）⇒ **不采纳** |

**判读**：v6 的能力来自「从**教师式 prev** 修正」；把第 1 轮强行改成 prev=0 的粗输出会破坏这个能力。
迭代精炼要成立，需要先让「prev=0 的第 1 轮」本身足够好（例如先单独训练一个粗模型 / 两阶段课程），
不是把 2 轮直接塞进同一张图。**这条负结果已登记，不再尝试同形做法。**

## 5. 当前最好版本：**v6（计划采样 + 自条件）**

| 指标 | v6 | v2a（旧最佳） | v8.1 SpeakerA基线 | 目标 |
|---|---|---|---|---|
| 历史 6 句 CER | **0.8865** | 0.9386 | 0.5853 | ≤0.35 |
| 留出 6 句 CER | **0.8534** | 0.9476 | 0.6893 | ≤0.35 |
| 教师强制 val loss | **0.0407** | 0.8128 | — | — |
| C13 | 两趟逐位同 | 同 | — | 必须 |

⇒ **离可懂（≤0.35）还差 0.5 左右；离 v8.1（0.585）也还差 0.27。** 但趋势是正的：
v2a 0.94 → v6 0.89（历史）/0.95→0.85（留出），且 S10 单句 CER 0.4615 已低于 v8.1。

## 6. v6 推理端扫描（迭代次数 / 阻尼）—— 找到了「3 轮」这个甜点

推理是「迭代自条件」：第 1 轮 prev=0，之后用上一轮输出作 prev。扫两个量（同一 v6 ckpt、同一双集）：

| 迭代次数 | 阻尼 | 历史 CER | 留出 CER | 备注 |
|---|---|---|---|---|
| 1 | 1.0 | 1.0000 | 1.0000 | 只用 prev=0 的粗输出 ⇒ 不可懂 |
| 2 | 1.0 | 0.9733 | 0.9199 | |
| **3** | **1.0** | **0.8865** | 0.8534 | 之前登记的最佳 |
| 5 | 1.0 | 0.9896 | 0.9056 | **过迭代漂移** |
| 5 | 0.5 | 0.9688 | 0.8789 | 阻尼缓解漂移 |
| 3 | 0.5 | 0.8993 | 0.8020 | 留出改善、历史略差 |
| **3** | **0.7** | 0.9004 | **0.7926** | **留出最好**；历史略差 |
| 4（待） | 0.7 | — | — | |

**判读**：
1. **迭代次数存在甜点（3）**：>3 会误差累积漂移；1 轮完全不可懂 ⇒ 「自我修正」是有效的，但需要控制。
2. **阻尼（与上一轮估计做指数平均）能把过迭代漂移变成增益**：3 轮 + 阻尼 0.7 留出 CER 0.8534→**0.7926**，但历史集略升 0.8865→0.9004。
3. 「历史 vs 留出」不一致 ⇒ 不能把单集当结论；下一步应把**阻尼自条件写进训练**（训练时就用阻尼 prev），而不是只在推理端调。

## 7. v9 长训（30 分钟继续训）—— 教师强制 val 更好，但**推理更差**（关键教训）

从 v6 ckpt 继续训 30 分钟（lr 1e-4、p=0.5、792 轮）：教师强制 val **0.0407→0.0216**（几乎减半）。
但推理双集：

| 版本 | 教师强制 val | 推理迭代/阻尼 | 历史 CER | 留出 CER |
|---|---|---|---|---|
| v6 | 0.0407 | 3 / 1.0 | **0.8865** | **0.8534** |
| v6 | 0.0407 | 3 / 0.7 | 0.9004 | **0.7926** |
| **v9** | **0.0216（更好）** | 3 / 1.0 | **0.9861（更差）** | **0.8714（更差）** |
| **v9** | 0.0216 | 3 / 0.7 | 0.9282 | 0.9344（更差） |

**教训（写入下一轮纪律）**：
1. **教师强制 val loss 不能用来选模型**——更小的 val 反而推理更差；
2. 长时间 teacher-forced / p=0.5 训练会让模型越来越依赖「教师式 prev」，**曝光偏差变大**；
3. 模型选择必须用**推理后的双集 CER**（或至少一小集 ASR），不能只看 val。

## 8. v10：高自条件概率微调（p=0.9，进行中）

- 从 **v6**（不是 v9）出发，lr 5e-5、p=0.9（训练时 90% 用模型自己的 prev）、10 分钟；
- 目的：把训练分布推向推理分布，压低曝光偏差；产物 `产物/模型_v10_高自条件/`；
- 验收：双集 CER ≤ v6 的 0.8865/0.8534。

## 8. v10：高自条件概率微调（p=0.9）—— 教师强制 val 变差、最优仍退回 v6 初始

- 从 v6、lr 5e-5、p=0.9、10 分钟：教师强制 val 0.0376→**0.0527**（越训越差，因 90% 用自产 prev）；
  脚本按 val 选 best ⇒ 最优@第 9 轮（≈v6 初始状态）⇒ **ckpt 实质 = v6，无可测增益**。
- 教训：**p 不能恒定调高**；需要 **p 从 0→0.9 的课程（scheduled sampling ramp）**，且**选择指标不能用 teacher-forced val**。

## 9. 本轮结论（阶段性）

1. **新最佳仍是 v6**：历史 0.8865 / 留出 0.8534；加推理阻尼 0.7 后留出 **0.7926**（历史 0.9004）。
2. **教师强制 val 不是有效的模型选择指标**：v9 把 val 从 0.0407 降到 0.0216，推理反而从 0.8865/0.8534 退化到 0.9861/0.8714。
3. **曝光偏差是当前主要矛盾**：训练越长、越依赖教师式 prev，推理越差；恒定 p 或高 p 都不是解。
4. **推理端有可控增益**：迭代 3 轮是甜点（1/2/5 都更差），阻尼 0.7 把留出 CER 从 0.8534 压到 0.7926。
5. 仍远未可懂（目标 ≤0.35），也仍差 v8.1（0.585）。

## 10. 第四轮：计划采样 ramp + 周期保存 + **按推理 CER 选模型**（v11/v12）

### 10.1 做了什么
- `模型_学说话.py` 新增：`--自条件ramp N`（p 从 0 线性升到 0.9）、`--周期保存 N`（每 N 轮存 `ckpt_e{N}.pt`）、训练结束存 `ckpt_末.pt`；
- 新件 `实施/选模型.py`：对每个候选 ckpt 合成 **3 条预注册探针句**（P1–P3，与训练/评测集都不重合）→ ASR → CER 排序选 best（不用 teacher-forced val）；
- v12：从 v6 出发、ramp 250 轮、p 最大 0.9、周期保存 20、14 分钟（359 轮，19 个候选 ckpt）。

### 10.2 关键结果：**val 选模型确实会选错**
| 候选 | 选择依据 | 探针 CER |
|---|---|---|
| `ckpt.pt`（best-val 0.0226@104） | teacher-forced val 最好 | **0.8928** |
| `ckpt_末.pt`（ramp 收尾） | 无 val 优势（final val 0.0727） | **0.8030（最好）** |

⇒ 按推理 CER 选出了 `ckpt_末.pt`，比 val 选出的 ckpt 探针 CER 低 **0.09**。**「按推理 CER 选模型」机制验证成功。**

### 10.3 但 eval 双集上没有赢 v6
| 模型 | 推理设置 | 历史 CER | 留出 CER |
|---|---|---|---|
| **v6** | 3 轮 / 无阻尼 | **0.8865** | 0.8534 |
| **v6** | 3 轮 / 阻尼 0.7 | 0.9004 | **0.7926（最好）** |
| v12 末 | 3 轮 / 无阻尼 | 0.8976 | 0.8435 |
| v12 末 | 3 轮 / 阻尼 0.7 | 0.8987 | 0.8257 |

⇒ **探针选择没有完全迁移到 S1–S12**（探针上 v12末 0.803 < v6 ~0.89，但双集上两者持平/略差）。
说明「选模型」还需要**与评测同分布、但不参与评测的验证集**（当前 S7–S12 已用于报告，不能再用作选择）。

### 10.4 本轮结论
1. **按推理 CER 选模型**的机制已落地并可复现（`选模型.py` + `选模型.json`）；
2. **ramp 训练本身**在本数据/架构上没有超过 v6；曝光偏差仍是主要矛盾；
3. **当前最佳不变**：历史=v6（0.8865）、留出=v6+阻尼0.7（0.7926）；离可懂 ≤0.35 仍差 0.45 左右；
4. 下一步：新建**独立验证集 S13–S18**（与探针/评测都不重合）用于选模型；架构侧 P1（K=4/8、通道 320）与 P2（F0/浊音+谐波声码器）；数据扩到 ≥10h。

### 17.1 AR v1（teacher forcing，25 分钟 / 130 轮）
- 结构：音素+帧特征 → Conv 编码器 [T,C]；GRU(384) 逐帧：`[上下文_t, 声学投影(mel_{t-1})]` → `mel_t = 输出(h) + 旁路(mel_{t-1})`；2,353,312 参数；

### 17.2 AR v2（AR 版计划采样，30 分钟 / 109 轮）

### 17.3 AR v3（60 分钟续训）与 v4（自由运行微调）——未达 v13，但方向已闭环

### 20.5 结构诊断（为什么失败，比「再训久点」有信息量）

同一句的未标准化 log-mel：v18 零起点 N1 = mean −10.48 / **std 1.29** / **帧间 0.031**；零起点 N4a = std 0.84 / 帧间 0.126；**噪声 Z4a = std 1.75 / 帧间 0.574**（真 mel = −11.04 / 3.49 / 0.527；v13 = −9.16 / 2.23 / 0.190）。

1. **确定性零起点 → 塌到条件均值**（std ≪ 真值，迭代越多越平滑）⇒ 生成自由度被轨迹抹掉；
2. **噪声起点 → 方差/时间变化量级接近真值，但逐帧独立采样 ⇒ 帧间不相干**，ASR 转写为空/单字；
3. ⇒ **帧级条件 flow 的「生成自由度 vs 时间相干性」冲突**；v13 的「条件均值 + 局部自条件 + 阻尼」恰好同时保住「不太噪」和「有包络」，这是它 0.83 的来源。

### 20.6 判定（写入结论）

1. **判据（预注册 §5.5）不成立 ⇒ 无效（负结果）**：双集 1.0375/1.0028，差 v13 约 +0.20/+0.25；
2. **排序不变**：并行回归 v13（0.8327/0.7533）> AR（0.9647/0.9297）> 帧级条件 flow（≈1.0）> 精炼器/对抗（≈1.0）；
3. **不是训练量单因素**：P 探针 500 轮无趋势，而 CFM 损失仍缓降（与 AR v7 同型）；
4. **下一步**：数据扩容（所有者新录音 ≥8–10h）仍是**唯一被反复证明的硬瓶颈**；若继续 flow 路线必须改**整句联合生成**（整段 flow/全局潜变量 + Conv 解码，仍非 Transformer），属更大实现且在 2.7h 上未验证——**不建议在扩数据前投入**；
