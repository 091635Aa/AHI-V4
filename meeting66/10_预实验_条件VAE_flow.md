## 1. 边界与目标（先说清楚这是什么、不是什么）

- 这是**预实验**（约 36 分钟训练 + 选择/报告各一次），**不是**新主线，也不改变 `08_当前最佳与复现.md` 的当前最佳；
- 目标只有一个：在与 v13 **同数据、同评测、同成本量级**的条件下，回答「**把核心从 L1 并行回归换成条件 flow，双集 CER 有没有可能更好**」；
- 不保证在 2.7h 数据上有效；若无效，交付**可复现的负结果 + 失败位置**，而不是「再训久一点就会好」。

## 2. 为什么是 flow（而不是逐帧 cVAE）——「最小参考」的取舍

「条件 VAE/flow」是路线名；本预实验选 **条件 Flow Matching（CFM）** 作最小参考实现，理由：

1. mel 是连续 80 维、10ms 帧级；**逐帧 cVAE 的先验采样**（z~N(0,I) 每帧独立）会引入帧间不相干噪声，推理端还要处理 KL/后验塌缩，最小实现反而更重；
2. CFM 只需要一个**速度场** + **Euler 积分**，训练目标是一行回归，**与 v13 的训练/推理框架可以逐件对齐**（同编码器、同前 K 帧自条件、同迭代阻尼），这样「换核心」的对照才干净；
3. CFM 的两种采样起点都满足 C13：固定种子的噪声起点（x0~N(0,I)，与训练同分布）与零起点（x0=0，先验中心）都逐位可复现。**零起点只是候选**（它是先验中心处的一条确定性积分轨迹，未必与训练分布一致），不是先验指定；最终由 S13 网格选择（复核 F-01 修正）。

参考：Lipman et al., *Flow Matching for Generative Modeling*, ICLR 2023（CFM 目标：x_s=(1−s)x0+s·x1，学 v=x1−x0）。

## 3. 最小参考实现（`实施/模型_条件流.py` 的全部内容）

| 组件 | 实现 | 与 v13 的关系 |
|---|---|---|
| 编码器 | 音素(声母/韵母/调)嵌入 ⊕ 10 维帧特征 ⊕ 前 K=4 帧 mel → Linear→LN→Conv1D 残差堆（核 5、dilation 1/2/4/8/16、通道 320）→ 上下文 [T,320] | **同构**（直接复用 `模型_学说话.残差块`），保证对照只差「核心」 |
| 速度场（核心） | `v(x_s, s \| 上下文) = 输出卷积( 头残差堆₂( 融合([上下文, x_s, 正弦时间嵌入(s)]) ) ) + 线性(x_s)` | 新增（替代 v13 的 1×1 回归头） |
| 训练 | x1=真 mel（逐带标准化域），x0~N(0,I)，s~U(0,1)，x_s=(1−s)x0+s·x1，损=**掩码 MSE(v̂, x1−x0)**；自条件 p=0.5（先滚 4 步粗估，按 0.7/0.3 与真值混合当 prev） | 同数据/同 batch/同预热 300 步/同裁剪 1.0/同周期保存 50 |
| 推理 | Euler 积分 s:0→1（步数 8–16；**零起点 x0=0 确定性主模式**，噪声起点为对照）→ 迭代自条件 + 阻尼（与 v13 `合成mel` 同款） | 同款迭代阻尼框架 |
| 参数量 | 3,591,008（3.59M） | v13 = 2,854,688（2.85M）；多出的是速度头 |
| 红线 | 无自注意力/Transformer/预训练/第三方推理栈（C1）；只读本仓自训练 ckpt（C10）；同 ckpt 两趟推理 mel 逐位同（C13）；只新增文件（C14） | — |

**不做的**（控制变量）：不换编码器、不换数据、不换声码器（Griffin-Lim 64 迭代/种子 0）、不换 ASR、不引入 U-Net/多尺度/判别器/精炼器。

## 5. 预注册（先于任何 v18 读数）

1. **训练**：36 分钟、周期 50 轮、种子 300；主损失 = CFM 掩码 MSE；自条件 p=0.5/步数 4/阻尼 0.7；
2. **选模型**：P1–P3 预筛全部周期 ckpt（默认推理设置）→ 取前 2 名进 S13；
3. **选推理设置**：S13–S18 × **11 组预注册设置**（零起点 N1/N3a/N4a/N4b/N7a/N4c/N4s16 + 噪声起点 Z3a/Z4a/Z7a/Z4c；见 `选模型_条件流.py` 网格），按**整组均值 CER** 取最小；两候选差 <0.02 视为持平，取更早/更简单者（复核 F-01：训练用 x0~N(0,I)，零起点不在训练分布，故噪声起点必须参赛，不能先验指定零起点）；
4. **报告**：用选中（ckpt, 设置）在 **S1–S12 只报告一次**；对照表 = v13 历史 **0.8327** / 留出 **0.7533**、AR v7 0.9647/0.9297、v8.1 0.5853/0.6893；
5. **判据（先写死）**：
   - **成功（值得继续投入）**：双集同时 ≤ v13 对应读数（历史 ≤0.8327 且留出 ≤0.7533），或任一集比 v13 好 >0.02 且另一集不差 >0.02；
   - **无效（负结果）**：双集均差于 v13，或只有单集小幅改善（<0.02）；
   - 无论哪种，都记录「损失曲线 / 生成 mel 结构 / 逐句转写」，用于判断失败在**训练量**、**条件表达**还是**flow 采样**。

### 6.5 结构诊断（失败位置）

同一句「今天的风很轻，适合慢慢地说一会儿话。」（未标准化 log-mel 域）：

| 生成源 | mel 均值 | mel 标准差 | 帧间平均变化 | 逐带时间 std 均值 |
|---|---|---|---|---|
| v18 N1（零起点，1 遍） | -10.48 | **1.29** | **0.031** | 0.17 |
| v18 N4a（零起点，4 轮） | -13.64 | **0.84** | 0.126 | 0.51 |
| v18 Z4a（噪声，4 轮） | -12.37 | 1.75 | **0.574** | 1.41 |
| v13 4轮/0.5 | -9.16 | 2.23 | 0.190 | 1.40 |
| 真 mel（数据样本 0075） | -11.04 | **3.49** | 0.527 | 3.27 |

**读法（这是本预实验最有信息量的部分）**：
1. **零起点确定性积分 → 塌到条件均值**：std 1.29（N1）/ 0.84（N4a）≪ 真值 3.49；迭代越多反而越平滑（阻尼把估计拉向 flow 的不动点）⇒ 生成自由度被确定性轨迹抹掉；
2. **噪声起点 → 方差/时间变化量级对了**（std 1.75、帧间 0.574 ≈ 真 0.527），但**逐帧独立采样** ⇒ 谱结构在帧间不相干，ASR 转写为空/单字（S13 上 Z 组全 1.0）⇒ 时间相干性丢失；
3. **v13 对照**：std 2.23、帧间 0.190（同样过平滑，但仍保住足够的谱包络让 ASR 拿到 0.83）——**v13 的「条件均值 + 局部自条件 + 阻尼」恰好同时满足「不太噪」和「有时间结构」**。

## 7. 判读与诚实边界

1. **结论**：在 2.7h 数据 + 36 分钟预算 + 3.59M + 最小参考实现下，**帧级条件 flow 核心无效**（双集 1.0375/1.0028，差 v13 的 0.8327/0.7533 约 +0.20/+0.25），也不如 AR（0.9647/0.9297）；**不改变 `08_当前最佳与复现.md` 的当前最佳**。
2. **失败位置**（比「再训久一点」更有信息量）：帧级条件 flow 的**生成自由度与时间相干性不可兼得**——确定性零起点 → 条件均值塌缩；噪声起点 → 帧间独立噪声、时间结构丢失。要同时拿到两者，必须做**整句联合生成**（潜变量/整段 flow 去噪），而不是逐帧条件。
3. **不是训练量单因素**：P 探针 500 轮无趋势（0.97–1.00 平），而训练损失仍从 0.17→0.10、验证 0.048→0.020 缓降——与 AR v7「损失降、CER 触顶」同型。
4. **与 AR 的排序**：AR 至少把 CER 从 1.0 拉到 0.93（逐帧条件在已生成帧上，天然保有短时相干）；帧级 flow 连这一步都没有（≈1.0）⇒ **在当前数据量下，时间结构的建模方式比边际分布的表达能力更决定可懂度**。
5. **若继续 flow 路线**：必须改**整句联合生成**（整段 flow / 全局潜变量 + Conv 解码），这是更大的实现（接近 U-Net 级结构，仍可不用 attention），且在 2.7h 上未经任何验证；**不建议在数据扩容（所有者新录音 ≥8–10h）之前投入**。
6. **边界（必须一起读）**：
   - 这是**预实验**：只测 36 分钟预算、只测帧级 CFM、只测单一最小参考实现；不宣称「flow 在更多数据/更长训练/整句实现下一定无效」；
   - 训练/推理同一因式分解只在「编码器条件 + 迭代自条件」意义上成立；零起点与训练先验不同分布（复核 F-01），已用噪声起点对照覆盖；
   - 声码器（Griffin-Lim）、ASR 仪器、S1–S12 口径均未改动；GPU/CPU 两趟推理逐位同已测；
   - 单说话人（SpeakerA）；预实验产物不进入「当前最佳」。
