# meeting66 · 03 首跑结果与诊断 —— 非 Transformer 神经 TTS v1：**声码器可用，声学模型塌缩**

> 执行：Lead + 3 队友（T-D 数据 / T-E 模型 / T-F 声码器与评测）｜2026-10-20｜只新增 `meeting66/`（C14）
> 口径：`[实测]`＝真跑；ASR = 离线外部仪器（Paraformer-seaco，不进生成路径）。

## 0. 一句话

**「音素 token → 学习的 log-mel → Griffin-Lim → 波形」这条链**里，**声码器 + ASR 仪器链路完全可用**（真 mel 回放 CER **0.0345**），
但**声学模型 v1 塌缩成「平均谱」**（合成 mel 的帧间变化只有真 mel 的 **9.3%**）⇒ 12 句可懂度 **CER 1.000 / 0.973**，**比 v8.1 更差**。
根因已定位：**训练对齐是「按音节均分」的假对齐**，模型学不到音素↔帧的时间结构。下一步 = 用 ASR **字符级时间戳**只做时间对齐（标签仍用所有者转写），重建数据后重训。

## 4. 根因诊断（`产物/判据/诊断_mel结构.json`）

| 指标 | 模型合成 mel | 真 mel | 比 |
|---|---|---|---|
| 帧间变化 | **0.071** | **0.768** | **9.3%** |
| 带内时间标准差 | 0.409 | 3.550 | 11.5% |
| 相对训练均值 | 0.14–0.17σ | — | 几乎=均值 |
| 带均值轮廓相关 | **0.92–0.93** | 1.0 | 只学到「平均谱包络」 |

**结论（分层，互不混淆）**：
1. **声码器无罪**：真 mel → Griffin-Lim → ASR = 0.0345 ⇒ 采样率/GL/写盘/ASR 链路都可用。
2. **声学模型塌缩**：它只预测「平均谱包络」，**帧间不变** ⇒ GL 输出稳态嗡鸣 ⇒ ASR 听到「嗯」。
3. **v1 模型的失败原因（按证据排序）**：
   - **假对齐**：训练时把 60s 的帧按音节数**均分**，同一音素在不同样本里的帧位置不一致 ⇒ 模型只能学平均；验证损失第 9 轮后反向 = 在拟合样本级 idiosyncrasy，而非音素映射。
   - 训练步数/容量/早停：1.47M 参数 vs 159 句 60s，val 只有 8 句（早停点不可信）。
   - 损失：纯 L1 在标准化 mel 上，均值预测已是 ~0.8；模型没有动力学约束（虽有时间差分项 0.05，权重偏小）。

## 5. 第二步（v2a）：ASR 时间戳真对齐 → 重训 → 复评

| 项 | 实测 |
|---|---|
| 对齐数据 | 162/167 有效（5 条因 ASR↔转写匹配字符过少丢弃）；总 **9291s（2.58h）**、总音节 30839、**音节率 3.32/s**；音节帧数中位 **23**（p5 10 / p95 51）——不再均分 |
| ASR 用途 | **只提供字符级时间戳**（`return_timestamp=True`，离线、CPU/GPU 仪器）；标签仍用所有者清单转写；已登记 `00_裁决` |
| 重训 | 同架构/同损失（原配方）：154 训练 / 8 验证；**255 轮早停（最佳 0.8128@55）**，620s；训练 0.949→0.622，验证 0.892→0.850 |
| 双集 CER | 历史 **0.9386**（v8.1 SpeakerA 0.5853，Δ +0.353）；留出 **0.9476**（v8.1 SpeakerA 0.6893，Δ +0.258） |
| 阳性对照 | 同样本真 mel → GL → ASR **CER 0.0345**（不变） |
| **mel 结构** | 帧间变化 **0.196**（真 mel 0.768，比 **25.5%**；v1 是 9.3%）⇒ 对齐后**时间结构恢复了 2.7 倍**，但仍只有真 mel 的 1/4 |
| C13/工程 | 两趟转写一致、推理两趟逐位同、sham 1.0/1.0、音节率 4.374/s、审计命中 0 |

**判读**：真对齐**有效但不够**——模型从"稳态嗡鸣"前进到"有音节起伏的含糊语音"，但离可懂仍远（0.94）。下一步配方已跑（v2b：时间差分损失 0.05→0.30、权重衰减 1e-4→5e-4、预热 300→100），结果见 `04_现状与下一步.md`。

## 6. 诚实边界

1. v1 **不是**「学说话成功」；它是「管线打通 + 失败可归因」。
2. 数据是所有者自备口语语料（含口误/噪声），音色=SpeakerA；本版**不做音色/情感**。
3. 训练端 GPU 浮点不保证跨机逐位复现；C13 只保证**推理**两趟逐位同（已实测）。
4. 阳性对照只证明「mel→波→ASR」链路；不代表模型输出会可懂。
