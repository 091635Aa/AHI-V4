## 2. v3 大模型（N3：2.75M 参数）—— 结果更差

| 项 | 实测 |
|---|---|
| 架构 | 同非 Transformer Conv1D，**通道 320、dilation 1/2/4/8/16（2,752,288 参数）** |
| 训练 | v3 数据（159/8）；255s→实际 830s 早停于 320 轮（最佳 val 0.8425@20） |
| 训练/验证 loss | 0.929→0.479 / 0.867→0.918（**第 20 轮后 val 反向**，train 继续降） |
| 双集 CER | 历史 **0.9768**（v8.1 SpeakerA 0.5853，Δ +0.392）；留出 **1.0000**（Δ +0.394） |
| 结论 | **比 v2a（0.9386/0.9476）更差 ⇒ 不采纳**；ckpt 留作对照（`产物/模型_v3_大/`） |

## 3. 记忆化诊断（关键）：**不是不泛化，是连训练句都拟合不了**

对 **v2a 模型（当前最佳）** 取 3 条**训练集句子**（同说话人、同录音条件）合成 + ASR：

| 训练样本 | 每音节帧数 | 合成 mel 帧间变化 | 真 mel 帧间变化 | CER |
|---|---|---|---|---|
| 0000 | 75 | 0.108 | 0.367 | **1.000**（ASR 转写为空） |
| 0001 | 36 | 0.160 | 0.629 | **1.000**（空） |
| 0002 | 30 | 0.173 | 0.775 | **1.000**（空） |

⇒ **模型对训练数据本身都只输出“平均谱 + 弱起伏”**，连记忆都做不到。
⇒ 之前“val 第 9/20 轮后反向 = 过拟合”的解读**不成立**：train loss 仍在降（0.62→0.48），
**val 反向来自 8 样本验证集噪声/分布差异**，早停（早停轮 120–300）把训练**过早停掉**了。
**真正的瓶颈是“训练不足/收敛太慢”**，不是“过拟合”。

## 4. v4 长训（已跑，提前收口）

- 数据 v3、同 2.75M 架构、**关掉早停（早停轮 5000）**、25 分钟预算、轮上限 5000；
- 目的：验证“train loss 继续下降后，训练句 CER 是否下降”。
- `[实测]` 跑到 **270 轮**时 train loss **0.479**、val 0.901，且 train 已**平台**（最后 6 轮 0.477–0.486 抖动）⇒ 判定“再训无用”，提前停止（用时 10.5min）。
- `[实测]` 用 v4 ckpt 做**训练句记忆化诊断**：3 条训练句 CER 仍 **1.000 / 1.000 / 1.000**（转写空/the），合成 mel 帧间变化 **0.084 / 0.131 / 0.128**（真 mel 0.367/0.629/0.775）⇒ **长训没有改善“过度平滑”**。

## 5. 追加诊断：token 路径是通的（排除代码 bug）

`诊断_token依赖.py`（v2a ckpt）：合成 撒/沙/八/妈/衣/乌/啊，两两 mel 平均绝对差 **0.58–1.74**（mel 全局 std ≈1.5–1.8）⇒ **模型输出确实随音素变化**，不是“embedding 没接上”的 bug；问题是**预测的谱形粗糙/过度平滑**，不是完全不依赖输入。

## 6. 本轮的硬结论（更新）

1. **对齐升级（v3）没有转化为 CER**：v3 大模型 0.9768/1.0000 比 v2a 0.9386/0.9476 **更差**。
2. **不是泛化问题**：连**训练句**都 CER 1.0、mel 起伏只有真值的 1/4–1/5 ⇒ 模型**连训练集都拟合不了**（欠拟合/过度平滑）。
3. **不是训练时长问题**：v4 关掉早停后 train loss 平台在 0.48，val 0.90；长训无改善 ⇒ 现有架构+损失（非自回归 Conv1D + 归一化 mel L1）**表达不出**可懂所需的谱细节。
4. **不是代码接线 bug**：token 依赖已验（差异 0.58–1.74）。

## 7. 下一步（据以上证据，换架构而非加时长）

| 优先级 | 动作 | 理由 |
|---|---|---|
| **P0** | 换**自回归 Conv/GRU 解码器**（或条件 VAE/flow，非 Transformer、无 attention） | L1 均值回归会把细节抹平；自回归/隐变量才能表达帧级细节 |
| **P1** | **F0/浊音单独建模 + 谐波声码器**（替代 Griffin-Lim 的相位） | 当前 mel 对音高/相位信息弱，GL 相位随机 |
| P2 | 数据扩到 ≥10h（EmoCompanion 26min + SpeakerA剩余；ASR 伪标签） | 2.7h 从零训练偏少 |
| P3 | CTC/Viterbi 帧级对齐替代 ASR 字符时间戳 | 时间戳 ±50–100ms 仍是噪声 |
