> 所有者裁决原话：「**换生成范式 或者修改核心 有必要时核心可以动**」。
> 本件记录新主线：**帧级自回归（AR）解码器**——不是对旧模型的增量修补，而是换掉「全帧并行回归」这个核心。

---

## 1. 为什么换（旧核心的硬伤）

旧核心 `说话模型`（v6/v13）：**全帧并行**地从「音素+前 K 帧真值」回归 mel。
问题链（全部有实测）：
1. L1(log-mel) 均值回归 ⇒ 输出过度平滑（训练句 CER 1.0、mel 帧间变化仅真值 1/4–1/5）；
2. 为补细节引入「自条件 prev + 计划采样」，但训练（teacher prev）与推理（自产 prev）分布不一致 ⇒ **曝光偏差**；
3. 训练越久推理越差（v9/v14 实测：val 变好、CER 变差），只能靠周期保存 + 独立验证集「打捞」峰值（v13 e0150）；
4. 所有增量（对抗、精炼器、时长、集成、自适应迭代）都**没有双集同时改善**。

## 2. 新核心：自回归帧级解码器（`模型_自回归.py`）

结构（全部非 Transformer、无 attention、从零训练）：
- **编码器**：音节音素嵌入（声母/韵母/调）+ 帧级 10 维特征 → Conv1D 残差堆（核 5、dilation 1/2/4/8、通道 256）→ 上下文 [T,C]；
- **解码器**：GRU（隐藏 384），**逐帧**：`x_t = 融合([上下文_t, 声学投影(mel_{t-1})])` → GRU → `mel_t = 输出(h_t) + 旁路(mel_{t-1})`；
- **训练**：teacher forcing（整段并行，nn.GRU 一次前向）；
- **推理**：从 `mel_{-1}=0` 起**逐帧生成**——训练与推理是同一因式分解（p(mel_t | 上下文, 之前所有帧)），**没有「全帧并行 + 计划采样」的分布错配**；
- 参数量 2,353,312；ckpt 自带词表/mel 统计/训练信息。

## 3. 与旧路线的关系

| | 旧核心（v6/v13） | 新核心（AR） |
|---|---|---|
| 生成方式 | 全帧并行回归 | 逐帧自回归 |
| 训练/推理一致性 | 不一致（teacher prev vs 自产 prev） | **一致**（同一因式分解） |
| 过平滑风险 | 高（均值回归 + 计划采样漂移） | 低（逐帧条件在已生成帧上） |
| 推理成本 | 3–7 轮全序列 | T 步（约 1500–3000 步/句） |
| 代码 | `模型_学说话.py` | `模型_自回归.py` + `评测_自回归.py` |
| 红线 | 非 Transformer / 无 attention / 从零训练 / 自训练权重 | 同 |

## 4. 训练与评测配置（本轮）

- 数据：`产物/数据_对齐asr`（167 条、2.7h、ASR 文本+时间戳对齐）；
- 训练：窗口 ≤1500 帧、batch 8、AdamW lr 2e-4、每 50 轮存 `ckpt_e{N}.pt`；
- 评测：`评测_自回归.py`（同 S1–S12、同 Griffin-Lim、同 ASR 两趟转写）；
- 结果：v1（teacher forcing，130 轮）双集 **1.0000/1.0000**（生成 mel 偏亮+过度平滑）；
  **v2（AR 计划采样，109 轮）历史 0.9768 / 留出 0.9400**（有改善，仍远差 v13 的 0.8327/0.7853）；
  **v3（60 分钟继续训练）进行中**。

## 5. 预期与判据

- 若 AR 核心成立：训练损失应持续下降，且**推理 CER 随训练单调改善**（不再出现「val 变好、CER 变差」）；
- 判据不变：双集 CER ≤0.35 为「可懂」；S13–S18 只选不报；
- 当前判断：AR 核心**方向有效但欠训练**（109 轮时损失仍 0.29），需要 1–2 小时量级的训练才能下结论。
