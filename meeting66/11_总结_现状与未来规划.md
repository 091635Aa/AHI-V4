## 4. 为什么 v18 失败（机制层结论，供未来决策）

1. **确定性零起点 → 塌到条件均值**：std 仅 0.84–1.29（真 3.49），迭代越多越平滑 ⇒ 生成自由度被确定性轨迹抹掉；
2. **噪声起点 → 方差/时间变化量级对了（std 1.75、帧间 0.574 ≈ 真 0.527），但逐帧独立采样 ⇒ 帧间不相干**，ASR 转写为空/单字；
3. ⇒ **帧级条件 flow 的「生成自由度 vs 时间相干性」不可兼得**。v13 的「条件均值 + 局部自条件 + 阻尼」恰好同时保住「不太噪」和「有包络」，这是它 0.83 的来源；
4. **不是训练量单因素**：P 探针 500 轮无趋势，而 CFM 损失仍在缓降——与 AR v7「损失降、CER 触顶」同型；
5. 结论：**要同时拿到生成自由度与时间结构，必须做整句联合生成**（见 P1），而不是逐帧条件。

## 5. 未来规划（全部拿出来；按优先级/依赖排序）

> 原则：**先数据、后模型**；任何新路线先预注册判据、再小预算预实验、再决定是否投入；不重复已否证项。

### P0（阻塞项）：数据扩容 —— 唯一被反复证明的硬瓶颈
- **需要所有者做**：提供新录音，目标 **≥8–10 h**、安静/录音室、含**朗读句**（当前 2.7 h 为对话语料）；同一说话人（SpeakerA）优先；格式 wav 22.05k/16bit/mono 或更高（数据侧会重采样）。
- **为什么是 P0**：三条神经路线（并行回归 0.83、AR 0.93、条件 flow 1.0）都卡在 2.7 h；L: 下「RVC 子集」已核实为同一批副本（不能扩数据）。
- **数据到位后的动作**：① 重跑 v13 配方（同口径，约 1–2 h GPU）→ 看双集是否随数据量下降；② 若仍 >0.6，再考虑 P1；③ 预注册判据不变（双集 ≤0.35 为可懂）。
- **验收**：数据从 2.7 h → ≥8 h；同协议复评 v13；判据「有改善」= 双集均下降 >0.05。

### P1（仅在 P0 完成且仍要突破时）：整句联合 flow / 全局潜变量生成
- **为什么**：v18 证明帧级条件 flow 不行；要生成自由度 + 时间相干，需要**整句联合分布**建模（整段 flow 去噪，或全局潜变量 z + Conv 解码），仍非 Transformer、无 attention（C1 允许 Conv/GRU/MLP 从零训练）。
- **实现范围（估计 1–3 天 + GPU）**：① 音素 + 时长 → 上下文（复用现有编码器）；② 整段速度场（Conv 残差堆，感受野覆盖音节级，或轻量 U-Net 结构）；③ 训练 = CFM（整段，可选加全局潜变量 z）；④ 推理 = 并行 Euler N 步（无逐帧自回归）；⑤ 评测复用现有 S1–S12 / S13 协议。
- **风险（必须先读）**：2.7 h 上未验证；整段 flow 需要更大感受野更久训练；可能仍被数据量卡死。**不建议在 P0 之前投入。**
- **预注册判据**：双集同时 ≤ v13 对应读数，或单集好 >0.02 且另一集不差 >0.02；否则停，不追加。

### P2（与 P0 独立；无新数据时唯一还可做的正交轴）：F0/浊音显式建模 + 谐波声码器
- **为什么**：当前 Griffin-Lim 对**音高/相位完全没建模**（mel 丢 F0）；这是与「核心表达」正交的一轴，可能改善韵律/可听度（不保证单独解决可懂度）。
- **实现步骤（估计 0.5–1 天）**：① 数据侧加 F0/浊音标注（pyworld/librosa pyin，离线、确定性）；② 模型加 F0/浊音输出头（或两阶段：mel→F0）；③ 声码器换谐波模型（谐波叠加 + 噪声成分，确定性）；④ 同协议复评 + 听测。
- **判据**：F0 相关性/浊音准确率达标 + 双集 CER 不退化且至少一集改善 >0.01；否则只登记为可选模块。
- **备注**：与 v13 直接兼容，可单独做，不依赖数据扩容。
