# 文本可观测判据员：T1 主正文通道判据规格（可观测/连续/状态依赖/经历依赖/C1 自检）

> 定位：只写 T1 蓝队的**可执行判据规格**，不宣称达成；未跑项标 [未验证假设]，空着=未测。
> 依据：[简报] §2.2/§4；[议题] T1；[宪法] 第二/三/四条；[裁决52] §I（C3 §0、§C10/C11）、§J1；[最终方案] §1.1/§2/§5；[证据_三层] §三/§七-4；[源码] `输出流.py:105-128`、`:466-491`；`事件契约_操作.py:16-27`。

## 0. 公共口径（五条共用；各条不另造定义）

- **文本单位**：一拍内 NFC 归一后的正文分片文本，长度 ≥1 个非空白 Unicode 字符，且不含内部键名（`s`/`z`/`h`/`A`/`g`/`内态`/`潜态`/`自我态`）。
- **正文流**：只读 JSON/文件；每条记录键集合 = {拍, 序, 文本, τ, 首字}（基数 5），**内部键数 = 0**（记录键命中内部键名的个数 = 0）；读序 = 固定拍序 0..N-1，禁按 τ 排序。
- **元话语命中**：源码 `输出流.py:69-75` 词表命中数，发布前须为 0（[实测] 净化前 5 → 净化后 0，证据_三层 §三）。
- **对标口径**：Transformer 的正文 = 外露 token 序列（[文献类比]，只作设计动机，不作阈值来源）。
- **两趟指纹**：`sha256(文本单位序列 + 拍号 + 种子 + 参数哈希)`；NFC、浮点转定点整数（×10^6）、外部调用记录-重放。两趟不一致 ⇒ **INVALID（未测/无效），不得记 FAIL**；四态 INVALID 优先于 FAIL。

## ① 可观测（外部只读输出流即可复读，无需读内部态）

- **主张**：正文流是独立通道；120 拍导出后仅凭文件即可复读，内部键数 = 0、元话语命中 = 0、两趟逐位同。[未验证假设]
- **证据**：`输出流.py:505`（分片键 τ/拍/文本/序/首字）、`:542-545`（链 = 三列）；`事件契约_操作.py:16-27`（四项量全从时间线算，不读内态）。[实测] 源码可查。
- **阈值**：内部键数 = 0 ｜ 元话语命中 = 0 ｜ 键集合基数 = 5 ｜ 两趟 sha256 一致 = 1/1。
- **必须失败臂**：① z 256 维潜态字段混进正文流 ⇒ 内部键数 ≥1（预期 1，上限 0）⇒ FAIL；②`_思考文本()` 原文直发 ⇒ 元话语命中 120（上限 0）⇒ FAIL。
- **迁移臂**：未见输入类型（str→dict/None）复读成功率 ≥0.70（目标 1.0000），内部键数仍 = 0。
- **干预臂**：注入必抛引擎（RuntimeError）⇒ 正文数 120→120、键集合不变、指纹逐位同（[实测] 证据_三层 §三 三臂）。
- **两趟**：同种子两趟，120 拍指纹一致 = 1/1；不一致 ⇒ 本臂 INVALID。
- **反证**：若外部必须调 `引擎台账_只读()` 才能出字 ⇒ 独立性不成立，本判据 FAIL。
- **算力代价**：导出 O(1)/拍，120 拍 ≤1 ms [未验证假设]；文件大小/内存**未测**。

## ② 连续（每拍 ≥1 文本单位，最大空隙拍 ≤1）

- **主张**：正文覆盖率 1.0000、最大空隙拍 ≤1、孤立动作 = 0；这是**排布判据**，不证明内生（见 §六）。[实测] 正常臂 120 拍：空隙 1 / 孤立 0 / 覆盖 1.0000（证据_三层 §三）。
- **证据**：`事件契约_操作.py:157-172`（空隙 = 相邻思考项拍间隔）、`:103-155`（孤立动作 = ±2 拍内无正文）。
- **阈值**：每拍文本单位 ≥1 ｜ 最大空隙拍 ≤1 ｜ 孤立动作 = 0 ｜ 覆盖率 = 1.0000。
- **必须失败臂**：①抽掉中间文本块 ⇒ 空隙 **61**（[实测] 反例①，上限 1）；②动作整体挪末尾 ⇒ 孤立动作 **120**（[实测] 反例②，上限 0）；③正文分片全删 ⇒ 覆盖率 **0.0000**（[实测] 反例③，下限 1.0000）。
- **迁移臂**：未见 horizon（120→2000 拍）/未见输入 ⇒ 空隙 ≤1、覆盖 1.0000，达标率 ≥0.70（=已见臂的 70%）。[未验证假设]
- **干预臂**：抽掉第 60 拍单点文本 ⇒ 空隙 2、覆盖率 119/120 = 0.9917 ⇒ 必须判 FAIL；注入空串（净化后 len<6 走回退池）⇒ 仍 ≥1 单位。
- **两趟**：拍号序列 + 文本单位序列哈希一致；不一致 ⇒ 本臂 INVALID。
- **反证**：若 120 条正文全堆末拍仍判过 ⇒ 覆盖率/空隙口径失效，判据作废。
- **算力代价**：O(1)/拍 计数，120 拍 ≤1 ms [未验证假设]；内存未测。

## ③ 状态依赖（打乱内部状态 ⇒ 文本分布变化；冻结 ⇒ 逐位同）

- **主张**：判决量用**跨候选非线性**统计量——文本单位分布 TV 与逐拍文本改变率；打乱 s 后 TV ≥0.10 且改变率 ≥0.30，冻结 s 后改变率 = 0.0000。[未验证假设]
- **证据（★口径铁律）**：meeting52 §I：**状态差 0.516 而决策翻转仅 5.5%**；C3 §0 单调变换恒等定理：对 argmax 的单调/尺度变换不改决策 ⇒ **禁用 argmax 单点翻转当唯一判决量**，必须用 TV / 残差 / 相对比较。[实测]
- **阈值**：TV(文本单位分布) ≥0.10 ｜ 逐拍文本改变率 ≥0.30 ｜ 冻结臂改变率 = 0.0000 且指纹逐位同。
- **必须失败臂**：预写句池（`_正文池` 按 `拍%3` 取句，`输出流.py:472-482`）⇒ TV <0.02（预期 0.0000，上限 0.02）、改变率 = 0（预期 0.0000，上限 0.30）⇒ FAIL。
- **迁移臂**：未见状态类别（held-out s 簇）TV ≥0.07（=0.10×70%）、改变率 ≥0.21（=0.30×70%）。[未验证假设]
- **干预臂**：冻结 s（s[t+1]=s[t]）⇒ 改变率 0.0000；替换 s（s←固定向量）⇒ TV ≥0.10。
- **两趟**：置换 π 由种子生成且固定，两趟指纹一致；不一致 ⇒ 本臂 INVALID。
- **反证**：若打乱 s 后 TV ≥0.10 但文本只由拍号决定（置换经历/状态无关）⇒ 状态依赖不成立；须同时报「仅拍号模型」零分布 TV <0.02。
- **算力代价**：TV 计算 O(120×|V|)；文本合成 O(D×|V|) 乘加/拍 [未验证假设]，D=256、|V|=512 ⇒ 131,072 乘加/拍、120 拍 15,728,640 乘加（设计值）；墙钟未测。

## ④ 经历依赖（同状态 + 不同经历 ⇒ 文本不同；清空经历 ⇒ 掉分）

- **主张**：逐位注入同一 s，两条 ≥200 拍经历历史 H1/H2 ⇒ 文本单位差异率 ≥0.10；清空经历（F5：E←0，只用当前输入 + 种子重算）⇒ 任务掉分 ≥0.10。[未验证假设]
- **证据**：最终方案 §1.1 F5 公理（清空跨拍状态须掉分 ≥0.10）；§2 判据表 F5 列；`输出流.py` 正文只依赖 `_码(种子,拍)` 与池（`:461`/`:476`/`:488`），无经历项 ⇒ 设计上该臂必失败。[实测] 源码可查。
- **阈值**：H1 vs H2 差异率 ≥0.10 ｜ 清空经历掉分 ≥0.10 ｜ 三个迁移臂各 ≥0.07（=0.10×70%）。
- **必须失败臂**：句池 ⇒ 差异率 0.0000（上限 0.10）、清空经历掉分 0.0000（<0.02，上限 0.02）⇒ FAIL。
- **迁移臂**：held-out 词组合 / 未见状态类别 / 未见噪声率（σ=0.15，已见 ≤0.10）三臂：掉分 ≥0.07 且差异率 ≥0.07。[未验证假设]
- **干预臂**：清空经历 ⇒ 掉分 ≥0.10；换成另一条等长经历（s 固定）⇒ 差异率 ≥0.10。
- **两趟**：经历 H1/H2 由种子生成，两趟指纹一致；不一致 ⇒ 本臂 INVALID。
- **反证**：若 H1/H2 的文本差异全部由拍号解释（置换经历后文本不变）⇒ 经历依赖不成立。
- **算力代价**：经历读写 O(D)/拍、两条 200 拍臂；墙钟/内存未测。

## ⑤ C1 自检（源码级 + 式级）

- **主张**：双级自检。源码级 = 禁词/AST/导入白名单/**前向 import 闭包**（现有「只扫 3 文件」作废）；式级 = 写出一拍文本生成更新式，判「是否等价全局 softmax 注意力：是/否/条件」三态。PASS 条件 = 禁词 0 ∧ 非白名单 import 0 ∧ 闭包覆盖 1.0000 ∧ 式级 ≠「是」。[未验证假设]
- **证据**：最终方案 §1.2（禁 `读(k=1)`/softmax/top-k 后重归一/logsumexp）；裁决52 §C8/G2（`读(k=1)` ≡ softmax(β→∞) ≡ Hopfield one-hot 极限 ⇒ 判「条件」）。[实测] 绿队 M6-P10：`读` 直接取值 3.1% ≈ chance。
- **阈值**：禁词命中 0 ｜ 非白名单 import 0 ｜ 前向闭包覆盖 1.0000 ｜ AST 命中 0 ｜ 式级三态 ∈ {否, 条件}；判「是」⇒ FAIL。
- **必须失败臂**：接入 `思核._相对门`（Σg = 1.0000 真 softmax，[实测] C8）⇒ 式级判「是」、禁词命中 ≥1（softmax）⇒ FAIL；扫描器可失败性：注入 1 个含禁词文件 ⇒ 命中 2（[实测] 证据_三层 §四 T7）。
- **迁移臂**：会后新增未见模块纳入前向闭包，覆盖 ≥0.70（目标 1.0000），禁词 0。
- **干预臂**：换 `读(k=1)` ⇒ 判「条件」（G2 强制补行）；换 top-k 后重归一 ⇒ 判「是」⇒ FAIL。
- **两趟**：源树文件哈希列表 sha256 两趟一致；不一致 ⇒ 本臂 INVALID。
- **反证**：若写不出一拍更新式 ⇒ 该项不参与裁决（议题 T3 口径），不得记 PASS。
- **算力代价**：全树 AST 扫描 O(文件数×行数)，120 个 .py ≤5 s [未验证假设]；内存未测。

## ⑥ 关键 must-fail：`输出流.py` 句池臂（三判据不得互相顶替）

- **主张**：把 `输出流.py` 的预写正文直接接进 T1 ⇒ ①可观测、②连续**仍会过**，③状态依赖、④经历依赖**必不过**。[未验证假设]
- **证据**：`:105-128` 六池（`_主题池/_物池/_元素池/_键入池/_正文池/_思考模板`）；`:472-482` 按 `拍%3` 取句（模0 正文池 / 模1 思考模板 / 模2 原子句 + 回退池）；`:466-470` 模板填空；`_码()` 只吃 (种子, 拍) ⇒ 与 s / 经历无关。[实测] 源码可查。
- **预期值**：② 空隙 = 1（[实测] 证据_三层 §三）、覆盖 1.0000、孤立 0；③ TV 0.0000（<0.02）、改变率 0.0000（<0.30）；④ 差异率 0.0000、清空掉分 0.0000（<0.02）。
- **上限**：③ TV 0.02 / 改变率 0.30；④ 掉分 0.02；达到上限内侧即判 FAIL。
- **反证**：若换更大池/模板树能过 ③④ ⇒ 说明判据只测字面多样性，判据本身作废（INVALID）。
- **算力代价**：池取句 O(1)/拍，不计文本合成成本；不提供 O(D×|V|) 账 ⇒ 不得算作「文本内生生成」。

## ⑦ 算力与单探针（本文所有成本口径）
