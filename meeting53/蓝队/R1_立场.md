## 0.1 执行器总纲（详见 `子代理/判据规格员.md`）

- **四态优先序**：`INVALID > FAIL > UNDECIDABLE > PASS`。INVALID 三条件：①must-fail 子句互斥（同一臂对同一量同时要过与不过）②判决量恒真（`if 允许`/`bool(允许)` 型）③替身臂不可分（真臂−替身 <2×SE_pooled 或 <0.05）。三条件任一命中 ⇒ 判 INVALID，**不得判 FAIL**。
- **F5 不可预演公理**：每子集 +1 臂，三变体 a 清空跨拍状态 / b 只用当前输入+种子重算 / c 历史置换；掉分 =分(有状态)−分(清空) **≥0.10**；掉分 <0.10 判「未证明」而**不判 FAIL**（[实测] provenance 掉分 0.897−0.504=**0.393**；记忆 K-差 **0.000**、潜推冻结掉 **0.000** ⇒ 后两项按未证明处理）。
- **两趟指纹三层**：L1 决策序列 / L2 格上状态 int64（2⁻²⁰ 格）/ L3 原始位型 sha256；外部调用（键鼠/焦点/时间戳）**记录-重放**、禁真实时钟进决策；不一致 ⇒ 归因外部=**INVALID**、归因内部=**FAIL**（现测 L1∧L2 **8/8 逐位同、格违例 0/20,993** [实测]）。
- **零分布 Z1–Z7**（置换 n=200、判 95% 分位）：状态打乱 / 标签置换 / 来源置换 / 槽位置换 / 时序置换 / 角色置换 / 文本置换。**零分布本身必须可失败**：oracle 标签臂必须 =1.00、正确槽映射 ≥0.70、句池臂 MI ≤0.02，否则该 Z 检测器失效 ⇒ 对应臂 INVALID。
