## T1 · 主正文通道：什么叫「和 Transformer 一样的正文」且可观测

**问题**：所有者要「输出和 Transformer 一样的正文内容，可以被可观测」。在 C1 红线（禁注意力/Transformer 架构）下，这句话的**可测操作化定义**是什么？「有字输出」与「正文可观测」的区别怎么判？

**为什么必须先答**：meeting41 的 L3 已经有「每拍出正文」，但那是**预写句池**（`输出流.py:105-128` 六个手写常量池、`_生成正文()` 按 `拍%3` 取句）。按宪法第三条这是焊死件。若口径不先定，下一版还会用「更大的句池」冒充「正文内生」。

**红队预设攻击面**（供展开，不是结论）：
- 把「每拍有字」当「正文档」；把「句子可读」当「内生」；
- 换一个更大的预写池／模板树冒充内生；
- 用随机拼接词冒充「生成」；
- 只测字数/流畅度，不测「文本↔内部状态」的依赖；
- 用外部现成语言模型生成正文（C10 红线）。

**各队必须给出**：
- **红队**：至少 5 种「假正文」伪造手法 + 各自的**可判定检测量**（如 `MI(文本;状态)`、置换状态后的文本变化率、清空经历的退化量）。
- **蓝队**：T1 判据规格：①**可观测**（外部只读输出流即可复读，无需读内部态）；②**连续**（每拍 ≥1 文本单位，最大空隙 ≤1 拍）；③**状态依赖**（打乱内部状态 ⇒ 文本分布变化 ≥ 阈值；冻结状态 ⇒ 文本不变）；④**经历依赖**（同一状态但不同经历 ⇒ 文本不同；清空经历 ⇒ 迁移掉分）；⑤**C1 自检**。给出每条的阈值、必须失败臂、两趟口径。
- **绿队**：内生语言机制候选（≥3 个）：词音外采/词义内生、听见序列统计、组合、指称绑定；每个给「它绝不能变成什么」的边界与文献类比（标 [文献类比]）。
- **黄队**：每条判据/机制的**实测代价**（拍数/乘加/内存/墙钟）与**最小可判实验**（≤30s 探针）。

**判定口径**：给出**可执行**测试描述（输入/操作/观测/阈值/必须失败对照），且**不依赖人工判读**。允许「无法判定」，但必须同时给能判定的实验 spec。

**落盘**：`<队>/R1_立场.md` 的 T1 节。

## T2 · 旁路由并行：边输出正文边操作电脑/接口，且观测真回流

**问题**：如何证明「三线并行」不是「先说话再动手」？如何证明旁路由的**观测回流**真进入下一拍决策，而不是开环摆动作？

**为什么必须先答**：meeting52 判「工具闭环＝未测」；meeting41 的「最大空隙拍 1」只证明排布，不证明因果。所有者要的「边说话边操作电脑」，本质是**同一时基上三条因果链互相供给**。

**红队预设攻击面**：
- 串行执行伪装并行（先攒文本再动手）；
- 动作序列预写＝查表；
- 观测只进日志、不进决策；
- 用「动作数量/覆盖率」当闭环证据；
- 外部非确定性（窗口焦点/时间戳）破坏两趟；
- 旁路由与主正文**无共同状态**（两条互不相干的流，拼在一起）。

**各队必须给出**：
- **红队**：≥5 种「假并行/假闭环」伪造手法 + 检测量（如：切断观测后行为退化量、扰动观测后动作 TV、串行重排后空隙拍、动作与文本的共同状态依赖）。
- **蓝队**：T2 判据规格：①**同拍并行**（最大空隙拍 ≤1、孤立动作=0）；②**共同状态**（正文与动作必须由同一内部态驱动：固定动作下扰动状态 ⇒ 文本变；固定文本下扰动观测 ⇒ 动作变）；③**观测回流**（切断/扰动观测 ⇒ 行为退化/改变 ≥ 阈值）；④**失败恢复**（尾部第 10 块触发，不得用中部）；⑤两趟口径（外部调用记录-重放）。
- **绿队**：三线调度机制候选（≥3）：时隙/抢占、共同黑板、事件驱动；每个给「不得变成写死流程树」的边界。
- **黄队**：实时性预算（每拍 100ms 内三线各占多少）、真键鼠沙箱风险清单、降级阶梯。

**判定口径**：给「闭环因果链证据 + 失败恢复 + 确定性口径」三件；允许「闭环仅在沙箱成立」，但必须说明沙箱边界与真机升级路径。

**落盘**：`<队>/R1_立场.md` 的 T2 节。

## T3 · 内部深度思考（不公布）：装饰 vs 真思考

**问题**：所有者要「内部还会做深度思考，像人说话一样会想东西」。如何证明内部潜态**真的进入因果链**，而不是装饰性中间量？在 C1 红线与 meeting52 的「潜在推理 INVALID/BLOCKED + 装饰证据」现状下，怎么重建？

**为什么必须先答**：蓝队 R3 已证「z 不携带 x 信息」（z 单独解码 0.550≈随机；放大 16× TV 0.357≈decoy 0.360）。任何「加个循环/加个潜态」的方案若不先过因果臂，就是重复失败。

**红队预设攻击面**：
- 潜态扰动不改变输出 ⇒ 装饰；
- 固定步数循环冒充「按难度调度」；
- 用 softmax 门控（C1 违规）实现「注意」；
- 潜态信息其实可由当前输入重算（F5 违反）；
- 「思考不公布」被用来逃避可观测性（既不可观测也不可证伪）。

**各队必须给出**：
- **红队**：≥5 种「假思考」伪造手法 + 检测量（替换/扰动/冻结三档 + 决策统计量改变率 + F5 可重算对照）。
- **蓝队**：T3 判据规格：①**不公布**（内部态不出现在正文流，逐位可查）；②**因果三档**（替换/扰动/冻结潜态 ⇒ 正文或动作改变 ≥ 阈值）；③**难度→步数**（ρ≥0.5，或给不可判定模板）；④**F5 不可重算**（清空历史/只用当前输入 ⇒ 掉分 ≥0.10）；⑤更新式文本 + C1 同构判定表；⑥两趟逐位同。
- **绿队**：C1 合规的潜态机制候选（≥3）：逐元素门控＋归/叠/符、无跨维混合的动力学、内生态调制；必须写「更新式」并标注与注意力的边界。
- **黄队**：每拍潜态迭代代价、步数调度的可行区间、预算内最大步数。

**判定口径**：每项机制给**更新式文本** + 同构判定（是/否/条件）+ 干预实验设计与预期；**没有更新式文本的方案不参与裁决**。

**落盘**：`<队>/R1_立场.md` 的 T3 节。

## T4 · 多脑协作与归属：不同组「人脑」怎么开会、怎么不被洗

**问题**：所有者要「不同组人脑之间的协作，需要 agent 开会商议」。多个自态体如何协作才算**内生协作**（不是多开几个 agent 各说各话）？外源信息如何不直接改写「我」（provenance）？

**为什么必须先答**：meeting52 的 provenance 争议（绿 PASS/蓝 FAIL 口径差）与「PS×PV 不可分离 I=0.478」说明归属判据必须重做；「多 agent 投票」是外部机制，不是内生协作。

**红队预设攻击面**：
- 多开 agent 但彼此不交换信息（并行独奏）；
- 用固定会议模板/轮流发言表冒充协商；
- 共识靠投票/规则加权（外部机制）；
- 外源信息直接覆盖自我态（归属失效）；
- 协作收益来自「多算力」而非「交换信息」（等算力单脑对照必须做）。

**各队必须给出**：
- **红队**：≥5 种「假协作/假归属」伪造手法 + 检测量（切断通信掉分、等算力单脑对照、外源注入后自我态漂移、置换来源标签后的归属 AUC）。
- **蓝队**：T4 判据规格：①**交换信息**（切断通信 ⇒ 联合任务掉 ≥0.15）；②**等算力对照**（3 脑 vs 1 脑×3 倍算力，增益来自通信而非算力）；③**归属**（外源消息经归属门；解除门控 ⇒ 自我态漂移 ≥0.10；来源置换 AUC≤0.55）；④**迁移**（未见组合/未见队友）；⑤两趟逐位同；⑥会议协议可复现（固定议程、固定种子）。
- **绿队**：多脑协作机制候选（≥3）：共享黑板/消息绑定/共识场；每个给「不得变成固定议程表」的边界。
- **黄队**：N 脑的算力/内存账（N=1/3/5）、并发风险、最小可判实验。

**判定口径**：给「通信因果链 + 等算力对照 + 归属门 + 两趟」四件；允许「协作只在沙箱任务成立」，但必须给任务定义与迁移臂。

**落盘**：`<队>/R1_立场.md` 的 T4 节。

## T5 · 整机：五问合一后的常驻闭环、资源与诚实边界

**问题**：P1–P4 同时常驻在一条闭环里时，怎么判「整机成立」？哪些必须**明确不宣称**（人脑复刻/现象意识/Transformer 级语言）？最小可判子集是什么？

**为什么必须先答**：宪法要求不作「已完成」宣称；meeting52 七项 0 项可宣称达成。本轮若再给一份「全 PASS」，就是重犯。

**红队预设攻击面**：
- 分项 PASS 拼成整机 PASS（耦合未测）；
- 用「演示视频/截图」代替可复跑判据；
- 把 Toy 规模说成通用能力；
- 隐藏未测项；
- 用「人脑复刻」当卖点（不可测）。

**各队必须给出**：
- **红队**：整机级伪造手法 + 「分项≠整机」的联合消融要求（≥2×2 交互）。
- **蓝队**：整机判据规格 + 四态汇总表 + **最小可判子集**（≤10 臂、≤5 分钟）+ 两趟口径。
- **绿队**：整机机制清单与「关键步骤→功能子集」映射（人脑关键步骤逐条对应到可测子集，标 [文献类比]/[未验证假设]）。
- **黄队**：整机资源账（五元组×两 horizon 口径）+ 并发预算 + 算不起清单。

**判定口径**：给出**整机四态汇总 + 不宣称清单 + 最小可判子集**；任何一项未测必须单列。
