## §B 好焊死件 vs 真内生：6 条可判定判据（每条给可 grep 的结构特征）

1. **池的出生地**：模块顶格常量 `^_[\u4e00-\u9fa5A-Za-z]* = \(` 或 `= \{` ⇒ 焊死；池只在方法内被写、初始为空（`语言_内生.py:149` 绑定表「出生为空」）⇒ 内生。[实测]
2. **索引的原子**：`grep "_码(self.种子"` 命中且参数只有 种子/拍 ⇒ 焊死；索引函数参数含 观测/误差/ε/自我态键 ⇒ 内生。[实测]
3. **输入→分支**：`if 原子 ==`／`if 意图 ==`／`elif Σ.get("Δ` ⇒ 查表；连续场（`符`／`软限(A−B)`／`ε_self`）⇒ 内生。[文献类比]（Transformer 无显式句池，输出＝参数×输入；宪法第二条要求只对标效果）
4. **未教输入的姿态**：`KeyError`／`return {}`／`return None` ⇒ 焊死；能退化但不崩且可复现（`铸()` 自铸符号 `语言_内生.py:226-230`、babble）⇒ 合格退化。[实测]
5. **名字/实体从哪来**：`_元素池[`／`_名物池` 出现＝名字焊死；`元素列()` 有真调用点＝从世界读（当前全仓 **0 调用**）。[实测]
6. **生成方式**：正文/思考函数内出现 `.format(`、`%3`、`% len(` ⇒ 骨架焊死；逐单位选择且能回溯到某个内部态分量 ⇒ 才有资格叫内生。[实测]

## §C 本提案（meeting53 将产出的方案）最可能新增的焊死件（7 条，全为 [未验证假设]）

1. **三线固定时隙表**：`时隙 = {"正":0.0, "手":0.4, "思":0.9}`。病：并行是「排出来」的，不是抢出来的。红线：禁 0.4/0.9 常量偏移、禁 `if 拍 % N`。
2. **旁路由动作表**：`动作表[意图] = [("左键",…), ("键入",…)]`。病：T2 明列「动作序列预写＝查表」。红线：禁 `if 意图 ==`、禁「dict 字面量 → list」映射。
3. **固定会议议程**：`议程 = ("开场","提议","表决","收尾"); for 阶段 in 议程`。病：T4 点名的「固定会议模板冒充协商」。红线：禁阶段元组常量；议程须由各脑自态差生成（现状：全仓 `.py` grep「议程」**0 处**，尚未存在＝现在防比以后拆便宜）。
4. **思考模板**：`"我在想{主题}"` 配 `_主题池`。病：T3 的装饰性思考。红线：禁 `.format(` 生成思考文本、禁任何常量句池 >0 行。
5. **归属门按标签分支**：`if 来源 == "外源": w = 0.3`。病：provenance 变成字符串查表。红线：禁来源字符串分支，只许 `ε_self`／一致度 连续门。
6. **判据侧焊死（最隐蔽）**：must-fail 对照臂 `from 输出流 import _正文池`。病：对照与主臂共享同一池 ⇒ 对照没坏、结论假强。红线：对照臂禁 import 主臂任何池常量，须独立生成。
7. **「共同状态」写成共享 rng**：`rng = default_rng((种子, 拍))` 同时喂正文与动作。病：同索引 ≠ 同因果。红线：禁以共享种子代替共同态，须给 `∂文本/∂状态` 与 `∂动作/∂观测` 双向探针（否则 T2② 无法判定）。
