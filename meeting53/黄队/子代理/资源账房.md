## 1. 口径绑定声明（不过此节，整份作废）

**主张**：本轮资源判据 = **五元组 × 两 horizon**；缺任一维记 **VOID**，VOID 判 **FAIL**。

- 口径五元组：`peak_wset`（PeakWorkingSet64）｜`commit`（PrivateUsage）｜`RSS`（WorkingSet64 的 median/p95）｜`device`（`mem_get_info`）｜`allocator`（`max_memory_allocated`）。

- **D 值绑定（G4/G7）**：凡称「引擎/全链 180MB」仅指 **D=1024**（179.2/179.9/180.2/180.7MB [实测]）；显式 **D=256 → 178.7MB** [实测]。**两者不得混用**，混用即 VOID。

- 证据：`meeting52/裁决/00_裁决记录.md:118`（G5）、`:120`（G7）、`:114`（G4）；`meeting52/最终方案.md:110-115`。
- **反证**：若「2000 拍 commit 306.11MB 当成 WS 报 320 线通过」未被判 VOID ⇒ 本主张被推翻。**必须失败对照臂**：同一读数分别落 WS 格与 commit 格，若两格同值 ⇒ 采样器串口径，判测量器失效。
- **算力代价**：120 拍单探针 = import ≈2s + 120×(0.15–0.285ms) ≈ 34ms + 轮询 100ms ⇒ ≤3s，远低 30s 上限 [推算，载体 V4 核]。
- 私有假设：320MB 是**可执行红线**不是成就线；**commit 口径下红线不成立**（见 §2）。
