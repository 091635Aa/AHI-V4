## 1. 每拍三线预算（按载体分列，硬回答 96.0ms 载体）

**成本模型**（除 m 外均为 [设计值/推算]，**未测**）：① 主正文 12ms（状态→词打分→拼单位→写出+flush；D=256 打分约 0.26M 乘加，flush 是主项）；② 旁路由 45ms（键鼠两原语注入 + `事件契约_操作` 校验 + 观测采集；量级参照千层行为探针 ~20ms/拍 [实测，仅供复现] `证据_千层.md:108`）；调度/守卫 3ms；写盘 3ms；余量 10%。

**结构提醒（必须写进 T3 结论）**：**K 大 ≠ 思考深**。① 简报 §2.5 教训 1「深度≠更多层」：千层 6 档−1 档 迁移差 **−0.004**（`证据_千层.md` 同向）；② meeting52 §C8:45 / F2:59：8 算子仅 `读` 带跨维混合 ⇒ 逐元素 + 固定驱动 ⇒ **唯一不动点**，"迭代次数=思考深度"在算子层被堵死；③ 丙1：迭代 1 步与 3 步**逐点同**。⇒ **K_max 只是"预算内还能算几步"的上限，不是能力判据**；T3 必须带「拆迭代→决策统计量变」的因果臂，且不得把 K 写进任何宣称。

**四件套**：① 主张：**只有 V4 核在两种时基下都能做 ≥3 档步数**；96.0ms 载体在任何时基下都做不了步数调度实验。② 证据：上表 + `裁决:45,59`。③ 反证：若在 V4 核上 K=94 与 K=3 的决策 TVD < 0.10（**这是预期结果**，按 C8 结构定理），则"步数多=更深"当场被推翻——**必须失败对照臂**＝同算力 K=1 单次投影；若 K=1 与 K=94 不可分，判"步数无因果"。④ 代价：每拍 ③ = K×m；100ms 档 V4 **27ms**、千层 **16.3ms**；200ms 档 V4 **117ms**、千层 **114.1ms**（K=7）。

## 4. 外部键鼠延迟（真机 = **未测**）

≥3 个量：**L1 注入→事件落地**（`SendInput` 返回 t0 → 低级钩子/WinEventHook 收到 t1，取 t1−t0）；**L2 UIA 事件时间戳差**（UIA `TimeStamp` 与本地 QPC 之差，含分辨率上限）；**L3 窗口焦点切换耗时**（`SetForegroundWindow` → 轮询 `GetForegroundWindow` 命中目标）；**L4 观测→可见变化**（截图 diff 首帧变化）。**方案**：单次探针 ≤30s，先**只读档**（0 注入：只遍历 UIA 计时 + 轮询焦点 ×1000，可立即跑，不碰键鼠）；L1/L4 需**所有者授权在场**（`AHI3\meeting41\实施\真机探头.py` 只到演练档，见锚点表末行 ⇒ 真机延迟＝未测）。

**四件套**：① 主张：**真机键鼠延迟未测**，任何"旁路由 <20ms"的宣称无据；② 证据：锚点表「真机键鼠＝未测」行 + 真机探头仅演练档；③ 反证：若独占实测 L1 median ≤5ms 且 p95 ≤15ms，则 ② 的 45ms 预算过度悲观，须下调并重算 §1 的 K_max。**必须失败对照臂**：把注入发向**非目标窗口**（预期 t1 不变但"落地=0"）；若该臂也报"落地成功"，说明探针读的是自己的日志而不是真实事件流 ⇒ 判 **VOID**。④ 代价：30s × 3 量 = 90s 独占 + 需所有者；内存 0。
