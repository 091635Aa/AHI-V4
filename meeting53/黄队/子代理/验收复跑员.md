## 2. 两趟协议（判「记录逐位同」，不判「真实世界动作相同」）

1. **种子**：显式常量表 `种子表.json`，`种子 = 基数 + 臂号×100 + 条件号`（Y1=53101…）；`PYTHONHASHSEED=0`、`np.random.default_rng(种子)`、`OMP_NUM_THREADS=1`；**禁** time/urandom/未种 random/线程池并行 IO。
2. **定点/浮点**：内部定点（引擎既有 Q 格式）与格上状态存 **int64**；判据取 L2（int64），**不取 float 原始位型**；指标先量化到 1e-6 再入指纹；float32 存储注入**不作违规**。
3. **读序**：文件列表 `sorted()`（UTF-8 字节序，禁 locale）、逐文件按行号递增、同一时刻只开一个文件；任何 set/dict 迭代先 `sorted()`；环境初始化顺序写死在 `臂注册表` 内。
4. **外部调用（键鼠/接口/时间戳）**：统一走 `外部口` 适配器。**A 趟**真调用并落 `外部_<臂>_A.jsonl`（`t, 请求, 返回码, 落点(x,y) 定标, 参数, 逻辑拍号`）；**B 趟** `重放=True` 只读记录、**不再真的点鼠标**。判的是「记录逐位同 ∧ 状态轨迹逐位同」，**不是**"真实世界动作相同"；时间一律逻辑拍号，禁墙钟（资源臂单列）。
5. **指纹（38B 定长）**：`sha256(臂号|种子|拍号|模型态 int64 摘要|输出 token id|动作原语|**实际落点 (x,y) 定点 1e-3 px**|外部返回码|门/自态摘要)`。**必须含实际落点**（红队 M25）；**禁止**只 hash 执行码/动作名（会漏 12.6786px 级行为差）。
6. **不一致时的四态**：两趟不同 ⇒ 先判 `INVALID`（确定性判据失效，**不是**功能 FAIL）；若差异仅在浮点末位/墙钟 ⇒ 标 VOID ⇒ `FAIL`（G5）；差异在落点/动作 ⇒ 该臂所有功能结论降「未证明」；B 趟超时缺数据 ⇒ `UNDECIDABLE`。

**四件套（§2）** ①主张：把外部不可复现性关进记录后，两趟能逐位判确定性，且不把"世界动了"当成"模型同了"。②证据：L1∧L2 4 配置×2 趟 **8/8 逐位同**、格违例 0/20,993、阳性 7/7 [实测]；38B 指纹 ×2.0 单列、峰值 +0 [实测]（meeting52 §2 #6/§4）。③反证：同一记录重放两趟仍不同 ⇒ 存在未登记耗散源（线程/哈希序/墙钟/浮点末位）⇒ C13 判 INVALID；必须失败对照=三注入（换种子/urandom/1 格步）**必须各不同 3/3**，任一不变即判据失效。④算力：2 趟 × 65s × 1 种子 = 130s；指纹 3,760×38B ≈ **143KB/趟** [推算]；峰值 +0 [实测]。

## 3. 复跑骨架（只写不跑）

```powershell
# 入口：验收_复跑.ps1   两趟=两个独立进程（meeting52 §2 #6：4 配置×独立进程）
param([switch]$自检, [string]$臂="all")
$py="<workspace>/03_AHI\.venv\Scripts\python.exe"; $env:PYTHONHASHSEED="0"; $env:PYTHONIOENCODING="utf-8"; $env:OMP_NUM_THREADS="1"
foreach ($趟 in "A","B") {
  & $py "$PSScriptRoot\验收_复跑.py" --趟 $趟 --臂 $臂 --种子表 "$PSScriptRoot\种子表.json" --单臂超时 30 --总预算 300
  if ($LASTEXITCODE -ge 2) { Write-Host "趟$趟 退出码 $LASTEXITCODE ⇒ 停跑第二趟"; break }
}
# 退出码：0 全PASS｜2 存在FAIL｜3 存在INVALID｜4 UNDECIDABLE/超预算｜1 运行错误
```
```python
# 验收_复跑.py —— 臂注册表（声明式）：阈值/对照/超时全部随臂登记，禁止在执行器里写死
臂表 = [dict(号="Y1", T="T1", 拍=120, 条件=["真","串行出字"], 对照="串行出字",
             阈值={"空隙拍":1,"置换变化率":0.15}, 超时=30, 种子=53101), ...]   # Y1..Y10
def 跑臂(a, 趟, 外部口):
    rng = np.random.default_rng(a["种子"])                        # 显式常量
    if 趟=="B": 外部口 = 外部口.重放(f"out/外部_{a['号']}_A.jsonl")  # 只读记录，不真点鼠标
    观测 = {c: 真前向(c, a["拍"], rng, 外部口) for c in a["条件"]}
    return dict(观测=观测, 指纹=sha256(定长38字段(观测)), 秒=取秒())
def 判四态(a, 观测, 秒, 超时=30):
    if 秒 > 超时:              return "UNDECIDABLE", "超时；**不判 FAIL**，给重跑预算"
    if 观测.get("VOID"):       return "FAIL",         "口径未定义即 FAIL（G5）"
    if not 落失败区(观测[a["对照"]]): return "INVALID", "must-fail 该失败却过 ⇒ 判据不可失败，整组作废"
    return ("PASS","真臂过阈值") if 真臂过阈值(a, 观测) else ("FAIL","真臂未过阈值")
# JSON schema（每臂一条，字段名固定，合计 + 指纹 + 四态汇总）
# {"臂":"Y1","T":"T1","实测":{"空隙拍":1,"置换变化率":0.31},"阈值":{...},"通过":true,
#  "说明":"…","标记":"实测|超时|VOID|对照未失败|未测","秒":4.2,"指纹":"<sha256-38B>","趟":"A"}
```
**执行器铁律**：看门狗到 30s 必杀子进程并记 `UNDECIDABLE`；**must-fail 臂自身崩错/超时** ⇒ 记为 UNDECIDABLE 且**整组 INVALID**（无法证可失败）；任何 `标记≠"实测"` 的臂不得进入汇总 PASS。

**四件套（§3）** ①主张：三类失败被分成三个不同出口，跑慢了不会被记成功能坏了。②证据：`判四态()` 的判定顺序（超时→VOID→must-fail→阈值）＋ `标记` 字段枚举。③反证：看门狗 25s 未杀、或超时臂被写成 FAIL ⇒ 整份结果作废；必须失败对照=`--自检` 注入 1 个 `while True` 假臂（预算 1s），须返回 `UNDECIDABLE` 且退出码 4——**本次未跑**。④算力：自检 1 臂 × 1s × 1 种子 × 1 趟 = **1s**；正式 10 臂两趟 135.4s。

## 5. 诚实边界

- **能判**：①T1–T5 各 1–2 臂的功能子集**在场/缺席**（四态）；②**因果臂**（切断/冻结/置换/清经历/解绑归属 各 ≥1）；③must-fail 的**可失败性**；④两趟确定性（含实际落点）。
- **不能判**：通用语言能力（Toy D=64/256、120 拍）、意识/现象意识、**人脑复刻**、"比 X 省显存"、跨硬件、>2000 拍长时程、真机与外部应用（上表 1/2/3/4/6）。
- **不宣称**：本轮 0 项"达成"；本子集 PASS **只等于**"该臂在该载体上过阈值"，不等于整机、不等于能力。
- **私有假设登记**：①载体用 千层骨 D=64 16.3ms/拍 作**上限**时间口径（换 V4 核则更宽）；②1 种子是本子集唯一允许配置（3 种子 390s 超 5min）；③落点以 px×1e-3 定点入指纹；④`I` 灰区 0.05–0.10 一律 UNDECIDABLE（不借"接近"下结论）。

**大白话**：用 10 个小测试、两分多钟跑两遍，专挑"假正文、假并行、假思考、假开会、假整机"的坑；跑不通就写"没测出来"，绝不写"已经成了"。
