## §0 五条核心结论（给主控的速读）

1. **C1 的地基是 `_归`**：`_归` 是「限端→clip(±16)→2⁻²⁰ 量化」的**逐向量逐元素有界归一，不是 softmax/概率归一**；`迭代` 的 `W迭` 是 (D,) **对角**；`读` 是**固定码本 M 行 hard argmax**（O(M·D)，与令牌数无关）。⇒ 用「逐元素门控 + 叠/绑/符/读」可以做**非注意力**的潜态与语言机制；任何把「候选集扩成序列 + 指数归一」的写法**立刻等价于注意力**，判违规（§1、§4）。
2. **正文内生的可操作定义**：词音可外采（音码任意固定、不含义），**词义/词序/指称三样出生全空**，只由 `(自态 A, 世界态 B, 听见音)` 的三元共现经 `绑/符/叠/归/读` 累积；正文由**内部态解绑→读**生成，源码里不得有任何整句常量（T1、§2）。**must-fail 对照臂 = `输出流.py` 的六个手写池**（`:105-128`、`:472-491`）。
3. **三线并行 = 同一内部态 + 共同黑板 + 抢占配额 + 同拍原子提交**；「并行」的判据不是空隙拍，而是「**切断观测 ⇒ 行为退化**、**优先级常数化 ⇒ 退化**」。现状 `输出流.py` 的动作队**不吃观测**（`:434-453`），是开环（T2、§3）。
4. **深度思考 = 逐元素门控潜态迭代，跑瞬态、不跑收敛**：`T·η≤0.5`，决策必须吃 `(a_T, T_t, m_t)` 三元组；只测 `a` 会重演千层丙1「完整臂与切断臂逐点同」（T3、§4）。
5. **多脑协作 = `符(A_i,·)` 逐元素准入 + 逐元素共识场 + `ε_self` 自触发议程**；**投票 / 固定议程表 / 轮转表 / 外源直写自我态 = 焊死件**；等算力单脑对照必须做（T4、§5）。整机只主张「功能子集 + 因果消融」；14 行「人脑步骤→功能子集」映射**0 行可称已验证**（T5、§6）。

## §2 T1 · 主正文通道：内生语言机制

### 2.0 口径（绿队定义，供蓝队打）
- **正文** = 可复读的**文本单位序列**；绿的粒度建议 = **词**（每拍 ≥1 词，句跨多拍组织）；与蓝队/红队的「句级」口径冲突见 §8-①。
- **可观测** = 外部只读输出流即可复读；**连续** = 每拍 ≥1 词、最大空隙 ≤1 拍；**状态依赖** = 置换/冻结内部态 ⇒ 文本分布必变；**经历依赖** = 清空经历 ⇒ 退化；**内生** = 出生为空 + 只经听见流进入 + 文本由内部态**计算**（不是从常量表取）。
- 全部机制共用一份空态：`D=256`；`音码 c_k=归(sha256(音k))`（外采、固定、不含义）；`义_k∈R^D=0`（词义，出生空）；`S∈R^D=0`（词序统计，出生空）。

### M1 听见序列统计（词序内生）
```
变量：C=[c_1..c_K]（音码本，只随"听见新音"增长，源码无预置词表）；S∈R^D=0
听见相邻音对 (k_{t-1},k_t)：S ← 归( λ·S + (1−λ)·绑(c_{k_{t-1}}, c_{k_t}) )      # λ≈0.99
解码：p=归(绑(S, c_上词))；r=读(C,p,k=1)；下一词=r.索引；r.相似度<θ序 ⇒ 停句
```
- **边界（绝不能变成）**：不是预写句池 / 不是 n-gram 硬编码查表 / 不是模板树。**可检测**：源码中以词串为键的常量 `dict/list` 计数必须 = 0；出现 `{(音A,音B):数}` 形态即判焊死——统计只许住在 D 维向量 `S` 里。
- **C1 判定：条件合规**。只用 绑/叠/归/读；无 softmax、无 QKV；`读` 开销 O(K·D) 与拍数无关。条件 = 必须分布叠加，**禁显式二元表**。
- **必须失败对照**：把正文换成 `输出流.py` 句池 ⇒ 预期 `MI(正文词袋;内部态)≈0`（句池与 A/B 无函数依赖），内生臂须显著 >0（置换 200 次取 95 分位）；shuffle 听见流 ⇒ 词序统计失效、迁移掉分。
- **迁移臂**：held-out 词对（从未同拍出现）+ 未见起点；decode top-1 **≥已见 70%**（阈值位置：top-1，开跑前写死）。
- **代价**：更新 `绑+归`≈3D/拍；解码 `Lmax=12 × (读 K·D + 5D)`，K=200,D=256 ⇒ **≈6.2×10⁵ 乘加/拍**（解析，**未测**）；内存 `C+义`≈800KB。

### M2 指称绑定（词义内生 · 跨情境消歧）
```
同拍听见音 k 又看见物 o（物码取 B_t 形状束）：义_k ← 归(义_k + η义·符(c_k, 物码_o))
解码：ô=解绑(c_k, 义_k)；得分=读(物码本, ô).相似度；得分<θ义 ⇒ 认作"还没认出来"，不许猜
```
- **边界**：不是 `音→物` 查表 / 不是人工本体表 / 不是外挂视觉编码器（C10）。**可检测**：词义只许存成向量 `义_k`；源码里 `音→物/音→义` 非空初始化即判焊死；0 拍时 `解绑(c_k,0)=0` ⇒ 一律"没认出来"。
- **C1 判定：合规**。`符` 与 `解绑` 均逐元素双线性 O(D)，零成对加权；`W绑=W解绑=W符` 时 `解绑(c_k,符(c_k,o))=o` ⇒ 多物叠加可被同键解回。
- **必须失败对照**：出生即会指称（空绑定表命中 >0）⇒ 焊接；`sham 听见`（随机换音，切断音-物对应）⇒ 指称命中须掉到随机水平。
- **迁移臂**：未见指称物（新形状束）**≥70%**；错配注入 ⇒ 失败率上升。
- **代价**：更新 O(K·D)/拍；解码 O(M物·D)；D=256 时 ~1.6×10⁵ 乘加/拍（解析，未测）。

### M3 组合（从状态到词串，不靠句法表）
```
句义：S句=叠([义_k : k∈本拍激活集])                     # 激活集由 M4 的 g 定
解码：序=S句；for j=1..Lmax(≤12)：
        p=归(绑(序,c_上词))；r=读(C,p,1)；说 r；序←归(叠([序,c_r]))
      停于 r.相似度<θ序 或 重复音
```
- **边界**：不是句法树 / 模板填空 / 随机拼词。**可检测**：把 `S` 置零后词序必须变（变化率 ≥阈值）；源码禁把整句连标点写死的常量（`语言_内生.py:81-88` 的 `_内白骨架`/`_正文收` 正命中此条）。
- **C1 判定：条件合规**。组合来自 绑/叠 的代数而非位置权重；Lmax 固定、每词一次 argmax。条件 = 不引入位置编码/相对位置加权。
- **必须失败对照**：模板填空臂（同一 S、不同 A 出同一句）⇒ 状态依赖 FAIL；随机拼词臂（可读性/迁移双掉）。
- **迁移臂**：未教词组合（held-out 搭配）**≥70%**。
- **代价**：已含在 M1 解码内。

### M4 内生态词选择（哪一拍说哪个词）
```
类目 pid 由"状态轨迹仓+在线原型聚类"自发现（沿用 语言_内生.py 的既有路）；门 g=符(A_t,B_t)
候选得分 s_k=读(C, 归(绑(g,义_k)),1).相似度；max s_k≥θ选 ⇒ 说该音；否则出自铸符号 ⟨h⟩（类目码派生）
```
- **边界**：不是情绪池（宪法第一条：状态词只在自发现类目激活时出现）/ 不是随机选词 / 不是 `pid→音` 精确查表（否则未见状态只会落回自铸，迁移臂必不过）。**可检测**：`原型→音` 非空初始化即焊死；选词函数内禁 `rng`。
- **C1 判定：合规**。门=逐元素凸组合，读=定长码本 argmax；无 softmax over positions。
- **必须失败对照**：冻结 `A` ⇒ 选词序列逐位不变 = 装饰；置换 `A` 维序 ⇒ 选词变化率 ≤5% ⇒ 状态依赖不过。
- **迁移臂**：未见自态（新类目）⇒ 应出自铸符号而非错绑。
- **代价**：K×D/拍 ≈5×10⁴ 乘加（解析，未测）。

### T1 四件套（组）
- **主张**：词音外采，词义/词序/指称出生全空；只由 `(A,B,听见音)` 三元共现经 8 算子累积，可读出**源码里不存在**的多词正文，且随态变、随经历变、未教组合 ≥70%。
- **证据**：[实测]（源码，非运行）`输出流.py:105-128` 六池 + `:472-491` 按 `拍%3` 取句；`语言_内生.py` 词义侧对（`:194` 绑定表出生为空）、渲染侧是模板树（`:81-88`）、`:279-304` 自态句只出单词；`符` 逐元素；`证据_三层.md:168-175` 自认"正文是确定性模板、只是管线证据"。实验设计：500 拍合成经历（A/B 轨迹+听见流）→ 观测 ①出生 20 拍内无已绑音 ②200 拍后已绑音数随"听见次数"单调 ③未教词对 decode top-1 ④置零 S 后词序变化率。
- **反证**：句池臂 MI≈0 仍判"内生"⇒ 假；清空经历仍出同样正文 ⇒ 假；空绑定表出生即会指称 ⇒ 焊死；源码命中常量句表 ⇒ 假。
- **算力代价**：≈6–7×10⁵ 乘加/拍（解析，未测），内存 ~1MB；**墙钟未测**，测法：1000 拍取单拍中位数（≤30s 探针）。

## §3 T2 · 旁路由并行：边输出正文边操作，且观测真回流

### 3.0 口径
三线 = **正文线 / 动作线 / 潜态线**；同一 `时基.拍钟`；拍长按议题取 **100ms 硬上限**（设计值，非实测）；每拍三线**各至少 1 次提交**。

### S1 时隙 + 抢占（主干）
```
每拍 p：τ*_p=拍转秒(p)；三线时隙起点上限 {0.00,0.35,0.70}     # 时隙是上限，不是次序
obs_t = 记录-重放读屏/接口()                                  # 不读墙钟（C13）
S_t   = 前向_双区室(obs_t 令牌列, 上下文=S_prev.自我态)
m_q=归(Wq⊙S_prev.输出)；m_a=归(Wa⊙S_prev.门)；m_t=归(Wt⊙S_prev.世界态)
χ_t=(1−β)·χ_{t−1}+β·mean(|S_prev.门|)                          # 阈值由内部态滑动，不写常数
g=[mean(阈值(m_q,χ_t)), mean(阈值(m_a,χ_t)), mean(阈值(m_t,χ_t))]   # 归一仅用于排序与保底配额
先跑 argmax3(g) 的线，再按 g 降序补跑另两线；每线每拍至少推进 1 次（保底，非轮转）
```
- **边界（不得变成写死流程树）**：不是固定轮转表（现状反例：`输出流.py:521-540` 每拍固定 思考→手→正文；`:128,527` 源由 `源序[(拍+种子)%4]` 轮转）；不是先攒文本后动作；不是动作查表。**可检测**：(a) **常数臂**——g 换成 `(1/3,1/3,1/3)` 或固定次序表，任务分/四项指标须退化 **≥0.10**；(b) **源码判据**——AST 出现「长度>3 的常量动作序列 tuple 且被 `拍%len` 索引」或「阶段/相位字段」即判焊死。
- **C1 判定：条件合规**。抢占权=逐元素门控→阈值→3 元 argmax；**无 q·k 打分、无候选集 softmax**。条件：一旦 g 写成 softmax over 三线候选 ⇒ 立刻违规。
- **必须失败对照**：串行重排（先攒 k=5 拍正文再动作）⇒ 最大空隙拍 >1 **或** 孤立动作 >0，动作滞后 L>1 的拍占比 ≥0.20；固定流程树 ⇒ 迁移到未见接口掉至 ≤0.70×已见。
- **迁移臂**：未见接口（新原语名）/未见窗口（新布局）/未见键鼠组合；**≥70%**。
- **代价**：潜态 ≈1.5×10⁴（k=3）+ 正文 ≈1.3×10³ + 动作 ≈1.0×10³ + 调度 ≈2.6×10³ ⇒ **≈2.0×10⁴ 乘加/拍**（解析，未测）。

### S2 共同黑板（三线共用一个内部态）
```
黑板 = S_t = {输出, 世界态, 自我态, 门}          # 前向_双区室 原样四件，不另加字段
三线各持私有工作区 W_x：
  W_x ← 叠(W_x, 读(黑板.键))                     # 读=逐元素抽维；叠=线性
  写标 ← 绑(W_x, 符(黑板.门, 授权掩码))          # 谁能写由门的逐元素强度定，不是固定写者
  黑板.新 ← 归(Σ_x 写标 ⊙ 门)
```
- **边界**：schema 可固定（接口需要），但**读写者配对不得固定**。**可检测**：把「哪条线写哪一维」的配对置乱后表现须下降 **≥0.10**；置乱无影响 ⇒ 固定管线伪装黑板。
- **C1 判定：合规**。绑/叠/符/门 全在 8 算子内，无跨位置归一。
- **必须失败对照**：三线各跑独立态、拼时间线 ⇒ 固定动作下扰动状态文本不变 = 假共同状态（S2 致死臂）。
- **迁移臂**：未见任务中同一状态须同时驱动两条线；≥70%。
- **代价**：每拍 3×D 读 + 2D 绑 + 归 ≈2×10³ 乘加（解析，未测）。

### S3 事件驱动（观测差分触发，作 S1 的 k 调制件）
```
δ_t=归(软限(obs_t−obs_{t−1}))；强_t=mean(|符(δ_t,S_prev.门)|)/(mean|A|·mean|B|+1e-9)
若 强_t>χ_t: 潜态线本拍多跑 Δk=clip(round(k0·强_t),0,k_max)，k0=1,k_max=4
χ_t←(1−β)χ_t+β·强_t
```
- **边界**：不是"事件类型表"——写成 `if 事件名=="窗口切换"` 即查表。**可检测**：未见事件须由连续量 `强` 决定响应，`强` 与响应步数 **ρ≥0.5**；固定 Δk≡常数臂须掉分 ≥0.10；χ 写常数即判焊死。
- **C1 判定：条件合规**。差分/符/均值都在算子内；条件 = χ 必须有内生更新式。
- **必须失败对照**：固定步数臂与自适应臂**无可测差**（<0.02）⇒ 调度不存在。
- **迁移臂**：未见事件（新接口反馈）；≥70%。
- **代价**：差分+符+归 ≈4D + 额外潜态步。

### S4 同拍原子提交契约（必配，防串行伪装）
```
每拍三线各出 提交项=(线名,键,值,digest(obs_t))
门槛：digest 与本拍 obs 摘要一致 且 g[线]>χ_t ⇒ 才入队
提交：一次性放出 [正文分片,动作原语,潜态增量]；缺任一件 ⇒ 该拍记"空心拍"
下一拍只读【已提交】的 S_t 与观测回执（未提交的不给下游看）
```
- **边界**：契约**不许有阶段序字段**（`阶段=1/2/3` 即焊死）。**可检测**：串行重排臂须触发 空心拍>0 或 最大空隙拍>1。
- **C1 判定：合规**（纯记账，不引入新算子）。
- **必须失败对照**：缺件不记空心拍 ⇒ 串行伪装过关（契约必须能抓住）。
- **迁移臂**：契约按「键」泛化到未见原语/未见接口（键由内容+来源绑定生成，不枚举原语名）；≥70%。
- **代价**：记账 O(1)/拍。

### T2 四件套（组）
- **主张**：三线不是三条各跑各的流程，而是同一内部态 S_t 每拍按"抢占权 g_t"分配时隙、经同一提交点同时放出；g_t 常数化或观测切断，行为必须退化——否则本主张作废。
- **证据**：[实测]（源码，非本队新跑）既有四项指标只测**时间线排布**（`证据_三层.md:142-151`：空隙 1/思考跨操作 120/孤立 0/覆盖 1.0）；动作队**不吃观测**（`输出流.py:434-453` 的 `_手推进一步(拍)` 参数只有拍，队列由内置计划/技能库补）⇒ **现状是开环**；契约只校验时间线邻接（`事件契约_操作.py:96-99,136-153`，按 |拍差|≤2 计孤立/覆盖率）⇒ 区分不了"动作由观测驱动"与"动作由表驱动"。
- **反证**：串行重排 / 固定流程树 / 观测只进日志 三支必须失败臂；任一支通过即本机制作废。
- **算力代价**：≈2.0×10⁴ 乘加/拍（解析，未测）；100ms 内余量**未测**；测量方案=`拍钟` 三线出口各打一点（τ_q/τ_a/τ_arb）+ 每次 叠/符/门 计数，单臂 ≤30s，报中位与最大每拍墙钟。

## §4 T3 · 内部深度思考（不公布）：装饰 vs 真思考

### 4.0 前置判定（全节地基）
`_归` 不是 softmax；`W迭` 对角；`读` 是 hard argmax。**丙1 根因**：λ=0.5 ⇒ 4 步即收敛（1−0.5⁴=0.94）；`读` 是 top-1 硬判 + 线性 `叠` ⇒ 迭代不改变 argmax ⇒ 完整臂与切断臂逐点同（`证据_千层.md:67,91`）。**故本节机制一律跑瞬态区（T·η≤0.5，不收敛），并把"收敛度"列成必须失败臂**（与千层口径的最大分歧，见 §7-3）。

### P1 逐元素门控潜态迭代（主推）
```
φ_t = 归(叠([读(码本, 归(x_t)).读出, 绑(x_t)]))          # 边界编码：每令牌仅一次
a_0 = 归(自我态 A)                                        # 两区室核 自我态，跨试次慢态
for s = 1..T_t:
    g_j = 软限(符(a_{s−1}, b_j), 1.0)   (j=1..K=4)        # 逐元素门∈(−1,1)^D，每步重算
    a_s = 归( W自⊙a_{s−1} + W入⊙φ_t + Σ_j g_j⊙b_j )
y_t = 读(码本, 归(叠([a_{T_t}, φ_t]))).索引[0]            # 离散读出 → 正文单位 / 动作
m_t = (1/D)Σ_i |符(a_{T_t}, b_1)[i]| / 界幅               # 门强标量（调度 + 决策第二腿）
```
- **C1 判定：不等价**。四栏：位置间成对打分矩阵=**无**（g_j 在 D 维逐元素，j 只枚举 4 个常数原子，不枚举 t）；softmax over positions=**无**（无 exp、无归一化分母，`软限` 是逐元素饱和）；跨维全连接混合=**循环体内零矩阵乘**（混合只在边界 φ 一次，码本 M=64 常数）；复杂度 `O(T·(3D+3KD))≈T·15D`，对 n **线性**。
- **红队缝（必须守住）**：可被指为"变相注意力"的一步 = φ 里的 `读`（打分+取最大，形态像 QKᵀ）。守三条：码本**不随 t 增长**、**hard argmax** 非 softmax、k≤2；若换成「码本=历史令牌集 ∧ k=M ∧ exp 归一」⇒ **立刻等价 ⇒ 违规**（写进源码级禁词+AST+更新式级双检）。
- **必须失败对照**：冻结/替换 `a` ⇒ 正文/动作改变率 **≤0.05 ⇒ 判"装饰"=FAIL**（≥0.30 才算潜态在因果链上）；固定步数 `T≡8` 与自适应臂差 **<0.02 或 ρ<0.5 ⇒ 调度 FAIL**；F5 清空历史掉分 **<0.10 ⇒ 判"可由输入重算"=未证明**。
- **迁移臂**：未见难度/未见序列长度/未见噪声率，各一组 held-out，不重训；**≥70%**。
- **代价**：`T·14D`；D=256、T∈[1,16] ⇒ **3.6k–57k 乘加/拍**（解析，未测）；T_max 待黄队预算裁。

### P2 无跨维混合的动力学（对角递推；最保守合规基线 / 下界对照臂）
```
a[i] ← 归( a[i] + η_i·( w_i·φ_t[i] − κ_i·a[i] + ρ_i·软限(a[i],1)·b[i] ) )   i=1..D
读出同 P1；另取 相位占空比 d_t=(1/D)Σ_i 1{a[i]>0}；约束 T·η_i≤0.5
```
- **C1 判定：不等价（构造性，不依赖参数取值）**。第 i 维只读第 i 维与其输入通道 i，**零**跨维项；无 softmax；唯一跨维操作是 φ 的固定码本（不学习、不在循环体内）；`T·6D`，对 n 线性。
- **定位（诚实弱点）**：纯对角 ⇒ 无跨维组合能力（做不了 XOR 类组合），红队会指"这不是思考，是 256 个独立标量滤波器"。**回应：P2 是下界对照臂**——若 P2 拿到与 P1/P3 同等分，则 P1/P3 的"深度"是假的，增益必来自别处。
- **必须失败对照**：同 P1；另 `ρ>κ` 的双稳是 F5 的结构性保障（当前输入不能重算历史）。
- **迁移臂**：同 P1；**≥70%**。
- **代价**：`T·6D` ⇒ **1.5k–25k 乘加/拍**（解析，未测）。

### P3 内生态调制（自适应步数/早停；唯一承担「难度→步数 ρ≥0.5」的机制）
```
ε_t = ‖φ_t − 归(W预⊙a_{T_{t−1}})‖₂ / √D                  # 预测误差（W预 对角）
T_t = clip( T_min + round((T_max−T_min)·(0.5+0.5·软限(γ(ε_t−θ),1))), T_min, T_max )
步内早停：若 ‖a_s−a_{s−1}‖∞ < ε_stop ⇒ T_t←s（记 早停=真）
读出取【末次】a_{T_t}，非加权求和
```
- **C1 判定：不等价**。T_t 是**标量**，只改循环次数，不改任何系数；无 softmax；跨维混合=零。**唯一翻车写法（写死为禁）**：把 T 步输出按归一化指数权重加权求和（`o=Σ_s w_s y_s, w=softmax_s`）⇒ 等价于"对内步序列的注意力" ⇒ **等价 ⇒ 违规**。本方案只用硬选择（整数 T + 早停取末次）。
- **必须失败对照**：`T_min=T_max` 或早停从不触发 ⇒ C 退化为常数 ⇒ 由固定步数臂直接抓；ρ<0.5 ⇒ FAIL。
- **迁移臂**：未见难度；**≥70%**。
- **代价**：只改 T，额外 O(D) 预测；无新大项。

### T3 四件套（组）
| 机制 | 更新式 | 与 softmax 注意力 | 必须失败对照 | 迁移 | 代价（解析） |
|---|---|---|---|---|---|
| P1 逐元素门控迭代 | `a_s=归(W自⊙a+W入⊙φ+Σg_j⊙b)` | **不等价**（四栏全否） | 冻结/替换≤0.05；固定 T<0.02；F5<0.10 | ≥70% | T·14D |

| P3 早停调度 | `T_t=clip(...ε_t...)` | **不等价**（标量；翻车=softmax_s 加权） | T_min=T_max；ρ<0.5 | ≥70% | O(D) |

- **证据**：[实测]（引用既有件）`_归` 逐元素（`:84-89`）、`W迭` 对角（`:249-266`）、`符` 逐元素、丙1 逐点同（千层 `:67,91`）、丙3 +0.027（`:68,93`）、戊2 回升比 0.762/0.921（`:74-77`）、L1 计费比 3.999918/ sham 16.0（`证据_三层.md:34`）。**本队零新读数**。
- **反证**：三档必须失败臂任一不过 ⇒ 机制 FAIL；P2 与 P1/P3 同分 ⇒ P1/P3 的"深度"证伪；收敛度 `‖a_T−a_{T+1}‖/‖a_T‖<0.02` ⇒ 迭代=装饰。因果干预臂另加：替换/扰动（`‖δ‖∞=0.1·界幅`）/冻结三档，改变率 **≥0.30（正文）/≥0.25（动作）**；先降后回升比 **≥0.60**；双分离——潜态干预使"需思考臂"掉 ≥0.15、使"直读臂"掉 ≤0.05。
- **代价**：P1 3.6k–57k、P2 1.5k–25k 乘加/拍（解析，未测）；墙钟**未测**，测法：D=256 单线程纯 numpy，单拍重复 2000 次 `perf_counter`，报中位与 p95，同时报两趟指纹是否逐位同。

## §5 T4 · 多脑协作与归属：不同组「人脑」怎么开会、怎么不被洗

### 5.0 约定
N 个**自态体**各自维护 `A_i∈R^D`、`ĝ_i`、`ε_self,i`、慢基线 `b_i`；**无共享总自我态**。D=256、定点、慢率 η=0.12。只许 8 算子。**「共识场」自判不是投票**：投票必含「每主体一个标量票权 + 跨主体归一（count/argmax/softmax）」，本式两项都没有（见 §7-6 与红线）。

### M1 共享黑板（coincidence blackboard）
```
for i: S_i←本脑前向(观测_i)；ε_i←1−cos(ĝ_i(S_i),S_{i+1})；b_i←b_i+α(慢更新)
       if ε_i>b_i: 黑板.追加(归(Ŝ_i−S_i), 来源标_i, ε_i)      # append-only；槽满淘汰符重合最低者
for i: g_ik←clip(符(A_i,黑板.m_k),0,1)；r_i←归(Σ_k g_ik⊙黑板.m_k)
       A_i←归(软限(A_i)+η·(符(A_i,r_i)⊙r_i))                 # 归属门：来源标=外源的槽不进 A_i
y_t←读(码本, 归(Σ_i 符(A_i,r_i)⊙r_i))                        # 共识读出（同 M3）
```
### M2 消息绑定 + 归属门（`符(A_i,A_j)` 门控）
```
发(i→j)：键_ij←绑(id_i,频道码_ij)；m_ij←绑(键_ij,归(Ŝ_i−S_i))   # 内容与来源物理绑定
收(j)： x̂←解绑(键_ij,m_ij)；g_ij←clip(符(A_i,A_j),0,1)           # ★两脑自我态逐元素重合才互通
        A_j←归(A_j+η·g_ij⊙x̂)
外源 m_ext（无有效 a_seal 绑定）⇒ g=0 ⇒ 只进内容记忆，A_j 逐位不变
```
### M3 共识场（逐元素门控加权和，不是投票）
```
F_0←归(叠({x_i}))                                             # 初值只做叠，不做 1/N 平均
for r=1..R:  for i: g_i←clip(符(A_i,F_{r−1}),0,1)；x_i←归(软限(A_i−F_{r−1}))
             F_r←归(Σ_i g_i⊙x_i)                              # 逐元素、无 softmax、无 agent 标量权
             if ‖F_r−F_{r−1}‖≤b_慢: break
y←读(码本,归(F_R))
```
### M4 内生议程触发（议题 = 各自 ε_self 的残差场）
```
每拍：for i: r_i←归(Ŝ_i−S_i)；e_i←clip(符(A_i,r_i),0,1)；d_t←归(Σ_i e_i⊙r_i)   # 议题=残差重合场，无议题词表
F←M3(d_t)；R_t 由 ‖d_t‖ 相对 b_i 决定（非固定步数）
若 ‖r_i‖ 连续 2 拍 > b_i：i 可发"复议"消息（走 M2），不占轮次表
```
- **边界（不得变成固定议程表/投票）**：不是轮流发言表 / 不是多数投票 / 不是规则加权表决 / 不是外源直写自我态。**可检测**：源码出现「发言顺序表/轮次表/`轮转=t%N`」即判焊死（AST 扫：以脑 id 列表索引拍号）；**用 `t mod N` 预测「下一发言脑」准确率 ≥0.90 ⇒ 判轮转表**（真机制应 ≤0.55）；用 N 个标量 `w_i` 拟合 `y≈Σw_i x_i`，**残差 ≤0.05 即判加权表决**；解除归属门（`注入外源规则(允许=True)`）⇒ 自我态漂移 **≥0.10**；来源置换（内容不动）⇒ 内部迹对来源标的线性探测 **AUC≤0.55**，真实来源-写入差异 AUC **≥0.75**。
- **C1 判定：全部不等价**。全逐元素乘加 + 归/叠；无 softmax、无 QKᵀ、无跨 agent/跨位置归一；O(NKD)/O(N²D)。条件：若把 `g_i` 换成对 agent 轴的 softmax/加权平均即违规。
- **必须失败对照**：①切断通信（黑板只读不写/消息全丢）⇒ 联合任务掉 **≥0.15**；②等算力单脑（三路观测拼接给 1 脑，总乘加≈3 脑 ±5%）⇒ 3 脑−单脑 **≥0.10**，若单脑 ≥3 脑−0.05 ⇒ 判「增益=算力」FAIL；③解除归属门 ⇒ 漂移 ≥0.10（门控臂 ≤0.02）；④来源置换 AUC ≤0.55；⑤冻结 ε（r_i 置零）⇒ 议程塌缩为常数 ⇒ 联合任务掉 ≥0.15。
- **迁移臂**：未见队友组合（如 {1,2,4} 中 4 未训）/未见任务参数（新 θ 区间+新噪声率），不重训；**≥70%**。
- **代价**：N=1/3/5 ⇒ **1.4×10⁵ / 4.1×10⁵ / 7.0×10⁵ 乘加/拍**（解析，未测；含 ĝ 前向+更新 2D²/脑/拍）；内存 float64 **0.57/1.56/2.56 MB**（定点 int32 约减半）；墙钟**未测**（方案：N∈{1,3,5}×1000 拍、单核、`OMP_NUM_THREADS=1`、取中位数；两趟指纹=定点 int32 字节 SHA-256 逐位同）。

### T4 四件套（组）
- **主张**：N 个各自维护自我态 A_i 的自态体，只用 8 算子做「符(A_i,·) 逐元素重合准入 + 逐元素门控共识场 + ε_self 自触发议程」，则联合任务必须依赖通信，外源不得直写 A_i，且全机制不含议程表/轮转表/投票/softmax。
- **证据**：[实测]=0 新跑；[源码可查] `符=归(W符⊙a⊙b)`（两区室核 `:163-171`）、外源默认不得塑造自我（`:259-266`）、仅自源更新 W_self（`内核_自我回路.py:233-234`）、`ε_self=1−cos(Ŝ,S)`（`内核_自模型.py:115`）、8 算子与「读≠注意力」（`算子_能力核.py:247`）。机制级=全部 [未验证假设]。
- **反证**：①切断通信掉<0.15；②等算力单脑 ≥3 脑−0.05；③解除门漂移<0.10；④来源置换 AUC>0.55；⑤标量拟合残差≤0.05；⑥议程预测准确率≥0.90——任一出现即 FAIL 或须重设计。
- **算力代价**：见上；两趟口径见上。

## §6 T5 · 整机：常驻闭环、最小可判子集与诚实边界

### 6.1 整机一拍主循环（P1–P4 的接口）
```
每拍 t（拍钟；模型时 100ms 为设计上限）：
 1) 观测 o_t ← 记录-重放读屏/接口（外部输入；显式种子或重放，不读墙钟）
 2) 世界态 B_t ← 能力核前向(令牌列 o_t)                      # 既有主循环
 3) 潜态 a_t ← P1/P2 迭代(a_{t−1}, B_t, T_t)；T_t 由 P3 定    # T3：不公布
 4) 自我态 A ← 学自我(credit=归一化符门强)                    # 两区室；只自源+后果可写
 5) 正文单元 ← 语言读出(A, a_t)                              # T1：M1/M2/M3/M4，无句池
 6) 动作 ← 技能/操作原语(a_t, o_t)                            # T2：键鼠两原语，非查表
 7) 黑板 ← {o_t, B_t, A, a_t, 正文, 动作回执}                 # T2 共同黑板
 8) 同拍原子提交；观测回执进入下一拍                           # T2
```

## §7 私有假设登记（与别队可能不同的前提，逐条）

1. **正文单位 = 词**（不是句）：每拍 ≥1 词，句由多拍组织；若蓝队按「句级每拍」判，阈值与 MI 窗口需重定，绿队反对「一句一拍」作为硬口径。
2. **三线共用一个内部态**（`前向_双区室` 的四件）而非三套独立态拼时间线；若黄队预算不允许同拍三次前向，退化为「共享只读快照 + 私有工作区」，因果臂不变。
3. **「思考」的载体 = (a_T, T_t, m_t) 三元组**，不是单独 a；只测 a 的干预臂会漏掉 P3 步数调度的贡献（丙1 正因只测 a 才逐点同）。采「**瞬态不收敛律**」（T·η≤0.5），并把收敛度 <0.02 列为失败臂——若主控要求"迭代必须收敛到不动点"，本节方向相反，需重裁。
4. **词音外采**（音码任意固定、不含"义"）；词义/词序/指称出生为空。不要求编码器无人设计，只要求音**不携带义**。
5. **固定随机投影 P 只作输入编码/码本，不进循环体、不学习 ⇒ 我判 C1 合规**；若红队判「跨维混合」违规，备选纯置换编码（无损合规，代价是失去码本查回）——这是本队最大的 C1 口径风险，主动登记。
6. **「共识场不是投票」自判**：投票必含「每主体标量票权 + 跨主体归一」；本式逐元素门、按范数归（不按 N）。若红队能用 N 参数标量模型复现共识输出 ≥95% 方差，绿队改判为投票并撤回 M3。

## §8 跨队冲突预判（≥3，逐条给绿队立场）

1. **正文单位粒度（vs 蓝队/红队）**：绿队按**词级**每拍 ≥1 单位、句跨拍；蓝队可能按**句级每拍**。冲突后果：MI 窗口、状态依赖置换检验、迁移阈值全部变口径。绿队立场：词级更可判、更便宜，句级可作为二阶段指标。
2. **状态依赖的检测量与阈值（vs 蓝队/红队）**：绿队主张 `MI(词袋;内部态分箱)` + 置换 200 次 95 分位 + 3-gram Jaccard；蓝队可能用 KL/TV。冲突点：置换零分布与分箱方式。绿队立场：阈值**开跑前预注册**，反对按结果调（否则重犯"更大句池"）。
3. **C1 口径：固定投影算不算「跨维混合」（vs 红队）**：绿队判「不在循环体内、不学习 ⇒ 合规」；红队可能要求**纯置换编码**（连 P 都禁）。冲突后果：T1/T3 全部机制需换编码。绿队立场：给「纯置换臂」作对照，若纯置换不显著掉分则接受；若掉分则证明 P 只是编码而非机制。
4. **T2 并行判据（vs 蓝队/黄队）**：绿队要「切断观测 ⇒ 退化≥0.15」，蓝队可能只要求「空隙≤1/孤立=0」，黄队可能说 100ms 内三线全前向不可行。绿队立场：排布指标是必要不充分；若预算不够，把潜态线降为「每 2 拍一次」但正文/动作仍每拍提交，**不可**退回串行。
5. **T4 议程（vs 蓝队/红队）**：T4 字面「固定议程、固定种子」；绿队判「固定议程表=焊死件」。绿队立场：协议可复现（固定种子）≠ 议程写死（议题由 ε_self 触发）；建议主控按宪法第三条裁。
6. **等算力对照口径（vs 黄队/蓝队）**：绿队主张按**乘加数**配平（可复现、可审计）；黄队可能按墙钟配平（更真但含 I/O 抖动）。绿队立场：两者都报，主判据用乘加、辅助用墙钟。
7. **确定性 vs 外部输入（vs 蓝队/黄队）**：听见流/观测流若不**录制-重放**，两趟不可能逐位同。绿队立场：输入流录制-重放是 C13 硬约束，不是可选项；真机 I/O 只允许出现在沙箱外挂层。
8. **整机判据（vs 红队/蓝队）**：分项 PASS 拼整机 PASS 是重犯；绿队要求 **≥2×2 交互 + 拆件先降后回升 + 清空经历臂**。若蓝队整机判据不含交互项，绿队 R2 将反对该判据。
