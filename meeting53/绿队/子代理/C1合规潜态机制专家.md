## §0 主张（一句话，可证伪）

**在 D=256、码本 M=64 固定、无 exp、无归一化指数、循环体内只有 Hadamard 乘加的约束下，存在 ≥3 个潜态迭代机制，其"步数 T 与潜态 a_t"对正文或动作的因果改变率 ≥0.30；且其更新式不可写成"对位置/令牌的 softmax 加权和"。任一机制若在「冻结 a / 固定 T / 清空历史」三档下输出改变率 ≤0.05，该机制判 FAIL（=装饰）。**

**前置判定（源码级，全文件地基）**：`算子_能力核.py:84-89` 的 `_归` = `nan→限端 → clip(±16) → rint(2^20·x)/2^20`＝**逐向量、逐元素**的有界量化归一，**不是**跨位置 softmax；`门`(:188-193)＝`g⊙x+(1−g)⊙y`（g=clip(0,1)）；`迭代`(:249-266)＝`s←归((1−λ)s+λ·软限(W迭⊙s+d))`，`W迭` 形状 (D,) ⇒ **对角**、无跨维混合、λ_默认=0.5；`读`(:214-247) 在**固定码本 M 行**上做 int64 内积 + hard argmax(k≤2)，O(M·D)，**与令牌数 n 无关**。`符`(`算子_两区室核.py:163-171`)＝`归(W符⊙a⊙b)` 逐元素双线性重合门。
**⚠丙1 根因（必须吸收）**：λ=0.5 ⇒ 4 步即收敛（1−0.5⁴=0.94）；`读` 又是 top-1 硬判 + 线性 `叠` ⇒ 迭代不改变 argmax ⇒ 「完整臂与切断臂逐点相同」(`证据_千层.md:67,91`)。**故本文件的机制一律跑在瞬态区（T·η≤0.5，不收敛），并把"收敛度"列成必须失败臂。**

## §1 机制候选（A/B/C/D；A 主推，B 为合规下界对照，C 为调度，D 可选）

### A · 逐元素门控潜态迭代（主推）
**① 更新式**（t=令牌序，s=内部步，K=4 固定基原子，全部 D 维向量）
```
φ_t = 归(叠([读(码本, 归(x_t)).读出, 绑(x_t)]))        # 边界编码：每令牌仅一次
a_0 = 归(自我态 A)                                     # 两区室核 自我态，跨试次慢态
for s = 1..T_t:
    g_j = 软限(符(a_{s-1}, b_j), 1.0)   (j=1..K)       # 逐元素门 ∈(−1,1)^D，每步重算
    a_s = 归( W自 ⊙ a_{s-1} + W入 ⊙ φ_t + Σ_j g_j ⊙ b_j )
y_t = 读(码本, 归(叠([a_{T_t}, φ_t]))).索引[0]          # 离散读出 → 正文单位 / 动作
m_t = (1/D)Σ_i |符(a_{T_t}, b_1)[i]| / 界幅             # 门强标量（调度 + 决策第二腿）
```
- 变量：`a_s∈R^D` 潜态（**不进正文流**，T3①）；`W自,W入∈R^D` 对角系数（种子固定或慢可塑）；`b_j` 固定原子（码本行，**不学习**）；`g_j∈R^D` 门；`T_t` 见 C。
- **每拍顺序（不可换）**：① 编码 φ_t → ② 由 **a_{s−1} 逐步重算** g_j → ③ 更新 a_s → ④ `_归` 限幅量化 → ⑤ s←s+1；T 步后读出。
- **读出式两条腿**：离散 `y_t` + 连续 `m_t`。**硬约束：决策须至少依赖 m_t**——只读 a 且读出头是线性 top-1，正是丙1 的坑。

**② 同构判定：不等价**。逐项：位置间成对打分矩阵＝**无**（g_j 在 D 维逐元素，j 只枚举 4 个常数原子，不枚举 t）；softmax over positions＝**无**（无 exp、无归一化分母，`软限` 是逐元素饱和）；跨维全连接混合＝**循环体内零矩阵乘**（混合只在边界 φ 一次，码本 M=64 常数，且不进循环体）；复杂度＝`O(T·(3D+3KD))≈T·15D`，对 n **线性**，≠O(n²)。
**③ 逐元素含义与红队缝**：循环体内每个乘法都是 Hadamard；固定投影＝码本行，只做一次边界编码。**可被指为"变相注意力"的一步＝φ 里的 `读`（打分+取最大，形态像 QK^T）**。守住三条：码本**不随 t 增长**、**hard argmax** 非 softmax、k≤2；若换成"码本=历史令牌集 ∧ k=M ∧ exp 归一"⇒ **立刻等价 ⇒ 违规**（写进源码级禁词 + AST + 更新式级双检）。
**④ [文献类比]** 门控 RNN/收敛式推断（思想来源，未核）；"边界混合一次、循环内逐元素"这一结构对立于注意力（本文自己的工程判断，非引用）。

### B · 无跨维混合的动力学（对角递推；最保守合规基线 / 下界对照臂）
**① 更新式**（逐维独立，η_i 逐维步长，T·η_i ≤ 0.5）
```
a[i] ← 归( a[i] + η_i·( w_i·φ_t[i] − κ_i·a[i] + ρ_i·软限(a[i],1)·b[i] ) )   i = 1..D
读出：y_t 同 A；另取 相位占空比 d_t = (1/D)Σ_i 1{a[i]>0}
```
每拍顺序：编码 φ_t 一次 → 对每 i 独立递推 T 步（**步内不通信**）→ 读出。`η_i,κ_i,w_i,ρ_i∈(0,1]` 全为 (D,) 对角参数；`b`=b_1 固定原子；ρ>κ 时单维呈**双稳**⇒ 状态携带历史、不可由当前输入重算（F5 的结构性保障）。
**② 同构判定：不等价（构造性，不依赖参数取值）**。逐项：成对打分矩阵＝不可能（第 i 维只读第 i 维与其输入通道 i，**零**跨维项）；softmax＝无；跨维混合＝零（唯一跨维操作是 φ 的固定码本，不学习、不在循环体内）；复杂度＝`T·6D`，对 n 线性。
**③ 逐元素含义**：全部乘法逐元素；"固定投影不学习"＝码本/种子置换；**可被指为变相注意力处＝无（这正是它存在的意义）**。
**④ [文献类比]** 漏积分神经元 / 双稳吸引子（思想来源，未核）。
**⚠ 诚实弱点（必须写进上报）**：纯对角 ⇒ 无跨维组合能力（做不了 XOR 类组合），红队会指"这不是思考，是 256 个独立标量滤波器"。**回应：B 的定位是下界对照臂**——若 B 拿到与 A/C 同等分，则 A/C 的"深度"是假的，增益必来自别处。这条本身就是反证设计，不是退让。

### C · 内生态调制（自适应步数 / 早停；**唯一能让"难度→步数"成立的机制**）
**① 更新式**（γ,θ,ε_stop 为**先验声明常数**：γ=0.5, θ=0.05, ε_stop=1e-3；不调参）
```
ε_t = ‖φ_t − 归(W预 ⊙ a_{T_{t−1}})‖₂ / √D          # 预测误差（W预 对角）
T_t = clip( T_min + round((T_max−T_min)·(0.5 + 0.5·软限(γ·(ε_t − θ), 1))), T_min, T_max )
步内早停：若 ‖a_s − a_{s−1}‖∞ < ε_stop ⇒ T_t ← s（记 早停=真）
读出：取**最后一次** a_{T_t}，非加权求和
```
每拍顺序：ε_t → 定 T_t → 跑 A 或 B 的循环 T_t 步（早停可截短）→ 读出。
**② 同构判定：不等价**。逐项：单独看 C **不产生任何跨位置/跨令牌权重**（ε_t 是 D 维残差的 RMS 一次归约；T_t 是**标量**，只改循环次数，不改任何系数）；无 softmax；跨维混合＝零；复杂度＝乘加只随 T_t 变，仍对 n 线性。
**⚠ 条件等价的唯一翻车写法（写死为禁）**：把 T 步输出按**归一化指数权重**加权求和（`o=Σ_s w_s y_s, w=softmax_s`）⇒ 等价于"对内步序列的注意力" ⇒ **等价 ⇒ 违规**。本方案只用**硬选择**（整数 T + 早停取末次）。
**③ 逐元素含义**：ε_t 的归约不产生权重、不产生位置对；T_t 标量。**红队缝**：若 T_min=T_max 或早停从不触发，C 退化为常数 ⇒ 由失败臂②直接抓。
**④ [文献类比]** 预测编码/主动推断中"误差驱动计算量"（思想来源，未核）；"思考多久由想不通程度决定"是宪法"内生"读法的功能化（本文解释，非引用）。

### D ·（可选）符作为潜态-世界重合门（读出侧路由）
**①** `o_t = 门( 归(符(a_{T_t}, w_t) / 界幅) , y_读 , y_自 )`，`w_t`=世界态（`前向_双区室` 的 B 列，`算子_两区室核.py:218-229`）。逐元素在"内部补全"与"感觉输入"之间路由，权重＝重合强度本身（同 `学自我` 用门强当 credit，:232-245）。
**② 不等价**：Hadamard 双线性，无成对打分、无 softmax、无跨维混合。**边界**：把 `符` 换成"内积 + softmax over 原子集"⇒ 退化成 meeting52 已判的 softmax 关联记忆 ⇒ 违规。
**③** 全部逐元素；`门` 的 g=clip(0,1) 是硬截断非归一化指数。**④ [文献类比]** 重合检测/门控路由（思想来源，未核）。

## §3 三条臂（输入 / 操作 / 观测 / 阈值位置）

| 臂 | 输入 | 操作 | 观测 | 阈值（位置写清） |
|---|---|---|---|---|
| **① 冻结潜态（必须失败）** | 同主臂序列 | 每步 `a_s ← a_0`（常数）**或** `a_s ← 种子固定的随机向量` | 正文 TV + 动作改变率 | **改变率 ≤0.05 ⇒ 判"装饰"=FAIL**；≥0.30 才算潜态在因果链上。阈值落在**正文/动作输出端**，不看内部态 |

## §7 大白话
