## §0 主张（一句话，可证伪）
在 C1 红线内，让 **N 个各自维护自我态 A_i 的自态体**只用 8 算子做「符(A_i,·) 逐元素重合准入 + 逐元素门控共识场 + ε_self 自触发议程」，则联合任务必须依赖通信（切断通信掉 ≥0.15；3 脑比等算力单脑高 ≥0.10，否则增益只是算力），外源不得直写 A_i（解除门漂移 ≥0.10、来源置换 AUC ≤0.55），且全机制不含议程表/轮转表/投票/softmax；任一阈值不过即推翻。
## §1 机制候选
**约定（全节）**：N 个自态体各自维护 A_i∈R^D、ĝ_i(W_i∈R^{D×D})、ε_self,i、慢基线 b_i；**无共享总自我态**。D=256、定点 2^-20、慢率 η=0.12。只许 8 算子：绑/解绑/门/叠/归/读/迭代/符（[源码可查] 算子_能力核.py:176-266；符=`归(W符⊙a⊙b)` 两区室核.py:163-171；门=`g⊙x+(1−g)⊙y` :188-193；读=码本索引、`是注意力=False` :247）。
### A · 共享黑板（coincidence blackboard）
① 更新式
```text
每拍 t（N 个自态体各自维护 A_i，无中心控制器）：
 for i in 1..N:
   S_i←本脑前向(观测_i)；ε_i←1−cos(ĝ_i(S_i),S_{i+1})；b_i←b_i+α(慢更新)
   if ε_i>b_i: 黑板.追加(归(Ŝ_i−S_i), 来源标_i, ε_i)   # append-only；槽满淘汰符重合最低者
 for i in 1..N:                                          # 每轮更新：只读与自己重合的维
   g_ik←clip(符(A_i,黑板.m_k),0,1)；r_i←归(Σ_k g_ik⊙黑板.m_k)
   A_i←归(软限(A_i)+η·(符(A_i,r_i)⊙r_i))                # 归属门：来源标=外源的槽不进 A_i
 y_t←读(码本, 归(Σ_i 符(A_i,r_i)⊙r_i))                   # 共识读出（同 C）
```
② 不得退化的边界：写板条件是 ε_i>b_i（自归一），**源码出现「发言顺序表/轮次表/`轮转=t%N`」即判焊死**（AST 扫：以脑 id 列表索引拍号）。不是投票：g_ik 是 D 维逐元素门；用 N 个标量 w_i 拟合 y≈Σw_i x_i，残差 ≤0.05 即判加权表决。不是外源直写：消息只能经符进 A_i。可检测：**用 t mod N 预测「下一发言脑」准确率 ≥0.90 ⇒ 判轮转表**（真机制应 ≤0.55）。
③ C1：**否**（不违规）。全逐元素乘加+归/叠；无 softmax、无 QKᵀ、无跨 agent 归一；O(NKD)。
④ [文献类比] 全局工作空间（内容广播、容量有限）；[文献类比] 黑板架构 Hearsay-II（思想来源，未核）。
### B · 消息绑定 + 归属门（符(A_i,A_j) 门控）
① 更新式
```text
发(i→j)：键_ij←绑(id_i,频道码_ij)；m_ij←绑(键_ij,归(Ŝ_i−S_i))  # 内容与来源物理绑定
收(j)：  x̂←解绑(键_ij,m_ij)
         g_ij←clip(符(A_i,A_j),0,1)                        # ★两脑自我态逐元素重合才互通
         A_j←归(A_j+η·g_ij⊙x̂)                              # A_i、A_j 分属两脑、各自维护
归属门： 外源 m_ext（无有效 a_seal 绑定）⇒ g=0 ⇒ 只进内容记忆，A_j 逐位不变
```
② 边界：不是外源直写（门在 A_i⊙A_j 上，不在「信任分」上）。不是规则加权表决：g_ij 随内容逐维变，N 个标量 w_ij 复现残差必须 ≥0.10（≤0.05 判表决）。不是轮转：发送由 ε_i 触发。可检测：**解除归属门（A_j←归(向量)）⇒ 漂移 ≥0.10**；**来源标随机置换（内容不动）⇒ 内部迹对来源标的线性探测 AUC ≤0.55**，同时真实来源-写入差异 AUC ≥0.75。
③ C1：**否**。绑/解绑/符/归 全逐元素；O(N²D)。
④ [文献类比] 来源监控（source monitoring）；[文献类比] 特征绑定问题（binding problem）（思想来源，未核）。
### C · 共识场（逐元素门控加权和，不是投票）
① 更新式
```text
每拍：F_0←归(叠({x_i}))                                     # 初值只做叠，不做 1/N 平均
 for r in 1..R:                                             # R 由 ‖F_r−F_{r−1}‖ 相对 b_i 触发
   for i in 1..N: g_i←clip(符(A_i,F_{r−1}),0,1)             # D 维门，每维不同
                  x_i←归(软限(A_i−F_{r−1}))                 # 各自维护 A_i；"我 vs 场"差分
   F_r←归(Σ_i g_i⊙x_i)                                      # 逐元素、无 softmax、无 agent 标量权
   if ‖F_r−F_{r−1}‖≤b_慢: break
 y←读(码本,归(F_R))                                         # 共识读出
```
② 边界：投票=「每主体一个标量票权 + 跨主体归一（count/argmax/softmax）」；本式两项都没有。**可检测**：N 参数标量拟合残差 ≥0.10；源码不得出现 `1/N`、`mean(axis=agents)`、`exp/softmax`、对 agent 轴的归一化；置换来源标 AUC≤0.55。不是固定议程：R 与初值都由场残差定；不是外源直写：F 的每一项都过 g_i=符(A_i,·)。
③ C1：**否**（**条件**：若把 g_i 换成对 agent 轴的 softmax/加权平均即违规；本式只许逐元素乘、不加跨维混合）。无 QKᵀ；「读」是码本索引（:214-247）。
④ [文献类比] 共享意向 / we-intention（集体意向性）；[文献类比] 共识场 / mean-field（思想来源，未核）。
### D · 内生议程触发（议题 = 各自 ε_self 的残差场）
① 更新式
```text
每拍：for i: r_i←归(Ŝ_i−S_i)                                 # 自模型残差（D 维），非议题标签
            e_i←clip(符(A_i,r_i),0,1)                        # 哪些维"我预测不了"
 d_t←归(Σ_i e_i⊙r_i)                                        # 议题=残差重合场；无议题词表
 F←C.共识场(d_t)；R_t←由 ‖d_t‖ 相对 b_i 决定（非固定步数）
 若 ‖r_i‖ 连续 2 拍>b_i：i 可发消息要求"复议"（走 B），不占轮次表
```
② 边界：**源码出现议题池/话题表/意图→议题查表即判焊死**（照 meeting41 输出流.py:105-128 句池的病）。不是轮流发言（t mod N 预测准确率 ≥0.90 即判轮转表）；不是多数投票（d_t 是逐元素场，不是计数）；不是外源直写（r_i 只由本脑 ĝ_i、S_i 产生）。可检测：冻结 ε（r_i 置零）⇒ 议程塌缩为常数 ⇒ 联合任务掉 ≥0.15。
③ C1：**否**。符/归/迭代/门；无 softmax、无对 agent 的归一化指数、无固定议程表。
④ [文献类比] 预测编码/自由能（预测误差驱动）；[文献类比] 显著性驱动觉察（思想来源，未核）。
## §2 四件套
- **主张**：同 §0（五条阈值任一不过即推翻本机制族）。
- **证据**：仅组件级。**[实测]=0（本件没跑）**；[源码可查] 符=`归(W符⊙a⊙b)`（两区室核.py:163-171）、外源默认不得塑造自我（:259-266）、仅自源更新 W_self（内核_自我回路.py:233-234）、ε_self=1−cos(Ŝ,S)（内核_自模型.py:115）、8 算子与「读≠注意力」（算子_能力核.py:247）。机制级=全部 [未验证假设]。

- **算力代价**（**解析设计值，未测**；D=256；只计协作层，主前向另计；含 ĝ 前向+更新 2D²/脑/拍）：乘加/拍 N=1≈1.4×10⁵、N=3≈4.1×10⁵、N=5≈7.0×10⁵（式 `N(2D²+15D)+N(N−1)3D+4ND+8D`）。内存 float64：0.57/1.56/2.56 MB（定点 int32 约减半）。墙钟**未测**：方案=N∈{1,3,5}×1000 拍、单核、`OMP_NUM_THREADS=1`、取中位数；两趟指纹=定点 int32 字节 SHA-256 逐位同。
## §3 四条臂（输入/操作/观测/阈值位置）
| 臂 | 输入 | 操作 | 观测 | 阈值位置 |
|---|---|---|---|---|
| ① 切断通信 | 同任务/同观测/同种子 | 黑板只读不写（追加=丢弃）或消息全丢 | 联合任务 Acc（及 与标签互信息） | 完整臂−切断 ≥0.15（设计值） |
| ② 等算力单脑 | 三路观测拼接给 1 脑 | 单脑总乘加≈3 脑 ±5%（D 与迭代步数组合取不超预算最大者） | Acc | 3 脑−单脑 ≥0.10；若单脑 ≥3 脑−0.05 ⇒ 判「增益=算力」FAIL |
| ③ 解除归属门 | 固定外源向量（种子固定） | A_i←归(向量)（`注入外源规则(允许=True)`），对照=经符门 | ‖ΔA_i‖/‖A_i‖ + 自指任务 Acc | 释放臂 ≥0.10；门控臂 ≤0.02 |
| ④ 来源置换 | 原消息流 | 来源标随机置换 ×10（种子固定，内容不动） | 线性探测 AUC（迹→来源标） | ≤0.55；真实来源-写入 AUC ≥0.75 |
| ⑤ 迁移臂 | 未见队友组合（{1,2,4} 中 4 未训）/未见任务参数（新 θ 区间+新噪声率） | 不重训，直接用 | Acc | ≥已见组合的 70% |
| ⑥ 因果干预 | 运行中 | 置换 A_k←A_j；冻结 A_k（消息照发） | 共识 y 的 TV；Acc | 置换 TV ≥0.15；冻结掉 ≥0.10 |
两趟：同种子两趟逐位同（指纹口径见 §2）；读数与失败判定均来自脚本输出，不靠人工判读。

## §5 私有假设登记
1. **「共识场是否算投票的变体」——自判：不是。** 投票必有「每主体一个标量票权 + 跨主体归一（count/argmax/softmax）」；共识场是逐元素门 + 归（按范数，不按 N）。若红队能用 N 参数标量模型复现共识输出 ≥95% 方差，我改判为投票并撤回 C。
2. **PS×PV 不可分离（I=0.478）是设计约束，不是缺陷**：同一「符」兼任准入与信用，故不做 PS-only/PV-only 分解；归属判据改用「漂移 + 来源置换 AUC」双读，不再用「W_self 谁在写」单读（这正是 meeting52 绿/蓝口径差的根）。
3. **与 T4 字面冲突**：T4 要「固定议程」，我判固定议程=焊死件（宪法第三条），改为「无议程表 + 固定种子 + 可重放」；若主控裁定必须固定议程，则本机制只算「协议可复现」，不算「内生议程」。
4. 「开会/商议」只是接口名；只主张功能子集：交换信息改变输出且可因果归因。
5. 任务必须部分可观测且交换必要；若等算力单脑打平，我判 FAIL，不改任务救它（R2 前允许重定任务族一次，须先声明）。
6. 判据阈值全是设计值（未测）；ε 慢基线沿用 内核_自我回路.py:102-107「相对自身基线」，不手挑阈值。
