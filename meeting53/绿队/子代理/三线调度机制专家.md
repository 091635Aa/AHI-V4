# 三线调度机制专家 · 三线并行的内生调度机制候选（T2）
> meeting53 绿队（队长 captain-green）｜只交**方案 + 判据规格**，零生产代码改动｜依据件行号均为只读核查
> 三线 = 正文线/动作线/潜态线；同一时基（沿用 `时基.拍钟`）；拍长按议题取 100ms 为硬上限。
## §0 主张
**一句话**：三线不是三条各跑各的流程，而是**同一个内部态 S_t 每拍按"抢占权 g_t"分配时隙、经同一个提交点同时放出**；故 g_t 常数化或观测被切断，行为必须退化——否则本主张作废。
**可证伪**：(a) 把 g_t 换成常数/固定次序表后任务分与四项指标退化 <0.05；(b) 切断观测后退化 <0.15。任一成立即判 FAIL（焊死/开环），不作"成立"宣称。
## §1 机制候选（A 主干 · D 必配 · B 作共享口径 · C 作加权件）
### A · 时隙 + 抢占（推荐主干）
① 伪代码（可照写）
```
每拍 p：τ*_p = 拍转秒(p)；三线时隙起点 = τ*_p + {0.00,0.35,0.70}   # 时隙是上限，不是次序
  obs_t = 读屏/读接口()                        # 记录-重放，不读墙钟（C13）
  S_t   = 前向_双区室(obs_t 令牌列, 上下文=S_prev["自我态"])
  g     = 抢占权(S_prev, obs_t)                # 逐元素门控+归+阈值；禁 softmax over 候选
  winner = argmax3(g)                          # 平局固定次序（C13）
  先跑 winner，再按 g 降序补跑另两线；每线每拍至少推进 1 次（保底，非轮转）
  三线各写"本拍提交项"，拍末统一提交（见 D）
抢占权（内生，无手调优先级表）：
  m_q = 归(Wq ⊙ S_prev.输出)   m_a = 归(Wa ⊙ S_prev.门)   m_t = 归(Wt ⊙ S_prev.世界态)
  χ_t = (1-β)·χ_{t-1} + β·mean(|S_prev.门|)    # 阈值由内部态滑动，不写常数
  g   = [mean(阈值(m_q,χ_t)), mean(阈值(m_a,χ_t)), mean(阈值(m_t,χ_t))]
  g   = g / (sum(g)+1e-9)                      # 标量归一：仅用于排序与保底配额
```
② 「不得变成写死流程树」边界：不是固定轮转表（现状正是反例：`输出流.py:521-540` 每拍固定 思考→手→正文，`:128,527` 源由 `源序[(拍+种子)%4]` 轮转，`:8-11` 三线钉在偏移 0.0/0.4/0.9）；不是先攒文本后动作；不是动作查表。可检测判据：(a) **常数臂**——g 换成 (1/3,1/3,1/3) 或固定次序表，任务分/四项指标须退化 ≥0.10；(b) **源码判据**——AST 出现"长度>3 的常量动作序列 tuple 且被 `拍 % len` 索引"或"阶段/相位字段"即判焊死。
③ C1 判定：**是（条件）**。仅用 叠/归/门/符/读/迭代/绑/解绑；抢占权 = **逐元素门控 → 阈值 → 3 元 argmax**，无 q·k 打分、无候选集上 softmax 归一 ⇒ 与注意力不同构。**条件**：一旦 g 写成 softmax over 三线候选向量，立刻判违规。
④ [文献类比] 抢占式调度与优先级反转（思想来源，未核）；[文献类比] 双任务的心理不应期 PRP——人也不能真同瞬做两件，只能快速交替（思想来源，未核）。
### B · 共同黑板（三线共用一个内部态）
① 伪代码
```
黑板 = S_t = {输出, 世界态, 自我态, 门}        # 前向_双区室 原样四件，不另加字段
三线各持私有工作区 W_x（D 维）：
  W_x ← 叠(W_x, 读(黑板.键))                  # 读=逐元素抽维；叠=线性
  写标 ← 绑(W_x, 符(黑板.门, 授权掩码))        # 谁能写由 门 的逐元素强度定，不是固定写者
  黑板.新 ← 归(Σ_x 写标 ⊙ 门)
```
② 边界：schema 可固定（接口需要），但**读写者配对不得固定**；判据：把"哪条线写哪一维"的配对置乱后表现须下降 ≥0.10；置乱无影响 ⇒ 固定管线伪装黑板。
③ C1：**是**。绑/叠/符/门 全在 8 算子内，无跨位置归一。
④ [文献类比] 黑板架构（多知识源共享一块工作区；思想来源，未核）。
### C · 事件驱动（观测差分触发，作 A 的 k 调制件）
① 伪代码
```
δ_t  = 归(软限(obs_t − obs_{t-1}))
强_t = mean(|符(δ_t, S_prev.门)|) / (mean|S_prev.自我态|·mean|S_prev.世界态|+1e-9)
若 强_t > χ_t: 潜态线本拍多跑 Δk = clip(round(k0·强_t), 0, k_max)   # k0=1, k_max=4
χ_t ← (1-β)·χ_t + β·强_t
```
② 边界：不是"事件类型表"——写成 `if 事件名=="窗口切换"` 即查表；判据：未见事件须由连续量 强 决定响应，且 强 与响应步数 ρ≥0.5；固定步数臂（Δk≡常数）须掉分 ≥0.10；χ 若写常数即判焊死。
③ C1：**条件通过**。差分/符/均值都在算子内；条件 = χ 必须有内生更新式。
④ [文献类比] 中断驱动系统（思想来源，未核）；[文献类比] 预测编码的"意外量"驱动（思想来源，未核）。
### D · 同拍原子提交契约（必配，防串行伪装）
① 伪代码
```
每拍三线各出 提交项 = (线名, 键, 值, digest(obs_t))
门槛：digest 与本拍 obs 摘要一致 且 g[线]>χ_t ⇒ 才入队
提交：一次性放出 [正文分片, 动作原语, 潜态增量]；缺任一件 ⇒ 该拍记"空心拍"
下一拍只读**已提交**的 S_t 与观测回执（未提交的不给下游看）
```
② 边界：契约**不许有阶段序字段**（`阶段=1/2/3` 即焊死）；判据：串行重排臂（先攒 k=5 拍正文再动作）须触发 空心拍>0 或 最大空隙拍>1。
③ C1：**是**（纯记账，不引入新算子）。
④ [文献类比] 事务原子提交/两阶段提交（思想来源，未核）。
**推荐组合**：A（调度）+ D（提交）为最小闭环；C 只调 k；B 只作 A 的状态共享口径，不叠两套机制。
## §2 四件套
**主张**：同 §0。
**证据**：[实测] 既有件只测排布——四项指标（空隙1/思考跨操作120/孤立0/覆盖1.0）见 `证据_三层.md:142-151`，其诚实边界自承"是管线证据、不是自然语言生成能力"（`:168-175`）。[实测] 动作队不吃观测：`输出流.py:434-453` 的 `_手推进一步(拍)` 参数只有拍、队列由内置计划/技能库补 ⇒ **现状是开环**，正是本方案要补的一环。[实测] 契约只校验时间线邻接：`事件契约_操作.py:96-99`（窗拍=2）、`:136-153`（按 |拍差|≤2 计孤立/覆盖率）⇒ 区分不了"动作由观测驱动"与"动作由表驱动"。
**反证**：§3 三支失败臂 + 三支因果/迁移臂；任一失败臂通过即本机制作废。
**算力代价**（每拍 100ms，D=256；口径 `拍数·U·D·(2m+11)·H`，m=4,H=1 ⇒ 单单元 4864 乘加/拍，参照 `证据_千层.md:104`）：
| 线 | 每拍乘加（解析） | 口径 |
|---|---|---|
| 潜态 | **≈1.5e4**（k=3） | k·4864 + 软限 D + 符 2D；k 由 §1C 的 强 定，上限 4 |
| 正文 | **≈1.3e3** | 读 2D + 绑/符 3D + 组合 D；词读出实现未定 |
| 动作 | **≈1.0e3** | 门 3D + 参数门控；7 原子为原语、非序列 |
| 调度开销 | **≈2.6e3** | 三个 门/归 + argmax（argmax 为比较，不计乘加） |
| **合计** | **≈2.0e4 乘加/拍** | 全为**解析设计值，未测** |
预算：100ms 内余量看似充足但**未测**。测量方案：`时基.拍钟` 在三线出口各打一点（τ_q/τ_a/τ_arb），每次 叠/符/门 加计数（+D 或 +2D），单次 ≤30s 探针，报中位与最大每拍墙钟、并报是否超 100ms。
## §3 三条臂
### 3.1 必须失败对照臂（三支，缺一不报）
| 臂 | 实现 | 预期失败值（判据） |
|---|---|---|
| ① 串行重排 | 先攒完 k=5 拍正文，再一次性出动作 | 最大空隙拍 >1 **或** 孤立动作 >0；动作相对观测滞后 L>1 的拍占比 ≥0.20 |
| ② 固定流程树 | 动作由"意图→原子序列"常量表给（宪法第三条的病，`双想公布.py::计划()` 同款） | 迁移到未见接口/未见键鼠序列掉至 ≤0.70×已见；且源码动作序列表判据命中 |
| ③ 观测只进日志 | obs 写日志但不进 S_t、不参与 g | 该臂切断观测后 Δ<0.05（恒等）⇒ 正常臂必须 Δ≥0.15 才算闭环 |
### 3.2 迁移臂
未见接口（新原语名）/未见窗口（新布局）/未见键鼠组合 三组 held-out，阈值 **≥0.70×已见**；另报"掉分最小的一组"与样本数。70% 可重定，须在开跑前写死。
### 3.3 因果干预臂
- 扰动观测（换另一屏）：下一拍动作必须变——`TV(动作分布|屏A,屏B) ≥0.20` 且 argmax 改变率 ≥0.30。
- 切断观测：任务分退化 ≥0.15，且潜态步数分布 TV ≥0.15。
- 冻结 `前向_双区室` 的自我态 A：正文或动作必须变（否则潜态=装饰，接 T3 口径）。

## §5 私有假设登记
1. **三线共用一个内部态**（`前向_双区室` 的 S）。若别队主张每线独立态，§1B 与 §3.3 须改为"共享只读快照 + 私有工作区"。
2. 观测延迟 = 1 拍；真机可能 2–3 拍 ⇒ 因果臂先按 L∈{1,2,3} 扫描再定阈值。
3. 100ms/拍 为硬上限（来自议题，**非实测**）。
4. argmax 平局用固定次序（C13）；红队可能判"写死"；备选＝平局沿用上一拍 winner（有状态、仍确定性）。
