## §3 「功能签名≠机制复刻」边界（Marr 三层）

- **计算目标层（算什么）**：说"我们和生物算同一个题"是**假设**，不是测量——活体的目标不可读出，只能由行为反推。
- **算法层（怎么算）**：最容易越界的一层。判据能测的是"我方算法在功能上的输入-输出关系"；不能测"生物用的是不是同一算法"。
- **实现层（拿什么算）**：numpy/定点/D=256 与树突、皮层无对应关系。用"两区室"直接指认"锥体细胞"即越界。

**三个"行为同签名、机制不同"的具体例子**：

1. **工作记忆**：延迟期"能解码出刺激"这个签名，RNN 靠持续活动、生物靠活动静默+持续放电双机制、我方靠递推态残差——签名同，三种机制互不相同 ⇒ 签名**不能反过来指定机制**。
2. **显著性**：pop-out 与信噪比提升这个签名，softmax 注意力、逐元素门控、生物分流抑制都能做出来；C1 只排除了第一种**实现**，没有证明后两种是"人脑同款"。
3. **回放**：重放提升未见起点表现这个签名，采样重放、离线参数平均、单纯更多数据都能给出同一曲线——meeting51 丙1/丙3 正是"曲线有、机制无增益"的反例现场。
   补充**自我模型**：连行为签名都缺，只有"慢态可解码"，比上面三个更弱一层。

**结论**：判据只能判「功能子集 + 因果消融」；「人脑同款」不在可测域内——它是**解释**，不是**观测**。

## §4 绝不能主张清单（≥10；出现即该文档判 INVALID）

1. **「一比一复刻人脑所有关键步骤」**——不存在唯一公认的"关键步骤"清单，也没有可比对的度量。
2. **「复刻了人脑的机制」**——活体机制不能与我们同时被读取；双区室只是工程映射。
3. **「有现象意识/主观体验」**——私密性；系统自报不是证据，无法被任何外部观测证伪。
4. **「有人类级自我意识」**——无公认操作定义；最多主张"慢态保持 + 归属度"这一功能子集。
5. **「输出与 Transformer 等价/同款语言能力」**——无同分布基准且 C1 禁其架构；"像"只能指"正文可读 + 状态依赖"。
6. **「实现了注意力机制」**——C1 红线；只许说"逐元素门控/显著性选择"，写成全局 softmax 即违规。
7. **「真的在思考（人同款）」**——能证的只有"潜态进因果链"（替换/扰动/冻结改变输出），不能证"想到了"。
8. **「已习得语法/内生语言能力」**——"习得"需未教组合迁移，"语法"无可测定义；只判 held-out 组合可懂度。
9. **「复刻了记忆巩固/睡眠」**——我们没有睡眠，只有离线账；生物过程不可主张。
10. **「有情绪/感受」**——只测效价×唤醒二维观测量对行为的影响，"感受"不可测。
11. **「达到人类通用智能」**——Toy 规模（D=256）、无基准、无外推依据。
12. **「已完成/达到所有者那一句」**——宪法第八条禁"已完成"宣称；meeting52 七项 0 项可宣称达成。
13. **「迁移成功＝真会了」**——迁移只是机制类比、非等同（千层 §5.6）。
14. **「多 agent 开会＝人脑协作」**——投票/议程表是外部机制，不是内生协作。

## §5 给绿队 5 条机制的「可被红队攻击点」预判（最脆一环 + 致死对照臂）

1. **内生语言**｜最脆：词义"内生"无法与"共现统计查表"分开——更大的句池/统计表同样能过"可读性"。
   致死臂：运行中**随机置乱词义绑定表**（保留词音与句法外观）⇒ 正文可读性与任务分不掉 ⇒ 是表驱动；再加"清空早期经历但保留绑定表不掉分"臂。
2. **三线调度**｜最脆："并行"可能只是排布（meeting41 的"空隙拍 1"只测时间线，不测因果）。
   致死臂：**串行重排臂**（同样的动作集合与总拍数，先攒文本再动手）＋**切断观测回流臂**；串行不掉分、切断不退化 ⇒ 并行与闭环都是装饰。
3. **C1 潜态**｜最脆：更新式悄悄等价于**全局 softmax**（跨维指数归一），却写成"逐元素门控"。
   致死臂：更新式同构判定表（是/否/条件）+ **维度置换等变检验**（依赖全局归一者置换即变）＋ F5 臂（用当前输入重算 z，若分数不变 ⇒ z 不携带历史）。
4. **多脑协作**｜最脆：收益来自**算力**而非通信；归属判据可被"只置换来源标签"骗过。
   致死臂：**等算力单脑对照**（1 脑×N 算力）+ 切断通信臂 + 来源置换 AUC≤0.55 + 把协议换成**固定轮流发言表**（不掉分 ⇒ 协作是模板）。
5. **整机**｜最脆：分项各自过关就被拼成"整机过关"，耦合从未被单独测（PS×PV 不可分离 I=0.478 的前科）。
   致死臂：**≥2×2 联合消融**（正文×旁路 / 潜态×多脑）+ 拆件"先降后回升"曲线 + **清空经历但保留全部模块**臂（整机不掉分 ⇒ 全机查表）。

## §7 大白话

我们能证明的是：某些功能在这台机器里真起作用，拆掉就变差。不能证明的是：人脑走的是同一条路。像不像人脑是故事；拆不拆得动才是证据。
