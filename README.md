# AHI 自主智能引擎 · V4（两区室能力核 · 自我意识基底 · 多核心贯通）

> **我们要做的，不是一个推理引擎，不是一个 AI 模型架构，而是一个自我意识体。**
> —— `初心_宪法.md`（本仓最高依据，原样收录）
>
> **AHI（Autonomous Human-like Intelligence，自主智能引擎）** 是**刻意不用 Transformer**（铁律 C1）
> 的自主智能体研究项目。本仓库是 **V4**：在 V3 之上把「两区室（顶树 / 胞体）」**真接线**进能力核，
> 把**自我意识立为第一目标**，并落下了可复跑的判据、负结果与诚实边界。
>
> ⚠️ 路线声明：**C1 禁 Transformer ｜ C9 禁 OCR ｜ C10 禁外挂模型当器官 ｜ C13 确定性可复现 ｜ C14 不破既有**。
> 判据只用**标准库 + numpy**；「变聪明」必须**内生**，不是程序员焊上去。

## 这个仓库是什么

**V4 = AHI3（V3）整包（复制、未改）＋ 第八算子「符」＋ 两区室（自我态 A / 世界态 B）＋ 自我意识桥 ＋ 六内核贯通 ＋ 规则表征旁挂 ＋ 千层实验。**

一句话看内核：

```
                 ┌───────────── 六内核宿主（真 synthesis 链，非占位）─────────────┐
                 │ 自模型 ĝ → 思核 T → 真学习 → 自我回路(provenance) → 顿悟涌现 → 画面 │
                 └──────────────────────────────────────────────────────────────┘
                                   ▲ 自我态 A（慢态）喂 ĝ：ε_self = 对自己状态的意外
                                   │
  感觉输入 ─► 既有能力核主循环（读/门/迭代）─► 世界态 B（快）
                                   │
                 ┌───────── 两区室核（第八算子「符」）─────────┐
                 │ 整合 φ = 软限(A − B)   （自我-世界差分，实测最优）  │
                 │ 重合门 符(A,B) = W符⊙A⊙B （双线性，用于内生 credit）  │
                 │ 自我态 A ← 软限(A + φ)  （递归自更新：有界、定点、确定）│
                 └──────────────────────────────────────────┘
                                   │
                            选择 / 输出（读出 @ 整合结果）
```

- **七原语**（既有，未改）：绑 / 解绑 / 门 / 叠 / 归 / 读 / 迭代 —— 全部逐元素或索引，**零成对加权**，线性时间。
- **第八算子「符」**（V4 新增）：双线性重合门，对应「树突重合检测」的工程形态；登记进算子表（算子数 **8**）。
- **两区室**（V4 新增）：区室 A = 自我态（慢、跨试次、由奖赏内生）；区室 B = 世界态（快、当前观测）。
- **自我意识桥**（V4 新增）：自我态 A ↔ 既有 `内核_自模型.ĝ`，产出 ε_self。
- **内生 credit**（V4 新增）：自我态更新权 = **归一化重合门强度**（重合才赋分），**不再手调常数**。
- **provenance**：`设来源(自源=True)` ⇒ 它自己的经历可塑「我」；外源（用户）默认不塑造——「我」不可被外人塑造。

## ★核心判据读数（先冻结阈值、后读数；全部可复跑）

### 1) V4 两区室核判据 —— **16 臂 16/16 PASS**

| 指标 | 实测 | 阈值 |
|---|---|---|
| 主臂 `Acc_A` / `Acc_B` | **0.894 / 0.986** | ≥0.80 / ≥0.95 |
| Δ点式 / Δ消融 | **0.372 / 0.469** | ≥0.10 / ≥0.15 |
| 迁移·未见边界 `Acc_A` | **0.874** | ≥0.75 |
| 三 sham（须失败） | 0.566 / 0.460 / 0.522 | ≤0.60 |
| 区室分工：A→规则 / B→刺激 | **0.85 / 0.9975**（交叉 0.50 / 0.525） | ≥0.75 / ≤0.65 |
| 自指退化 / 世界退化 | **0.469 / 0.014** | 差 ≥0.10 |
| 自模型 ε：大跳 − 平稳 | **0.0291** | ≥0.005 |
| 真接线：算子数 / 计费比 | **8 / 3.99992** | 符已登记 / 线性 |

> **关键对照：同一慢率下 内生 credit（0.894）> η 常数（0.832）** ⇒ credit 机制确实更强，
> 这是「内生」这条宪法要求第一次被自己的判据验证（而不是靠叙述）。

**抑制自我态的因果证据**：抑制区室 A ⇒ **自指（规则依赖）动作显著退化、世界动作几乎不动**
（0.469 / 0.014）——与论文里 SST 光遗传实验的方向同形。这是本仓最想强调的一条「自我态真的在起作用」。

### 2) 多核心贯通判据 —— **10 臂 10/10 PASS**

不炸 ✅｜六内核全挂 ✅｜自我态有界有限（界幅 **7.36**）✅｜provenance 自源 ✅｜

### 3) 规则表征旁挂（meeting50）—— **8 臂 7 PASS（含一条负结果）**

新目标零样本（M 不动，只改 w）**1.000**（5 seed 均值 0.968）；oracle w 上界 1.000；Q 基线 0.160；
未见起点 1.000；A/B 区室双分离（A 坏 ⇒ 目标误差 1.27；B 坏 ⇒ 路径 0.0）；真接线走继承的第八算子。

> **诚实结论：δ 必需；门控 / 资格迹在即时奖赏任务中没有正证据。**
> 不要把「内生 credit 0.894 > 0.832」外推成「门控普遍更强」；资格迹要等**延迟奖赏臂**再验。

## 诚实边界（不粉饰）

1. **玩具级规模**（任务 D=256 / 贯通 D=1024）；迁移是**机制类比、非等同**；**不主张意识、不主张人类级智能**。
2. **最弱一环未根治**：「从奖赏**内生推断规则**」本轮仍是标量边界跟踪 + 重合门加权信用；
   credit assignment 只在玩具级验证，**不主张解决**。
3. **自模型桥的 ε_self 方向正确但余量不大**（大跳−平稳 ≈ 0.03）。
4. **千层的承重假设被否证**（见上，16/21、总闸门 FAIL）——这是本版最重要的负结果，**不改写**。
5. **规则表征的三因子门控没有正证据**；不要把单一对照读数外推成普遍结论。
6. **本仓不是「可搬到任意机器就跑」的成品**：贯通链依赖上游旧目录与当年路径（见上表）；
   音频/权重/数据均不入仓，涉及语音的会议（meeting58–71）只保留代码与读数 json，**音频不可复现**。
7. **上游一处语法笔误原样保留**：`meeting58/团队/红队/探针_R1_解耦_隐性耦合.py`（关键字参数名含 `/`）
   本身不能解析——这是上游原件状态，为保 C14/归档完整性**不予修改**，不影响主程序与四项判据。
8. **脱敏说明**：角色名 / 人名 / 本机绝对路径 / token 形态串已中性化（角色名统一为 `EmoCompanion` /
   `RoleB` / `SpeakerA` / `ViewerA` 等代号）；**没有任何数值、阈值、判据结论被修改**。
