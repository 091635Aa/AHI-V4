## 一、论文给出的可迁移内核（五专家一致）

| 生物学事实 | 抽象成计算原语 |
|---|---|
| 顶端树突接收**情境/自上而下**输入，**编码推断出的抽象规则** | 区室 A（**顶树/规则态**）：慢速、跨试次存活的**隐变量**，由**自身奖赏统计**推断 |
| 胞体接收**感觉**输入 | 区室 B（**胞体/感觉态**）：快速、即时的当前观测 |
| 两区室在**同一神经元内非线性整合** | **整合算子 φ(A,B)**：非简单加权求和（符合检测/乘法门） |
| 选择信号**两区室都有**，单独任一区室给不出 | 输出 = φ(A,B)，**缺一即失效** |
| **光遗传抑制树突 ⇒ 规则依赖选择编码受损**（依赖规则的试次最重、刺激无关几乎不动） | **可检验预言**：抑制/冻结区室 A ⇒ 规则依赖试次显著退化、刺激无关几乎不变（**消融臂**） |
| 区室各有**局部计算特性** | **区室特异可塑**：A、B 各有独立学习规则/时间常数 |
| 「点状神经元」模型不够用 | **对"点神经元"基线的超越**：同参数下两区室版在规则切换/迁移上更强 |

论文原话：这种**神经元内计算「扩充了皮层网络可用算力」，并「可能启发更高效的人工系统」**——这正是我方架构优化的着力点。

## 二、我方现状瓶颈（引擎架构师实读代码，逐条定位）

| # | 瓶颈 | 精确位置 | 与论文冲突 |
|---|---|---|---|
| B1 | **单状态点式递推**：前向只带一个 D 向量 `s` | [`算子_能力核.py`](../../meeting41/实施/算子_能力核.py) `前向`（`s=_取上下文` / `s=self.迭代(s,c,步数)`） | 论文是**两区室**（规则 vs 感觉）；我方规则与感觉被压进同一向量 |
| B2 | **上下文一次性外给、不随试次存活** | 同上 `_取上下文` | 论文规则是**逐试次内生推断、持续存活**的隐变量 |
| B3 | **整合是线性/门控混合**：`门控=0.5+0.5·软限(...)`；`门` 是凸组合；输出 `0.5·s+0.5·c` | 同上 `前向` 内、`门` | 论文要求"任一单独区室都给不出"的符合/双线性语义 |
| B4 | **学习只动单个 W、无区室特异可塑** | `更新(名,ΔW)` | 论文两区室各有局部计算特性与可塑时间常数 |
| B6 | **总装层「规则→选择」无通路**：知觉码经 `sign(投影@码)` 降成 64 脉冲喂神经 | [`中枢.py`](../../meeting44/实施/中枢.py) `_感官` | 论文选择信号产生于"规则⊗感觉"整合；我方两路**并联、不相乘** |

一句话：**能力核是「单状态点式递推 + 线性门控混合 + 单表单速率学习」；论文要的是「双状态 + 非线性整合 + 分区可塑」。**

## 三、核心裁决

### 裁决 1：**在 V3 上纯新增扩展，不新开 V4**（五专家一致）

**理由**：
1. **论文迁的是"计算单元的形态"（点 → 区室），不是推翻我方的三条腿**（码本索引读出 / 逐元素门控 / 定点迭代）。我方 `门`、`绑/叠`、以及 `前向` 的**未定义令牌**机制（码本外仍给稳定值并如实上报）**已是两区室整合的骨架**，只缺"**第二路规则态** + **非线性整合** + **分区可塑**"。
2. **C14 不破既有**：以**旁挂新增件**实现（只读 `import` 能力核），既有七原语、W 表、`参数基线`、`计费` 口径**一字不改**；新件默认关 ⇒ 一键回滚、老判据全绿。
3. **C1 / 线性时间守恒**：两区室整合全为**逐元素** ⊙/门，**零成对加权**；`计费(4096)/计费(1024)` 仍 ≈ **4.0**，不引入 n²。
4. **升级 V4 的触发条件（登记为结构事件）**：仅当判据 **A2** 证明现有 `门/叠` **无法表达**所需非线性整合时，才升 V4 全量重写——代价是 W码基线全失效、138 判据须重验，**非必要不做**。

### 裁决 2：**融合方案 = 「两区室能力核」**（他们研究 × 我们研究）

- **他们的**：顶树/胞体**分区** + **非线性整合** + **区室特异可塑**（论文）。
- **我们的**：七原语（绑/解绑/门/叠/归/读/迭代）、定点可复现（`_归`/2^-20 格）、**未定义令牌**（任意训练/泛化雏形）、**DA = 奖赏预测误差**（`中枢` 已有）。
- **融合**：新增第八算子「**符合门 `符`**」= **逐元素乘积**（双线性符合检测，**A 或 B 为 0 即无输出**），把 `前向` 的 `0.5·s+0.5·c` 换成 `φ(A,B)=符(A,B)`；并给单元开**第二递推态 A（规则态，慢）**，与既有 `s`（感觉态 B，快）**分区**；**A 只由奖赏反馈按慢时间常数更新**（`学规则(反馈,Δ)`），**B 保留既有 `更新(名,ΔW)`** ⇒ 分区可塑。

## 五、判据编排（系统工程专家，阈值**先冻结**）

**任务**（论文范式抽象）：音调 `x_t∈(0,1)`；隐藏规则 = 分类边界 `b_t∈{0.35,0.65}`，每 20–60 试次**无预警**突变；选择 ∈ {低, 高}；奖赏 correct→+1 否则 0。
**试次划分**：**A 规则依赖** = `x_t∈(0.35,0.65)`（只有应用当前规则才能做对）；**B 刺激无关** = `x_t∉[0.35,0.65]`。

| 臂 | 测什么 | 判过条件 |
|---|---|---|
| A1 区室分工 | 从 A 态解码**规则**、从 B 态解码**刺激**；交叉解码低 | 两侧各自可解码 **且** 分离 |
| A2 非线性整合 | 规则依赖试次上 `φ(A,B)` 正确率 | **> 单独 A 或单独 B**，且 >同参数量**线性求和**基线 |
| **A3 消融（必须退化）** | 冻结/抑制区室 A | 规则依赖正确率降幅**大** **且** 刺激无关降幅**小**；**两者必须显著不同** |
| **A4 迁移（宪法强制）** | 训练边界 `{0.35,0.65}` → 测**未教**边界 `{0.25,0.75}` | 正确率 ≥ 阈；切换后恢复试次数 R ≤ 阈 |
| A5 点式基线 | 同参数量**单点**模型 | 两区室在规则依赖/迁移上**显著更强** |
| A6 线性时间 | `计费(4096)/计费(1024)` | ∈ [3.95, 4.05] |
| A7 C1/依赖审计 | 禁词自扫 + import 白名单 | 命中 0 且 白名单内 |
| A8 确定性两趟 | `PYTHONHASHSEED∈{0,1,42}` 三进程 W码 | 逐位同 |

**必须失败的反例臂**（防假通过）：① 二次 n² 计费臂；② "无区室版"（打乱规则通道）在规则依赖试次上必须不过阈；③ 区室 A sham（随机通道冒充）；④ 仅胞体臂不报规则；⑤ 数据泄漏哨兵（未见规则若也 100% ⇒ 判不过）。

**"有提升"的定义**：`Δ点式 = Acc_A(两区室) − Acc_A(点式) ≥ 0.10` 且 `Δ消融 = Acc_A(两区室) − Acc_A(消融) ≥ 0.15` 且 B 臂在消融下几乎不动。**只有同时满足，才按此思路走；否则记"未测/无提升"**。

## 六、诚实边界（五专家共同声明）

1. 论文的**非线性整合数学形式未公开**；我们取最小乘积门是**工程近似**，**≠ 生物事实**；只在两区室，论文实为多层树突，属**降维**。
2. **最弱一环 = "从奖赏反馈内生推断规则"**（credit assignment）：两区室形态能加，但"规则**学得对**"仍缺——这是比"两区室"更深的坎，本轮**不声称解决**。
3. C10：不能借外部 RL/预训练替我们推断规则；**判据必须有迁移臂**。
4. 迁移是**机制类比、非等同**；测的是**内生迁移与区室分工的计算效果**，**不主张意识/人类级智能**。
5. **不作"已完成"的宣称**：阈值先冻结、实测落盘、空着＝未测；**未跑前所有数字都是设计值**。

### 结论：**"有提升"，且提升是"强"的（在冻结阈值下成立）**

- **机制方向被实测支持**：两区室在**规则依赖试次**上显著 > 点神经元基线（**Δ点式 0.29**）、显著 > 冻结顶树（**Δ消融 0.39**）；**抑制顶树只重创规则依赖试次（Acc_A 0.81→0.42），刺激无关试次几乎不动（Δ0.017）** —— 与论文的 SST 光遗传结论**逐条同形**。

- **反例臂全部失败**（随机规则/无区室/线性求和均 ≤0.60）⇒ 不是假通过。

### 诚实边界（不粉饰）

1. **本轮落地的是"最小解析参照单元"**（D=256），**只读复用**了我方 `算子_能力核.软限/_归/定点/禁词列` 等**原语与可复现口径**；**尚未**把它 graft 进 `能力核` 的 `绑/读/迭代` 主循环（那是下一步的"真接线"）。
2. **测试期对所有臂一律冻结读出、只在线适应规则通道**（口径一致，已写进 JSON 说明）—— 这是隔离"规则通道"贡献的判据设计，非结果调参。
3. **最弱一环仍是"内生规则推断"**：本轮的规则态=标量边界跟踪，**不是学出来的表征**；比"两区室"更深的坎（credit assignment）**本轮未解决**。
4. 规模玩具级；**不主张意识/人类级智能**；迁移是**机制类比、非等同**。
5. 判据阈值先冻结、ηb 由**预先声明的扫描**选定；**未作任何"已完成"的宣称**——只报实测。
