# 04 · 认知灵活性 / 迁移泛化专家

> 依据：《初心_宪法.md》（"太傻"=教过的会、没教的不会=不合格；**判据必须含迁移臂**）＋ 论文 adz5323 §0/§2/§5/§6。
> 我的职责：**设计判据、定义"提升"**。纯 numpy/hashlib/CPU；确定性；C1 禁注意力；C14 纯新增优先。

## 1. 我的判断

论文的"顶树=抽象规则、胞体=感觉、同一细胞内**非线性和**"给出了一条**可判有罪的迁移路径**：把 V3 的"单状态点式递推"升级为**规则态 × 感觉态的两区室节点**，就能把"查表（教过的会）"换成"从奖赏反馈**内生推断规则**"。**"提升"的定义权在我这里**：只有"未教边界/规则在规则依赖试次上也能做对、且**切换后快速恢复**"才算提升，否则一律不算。

## 2. 任务与判据设计（规则切换灵活分类 · numpy 版）

**任务五要素**（对应论文范式逐项抽象）：

| 论文 | 本任务 |
|---|---|
| 音调刺激 | 观测 `x_t = 音高 ∈ [0,1]`，`default_rng(显式种子)` 生成；感觉令牌 `归(P @ x_t)` |
| 分类边界（两候选，无预警变） | 隐藏规则 `b_t ∈ {0.35, 0.65}`；每 `20~60` 试次（种子固定）随机突变 |
| 左/右选择 | 选择 `y ∈ {低, 高}`，判据 = `x_t` 相对 `b_t` |
| 奖赏反馈 | correct→`+1`，否则 `0`；逐试次级，供规则推断 |
| 试次 | 单序列 `~400` 试次 |

**试次划分（论文对照的关键）**：
- **A 规则依赖**：`x_t ∈ (0.35, 0.65)`（落在两候选边界之间，**只有应用当前规则才能做对**）——对应"正确选择取决于规则的试次"。
- **B 刺激无关**：`x_t ∉ [0.35, 0.65]`（无论哪条规则都判得对）——对应"刺激无关试次"。

**六臂（同参数、同种子、同序列）**：

| 臂 | 定义 | 论文对应 |
|---|---|---|
| 主臂（两区室） | 规则态(A) ⊗ 感觉态(B) → `门`非线性整合 | 完整 L5-ET 神经元 |
| 消融臂 | 切"顶树/规则通道" ⇒ 只留感觉 | 光遗传 SST 抑制树突 |
| 点神经元基线 | 同参数**单点版**（无第二区室） | "点状神经元"模型 |
| 迁移臂 | 训练边界 `{0.35,0.65}`，测**未教**边界 `{0.25,0.75}`；并测切换后恢复 | 泛化/迁移（宪法强制） |
| sham/反例臂 | 规则随机、上下文置零 | 必须判不过 |

## 3. "提升"的可测标准（阈值**先冻结**，不得看留出集定；双集 seed 0–5 / 6–11）

| 指标 | 主臂(两区室) | 消融臂 | 点式基线 | sham |
|---|---|---|---|---|
| Acc_A 规则依赖正确率 | **≥ 0.80** | **≤ 0.62 且 ≤ 主臂−0.15** | **≤ 主臂−0.10** | **≤ 0.55** |
| Acc_B 刺激无关正确率 | **≥ 0.95** | 与主臂差 **≤ 0.05**（几乎不变） | ≥ 0.95 | ≥ 0.95 |
| R 切换后恢复试次数 | **≤ 6** | ≥ 20 / 不恢复 | ≥ 12 | ∞（永不恢复） |
| Acc_trans 未教边界命中 | **≥ 0.75** | — | ≤ 0.60 | ≤ 0.55 |

**"提升"= 两个差**：`Δ点式 = Acc_A(两区室) − Acc_A(点式) ≥ 0.10`；`Δ消融 = Acc_A(两区室) − Acc_A(消融) ≥ 0.15`，且 **B 臂在消融下几乎不动**（这才是"SST 只损规则依赖"的复刻）。**判过规则：主臂全过 ∧ 消融/sham 必须失败 ∧ 迁移臂 R≤6 且 Acc_trans≥0.75**；任一恒真或恒假即无效。规则推断用**相对边界的比较型隐状态**（非绝对查表），迁移臂才可能过。

## 4. 对我方架构的落点：**V3 扩展优先（不新开 V4）**

理由：既有 `门`（`g⊙x+(1−g)⊙y`）、`绑/叠`、以及 `前向` 的**未定义令牌**机制（码本外仍由 `绑(解,s)+键+读出` 给出稳定值、并上报）**已是两区室整合的骨架**，只缺"规则态"这一路状态＋反哺：

```
区室A(顶树/规则态)  ← 造知觉隐状态 + 工作记忆 + 神经调质DA(奖赏预测误差) 逐试次更新
区室B(胞体/感觉)    ← 当前观测令牌 归(P @ x_t)
整合               ← 门(g, 区室A, 区室B)   # 非线性符合检测，任一路给不出
选择               ← 读出(整合) → 做
记忆               ← 绑(选择后果 ⊗ 规则态) 存束，供下一试次推断
```

**认知灵活性如何内生**：规则态是**它自己的隐变量**，由**它自己的奖赏统计（DA=奖赏预测误差）**逐试次长出——不是程序员写的 `rule→action` 表；未教边界靠"相对比较型隐状态＋未定义令牌"仍可用。落盘纪律：**默认关开关、纯新增、逐位恒等回退**（C14）。

## 5. 诚实边界

1. 这是"规则推断"的**机理复刻**，不是意识证明；规模玩具级（D=1024、低维隐状态）。
2. 上表阈值为**设计判据（先定、冻结）**，非实测结果；**未跑前不作"已通过"宣称**（宪法第八条）。
3. 已知失败点：若规则态被感觉令牌主导 ⇒ 退化成点式（消融臂判不过＝真缺陷）；若迁移靠记忆查表 ⇒ sham/迁移臂必须**判不过**。
4. 仍缺"学出来的表征"：规则态是低维隐状态，不是训练表征——本方案**不因此改称"表征学习"**。
