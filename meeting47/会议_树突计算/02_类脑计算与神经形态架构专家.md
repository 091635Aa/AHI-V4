# 类脑计算 / 神经形态架构专家 · 独立方案

> 议题：Science 2026 树突计算（DOI 10.1126/science.adz5323）能否迁移进 AHI V3。
> 本方案只管**工程实现形态**：给「区室化计算单元」一个可跑、线性、确定性的写法，不复述论文。

## 1. 我的判断

论文的可迁移内核**不是某个生物学细节，而是一条算力账**：把「一个状态位」拆成「两个各自有局部非线性、再被非线性整合的区室」，**每神经元可用算力倍增**。我方 V3 的 `0.5·s+0.5·c` 是**对称线性平均**，恰好丢掉了这条增益——这是最值得补的一处，且能纯新增、不破坏既有的七原语与定点账。

## 2. 区室化单元的设计（两区室：顶树 A + 胞体 B）

核心是**符合检测式非线性整合**：逐元素相乘（＝现有 `绑` 的同形内核），再经软阈值（树突棘波式门）与饱和（NMDA 式），**全程逐元素、无任何两两加权**。

```
每令牌一拍（进出都是 (D,)，D=1024）:
  b ← 门(g_b, 感觉令牌 p, b)                 # 胞体：即时观测，走快时间常数
  a ← 迭代(a, 读(码本, 上下文线索).读出, 步A)  # 顶树：内生推断的规则，慢常数（步A≥1）
  枝 = 软限(W枝 ⊙ (a ⊙ b))                   # 符合检测：a⊙b 逐元素积（=绑的内核）
  棘 = 软限_棘(β·(枝 − θ))                   # 棘波式软阈值门 ∈(−1,1)，免 sign 跳变
  合 = 软限(W合 ⊙ (棘 ⊙ b) + W加 ⊙ (a ⊙ b))  # ★ 非线性整合（乘法项 + 加性项并存）
  输出 = 归(0.5·合 + 0.5·b)                   # 规则依赖的选择信号
```

**相对 `0.5·s+0.5·c` 的增益来源**：线性平均下，同一刺激改规则只能靠 s 单侧出力；`合` 中 `a⊙b` 是**双线性**项——输出依赖「规则∧刺激」的**联合模式**，任一单独区室给不出（复刻论文「任一单独区室都产生不了选择信号」）。故同一感觉输入在不同推断规则下可给出**定性不同**的选择，这正是泛化/组合能力的来源。

**额外开销（解析乘加账）**：新增 ≈ 顶树迭代 `10D·步A` + 符合检测/棘/合 ≈ `18D`。每令牌由 `4MD+20D+10D·步` 变为 `4MD+38D+10D·(步+步A)`。M=64、D=1024 时 `4MD=262144` 占绝对主导，**增幅约 6%**；计费仍为 `n·每令牌+固定`，**O(n) 严格线性不变**（比值仍 4.0000；仅固定项/步数计费口径随之更新，非二次）。

## 3. 与 `能力核` 七原语 / `神经.py` LIF 的对接

| 复用（改动=0） | 说明 |
|---|---|
| 绑 | `a⊙b` 逐元素积＝符合检测内核，**直接复用**，不改语义 |
| 门 / 叠 | 胞体融合、两区室相加、输出合成 |
| 迭代 | 顶树慢常数定点推进（`步A` 当「推断深度」），收缩性保证不发散 |
| 读 / 归 | 规则线索按码本索引读出；全流程走 2^-20 定点格，逐位可复现 |

| 必须新增（纯新增，C14） | 说明 |
|---|---|
| `合`（一个步进） | 双线性整合 `软限(W合⊙(棘⊙b)+W加⊙(a⊙b))`；仅登记两个 W，不新数值内核 |
| `棘`（软阈值） | 由 `软限` 变形导出，**无 sign 跳变、无超越函数**，仍是逐元素恰定 |

与 `神经.py` 对接：把 `LIF群` 的**单膜电位**扩为**双膜电位**——`电位_胞体`（喂感觉）、`电位_顶树`（喂调质/规则上下文），发放前用 `合` 合并；STDP 保持在线、调质仍广播。**单点是"每神经元一膜电位"，区室是"每神经元两膜电位"**，N 不变、账不变。默认 `区室开=False` 保证可回滚。

## 4. 可检验预言 / 反例臂（≥3）

1. **sham 臂（必须不过）**：同参数量下把 N 个**点状** LIF 堆叠（总参数与区室版相等），在「规则无预警切换」任务上，规则依赖正确率**不得显著优于**固定边界基线。
2. **对照臂（关键机制）**：同一参数、同一任务，**区室版 vs 点式版**对照；另设**「整合退化为纯加性 0.5a+0.5b」**臂，若它成绩塌回点式水平，即证明增益来自**非线性整合本身**而非参数量。
3. **消融臂（复刻光遗传）**：将顶树 `a` 增益置零/截断，则**「正确选择依赖规则」的试次**正确率大跌，**刺激无关试次几乎不变**。
4. **开销臂（必须仍线性）**：`计费(4096)/计费(1024)=4.0000`；二次反例臂（`D·n²`）必须不过。
5. **确定性臂**：同种子两实例喂同序列，输出逐位同（C13）。

## 5. V3 扩展 vs 全新 V4

**建议：在 V3 上做纯新增扩展（`区室开` flag），不另起 V4。** 理由：① 七原语、定点账、判据套件（PASS 基线）全可复用，风险与成本最低（C14）；② 增益机制是**在既有 `前向` 内加一个 `合` 步**，不触碰签名的前提下属可达改动。**触发另起 V4 的唯一条件**：若自证显示必须改 `前向` 契约或既有判据，则整枝为新 V4，否则即为过度工程。

## 6. 诚实边界

- 纯 numpy / hashlib / CPU；随机只来自 `default_rng(显式种子)`；**禁注意力/Transformer**（`合` 是逐元素双线性，无两两加权，`禁词自检` 必须仍为 0 命中）。
- 不引 GPU、不引深度学习框架、不"训练一个网络"，不新增外挂模型当器官（C10）。
- `棘` 是**软阈值近似**树突棘波，非真实离子动力学；本方案只宣称**机理级可测增益**，不宣称"主观体验"或"意识"。
- 若对照/消融臂证不出「区室版显著优于点式且靠非线性」，则诚实判为**未迁移成功**，不粉饰。
