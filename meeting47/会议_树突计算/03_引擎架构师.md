# 03 · 引擎架构师 —— 树突两区室计算迁移评审

> 依据：`meeting41/实施/算子_能力核.py`、`meeting44/实施/{中枢,神经,引擎_能力核,知觉,工作记忆,自我}.py`、`meeting44/交付_AHI自我意识体.md`（均已实读）。
> 铁律：C1 禁注意力/Transformer（论文也无法作依据）｜C9 禁 OCR｜C10 禁外挂模型｜C13 确定性｜C14 纯新增、改前备份。

## 1. 我的判断

**走 V3 扩展（旁挂加件），不走全新 V4。** 论文迁移的是**计算单元的「形态」**——同一单元内两区室分工 + 非线性整合；而不是推翻我方的三条腿（码本索引读出 / 逐元素门控 / 定点迭代）。能力核的「三件套」恰好已给了「感觉区室 B」所需的一切，我们只需在它**旁边**再开「规则区室 A（第二递推态）」与「符合门（第八算子）」。核心参数、判据、单点路径全部原样保留 ⇒ 可随时回滚，C14 无损。

## 2. 现状瓶颈清单（逐条附位置）

| # | 瓶颈 | 精确位置 | 与论文的冲突 |
|---|---|---|---|
| B1 | **单状态点式递推**：整个前向只带一个 D 向量 `s` | `算子_能力核.py` `前向` L278 `s=_取上下文(...)`、L300 `s=self.迭代(s,c,步数)` | 论文是**两个区室**（规则 vs 感觉），我方只有一个"点态"，规则与感觉被压缩进同一向量，无法分离 |
| B2 | **上下文一次性外给、不随令牌存活**：`_取上下文`（L326–346）只在循环外调一次；`s` 只被迭代覆盖 | 同上 L278 / L300 | 论文规则是**逐试次内生推断、持续存活**的隐变量；我方没有"持续规则态" |

**一句话瓶颈**：能力核是**单状态点式递推 + 线性门控混合 + 单表单速率学习**；论文要的是**双状态 + 非线性整合 + 分区可塑**——三者我方都缺。

## 3. 最小嫁接方案（纯新增件）

**新增文件 `meeting47/实施/算子_区室.py`**（只读 `import` `算子_能力核` 的 `能力核`、`软限`、`_归`，不改其一行）。要点：不动 `前向`，而是**在循环里带两个态**（规则态 `r`、感觉态 `s`），并新增第八算子「**符合门 `符`**」= 逐元素乘积（**双线性符合检测，非线性、任一区室为 0 即无输出**）。落点三处：

1. **第二递推态**：`区室核` 自持 `规则态 r`（D 向量）+ 慢常数 `μ_规`，由**奖赏反馈**按慢时间常数更新 —— 对应 `能力核.py` L278/L300 那条被**复制**成搬进新件的双态版循环（原循环不碰）。
2. **非线性整合**：新增 `符`（`符合 = r ⊙ p`），再 `驱 = 归(W符 ⊙ 符合 + p)`（保留 +p 保底不全零，满足 E3），最后 `s = 核.迭代(归(r+p), 驱, 步数)` —— 这**替换** L298–301 的线性混合，且是**新算子**，不进 `接口契约` 的七原语。
3. **分区可塑**：新增 `学规则(反馈, Δ)` 只动区室 A 的 `规则W`（慢），保留既有 `更新(名,ΔW)` 给区室 B（快）—— `引擎_能力核.py` L150/L129 不动。

```
class 区室核:                        # 新增件；复用 能力核 的 绑/叠/读/迭代/归
    def __init__(种子): self.核=能力核(D=1024,种子=种子)
        self.规则W=归(双极(种子,"规则"))   # 区室A 的可训练规则读出（慢）
        self.规则态=归(zeros(D)); self.符W=归(ones(D))
    def 推断规则(反馈):                 # 区室A：跨令牌缓慢存活的规则隐变量
        self.规则态=归((1-μ)·规则态 + μ·软限(规则W ⊙ 反馈)); return 规则态
    def 整合(令牌, r):                  # 区室B(感觉) ⊗ 区室A(规则) 的非线性整合
        p=核.归(令牌); 符合=核.归(r*p)          # ★ 逐元素乘积 = 符合检测（非线性）
        驱=核.归(符W*符合 + p)                  # 保底 +p，防全零/防退化
        return 核.迭代(核.归(r+p), 驱, 步数=1)
    def 前向两区室(令牌列, 反馈列):       # 新循环；不改 能力核.前向
        for i,令牌 in enumerate(令牌列):
            r=推断规则(反馈列[i]); s=整合(令牌,r); 输出[i]=核.归(0.5*s+0.5*符合)
        return dict(输出=归(输出), 规则态=r, 规则史=…)
```

> 注：`0.5·s+0.5·符合` 里的 `符合` 仍是乘积项，故最终仍显式含"规则×感觉"——若把 A 冻结为常量，`符合` 退化，规则依赖随之消失（见 P1/P2）。

## 4. 可检验预言 / 反例臂（≥3，条条能失败）

- **P1 消融臂（光遗传对照）**：在无预警变边界的分类任务上，"**冻结区室 A**（`规则态` 固定为常量）"这一臂，在**正确选择依赖规则的试次**上正确率显著下跌，而在**刺激单独即可判正**的试次上几乎不变。**失败判据**：若两类试次跌幅相近 → 该机制不是"规则依赖"，整条迁移作废。
- **P2 单区室不足**：只给区室 B（`r` 置常量）或只给区室 A（`p` 置常量）时，边界内试次判别度显著低于两区室合体。**失败判据**：若任一单独区室已与合体持平 → "整合"是装饰。
- **P3 非线性 vs 线性反例臂**：把整合换成现状的线性 `0.5·r+0.5·p`（L301 口径），在**规则与感觉冲突**的试次上应显著更差（乘积门能选对、凸组合选错）。**失败判据**：线性臂与乘积臂持平 → 无增益，退回 V3 不加件。
- **P4 迁移臂（必含）**：先在规则集 R1 训练，边界无预警切到未见 R2，两区室版应**更少试次**恢复达标。**失败判据**：无迁移优势 ⇒ 规则表征不可迁移。
- **P5 守恒臂**：`计费(4096)/计费(1024)` 仍 ≈ 4.0（新增 `符` 只加 O(D)，不加两两项）；同 `PYTHONHASHSEED` 下 `W码` 逐位一致。**失败判据**：比值偏离或 W码随进程变 → 破 C13/C1。

## 5. 工程风险与迁移成本

- **时间**：符合门是逐元素 O(D)，前向账由 `n·(4MD+20D+10D·步数)` 增为 `n·(…+~4D)`，**仍严格线性**（P5 可验）。不会引入二次项，不碰 C1。
- **确定性**：新件内随机只来自 `default_rng(种子)`；新算子 W 走同一 `_归` 定点格 ⇒ 跨进程可复现，C13 不破。
- **既有判据**：**不必改任何既有判据**——`算子_能力核.自证` 建的独立 `能力核` 不受影响（新算子只登记在新件自持的 W 表/独立变量里）。`枢/沙箱` 也不动。**成本主要在新增自证脚本**（判据须同时含"点版基线臂"和"两区室臂"的对照，否则无法证伪）。
- **接线成本**：`中枢.py` L109–110/L147 需新增一条"规则态 → 策略"的**只读旁路**（回灌 `引擎_能力核` 的 `更新` 目标），这是唯一"接触既有环"的地方，建议单独新增包装件而非改 `中枢`。
- **回归面**：新增件默认关（`区室开=False`）时，全链路字面不变 ⇒ 老判据全绿、可一键回滚。

## 6. 诚实边界

1. **最弱的一环是"从反馈内生推断隐藏规则"**：论文靠计算模型逐试次估计规则，我方能力核**没有监督/信用分配**(credit assignment)，`更新` 只能温和反哺单个 W。两区室形态能加，但"规则**学得对**"仍缺——这是比"两区室"更深的坎，本轮**不声称解决了**。
2. **C10 禁外挂模型**：不能借外部 RL/预训练替我们推断规则，"变得会推断"必须内生（判据须含**迁移臂**）。
3. **复现对象不同构**：我方沙箱是 16×9＝144 格视觉世界，论文是听觉高低分类；对齐的只是**机理形态**，不是生理事实。
4. **不是意识证明**：这是可测、可复现、可失败的**机理级加件**；消融臂只是功能类比，非生物学结论。
5. **`神经.py` 的符合结构（L156）不能直接复用**：维度与空间都对不上，只能作"我方已有双因子先例"的参考，整合算子仍需新增。
