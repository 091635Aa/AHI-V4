## 3. 判据编排 · 总账脚本 `meeting47/实施/判据_树突两区室.py`

沿用既有 `判()` 口径：返回 `dict(全过, 条数, 通过条数, 臂=[...])`，结果落 `判据_树突两区室结果.json`。

| 臂 | 测什么 | 判过条件 |
|---|---|---|
| A1 区室分工 | 从区室A态解码规则、从区室B态解码刺激（线性探针「读」） | A规则解码≥阈 **且** B刺激解码≥阈 **且** 交叉解码低（分离） |
| A2 非线性整合 | 边界内「规则依赖」试次上 f(A,B) 正确率 | >单区室A或B任一 **且** 乘法门 >同参数量**线性求和**基线 |
| A3 消融（**必须退化**） | 抑制区室A | 规则依赖试次降幅≥大阈 **且** 刺激无关试次降幅<小阈；**两者必须显著不同** |
| A4 迁移（宪法强制） | **未教规则**（训练未见边界） | 正确率≥阈 |
| A5 点式基线 | 同参数量单点模型 | 两区室在规则依赖/迁移上**显著更强** |
| A6 线性时间 | 计费比值 | `计费(4096)/计费(1024)=4.0±0.05` |
| A7 C1/依赖审计 | 见 §2 | 命中0 且 白名单 |
| A8 确定性两趟 | 见 §2 C13 | 逐位同 |

**总 PASS ＝ 所有「必须过」臂全过 且 所有「必须失败」臂全失败。** 任一**反例臂反而通过** ⇒ 总体判不过（防假通过）。**必须失败**的反例臂：

1. **二次(n²)计费反例臂**：注意力口径比值≈16，必须 `不<4.5`。
2. **「无区室版」反例**：打乱/移除规则通道后，规则依赖试次必须**不过阈**（否则说明任务太易或基线被调弱）。
3. **区室A sham**：用**不承载规则的随机通道**替换A，必须**看不到规则依赖增益**。
4. **仅胞体臂**：单元测试「B 单独不报规则」必须成立（否则A3 退化无从归因）。
5. **数据泄漏哨兵**：未教规则集若也 100% 正确 ⇒ 判据泄漏，判不过；须留出「从未出现」规则并保留一定基线难度。

## 5. V3 扩展 vs 全新 V4 —— 工程裁决

**推荐 V3 纯新增扩展**，不升 V4。理由：
- 「两区室」＝给**既有递推态 s** 加一条**规则通道**，再用 `门`（逐元素）做**非线性整合**，完全可在七原语上**组合**实现，无需推翻任何原语、不触 W码口径。
- C14 纯新增优先：新件 `算子_双区室.py` **旁挂/组合**能力核（不改其源码），既有件哈希不变、138 判据不回退。
- **回滚点**：备份 `meeting47/备份_树突迁移前/`；删除新文件即回滚；git 分支 `meeting32_声带与十倍维`。
- **升级触发条件（登记为结构事件）**：若 A2 证明现有 `门/叠` **无法**表达所需非线性整合，才升 V4 全量重写 —— 代价是 W码基线全失效、138 判据须重验，故非必要不做。

## 6. 风险清单

1. **判据自造假阳性**：阈值调低 / 臂间共享泄漏数据 ⇒ 预注册阈值 + 独立留出集 + sham 臂。
2. **消融臂实现不当**：只置零A 而 B 仍含规则信息 ⇒ 退化不显著、误判；须先用解码探针证「B 不含规则」。
3. **把点式基线调弱以显得两区室更好** ⇒ 强制**同参数量/同预算/同种子**，且基线须先自证能完成刺激无关任务。
4. **迁移臂数据泄漏**：未见规则被间接教到 ⇒ 严格留出集 + 泄漏哨兵臂。
5. **借「融合」之名引外挂/注意力** ⇒ 依赖白名单 + 禁词自扫 + n² 结构检查三重堵。
6. **确定性被破坏**：引入墙钟/系统时间/浮点非结合求和 ⇒ 定点 2^-20 格 + int64 精确累加 + 禁 `time/random`。
7. **把生物学叙事当实现**：拿「光遗传抑制」当结论而不做对照 ⇒ 必须实现 sham 对照臂，缺对照不算。
