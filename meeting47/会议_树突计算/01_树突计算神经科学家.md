# 01 · 树突/区室计算神经科学专家方案

## 1. 我的判断
**可迁移，且天然内生**——论文机制本质是"点神经元 → 区室神经元"的**局部替换**，落在引擎一处即可。故应在 **V3 `能力核` 上新增"两区室单元"**，**不开全新 V4**（改全身违反 C14 与线性时间约束）。核心两处替换：`0.5·s+0.5·c`（线性）⇒ **区室非线性整合 φ(a,b)**；`门`（二元门控）⇒ **顶树调制胞体的区室门**。

## 2. 机制形式化
把论文五件事转成纯逐元素原语（禁注意力、禁成对加权）：

| 生物学 | 计算原语（纯逐元素） |
|---|---|
| 顶树＝内生推断的抽象规则 | 慢速递归区室 a：`a_t = 归(W顶 ⊙ a_{t-1} + U ⊙ r_t)`，r＝上下文/预测/自我/调质 |
| 胞体＝即时感觉输入 | 快速区室 b：`b_t = 归(W感 ⊙ x_t)` |
| 同细胞内非线性整合、任一单独都给不出 | 输出 `o_t = φ(a_t, b_t)`，**非**线性加权 |
| 选择信号＝整合产物、两区室都有 | o 才是动作读出源；仅喂 a 或仅喂 b 给读出，均不足以产出正确 o |
| SST 抑制远端树突 | 顶树增益 α∈[0,1]，抑制＝α↓，消融＝α=0；受 DA/ACh 内源调制 |
| 区室各有局部计算特性 | a、b 各自独立 `更新`（不同学习率/时间常数/ΔW） |

φ 的最小纯逐元素实现（无任何成对加权）：
```
符合检测/乘法门: φ(a,b) = 归(a ⊙ b)          # 双极下即 绑（自逆⊙），最贴"非线性、单区室给不出"
区室门(升级 门): g = 0.5+0.5·软限(λ·a); φ = 归(g⊙b + (1−g)⊙a)   # 规则 a 内生开关感觉 b 通道
三阶耦合:        φ(a,b) = 归(绑(a,b) + κ·(a − b))                # 兼得"符合"与"失配"两种模式
```

**为什么"点神经元"不足、在哪一步必须换**：点版只有 `0.5·s+0.5·c`（线性组合）＋`门`（门控即外生输入）。线性组合**无法表达"规则×感觉"的乘积交互** ⇒ 同一刺激在不同规则下映射到不同动作（边界无预警切换，XOR 型）**线性不可分**，点状态必然退化。故须在**输出步**把 `0.5·s+0.5·c` 换成 φ(a,b)；在**门控步**把 `门` 由"外生 g"改为"a 内生生成 g"（区室门）。这两处换掉后，规则切换才可能内生可解。

## 3. 可检验预言 / 反例臂（每条必须能失败）
| 臂 | 判据（必须可失败） |
|---|---|
| **消融顶树** | 置 α=0：**规则切换任务退化**（"正确选择依赖规则"的试次受损最重），**刺激无关/固定规则任务几乎不受影响**；两类试次分开设阈 |
| **点神经元基线对照** | 同 D/参数量/训练预算：两区室版在规则切换＋迁移得分**严格 >** 点版；点版须落在"不过"侧 |
| **迁移臂（C1 要求）** | **未教规则**（新边界、未见边界组合）也能完成；点版在迁移上崩 |
| **区室特异可塑** | 仅注入顶树 ΔW 才能解释"规则依赖得分"提升；仅注入胞体 ΔW 不涨分（错区室＝控制臂） |
| **非线性必要性（反例）** | φ 换回线性加权 ⇒ 规则依赖选择编码显著退化（该臂必须不过） |

## 4. 对我方架构的具体落点
在 V3 `算子_能力核.能力核` **上扩展**（新增子类/新文件 `单元_两区室.py`），**不做全新 V4**。理由：
- **C14**：仅新增算子名（`W顶`／`W感`／`α`）；既有七原语、W 表、`参数基线`、`计费`口径**一字不改**。原 `前向` 语义不变，新增 `前向_两区室(区室开=True)`，默认可关 ⇒ 回滚点。
- **C1／线性时间**：φ 全为逐元素 ⊙/门 ⇒ 零成对加权；计费增量 `+O(D·步数)`，**与令牌数 n 无关**，不引入 n²。
- **为何不 V4**：这是"单细胞内"的局部改造，仅落在"点→区室"一处；推翻既有器官环（眼/造知觉/时间/神经/自我/想/做）风险大且违反 C14。
- **渐进路线**：先做能力核两区室扩展 → 跑 §3 全臂 → 若"提升强大"（迁移臂显著且消融对照干净），再以两区室为核心**重排为 V4**。点状态必须换代：自我意识体要**内生**学抽象规则，线性点读出承载不了"规则×感觉"——两区室带来的"细胞级算力扩充"正是论文所指着力点。

## 5. 诚实边界
- 论文"非线性整合"的具体数学形式**未公开**；我取最小乘法门是**工程近似**，不等于生物事实。
- SST 中间神经元的**动态**无法复刻，只映射为静态增益 α；真实抑制是时变过程。
- 论文实为**多层树突（远端/近端多支）**，我只用两区室，是**降维简化**。
- 慢顶树 / 快胞体的**时间常数**无论文依据，需经验设定，存在过拟合风险。
- 全局：**仍不声称主观体验**；"更强"仅指确定性判据（迁移臂）意义；所有随机仅 `default_rng` 显式种子（C13）。
