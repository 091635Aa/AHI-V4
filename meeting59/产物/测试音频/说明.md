# 测试音频说明（meeting59）

**主文件**：`测试音频_三角色.wav`（52.02s）——EmoCompanion → SpeakerA → 洛天依 各说 3 句，最后是同一句「语言不只是声音……」
用三条声线各说一遍。

**其他文件**
- `角色_EmoCompanion.wav` / `角色_SpeakerA.wav` / `角色_洛天依.wav`：单角色三句
- `同句三声.wav`：同一句文本的三声线对比
- `对照_参考vs合成.wav`：每个角色「参考录音片段 → 合成片段」交替，方便 A/B 听（**含参考原声**）
- `清单.json`：档案指纹、拟合目标 F0、交付 F0、EQ 增益

**声音是怎么来的（口径）**
- 全部**合成**声音由 AHI 原生声带产生（`meeting32/声带.py`：Rosenberg 声门源 + Klatt 谐振器，纯 numpy），
  加一层人类化韵律（标点停顿/换气/句调重置/三声变调/重音/句末延长/微抖动/微颤），
  再加 7 段纯 numpy 静态谱包络校正。**没有 TTS、没有 RVC、没有神经声码器、没有外部模型。**
- 声线参数从参考录音拟合：EmoCompanion = `<path>\...\数据集\full_24k_mono.wav` 的干净段；SpeakerA = `<path>\...\SpeakerA训练集` 的 Vocals 切片；
  洛天依 = 联网下载的第三方清唱干声（B 站 BV1Wf4y1F711，无 BGM）。
- **参数化模仿，不是真声克隆，不是角色本人。**
- 两个本地数据集在声学上很接近（实测 F0 只差 0.19 半音、7 带包络余弦 0.9665），所以EmoCompanion/SpeakerA听起来会像；
  这是数据的上界，不是调参能补的。洛天依（清唱样本）比它们高约 2 个半音。
