## 2. 「有没有 BGM / 混响 / 是说话还是歌声」——判定依据

### 2.1 BGM 判定（三重检验）

| 检验 | 含义 | L-A | L-B | L-C |
|---|---|---|---|---|
| 停顿段（能量最低 8% 帧）RMS | 纯人声录音停顿应接近数字静音 | **−55.8 dBFS** | −92.8 dBFS | **−240.0 dBFS**（恒 0） |
| 停顿 vs 活动 带内能量比 | 差越大越干净 | **−20.8 dB** | −70.6 dB | −178 dB |
| 60–200 Hz 窄带稳态峰 | 伴奏贝斯/嗡声的指纹 | **峰/均 ≈ 171×，峰位中位 110 Hz（p10–p90 90–160 Hz，随时间变化→旋律性低频）** | 峰/均 105× 但带内 RMS −74.5 dBFS（量化底噪，可忽略） | 105× / −88.5 dBFS（可忽略） |
| 立体声侧信号（仅 L-A 有原始立体声流） | 停顿帧 side−mid | **−0.55 dB（停顿底噪左右相同=单声道相关噪声）** | —（单声道源）| — |

**结论**：
- **L-A [实测] 有 BGM/低频伴奏**：句间从未回到数字静音、60–200 Hz 有随时间移动的窄带能量（171× 集中度）。这也是 lead 最初怀疑「带 BGM」的原因，本目录独立复核**成立**。
- **L-B [实测] 无 BGM**：停顿段 −93 dBFS 且与活动段差 70 dB，安静到只剩 16-bit 量化底噪。
- **L-C [实测] 无人声外 BGM**：停顿段是**逐样点恒为 0** 的数字静音（−240 dBFS）。但它是**第三方分离干声**，静音被硬门控过，**人声内部是否残留分离伪影[未测]**（UP 自述「消得可能不是很干净」）。

### 2.2 混响判定

指标：能量急降后 300 ms 内 dB 衰减线性斜率（越大越干）+ log 包络自相关（长滞后仍有正相关 ⇒ 拖尾）。

| | L-A | L-B | L-C |
|---|---|---|---|
| 衰减斜率中位 | **23.3 dB/s**（n=29） | 13.0 dB/s（n=310，p25 −59.7 → 大量硬切） | **40.2 dB/s**（n=50） |
| 包络自相关 @0.05/0.1/0.2/0.3 s | **0.82 / 0.58 / 0.33 / 0.29** | 0.87 / 0.73 / 0.48 / 0.27 | 0.99 / —（持续音高，指标不适用） |

**结论**：L-A **有可测混响/拖尾**（0.2 s 仍有 0.33 相关、衰减慢）；L-B 衰减快、大量硬切 ⇒ 干声为主；L-C 是持续演唱，包络自相关指标失真，**不用于判混响**（[未测] 精确 RT60）。

### 2.3 说话 vs 歌声

方法：把 NSDF(McLeod) F0 跟踪**限带到 280–700 Hz**（避开 L-A 的低频伴奏），看浊音段长度与 F0 平滑度。

| | L-A（限带） | L-B（限带） | L-C（限带） |
|---|---|---|---|
| F0 中位 | 409 Hz | 348 Hz | 372 Hz |
| 帧间 \|ΔF0\| 中位 | 0.14 st / 10 ms | 0.16 st / 10 ms | **0.06 st / 10 ms** |
| 浊音段 中位 / 最长 | 0.10 s / 0.67 s | 0.15 s / 1.35 s | **0.29 s / 3.34 s** |
| 浊音段 > 0.4 s 占比 | 0.03 | 0.10 | **0.39** |

**结论**：
- **L-B [实测] 说话**：短语 burst（中位 0.19 s、最长 1.39 s）+ 句间真静音；F0 中位 346.8 Hz（全带）/348 Hz（限带）。
- **L-C [实测] 歌声**：最长连续浊音 7.26 s、浊音帧 71%、帧间 ΔF0 0.06 st、谱图可见颤音状谐波摆动（见 `核验_干声_谱图.png`）。
- **L-A [推断·中] 说话/轻哄式念白，不是普通歌**：限带后浊音段 0.10 s、ΔF0 0.14 st，**接近 L-B（说话）**、明显不同于 L-C（清唱）；但含 BGM、F0 跟踪受污染，故只标推断。
  - 附带：[实测] 全带 F0 跟踪在该文件上**不可靠**（NSDF 锁到 ~133 Hz 的低频伴奏周期性，p5/中位/p95 = 70/133/527 Hz），别直接用它算 F0 指标。
  - 手工谱峰点查（5 帧 × 250 ms Hann）：t=2.75 s → 376/750/1125/1500/1875/2262 Hz（F0≈375）；t=5.0 s → 562/1125/1675/2238 Hz（F0≈562）⇒ 人声谐波系列 **375–562 Hz**。
- **[未测]** 人耳盲听 / MOS / 主观「像不像人」评价——本目录不做主观判断。

## 3. 处理链（可复跑，全部确定性）

1. **取元数据**：`x/web-interface/view?bvid=` → aid/cid/标题/UP/日期；`x/tag/archive/tags` 取标签（L-A）。
2. **取音频流**：`x/player/wbi/playurl?avid=&cid=&fnval=16`（wbi 签名，UA + `Referer: https://www.bilibili.com`）→ dash audio 取最高码率流；
   下载 `raw_*.m4s`（**不转码、不改内容**，保留原流作 provenance）。
3. **解码**：`ffmpeg -i raw_*.m4s -ac 1 -ar 16000 -c:a pcm_s16le <16k.wav>`（只用 ffmpeg 重采样/单声道，符合简报 §5 切取纪律）。
4. **核验**：`工具_核验分析.py`（NSDF F0 / 帧能量 / 7 带 LTAS / 静音率 / 停顿稳态谱 / 包络衰减）＋ `工具_侧信号与F0.py`（立体声侧信号）＋ `工具_点查.py`（谱峰点查）＋ `工具_放大谱图.py` / `工具_可视化.py`（谱图）。
5. **选段**：`工具_切段.py list` —— 滑窗打分 = 活动帧占比 − 2×静音占比 − 0.02×段内能量标准差 − 50×削波率；滑窗步进 10 ms、非重叠间隔 ≥ 段长+0.5 s。
6. **切段落盘**：`工具_切段.py cut` —— 去直流均值 + **5 ms 淡入淡出** + s16 量化；**不归一化、不降噪、不增强、无 TTS/RVC/任何神经网络**。
7. **登记**：`工具_片段统计.py`（逐段 F0/LTAS/倾斜/浊音率/静音率/sha256）→ `工具_写manifest.py` 生成 `manifest.json`。

**禁用项自查**：本目录脚本只 import `numpy/scipy/matplotlib` + 标准库（`urllib/hashlib/json`），无 `torch/transformers/rwkv/onnxruntime/TTS/pyttsx3`；未使用 RVC / 变声器 / TTS 生成任何音频；切段全部来自真实第三方录音/分离干声。
