## 1. 我们要做的事（一句话）

做一条**最小的「文本→声音」线**，再给它一个**自己的耳+自己调参**的闭环，让它能像人一样**听自己 → 修自己**，并且**情绪/风格由参数控制**而不是写死。

## 2. 决策

| # | 决策 | 理由/边界 |
|---|---|---|
| **D1** | 音频线 = 文本 → 音素 token → **v13（只读 ckpt）** → log-mel → **Griffin-Lim** → wav | 复用项目现有最好声学模型（C1 允许自训练权重）；不新造模型，先有可听闭环 |
| **D2** | 控制层 = **5 个旋钮**：`音高(半音)`、`增益(dB)`、`谱倾斜(dB)`、`每音节帧数(语速)`、`停顿毫秒`；**情绪/风格 = 这 5 个旋钮的预置** | 对应所有者三词：转动频率=音高、特殊振幅=增益、发生概率=语速/停顿；情绪是参数级模仿，不是情绪模型 |
| **D3** | 内生耳 = **自研 DSP 嵌入**（F0 中位/90/10、浊帧占比、能量均值/标准差、包络周期性、语速、谱质心/带宽/滚降/平坦度、8 带 log-mel 均值/标准差） | **不用外部模型当耳**（C10）；可解释、确定性；外部 ASR 只作离线仪器，本会议未用 |

## 3. 与 meeting67 的衔接

- meeting67 的 G0/器官线已判死（`09`）；V 点/扩容实验结论「训练预算不足」（`12`/`16`）；
- 本会议**不重跑训练**，先在「已有 v13」上把**闭环**跑通：音频线 → 耳 → 自优化 → 可控情绪/风格；
- 若闭环成立，下一步再考虑「自听学习反哺声学模型/控制头」（需新预注册）。

## 4. 未决 / 边界

1. 自听学习目前只优化**后置 5 旋钮**，不更新 v13 权重；「学习引擎」是最小版；
2. 情绪/风格是**参数化模仿**；不做「情绪识别」「风格迁移网络」；
3. 耳嵌入是手工特征，不是学出来的耳；后续可做「学出来的耳」（新预注册）；
4. 未做人耳听测（当前音频可懂度低，先看机制）；人耳终判沿用 `meeting67/08` 协议。
