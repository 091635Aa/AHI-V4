## 0. 一句话

**部分成立。** 自模仿恢复在 **L2–L4 退化上有效**（val 耳统计误差改善 **79.6% / 85.9% / 35.2%**），但在 **L1（近干净，仅增益偏移）上失败**（−298%，把很轻的退化改坏）；**课程（先易后难）没有赢过直训 L4**（L4 35.2% vs 直训 91.7%）；**语气潜变量 z 成立**（线性探针 R² 0.76–1.00，插值单调）、**确定性成立**（同 ckpt 两趟 wav sha256 同）、**非 Transformer 成立**（Conv1D，0.825M 参数）。
按预注册：**M1 未全过（L1 失败）、M2 FAIL、M3/M4/M5 PASS ⇒ 不判「v2 成立」，判「部分成立 + 缺口明确」**，不追加硬调参。

## 1. 设置（实测）

| 项 | 值 |
|---|---|
| 数据 | 167 条 60 s → 确定性划分 **120 train / 20 val**（seed 300）；5 s 窗（T=500） |
| 表示 | log-mel 80 / 22.05 kHz / n_fft 1024 / win 551 / hop 220 |
| 退化 | L1 增益 ±6 dB；L2 低通（高频最多 −25 dB）；L3 高斯噪声 σ 0.05–0.2；L4 时间掩蔽 2–3 段×8–15 帧 |
| 网络 | Conv1D 编码（3 残差块，dil 1/2/4，112 ch）→ z(8) → 解码（3 残差块）→ mel 残差；**825,134 参数**；**0 attention/Transformer** |
| 损失 | `MSE(恢复, 自己) + 0.2·耳统计距离 + 0.1·语气头`（耳统计 = 可微 6 维：能量均值/标准差、谱质心、质心帧标准差、低带、高带） |
| 训练 | 课程：L1→L4 各 250 步 + **巩固 L1–L2 100 步**（防高阶冲掉低阶）；batch 2、Adam 2e-4、seed 300 |
| 对照 | 直训 L4：同总步数（1000 步） |
| 环境 | GPU；`torch.use_deterministic_algorithms(True)` |

## 2. 读数（val 20 条，耳统计距离，越小越好）

| 级 | 退化距离 | 恢复距离 | 改善 | 判（M1 需 ≥30%） |
|---|---|---|---|---|
| L1 增益 | 0.1714 | 0.6831 | **−298.5%** | ❌ 失败（轻退化被改坏） |
| L2 低通 | 0.3418 | 0.0696 | **+79.6%** | ✅ |
| L3 噪声 | 0.7734 | 0.1090 | **+85.9%** | ✅ |
| L4 掩蔽 | 19.3294 | 12.5180 | **+35.2%** | ✅（刚过线） |
| 直训 L4（对照） | 19.3294 | 1.6139 | **+91.7%** | 课程 **输给** 直训（M2 FAIL） |

**语气潜变量（M3）**：z→6 维语气统计的线性探针 **R² = [0.9998, 0.9189, 0.8623, 0.7583, 0.9977, 0.9926]** ⇒ z 确实携带自身语气/音色信息（自监督，无情绪标签）。
**Demo（05 附属）**：两个自己的片段 z 插值 α=0…1 解码，耳统计 **能量、谱质心均单调**；恢复单条耳统计平方误差 15.73→8.90（改善 **43.4%**）；**同 ckpt 两趟 wav sha256 逐位同**。

## 3. 判据对照（不事后改口径）

| 判据 | 结果 | 判 |
|---|---|---|
| M1 自模仿恢复有效（4 级全部 ≥30%） | L2/L3/L4 过、L1 失败 | ❌ |
| M2 课程优于直训 L4 | 35.2% vs 91.7% | ❌ |
| M3 语气潜变量（探针 R²≥0.5，插值单调） | R² 0.76–1.00；插值单调 | ✅ |
| M4 确定性 | 同 ckpt 两趟 wav sha256 同 | ✅ |
| M5 非 Transformer（≤1M 参数） | 825,134 / 0 attention | ✅ |

⇒ **v2 未整体成立**；可复用的成立项：L2–L4 的「自听恢复」机制、z 自监督语气潜变量、确定性、非 Transformer 约束。

## 4. 失败位置（不硬调参，登记缺口）

1. **L1 失败**：近干净输入（仅增益偏移）被网络轻微改坏 —— 耳距离绝对值很小（0.17），但方向错；可能原因（**未做消融**）：GroupNorm 对常数偏移不友好 + 混合课程里 L1 样本占比低；
2. **课程不如直训 L4（L4 35.2% vs 91.7%）**：巩固阶段把 L4 能力换回 L1–L2（L4 从 87% 掉到 35%），说明**课程回放与巩固的配比**是缺口，不是「课程本身无用」；
3. 目标「像自己」= 耳统计距离，**不是内容保真/可懂度**；mel→GL 未做人耳。

## 6. 下一步（需新预注册）

1. **修 L1**：给「近干净输入」加恒等/偏移恢复专项（例如 residual 门控 + 级别条件）；先小预实验；

3. **语气 z** 已成立：下一步可用 **z 作为内部状态**（而不是手设旋钮）接回音频线：z→（学习出的解码）→ 声音，实现「它自己控制语气」；
4. 可懂度/人耳：沿用 meeting67/08 协议，不在本会议宣称。

## 7. 诚实边界

1. 「自己的声音」= 同一说话人真人语音；恢复目标是**统计上像自己**；
2. z 是自监督潜变量，**不对应情绪标签**；插值单调 ≠ 自然语气；
3. 网络小（0.825M）、数据 120 条 5 s 窗、训练 ~50 s；不排除放大数据/模型后 L1 可修；
4. 未做人耳、未用 ASR 评测可懂度；不宣称「会说」「像人一样自然」；
5. v1（强制 5 旋钮坐标下降，损失改善 36.3%）**被所有者否决**，仅作反面记录。
