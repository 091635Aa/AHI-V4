## 1. 问题（v2）

> 把一段**自己的声音**弄退化（增益/低通/噪声/时间掩蔽），系统能不能**靠自己听自己**把它恢复成「像自己」，并从自己声音里**自监督学出语气潜变量**（无需情绪标签/手调参数）？

## 2. 固定口径

| 项 | 值 |
|---|---|
| 数据 | `<path>\SpeakerA7代模型训练数据\` 167 条 60 s（**只读**）；确定性划分：前 120 条 train / 后 20 条 val（固定 seed 300） |
| 表示 | log-mel 80 带 / 22.05 kHz / n_fft 1024 / win 551 / hop 220（与既有 v13 口径一致） |
| 退化（标定在 mel 域，确定性种子） | L1 增益 dB[−6,+6]；L2 低通（高频带线性衰减 0–25 dB）；L3 高斯噪声 σ∈[0.05,0.2]；L4 时间掩蔽 2–3 段×8–15 帧；课程逐级叠加 |
| 恢复网络 | Conv1D 编码器（3 残差块，dilations 1/2/4，128 ch）→ 全局池化 → **z(8 维)**；解码器以 z 广播 + 编码特征 → Conv1D → 预测 **mel 残差**（加回退化 mel）；约 0.82M 参数，无 attention/Transformer |
| 自监督损失 | `L = MSE(恢复, 自己干净 mel) + λ·耳统计距离(自身可微版)`（能量均值/标准差、带均值/标准差、谱质心）；λ=0.2 |
| 语气潜变量 | z 由网络自编码得到；辅助头用 **自身耳统计**（非情绪标签）预测 6 维语气描述，迫使 z 携带语气；**不喂任何情绪标签** |
| 课程 | L1→L4 各 250 步（batch 2，Adam 2e-4）；**级间门**：val 上恢复后耳统计误差相对本级起步下降 ≥15% 才进入下一级 |
| 报告 | 课程曲线、各级恢复前后耳距离、恢复音频、z 插值音频、确定性 |
| 确定性 | 固定 seed；`torch.use_deterministic_algorithms`；同 ckpt 推理两趟逐位同 |

## 3. 判据（先定后跑）

| # | 判据 | 通过条件 |
|---|---|---|
| M1 | 自模仿恢复有效 | val 上「恢复后 vs 干净自己」耳距离比「退化 vs 干净自己」**下降 ≥30%**（4 级全部达标） |
| M2 | 课程有增益 | L4 的 val 恢复误差 **低于**「跳过课程直接 L4 训练」的同预算对照（≈同一步数） |
| M3 | 语气潜变量存在 | z 在 val 上对自身耳统计（能量/质心）的线性探针 **R²≥0.5**；z 插值解码出的音频耳统计**单调变化** |
| M4 | 确定性 | 同 ckpt 推理两趟逐位同 |
| M5 | 非 Transformer | 静态审计：0 attention/Transformer 字样调用；参数量 ≤1M（实测约 0.82M） |

**判定**：M1–M5 全过 ⇒「自模仿·恢复 v2 成立（机制级）」；任一不过 ⇒ 登记缺口，不硬调超参救（无效即跳）。

## 5. 诚实边界

1. 「自己的声音」= 同一说话人真人语音（所有者指定的数据）；恢复目标是**统计上像自己**（耳距离/耳统计），不是内容保真；
2. z 是**自监督**语气潜变量，不对应任何情绪标签；「自己能控制语气」= 改 z 解码，不是情绪分类；
3. 网络是小型 Conv1D（非 Transformer），**不是**「换一个 TTS 模型」；输出仍是 mel → GL；
4. 未做人耳；可懂度仍受 v13/GL 限制；不宣称自然度；
5. v1（强制旋钮+坐标下降）登记为**被否决路线**，不作主结论。
