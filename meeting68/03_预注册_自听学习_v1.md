## 1. 问题

给最小音频线装「自己的耳」后，**它能不能靠听自己+听目标，把自己的发声参数调得更接近目标（同一说话人真人语音）？**
这是「人类式学习」的最小可测版本：**听 → 比 → 调 → 再听**。

## 2. 固定口径

| 项 | 值 |
|---|---|
| 合成文本 | 「今天的风很轻，适合慢慢地说一会儿话。」（S1，只报一次） |
| 目标语音 | `<path>\SpeakerA7代模型训练数据\(1).wav` 前 **20 s**（同一说话人真人；**非同句**） |
| 耳 | `实施/内生耳.py`（自研 DSP，电平归一 0.9；无外部模型） |
| 损失 | 加权耳距离（尺度/权重固定于 `内生耳.尺度/权重`） |
| 优化 | 坐标下降：θ0=[0,0,0,24,60]，步长 [1.5,1.5,1.5,2,40]，**6 轮**，整轮无改进步长×0.5；每轮 5 维 × ±1 方向 |
| 域 | 音高[−6,+8]、增益[−6,+6]、倾斜[−6,+6]、每音节帧数[18,30]、停顿[0,300] ms |
| 报告 | 学习曲线（每次评估）、初始/最终损失、θ、学习前后 wav、耳距离分项 |
| 确定性 | 固定 θ0/步长/顺序；同输入两趟同结果（C13） |

## 3. 判据（先定后跑）

| # | 判据 | 通过条件 |
|---|---|---|
| J1 | 自听学习有效 | 相对损失下降 **≥10%** |
| J2 | 方向可解释 | 最优 θ 的调整方向与耳距离分项一致（如目标 F0 更低 ⇒ 音高调低）；由 `04` 人工判读 |
| J3 | 确定性 | 同输入两趟：θ 与损失逐位同 |
| J4 | 不塌缩 | 学习后音频仍可被耳读出（非静音/非 NaN，时长正常） |

**判定**：J1 过 ⇒「第一版自听学习有效（参数级）」；J1 不过 ⇒「无效」，**不硬调轮数/步长救**（无效即跳）；J2–J4 任一项不过 ⇒ 只登记机制缺口，不宣称有效。

## 6. 诚实边界（预注册时声明）

1. 只优化后置 5 旋钮，**不更新 v13 声学模型**；「学习」是控制层闭环，不是端到端训练；
2. 目标是**非同句**真人片段，只能对齐统计风格（音高/能量/语速/音色），不是内容模仿；
3. 耳为手工 DSP 特征；「更像目标」= 耳距离更小，**不等于**更可懂/更自然（可懂度仍由 ASR/人耳另测，本会议不做宣称）；
4. 情绪/风格是参数级预置；不认为参数能覆盖人类情绪；
5. 若 J1 不过，登记「第一版自听学习无效」，不追加轮数硬救；下一步应换「学出来的耳/端到端控制器」并新预注册。
