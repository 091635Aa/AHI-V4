## 1. 架构（最小闭环）

```text
文本 ──► 音素 token ──► v13 声学模型（只读 ckpt）──► log-mel
                                                     │
                                          5 旋钮控制层（音高/增益/倾斜/语速/停顿）
                                                     │
                                                     ▼
                                              Griffin-Lim → 波形 ──► 听（wav）
                                                                       │
                                          ┌────────────────────────────┘
                                          ▼
                                 内生耳（自研 DSP）→ 耳嵌入 e_self
                                          │
                目标真人片段 ──► 内生耳 → e_target
                                          │
                                   距离 L = ‖e_self − e_target‖²（加权）
                                          │
                                  坐标下降：θ ← 更优的 5 旋钮
                                          │
                                    回到控制层（再生成、再听）
```

## 2. 5 个控制旋钮（对应所有者三词）

| 旋钮 | 范围（默认） | 对应所有者三词 | 实现 |
|---|---|---|---|
| 音高（半音） | −6 … +8（0） | **转动频率** | `librosa.effects.pitch_shift`（确定性） |
| 增益（dB） | −6 … +6（0） | **特殊振幅** | 波形乘 10^(dB/20) |
| 谱倾斜（dB） | −6 … +6（0） | 音色明暗（附加） | mel 域低带−/高带+ 线性倾斜 |
| 每音节帧数 | 14 … 40（24） | **发生概率/快慢** | v13 合成帧数（越少越快） |
| 停顿毫秒 | 0 … 300（60） | 节奏/换气 | 标点处插静音（按字符位置比例近似） |

**情绪预置**（参数级，不是情绪模型）：
平静(0,0,0,24,60)｜高兴(+3,+2,+1.5,23,40)｜低落(−3,−2.5,−1.5,27,180)｜激动(+5,+3.5,+2.5,21,0)｜温柔(−1,−1,−0.5,26,120)。
**风格预置**：慢(28,150)｜正常(24,60)｜快(20,0)。

## 3. 内生耳（自研 DSP，C10）

- 采样 22.05 kHz、25/10 ms 帧；
- F0：40 ms 窗自相关（60–500 Hz，峰>0.30 且能量>阈 ⇒ 浊）；
- 能量：帧 RMS 均值/标准差；包络 8–20 Hz 自相关峰（节奏）；
- 语速：能量包络峰/秒；
- 谱：质心/带宽/滚降/平坦度 + 8 带 log-mel 均值/标准差；
- **电平归一（峰值 0.9）**：耳比较相对动态/音色，不让绝对音量主导；
- 距离：`尺度` 归一 + `权重` 加权；输出总距离 + 分项（可解释）。
- **不用任何外部模型/ASR**；同波形两趟嵌入逐位同（确定性）。

## 4. 自听学习（第一版：坐标下降）

- 目标：真人（同一说话人）片段前 20 s 的耳嵌入 `e_target`（**非同句**，只对齐统计风格）；
- 自产：文本固定（S1）→ 当前 θ 合成 → 耳嵌入 `e_self`；
- 损失：`L(θ)=Σ w_k (e_self,k − e_target,k)²`；
- 优化：坐标下降——对 5 维逐一试 ±步长，保留更优；整轮无改进则步长减半；6 轮（≤60 次合成）；
- 输出：学习曲线（每次评估）、学习前后 wav、θ、耳距离分项、改善百分比；
- 确定性：固定 θ0/步长/顺序；同输入两趟同结果。

## 5. 预算与产物

| 项 | 预算 |
|---|---|
| 单句合成（一次） | ~1–3 s（模型常驻后） |
| 自听学习 6 轮 | ≤60 次合成 ≈ 3–6 min CPU |
| Demo（4 情绪×2 风格） | ~8 次合成 ≈ 1 min |
| 产物 | `产物/音频线/*.wav`、`Demo报告.json`；`产物/自听学习/*.wav`、`自听学习_报告.json`、`自听学习_曲线.json` |

## 6. 失败与停止

| 触发 | 动作 |
|---|---|
| 合成非 finite / 长度异常 | 停，报「音频线损坏」 |
| 方向验证 <3/4 | 登记「控制方向不成立」，不补参数硬凑 |
| 样式两两最小耳距离 ≈0 | 登记「控制塌缩」 |
| 自听学习相对改善 <5% | 判「第一版自听学习无效」并停（无效即跳） |
| 任何「像人一样自然」的宣称 | 禁止：本会议只报参数级与闭环机制 |

## 7. 诚实边界

1. 音频线 = **v13 + GL** 的薄封装，可懂度仍是 v13 的水平（约 0.83/0.75 CER，未达可懂门）；
2. 情绪/风格 = **参数化模仿**；不是情绪识别、不是风格迁移；
3. 自听学习只调**后置 5 旋钮**，不更新声学模型；「像人一样学习」是**机制类比**；
4. 目标非同句；耳是手工特征；未做人耳；
5. 不复活器官线；不改 meeting66/67 既有件。
