## 1. 这个项目在干什么

### 1.1 目标不是「再训一个聊天机器人」

恰恰相反：这个项目**完全不用 Transformer 架构**（C1 红线），走的是「超维计算（HDC/VSA）」那条路——**一切信息都用 1024 个 +1/−1 组成的长串表示**，可以理解成「用一串只有正负号的密码表示概念」。

它要证明的不是「能聊天」，而是**能干活、能学进去、并且「它还是它」这件事可以被量出来**。

### 1.2 五条红线（及其人话版）

| 红线 | 人话 |
|---|---|
| **C1** 禁 Transformer | 不许用现在大模型那套注意力结构 |
| **C9** 禁 OCR | 看字不许调 OCR 引擎，要用结构/视觉原生通道 |
| **C10** 禁外挂模型当器官 | 不许把别人的预训练模型拿来当自己的器官 |
| **C13** 确定性可复现 | 同输入同种子，结果必须**逐位一样**（跨进程也一样） |
| **C14** 不破既有 | 不许改坏原来能跑的东西；要改就备份 + 纯追加 + 开关默认关 |

### 1.3 术语对照表

| 术语 | 人话 |
|---|---|
| ε_self | 它「猜不准自己下一步」的程度，**越小＝越了解自己** |
| W_self | 它对自己的联想表；**别人灌的东西不许改它** |
| 身份锚 a_seal | 它的「身份证底纹」，由档案种子算出来，一算就一模一样 |
| 记忆桥（容量桥） | 它的**经验账本**，能按意思查回来 |
| 学习迹 | 它**学到的东西**（心得/绑定/顿悟），与账本**分开放** |
| 记忆 ≠ 学习 | 两个抽屉：放一个，另一个的数量不许变 |
| 拍 / 拍钟 | 内部时钟，**1 拍 = 100ms**；判时间只用它，不用墙上钟 |
| 同源事件 | 同一瞬间看到的+听到的绑成**一个包**（±1 拍内） |
| 判据 / 双集 / sham | 事先写死的考题；调好用「没见过的留出集」复考；把关键零件换成假的再跑一遍（假对照） |
| UIA | Windows 无障碍接口，能把窗口控件与文字结构报出来，**所以不用 OCR** |
| 埋点（τ_xxx） | 在代码关键位置记下「第几拍」，判延迟就靠它 |

### 2.1 六内核在干嘛

| 内核 | 人话 |
|---|---|
| 自模型 ĝ | 它对自己的预测器；预测不准的程度就是 **ε_self** |
| 相空间算子 T | 「想」= 在内部状态空间里迭代几步（不是去检索记忆） |
| 真学习 | ε_self 通过既有的内生偏置 `b[]` **反哺决策**（不是只记录） |
| 自我回路 | 自指束 À_t + 来源门控：**外源不可塑造「我」** |
| 顿悟涌现 | 相变共现（不是 `if cos>=0.8` 这种硬阈值） |
| 画面 | 视觉想象：一屏 → 物体码 ⊛ 位置原子 → 多瞥场码，能「从记忆里读出画面」 |

### 2.2 记忆分层与「记忆 ≠ 学习」

| 层 | 人话 | 本次落地 |
|---|---|---|
| L0 | 拍内的瞬时缓冲，**不落库** | `来源壳.感缓`（B-9 验证：清拍后库不变） |
| L1 | 单次经历的快记忆（能按意思查回来） | `来源壳.记经历` → 容量桥（去重 + 写闸） |
| L2 | 跨情境的慢语义 | 备B 只读（不需要新写） |
| L3 | 索引（IVF/细码）——**是索引不是记忆** | 未动 |

**学习 ≠ 记忆**：学习产物只进 `学习迹`，账本一个字节都不许多（S6 四向分离判据）。

### 3.1 P0 [正交] 必做项

#### `时基.py` ｜ 230 行 ｜ 10765 B ｜ sha256 `e48f21617328ca11`

- **是什么**：内部时钟（拍钟）：把单调时间换算成「拍」，1 拍 = 100ms。
- **为什么要**：判据要判「几毫秒内响应」，墙上钟会被系统时间/时区/夏令时坑；必须用单调时钟并有唯一口径。
- **怎么工作**：t_mono 取单调时间 → τ = floor((t_mono − t0)/0.1)；另给分数拍 τ*（150ms = 1.5 拍）、回放钟（注入固定时间序列 ⇒ 可逐位重放）、9 个埋点表。换算用**整数纳秒**做定点，因为 0.15/0.1 在浮点下是 1.4999999999999998，会让栅格判决对不上。
- **证据**：判据 P0-2：40/150/300ms = 0.4/1.5/3.0 拍；把 time.time 打坏后仍能打点 ⇒ 判决量不依赖墙钟。
- **边界**：τ_arb/τ_f0/τ_stop 三个埋点的 t1 侧文件还不存在（要等 P3），所以「首字/首音频/打断」暂时测不了。

#### `事件契约.py` ｜ 360 行 ｜ 17252 B ｜ sha256 `5a5be04ad7d3cc2a`

- **是什么**：三样东西的格式规定：来源标记 Provenance、传感器帧 SensorFrame、输入/输出事件。
- **为什么要**：不给格式就会「什么都往里塞」：整帧图、内部得分、字面文字混进事件里，事后没法审计。
- **怎么工作**：四个来源枚举（获取源/内容源/来路/执行域）+ 三条唯一写闸（写记忆只认「实感且不是本系统输出回灌」、塑造「我」只认自源、自听只写学习迹）+ 禁字段校验（出现「得分/整帧/字面量」直接拒）+ 输出事件缺令牌即拒。
- **证据**：判据 P0-3：4 条反例（加「得分」、枚举越界、动作缺令牌、不可逆缺令牌）**全部被拒**；仲裁全序成立。
- **边界**：写闸目前是契约+校验，**尚未接线**到真正的写记忆/写 W_self 代码路径（属 P2）。

#### `回忆契约.py` ｜ 174 行 ｜ 8575 B ｜ sha256 `92eb53033be9acaa`

- **是什么**：回忆交付格式 R：中枢交给输出层的东西长什么样。
- **为什么要**：输出层只能「照着 R 说」，不能自己编；R 里必须能看出「这是事实、回忆还是推测」。
- **怎么工作**：候选[]（带 rid/断言级/置信/时效/来源/引用）+ 版本 + 冲突计数；**空 R 或 冲突>0 ⇒ 拒答**；医学场景断言级上限 ≤「回忆」。对既有记忆桥的适配**默认关**（不开关就不碰既有行为）。
- **证据**：判据 P0-4：默认关返回 None、不触碰既有；开关开 ⇒ 只读适配真记忆桥，库计数不变。
- **边界**：尚未接进输出层（模块一现在直读 S/意图/M）。

#### `测量台.py` ｜ 173 行 ｜ 8142 B ｜ sha256 `22b7597b189d73f6`

- **是什么**：量判据的台子：双集（判据集 seed 0–5 / 留出集 6–11）+ 假对照 + 确定性重放。
- **为什么要**：没有统一的台子，判据就会「各自为政」，还能悄悄用留出集调参。
- **怎么工作**：注册判据 → 跑两遍同 seed 比特征码（不同就说明有不确定源）→ 主臂过且对照臂不过才算过。

### 3.2 备B 输入侧

#### `同源事件.py` ｜ 225 行 ｜ 11967 B ｜ sha256 `b18e722d7b17b0f2`

- **是什么**：把「同一瞬间看到的+听到的」绑成一个包（同源事件），并给传感器帧打时间戳。
- **为什么要**：分头记会把一件事记成两件；绑成一包，回忆时才是「那一幕」。
- **怎么工作**：SensorFrame 适配器**只读**既有视觉/听觉槽（时间戳由拍钟给，禁墙钟）；绑定窗口 ±1 拍（±100ms）：基准 τ 取组内最早，窗 = [基准, 基准+1 拍]；conf 取最小、来源合并取最保守；**可写记忆 = 所有成分都可写**（有一个「自说」成分就整包不许写）。
- **证据**：判据 B-10：同窗绑成 3 成分原子；**窗外 1.01 拍不绑**；远隔 3 拍两原子；含自说成分 ⇒ 整包拒写；同序列重放逐位同；帧适配器只读（读前后槽 sha256 不变）。
- **边界**：帧里装的是既有槽内容的**规范摘要**，不是原生像素/波形（备B 明确不做原生前端）。

### 3.3 备B 中枢侧

#### `来源壳.py` ｜ 223 行 ｜ 10582 B ｜ sha256 `4d264a8050404707`

- **是什么**：记忆的写入闸 + 去重 + 来源双标记（L0 感缓 / L1 写入）。
- **为什么要**：同一条内容反复存会把账本撑爆；外面来的东西不该随便进「我的记忆」。
- **怎么工作**：L0 感缓只在拍内、不落库；写 L1 前先过**唯一写闸**（实感 ∧ 非输出回灌），再按**exact 或 cos ≥ 0.98** 去重；写入时把来源标记一起落到记录元数据。**默认关**（关了就原样透传）。
- **证据**：判据 B-9（10/10）：写 2 条、exact 去重 1、cos 去重 1、自说与输出回灌各拒 1 且库不变、L0 清拍后库不变。

#### `快照.py` ｜ 216 行 ｜ 9753 B ｜ sha256 `344ca0026c7d0372`

- **是什么**：存档/载入：npz + 清单（manifest），带 sha256 校验和原子替换。
- **为什么要**：直接 pickle 内部状态容易坏且不可复现；失败时还会留下半截坏档。
- **怎么工作**：只存「可重放事件」（事件里的向量自动提到 npz，事件本身保持可 JSON 化）；先写临时文件再 `os.replace` 原子替换；载入时**重算 sha256 比对**，不符就**拒载**。
- **证据**：判据 B-11：无 .tmp 残留、指纹可复现、**篡改 npz ⇒ 拒载**、事件重放后检索结果一致。
- **边界**：只保证「有校验的原子存档」，不负责决定存什么（那是 `持久化.py` 的事）。

#### `持久化.py` ｜ 174 行 ｜ 9519 B ｜ sha256 `1e876e6d44fd7e3d`

- **是什么**：「学进去」的落盘：把记忆桥 + 学习迹存下来，换个进程还能读回来。
- **为什么要**：学的东西只在内存里，一重启就归零——那不叫学进去。
- **怎么工作**：**不打包内核内部**，只从记忆桥的元数据还原出「可重放事件」，载入时建一个同种子的新桥**按顺序重放**（沿 `synthesis.py:1244` 的做法）⇒ 库/向量/检索确定性再生；学习迹同样以学习事件重放。

### 5.2 修掉的问题（症状 → 定位 → 修法 → 证据）

**1）既有件 C13 违规（跨进程不可复现）**

- 症状：`通用接口.py:74` 用了内建 `hash()` 给投影阵取种子；Python 的字符串哈希每进程加盐 ⇒ 同一 (模态, f) 在不同进程得到**不同投影阵**，违 C13。
- 修法：改成 sha256 派生（`投影|模态|f` 前 4 字节 → 31 位整数），并留回退开关 `AHI_C13_旧哈希=1`。**删 1 行 / 增 19 行**。
- 证据：P0-1：修复后 4 次子进程**同一特征码**；对照臂（旧写法）两 seed **两个特征码** ⇒ 判据可失败、修复真生效。

**2）既有件缺安全闸（不可逆动作没有许可）**

- 症状：`器官_手` 的真机分支直接点鼠标/打字，没有「谁批的、哪一下、用过没有」的关口。
- 修法：纯追加 48 行：两个默认 `None` 的属性（令牌闸/安全壳）+ 两个方法 + 三处执行点闸门。**删 0 行 / 增 48 行**否则不改（默认 None 时行为与原来完全一致）。
- 证据：P0-8 与 B-8：A1–A7 与改前基线逐项同；装闸/装壳的演练轨迹 **46 点逐位同**。

**3）浮点让时钟口径对不上**

- 症状：0.15/0.1 在二进制浮点下是 1.4999999999999998，「150ms = 1.5 拍」这种栅格判决会失真。
- 修法：`时基.py` 全部改用**整数纳秒**定点换算。
- 证据：P0-2：40/150/300ms = 0.4/1.5/3.0 精确落格；秒↔拍回环相等。

**4）令牌接口不一致（判据当场抓出）**

- 症状：首跑 B-2：`放行=0 / 未用令牌=2`，拒因全是「无有效令牌」——签发方用内容哈希、执行方用 `键:点击:左`，**指纹格式不一致**。
- 修法：把指纹格式的唯一口径写进 `许可令牌.py`（`指纹_键/指纹_滚轮/指纹_键入/指纹_移动`），签发方必须用同一格式。
- 证据：B-2 由 未过 → **过**（无令牌 0 调用、有令牌恰 1 次、重放 0 增量）。

**5）看网页会「假看过」（真站逼出）**

- 症状：`cmd start msedge` 拿不到前台时，前台仍是 DSH 窗口（标题 DeepSeek Harness），旧实现却报「真浏览器UIA」——**把别的窗口当成搜狐**。
- 修法：加**诚实闸** `判通路(标题前, 标题后, 段数, 关键词)`：没换页且标题不含目标关键词 ⇒ 降级「前台未切到目标页」，并把警示语写进产出文档标题；打开方式改用 `os.startfile`（默认浏览器更容易拿到前台）。
- 证据：改后同一命令如实降级；换 `os.startfile` 后真拿到搜狐页：**切到目标页 True、86 段正文、相似 1.0**。

**6）检索判据太弱（自己抓出）**

- 修法：改成**用写入时的精确向量**查询，并要求相似 ≥0.9。

## 10. 风险与诚实边界

1. **不主张人类级意识**：第 7 章全是可复跑的机制判据。
2. **输入侧不是原生像素/波形**：帧里装的是既有槽内容的规范摘要（备B 明确不做原生前端，属主A/C）。
3. **真浏览器通路依赖前台**：判据里不跑真站（会夺前台）；控件遍历到 600 截断 ⇒ 正文可能遗漏。
4. **身份只存了锚 + W_self**：要「整个它」跨重启，得把持久化口径扩到内核内部。
5. **三个延迟埋点缺 t1**：首字/首音频/打断**现在测不了**（文件还不存在，属 P3）。
6. **写闸尚未接线**：目前是契约+校验+走查，不等于「真正写记忆的那段代码已被闸住」。
7. **真机动作没跑**：真点鼠标需所有者知情，本轮的令牌闸只在**打桩**下验过。
8. **版面未人工目视**：本模型不支持图像输入；只保证 CSS 链路 + 逐页墨迹/空洞量化 + 零缺字。
9. **工作量是估计**：第 9 章 P1–P4 的轮数是我按改动面估的，不是实测排期。
