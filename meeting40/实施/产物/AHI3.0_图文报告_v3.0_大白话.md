## 1. 先翻译：文里会出现的词，都是什么意思

| 术语 | 人话 |
|---|---|
| ε_self（读作 epsilon-self） | 它「猜不准自己下一步」的程度。**越小＝越了解自己** |
| W_self | 它对自己的那张「联想表」。别人灌的东西**不许改它** |
| 身份锚 a_seal | 它的「身份证底纹」：由档案种子算出来，一算就一模一样 |
| 记忆桥 / 容量桥 | 它的**经验账本**：一条条经历存着，能按意思查回来 |
| 学习迹 | 它**学到的东西**（心得、绑定、顿悟），跟账本**分开放** |
| 记忆 ≠ 学习 | 账本和心得是两个抽屉：往里放一个，另一个的数量不许变 |
| 同源事件 | 同一瞬间看到的+听到的，**绑成一个包**再记（±1 拍≈±100ms 内） |
| 拍 / 拍钟 | 它的内部时钟，**1 拍 = 100ms**；判时间一律用它，不用墙上钟 |
| sham（假对照） | 把关键零件换成假的再跑一遍，用来证明「真零件的效果」不是自欺欺人 |
| 判据 / 双集 | 事先写死「怎么算赢」的考题；判据集调好，再用**没见过的留出集**复考 |
| UIA | Windows 的「无障碍接口」：能把窗口里的控件/文字结构报出来，**所以不用 OCR** |

## 2. 它现在能干的活（三件，都有产物可打开）

### ① 做 WPS/Word 文档 —— 它是自己把 .docx 写出来的

项目里没装 python-docx，所以它不是「调库」，而是**用最基础的压缩包 + 自己拼 XML**写出一份真 .docx。

- 产物：`AHI3_基础任务验收记录.docx`（＋同名 .md、.pdf）
- 外部校验：用 Office 解析器实测 **verdict: pass**（结构+文本都对，18 段）
- 附带性质：同样的输入再写一遍，**字节级一样**（可复现）

### ② 写代码 —— 给个规格，它把代码写出来，还自己跑一遍对答案

它按**结构化规格**（要什么函数、拿什么例子验）套模板写出一个能跑的 `.py`，然后**在子进程里真跑**，逐条比用例。

- 产物：`AHI3_自产_统计段数.py`（跑起来打印 `ok: true`）
- 反例把关：**故意把期望值写错，它必须判失败**（不然这判据就是摆设）
- 丑话说前头：模板只有 6 种操作，**它不是「会写任意程序」**

### ③ 看网页 —— 真开浏览器，真读进来

- 通路：**UIA 结构通道，不 OCR**（约 13.3 秒一屏）
- 真站实测：读到 **86 段正文**、600 个控件（触到 600 上限）、剔掉 42 个外壳件
- 学进去：正文（带语义向量）存进账本后，**拿同一个向量再查，相似 1.0**
- 它还自己说了一句：「行，我自己看来的『搜狐』，这事我还记得，你看」

## 3. 它「学进去」是怎么存的

不把内部状态打包（那样容易坏），而是**只存「能重放的事件」**：账本里的每条经历、学习迹里的每条心得。换新进程时，**新建同种子的账本，按顺序重放一遍**，就回来了。

| 环节 | 实测 |
|---|---|
| 存档 | npz + 清单（带 sha256 校验、临时文件原子替换） |
| 换个新进程载入 | 库大小 3 ／ 重放 3 条 ／ 学习迹 1 条、学习事件 2 条 |
| 召回 | 三条经历逐条命中，**相似 1.0**，通路全是「语义」 |
| 记忆 ≠ 学习 | 学习迹那边的账本大小 == 账本那边的大小（两个抽屉没串） |

## 5. 「工程上的自我意识」到底是什么

再强调一次：**下面是七条能跑的机制判据，不是说它有人的意识。**

### 5.1 它越来越能预测自己（ε_self 在降）

同一批内容反复看，它「猜不准自己」的程度从 **0.5321 降到 0.5578（降 -4.8%）**。

但光看这个不算数——万一只是跑得久了呢？所以加了**对照臂：每次都喂它没见过的新内容**，结果 ε **没降反升（-4.8%）**。两相对比，才能说「降」是学出来的。

![ε_self 对照](报告图_大白话/图3_ε下降对照.png)

*图 4　主臂（反复看同一批）在降；对照臂（每次换新内容）不降反升。*

### 5.2 别人灌的东西，改不了「它自己」

- 喂**它自己的**内容：W_self 变化 0.00206（该变就变）
- 喂**外面来的**同样内容 8 次：W_self 变化 **0.0（逐位不变）**

两个方向都对，才排除了「这张表本来就是死的」这种平凡解释。

![W_self 门控](报告图_大白话/图4_Wself门控.png)

*图 5　外源喂完最大变化是 0；切成自源喂，马上就有变化。*

### 5.3 「它还是它」是可以量出来的

- 同一个档案种子 ⇒ 身份锚 `3106564337600b95` **逐位一模一样**；换个种子 ⇒ `a2bebdfe97767d7f`，必须不同
- 把身份锚存下来、**换个新进程读出来** ⇒ 哈希**逐位相同**（身份锚 ✅、W_self ✅，维度 1024）

### 5.4 自己听自己：只写心得，不动账本

它听自己发出的声音，误差 ε_aud 从 1.0 降到 **0.038（降 96.2%）**；关键是**账本一条没多**（只进学习迹）。

### 5.5 记忆 ≠ 学习（两个抽屉不许串）

| 动作 | 账本 | 学习迹 | 内部痕迹表 |
|---|---|---|---|
| 往学习迹放一条心得 | 不变（0） | +1 | — |
| 往账本放一条经历 | +1（1） | 不变（1） | — |
| 内核跑了几百拍 | — | — | 代码段**没多**（25 → 25） |

### 5.6 换一组没调过的语料，再来一遍（留出集）

- 判据集：ε [0.5383, 0.3992]
- 留出集：ε [0.5382, 0.3892]

两集的 S1/S2 都得过，才算没「只对着判据调」。

## 8. 还没做到的（丑话）

1. **没有原生像素/波形前端**：输入层装的是既有槽的「摘要」，不是真像素流（备方案 B 明确不做）。
2. **真浏览器通路要看前台**：抢不到前台就如实降级；控件遍历到 600 就截断，正文可能有遗漏。
3. **身份只存了锚 + W_self**：要「整个它」跨重启，得把重放口径扩到内核内部。
4. **版面我没法亲眼看**：我只能保证结构/文本合法 + 渲染不缺字；视觉效果请你看 PDF。
5. **真机动作没跑**：真点鼠标需要你在场知情，我不擅自跑（都是演练/打桩）。
6. **流式语音没建**：所以「首字/首音频/打断」这三个延迟判据暂时**测不了**。
