## 3.5 真站实测 + 一个被真站逼出来的缺陷（这轮最值钱的一条）

**真站跑通**（`打开方式="默认"` ⇒ `os.startfile`，默认浏览器更容易拿到前台）：

| 项 | 值 |
|---|---|
| 通路 | **`真浏览器UIA`** |
| 前台标题（开浏览器前 → 读完后） | `动效与颜色增强创意方案 — DeepSeek Harness` → `搜狐 和另外 2 个页面 - 个人 - Microsoft Edge` |
| 切到目标页 | **True** |
| 读到 | 正文 **86 段**、控件 **600**（触到 `取控件(上限=600)` 截断）、外壳剔除 **42** |
| 学 | 正文入 `容量桥`（`rid=0`），**同向量检索相似 1.0（语义通路）** |
| 产出 | `产物/网页摘要_c61b57c8.docx` + `.md` + 证据 json |
| 说 | 「行，我自己看来的『搜狐』，这事我还记得，你看」 |
| 耗时 | 13.3s |

**缺陷（首跑就暴露）**：用 `视觉_看网页.打开网页()`（`cmd start msedge`）时 **Edge 没拿到前台**，
前台仍是 DSH 窗口（标题 `DeepSeek Harness`）——旧实现却报 `通路=真浏览器UIA`，**等于把别的窗口当成搜狐**。
⇒ 已加**诚实闸 `判通路(标题前, 标题后, 正文段数, 关键词)`**（纯函数、可判据化，见 T-5 的 4 例）：
没换页且不含目标关键词 ⇒ 一律降级为 `前台未切到目标页`，并在产出文档标题前加
「（注意：前台未切到目标页，实际读到的是另一个窗口）」。改完后同一条命令如实报 `前台未切到目标页`，
换 `os.startfile` 才拿到真·搜狐页。

> 这条说明：**"能看网页"不是加个函数就算完**——得先证明它没有把别人的窗口当成目标页。

## 3.6 「学进去」的跨进程证据（T-6 细节）

新进程（`subprocess`，独立解释器）载入存档后的输出：

```json
{"库大小": 3, "重放条数": 3, "学习迹条数": 1, "学习重放条数": 2,
 "命s": [{"文本":"网页正文：搜狐首页有新闻和导航。","相似":1.0,"通路":"语义"},
        {"文本":"笔记：正文用语义向量存。","相似":1.0,"通路":"语义"},
        {"文本":"任务经历：代码任务把规格落成代码。","相似":1.0,"通路":"语义"}],
 "学习迹_记忆库大小": 3}
```

机制：**不 pickle 内核内部**，只存**可重放事件**（`容量桥._文本`+`_向量` → 事件；`学习迹` → 学习事件），
载入时**新建同种子桥 + 顺序重放** ⇒ 库/向量/检索确定性再生（沿 `synthesis.py:1244` 做法）。
`学习迹_记忆库大小 == 库大小` 同时证明**记忆与学习物理分离**没被存档流程破坏。

自产代码产物：`实施/产物/AHI3_自产_统计段数.py`（sha256 `293afc3ea2ce07d3…`，**用例全过、退出码 0**）。
