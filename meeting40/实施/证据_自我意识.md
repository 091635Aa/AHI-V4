## 3 逐条读法（为什么这些数算「机制成立」）

1. **S1**：`0.5383 → 0.3992` 本身说明自模型在**预测自己**这件事上进步了；关键是**对照臂**——
   每拍新内容时 ε 不降反升（−4.8%），所以「降」不是时间/步数带来的假象。
2. **S2**：外源喂同一段话，`max|ΔW_self|` **正好 0.0**；再切回自源喂就变（`0.00206`）——
   两个方向合起来才排除了「W 本来就是死的」这种平凡解释。
3. **S3/S4**：身份锚由**档案种子**确定性派生 ⇒ 同种子逐位同、异种子不同；把它存进快照后，
   **另一个进程**里读出来 sha256 仍逐位一致 ⇒ 工程意义上的「还是我」（跨重启不变），
   而不是「每次都重新随机一个我」。
4. **S5**：自听是**输出回灌**，写闸判它 `可写记忆=False` ⇒ 只落学习迹；ε_aud 随重复自听下降 96.2%。
5. **S6**：三组计数（记忆库 / 学习迹 / `codec._段`）**互不影响**，且**生产路径**（`命.学()` 复盘）
   同样只让学习迹增长。

## 4 诚实边界

1. **不主张人类级意识**：这里只有可复跑的机制判据；「像人一样有自我」不是本套件能宣称的结论。
2. **S6 第 ④ 项用的是回退口径**：`命.学()` 的返回里**没有** `记忆底图未增` 这个键
   （`模块四_记忆底图未增: null`），故该项按 **`库3 == 库2`** 判定（且同一轮里学习迹 `0→1`）。
   已在 JSON 里如实登记 `null`，不假装读过那个键。
3. **S1 的对照臂强度**依赖语料新颖度：本次用「未见过的新说法」效果显著（ε 不降反升）；
   换更同质的语料，对照臂可能不那么干净——这是**数据性质**，不是机制结论。
4. **S4 存的是身份锚 `a_seal` 与 `W_self`**（不是整套内核状态）：内核其余内部态未纳入存档；
   若要「整个我」跨重启，需要把 `持久化.py` 的事件重放口径扩展到内核侧（当前只覆盖记忆/学习）。
5. **本体面未纳入**：`器官_手`/`器官_嘴`/`器官_眼` 的实时闭环、真机动作、流式语音不在本套件内
   （真机动作需所有者知情；流式声带属 P3）。
6. **单机单次**：S1–S7 是**同机同次**跑的判据集；跨机器一致性未验（C13 的跨机口径另属 `步7`/P0-1）。
