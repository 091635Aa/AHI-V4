## 0. 一句话结论

**想象画面 = 大脑用内部信号，在**同一套**视觉层级上做一次"离线建构"；它不是把一丝视觉搬到某个解剖位置。**
把这句话落到 AHI4：现有 [`内核_画面`](../meeting39/实施/内核_画面.py)（HDC 生成式画面核）已经**机制级**实现了这条解释的
三个可测部分（同一网络复用、地址≠内容、离线组合），但**缺两个接线**——①自我态 A 不驱动想象（A 不回写视觉）；
②源监控仍是元数据 `来路` 而不是内生量。本轮实测把可测部分做成数字，并把缺口写成判据臂（§6）与接缝（§7）。

## 1. 对人脑解释的裁定（所有者给的那段基本正确，两处要拧紧）

### 1.1 正确的部分（保留）

| 命题 | 裁定 |
|---|---|
| 视觉不是摄像头成像；视网膜只给粗糙、局部、带噪声的信号 | ✅ 皮层下（LGN）+ V1 已有中心-外周、增益控制、适应；"看见"是**受约束的推断** |
| 视觉本身是模拟/建构 | ✅ 但更准确：**知觉 = 生成模型对感官证据的受约束推断**（预测加工/自由能），不是"先拍再放" |
| 想象画面 = 内部信号驱动同一套视觉网络 | ✅ 额叶/顶叶/海马/内侧颞叶 → 自上而下进入视觉层级；高级视觉区、部分 V1 被重新激活 |
| 想象与看见共享回路，但更弱、更不稳、受注意与工作记忆控制 | ✅；证据族：想象-知觉的交叉解码、TMS 干扰 V1 影响想象、心理旋转的角度-时间关系、双眼竞争启动 |
| 没有"屏幕/电影院/小人"；是分布式表征；"在头脑中"是表征属性不是投影 | ✅（这是原话里最关键的修正） |
| 心盲症：想象弱、知觉正常；幻觉：内生表征过强且被当成外部 | ✅ 双分离说明：**共享回路 + 输入来源/强度/现实监控**三者缺一不可 |

### 1.2 要拧紧的两处

1. **"抽一丝视觉映射到某个地方"不成立。** 位置本身不是画面内容的一部分：在 AHI4 里这条是可测的——
   `读出` 的残范数对所有位置恒等，位置**不在场码的模里**（[`内核_画面.py:431-432`](../meeting39/实施/内核_画面.py)）；
   位置由**外部空间帧**（格位原子/身体参考系）给出，正如视网膜不自己发明"左/右"。
   本轮实测（§5 P3）：同一想象场码在**正确地址** 0.9453、**错误地址** 0.0734（5 次最高 0.1914）。
   ⇒ "画面在头脑中"＝分布式表征 + 外部空间帧的归属感，不是把一个缩微图像投影到某处。
2. **"视觉本身是模拟"要限定为"受约束"。** 没有视网膜输入的想象是**无校准**的生成（易漂移、细节少）；
   真实知觉是**每时每刻被预测误差拉回**的生成。所以想象不是"更弱的看见"，是"**失去误差纠正的同一台生成器**"。
   这正好解释 AHI4 的既有负结果（§4）：**被动重放**（丙3 增益 +0.0273）没有可测收益——重放没有"目标/先验"，
   不是想象；想象要有①内容先验 ②组合生成 ③可辨识性判据，三者缺一即回放或幻觉（[`内核_画面.py:38-39`](../meeting39/实施/内核_画面.py)）。

### 1.3 机制链条（四层，与 AHI4 一一对应）

| 层 | 人脑 | AHI4 对应件 |
|---|---|---|
| 生成模型 | 皮层层级 + 联想区（内容先验） | 画面库（episodes）/ 物体码库（[`内核_画面.py:166`](../meeting39/实施/内核_画面.py)） |
| 自上而下注入 | 额/顶/海马 → 视皮层（预测） | **缺**：A 不回写视觉；只有 `意图偏置场` 改眼跳（[`视场前端.py:265-288`](../meeting38/实施/视场前端.py)） |
| 精度/增益控制 | 注意 = 预测精度加权 | 无（本轮的 P2 扫描就是在标定这个量的阈值） |
| 现实监控/源归属 | 前额叶 + 岛叶等（自我 vs 世界） | provenance 元数据 `来路`（[`内核_画面.py:46-48`](../meeting39/实施/内核_画面.py)）；两区室 A/B 已在 V4 里但未接视觉 |

## 3. 本轮实测：把解释做成五条可证伪的臂

脚本：[`实施/实验_想象三条理论预测.py`](实施/实验_想象三条理论预测.py)
（合成屏 144×256、7 件、D=1024、种子 3800/7/5601；**不用真屏**以保证 C13；两趟 SHA256 逐位同 ✅）
结果：[`实施/实验_想象三条理论预测结果.json`](实施/实验_想象三条理论预测结果.json)
产物（人眼核对"脑子里那块"）：[`产物/回放屏.png`](产物/回放屏.png)、[`产物/想象屏.png`](产物/想象屏.png)

### P1 同一网络复用（感知 vs 想象，同一个 P/Pᵀ/同一码库）

| 量 | 实测 | 读法 |
|---|---|---|
| 感知 码似 均/低 | **0.9010 / 0.8066**，认出 16/16 | 编码驱动 |
| 想象 码似 均/低 | **0.8936 / 0.7910**，认出 16/16 | 同一解码器、无新网络 |
| 差（感知−想象） | **0.0074** | 想象**并非另一套系统**；弱一点点 |
| 新组合格数 | 14（位移 (3,2)） | 是离线建构，不是回放复述 |

⇒ 支撑"想象重用同一套视觉网络"；AHI 的想象没有自己的编码器/解码器，只把库里的码**重新绑定到新位置**。

### P2 精度（信噪比）→ 可辨识：同一解码器的崩塌曲线

| 扰动 | 0 | 0.5σ | 1σ | **2σ** | 3σ | 4σ | 6σ |
|---|---|---|---|---|---|---|---|
| 感知 均 | .9010 | .8876 | .8507 | .7728 | .7062 | .6541 | .5146 |
| 想象 均 | .8936 | .8763 | .8618 | **.7766** | .6954 | .6287 | .5083 |
| 想象 认出率 | 1.0 | 1.0 | 1.0 | **0.50** | 0.19 | 0 | 0.06 |

| 翻位比 | 0 | .05 | .10 | .15 | .20 | **.25** | **.30** | .40 | .50 |
|---|---|---|---|---|---|---|---|---|---|
| 感知 均 | .9010 | .8854 | .8658 | .8610 | .8406 | .8101 | .7557 | .5989 | .3375 |
| 想象 均 | .8936 | .8771 | .8654 | .8552 | .8286 | **.7838** | **.7583** | .5579 | .3425 |
| 想象 认出率 | 1.0 | 1.0 | 1.0 | 1.0 | .94 | .56 | .31 | 0 | 0 |

**认不出阈：高斯 2.0（场范数倍数）／翻位 0.30。** 两曲线在崩塌前相差 ≤0.02 ⇒ 同一解码网络；
崩塌点一致说明"想象更弱"不是网络不同，而是**信号精度更低**——这正是心盲症/想象模糊的机制类比：
**不是没有画面模块，是精度低于可辨识阈。**

### P3 地址 ≠ 内容（位置是读键，不是投影位）

| 量 | 实测 |
|---|---|
| 同一想象场码，**正确地址** | **0.9453** |
| 错误地址（5 个格网外新键） | **均 0.0734，最高 0.1914** |
| 整屏场码在**空位**（40 个格内空位） | 最高 **0.4863**（低于判据 0.78） |

⇒ 画面不是"铺在某个地方的一张图"：**换地址就解不出**；空位也解不出"那里有什么"。
这也解释了 `内核_画面.py` 头部"位置不在场的模里"的预检：位置由外部空间帧给，不由图像自己产生。

### P4 组合想象（离线建构 vs 回放）

合成屏：**16/16 认得，码似最低 0.7910（≥0.78），新组合 14** → ✅。
真屏（同一判据）：**15/16、最低 0.7754–0.7793 < 0.78** → ❌（既有记录）。
**结论**：离线建构在合成屏上成立，在真屏上处在阈值边缘——**必须固定屏幕口径**，否则判据不可复现（§8）。

### P5 源监控：来路不在内容里（结构化事实）

同一物体：`实感场` 与 `想象场` 用的是**同一个物体码**（逐位同），只有位置原子不同；
两场码域 cos = 位置原子 cos = **−0.0488**。
⇒ **单看内容判不出来源**。人脑的"这是我想的还是我看见的"必须另有一路信号；
AHI 里对应两样：①元数据 `来路`（provenance，且**只有实感入库**，[`内核_画面.py:46-48,341`](../meeting39/实施/内核_画面.py)）；
②**两区室 A/B 差分**（自我态 vs 世界态）——但这条**还没接**（§7 接缝2）。

## 5. 把它接进 V4：三个接缝（零新算子）

> 原则：不复刻 Transformer、不上外挂模型、不改 `两区室核` 与 `画面核` 的默认行为（C14）；
> 新东西一律**旁挂 + 保护开关默认关**，判据先行。

### 接缝1：自我态 A → 画面先验（"想象由自我驱动"）

- **现状**：A（慢自我态）只进整合输出（`o=软限(A−B)`），不回写视觉；视觉侧唯一自上而下是意图偏置（只改看哪里）。
- **最小改动**：新旁挂 `旁挂_想象由A驱动.py`，每拍后：
  1. 把 A 的 256D 经**既有**固定投影得到"想什么"的查询向量；
  2. 在画面库码库里 argmax → 选一个物体下标/新位置键（**不新增算子、不训练**）；
  3. 调 `画面核.想象()/想象码()` 得到想象场码 → 按同一读出路径解码；
  4. 结果喂 `喂想象给自模型(更新=False)`（已有，[`内核_画面.py:748`](../meeting39/实施/内核_画面.py)）——自编的东西塑造"我"？**默认不塑造**，这条纪律保持。
- **不动的**：`算子_两区室核.py`、`画面核` 的默认开关、`贯通_多核心.py` 的每拍结构。

### 接缝2：源监控从"元数据"升级为"内生量"

- **现状**：只有 `来路` 标签（实感/回忆/想象），且只有实感入库。
- **最小改动**：新旁挂里记 `源分数 = g(重合门强度, ‖A−B‖)`（都是既有量，不新造）；入库条件改为
  "`来路=实感` **且** 源分数 ≥ τ"。τ 由判据臂戊1 标定。
- **为什么重要**：这正是"幻觉 = 内生信号过强且被误归因为外部"的工程对应；也守住"想象污染看到的"这条病。

### 接缝3：帧源与可复现

- 真帧（截图）不可复现（本轮实测：真屏 15/16 & 0.7793，合成屏 16/16 & 0.791，差在环境）。
- **判据一律用合成屏**；真机演示另开一个"演示"通道（与判据分离），否则 C13 作废。

## 6. 判据臂设计（沿用 甲/乙/丙/丁/戊 命名 + must-fail 纪律）

> 参照 [`判据_千层骨架.py:14-18,56-60,908-916`](../meeting51/实施/判据_千层骨架.py) 的五字段格式与"先冻结阈值再跑"。

| 臂 | 验什么 | 阈值（本轮标定） | 反例/must-fail |
|---|---|---|---|
| 甲1 同网络复用 | 想象与感知走同一 P/Pᵀ/码库 | 想象认出率 = 1.0 且 码似低 ≥ 0.78（本实验已过） | 给想象单独建一套码 → 必须测出差异消失 |
| 甲2 想象→ĝ | 想象码喂自模型（更新=False）不塑"我" | 既有 N6-5b（W 逐位同）已过 | 打开 `更新=True` → 必须污染 |
| 乙1 双分离 | A 降权/切断 ⇒ 想象退化、感知不变 | 想象降幅 ≥ 0.10 且 感知降幅 ≤ 0.03 | 镜像 V4 `自指 0.469 / 世界 0.014` |
| 乙2 精度阈 | 想象在同噪声下仍可辨识 | 高斯 ≤2.0σ 且 翻位 ≤0.30（本实验已标定） | 噪声超阈仍"认出" ⇒ 判据失真（须重标） |
| 丙1 地址非内容 | 错地址解不出、空位解不出 | 正确 ≥0.78 且 错误 <0.30、空位 <0.78（已过：0.9453 / 0.0734 / 0.4863） | 换地址仍能解 ⇒ "屏幕"假设成立（当前不成立） |
| 丙2 组合想象 | 搬家后全认得 ∧ 新组合 >0 | 全认 ≥ 判据（合成屏 0.791 已过；真屏边缘 FAIL） | 不换位却"认得" ⇒ 实为回放 |
| 丁1 确定性/计费 | 两趟逐位同；想象 pass 不加算子 | 结果 JSON SHA256 两趟同 ✅；算子数仍 8 | 引入迭代反演但不计费 ⇒ 必须失败 |
| 戊1 源监控 | 想象不入库；强增益 → 误归因 must-fail | 仅实感入（既有）；源分数 τ 由本臂标定 | 把 τ 放宽到 0 → 想象污染必须被测出 |
| 戊2 迁移 | 未见位置/未见组合 | 认出率 ≥0.75（未见位置单件 cos 0.9102 已过） | 只认训练过的位置 ⇒ 不合格 |

**必须诚实的一条**：丙2 在真屏上本来就是 FAIL（0.7754–0.7793<0.78）。**不许调低判据去过臂**；
要么固定合成屏口径，要么把生成器精度提上去（同网络内），并在台账写明改了什么。

## 7. 对人脑解释的最终表述（可直接引用）

> 想象画面不是"从视觉里抽一丝，映射到大脑某处"。
> 大脑是一台**受感官证据约束的生成器**：知觉＝生成器在当前证据下的推断，想象＝同一台生成器**撤掉证据、由内部先验驱动**的一次离线建构。
> 画面不是一个被投影的位置，而是**分布式表征**：颜色/形状/空间/意义分散在不同区域被重新组合；位置感来自空间参考帧（身体、眼位、海马位置细胞），不是来自图像。
> 想象与看见共享回路，所以"像看见"；但想象没有视网膜校准，所以更弱、更易漂、细节更少；
> 心盲症＝内生信号精度不足；幻觉＝内生信号过强且源监控失败（被误归因为外部）。
> 结论：**想象是离线建构，不是投影。**

### 12.2 人脑侧依据（为什么"轮廓/碎片"是对的方向）

- 心理意象不是照片回放，而是**类似感知的、但细节更少、更不稳定的重建**（imagery-perception 共享表征、TMS 干扰 V1 影响想象、心理旋转的角度–时间关系）。
- 意象常是**概括化/原型化**的：想到"文件夹"想到的是**文件夹的轮廓/典型特征**（页签+矩形），不是某次看到的那张截图；
  这正对应"想象重用同一网络、但由内部先验驱动、无视网膜校准"的预测加工解释（§7）。
- 所以可观测画面应是**边缘/轮廓示意 + 稀疏碎片**；"模糊虚影"是**生动度**问题，不是分辨率问题。

### 12.3 实现：`画面_轮廓想象.py`（新件、默认旁挂、既有件一字未改）

1. **看**：线画图标屏 → 亮线掩码 → 膨胀 2 → 连通域 → 图标框（`框±6px` 补块）；
2. **结构**：补块 64×64 灰度 → 三阈值二值（μ±0.6σ, μ，与 `形状束.py` 同律，**色无关**）；
3. **轮廓**：三层二值图的**边界并集**——这就是"边框线"；退化层（几乎全真/全假）跳过、补块边框不算轮廓
   （不跳过的话每个图标外面会多出一个假虚线大框——实测踩过）；
4. **记**：每个图标存 `框/位置/轮廓/972 维池化码`（位置来自空间参考帧，不是像素投影）；
5. **想**：从记忆取轮廓 → 按**生动度**保留一部分轮廓像素（固定种子 ⇒ 确定性）→ 画成**点线/碎片/虚影**；
6. **认**：把想出来的碎片轮廓重新算 972 码 → 库最近邻 → **身份 + 位置**；
7. **用**：身份+位置直接生成"去 (x,y) 点一下"的计划（想象服务于行动，不是摆看）。

### 12.5 诚实边界（这一版仍不是"人级想象"）

1. **合成线画图标**：不是真桌面截图；检测用"亮线+膨胀+连通域"启发式，**不是**眼的误差场涌现/中央凹确认。
2. **接的是"形状原型"这一路**：身份用轮廓的 972 码；**未接** `形状束` 全链、`图标簿`、识别门 0.75 的标定口径（门值需在用真图标后重标）。
3. **生动度是单标量**：人脑的想象细节还受内容/任务/自上而下（A）调制；本轮"想哪个"由外部指定下标，**不是自我态 A 驱动**（§5 接缝仍未做）。
4. **C8 严格 IoU 低**：1px 虚线对细线极敏感；容差 2px 才 0.689。它说明"轮廓大体对上了"，不说明"逐像素可预测"。
5. **C5 是均值判定**（10 种子均 0.28 ≤0.4 通过；单种子最高 0.6）——n=5 的臂，结论按多次平均读，别按单次。
6. **颜色**：全程同色线画（形状是唯一身份），这是故意的（专家：颜色恒常不可、形状才是身份）；真图标若靠颜色区分，本件不覆盖。

### 14.1 做法

1. **对齐补强**（`对齐补块`）：用 `前景对比图` 的亮度加权质心当字形锚点，把补块平移到格带中心（`warpAffine`，确定性；
   位置仍由桌面栅格 (行,列) 承担，这里对齐的是"格内落点抖动"）。原型与探针**都**对齐。
2. **背景分离**（`前景对比图`）：补块边缘带中位色 = 局部背景 → Lab 距离图当"形状地形"（不做颜色恒常、不把颜色当身份）。
