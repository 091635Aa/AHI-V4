# AHI4 · 连续说话层证据（修「一拍一断」与「结构不像 Transformer」）

> 所有者 2026-10-18 00:03 指出两个问题：
> ① 人类说话不会「一拍一断」；② 说话结构要和 Transformer 一致。
> 本件只记修正后的实测；旧「一拍 2–3 词」的挂载演示作废，不再作为说话证据。

## 1. 修了什么

| 问题 | 旧做法（错） | 新做法 |
|---|---|---|
| 一拍一断 | 每拍吐 2–3 个词，按 100ms 拍切碎 | **一次调用产出一整段**（3–5 句、50–90 字）；内部拍**只用于选内容**，不再切文本 |
| 没有句结构 | 词串，无标点 | 完整句子 + 句末标点；平均句长 17.6 字；四字重复率 1.5% |
| 说话流 | 与拍绑定 | **逐字流式**：每字一个虚拟毫秒（12 字/秒），与拍钟解耦（`说话_流式示例.jsonl`） |
| 结构对齐 | — | **推理结构与 Transformer 一致**：自回归、逐 token、定长上下文窗口（5 字）、条件于角色/状态；**架构不是 Transformer**：字符 n-gram 计数回退（无注意力、无外挂模型，C1/C10 合规） |

**数据来源（外采、只读）**：工作区打标日记（`RWKE/训练数据/EmoCompanion_日记_全量.txt` 前 160KB + 精选 32KB）＋ `550W.log`；角色包记忆与听见句。**不加载任何外部权重**（A9 已 AST 检查）。

## 4. 诚实边界（这版**还不是** Transformer 级说话）

1. **内容来自角色记忆模板的整句选择**（状态选句桶），不是自由生成；所以「结构对」但「内容新意有限」，同一角色 8–20 句记忆会出现重复。
2. **字符 n-gram 只用于结构/合法性检查与后续续写研究**；本轮没把自由续写作为输出（早期版本自由续写会跑偏，已撤回）。
3. **不是 Transformer 架构**（C1 红线）：相同的是「自回归逐 token + 上下文窗口 + 条件生成」的推理结构；不同的是用计数回退替代注意力。
4. 三种角色里，洛天依/MOSS 的包是**公开资料摘要模板**（非本人/非台词）；EmoCompanion包来自**工作区打标日记**（真实文件）。
5. 无声音/歌声；单机 D=64；资源账未做。

## 5. 下一步（V6 说话）
