## 1. 四轴定义

```
轴 A 功能分区  U_A = 12
轴 B 层内阶段  U_B = 6     （L1..L6 功能档；L1 只作偏置）
轴 C 区室      U_C = 3     （顶树-情境 / 胞体-感觉 / 基树-输出门）
轴 D 时间尺度  U_D = 6     （τ 档 ≈ 1 / 3 / 10 / 30 / 100 / 300 拍）

层单元数 U = U_A·U_B·U_C·U_D = 1296 ≥ 1024   ⇒ 千层达标

扩展规则（乘性，非串行加层）：
  轴A 12 → 24 → 36      （同模板复制；新增分区必须自带 provenance 语义与入边类别）
  轴B  6 → 8            （加"跨区整合档""输出门控档"）
  轴D  6 → 8            （加超慢档，用于巩固）
  四轴乘积自动扩到数千
```

## 2. 单元参数容器（唯一的新增数据结构）

```python
# 伪规格；实现时数值一律走既有 _归（2^-20 定点格）
class 层单元:
    D:   int                     # = 256（默认，与 V4 一致）
    g:   float[D]                # 逐元素增益（含丘脑增益档 κ_th），可塑、慢
    τ:   int                     # 时间档索引 ∈ 1..6；映射到 λ_u = 1/τ档值
    P:   list[tuple[int,int]]    # 稀疏入边：(源单元id, 目标阶段档)；m = 3..4 条
    l:   int                     # 层档 ∈ 1..6
    c:   int                     # 区室 ∈ 1..3
    pro: float                   # provenance ∈ [0,1]：自源经历累积占比
    A:   float[D]                # 慢态（跨试次存活）
    B:   float[D]                # 快态（当前观测投影）
```

**硬约束（写进实现自检）**：
- **不存在** `dict[分区名] → 功能` 形式的映射（己3 源码自扫）；
- **不存在** `U×U` 或 `D×D` 的耦合矩阵（丁1 线性计费）；
- 单元之间只通过**共享的 D 维状态**与**逐元素 `符`** 交互。

## 3. 前向规格（每拍，全部逐元素 + 定点）

```python
def 前向一拍(单元列, 外部输入):
    # ① 重合汇集：任一入边为 0 则该项为 0（双线性符合）
    for u in 单元列:
        acc = 0
        for (v, 目标档) in u.P:
            acc += 符(单元列[v].A, 单元列[v].B)      # 复用第八算子
        u.B_汇集 = 归(acc)

    # ② 丘脑增益（已并入 g，此处仅注释）
    #    u.B_汇集 = 归(u.g ⊙ u.B_汇集)

    # ③ 快态：当前观测的投影（仅"快速接收"类单元接外部输入）
    for u in 单元列:
        if u 接外部:
            u.B = 归( u.g ⊙ 软限( u.W_in @ 外部输入 ) )
        else:
            u.B = 归( u.g ⊙ u.B_汇集 )

    # ④ 竞争归一（对应基底节 + 抑制性中间神经元）
    活性 = 归( 全单元 |u.B| 的逐元素汇总 )
    阈值 = 归( 均值(活性) + β · 标准差(活性) )
    for u in 单元列:
        u.B = 归( u.B ⊙ 1[活性 ≥ 阈值] )            # top-k 式保留
    全局抑制 = 归( γ_g · 均值(活性) )                # 广播回所有单元

    # ⑤ 慢态更新（自带衰减，λ_u 由时间档决定）
    for u in 单元列:
        u.A = 归( 软限( u.A + λ_u · (u.g ⊙ u.B) − 全局抑制 ) )
        u.输出 = 归( 符(u.A, u.B) )                  # 双线性符合：缺一即无输出
    return 单元列
```

**耦合权实时化（裁决 4 的落实）**：
```python
def 耦合权(a, b):                                    # a←b 的耦合强度
    return 归( 归一化( 符(单元[a].A, 单元[b].B) ) )     # ★ 每拍算，不查表
```

## 4. 入边拓扑生成规则（四类边）

| 类别 | 源 | 目标 | 生成规则 |
|---|---|---|---|
| 前馈 | 低档分区 **L2/3** | 高档分区 **L4** | 按分区序号单调递增连线 |
| 反馈 | 高档分区 **L5/6** | 低档分区 **L1/L2/3** | 反向连线，目标档按 L6→L1（偏置）、L5→L3 |
| 横向 | 同档分区 L2/3 | 同档分区 L2/3 | 侧向竞争（提供 top-k 稀疏） |
| 皮质下 | L5 | 竞争层(10) / 增益层 | 唯一的"出脑"口 ⇒ 鼠标/键盘两原语 |

## 5. 三档记忆 + 重放容器（裁决 5 的落实）

```python
回波     痕    ← 归( λ_e · 痕 + 广播激活 )                 # λ_e < 1，泄漏衰减；不参与广播
冻结槽位 槽[k] ← 归( 0.999 · 槽[k] + 快照 )                 # 容量 K；冻结期不参与广播
         解冻：若 归一化(符(线索, 槽[k])) > ζ ⇒ 注入竞争
         淘汰：优先级 = w_recent·最近使用 + w_match·重合强度
慢态     单元.A                                              # 见 §3
重放     在无外部输入时，按优先级抽样重跑主循环 N_replay 拍，
         只更新慢系统 W（低可塑率），**不接输出**           # 离线账，不进在线计费
参考系   η_u = η_0 · (1 − pro_u)                             # 自源 ⇒ 低可塑、承重
```

**C1 红线（强制）**：记忆钥匙**不得**写成 `softmax(QK^T)` 一步检索。必须：迭代补全 + 稀疏存储 + 阈值门控。
**实施前置动作**：源码级扫描 + 更新式级审查（判据 己2）。

## 6. 代价核算（设计值，须实测修正）

| 项 | 公式 | 取 U=1296, D=256, m=4 |
|---|---|---|
| 参数量 | `U·D·(1+m)` | ≈ **1.66 M** |
| 定点存储（int32） | `参数量 × 4B` | ≈ **6.6 MB** |
| 每拍乘加 | `U·(m·D + D)` | ≈ **1.66 M** 乘加/拍 |
| 耦合 | `入边数·D` 逐元素 | **不含 U²** |
| 抑制/竞争 | `D` 逐元素 + 一次全局汇总 | **不含 U²** |
| 冻结槽位 | `K·D` 存储 | K=8 时 ≈ 2048 |
| 重放 | 离线 `N_replay × 每拍成本` | **分开上报** |

**不变式**：全部新增为 **O(U·D)** 或 **O(D)** ⇒ `计费(4096)/计费(1024)` 仍须 ∈ **[3.95, 4.05]**（判据 丁1）。

## 9. 诚实边界

- 本件为**规格**，无实测；1.66 M 参数 / 6.6 MB / 每拍 1.66 M 乘加均为**设计值**。
- 1296 是**配置值**；"千"无魔力，须由 戊1/戊2 验证其实质。
- 12 分区的角色标签**不是解剖学**；判据 甲4 要求重命名后行为逐位不变。
- τ 档、λ_e、K、ζ、β、γ_g **均为扫描候选**，不得类比定值。
- provenance 调制可塑率是**工程推论**（落实宪法第一条），无直接实验支持。
- **不主张意识/现象意识/人类级智能**；不宣称"已完成"。
