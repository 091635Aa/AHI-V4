## 2. 千层配置（冻结）

```
U = 轴A 12（分区）× 轴B 6（层档）× 轴C 3（区室）× 轴D 6（时间档）= 1296 ≥ 1024 ⇒ 千层达标
D = 64（行为探针；代价臂另按 D=256 解析上报）   m = 4 条稀疏入边    定点 2^-20 格
τ档 = (1, 2, 5, 10, 20, 50) 拍（扫描冻结；原设计 1/3/10/30/100/300 的慢档在 900 拍预算内不可收敛）
```

**单元参数容器**（规格 §2 唯一新增数据结构）：`g_u∈R^D / τ_u / P_u=稀疏入边(源单元号,边类) / l_u / c_u / pro_u`
+ 快态 `B`、慢态 `A`、输出。四轴坐标只做**参数寻址**，名字不进入计算（甲4 实测逐位同）。

**入边拓扑生成器**（规格 §4，索引规则确定性生成，无名字查表）：

| 槽 | 边类 | 生成规则 |
|---|---|---|
| 0 | 柱内 | 同分区/区室/时间档：层档 b ← b−1（多阶段推进） |
| 1 | 前馈 | 分区 a ← a+1 的 b−1 档（低档→高档的不对称目标档） |
| 2 | 反馈 | 分区 a ← a−1 的 b−1 档（反方向；乙4 可证伪） |
| 3 | 横向 | 同分区：跨区室 + 跨时间档（侧向竞争 / 多尺度混合） |

**前向一拍**（规格 §3 + 实测修正 R1–R8）：逐档序贯推进 → 逐单元重合汇集（第八算子「符」+ 直通支路）
→ 丘脑增益（并入 g）→ 三区室整合（顶树/胞体/输出门：第三次调用既有 `门`）→ 竞争归一（全局 top-k）+ 全局抑制
→ 慢态 A（泄漏积分，λ=1/τ档）→ 输出 = 门(门控, 符(A,B), B)。**耦合权 α_{u←v} = 静息基线 + 归一化符(A_u,B_v)，每拍实时算，不查静态权重表**。

**零新算子**：算子表实测仍为 **8**（绑/解绑/门/叠/归/读/迭代/符），`符` 走 meeting49 的继承登记；
`门` 的批量化同式与继承 `门` 实测**逐位同**（判据 真接线 臂）。

## 3. 实测修正（相对 `规格_千层张量_四轴.md`；全部是**跑出来**才发现的，逐条登记）

| # | 规格原式 | 实测问题 | 实施修正 | 影响 |
|---|---|---|---|---|
| **R1** | 汇集 = Σ 符(A_v,B_v) | 纯符合支路把线性信息在 2~3 档内绞成高阶乘积：线性读出从深层解单通道输入的上界≈0.58（≈随机） | 双支路：`源快态 B_v`（直通，保信息可达）+ `符(A_v,B_v)`（重合，保留规格那条支路）；`符` 另在**耦合门**与**输出门**承重 | 算子数不变（仍 8）；深层线性可解码性 0.58→0.92（层0） |
| **R2** | 同拍全档一次算完 | 实测这样“深度”退化为延迟管线（1 档/拍），层级不产生同拍组合 | 改为**同一拍内 b=0→5 序贯推进**；环路轮数 = 整链重复次数（乙3 实测 0.71→0.83） | 深度成为拍内组合；乙3 可证伪 |
| **R3** | A ← 软限(A + λ(g⊙B) − 抑制) | 快档 λ=1 时退化为纯积分（不跟踪、易饱和） | 按“自带衰减”改为泄漏积分 `A ← 软限((1−λ)A + λ(g⊙B) − 抑制)` | A 有稳态；丙4 参考系可测 |
| **R4** | （无） | 逐档幅度指数衰减（2 档即掉量级），深层全灭 | 每档 B 逐单元**定点归一**（丘脑增益稳态标定） | 6 档都能保有量级 |
| **R5** | 前后馈按“环” | 环形拓扑下“去反馈”可绕环到达 ⇒ 乙4 不可证伪 | 前馈/反馈改**路径制**（a+1 有界 / a−1 有界，不绕环） | 乙4 实测 0.634 vs 0.496（差 0.138） |
| **R6** | W_in 随机正负 | 混合号投影下逐档乘积的单项式系数在各维上随机反号，线性读出互相抵消（2 阶上界 0.80） | 输入投影取 **ON 型**（\|·\|，极性别一致） | 2 阶上界 0.80→**1.00** |
| **R7** | （无） | 读出前不做归一，在线学习**学不动**（训练内一直停在 0.51） | 读出前**稳态归一**（逐特征维运行均值/方差，确定性、非算子） | 训练内 0.51→0.83+；测试 0.80+ |
| **R8** | （无） | η_pro 纯累加 ⇒ pro 全部饱和到 1，参考系消失（丙4 反例与参考系完全同值） | pro 改为**泄漏估计** `pro ← (1−η)pro + η(正确·用 − 0.5·错误·用)`，η_pro=0.01 | 丙4：漂移比 0.021（反例 5.16 倍） |
| 补充 | 读出 = 末档输出门 | 末档（层5）特征线性可解码性差（f_a≈0.58） | 读出默认 = **接收层档 × 输出门 × 最快时间档**（单输出门单元）；多档拼接为可配置项 | 主任务 0.89；甲1 单单元冻结可测 |

> 这些修正**不改变**裁决 1–6 的骨架（四轴张量积、零新算子、零总控、三档记忆、步进实施），
> 只改“规格伪码级”的实现细节；其中 R1/R2/R5 是**为了可证伪性**（否则对应判据臂无法失败）而必须做的。

## 7. 诚实结论（照会议纪律，不粉饰）

1. **四轴实现成立**：1296 单元、四轴张量积、零新算子（8 个）、零总控/零路由器（乙1、乙2）、
   三档记忆容器与参考系（丙2/丙4/丙5）、线性计费与定点确定性（丁1/丁2）——**都真跑并通过**。
