## 1. 我对第 1 轮三大张力的表态

| 张力 | 我的表态 |
|---|---|
| **解剖 vs 原理** | 可复刻的是**连接的方向性与统计拓扑**（前馈到 L4、反馈到 L1/L2/3 与 L5/6 不同目标、丘脑作为中继与增益、基底节作为竞争选择）。**不可复刻的是"分区清单"当图纸**。 |
| **千层定义** | "千层"在生物上对应的是**跨区层级数 × 柱内阶段数 × 环路轮数**的**乘积**，不是串行深度。 |
| **深度是否等于堆层** | **不等于**：皮层-基底节-丘脑是**闭环**，深度来自**环路的轮数**；串行堆层既无生物依据，也会破坏线性代价。 |

> **我反对 01 的一点**：01 把微回路讲透了，但**没回答"区与区之间凭什么耦合"**。若耦合系数是预设的，那就是**隐式总控表**；必须是**实时由重合强度决定**。这正是我这一节要解决的问题。

## 2. 可复刻的长程事实（细分）

### 2.1 丘脑：不是"路由"，是**中继 + 增益**

| 环节 | 生物事实 | 我方抽象 |
|---|---|---|
| 一级（FO）核 | 感觉上行在 FO 丘脑换元，**发放到 L4** | **接收门**：只做增益，不做路径选择 |
| 高序（HO）核 | 接收 L5/6 回灌，参与跨区协调 | **回灌缓冲**：慢态 |
| 基质（matrix） | 弥散投射到 L1，调制整体兴奋性 | **全局偏置**（逐元素加性偏置，非通路） |

**关键**：丘脑的区分是"**增益档**"（FO 快、HO 慢、matrix 全局），**不是分发器**。这直接支持"突显网络＝增益调节不是路由"的既定结论。

### 2.2 基底节-丘脑-皮层环：**竞争选择**，不是选择器模块

| 环节 | 生物事实 | 我方抽象 |
|---|---|---|
| 环数 | 经典 5 环（运动/眼动/眶额/背侧前额/扣带）；**现代观点：环数≈投射到纹状体的皮层区数** | **每个分区可各自拥有一条闭环**，环数**随分区数自动增加**，不预设 |
| 结构 | 皮层 → 纹状体 → 苍白球/黑质 → 丘脑 → 回皮层，**并行闭环** | **闭环回路**：分区→竞争层→增益层→分区 |
| 直接/间接通路 | 直接通路**去抑制**（放开），间接通路**加抑制**（收住） | **WTA + 全局抑制**：胜者获得去抑制增益，其余被压 |
| 功能 | **奖励驱动的动作自适应需要强回环** | 后继表征 M 的**动作价值**在环内迭代收敛 |

**关键**：基底节不"决定"选什么，它**提高胜者的增益、压低败者**——选择的**内容**来自皮层竞争，基底节只提供**对比度**。

### 2.3 跨区层级：**不对称连接**

| 方向 | 源 | 目标 | 我方规则 |
|---|---|---|---|
| 前馈 | 低区 **L2/3** | 高区 **L4** | `P` 的入边集合按"低→高"自动生成 |
| 反馈 | 高区 **L5/6** | 低区 **L1/L2/3** | 同上，但**目标阶段档不同**（L1 只做偏置） |
| 横向 | 同级 L2/3 | 同级 L2/3 | 侧向竞争（提供 top-k 稀疏） |
| 皮质下 | L5 | 基底节/丘脑 | 唯一的"出脑"口，对应鼠标/键盘两原语 |

## 3. 规格提案：耦合层（三层，全部逐元素）

```
① 丘脑增益层 Th（每单元一份增益档，与 01 的 g_u 合并）
   B'_u = 归( κ_th_u ⊙ 符(A_v_slow, B_v_fast) )      # κ 只缩放，不改路径

② 竞争选择层 Sel（对应基底节，逐元素 + top-k）
   活性_u = |B'_u|
   阈值 = 归( 均值(活性) + β · 标准差(活性) )         # β 为冻结常数
   Sel_u  = B'_u ⊙ 1[活性_u ≥ 阈值]                  # 胜者保留、败者归零
   全局抑制 = 归( γ_g · 总和(活性)/U )                # 广播回所有单元的减项

③ 回灌层 Fb（对应丘脑回灌 + 跨区反馈）
   入边由 02 决定（前馈/反馈/横向/皮质下四类），
   耦合权重 α_{u←v} = 归( 符(A_u, B_v) 的归一化强度 )   # ★ 实时由重合强度决定
```

**核心断言**：`α_{u←v}` **不是预设矩阵，而是每拍由 `符` 实时算出的重合强度**。
⇒ 这就是"**无总控**"的工程落实：系统里**不存在**一张"谁连谁、权重多少"的静态表。
⇒ 也同时满足"内生"：耦合强度是**长出来的**，不是写好的。

| 竞争 / top-k / 全局抑制 | `迭代` + 稀疏化 + `叠` | **直接复用**（`叠` 已可做全局汇总） |

**结论：本方案同样不需要任何新算子。**

## 5. 可失败判据（≥3，含反例臂）

| # | 判据 | 通过条件 | 反例臂（必须失败） |
|---|---|---|---|
| L1 | **无总控检验** | 删掉任何"总控/调度"假设后系统仍能工作；具体做法：**把任意一个单元的入边全部置零**，系统整体任务成功率下降但**不崩**（≥ 原水平的 60%） | **反例**：若某个单元的置零导致整体归零 ⇒ 说明存在事实上的单点总控，方案作废 |
| L2 | **竞争胜出可复现** | 两路同时输入时只有一路进入广播；给某一路加**微弱偏置**（Δ=0.01）可**可复现**地切换胜者 | **反例**：若胜者切换依赖**未声明的随机性**（两趟不一致）⇒ 判失败 |
| L3 | **环路必要性** | 把闭环切断（只跑单拍，不迭代）后，规则依赖子任务成功率显著下降（≥0.10） | **反例**：若单拍与多拍持平 ⇒ 环路是装饰，深度无收益 |
| L4 | **反馈必要性** | 去掉全部反馈边（L5/6→低区）后，迁移臂下降 ≥0.10 | **反例**：若去掉反馈**反而更好** ⇒ 前馈即可，深度应缩减 |
| L5 | **代价守恒** | 单元数从 12×6×3×6 增到 2 倍后，`计费(4096)/计费(1024) ∈ [3.95,4.05]` 仍成立 | **反例**：出现 n² 增长 ⇒ 违反 C1，作废 |
| L6 | **耦合不得是预设表** | 把 `α_{u←v}` 换成**同分布的固定随机矩阵**（同种子生成、不随拍更新）后，迁移成功率下降 ≥0.10 | **反例**：若固定矩阵表现一样好 ⇒ 所谓"动态耦合"没有价值，应删掉它而不是保留 |

> L6 是**本专家自设的反例臂**，用于否证我自己的核心主张。若 L6 失败，我撤回 §3 的 `α` 实时化设计。

## 6. 诚实边界

1. **环数≈皮层区数**这一现代观点在文献中仍在演进（经典 5 环 vs 现代"每个皮层区一条环"），我方按**后者**设计，属**前沿未定论的工程取用**，须标 `[未定论]`。
2. **直接/间接通路的分子层级细节不复刻**（D1/D2 受体、多巴胺调制曲线）；我方只保留**去抑制/抑制**这一对**净效应**。
3. **丘脑 FO/HO/matrix 三档是功能简化**；生物上矩阵投射的弥散结构与我方"全局逐元素偏置"不等同。
4. **没有"意识"含义**：竞争胜出/广播只作**工程可测事件**，不主张任何现象意识。
5. **不在本轮声称"复刻人脑"**；复刻对象是**连接统计与环路的动力学形态**。
