# 04 · 类脑深度架构师（我方能力核） —— 千层的工程形态与代价

> 依据（实读源码）：`meeting41/实施/算子_能力核.py`（七原语/`计费`）、`meeting49/实施/算子_两区室核.py`（第八算子「符」/`前向_双区室`）、`meeting49/实施/贯通_多核心.py`、`meeting50/实施/算子_规则表征.py`（`规则表征核(两区室核)`）。
> 铁律：C1 禁注意力 ｜ C10 禁外挂模型 ｜ C13 两趟逐位同 ｜ C14 不破既有（V4 16 臂 + 贯通 10 臂 + 规则 8 臂）。
> 锚定领域：我方七原语/符/provenance 的承载力与缺口；千层的工程实现形态。

## 1. 我对第 1 轮三大张力的表态

| 张力 | 我的表态 |
|---|---|
| **解剖 vs 原理** | **完全同意 01。** 但我要把"原理"钉得更死：**分区 = 一组连续参数（增益 / 时间档 / 区室配比 / provenance 语义 / 入边类别），不是一张"名字→功能"的表。** |
| **千层定义** | 千层 = **四轴张量积**（见 §3），满足 ≥1024 即达标。它不是 1000 个串行模块，也不是 1000 个矩阵。 |
| **深度是否等于堆层** | **不等于，且堆层会直接作废。** 若把 1296 个单元做成 1296 个独立矩阵串行，代价 U²，线性计费立刻破；并且那正是"复刻 Transformer 架构"的方向，触 C1 精神。 |

> **我反对 02 与 03 的具体一点**：两位都想加**新机制**（02 加动态耦合、03 加冻结槽位+重放），但**都没有给出代价量级**。
> 约束是硬性的：**任何新增都不得让 `计费(4096)/计费(1024)` 偏离 [3.95, 4.05]**。若做不到，就该改设计而不是改约束。我在 §4 给出全部三位的代价核算。

## 2. 我方承载力盘点（哪些够、哪些缺）

| 需要的能力 | 既有件 | 够不够 |
|---|---|---|
| 逐元素门控 / 增益 | 七原语 `门` | **够**（`门` 已是 `g⊙x+(1−g)⊙y`，取 `g≡1` 即纯增益） |
| 双线性重合 | 第八算子 `符` | **够**（A2 论文同形；A 或 B 为 0 ⇒ 无输出） |
| 非线性整合 | `软限(A−B)` | **够**（实测 0.894 ≫ 纯符 0.522） |
| 定点确定性 | `_归` / 2^-20 格 / `定点` | **够** |
| 全局汇总（竞争/抑制） | `叠` + `归` | **够** |
| 迭代收敛（吸引子） | `迭代` | **够** |
| 稀疏化 | 能力核内已有 | **够** |
| **单元参数容器**（g/τ/P/l/c/pro） | 无 | **缺**（数据结构，非算子） |
| **冻结槽位 / 回波 / 重放** | 无 | **缺**（状态容器 + 衰减，非算子） |
| **分区间入边拓扑** | 无 | **缺**（生成规则，非算子） |

**总结论：三位专家提出的全部机制，在我方原语下都只需新增"容器与规则"，不需要任何新算子。**
⇒ 这是千层方案最关键的可行性依据：**第八算子仍停在 8 个，不动。**

## 3. 千层规格：四轴张量

```
轴 A 功能分区 U_A ：12（可扩 24 / 36，同一模板复制）
轴 B 层内阶段 U_B ：6 （对应 01 的 L1..L6 功能档）
轴 C 区室     U_C ：3 （顶树-情境 / 胞体-感觉 / 基树-输出门）
轴 D 时间尺度 U_D ：6 （τ 档 ≈ 1 / 3 / 10 / 30 / 100 / 300 拍）

层单元数 U = U_A × U_B × U_C × U_D = 12 × 6 × 3 × 6 = 1296  ≥ 1024  ⇒ 千层达标
```

**12 个分区（标签只是标签，判据 M3 要求重命名后行为逐位不变）**：

| # | 角色标签 | 时间档 | 主要入边类别 | provenance 语义 |
|---|---|---|---|---|
| 01 | 快速接收（丘脑中继型） | τ1 | 外部 | 外源（低 pro） |
| 02 | 拓扑编码（初级感觉型） | τ1–2 | 01 | 外源 |
| 03 | 特征绑定（联合型） | τ2–3 | 02, 06 | 混合 |
| 04 | 增益调节（突显/岛叶型） | τ2 | 全域活性汇总 | 混合 |
| 05 | 背侧注意（顶叶型） | τ2 | 03, 04 | 外源偏多 |
| 06 | 额顶控制（控制型） | τ4–5 | 05, 07 | 自源偏多 |
| 07 | 默认模式（自我型） | τ5–6 | 06, 09 | **自源（高 pro）** |
| 08 | 情景编码（快学型） | τ2（快学） | 03 | 外源快变 |
| 09 | 补全联想（吸引子型） | τ3 | 08, 02 | 混合 |
| 10 | 竞争选择（基底节型） | τ2 | 06 自环 + 各分区 | 混合 |

**扩展规则（"千层"如何继续长）**：
- 分区轴：12 → 24 → 36（**按同一模板复制**，新增分区必须自带 provenance 语义与入边类别，**不得新增名字→功能表**）；
- 层档轴：6 → 8（加"跨区整合档"与"输出门控档"）；
- 时间档轴：6 → 8（加超慢档，用于巩固）；
- **四轴乘积自动扩到数千**；扩展是**乘性**的，**不是串行加层**。

## 4. 代价核算（三位专家的新增机制，逐条算）

**核心不变式**：单元**共享同一 D 维状态空间**。单元只持有 `g_u∈R^D` 与稀疏 `P_u∈R^{D×m}`（m≈3~4），**不持有 U×U 的耦合矩阵**。

| 项 | 量级 | 核算 |
|---|---|---|
| 参数 | `U·D·(1+m)` | 1296 × 256 × (1+4) ≈ **1.66 M** 浮点；定点 int32 约 **6.6 MB** |
| 每拍乘加 | `U·(m·D + D)` | 1296 × 5 × 256 ≈ **1.66 M** 乘加/拍 |
| 耦合（02 的 α 实时化） | `入边数 · D` 逐元素 | **不引入 U²**：α 由 `符` 逐元素算出，**零成对加权** |
| 抑制/竞争（02） | `D` 逐元素 + 一次全局汇总 | 全局汇总为 `D` 量级，**不是 U²** |
| 冻结槽位/回波（03） | `K · D` 存储 + `D` 衰减 | K=8 时 ≈ 8×256，**可忽略** |
| 重放（03） | 离线 `N_replay` 拍 × 每拍成本 | **离线，不进在线计费**；须在结果里如实分开报 |

⇒ **全部新增都是 O(U·D) 或 O(D)，无一含 U² 或 n²。** 线性计费可保。
⇒ 3080 级别可承载：1.66 M 参数 + 1.66 M 乘加/拍，属**轻量级**。

**与 C1 的关系**（必须写清楚）：

| 是否触碰 C1 | 判定 |
|---|---|
| 引入注意力 / QKV / softmax 全局加权 | **无** |
| 引入位置编码 | **无** |
| 引入预训练主干 | **无** |
| 阶段推进是"逐元素门控 + 定点迭代" | **是**（合规路径） |
| 深度由四轴**组合**而非串行堆叠 | **是**（合规路径，且非 Transformer 形态） |

## 6. 可失败判据（≥3，含反例臂）

| # | 判据 | 通过条件 | 反例臂（必须失败） |
|---|---|---|---|
| A1 | **线性计费守恒** | U 从 1296 增到 2592 后，`计费(4096)/计费(1024) ∈ [3.95, 4.05]`；且每拍成本 ≈ 2×（严格线性，非 4×） | **反例**：出现 U² 项 ⇒ 作废 |
| A2 | **两趟逐位确定性** | 同种子两遍：全部单元参数副作用后的指纹逐位相同 | — |
| A3 | **迁移臂（宪法强制）** | 训练集 A → 未见任务 B：成功率显著高于同参数量**无分区基线** | **反例**：打乱四轴索引映射后仍一样好 ⇒ 说明四轴没起作用 |
| A4 | **拆件回升臂** | 拆掉任一轴（如把 U_B 降到 1）后指标**先下降**，随继续经历**回升**到 ≥90% 原水平 | **反例**：拆后**永久不回升** ⇒ 该轴是焊死件，不是内生结构 |
| A5 | **名字无关** | 随机重命名 12 分区后行为逐位不变 | **反例**：重命名改变行为 ⇒ 存在名字→功能查表 |
| A6 | **既有回归不破** | V4 判据 16/16、贯通 10/10、规则 8 臂中 7 过（三因子臂维持 FAIL 为已知） | — |
| A7 | **反焊死件自扫** | 源码级：不存在 `dict[分区名] → 功能` 形式的查表 | — |

> **A4 是本次会议最重要的判据**：它把"千层"从"堆了多少层"转成"**这些层是不是长出来的**"。若 A4 失败，本方案退回"预设结构"，判为焊死件。

## 7. 诚实边界

1. **12 个分区角色是工程映射，不是解剖学**。它们是"参数模板"的标签，**不是**脑区的 1:1 对应；生物上不存在"12 个系统"这一官方数字。
2. **1296 是配置值，不是目标本身**。"千"这个数字没有魔力；关键是四轴**可组合、可分离、可迁移**（A3/A4 验证）。
3. **33080 可承载是估算**，须实测 `计费` 与显存后修正；本节数字在实测前**均为设计值**。
4. **τ 档的 6 个取值不是生物测量值**，是扫描候选；**必须扫描冻结**，不得类比定值。
5. **重放必须离线**，否则在线行为被污染（H3 反例臂已设）。
6. **不主张意识/人类级智能**；"自我""我"仅指可测的慢态保持与 provenance 归属度。
