## 1. 我对第 1 轮三大张力的表态

| 张力 | 我的表态 |
|---|---|
| **解剖 vs 原理** | **只复刻原理，不复刻名册。** 可以复刻的是：**层内连接的方向性统计**（谁给谁、给哪一层）与**区室的非线性整合**。不可以复刻的是"这是前额叶、那是海马"这种命名装配。判据：若把任意分区的**名字**随机重命名后系统行为逐位不变 ⇒ 说明名字没进入计算，方案合格。 |
| **千层定义** | 生物学皮层的"深度"**不是 1000 个串行层**——哺乳动物新皮层只有约 6 层（柱是**复制**出来的基本模块）。因此"千层"只能解释为**组合出来的层单元数**，而非串行深度。 |
| **深度是否等于堆层** | **不等于。** 皮层的算力来自"柱内多阶段 + 跨区层级 + 环路迭代"三者相乘；单纯堆叠串行层在生物上不存在，在工程上会立刻引入 n² 代价并触碰 C1 精神。 |

## 2. 可复刻的微回路事实（细分到细胞类型）

| 层 | 主要输入 | 主要输出 | 细胞类型 | 时间特性 | 我方抽象 |
|---|---|---|---|---|---|
| **L1** | 反馈（高层 L6、非特异性丘脑基质） | 顶树调制 | 稀疏神经元 | 最慢调制 | **顶层偏置通道**（增益项，非通路） |
| **L2/3** | L4、L2/3 侧向、反馈 L6 | **→ 高层 L4（前馈）**、→ L5 | 锥体 + PV/SST/VIP | 中 | **输出阶段**（向上一档前馈） |
| **L4** | **丘脑 FO 核（颗粒层接收）** | → L2/3 | 星形锥体 + PV | 快 | **接收阶段**（唯一快速入口） |
| **L5** | L2/3、L1 顶树 | **→ 皮质下（基底节/丘脑/脑干）** | 粗锥体（含顶树） | 中慢 | **行动出口**（两原语动作的发起源） |
| **L6** | L5、L4 | **→ 丘脑 + 跨区反馈（L6 是主要反馈路径）** | 锥体 | 慢 | **反馈阶段**（回灌下游） |
| 中间神经元 | 局部 | 局部 | PV(约 40%) / SST / VIP | 不同 | **抑制/增益机制**（逐元素，非独立模块） |

**连接统计要点**（可复刻的"图纸"）：

1. **前馈**：低区 **L2/3 → 高区 L4**；
2. **反馈**：高区 **L5/6 → 低区 L1/L2/3**，其中 **L6 是跨区/跨半球反馈的主导路径**；
3. **柱内**：L4 → L2/3 → L5，L6 回灌 L4/L5；**同性连接为主、少量跨层**（不是全连接）；
4. **柱结构**：**minicolumn 约 40–50 µm**，含 **约 80–100 个锥体细胞**，纵贯 L2–L6；**中间神经元占 15–25%**；多个 minicolumn（约 50–80）组成 column（直径 300–500 µm，数千神经元）；
5. **模块化**：整个新皮层由**同一个六层柱模块的复制**实现规模扩展——**这正是"组合出深度"这一路线的生物学背书**。

## 3. 规格提案：层单元（Layer Unit, LU）

**一个层单元不是一个模块，而是一组参数 + 一次前向阶段。**

```
LU u 的参数（全部为连续量，无名字→功能查表）：
  g_u   ∈ R^D      逐元素增益（对应 L1 顶树偏置 / 抑制强度）      —— 可塑、慢
  τ_u   ∈ R^+      时间常数档（从 6 档中取值，独立于索引）          —— 慢变量
  P_u   ∈ R^{D×m}  投影（m = 该单元的入边条数，稀疏）               —— 可塑、慢
  l_u   ∈ {1..6}   层内阶段档（决定它在柱内第几阶段参与）
  c_u   ∈ {1,2,3}  区室索引（顶树 / 胞体 / 基树-输出门）

前向（单拍，全部逐元素 + 定点）：
  B_u = 归( Σ_{v∈入(u)} 符(A_v_slow, B_v_fast) )        # 重合汇集：任一入边为0则该项为0
  A_u = 归( 软限(A_u_prev + λ_u · (g_u ⊙ B_u) − 抑制_u) )   # 慢态更新（自带衰减）
  B_u_fast = 归( g_u ⊙ 软限(P_u @ φ_in) )               # 快态（当前观测投影）
  抑制_u = 归( 初_k( |B_u| ) )                          # 竞争性归一（对应 PV 中间神经元）
  输出_u = 归( 符(A_u, B_u_fast) )                      # 双线性符合：缺一即无输出
```

关键设计选择（逐条给理由）：

| 选择 | 理由 |
|---|---|
| **单元间共享同一 D 维状态空间**，单元只是"投影 + 增益 + 时间常数" | 若每个单元自持独立矩阵，代价立刻变成 O(U²D²)；共享后为 **O(U·D)**，保住 `计费(4096)/计费(1024)≈4.0` |
| **抑制 = 逐元素竞争归一 + top-k 稀疏**，不做"抑制性模块" | 对应 PV/SST/VIP 是**增益调制**而非独立通路；做成模块即等于新增总控 |
| **六层档 = 同一状态上的六次阶段推进**，不是六个矩阵 | 对应"柱内多阶段"；生物上是同一柱，不是六个器官 |
| **三区室固定为顶树/胞体/基树-输出门** | 与 meeting47 已验证的两区室同形 + 一个输出门（对应 L5 出口）；**不新增算子** |

## 4. 与既有原语的映射

| 本方案需要 | 既有件 | 结论 |
|---|---|---|
| 逐元素增益、门控、定点归一 | 七原语 `门/叠/归` | **直接复用** |
| 双线性符合 `符(A,B)` | 第八算子（meeting49） | **直接复用**，不再新增 |
| 软限慢态更新 | `软限`（能力核） | **直接复用** |
| 竞争 / top-k 稀疏 | `迭代` + 现有稀疏化 | **直接复用**（`迭代` 已提供逐次收敛） |
| 三区室 | 现有 A/B 两区室 | **需扩为 3**：新增"基树-输出门"= 对 `输出_u` 再做一次门控。**不是新算子**，是同一 `门` 的第三次调用 |
| 单元参数表（g/τ/P/l/c） | 无 | **必须新增**（数据结构，不是算子） |

**结论：本方案不需要任何新算子。** 需要新增的只是一个**单元参数容器**。

## 5. 可失败判据（≥3，含反例臂）

| # | 判据 | 通过条件 | 反例臂（必须失败） |
|---|---|---|---|
| M1 | **层档必要性** | 6 档柱 vs 1 档（只有 L4+L5）在同一任务上的迁移成功率差 ≥ 0.10 | **打乱层档索引顺序**（l_u 随机置换）后，成功率**不得**提升 ⇒ 证明不是索引顺序在起作用 |
| M2 | **单元可分离性** | 消融**单轴**（把某单元的 `g_u` 冻结为常数）造成**可分离**退化：只在该单元负责的子任务上掉、其他子任务几乎不动 | 若消融造成**全体同幅**退化 ⇒ 说明单元没有分工，只是一个大标量 |
| M3 | **名字无关性** | 随机重命名所有分区后，两趟运行**逐位相同** | 若重命名改变了行为 ⇒ 名字进了计算，判为焊死件 |
| M4 | **抑制必要性** | 去掉竞争归一（抑制_u=0）后，单元激活的稀疏度显著下降且噪声检出变差 | 若去掉后指标不变 ⇒ 抑制是装饰 |
| M5 | **C1/确定性** | 禁词自扫 0 命中；导入白名单无越界；两趟定点逐位同 | — |

## 6. 诚实边界

1. **六层是功能档，不是解剖层**。生物上 L1–L6 各有特异细胞类型与电导，我方只有 6 个**阶段档**；这是**降维**，不可宣称等同。
2. **抑制做不成生物等效**。PV/SST/VIP 三类的分工（前馈抑制 vs 反馈抑制 vs 去抑制）我方用**一个逐元素竞争式**近似，**做不到**类别特异。
3. **柱数（50–80 minicolumn/column）与神经元数（80–100/minicolumn）不被复刻**。我方的"单元"是**功能单元**，不存在与真实柱的 1:1 对应。
4. **minicolumn 间距 30–80 µm、中间神经元占比 15–25% 这类数字不进入实现**。它们只用于说明"柱是复制模块"这一**结构性结论**，不作参数。
5. 本方案**不主张意识/人类级智能**；仅提供可消融、可复现的机理级加件。
