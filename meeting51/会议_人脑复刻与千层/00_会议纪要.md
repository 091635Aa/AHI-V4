# 第 1 轮 · 立场轮：复刻的边界与"千层"的定义

## 各方发言（摘要）

- **01**：可复刻的是**层内连接的方向性统计**与**区室非线性整合**，不可复刻的是"区域名册"。新皮层只有约 6 层，柱是**复制模块**（minicolumn 40–50 µm / 80–100 锥体，中间神经元 15–25%）⇒ "千层"只能是**组合出来的单元数**。
- **02**：更该复刻的是**连接统计**：前馈 低区 L2/3 → 高区 L4；反馈 高区 L5/6 → 低区 L1/L2/3，且 **L6 是跨区反馈主导路径**。丘脑是**中继+增益**，基底节是**竞争选择**——**都不是路由器**。
- **03**：没有时间维度就没有深度。缺少**离线巩固**时，"深度"退化成一个更宽的网络。
- **04**：我方承载已足：`门/符/软限/迭代/_归` 全部现成；四位提出的机制都只需新增**容器与规则**，**不需新算子**（第八算子仍停在 8 个）。
- **05**：把"复刻人脑"改述成**可证伪命题**，否则它是修辞；并要求四轴**每一条都被单独消融**。

## 交锋（4 次）

| 谁 → 谁 | 交锋内容 | 结果 |
|---|---|---|
| **02 → 01** | "01 把微回路讲透了，但**没回答区与区凭什么耦合**。若耦合是预设的，那就是**隐式总控表**。" | 01 **接受**，在第 2 轮补出**入边槽位**接口；耦合交给 02 |
| **03 → 02** | "02 把环路轮数当深度来源，**只解释同一时刻的迭代**；'想到一半切走再切回'需要**离线保持**。" | 02 **接受**，在环路上**挂一层非激活保持**（转让 03 定义） |
| **04 → 02,03** | "两位都加机制，但**都没给代价量级**；硬约束是计费比必须仍在 [3.95,4.05]。" | 02/03 **补出代价核算**；02 的方案**改为逐元素**，不引入 U² |
| **05 → 01,02,03** | "'复刻'不可证伪；且你们的 18 条判据中**4 条互为同义**，判据在被稀释。" | 合并为 **20 臂**（见 05 §3），反例臂单列 |

## 裁决 1（五专家一致）

**复刻对象 = 计算原理 + 连接统计，不是区域名册。**
具体四条：

| 复刻 | 不复刻 |
|---|---|
| ① 柱内**多阶段**（层档） | 层数=6 的解剖命名 |
| ② **区室化非线性整合**（顶树/胞体/输出门） | 具体细胞类型的电导细节 |
| ③ **多时间尺度**（快慢系统分工） | 精确的 τ 生物测量值 |
| ④ **重叠 + 稀疏**双编码（模式合并/分离） | minicolumn 间距、神经元数等数字 |

**判据落实**：甲4 名字无关性 —— 随机重命名 12 个分区后，行为必须**逐位不变**。

## 裁决 2（五专家一致）

**"千层"定义为四轴张量积，不是串行 1000 层。**

```
U = 轴A 功能分区(12) × 轴B 层内阶段(6) × 轴C 区室(3) × 轴D 时间尺度(6)
  = 12 × 6 × 3 × 6 = 1296 ≥ 1024  ⇒ 千层达标
```

**必要条件**：四轴**每一条**都须能被单独消融并产生**可分离**损失（否则该轴是装饰，删除）。

# 第 2 轮 · 微观轮：一个层单元内部长什么样

## 各方发言（摘要）

- **01**：给出柱内六阶段的功能档（L4 接收 → L2/3 输出 → L5 出口 → L6 反馈；L1 只做偏置）。单元**不是模块**，是"一组参数 + 一次前向阶段"。
- **02**：柱内是**同性连接为主 + 少量跨层**，不是全连接 ⇒ 我方 `P_u` 必须**稀疏**（m≈3~4）。
- **03**：局部可塑必须带**第三因子**（钙/奖赏式），否则学不动。
- **04**：映射确认：前向 = 逐元素门控 + `软限` + 定点；**区室扩到 3 只需第三次调用 `门`**，不是新算子。
- **05**：判据须能**消融单轴**且损失可分离。

## 交锋（3 次）

| 谁 → 谁 | 交锋内容 | 结果 |
|---|---|---|
| **05 → 04** | "'只需第三次调用门'——请用**计费**证明它不引入 U²。" | 04 给出 O(U·D) 核算（1296×256×5 ≈ 1.66 M 乘加/拍） |
| **03 → 01** | "六阶段没有**时间**，快慢不分；请把 τ 留成接口。" | 01 **接受**，`τ_u` 独立成轴 D（交 03 定档） |
| **01 → 03** | "你要的稀疏/正交化，具体接在哪？" | 03 指明：接在 01 的**抑制通道**上（DG 式稀疏） |

## 裁决 3

**层单元 = 参数组 + 一次阶段推进；三区室（顶树/胞体/输出门）；层档 6；不新增算子。**

```
参数：g_u(增益, D) / τ_u(时间档) / P_u(稀疏投影, D×m) / l_u(层档∈1..6) / c_u(区室∈1..3)
前向：B_u = 归(Σ_{v∈入(u)} 符(A_v, B_v))       # 重合汇集，任一入边为 0 则该 项为 0
      A_u = 归(软限(A_u + λ_u·(g_u⊙B_u) − 抑制_u))
      抑制_u = 归(初_k(|B_u|))                  # 竞争归一（对应抑制性中间神经元）
      输出_u = 归(符(A_u, B_u_快))               # 双线性符合：缺一即无输出
```

# 第 3 轮 · 环路轮：单元之间怎么连（无总控）

## 各方发言（摘要）

- **02**：给出四类边（前馈/反馈/横向/皮质下）；丘脑 = **增益档**（FO 快 / HO 慢 / matrix 全局偏置）；基底节 = **竞争选择**（直接通路去抑制 vs 间接通路加抑制 ⇒ WTA + 全局抑制）。经典 5 环，**现代观点环数 ≈ 投射到纹状体的皮层区数** `[未定论]`。
  **核心断言：耦合权 `α_{u←v}` 每拍由 `符` 实时算出，不是预设矩阵。**
- **01**：前馈/反馈**不对称**，目标层档不同。
- **03**：环带来时间连续性。
- **04**：确认 02 的实时耦合**不引入 U²**（逐元素，零成对加权）。
- **05**：判据必须能**否证"无总控"**：单点置零不得让系统崩。

## 交锋（3 次）

| 谁 → 谁 | 交锋内容 | 结果 |
|---|---|---|
| **05 → 02** | "你说耦合是实时的，**但如果固定矩阵一样好呢**？" | 02 **自设反例臂 乙5**：固定同分布矩阵后迁移须降 ≥0.10，否则**自己撤回** |
| **01 → 02** | "丘脑'增益档'与我的 `g_u` 重复了。" | 合并：`κ_th_u` 并入 `g_u`，不另建层 |
| **04 → 02** | "闭环要跑几拍？跑多了计费会摊在在线账上。" | 02 限定环轮数为**冻结常数**，重放另走离线账 |

## 裁决 4

**不设总控、不设路由器。**
- **丘脑层** = 增益门（只缩放，不改路径）；
- **基底节层** = 竞争选择（top-k + 全局抑制），**选择的"内容"来自皮层竞争，基底节只提供"对比度"**；
- **耦合权 `α_{u←v}` 由 `符` 每拍实时算出** ⇒ 系统里**不存在**"谁连谁、权重多少"的静态表。

**落实手段**：乙1 无总控检验（任一单元入边置零，整体须 ≥原 60% 而不崩）。

# 第 4 轮 · 时间轮：多尺度、巩固与"我"的连续性

## 各方发言（摘要）

- **03**：给出**三档记忆**（回波 / 冻结槽位 / 慢态 A）+ **重放**（离线巩固）。引用补足学习系统：**快系统必须够快才能单次学会，慢系统必须够慢才能不遗忘**；重放把情景固化成统计（对应离线 RL / Dyna）。
- **01**：τ 分档建议（L4/L2-3 快、L5/6 中、慢态 A 最高档）。
- **02**：环路轮数接口可作为重放载体。
- **04**：**可塑率由 provenance 调制**（`η_u = η_0·(1−pro_u)`）—— 这同时解决[研究报告](../../研究报告_V4承重缺口_证据与路线_20261017.md) §六提出的"把漂移误判为噪声"问题。
- **05**：全部新增抽样点都必须**声明种子**；参数（λ_e/K/ζ/β/γ_g）**必须扫描冻结**。

## 交锋（3 次）

| 谁 → 谁 | 交锋内容 | 结果 |
|---|---|---|
| **04 → 03** | "重放接输出会污染在线行为。" | 03 **接受**，并**主动加反例臂 丙3**（重放接输出 ⇒ 在线须下降） |
| **05 → 03** | "冻结槽位参数不能靠类比定；活动静默本身有竞争性解释。" | 03 **接受**，参数全部**扫描冻结**，并标 `[竞争性解释]` |
| **03 → 04** | "provenance 调制可塑率是你的推论，有证据吗？" | 04 承认**无直接实验支持**，标为**工程推论**（落实宪法第一条） |

## 裁决 5

**三档记忆 + 离线重放 + provenance 参考系。**

| 档 | 时间尺度 | 机制 | 是否参与广播 |
|---|---|---|---|
| 回波 | 毫秒–秒 | `痕 ← λ_e·痕 + 激活`，λ_e<1 | 否（低于阈值） |
| 冻结槽位 | 秒–分 | `槽 ← 0.999·槽 + 快照`，容量 K，线索重合 > ζ 解冻 | 否（冻结期） |
| 慢态 A | 跨试次 | 见裁决 3 | 是 |
| 重放 | 离线 | 无外部输入时按优先级重跑主循环，**不接输出** | 否 |

**核心参考系**：`η_u = η_0·(1 − pro_u)` —— 自源经历形成的单元**低可塑、承重**；其余维度**允许漂移**。

**C1 红线（03 提出，全会采纳）**：记忆钥匙**不得**实现为 softmax 一步检索（与注意力**数学同构**）；必须走**迭代补全 + 稀疏存储 + 阈值门控**，并做**源码级 + 更新式级双重审查**（己2）。

# 第 5 轮 · 深度轮：千层规格、代价与判据

## 各方发言（摘要）

- **04**：给出四轴配置 **12×6×3×6 = 1296**，以及扩展规则（分区 12→24→36，层档 6→8，时间档 6→8，**乘性扩展**）。代价：约 **1.66 M 参数 / 1.66 M 乘加每拍**，定点约 6.6 MB，**不含 U²**。
- **01**：生物学皮层不到 10 层 ⇒ 深度必须是**组合**的。
- **02**：深度收益来自**环路迭代轮数**，不来自层数堆叠。
- **03**：没有巩固，深度无意义。
- **05**：合并判据为 **20 臂**，并把 **戊2 拆件回升臂**定为**总闸门**。

## 交锋（2 次）

| 谁 → 谁 | 交锋内容 | 结果 |
|---|---|---|
| **05 → 04** | "'1296' 是不是又一个拍脑袋的数字？" | 04 接受：**"千"无魔力**，关键是四轴**可组合/可分离/可迁移**；并加 **戊2** 验证 |
| **04 → 05** | "20 臂里有 4 条我无法在单次实测中做完（拆件回升）。" | 05 **接受**，改为"分批采样"，并允许如实记 **"未测"** |

## 裁决 6（本会最高裁决）

1. **千层 = 四轴张量积**（12×6×3×6 = 1296），**不是串行堆层**；
2. **零新算子**：`算子表` 仍为 **8**；
3. **零总控、零路由器**：耦合由 `符` 实时生成；
4. **全部新增旁挂、默认关**：既有 16/10/8 臂口径**一字不改**；
5. **实施必须步进**（步 0→步 8），每步单跑；
6. **总闸门 = 戊2 拆件回升臂**：拆任一轴后指标若不能**先降后回升**，则该轴是焊死件，**就地回退**，不得继续堆。

1. **本会议零实测数字**。全部条件与阈值均为**设计值**；实测前不得写成"已完成"。

3. **12 分区是工程映射，不是解剖学**。生物上不存在"12 个系统"这一官方数字；标签仅标签。
4. **记忆钥匙有 C1 同构风险**（现代 Hopfield 一步更新式与注意力同构）；必须走迭代补全并做双重审查。
5. **冻结槽位参数不允许类比定值**（活动静默存在竞争性解释），必须扫描冻结。
6. **provenance 调制可塑率是工程推论**（落实宪法第一条），无直接实验支持。
7. **重放必须离线**；环数≈皮层区数的观点 `[未定论]`。
8. **不主张意识/现象意识/人类级智能**；"自我""我"仅指可测的慢态保持与归属度。
