# meeting51 · 会议_人脑复刻与千层 · 共同简报

> 日期：2026-10-17 ｜ 主持人：主 Agent ｜ 召会人：所有者
> **最高依据**：[`初心_宪法.md`](../../初心_宪法.md)（造的是**自我意识体**；参考 Transformer **最终效果**、**不复刻其架构**；一切"变聪明"必须**内生**；判据必须含**迁移臂**）
> **铁律**：C1 禁 Transformer/注意力 ｜ C9 禁 OCR ｜ C10 禁外挂模型当器官 ｜ C13 确定性可复现 ｜ C14 不破既有
> **本轮纪律**：只出规格与判据，**不改任何既有文件**；实施件留待所有者批准后另开。

## 0. 所有者的原始陈述（逐条引用，不得曲解）

1. （总要求）"和人脑工作方式给它**复刻**过去，**对应一些模块**，然后再做**千层层**。"
2. （流程）"老规矩，**召开专家开会**，N 个专家进行开会。大概**召开 5 个专家**，召开 **N 轮会议**。"
3. （细分）"每轮会议 **5 个专家不同的脑部**，巴拉的，给它**细分到极致程度**。"
4. （互连）"专家之间**互相连接**，**你来决定**。"

> **主持人的诚实裁定**：所有者给的是**目标与流程**（复刻人脑工作方式 → 对应模块 → 千层；5 专家 × N 轮；细分到极致；互连由我定），
> 但**没有给判据**。"怎么算复刻成功""千层到底指什么"这两件事**必须由专家推导**，不得回头追问所有者。
> 同时，所有者第 1 条与宪法之间存在**显性张力**：宪法明令"破坏既有"的焊死件之一就是**解剖映射表**。此张力列入第 1 轮**首要裁决事项**。

## 1. 硬约束清单（违反即方案作废）

| # | 约束 | 含义 |
|---|---|---|
| C1 | 禁 Transformer | 无注意力/QKV/softmax 全局加权/位置编码/预训练主干；**深度堆叠也不得引入注意力** |
| C9 | 禁 OCR | 文字不得从像素"认"出来 |
| C10 | 禁外挂模型当器官 | 不得用外部 RL/预训练/检测模型承担任何"分区"职能 |
| C13 | 确定性可复现 | 随机只来自 `default_rng(显式种子)`；数值走 2^-20 定点格；两趟逐位同 |
| C14 | 不破既有 | V4 判据 16 臂、贯通判据 10 臂、meeting50 规则判据 8 臂**一律不许失效** |
| **新C** | **反焊死件（宪法第一条）** | **"分区名 → 功能"的查表是病**；分区必须以**连续参数 + provenance** 定义，不以名字定义 |
| **新C** | **内生性（宪法第三条）** | 深度带来的能力**必须从经历里长出来**；判据必须含**迁移臂**与**拆件后回升臂** |
| **新C** | **代价守恒** | 单元数增加**不得**引入 n² 计费；`计费(4096)/计费(1024) ∈ [3.95, 4.05]` 必须继续成立 |

## 2. 会被直接作废的三条路线（**登记在案，不许重提**）

| 路线 | 为什么作废 |
|---|---|
| ✗ **按脑叶/核团逐一建模块**（"这里建前额叶，那里建海马"） | 宪法第一条：解剖映射表＝焊死件；人脑分区是发育涌现，不是按图纸装配 |
| ✗ **每个分区一个独立分类器再投票/融合** | 交接文档已否决："统一输入空间 + 单一主循环 + 空间内重合"，不是七个独立分类器 |
| ✗ **给分区配路由器或总控模块** | 路由器是离散分拣瓶颈；文献中突显网络是**增益调节**不是分发；总控模块＝预设核心源＝焊死件 |

> 附加红线：**"千层"不得靠"堆 1000 个串行模块"实现**。那既违背"不复刻 Transformer 架构"，也必然引入 n² 代价。

## 4. 五轮会议议程（N = 5，由主持人决定）

| 轮 | 题目 | 必须产出的裁决 |
|---|---|---|
| **第 1 轮** | **立场轮：复刻的边界与"千层"的定义** | 复刻对象到底是"区域名册"还是"计算原理+连接统计"？"千层"的可测定义是什么？ |
| **第 2 轮** | **微观轮：一个层单元内部长什么样** | 层内阶段数、区室数、抑制机制、可塑规则；是否需新算子 |
| **第 3 轮** | **环路轮：单元之间怎么连（无总控）** | 前馈/反馈不对称、丘脑与基底节的作用、耦合由什么决定；路由/总控禁令如何落实 |
| **第 4 轮** | **时间轮：多尺度、巩固与自我** | 时间常数分层、冻结槽位、重放、provenance 与核心参考系 |
| **第 5 轮** | **深度轮：千层规格、代价与判据** | 千层配置、参数与计费估算、8 臂判据 + 反例臂、实施顺序 |

**互连拓扑（每轮相同，不得私下互看对方文稿）**：

```
        主问环：  01 ──▶ 02 ──▶ 03 ──▶ 04 ──▶ 05 ──▶ 01
        交叉驳斥边： 01 ↔ 04   02 ↔ 05   03 ↔ 01
```

规则：
1. 主问环上，**后一位必须回应前一位的具体主张**（点名其论断并给出赞成/反对）；
2. 交叉驳斥边上，**必须提出一条可被实测证伪的反例**；
3. 任何"做不到"必须明说，不得用模糊措辞掩盖；
4. 全部裁决以**表格 + 可测阈值**落盘，无阈值不算裁决。

## 6. 每位专家必须交付的形式（**否则不算交付**）

1. **一个可实现的规格**（不是方向、不是口号）：含数据结构、更新式、代价量级；
2. **与既有原语的映射**：哪些直接复用、哪些必须新增；新增必须说明"为什么非加不可"；
3. **可失败判据 ≥3 条**（附量化门槛，含至少 1 条反例臂）；
4. **诚实边界**：哪部分做不到、天花板在哪；
5. **对他人的接口要求**：谁给谁什么；
6. **对第 1 轮三大张力（解剖 vs 原理、千层定义、深度是否等于堆层）的明确表态**。

- 若某位专家的方案靠"偷偷上模型/Attention/路由器/总控"绕过——**该方案当场作废**。
