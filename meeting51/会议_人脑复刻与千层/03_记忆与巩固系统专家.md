## 1. 我对第 1 轮三大张力的表态

| 张力 | 我的表态 |
|---|---|
| **解剖 vs 原理** | 可复刻的是 **"快系统 + 慢系统"这对分工原理**，而不是"海马"这个名字。判据：只要满足"一个快稀疏单次编码 + 一个慢重叠统计固化"，叫什么都行。 |
| **千层定义** | **没有时间维度就没有深度。** 千层若只是一次前向的 1296 个阶段，那它只是一个更宽的网络；**深度必须包含"同一批单元在不同时间尺度上被反复调用"**。 |
| **深度是否等于堆层** | **不等于，而且比 01/02 更反对**：**没有巩固的深度等于无意义的深度**。生物上"深度"的收益大半来自**离线重放把情景固化成统计**，而不是层数本身。 |

> **我反对 02 的一点**：02 把"环路轮数"当深度来源，**只解释了同一时刻的迭代**。但"想到一半切走再切回"这类现象**不是环形迭代能解释的**——它需要**离线保持**（活动静默）。因此我要求 02 的环路上**挂一层非激活保持**。

## 2. 可复刻的记忆事实（细分到亚区）

### 2.1 快系统（海马）：稀疏、单次、可分离

| 亚区/通路 | 生物事实 | 我方抽象 |
|---|---|---|
| **内嗅 LII → DG** | 高维扩张、**极度稀疏** | **扩维 + top-k 稀疏化**（对应 01 的抑制通道） |
| **DG（齿状回）** | **模式分离**：相似输入 → 不同表征，防混淆 | **正交化**：把相邻输入推远（逐元素去相关） |
| **CA3 循环** | **吸引子**：**模式完成**，从残缺线索补全整段 | **迭代补全**：用 `迭代` 收敛到记忆盆地（对应"记忆钥匙"） |
| **CA3 → CA1** | 与 **EC LIII 直通**（通路比较） | **两路对比**：预测 vs 直送，差值即"意外" |
| **CA1 → 下托/皮层** | 输出回灌新皮层 | **回灌慢系统** |
| **SWR（尖波涟漪）** | **时间压缩的重放**，与皮层活动协同 | **离线迭代**：不接输出、只跑主循环 |

### 2.2 慢系统（新皮层）：重叠、统计、可泛化

| 特征 | 生物事实 | 我方抽象 |
|---|---|---|
| 编码 | **重叠表征**（模式合并） | 不稀疏化，保留逐元素叠加 |
| 学习率 | **很慢** | 慢时间常数档（τ 最高档） |
| 功能 | 抽取**统计规律**并泛化 | 对应 meeting50 的后继表征 M（学的是转移统计） |
| 弱点 | **灾难性遗忘** | 靠**重放 + provenance 低可塑核**保护 |

### 2.3 CLS 的核心张力（我要解决的）

补足学习系统的本质是：**快系统必须够快才能单次学会，慢系统必须够慢才能不遗忘**——两者**不可兼得**，所以必须**分开存在，靠重放耦合**。
⇒ 我方的两区室（A 慢 / B 快）**已经天然对应这一对**，但**缺"重放"这条耦合通路**。这是本轮我要补的。

## 3. 规格提案：三档记忆 + 重放 + 参考系

```
① 回波（毫秒–秒）：  痕_u ← λ_e · 痕_u + 广播激活     (λ_e<1，泄漏衰减)
                    低于广播阈值 ⇒ 不参与竞争与读出；只提供"刚刚想到"的连续性
② 冻结槽位（秒–分）：槽_k ← 0.999 · 槽_k + 广播快照     (极低衰减，容量上限 K)
                    冻结期**不参与广播**；线索与槽_k 的符重合度 > ζ ⇒ 解冻注入竞争
                    淘汰规则：优先级 = w_recent · 最近使用 + w_match · 重合强度
③ 慢态 A（跨试次）：  A_u ← 归(软限(A_u + 步长·(功 − 抑制)))       (见 01 规格)
④ 重放（离线巩固）：  在无外部输入时，按优先级抽 冻结槽位/回波，重跑主循环 N_replay 拍，
                    **不接输出**；重放中只更新慢系统的 W（低可塑率）
⑤ 核心参考系：      pro_u ∈ [0,1] = 该单元来自"自源经历"的累积占比
                    可塑率 η_u = η_0 · (1 − pro_u)              # 自源经验 ⇒ 低可塑，承重
                    ⇒ 任务相关子空间由 pro_u 高的单元承担，允许漂移的是 pro_u 低的单元
```

**为什么必须这样分**（逐条给理由）：

| 设计 | 理由 |
|---|---|
| 三档记忆**都必须存在**，不能合并 | 回波/冻结/慢态的时间尺度相差 3 个数量级；合并会导致"要么太短记不住、要么太长下不来" |
| 冻结槽位**不参与广播** | 这是交接文档已定的语义：否则"冻结"退化成"高激活"，会污染当前读出 |
| 重放**不接输出** | 生物重放发生在离线（睡眠/静息）；接输出会污染在线行为，且违反"巩固是离线过程" |
| **可塑率由 provenance 调制** | 直接落实宪法第一条"自源经历塑我"；同时**解决研究报告 §六提出的"漂移无结构"误判**：任务相关维度低漂移、其余维度允许漂移 |

## 4. 与既有原语的映射

| 需要 | 既有件 | 结论 |
|---|---|---|
| 记忆钥匙（线索→补全） | `符` 做重合检测 + `迭代` 做吸引子补全 | **直接复用**（不新增算子；这正是交接文档 §2.7 的既定方案） |
| provenance 门控 | `桥_自我态_自模型.py` / `内核_自我回路.py` | **直接复用**（已实测：默认拒绝外源塑造为真） |
| 稀疏化/正交化 | 01 的抑制通道 | **复用** |
| 重放循环 | 既有主循环（不接输出） | **复用** |
| 冻结槽位 / 回波 | 无 | **必须新增**：只是两个**状态容器 + 衰减系数**，**不是算子** |

> ⚠️ **C1 红线提醒**：记忆钥匙**不得**实现为"对存储模式做 softmax 加权求和后一步检索"。现代 Hopfield 网络的一步更新式与注意力在数学上同构。**必须**走"能量下降的迭代补全 + 稀疏分布式存储 + 阈值门控"。**动工前须做同构预检。**

## 5. 可失败判据（≥3，含反例臂）

| # | 判据 | 通过条件 | 反例臂（必须失败） |
|---|---|---|---|
| H1 | **残缺线索召回** | 线索损坏比例从 0 扫到 0.6，召回率呈**可复现的相变**（先平台后陡降），而非线性缓降 | **反例**：把 CA3 循环切断（只做单次投影）后，相变消失、全程低平 |
| H2 | **冻结-解冻** | 延迟 N 步后凭线索恢复的准确率显著高于**无槽位对照**（≥0.15） | **反例**：把冻结改为"高激活保持"（λ→1）后，当前读出被污染，在线任务下降 |
| H3 | **重放增益** | 有重放 vs 无重放的**迁移臂**成功率差 ≥0.10 | **反例**：把重放接进输出（不休眠）后，在线性能**下降** ⇒ 证明巩固必须离线 |
| H4 | **参考系稳定化** | 反复活跃的"核心单元"（pro_u 高）的表征漂移显著低于 pro_u 低的单元 | **反例**：全局统一压制漂移（所有单元同 η）后，**适应性与稳定性同时下降** |
| H5 | **不参与广播** | 干预验证：冻结期内改动槽内容，当前读出**逐位不变** | **反例**：改动槽内容导致读出改变 ⇒ 槽在参与广播，"冻结"名不副实 |
| H6 | **C1 同构预检** | 源码扫描 + 更新式审查：无 `softmax(QK^T)` 形式的全局注意力 | **反例**：出现一步 softmax 检索式 ⇒ 触碰 C1，作废 |

## 6. 诚实边界

1. **海马亚区不是模块**。DG/CA3/CA1 在我方只是**四种逐元素操作**（稀疏、扩维、迭代、比较），不存在"海马模块"这个器官。
2. **SWR 时间压缩不复刻**。生物学上重放可压缩 10–20 倍；我方用"少拍重放"逼近，**不等同**。
3. **"活动静默工作记忆"存在竞争性解释**（也有工作认为持续振荡服务于注意优先级而非维持）。因此冻结槽位的**参数（λ、K、ζ）不允许类比定值，必须扫描冻结**。
4. **provenance 调制可塑率是本专家的工程推论**，尚无直接实验支持；它落实的是宪法第一条的归属语义，**不是**生物学事实。
5. 重放的"优先级抽样"是启发式；不主张恢复生物的抽样分布。
6. **不主张意识/人类级智能**；"连续性""我是谁"仅作**可测的保持时长与归属度**，不作主观体验主张。
