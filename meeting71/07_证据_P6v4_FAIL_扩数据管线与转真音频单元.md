## 2. 由此产生的路线判断（诚实）

- **继续加大训练投入（v5: 全 38 h 切完 ≈ 15 h 数据 + 更久训练）**：可能把 CER 推到 0.7 左右，但**离 ≤0.35 仍远**，且成本以天计；不作为下一轮首选。
- **回到「真音频单元」**：这条线之前失败是因为**单元边界/标签错**（`01` §3 已证），但现在我们已经有：
  - 声学切分单元（能量核+谷）+ **修正偏移 + DP 单调对齐后的正确标签**（`01` §4：样本 117 标签逐字吻合、三元组不一致仅 10/279）；
  - 真实音频片段（不是合成控制）。
  之前 **打乱对照** 用的是「器官合成移植控制」（CER 1.0），**没有测过「真音频单元的 PSOLA 拼接」**。经典拼接式 TTS 正是这么做的：选真单元 → PSOLA 调音高/时长 → 交叉淡化拼接。这是下一个可验证的假设。

## 3. 下一轮（v5 预注册要点，先写后跑）

**真音频单元拼接器**：
1. 单元库：346 条录音按声学切分 + DP 标签（复用 meeting71 已有的库构建逻辑，扩展到 346 条）；
2. 选单元：文本 → (声母,韵母,调) → 同音节候选（按时长接近、F0 中位接近、浊音比排序）；
3. 韵律：句内 F0 目标轮廓（基线 300 Hz + 句末下降）→ **TD-PSOLA** 把每个单元音高/时长拉到目标；
4. 拼接：**30–50 ms 波形交叉淡化**（不拼控制、不过器官）；
5. 判据：主句 CER ≤0.60 有信号 / ≤0.40 可续 / >0.60 判死真音频单元路线；Whisper 非空、四句、确定性两趟。

若 v5 ≤0.60：说明「不训练、真音频拼接」可行，再往听审+音色走；若仍失败：**唯一剩余是「继续训练到 15 h 数据 + 数天算力」**，登记后交所有者决定。
