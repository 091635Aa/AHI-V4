# meeting71 · 01 证据：特征点检索移植 v1–v4 —— **重建通了，标签卡住**

> 2026-10-22 11:07–11:35 ｜ 依据 `00_指令.md`（所有者 A+B + 检索式特征复制思路）
> 件：`实施/音节控制移植_v1.py`、`音节控制移植_v2.py`、`声学单元移植_v3.py`、`声学单元移植_v4.py`

## 0. 一句话

**把「真人语音」切成声学单元、按顺序把控制特征移植回器官，能重建出可懂的同一段语音（自检 117 条：ASR 转写连贯可读）。——说明所有者「检索特征点、复制特征」的思路在重建层面成立。**
**但「文本 → 选单元」这一步失败了（CER≈1.0、空转写），根因是单元标签对齐（哪个声学单元对应哪个字），不是嗓子、不是合成。**

## 1. 四个版本的读数（4 句 arbitrary text）

| 版本 | 做法 | 均值 CER | 判 |
|---|---|---|---|
| v1 | 直接插值 24 阶 LPC 系数 → 全极点 | **1.023** | 失败（滤波器失稳） |
| v2 | 对数幅度包络插值（ASR 帧边界单元） | **1.174** | 失败 |
| v3 | 声学切分（能量核+谷）定界 + 信封插值 | **1.000** | 失败 |
| v4 | 声学切分 + **自相关域插值** + 全极点 | **0.997** | 失败 |

## 2. 决定性自检（同一条真人录音 117，用它自己的声学单元按序重建）

- 单元：声学切分（能量核+谷）→ 275 个单元；按序拼接 + 自相关插值（40 ms）+ 器官全极点发声。
- 输出 62.1 s；**Paraformer 转写（截选）**：

> 「什么穿越火线就是 我好像一提到这游戏我就知道穿越火线 因为这个游戏很很老了嘛 后面的话就是绝地求生和平精英这种三岛求生 那种竞技游戏吗 开一盘十几分钟那种还是能一直玩的呢 …」

- **这段是连贯、可懂的**（同一录音的文字内容大体对上）⇒ **「特征点检索 + 移植 + 插值 + 器官发声」这条链本身成立**。

## 3. 失败定位：文本 → 单元选择

同一套件，用样本 117 的**已知文本**走「字 → (声母,韵母,调) → 库里选单元」：输出 11884 帧、缺 0 字，但 **ASR 空转写、CER=1.0**。
对比 §2（同源单元、同合成器、仅挑选方式不同）⇒ **问题在标签**：
- 单元边界是声学切的（对）；
- 单元标签（sm/ym/tone/字）来自 ASR 字时间戳的**最近中心单调分配**（粗、会错位）；
- 错一个字的标签 ⇒ 整句音素错位 ⇒ ASR 全空。

## 4. 追加（11:36–11:44）：标签 bug 已修，标签现在是对的，但「按文本重选」仍失败

**发现并修掉一个真 bug**：`建库_声学` 里算 ASR 字中心时**漏了 `偏移帧`**（对齐证据 `per_sample[].偏移帧`，最大 1193 帧 = 11.9 s）。修法：`cen = (偏移 + cumsum(帧数) − 帧数/2) × 0.01`；并加 **DP 单调对齐**（match / skip-unit / skip-char，罚 0.2 s）替代原来的「最近中心贪心」。

**修后验证**：
- 库从 6587 → **8554** 单元（D2，30 min）；
- 样本 117 的单元标签 vs 真文本：前 40 字**逐字吻合**（仅个别「击/游/穿」被并进邻字）；样本 117 全文 279 字里，字表三元组与本文本 npz 三元组**不一致仅 10/279** ⇒ **标签基本正确**。

**但**（诚实登记，尚未解决）：
- **按序重建**（样本 117 自己的 314 个单元按原顺序）→ **ASR 转写连贯可读**（`自检_117.wav`）；
- **按标签重选**（用样本 117 的文本，从它自己的单元按字选 279 个）→ **ASR 空转写**（`自选117_不归一.wav`，另加 E 归一版 `自选117_归一E.wav` 亦空）；
- 两段音频统计几乎相同（RMS 0.0657 vs 0.0672、峰值同 0.9），**所以不是电平/削波问题**。

⇒ 矛盾已收窄到「重选出的**单元序列**与按序序列的差异」，下一步做**逐单元 id 对照 + 逐单元交叉检查**（把重选序列强行替换回原序列位，看第几处开始崩），定位是「选错单元」还是「重复选同一单元导致上下文破坏」。


## 5. 决定性判决（11:55–12:32）：非训练「文本路径」判死；训练路线被证据逼出来

**同一批 117 声学单元、同一合成器，只改「顺序」：**

| 序列 | 做法 | CER | 转写 |
|---|---|---|---|
| **按序** | 314 单元原顺序 | — | **连贯可读**（自检） |
| **乱序** | 随机打乱 | **1.000** | 空 |
| **乱序 + 长插值** | 打乱 + 插值 100 / 200 ms | **1.000 / 1.000** | 空 |
| **局部互换（5% 相邻）** | 换 5% 位置 | **0.326** | 「那什么穿越火线就是…」连贯 |
| 按标签重选（117 文本） | 本文本单位按字选 | 1.000 | 空 |
| 按标签重选（全库 + 归一） | 跨样本选 | 1.000 | 空 |
| **帧级检索移植 v5** | v13 mel 引导，逐帧最近邻复制真实帧 | **0.931** | 主句 0.809，其余空/乱 |

**判决**：
1. **器官合成管线只对「时间连续的控制轨迹」有效**：连续 → 可懂；打乱 → 即使 200 ms 插值也空；5% 局部错位仍可懂（0.326）。
2. 因此「从真语料里选片段再拼」这条**非训练文本路径判死**——不是标签问题（标签已验对）、不是电平问题（RMS/峰值几乎相同），是**拼接本身**。
3. **训练路线（所有者已放开的 A）被证据逼出来**：要任意文本，必须有一个**连续的「控制轨迹生成器」**（文本 → 每 5 ms 的 F0/LPC/能量/噪声），再喂器官；不是传统 Transformer，不违反 C1。

**下一轮（P6，先预注册）**：非 Transformer（Conv1D/GRU）控制生成器，数据 = 对齐语料（D2 30 min 起，D4 扩），目标 = 5 ms 控制帧（24 阶 LPC 包络 + F0 + 能量 + 噪声比）；判据：主句 Paraformer CER ≤0.35、听审「真人/自然」、两趟 sha256 同；≤0.60 有信号，>0.60 判死该架构换 B 线。
