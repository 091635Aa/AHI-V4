# v6 修复说明（meeting61）：底层发音 —— **浊音声道滤波架构修正**

> 针对「我已经听出来了辅音表，其他还有点模糊；允许改底层甚至核心，但要守核心宪法，禁 Transformer / 外挂模型」。
> 这轮**没动 EQ、没动音量、没动音色、没动音高**；改的是**声道滤波架构**（并联共振峰组 → Klatt 串联）
> 与随之必须的浊声母电平补偿。v4 / v5 的所有文件**一字未动**（C14），随时可 A/B。
> 口径不变：参数化模仿，不是声克隆/角色本人；纯 numpy/scipy，无 TTS/RVC/外挂模型（C1/C9/C10）；同种子逐位同（C13）。

---

## 0. 先给结论（一句话）

**「元音模糊、整句听不出说什么」的根因是 v4 起为了修「串联太闷」而换上的「并联共振峰组」引入了一个
模型级错误**：5 个二阶谐振器每个都是 DC 增益=1（`A=1−B−C`），5 路相加 ⇒ **低于 F1 的频段被整体抬高 +5.5dB**，
形成低频平台。耳听等价量（逐谐波电平）实测：**v5 里 /a/ /e/ /i/ /u/ 的谱峰全部落在 240Hz，不在 F1**，
所有元音共用一个低频「轰」⇒ F1/F2 身份丢失。换成 Klatt 串联后谱峰回到 F1（/a/ 从 240Hz → 840Hz，
F1 突出度 −1.4dB → **+9.9dB**）。

v6 的客观判据 **23/24 PASS**（`判据_发音_v6.py`）。**唯一未过是 E5 的带分布 L1**，
原因见 §5——它与本轮的元音修复方向**直接冲突**，且门限锚在歌唱参考上（诚实说明，见下）。

### 1.3 为什么是模型错，不是音色错 —— 解析传递函数

同一「声门流 −12dB/oct + 单次唇辐射 +6dB/oct」声源下，两种声道架构在共振峰处的相对电平：

| 架构 | F1 | F2 | F3 | F4 | F5 | 100Hz |
|---|---|---|---|---|---|---|
| 并联（v5） | 1.88 + 各峰 | 各峰幅度手工给 (1.0/0.55/0.20/0.09/0.04) | | | | **−5.5dB 平台（5×DC 增益相加）** |
| 串联（v6） | 0.0dB | −3.5dB | −20.3dB | −33.5dB | −55.1dB | −27.3dB（/a/） |

结论：串联的 **F1/F2 相对电平是健康的**（/a/ F2 −3.5dB、/i/ F2 −4.8dB），
被压掉的是 F3–F5（这是串联固有滚降，见 §5 旋钮）。并联的问题在**低频平台**，不在共振峰本身。

## 2. 这轮改了什么（新件，v4/v5 未动）

### 2.1 新增 `引擎_v6.py`（浊音声道：并联 → Klatt 串联）

1. **浊音道改 Klatt 串联 F1→F5**：每个二阶节 DC 增益=1，串联后低于 F1 增益=1（不再有平台），
   F1 处 |H|≈Q ⇒ 谱峰回到 F1。清辅音/噪声道**与 v5 逐位同**（实测 `array_equal=True`）。
2. **F3/F4/F5 高通并联支路**（1.6kHz 二阶高通 × F3/F4/F5 谐振，相对幅度 0.30/0.70/0.40）：
   补串联在高频的累积滚降；因为激励源被高通，**直流处增益=0，不会重新造出低频平台**。
3. **源标定按「带辅音音节内的浊音电平」对齐 v5**（`_源标定 0.55 → 0.304`，实测 v6/v5 = +3.98dB），
   噪标定不变 ⇒ 清浊比与 v5 一致（B2 逐项与 v5 同：−12.21/−13.57/−12.38）。
4. 其余（声门流表、单次唇辐射、噪声链、2ms 交叉包络、确定性种子）与 v5 同。

### 2.2 新增 `韵律_v6.py`

- 韵律/音韵/协同发音部分**与 韵律_v5 逐位同**（只改 `import 引擎_v6`）。
- **唯一新增：浊声母逐音位电平补偿** `浊声母增益 = {m:1.63, n:1.84, l:2.17, r:1.85}`
  （依据 §1.4 的实测 delta，把 m/n/l/r 的擦音级电平补回 v5 量级；残余 <1dB）。

### 2.3 新增 `声带后端_v6.py`

与 `meeting32/声带.py` 的 `发声(向量, 文本, 遥测, 音色)` 同形；内部 = 韵律_v6 + 引擎_v6；
14 维音色字段 / 注册表 / 热插拔 / 契约不变；`发声_流式` 100ms 分块。
稳定态实时率 **0.0872**（v5 0.068；冷启动 2.96s 是 pypinyin/jieba 首次加载）。

### 2.4 新增 `诊断_元音_v5.py` / `实验_共振峰架构.py` / `实验_共振峰频谱.py` / `判据_发音_v6.py`

诊断与判据工具；判据在 v5 的 19 臂基础上**保号保定义**，另加 5 臂：
F1 谱包络峰位（并列 v5 对照）、F2 F1F2 区突出度、F3 单元音 F1F2 可辨、
F4 噪声道逐位同 v5（C14 护栏）、E7 整句噪帧带分布未变（C14 护栏）。

## 5. 诚实边界（必须一起读）

- **E5 的带分布 L1（0.628）未过，且它和本轮修复方向直接冲突**：这条臂把「整句带分布」与
  **歌唱/清唱录音**（且只取每个角色的第 1 个文件）的均值做 L1。实测这 11 个参考文件本身：
  0–500Hz 占比 **12.1%–56.9%**（差 4.7 倍）、1–2k 占比 **7.6%–51.5%**（差 6.8 倍）
  ⇒ 带分布不是「正确发音」的稳定属性。v5 之所以过这条，部分原因是**它的 F1 区被低频平台让位**——
  即这条臂与 §1.2 的元音峰位判据**互相冲突**。本轮选择元音身份（对应用户「听不出说什么」），
  不选择去拟合歌唱录音的频谱直方图。**如果听完觉得「偏暗/偏闷」，可控旋钮见下。**
- **仍没有真人盲评 / ASR 校验**：可懂度只用「谱包络峰位、F1F2 区突出度、辅音电平/部位谱、CV 过渡、
  元音峰位、鼻尾差、四声轮廓、音节率」做代理，最终仍要你耳朵判。
- **/i/ /ü/ /in/ /ing/ 的 F2 在输出里本来就比 F1 低 ~17–21dB**：这是**源谱 −6dB/oct 的物理结果**
  （解析验证：/i/ 的 F2 在滤波器里只比 F1 低 4.8dB，但源在 2349Hz 已比 363Hz 低 16dB）。
  所以「元音表低频占比高」不等于模型错；**判据不拿带分布当元音成形的门**。
- **F3–F5 在串联下偏低**（/a/ −20/−34/−55dB）：这是串联固有滚降，靠 §2.1 的高通并联支路部分补。
  对照参考原声（2–4k 2.0%、4–8k 1.16%）当前不算偏离；**若你要更亮，把 `引擎_v6._高频支路`
  从 0.55 往上调即可**（这是声道架构参数，不是输出端 EQ）。实测：过大会让 /o/ /e/ 的谱峰跳到 F3
  ⇒ 上限建议 ≤0.8。
- **音高没改**：F0 中位仍 367–428Hz（参考 318–362Hz）；E/I 两个降调旋钮仍可叠加。
- **响度**：交付文件统一 RMS 0.06（−24.4dBFS）；A/B 时请对齐音量。
- **实时率**：0.0872（v5 0.068），多的是每帧 F3/F4/F5 并联支路 + 一路高通。
- **参数化模仿，非克隆**；鼻音仍是「浊音 + 共振峰目标 + 低电平 + 电平补偿」的近似，没有独立鼻零极点。
