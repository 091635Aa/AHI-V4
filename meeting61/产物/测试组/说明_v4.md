# v4 修复说明（meeting61）：可懂度 / 流畅度 / 去电音 —— 底层改，非补丁

> 对所有者在 v3 上指出的三个问题：①语言混、听不出说什么 ②说话不流畅 ③听不出是啥/电音过高。
> 这轮改的是**发声底层与韵律内核**（新 44.1k 引擎 v4 + 韵律 v4 + 内核适配层），不是给旧 16k 声带打补丁。
> 口径不变：参数化模仿，不是声克隆/角色本人；纯 numpy/scipy，无 TTS/RVC/外部模型。

## 0. 三个问题的直接处置

| 问题 | 根因（v3） | v4 处置 |
|---|---|---|
| ① 语言混、听不出说什么 | 辅音全部用 `幅度×0.06` 合成（擦音/爆破低到 -18dB 以下）；F1–F5 串联谐振器各峰幅度接近 ⇒ 元音含混 | **辅音按发音方式重建**：爆破 0.10–0.16、擦音 0.14、塞擦 0.10、送气 0.08，带段内起落包络；**并联共振峰组**（F1→F5 增益 1.0/0.55/0.30/0.16/0.08，F1 最强），元音谱峰更清楚 |
| ② 说话不流畅 | 参考源偏慢/偏歌，拟合把语速对齐到 1.7–2.5 音节/秒；停顿过长（逗号 0.18s、句号 0.40s、句间 ~0.8s）；句调夸张（四声 ±0.78、句首 +1.5st、句末 1.45×+140ms 拖尾） | **语速与参考解耦，固定自然说话语速 4.8**；停顿缩短（逗号 0.10 / 句号 0.26 / 句间 0.30s）；四声 ±0.60、句首 +0.7st、句末 1.25×+80ms |
| ③ 电音过高 | 纯周期脉冲源（无气声底噪）、无幅度微颤、串联网状共振峰、音高偏高 | 并联共振峰 + **固定气声底噪 0.018** + **4.7Hz 幅度微颤 1.2%** + 软限峰（去咔哒）；另给 **组E 音高×0.90 / 组I 音高×0.82 / 组J 气声+粗糙** 三个人类化变体 |

## 3. 内核适配（不是补丁）

新增 `实施/声带后端_v4.py`：`声带V4` 与 `meeting32/声带.py` 的 `发声(向量, 文本, 遥测, 音色)` **同形接口**，

## 4. 诚实边界

- **未做真人盲评/ASR 校验**：可懂度只能用「辅音段存在/时长/能量」「自然音节率」「五峰位准确」做代理，
  最终要你耳朵判。
- 若仍「听不出说什么」，下一步底层要做的是**音素级协同发音**（CV 过渡 30–50ms、爆破除阻、擦音起止对齐）
  与**音节规范目标**（目前韵母是声带表 + 我的简化映射），不是再加 EQ/音量。
- 电音感与「像参考」可能有悖论：音高越高/越纯周期越像 v3 的电子歌姬；降音高、加气声/粗糙会更像人但更不像参考。
  这正是你说稍后会讲的悖论——这轮先给 E/I/J 三个方向让你选，底层参数都可直接改，不锁死。
- 组B 裸声、组H 辅音增强、组I 低音高、组J 去电音都只是**听感试验组**，不是交付承诺。
- 参考源本身带宽/质量有限（EmoCompanion 24k、SpeakerA 40k、洛天依清唱 44.1k）；参数化模仿，不是声克隆。
