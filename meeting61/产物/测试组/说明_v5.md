# v5 修复说明（meeting61）：底层发音重建 —— 音韵 / 协同发音 / 声门源

> 针对「还是有问题，底层发音就是有问题，可以对比声音波形」。
> 这轮**没有动 EQ、没有动音量补丁**；改的是 y/w 音韵映射、复合韵目标、CV 协同发音、
> 辅音发声方式与声门源频谱。v4 的 `引擎_v4.py` / `韵律_v4.py` / `声带后端_v4.py` 一字未动（C14）。

## 0. 先给结论（一句话）

**「听不出说什么」的根因不在音色，而在三处底层错误：**
1. **音韵映射错**：121 个测试音节里 76 个有问题（y/w 零声母 26、韵母表未命中 42、复合/鼻韵只给单目标 55、介音丢失 6）。
2. **辅音太弱、没有协同发音**：v4 波形清/浊帧电平差 **−30 dB**，参考语音约 −10 dB；静音占比 27–32%，参考 2–5%。
3. **声门源频谱错**：v4 用「声门流导数 + 唇辐射」，净频谱近似平直；参考 0–500Hz 占 55%，v4 只占 11%，2–4kHz 却占 25%（参考 2%），4–8kHz 占 8.4%（参考 1.2%）。这就是「薄、电、听不清」的波形证据。

v5 的客观判据 **19/19 PASS**（`判据_发音_v5.py`）。

## 2. 这轮改了什么（按底层顺序）

### 2.1 新增 `音韵_v5.py`（音韵层重建）

- y/w 零声母归一：`wo→uo`、`yuan→van`、`yi→i`、`yao→iao`、`wei→uei`、`yue→ve`、`yun→vn`、`wang→uang`…
- 舌尖元音：`zi/ci/si→ɿ (320,1450,2500)`；`zhi/chi/shi/ri→ʅ (360,1550,2050)`。
- 复合韵/鼻韵全表：ia/ie/iao/iou/ua/uo/uai/uei/üe/ian/üan/iong/uen…，每韵 2–3 个滑移目标；
  `-n` 尾 F2≈1600、`-ng` 尾 F2≈1100。
- 声母发音方式表：塞（塞闭/爆破/VOT/送气）、擦（频带）、塞擦（塞闭+爆破+擦）、浊（鼻音/边音/近音）；
  每个声母带**部位轨迹（locus）**，供 CV 过渡使用。

### 2.2 新增 `韵律_v5.py`（音素级协同发音）

- **CV 过渡 30ms**：元音开头从声母 locus 平滑滑向元音目标（塞音 b/d/g 的 F2 起点 825/1200/1650Hz）。
- **送气噪声按后续元音 F1–F3 成形**：塞音 VOT、喉擦 h 不再是固定窄带，而是声道滤波后的噪声
  ⇒ 爆破部位有可听线索（这是可懂度关键，不是 EQ）。
- **擦音部位**：s≈6.8k、x≈5.0k、sh≈3.3k、f 宽带弱摩擦；爆破 VOT 不送气 10ms / 送气 30ms。
- **鼻韵尾**：韵腹末 30% 滑向鼻尾目标，再补 20ms 鼻音（an/ang 末段 F2 差 783Hz）。
- 语速/停顿：同 v4 的自然区间（4.35–5.26 音节/秒），句首换气 35ms、逗号 75ms、句号 180ms。

### 2.3 新增 `引擎_v5.py`（声门源与噪声链）

1. **声门源改用声门流**（不是导数）：流谱 −12dB/oct + 唇辐射 +6dB/oct ⇒ 净 −6dB/oct，
   0–500Hz 能量回到参考量级；F3–F5 并联增益降为 `1.0/0.55/0.20/0.09/0.04`。
2. **唇辐射只做一次**：v4 噪声源先 `diff` 再在输出端 `diff`（+12dB/oct），擦音谱重心虚高到 8–14kHz。
3. **噪声链连续 + 增益平滑**：噪声段内滤波器状态连续、逐帧增益 3 帧平滑、非噪声帧取最近噪声帧增益。
4. **滤波状态跨段连续**（只衰减、不清空）；浊/清边界 2ms 交叉包络（同时修正了 v4 遗留的「帧号当样本号」问题：v4 的包络实际只作用在句首约 100 个样本）。
5. **修复 v5 施工中实测到的单采样咔哒**：中间版 `maxdiff/峰值 ≈ 1.07`，修正噪声段状态/增益插值后原始句 0.20–0.34；
   交付文件最大样本差 0.227（出现在爆破瞬态，不是孤立尖峰），无削波。

### 2.4 新增 `声带后端_v5.py`（内核适配）

与 `meeting32/声带.py` 的 `发声(向量, 文本, 遥测, 音色)` 同形；内部 = 韵律_v5 + 引擎_v5；
14 维音色字段/注册表/热插拔不变；`发声_流式` 100ms 分块。稳定态实时率 **0.068**（冷启动 2.7s 是 pypinyin/jieba 首次加载）。

## 5. 诚实边界（必须一起读）

- **仍没有真人盲评/ASR 校验**：可懂度只用「辅音时长/电平/部位谱、CV 过渡、元音峰位、鼻尾差、四声轮廓、音节率、与参考的谱形距离」做代理。最终仍要你耳朵判。
- **参考与合成文本不同**：波形对比图只比谱形/包络/清浊比例，不做逐字对齐；参考源本身是歌唱/清唱（尤其洛天依），静音占比天然接近 0。
- **高 F0 的共振峰测量不确定**：EmoCompanion F0≈285Hz（乘声区≈350Hz），F1≈825Hz 只有 2.4 个谐波，任何包络估计都会被拉到相邻谐波。D1 因此用 120Hz 测试声线验证「引擎+音韵」；高 F0 的听感仍受谐波稀疏影响（这是物理限制，不是共振峰错）。
- **音高没改**：F0 中位仍为 367–428Hz（参考 318–362Hz）。E/I 两个降调旋钮仍可叠加；这轮只保证降调后发音仍然正确。
- **响度**：交付文件统一 RMS 0.06（−24.4dBFS），与 v4 组一致；不是参考的 −14dBFS。A/B 时请对齐音量。
- **元音目标表是规则化的普通话声学中心**，不是从真人语料逐音素拟合；可能有 5–15% 的个体差异。
- **m/n/l/r 的鼻音/边音谱**仍是「浊音 + 共振峰目标 + 低电平」的近似，没有独立鼻零极点；an/ang 的鼻尾差主要靠 F2 轨迹。
- **参数化模仿，非克隆**：三份参考的声学参数接近（共振峰缩放均约 1.1/1.04），声线可分辨性仍有数据上界。
