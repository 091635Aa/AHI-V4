## 0. 本会议给所有者的建议（一句话）

**先签草案 B（L0 + L1a，不碰实质红线）；只有在明确需要 L1b（仪器当否决门）/ L2（离线教师）时，才签草案 A 并勾选级别。**
理由：①本次 LST 的「机制可借」用 **L0** 就能完成，一条红线都不用改；②「让外部模型帮我判断像不像人话」的需求，**B 已经覆盖**（离线仪器、登记、非阻断）；③L2 是四级里本质风险最大的一级（生成路径读入=0 也会让能力被教师转移，审计看不出来）；④L3（进生成路径）＝现行 C10 明文禁止，且一旦依赖就不可逆。

## 1. 级别总表（勾选依据；详细论证见 `03` §3）

| 级 | 外挂模型角色 | 现行条文 | 需谁授权 | 解锁什么 | 代价/风险 | 本会议推荐 |
|---|---|---|---|---|---|---|
| **L0** | 不接触模型产物；只读论文/公开描述，机制用本仓 8 算子 + numpy/scipy 重实现 | **允许** | 无需（项目常规） | 单元边界/静音单元/patch 级诊断等「机制」；零依赖、C13 全保 | 收益不可证；**不得称「采用 LST」** | **强烈推荐（默认）** |
| **L1a** | 离线**评估仪器**：只吃文件产物（WAV）、只出读数、**非阻断** | 允许（meeting63 §5 先例） | 所有者登记即可 | 可懂度/自然度的外部第二意见、给本仓代理量做对照 | 仪器版本漂移（需权重 sha256+两次解码同）、许可（未核）、Goodhart 风险 | **推荐** |
| **L1b** | 离线**判据门**：可阻断，但**只能否决、不能单独放行** | **灰区**（meeting63 曾当场否决 ASR 当判据门） | 所有者**明示授权 + 签字** | 「可懂度不许回退」硬门，弥补代理量盲区 | 判据主权外移；「零外挂判据」口径失效；判据集过拟合 | 有条件（仅否决门） |
| **L2** | 离线**教师/蒸馏/初始化参考**：开发期产信号，生成路径只读本仓自产参数 | **灰区→不允许** | **必须修宪** + 逐案签字 | 用外部标签加速音素格/韵律 θ 初始化；可能压低 CER（**未测，禁宣称**） | **本质风险最大**：能力被转移而审计 PASS（温水越宪）；C1 灰区；许可衍生义务 | 有条件、严格限定：只许初始化/参考分布/边界校准，**不许用于第一目标能力** |
| **L3** | **进生成路径/当器官**（在线外挂） | **明文禁止**（C10） | 走「全取消程序」（同时改第一、二、三条） | 可懂度/自然度/情感/歌声/多语言直接到外部上限；工程量最小 | 判据失去可证伪性；项目身份崩塌；不可逆；审计体系失效 | **不推荐** |

**「全取消 C1/C10」不是放宽，是换项目**：第七条是第二条的执法条款；取消 C1 ⇒ 第二条「不复刻架构」失效 ⇒ 第一条「不是 AI 模型架构」失效 ⇒ meeting48「自我意识为第一目标」失去可测口径。最致命后果：**30 臂 PASS 只证明外挂强，内生件退化也不影响 PASS——判据失去可证伪性**。若所有者决定走这条路，必须**同时**重写宪法第一/二/三条并重新定义项目目标（E3 §5.3 草案 C），并接受既有判据与「原生声带」对外口径作废。

## 2. 草案 B（**推荐首选**）：C1/C10 原文不动，只固化「离线仪器」附则

> 适用：所有者只想「零外挂审计 + 外部参考」，不想碰教师/器官。**不触碰任何实质红线。**

```markdown
# 附则七之一（最小版·只固化离线仪器）

1. 现行 C1/C10 原文不变：C1 禁 Transformer；C10 禁外挂模型当器官。
2. 对「离线评估仪器」的既有解释（meeting63 §5）予以固化：
   仪器只吃文件产物（如 WAV）、只出读数、只作参考或否决、不进生成路径、不回写生成目录；
   生成路径读入 = 0 的审计断言照旧；须登记。
3. 登记字段（缺一即越宪）：
   模型名 / 来源 URL / 权重 sha256 / 版本或 commit / 许可证 / 调用脚本 / 种子 /
   产物 sha256 与大小 / 生成时间 / 使用级别（L1a）/ 使用者 / 复审日期。
4. 离线教师/蒸馏/初始化（L2）与在线外挂（L3）不在本附则允许范围内；
   如需，须另签修订（见草案 A）。
5. 本附则只解释边界，不构成对 C1/C10 的修改；与宪法冲突时以宪法为准。
```

## 3. 草案 A（**升级选项**）：C1 改为「禁承重/器官，允许离线参考·仪器·教师」

> 适用：所有者明确需要 L1b（仪器当否决门）或 L2（离线教师/蒸馏/初始化）。

```markdown
## 第七条 · 铁律（不可违反；分级启用见附则七之一）

C1 禁 Transformer 作**承重路径/器官**：本仓生成路径（发声、听觉、读出、韵律、动作、自我态更新）
   不得含注意力/自注意力主干、预训练语言模型权重或第三方推理栈；不得 import torch/transformers/rwkv 等。
   允许 Transformer 系模型**仅**以离线身份出现，分三级（见附则七之一）：
     L0 机制参考（不接触模型产物，只读论文/公开描述并用本仓算子重实现）；
     L1 离线评估仪器（只吃文件产物、只出读数、只否决不放行；须登记）；
     L2 离线教师/蒸馏/初始化参考（开发期产教师信号，最终只落本仓自产参数；
        须登记 + 判据含内生臂对照 + 去教师消融 + provenance 可剥离）。
   L3（进生成路径/当器官）仍禁；解除须走「全取消程序」——同时修订第一、二、三条，
   并重新定义项目目标（见 03 §4.4）。归因纪律：任何借用外部模型的改动，对外只能宣称
   「参考/仪器/教师」，不得宣称「本项目采用了该架构」，更不得把外部模型的读数写成本项目的能力读数。

C9 禁 OCR（不变；若引入任何图像/文档解析外挂，本条重新生效并须登记）

C10 禁外挂模型当器官（不变；仪器/教师的边界按 C1 分级条款与附则七之一执行；
    外挂模型不得进入生成路径，生成路径读入=0 的审计断言照旧）

C13 确定性可复现（不变；内生路径两趟逐位同不豁免；外挂仪器/教师只要求
    「归档产物可复现 + 仪器两次解码同」，不豁免本仓生成路径）

C14 不破既有（不变；外部依赖只进独立环境与独立目录，不得改共享 .venv、不得改既有件）
```

**附则七之一（分级启用与登记）**

```markdown
七之一.1 级别与许可
  L0 默认允许；L1a 须所有者授权 + 登记；L1b 须所有者明示授权 + 登记（只能否决）；
  L2 须所有者逐案签字 + 登记 + 判据含内生对照；L3 禁止（除全取消程序）。

七之一.2 登记字段（缺一即越宪）
  模型名 / 来源 URL / 权重 sha256 / 版本或 commit / 许可证 / 调用脚本 / 种子 /
  产物 sha256 与大小 / 生成时间 / 使用级别 / 使用者 / 复审日期。

七之一.3 双门原则
  外挂只能当刹车（否决），不能当油门（单独放行）；内生主判据仍是唯一放行依据。

七之一.4 内生对照
  任何 L1/L2 判据必须并列「内生臂」与「去外挂消融臂」；外挂介入后内生读数下降即回滚。

七之一.5 隔离
  外挂模型独立进程/独立环境；生成件对其 import 边 = 0；生成路径读入 = 0。

七之一.6 回滚
  触发条件（生成路径读入>0 / 内生对照 FAIL / G4 审计 FAIL / 两趟不同 / 许可争议）
  任一出现，7 日内回滚并登记。

七之一.7 复审
  每 30 天或判据改版时复审；升级级别须重新签字。
```

## 4. 签署前的强制固定项（无论签 B 还是 A）

1. **L0 不需要签**：它不接触模型产物，用本仓算子重实现即可——**本次「借 LST 机制」的全部工作都在 L0**。
2. **任何级别都不得「默认全开」**：只启用勾选级别；升级须重新签字。
3. **登记缺一即越宪**：模型名/权重 sha256/来源/许可/调用脚本/产物 sha256/级别/复审日期。
4. **探针先行**：LST「单位粒度假设」的验证（E4 §3 预注册探针）**不需要任何放宽**；先把探针跑完，再谈是否需要 L1b/L2。
5. **对外口径**：任何 L1/L2 介入都必须标注来源分层，不得说成「它自己想/自己长」；L2 产物不得计入「内生」判据。
