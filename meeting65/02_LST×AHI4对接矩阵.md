## 0. 结论先行（7 条，每条可被证伪）

1. **LST 的 7 个要素里，能「直接借」的只有 2 条**：静音/重复模式的紧凑编码、patch↔文本单位对齐；**3 条需改造**：离散语音 token、latent patch 聚合、ASR-TTS 共用 token 空间；**2 条不可用**：AR 序列压缩（机制）、交错预训练数据格式。`[推导]`（逐条见 §2/§3）
2. **最关键的发现：AHI4 不缺「patch 那一层」，缺的是「不由文本给定的边界」。** `[实测]`+`[源码]`
   AHI4 已经有音节级符号序列（「亚版本」`meeting62/实施/契约_谱与亚版本.py:309`），其粒度天然等于 LST 的 patch（与文本单位对齐）；
   同时也有比它长 ~20.9 倍的帧序列（`meeting65/产物/E2/读数_序列基座.json`：帧/音节 = 19.38–22.83，均值 20.92）。
   ⇒ 所以「聚合」这件事 AHI4 已经在做（文本→音节→帧），LST 真正多出来的只有「**边界是从数据里学/量出来的**」。
   **旁证（对 AHI4 有利）**：LST 的「对齐 patch」还要额外付一个 Wav2Vec2+CTC 推理期模型（`LST_全文.txt:326-331`），而 AHI4 的音节边界由 `音韵_v5` 规则免费给出 ⇒ **对齐这一层 AHI4 比 LST 强，不是短板**。
   凡是把 patch 边界写成「音节边界/标点边界/固定帧数」的接法，都等于把 LST 的机制退化成 AHI4 已有的查表。
3. **落点：听觉前段 + 音素格读出侧；不该落在韵律 θ / 帧计划。** `[推导]`（§3/§7）
   帧计划（韵律 θ 侧）被 5 条现有判据**直接承重**（C3 F0 轮廓、C2 CV 过渡、B4 VOT、D1 元音峰位、F1 谱包络），
   在其上做任何均值/池化聚合都会同时动这些量；而波形侧段表（耳）聚合不动波形，护栏臂可要求**逐位同**。
4. **8 算子够用，但有一个容量天花板。** `[推导]`+`[实测]`
   绑/解绑/门/叠/归/读/迭代/符 全部是确定性 numpy 定点运算（`meeting41/实施/算子_能力核.py:67-89`），
   patch 聚合＝`叠`+`归`、对齐＝`绑`/`解绑`、边界＝`门` 或新用法的 `符`；
   但 `叠` 在 D=1024 上有实证的容量上限：1024 叠加态长程回查 Δ8→Δ96 从 0.994 掉到 0.087（`AHI4/AGENTS.md:113`）；而 LST 自己的 patch 只有 **3.7（静音）–5.8（词）** 个 token（`LST_全文.txt:565,911`，静态 p=4），AHI4 一个音节却有 **20.9 帧** ⇒ **按音节叠必然越界**，长静音段必须用**显式段表**而不是叠向量。
5. **焊死件风险集中在三张既有表上**：音韵表（当 token 空间）、标点停顿表（当静音折叠规则）、固定帧数（当 patch 窗）。`[提案]`（§5 给反例/合格写法/检测臂）
6. **判据接法清楚且便宜**：承重挂 `G2_皮层可分度`（现 0.8571，阈 0.60），次承重挂 `G3_反馈学习`（0.7381→0.7857）；
   `F1/F2/E6/E7/F4/E1` 降为护栏（要求波形逐位同）；新增 `H1–H6`，其中 **`H2`（边界不是查表）与 `H3`（共享码从波形来）是 must-fail 型**。`[提案]`
7. **红线：只借机制、不接模型 ⇒ 一条红线都不用改（L0 即可）。** `[推导]`
   本席提出的全部方案只用本仓算子 + numpy/scipy；`审计_零外挂.py` 的 A/B/C 三断言（`:119-141`）可照旧跑；不引入外部权重、不引入第三方推理栈。
   若要接「神经分词器/预训练权重」才需要 E3 的 L2/L3 —— **那是另一件事，与「借 patch 机制」无关。**

## 3. 逐要素展开（机制 → AHI4 现状 → 判定 → 落点 → 8 算子 → 证伪条件）

### 3.1 离散语音 token —— 需改造

- **LST 侧**：离散语音 token 来自神经语音分词器（简报 §3:71 明确「与 C10 直接冲突（若进生成路径）」）。`[文献]`（`meeting65/00_共同简报.md:67,71`）
- **AHI4 现状**：已有**手写离散符号层**——21 个声母（`音韵_v5.py:30-83`）、韵母表（`:100-144`）、四声五度轮廓（`:150-154`）、鼻尾目标（`:147`）；`解析音节`（`:238-246`）把拼音拆成 `声/韵/调/目标s/尾`。读出侧另有离散档位码：8 角色 × 3–4 档（`皮层_音素格.py:58-69`）。`[源码]`
- **判定**：**需改造**。可借的是「离散单位」这件事本身——AHI4 已经做了；**不可借**的是分词器（外部权重，C10）与「token 由数据学出来」（AHI4 的符号是语言学先验写死的）。
  所以本条在 AHI4 上是「**不需要迁移**」，只需要承认：**符号层是查表**，不能把它包装成「学到了 token」。
- **落点**：音素格读出侧（离散码空间，`皮层_音素格.py:129-169`）。**不该落**：韵律 θ（θ 是连续参数，塞离散 id 进去只会多一层查表）。
- **8 算子**：`绑`（音素×调×韵的 role-value 编码，已是 `皮层_音素格.编码` 的做法）；`读`（码本最近原型）。
- **证伪条件**：若「离散码」能离开手写表独立存在（例如打乱 `音韵_v5.声母` 后仍能正确编码同一批波形），则本条应升级为「直接借/无需迁移」；若打乱后一切照旧，则证明码不是学来的。**未测**。

### 3.2 latent patch 聚合 —— 需改造（本席的核心结论）

- **LST 侧**：把 N 个语音 token 聚合成「潜变量语音 patch」，作为更高层 AR 单元（简报 `:67`）。原文已落到本仓（E1/E4 抽取）：`meeting65/产物/文献/LST_全文.txt`
  · **聚合器**＝局部 patch encoder（滑窗自注意力 + 交叉注意力），**patch query 由 span 内 token 隐状态的池化初始化**（`LST_全文.txt:250-253,770-777`）⇒ 是**学出来的池化**，不是统计平均；
  · **patch 规模**：静态 p=4 个 token（`:383`，正文亦称 4→1，`:943`）；词对齐 patch 平均 **5.8** 个 token、静音段 patch 平均 **3.7**（`:565,:911`）；
  · **三种策略**：静态 / 对齐（每文本单位一个 patch + 静音单独成 patch）/ 课程（对齐→静态渐变）/ 混合（`:271-341,:382-388`）。`[文献]`
- **AHI4 现状（三处「类 patch」都要看清）** `[源码]`：
  1. **亚版本**＝音节级符号序列（`契约_谱与亚版本.py:266`（`亚音节`）、`:309`（`亚版本`）、`:373`（`建亚版本`））——**已经与文本单位对齐**，粒度＝patch；
  2. **耳段表**＝波形侧静/清/浊段（`耳_内生.py:77-107`）——**从波形量出来的**，粒度比音节细 1.63×（实测）；
  3. **皮层原型**＝`叠`（`算子_能力核.py:195-208`）+`归`（`:84-89`）的叠加向量（`皮层_音素格.py:146-159`）——把多帧特征叠成一个码。
  ⇒ 三者合起来，AHI4 **已经有一条「token→patch」的算子链**，只是边界由**文本**给定（音节）。
- **判定**：**需改造**。learned pooling 不可借（要训练、要梯度、违 C13 风险）；可借的是「**聚合单元 + 边界**」这件事，而边界必须换成**确定性证据**（能量/浊度/谱变化/段表），边界**不能**来自文本或词表。
- **落点**：**听觉前段（耳段表）**为主，音素格读出侧（叠向量）为辅。**不该落**：韵律 θ / 帧计划（§7 给 5 条会打架的判据与现有余量）。
- **8 算子**：`叠`（patch=叠(tokens)）、`归`（定点归一，2^-20 格，`算子_能力核.py:84-89`）、`门`（边界软门控 `:188-193`）、`符`（边界检测新用法，`meeting49/实施/算子_两区室核.py:163-171`）。
- **容量上限（必须先接受）**：`叠` 是有损的。实证：1024 维叠加态长程精确回查 Δ8→Δ96 = 0.994→0.087（`AHI4/AGENTS.md:113`）。
  ⇒ **LST 自己的 patch 只有 3.7（静音）–5.8（词）个 token（`LST_全文.txt:565,911`），静态 p=4（`:383`）**；而 AHI4 一个音节＝**20.9 帧**（本席实测）＝ LST patch 规模的 **3.6–5.6 倍**。
  ⇒ 若强行「按音节叠」，K 会落在叠加态已明显退化的区间；**长静音段（实测 10.9–19.0% 帧）必须用显式段表（见 3.4），不能用叠向量**。`[推导]`+`[实测]`+`[文献]`
- **证伪条件**：若「证据定界」与「音节定界」在波形侧的一致率不显著高于「固定窗定界」（±40ms 容差），则本条的「需改造」应降级为「不可用/无收益」。**未测**（见 `H2`）。

### 3.3 patch↔文本单位对齐 —— 直接借

- **LST 侧**：patch 与文本单位对齐以促进跨模态迁移（简报 `:67`）。`[文献]`
- **AHI4 现状**：**这条 AHI4 已经有，而且是构造性的**：`音韵_v5.音节列表`（`:249-253`）逐字产音节，`解析音节`（`:238-246`）同时产 `声/韵/调/目标s/尾`；`A3_全句查表` 实测 121 音节 0 问题（`判据_发音_v9.py:97-105`，v9 读数 `问题数=0`）。`[源码]`+`[实测]`
  对齐的**编码方式**可直接借：`绑(文本单位原子, patch向量)`（`算子_能力核.py:176-180`）+ `解绑`（`:182-186`）——这正是 `皮层_音素格.编码` 已经在用的 role⊛value 写法（`:146-152`）。`[源码]`
- **一个关键差别（对 AHI4 有利）**：LST 的对齐 patch 靠 **Wav2Vec2+CTC 强制对齐**，原文自陈「需要推理期辅助模型，会引入错误」（`LST_全文.txt:326-331`）；而 AHI4 的文本→音节对齐由 `音韵_v5` 规则直接给出（零模型、零错误）。**所以「对齐」这一层 AHI4 比 LST 便宜，不是短板。** `[文献]`+`[源码]`
- **判定**：**直接借**（编码方式），但**收益要打折**：LST 靠对齐做跨模态迁移（文本知识→语音），AHI4 没有预训练知识可迁，所以本条的实测价值只剩「**解绑可读性**」——从 patch 里读回文本单位类别。
- **落点**：音素格读出侧。**不该落**：听觉前段（耳不该知道文本，否则违 M3，见 §5-R6）。
- **证伪条件**：`解绑` 读回文本单位类别的准确率若不高于 chance 的 2 倍（4 类 ⇒ ≤0.50），则「对齐可读」不成立。**未测**（见 `H6`）。

### 3.4 静音/重复模式紧凑编码 —— 直接借（最干净的一条）

- **LST 侧**：patch 可紧凑编码静音等重复声学模式（简报 `:67`）。原文口径很具体：**对齐 patch 里「文本跨度之外的帧（如静音）单独成 patch」**，一个静音段一个 patch（`LST_全文.txt:326-329`）；消融里 **Align (sil sep.)＝静音单独成 patch** 优于静音并进相邻词（`:496-500`）；静音 patch 平均 **3.7** 个 token（`:565,:911`）。`[文献]`
- **AHI4 现状**：
  - 静音在帧计划里是**显式帧**：`_静音`（`韵律_v7.py:217-219`）写 14 字段、`声源=-1`、`幅=0`；实测静帧占比 18.98%/10.94%/12.47%（本席探针 `[实测]`）；标点停顿是手写表（`:48-52`）。
  - 波形侧已有**段表**：`切段`（`耳_内生.py:77-107`）输出 `[(类, 起样本, 止样本)]`，`_段统计`（`:110-127`）给每段时长/谱重心/谱峰/能量/浊度；`听`（`:130-159`）已是确定性（判据 `G1` 两趟逐位同，`判据_发音_v9.py:346-348`）。
  - 实测压缩潜力：段/帧 = 0.0657/0.0881/0.0796（合计 75/931 = 0.0806，约 12.4×）；类别级游程压缩比 0.0939（约 10.6×）；但**帧级精确 RLE 只有 1/0.8793 ≈ 1.14×**（几乎无冗余）。`[实测]`
- **判定**：**直接借**。这是 7 条里唯一「不需要新机制、纯 numpy、确定性已被 G1 证明」的一条。
  落法只有一句：**把静音/重复折叠成「段游程」，不要折叠成「帧」**。
- **落点**：听觉前段（段表＝规范表示）；判据侧（`H1` 用段表重建）。**不该落**：波形（折叠不许改音频）。
- **8 算子**：`叠`/`归`（把段长/谱量编码成向量）；`绑`（段类×时长的 role-value）；**不需要 `迭代`/`符`**。
- **证伪条件**：段表→帧计划的重建必须**无损**（时长逐段一致）；若重建误差 > 1 帧（10ms）或重建后波形不能逐位同，则「紧凑编码」变成「有损压缩」，须撤回。**未测**（见 `H1`）。

### 3.5 AR 序列压缩 —— 不可用（机制），可借（度量）

- **LST 侧**：patch 缩短有效 AR 序列长度，从而降低 ASR/TTS 推理算力（简报 `:67`「reduces the effective autoregressive sequence length」）。原文给的量：交错预训练段 **4→1 压缩把序列长度 3.00→2.42（约 20% FLOPs 降）**（`LST_全文.txt:943-956`），TTS 推理减少自回归声学生成步数（`:959`）。**注意：这两个数的分母都是「AR 步数/注意力 FLOPs」。** `[文献]`
- **AHI4 现状**：**没有自回归**。帧计划由 `建帧`（`韵律_v7.py:390-433`）一次性生成，引擎按帧**线性**消费（`引擎_v6.py:221-238` 逐帧 IIR；实测实时率 0.0451，10s 合成 0.4513s，`meeting62/诊断报告.md:200`）。计费线性：计费比 3.99992、U 翻倍 2.000（`AHI4/AGENTS.md:69,99`；`算子_能力核.py:361`）。`[源码]`+`[实测]`
- **判定**：**不可用（机制）**。LST 省算力的前提是 Transformer 注意力的超线性代价；AHI4 是 O(N帧) 的 IIR 串联，**序列变短不会省算力**（帧数才是成本）。
  ⇒ 任何「借 AR 压缩来省算力」的说法在 AHI4 上**必须当场驳回**，除非同时给出「帧数减少」的实测。
- **可借的只有度量**：把「单位数」当一个记录量（`H5`，否定性臂），用来防止有人把「序列变短」包装成「算力变省」。
- **落点**：仅判据（记录臂）。**不该落**：生成路径。**特别警告**：不要用 `迭代` 算子冒充 AR（千层 丙1/丙3 已否证「迭代补全/离线重放无可测增益」，`AHI4/AGENTS.md:97`）。
- **证伪条件**：若有人主张省算力，测 `合成耗时 / 帧数`：若帧数未降而耗时降了，说明测的是别的东西；若帧数降了而 F1/C2/B4 掉出阈，说明省的是发音质量。**未测**（见 `H5`）。

### 3.6 ASR-TTS 共用 token 空间 —— 需改造

- **LST 侧**：ASR/TTS 共用同一离散语音 token 空间（简报 `:73`「ASR-TTS 共用」）。`[文献]`
- **AHI4 现状（关键：目前两侧不共用）** `[源码]`：
  - **生成侧**只有连续参数 θ（`韵律_v8.py:53-74`：爆破秒/终点混合/过渡秒/缩底/鼻尾…）与帧字段（`韵律_v7._清 :195-198` 的 14 个键）；**不写任何离散码**。
  - **感知侧**有离散码：`皮层_音素格` 把波形侧 8 个角色量化成档（`:57-69` 界值 + `_档 :72-77`），`编码` 成 HDC 向量（`:146-152`），`写/冻结/读`（`:154-169`）。
  - **闭环**：`学_咬字反馈` 只用「可分度」当目标（`学_咬字反馈.py:123-152`），**没有把两侧拉到同一个码空间**。
  ⇒ 所以「共用空间」在 AHI4 是**部分存在**（皮层码是同一种空间），但**未贯通**：生成侧不产码、耳侧按音节独立读、没有序列级共享。
- **判定**：**需改造**。可借的是「两侧共用一套离散码」的结构；**不可借**的是「生成侧直接写 token id」——那会让耳变成「读文本的耳」，`M3_波形敏感(真耳只认波形)`（敏感率 1.0 = 21/21）会当场失败（`判据_发音_v9.py:322-324`）。
- **落点**：音素格读出侧（共享码 = 皮层原型码）+ 听觉前段（码只能从波形来）。**不该落**：韵律 θ。
- **8 算子**：`绑`/`叠`/`归`（编码 patch 码）、`读`（共用码本读出）。
- **证伪条件**：跨角色（EmoCompanion学的码读SpeakerA/洛天依）可分度须 ≥0.60（chance 0.25）；若只在同角色成立，则「共用空间」只是「同一声线的过拟合」。**未测**（见 `H3`）。

### 3.7 交错预训练数据格式 —— 不可用

- **LST 侧**：interleaved text tokens + discretized speech tokens 的预训练（简报 `:67,70`）。`[文献]`
- **AHI4 现状**：无预训练、无交错语料；`接口契约_角色声线.py:256-265` 的 `文本产物`/`渲染产物` 是**工程数据类**，不是训练样本格式。`[源码]`
- **判定**：**不可用**。撞 C1（预训练 Transformer）+ C10（外部权重）+ C13（权重漂移不可复现）+ 无数据。
- **落点**：**不该落**。唯一可借的只是「离线评估数据怎么组织」（语音-文本配对清单），那是**评估工程**，不是机制；已由 E3/E4 处理。
- **证伪条件**：不存在「不引入预训练权重却能复现交错预训练收益」的路径——若有人提出，须先过 `G4_零外挂审计`（`判据_发音_v9.py:362-372`）。

## 4. 8 算子逐算子可实现性（本仓算子表：`绑定/解绑/门/叠/归/读/迭代` + 第八算子`符`）

口径常量：D 默认 1024、界幅 16、2^-20 定点格、码本默认 64、命中阈 0.35（`meeting41/实施/算子_能力核.py:67-74`；`_归 :84-89`）；`符`的登记与定义见 `meeting49/实施/算子_两区室核.py:63,144-145,163-171`。`[源码]`

| 算子 | 数值性质（出处） | 在本对接里干什么 | 能否实现 LST 对应机制 | 风险 |
|---|---|---|---|---|
| 绑 | `归(W绑⊙k⊙v)`，`:176-180` | patch↔文本单位对齐；patch 内 (角色,值) 绑定 | ✅ 对齐编码（#3） | 键是随机双极原子 ⇒ 语义不来自数据；别称它「学到了对齐」 |
| 解绑 | `归(W解⊙k⊙b)`，`:182-186`；初值取绑的逆 ⇒ 往返逐位还原（`:134`） | 从 patch 读回文本单位类别（可读性证明） | ✅（#3 的证伪臂） | 容量：叠多个键后解绑会串扰（AGENTS:113 的长程退化） |
| 门 | 逐元素门控，`:188-193` | patch 边界软门控（边界强度→0/1 连续过渡） | ✅ 边界软判（#2） | 门控参数是常数向量，若写成硬阈值即退化为查表 |
| 叠 | 向量列求和后归，`:195-208` | patch = 叠(tokens)；段表向量的组合 | ✅ 聚合（#2/#4/#6） | **有损**；LST patch 只 3.7–5.8 token（`LST_全文.txt:565,911`），AHI4 音节 20.9 帧 ⇒ 按音节叠必越界（§3.2 容量上限） |
| 归 | 限幅 + 2^-20 定点，`:210-212`/`:84-89` | patch 幅度规整；保证跨进程逐位同（C13） | ✅ 确定性（全部方案） | 无限幅会溢出界幅 16 ⇒ 读数跨机器漂移 |
| 读 | 码本最近原型 + 命中阈 0.35，`:214-247` | 共用 token 空间的读出（#6） | ✅ 读出（#1/#6） | 命中阈 0.35 是**设计值**不是标定值；跨角色会掉命中率 |
| 迭代 | 定点推进，`:249-267` | **不用**（不得冒充 AR） | ❌ 不支持 #5 | 千层 丙1/丙3 已否证「迭代补全有可测增益」（AGENTS:97） |
| 符 | `归(W符⊙a⊙b)` 双线性重合门，`两区室核.py:163-171` | **边界检测**（快态⊗慢态：重合度骤降 ⇒ 收边界） | ✅ 边界证据（#2 的候选实现，**新用法**） | 逐元素乘积的标量摘要方式未定；且 `符` 至今只用于 credit，当边界器属**未验证新用法** |

唯一「新用法」是 `符` 当边界检测器 —— 它在 30 臂里**没有任何承重记录**（只在 V4 判据的 credit 里用过），所以 `H2` 必须把它与「音节定界」「固定窗定界」放在同一张表里比。

## 5. 焊死件风险：哪些「借机制」的写法会退化成查表/池子/硬编码（违规第三条初心）

> 初心口径：一切「变聪明」必须内生（`AHI4/AGENTS.md` 置顶；`初心_宪法.md`）。**程序写好的表/池子/硬编码 = 假机制。**
> 下面每条给：反例写法 → 为什么是焊死 → 合格写法 → 用哪条臂检测。

### R1 把「音韵表」当离散 token 空间（查表）
- **反例**：`token = 声母表下标`（`音韵_v5.py:30-83`），于是「离散语音 token」= 21 个手写符号；「ASR-TTS 共用空间」= 生成侧查 `声母表` 写 id，耳侧读同一张表。
- **为什么焊死**：token 不来自波形，来自**语言学先验的字典**；耳若读表就变成「读文本的耳」，`M3_波形敏感`（现 1.0，`判据_发音_v9.py:322-324`）必然掉。
- **合格**：token/码只能由 `耳_内生`（波形）→ `皮层_音素格`（量化 + `叠`）产生；音韵表只用于**生成侧的发声目标**，绝不进感知侧的码。
- **检测**：`M3`（时间反转 ⇒ 特征必变）+ `H3`（跨角色可分度；查表法会因角色无关而虚高，但重合成后波形一变就掉）。

### R2 把「标点停顿表」当静音折叠规则（查表）
- **反例**：静音折叠 = 按 `标点停顿`（`韵律_v7.py:48-52`）折叠：把「，。？！…」分别折成固定长度 L1/L2/L3。看起来压缩漂亮，实际只复述了标点表。
- **为什么焊死**：折叠决策与**波形里的静音**无关；改了标点表就改折叠，改了音频却没改折叠 ⇒ 机制是假的。
- **合格**：折叠单元从 `耳.切段` 的**静段**来（`耳_内生.py:85-106`，静阈 30dB `:31`），段长就是实测时长；标点表只用于**生成侧**决定"该不该有停顿"。
- **检测**：`H1`（段表→帧计划重建）+ **must-fail**：把音频里的停顿人为拉长/缩短，段表必须跟着变；若段表不变，说明读的是标点表。

### R3 把「固定帧数」当 patch（固定池化）
- **反例**：`patch = 每 20 帧取均值`（200ms 固定窗）。压缩比一定好看（20×），但它不是聚合，是**降采样**。
- **为什么焊死**：边界写成常数 `20`，与语音内容无关；换语速/换角色/换句子结果结构不变 ⇒ 等于程序写死的池子。
- **合格**：边界由证据触发（能量/浊度/谱距离突变，或 `符(快态,慢态)` 重合门骤降），窗长**由数据给出**；固定窗只能当**对照臂**。
- **检测**：`H2` + **must-fail**：打乱边界（把证据序列置乱）后，压缩率/重建误差必须显著变差；若读数与真边界几乎一样 ⇒ 是固定池化。

### R4 把「词边界（jieba）」当 patch 边界（外部词典查表）
- **反例**：用 `词边界`（`韵律_v7.py:117-131`，内部 `import jieba.posseg` `:120`）当 patch 边界：词首/实词 ⇒ patch 起点。
- **为什么焊死**：词边界来自**第三方词典**，不是从本仓数据/波形量出来的；换词典就换边界。严格说它连「本仓内生」都不是（虽然不违 C10——审计把字典读入归为「既有语料基础设施」，`审计_零外挂.py:133`）。
- **合格**：词边界只能作**生成侧的重音/停连线索**（现状即如此：`:404-421` 决定 `重音` 与时长倍）；感知侧边界必须从波形来。
- **检测**：`H2`；另加静态审计一条（`G4` 扩到 patch 边界模块：禁读 jieba/字典）。

### R5 用「迭代」算子冒充 AR（把定点迭代说成序列建模）
- **反例**：`patch 序列 → 迭代(态, 驱动力)` 反复推进，声称「这就是 AR，序列变短了」。
- **为什么焊死/无收益**：千层 丙1/丙3 已实测「迭代补全/离线重放无可测增益」（`AHI4/AGENTS.md:97`）⇒ 迭代不是序列模型，套上去只多一层常数。
- **合格**：承认 AHI4 无 AR；若要做序列建模，先给「帧数减少 ⇒ 质量不降」的实测（本仓尚无）。
- **检测**：`H5`（否定性记录臂：合成耗时/帧数 必须线性，`AHI4/AGENTS.md:99`）。

### R6 用「共享码」让耳偷看生成侧（自证）
- **反例**：生成侧先算好 `音素类 → id`，把 id 写进 patch，耳侧直接读 id ⇒ 两侧「共用空间」完美，可分度≈1.0。
- **为什么焊死**：这不是感知，是**把答案抄给耳**；`M3_波形敏感(真耳只认波形)`（敏感率 1.0 = 21/21，`判据_发音_v9.py:322-324`；同口径见 `学_咬字反馈.py:102-120` 的 must-fail）是既有护栏，正好抓这种写法。
- **合格**：耳侧只能拿波形（`耳_内生.py` 头注 `:8-13` 明写「绝不读生成器内部帧」）；共享码必须是「生成侧**合成了**波形，耳从波形读出码」这条路。
- **检测**：`M3` + `H3` 的 must-fail（把 id 通道断开后，若可分度立刻掉到 chance，说明之前靠抄答案）。

### R7 把「皮层固定界值」当学出来的词表（手写分档冒充 tokenizer）
