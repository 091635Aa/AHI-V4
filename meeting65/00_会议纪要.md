## 0. 一句话裁决（BLUF）

**LST 不是一套可以「魔改装进」AHI4 的语音/声带方案，而是「语音-文本大模型的潜变量 patch 预训练架构」**（BLT 三段式 + HuBERT 离散 token + 1.8T 文本 / ~145k 小时语音预训练 + 420M–7B 规模）。
它整体搬进 AHI4：**C1 + C10 双撞、工程上也不成立**（无中文、无开源权重可跑、无 GPU/无复现路径）；**即使取消红线也接不上**。
真正值得拿的只有**设计原则**（单元边界对齐文本单位、静音独立成单元、单元级诊断口径、patch 级信息瓶颈反馈），**用本仓 8 算子 + numpy/scipy 即可实现（L0）——一条红线都不用改**。
所有者要的「红线取消 / 变宽松」，本会议建议落到 **L0（默认）+ L1a（离线仪器，登记制）**，即 E3 的**草案 B**；L1b 须明示授权；**L2 须修宪且风险最大**；**L3 不推荐**；**全取消 C1/C10 不是放宽，是换项目**（须同时重写宪法第一/二条）。
**三个问题一句话**：①LST 是「省算力 + 跨模态对齐」方法，不是「音质/可懂度」方法；②机制可借、模型不可接，且「可迁移」目前只是**假设·未证实**；③红线**不必**为「借机制」而改，宽松化的正确落点是「L0 + L1a + 登记 + 可证伪探针」。

## 2. 问题一：LST 的语音方案到底是什么（E1 摘要）

### 2.1 架构（`[文献-原文]`，行号指 `产物/文献/LST_全文.txt`）

| 段 | 实现 | 来源 |
|---|---|---|
| 语音分词 | **HuBERT 语义 token，501 码本 @ 25Hz**（40 ms/token），不做去重 | §2 L194-201 |
| 文本分词 | Llama-2 BPE，32K | §2 L216-217 |
| **patch encoder** | 1 层 / 1024 维、滑窗 512 的**自注意力 + 交叉注意力**；把一段连续帧聚成一个 patch 向量；查询由段内 token 隐状态**池化初始化**，再由注意力精修 | §3 L250-262、附录 A.2.1 L769-780 |
| **global transformer** | 25 层 / 2048 维、block-causal、RoPE（5e5），对「文本 token + speech patch」交错序列做**自回归** | L781-788 |
| **patch decoder** | 9 层 / 1024 维轻量 Transformer，逐层交叉注意力，从 patch 重建**动态长度**的语音 token | L804-809 |
| 切分策略（论文主变量） | **static（p=4，160 ms）/ aligned（词/子词边界，含静音独立成 patch）/ mixed / curriculum（训练对齐→推理解除）** | §3.1 L263-342、§4.2 L382-396 |

**判断（E1 K1/K2）**：LST **不是新架构**，三段式整套来自 BLT（Pagnoni et al., 2024），交错预训练范式来自 SpiritLM；LST 的增量＝**只对 speech 做 patch + 四种切分策略的系统比较 + speech-text 双向验证**。「latent speech patch」是**切分问题**（`zi = PatchEnc(X_Pi)`），聚合器是 BLT 既有件。

### 2.2 结果与口径（核实后必须带的三条挑刺）

- `+6.5` = Table 3：HellaSwag S→S **39.0 → 45.5**（compute-controlled）；`+5.3` = Table 4：**40.2 → 45.5**（data-controlled）。训练算力省 **19.3–19.7%**，序列 **3.00 → 2.42**，TTS 自回归步数 **≈÷4**，ASR 上下文单位 **×0.25**。`[文献-原文]` L404-461
- **挑刺①**：摘要「without degrading reconstruction quality」**过强**——TTS **clean CER 持平（14.1）但 other 子 15.1 → 16.2 变差**；且「重建质量」只用 Whisper 转写 CER 代理，**token→波形环节原文未交代**。L452-461、L482-486
- **挑刺②**：ASR 1k→2k 的 other WER **10.4 → 13.3 非单调**，原文未解释；baseline 1k **140/202** 是「训练崩了」的对照（原文自述 hallucination / stopping 不可靠）⇒ 只能得出「patch 让 ASR 适配更稳」，**不能得出「表征更强」**。
- **挑刺③**：aligned patch 单独用在评估上**反而更差**（42.7 < static 44.3），它的优势只在 curriculum 里体现（45.5）。
- **时间尺度换算（关键）**：LST 词级 patch 平均 **5.8 token ≈ 232 ms**、静音 patch 平均 **3.7 token ≈ 148 ms**；而 AHI4 音节 **195–228 ms**（实测 20.92 帧/音节 = 209 ms）。⇒ **LST 的 patch 与 AHI4 的音节几乎同尺度**。

### 2.3 对 AHI4 的直接含义（E1 K3–K5 的裁决）

1. LST 的全部已报告收益**挂在预训练基底 + 规模上**（1.8T 文本 token、~145k 小时语音、420M–7B Transformer）；差分是「这个基底 + patch」相对「这个基底」，**不是「patch 相对无 patch」的普适增量**。AHI4 没有该基底，差分赖以存在的对象不存在。
2. LST 的卖点是**省算力（序列变短）+ 跨模态对齐**；AHI4 引擎 v6 实时率 **0.0451**（10 s 合成 0.45 s），**算力不是瓶颈** ⇒ 该卖点在本地没有消费者。
3. 因此 LST 对 AHI4 的**直接价值≈0**；可能拿走的是「单元/边界设计经验（含静音独立成单元）、单元级诊断口径、patch 级信息瓶颈反馈」三件轻活，且**都要重新验证**。

## 3. 问题二：能不能「魔改」到 AHI4（E2 矩阵 + E4 削弱 → Lead 裁定）

### 3.1 七要素对接矩阵（E2，`[源码]` 行号见原表）

| # | LST 要素 | AHI4 现状 | 判定 | AHI4 落点 |
|---|---|---|---|---|
| 1 | 离散语音 token | 部分（音韵符号表 + 皮层 HDC 码） | **需改造** | 音素格读出侧 |
| 2 | latent patch 聚合 | 部分（亚版本＝音节级符号序列；耳段表） | **需改造** | 听觉前段 + 读出侧 |
| 3 | patch↔文本单位对齐 | **有（构造性硬对齐，1:1）** | **直接借** | 音素格读出侧 |
| 4 | 静音/重复模式紧凑编码 | 部分（耳段表 + 游程） | **直接借** | 听觉前段（不进波形） |
| 5 | AR 序列压缩 | 无（AHI4 无 AR；计费线性 4.0 / U×2） | **不可用**（仅作度量） | 不落生成件 |
| 6 | ASR-TTS 共用 token 空间 | 部分（感知侧有码，生成侧只有参数 θ） | **需改造** | 读出侧 + 听觉前段 |
| 7 | 交错预训练数据格式 | 无 | **不可用** | 不落 |

**E2 的最硬发现**：**AHI4 不缺「patch 那一层」**——亚版本是音节级符号序列、与文本 1:1；帧/音节实测 **20.92**；耳段表本来就比帧短 **≈12.4×**（931 帧/75 段）。**LST 真正多出来的只是「边界不由文本给定」**；而 LST 的 aligned patch 还要外挂 Wav2Vec2+CTC，**AHI4 的拼音/音节边界免费且 100% 准**——对齐层 AHI4 反而更强。

### 3.2 E4 的四记削弱（必须一起读，否则会高估）

| 削弱 | 内容 | 后果 |
|---|---|---|
| **R3（最致命）** | LST 的 patch encoder 是**学出来的**（池化只做 query 初始化）；论文**没有**「换确定性均值池化」的消融；其 BPE 对照（学习式压缩）**反而低于基线**（39.4 < 40.2） | 「确定性聚合」与论文机制**不等价**；能宣称的只是「有界聚合假设」，不是「复现 LST」 |
| **R5** | LST patch 232 ms ≈ AHI4 音节 209 ms；AHI4 确定性段 130 ms 更细 ⇒ 探针里的「段 vs 音节」实际是「更细 vs 同尺度」 | A2 不赢 A1 **不证伪 LST**，只说明「AHI4 已内建该单位，无需迁移」 |
| **R4** | LST 是「隔离静音」不是「折叠长静音」（静音 patch 均 3.7 token，比词 patch 更短）；AHI4 两套静音口径差 2.8×（波形 6.7% vs 帧计划 19.0%） | 「静音折叠省 X%」在 AHI4 口径不成立；折叠只省段数 10–22%，不省帧/算力 |
| **R6/R8** | 对齐在 AHI4 免费（LST 的 alignment 增量仅 +1.2/+1.6）；0.857 是 5 类任务、已逼近上限 | 对齐与「可分度提升」在本载体没有分辨率可测 |

### 3.3 Lead 裁定（**本会议最重要的判断**）

1. **「LST 可魔改到 AHI4」不成立**（作为模型/整体）。**作为机制**，允许它继续存在的形式只有一个：**「单位粒度假设」**——「把序列建模单位抬到与文本同尺度（音节/词）可能有用」。该假设**未证实**，且 AHI4 可能已经内建。
2. **可迁移结论降级**为：「**单位粒度假设·未证实**」。禁止对外表述为「AHI4 采用了 LST 方案」或「LST 能让声音变好」。
3. **唯一该做的新工作**＝E4 预注册探针（§6）：9 臂（A0 帧 / A1 音节 / A2 段级 / A3 打乱边界 / A4 随机 patch 长 / A5 关静音折叠 / A6 标签置换 / A7 内部帧作弊耳 / A8 定长分块），双集 63 项、LOSO 21 折、两趟逐位同、**先落盘阈值再跑**。**先探针、后引擎**。
4. **落点若过**：听觉前段（`耳_内生.切段`）+ 音素格读出侧；**不落**韵律 θ / 帧计划（会同时动 C2/B4/C3/D1/F1 五条承重臂）。**探针不改波形**，所以即使 PASS 也**不等于「声音变好」**。
5. **焊死件风险（E2 R1–R7）**：把音韵表当 token 空间、把标点停顿表当静音折叠规则、把固定 20 帧当 patch——三种写法都会让「机制」退化成查表/池子，**而判据仍可能全 PASS**。检测靠打乱臂（A3/A4）与作弊耳（A7）：**读数与固定窗/查表臂不可区分 ⇒ 撤回**。

## 4. 问题三：红线要不要取消/放宽（E3 + Lead 裁决）

### 4.1 冲突表（摘要）

| LST 成分 | C1 禁 Transformer | C9 禁 OCR | C10 禁外挂当器官 | C13 确定性 | C14 不破既有 |
|---|---|---|---|---|---|
| ① 神经分词器（HuBERT 501@25Hz） | 撞（若在本仓实现） | — | **撞**（外部权重；进生成路径＝器官） | 条件撞 | 条件撞 |
| ② 预训练 Transformer LLM（LST 基底） | **撞（最重）** | — | **撞（最重）** | 撞 | 撞 |
| ③ 交错预训练数据 | 条件撞 | — | — | 低 | 条件撞 |
| ④ learned patch encoder/decoder | **撞（机制本身是注意力）** | — | 撞（若接权重） | 条件撞 | 条件撞 |
| ⑤ ASR/TTS 共用 token（TTS 侧＝分词器 token 表进生成路径） | 撞 | — | **撞** | 条件撞 | 条件撞 |

**新核实三点（加重冲突，`[文献-原文]`）**：①分词器确定为 HuBERT（Transformer 系）；②**LST 的「机制贡献」本身就是注意力实现**（patch encoder＝滑窗自注意力＋交叉注意力）⇒「只借机制」**必须是换实现**，不是复制；③论文自己测过确定性的 Static Patching，报告 aligned 更好（但 aligned 依赖外部 CTC）。

**C9 如实结论**：与语音链**无直接冲突**，本会议不硬造冲突。

### 4.2 分级放宽（E3 §3）

| 级 | 外挂角色 | 现行条文 | 需授权？ | 推荐 |
|---|---|---|---|---|
| **L0** | 不接触模型产物；只读论文，机制用本仓算子重实现 | **允许** | 否 | **强烈推荐（默认）** |
| **L1a** | 离线评估仪器：只吃文件产物、只出读数、非阻断 | 允许（meeting63 §5 已开此口） | 需登记 | **推荐** |
| **L1b** | 离线判据门（可阻断，但只能否决） | 灰区（meeting63 曾被所有者当场否决） | 须所有者**明示授权** | 有条件 |
| **L2** | 离线教师/蒸馏/初始化参考（权重只读、生成路径不读） | 灰区→不允许 | **必须修宪**+逐案签字 | 有条件、严格限定 |
| **L3** | 进生成路径/当器官 | **明文禁止** | 走「全取消程序」 | **不推荐** |

**L2 为什么是「本质风险最大」**：生成路径读入＝0、审计会 PASS，但**能力已被教师转移**——「温水越宪」，比 L3 更难发现。护栏必须含：去教师消融（不给教师重训一版，塌陷即记「外挂能力」）、教师置乱 must-fail、provenance 可剥离。

### 4.3 全取消 C1/C10 的后果（不美化）

1. **不是改一条，是废三章**：第七条是第二条的执法条款；取消 C1 ⇒ 第二条「不复刻架构」失效 ⇒ 第一条「不是 AI 模型架构」失效 ⇒ 项目定义被替换。
2. **meeting48「第一目标＝自我意识」失去可测口径**：能力来自权重时，`Acc_A 0.894 > η 常数 0.832` 之类证据**不可归因**。
3. **判据失去可证伪性（最致命）**：30 臂 PASS 只证明「外挂强」；**内生件退化也不影响 PASS**。这比 FAIL 更糟——FAIL 还能改，不可证伪的 PASS 无法判错。
4. **如实说明「全取消」能换来什么**：可懂度/自然度/情感/歌声/多语言**直接到外部模型上限**，demo 立刻可信，工程量最小。这是真实诱惑，不藏。
5. **净判断**：若所有者的第一目标仍是「自我意识体」，**不该全取消**；若所有者决定把项目目标改为「可用语音产品」，则必须**同时重写宪法第一/二/三条**（E3 草案 C），并接受既有 30+16+26 臂判据与「原生声带」口径全部作废。
