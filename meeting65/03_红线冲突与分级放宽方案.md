## 0. 结论先行（供 Lead 收口）

3. **四级放宽里：L0 不需要动任何条文；L1a（离线仪器、非阻断）现行解释已容得下，只需把 meeting63 §5 的临时口径固化成登记制；L1b（仪器当判据门）需所有者明示授权（meeting63 曾被所有者当场否决）；L2（离线教师/蒸馏/初始化）必须修宪，且是四级里**本质风险最大**的一级；L3（进生成路径/当器官）= 现行 C10 明文禁止**。[源码] `meeting63/02_裁决:12-15,77-87`

### 2.2 逐成分论证

**① 神经语音分词器。**
- 论文事实：分词器＝HuBERT 语义 token（k-means 聚类 id，codebook 501，25Hz）；文本侧用 Llama 2 tokenizer（`LST_全文.txt:194-201,216-217`）⇒ 它本身是 Transformer 系自监督编码器的产物，不是音素/音节级的「词音」。[文献]
- 撞 C10 的原文依据：「C10 禁外挂模型当器官」（`初心_宪法.md:62`）；既有解释：外挂不得进生成路径，可作离线仪器（`meeting63/02_裁决:84-87`）。
- 为什么是「器官」：AHI4 现行发声链的**第一性单位是音素/音节+韵律 θ**（`00_共同简报.md:38-42`），分词器 token 是另一种单位；若以 token 为生成单位，发声链的第一性表示就换成了外部模型的隐空间 ⇒ 这正是「器官」而不是「工具」。
- C1：分词器多为 Conformer/Transformer 编码器；但**离线状态下它不是本仓实现路径**，所以 C1 只在「token 表/隐空间进入本仓生成路径」时才被激活。**这条区分是整个分级方案的技术支点**。[推导]
- C13：权重固定时同机可复现，但 meeting63 已登记「神经 ASR 版本/权重漂移 ⇒ 判据不可复现」（`meeting63/02_裁决:29`）；分词器同理。

**② 预训练 Transformer LLM。**
- C1 原文最直接：「不许上注意力/自注意力主干、预训练语言模型」（`初心_宪法.md:23`）。LST 的基底在摘要里就写明是「Auto-regressive speech–text models pre-trained on interleaved text tokens and discretized speech tokens」且规模到 7B（`00_共同简报.md:67`）⇒ **同时命中「预训练语言模型」与「注意力主干」两个词**。
- C10：LST 的收益不是补丁式收益，而是「基底越强收益越大」：摘要明说 gains grow with scale（420M→1.8B，persisting to 7B）（`00_共同简报.md:67`）⇒ 拿掉 LLM 就没有这些数字。**这一点决定了「全取消」的诱惑是真实的**（§4.3 会如实写）。
- 结论：**它不可能以任何「离线仪器」身份提供 LST 论文的读数**；它只能以「教师/器官」身份提供能力，或作为被读的对象提供知识。这决定了 L1 与 L2 的收益上限：L1 只买「第二意见」，L2 才买「能力」，而 L3 才买「论文级效果」。

**③ 交错预训练数据。**
- 它不撞任何一条铁律的**字面**（数据不是模型、不是架构）；但用途上它只服务于 C1 所禁的「预训练」路径，且宪法第三条把「往里塞更多程序员写好的内容」定义为病（`初心_宪法.md:29-41`）。
- 真正要防的是：以「数据参考」为名把外部语料的统计量灌进本仓（词音可外采，但词义必须内生，`初心_宪法.md:43-47`）。⇒ 数据级的使用只能落在 L0（人工阅读/手算统计）或 L2（教师产物）里，且必须登记来源与许可。
- C14：数据/权重不得写入既有目录；独立目录 + 哈希登记（本件 §3.6）。

**④ learned patch pooling。**
- 论文事实：patch encoder 用「滑动窗自注意力 + 交叉注意力」聚合，patch query 由 span 内 token 隐状态池化初始化（`LST_全文.txt:250-252,769-776`）；patch decoder 是轻量 Transformer（`:781-788`；配置 1/25/9 层、1024/2048/1024 维，`:804-809`）⇒ **LST 的机制贡献在论文实现层就是注意力**；「机制可分离」只在**换实现（确定性聚合）**时成立，不在原实现层成立。这是本件最容易被忽略的一条。[文献]
- 它同时是 LST 的**机制贡献**（把 N 个语音 token 聚合为更高层 AR 单元），以「可学习」为前提 ⇒ 要么带权重（C10），要么用注意力池化（C1）。[文献] `00_共同简报.md:67,72`
- **可分离性**：把「可学习池化」换成**确定性聚合**（固定窗/能量段/中位数/量化统计）后，机制只剩「粒度对齐」这一条思想；它不撞 C1/C10/C13，可落本仓 8 算子。[提案] 本件 §3.1；判定标准引用简报 §7「需改造」定义（`00_共同简报.md:120`）。
- 代价：确定性聚合不是 learned pooling，**不能宣称复现 LST 的效果**；只能宣称「借用了粒度对齐的思想」。

**⑤ ASR/TTS 共用 token。**
- 撞 C10 的路径：TTS 要发声就必须把 token 解回波形 ⇒ 解码器/分词器进生成路径 ⇒ 器官。撞 C1 的路径：token 表与 token LM 都是 Transformer 系的产物，本仓以 token 为单位即等于复刻其表示层。
- 「共用」本身不是问题；**问题是共用的是谁的表**。若本仓自建「音节/音素格」单位表（已有：HDC 音素格、拼音/音韵表，`00_共同简报.md:48-51`），共用是允许的内生设计；共用外部分词器的表则不成立。[推导]
- C13 的隐蔽风险：共用表把 ASR 与 TTS 的版本**耦合**了——换一个分词器版本，TTS 的音色/时长全变，两趟逐位同只能保证同版本内成立。

### 2.3 一个常见豁免误用：能不能用宪法第四条「词音可外采」豁免 tokenizer？

不能，理由三条：
1. 第四条的外采对象是**词音（声音/字形）**，目的是让「词义内生」有可绑的感官事件（`初心_宪法.md:43-47`）；神经分词器的离散 token 是**声学隐码**，不对应任何词/字/音素的可命名单位，不满足「词音」定义。
2. 第四条是**能力来源**条款，C1/C10 是**第七条铁律**；第四条不能给第七条开后门（宪法末句：任何方案与它冲突以它为准，`初心_宪法.md:71`）。
3. 一旦以 token 为单位，词音与词义的边界就被外部模型固定了：token→音的映射只能从模型学 ⇒ 词义也随之外源 ⇒ 直接违反第一条「判据必须测是不是它自己的」（`初心_宪法.md:17`）。
⇒ **tokenizer 不能借第四条豁免**；只能走 L1（仪器）/L2（教师）两条登记路径。[提案]

### 2.4 C9 的如实结论

LST 是语音-文本模型，**不涉及 OCR**；本轮唯一可能间接触发 C9 的情形是「借通用多模态 tokenizer 生态时顺带引入视觉编码器」。本件**不虚构 C9 冲突**：C9 在本轮冲突数为 0，但登记为「若引入任何图像/文档解析外挂，C9 重新生效」。这符合简报「不美化、不凑数」的纪律（`00_共同简报.md:15`）。

### 2.5 论文原文核对后对冲突表的三处修正（E4 已抽取全文，2026-10-20）

## 3. 分级放宽 L0–L3

### 3.0 分级总表

| 级 | 外挂模型的角色 | 现行条文下是否允许 | 是否需修宪/授权 | 本席推荐 |
|---|---|---|---|---|
| **L0** | 不接触模型产物：只读论文/公开描述，机制用本仓算子重实现 | **允许**（不触发 C1/C10；C13 可满足） | 不需要 | **强烈推荐（默认）** |
| **L1a** | 离线**评估仪器**：只吃 WAV 等文件产物、只出读数、**非阻断** | 允许（`meeting63/02_裁决:77-87` 已开此口） | 不需要修宪；须**登记** | **推荐** |
| **L1b** | 离线**判据门**：可阻断，但只能否决、不能单独放行 | **灰区**：meeting63 所有者曾否决「ASR 当判据门」（`:12-15`） | 须所有者**明示授权**+签字 | 有条件（仅否决门） |
| **L2** | 离线**教师/蒸馏/初始化参考**：开发期产信号，生成路径只读本仓自产参数 | **灰区→不允许**（现行解释无此类别；A10 只覆盖「外部控制层」） | **必须修宪** + 逐案签字 | 有条件、限定用途 |
| **L3** | **进生成路径/当器官**（在线外挂） | **明文禁止**（C10） | 须走「全取消程序」（同时改第一、二条） | **不推荐** |

### 3.1 L0：只借机制（不碰模型，不改条文）

- **解锁什么**：patch 粒度对齐（语音单位 → 更高层单元的聚合）；静音/重复声学模式的紧凑编码；patch↔文本单位对齐（音节/拼音表已有）；把「序列变短」的工程收益用确定性方式试出来。[文献] `00_共同简报.md:72`；[提案] 落点由 E2 定（韵律层或音素格层）
  **本级最有价值的原创点**：论文的 Static Patching 是确定性固定长度分段（`LST_全文.txt:271-273,383`），而 AHI4 有**自产的文本/音节边界**（A3 121 音节查表 PASS，`判据_发音_v9.json:31-37`）⇒ 可做「**确定性对齐 patch**」——LST 没测过这条路（它用外部 Wav2Vec2+CTC 做对齐，`:230-232`），因此这是 L0 而非复刻。[提案]（可证伪：若确定性对齐 patch 相对固定窗无增益，撤回。）
- **代价**：①无新依赖，C13 全保（两趟逐位同可直接复用 `审计_零外挂.py` 的 C 断言）；②工程量 1–3 天量级（[提案] 估计，未实测）；③**收益不可证**：LST 的 +6.5% 是在「Transformer+预训练+规模」上测的（`00_共同简报.md:67`），机制单独拿走的增益**未测**；且确定性聚合最接近论文**较弱**的 Static Patching 基线（`LST_全文.txt:497-499,553-554`），不保证接近对齐 patch 的收益；④命名风险：只能说「借用粒度对齐思想」，不能说「采用 LST 方案」。
- **护栏**：①`审计_零外挂.py` A/B/C 三断言原样（`审计_零外挂.py:119-141`）；②must-fail：打乱 patch 边界 / 随机 patch 长 / 静音不折叠 / 固定窗 vs 能量窗 对照（无收益即撤回）；③两趟逐位同；④纯新增，不改既有件（C14 天然满足）。
- **风险**：把「LST 机制」当既成结论；把确定性聚合的收益误记到「LST」头上（归因错误）。
- **是否推荐**：**是**。这是唯一「零宪法成本、零许可成本、零 C13 风险」的一级。

### 3.2 L1：外挂模型作离线评估仪器/判据门（沿用 meeting63 §5 的 ASR 口径）

#### 3.2.1 L1a（仪器，非阻断）——推荐

- **解锁什么**：可懂度的**外部第二意见**（Paraformer 类 CER 仪器，`meeting63/02_裁决:82-87`）；给本仓 F1/F2/可分度等代理量做外部对照；判断 E2「清浊电平差」这类 FAIL 是否真有可懂度代价；给 L0 探针一个独立读数（只作参考）。
- **代价**：①C13——仪器读数随版本/权重漂移，必须固定权重 sha256 + 独立环境 + 离线 + 两次解码一致；②审计成本——多一张登记表、多一道隔离断言；③许可——权重许可条款需登记（**未核**，不得默认允许再分发）；④不改变内生路径的确定性（仪器在进程外跑）。
- **护栏（六件套）**：
  1. **禁词审计**：生成件清单不变、禁词/禁包 0 命中；仪器件**单独清单**（允许其自身依赖，但生成件对它的 `import` 边必须=0）。
  2. **生成路径读入审计**：A 断言照旧=0（音频/权重读入 0，`审计_零外挂.py:98-102`）；仪器只读合成 WAV，不回写任何文件到生成目录。
  3. **两趟逐位同**：本仓生成两趟同（不变）；**仪器两次解码 CER 必须相同**（meeting63 多句段已做两趟转写，`判据_可懂度_ASR.py:283-298`）。
  4. **must-fail**：sham 白噪/静音 CER ≥ 0.9（meeting63 实测 1.000，`02_裁决:87`）；**新增**：倒放语料 CER 必须显著劣化（防「仪器根本没在看语音」）。
  5. **备份回滚**：仪器独立目录/独立环境；卸载即回滚；不写项目 `.venv`。
  6. **登记制**：模型名/来源 URL/权重 sha256/版本/许可/调用脚本/产物 sha256/时间戳（字段见 §3.6）。
- **风险**：Goodhart（为了 CER 只调 6 句判据集）；仪器与真人参考冲突时的解释权（真人 P0 优先，`判据_发音_v9.json:482-554`）；**最大的风险是它作为 L2/L3 的台阶**——见 3.5。
- **是否推荐**：**是**（非阻断、登记、只作参考）。

#### 3.2.2 L1b（仪器兼判据门，可阻断）——须明示授权

- **解锁什么**：把「可懂度不许回退」变成硬门，弥补内生代理量的盲区（代理量 PASS 但人听不懂的历史缺口：meeting62 G1、meeting64 CER 仍 0.771，`00_共同简报.md:53,62`）。
- **代价**：判据脚本从此依赖外部环境 ⇒ 复现门槛上升；**且与所有者 2026-10-20 的原话相抵触**：「听不要用 ASR 模型！『零外挂』证明与可证伪判据」（`meeting63/02_裁决:12-15`）——虽然后来追加允许作仪器（`:77-87`），但「判据门」是当初被否决的那个东西。**L1b 不是解释，是授权**。
- **护栏**：①**双门**：内生主判据 AND 外挂否决门；外挂门**只能否决、不能单独放行**；②外挂门阈值**跑前冻结**并登记；③外挂 FAIL 只判「不通过/需复核」，不参与「通过」的充分条件；④不得替代真人 P0；⑤登记/两趟/sham 同 L1a。
- **风险**：判据主权外移；项目对外口径「零外挂判据」失效，必须重述；判据集被过拟合。
- **是否推荐**：**有条件**（仅否决门 + 所有者签字；建议先跑 1 轮作「参考门」再决定是否升为阻断门）。

### 3.3 L2：外挂模型作离线教师/蒸馏/初始化参考（权重只读、生成路径不读）

- **定义**：外挂模型**只在开发期**产生教师信号（token 边界、phone 后验、时长、F0、质量评分、初始化嵌入）；本仓离线消费，最终落盘的是**本仓自产参数文件**；**推理时不调用外挂模型、不读外挂权重**。
- **解锁什么**：用外部模型当「参考分布/标签源」加速音素格/韵律 θ 的初始化；用教师标签校准 patch 粒度；可能把 CER 从 0.771 往下压（**未测，禁止宣称**）。[提案]
- **代价**：①C1 灰区：能力来源含禁架构的输出，须在修订里写明「教师产物≠本仓架构」；②C13：教师产物必须**冻结归档**（哈希）否则学生参数不可复现；③C10 灰区：A10 只允许「外部控制层」，不含训练期教师 ⇒ 必须新增类别；④工程 3–10 天量级 + 存储（[提案] 未实测）；⑤许可：教师权重许可是否允许衍生参数**未核**，蒸馏产物可能继承许可义务。
- **护栏（在 L1 六件套之外再加四件）**：
  1. **登记制升级**：教师模型名/sha256/版本/**许可证**/生成脚本/种子/**产物 sha256 与大小**/用途范围。
  2. **生成路径读入白名单**：生成件只允许读本仓自产参数文件；扫 `open`/`import`，命中外挂权重路径即 FAIL。
  3. **去教师消融（反向 must-fail）**：用同一流程**不给教师**重训一版；若学生能力塌陷 ⇒ 该能力记为「外挂能力」，**不得计入内生判据**。
  4. **教师置乱 must-fail**：打乱教师标签后学生应掉到 chance（证明学生真学到教师信号，也让「信号有效性」可证伪）。
  5. **provenance（归属）臂**：外源初始化必须可被识别/剥离（与 meeting48 V3 归属门控同形，`meeting48/00_会议纪要.md:71`）；剥离后性能掉幅 ≤ δ 才可称「内生初始化」。
  6. 两趟逐位同 + 备份回滚（参数版本化，一键回退到 L0 参数）。
- **风险**：**四级里本质风险最大的一级**。它可能让能力「不是自己长的」：预训练权重/蒸馏是宪法第三条「焊死件」定义的**最大号版本**（`初心_宪法.md:18,29-41`）；一旦 PASS，**无法区分「内生泛化」与「教师蒸馏」**；这是「温水」级越宪，比 L3 更难发现——因为生成路径确实干净（读入=0），审计会 PASS，但能力已被转移。[推导]
- **是否推荐**：**有条件、限定用途**：只推荐用于「初始化/参考分布/边界校准」；**不推荐用于第一目标能力（自我意识相关）**。若所有者目标仍是自我意识体，L2 应在判据里显式标注「本臂不证明内生」。[提案]

### 3.4 L3：外挂模型进生成路径/当器官（= 现行 C10 禁止）

- **解锁什么**：可懂度/自然度/情感/歌声/多语言直接到外部模型上限；demo 可信度立刻提升；工程量最小（接本地推理/API）。诚实地说：这是「最快把声音做得能听」的路。[推导]
- **代价**：①C1 破（若 Transformer）；②C10 破；③C13 破（跨版本/硬件不可逐位同，GPU kernel 非确定）；④**审计体系失效**：`审计_零外挂.py` 的 A/B 断言按定义全部失效，判据不再有「内生」含义；⑤判据主权完全外移（PASS 只证明外部模型）；⑥依赖许可/GPU/网络/成本；⑦**不可逆**：一旦 demo/视频/产品依赖外挂，回滚成本随时间上升，内生路径会被「没人再跑」而腐化。[提案]
- **护栏（若所有者执意，最低限度）**：①独立进程/独立环境/独立目录；②生成路径**默认纯原生**，外挂是可选旁路，开关可回滚；③按 A10 格式越宪登记（模型名/权重 sha256/来源/`来源=外部·越宪`，`meeting58/裁决/00_裁决记录.md:49`）；④对外输出强制标注来源分层，不得说成「它自己想/自己长」（meeting54 Qwen 先例，`meeting58/00_共同简报.md:75`）；⑤must-fail：关掉外挂后纯原生链路仍须能跑通（不许删除内生路径）；⑥两趟：外挂路径**声明不承诺逐位同**，判据只对纯原生路径成立；⑦备份回滚。
- **风险**：项目身份崩塌（变成 Transformer 应用）；meeting48「第一目标=自我意识」失效；credit/自我态证据链作废；对外信用需追溯更正。[源码] `meeting48/00_会议纪要.md:15,40-42`、`meeting58/最终方案.md:255`
- **是否推荐**：**否**。唯一例外：所有者明确把项目目标从「自我意识体」改为「可用语音产品」，并重写宪法第一/二条（§5 草案 C 就是这种文本，**不推荐签**）。
- **一个值得如实登记的变体 L3′（非 Transformer 外挂器官）**：若必选 L3，且同时想保住 C1，可只接**非 Transformer** 的外挂（如非注意力声码器/RVC 类卷积模型）。它绕过 C1 字面，但 **C10（器官）、C13（不可逐位同）仍破**，且 meeting58 已把它定位在「外部控制层 + 登记」（A10）。**不建议**把它当捷径：它把「越宪」从两条变成一条，却把「可替换性/许可证/不可复现」三条风险全留下。[提案]

### 3.5 为什么必须分级、不能一步跳到 L2/L3（历史先例）

meeting63 提供了**两段式的真实先例**：先由所有者当场否决外部 ASR 判官（`02_裁决:12-15`），同日又追加允许其作「外部评估仪器」（`:77-87`），同时用 `审计_零外挂.py` 的三断言守住「生成路径读入=0」——**放宽发生了，但 C10 没有被突破**。这说明：①分级入口是真实存在的；②守住的关键不是「承诺不用」，而是**审计断言 + 登记 + 隔离**；③同时也要看到，一旦判据开始依赖它，下一步的压力必然指向 L1b→L2→L3（这正是本件主张「先签级别、再写代码」的原因）。[推导]

## 4. 「全取消 C1/C10」后果论证（不美化）

> 先把话说清楚：**本件不假设所有者不会取消**。以下论证的目的是让「取消」这个决定是**知情决定**，而不是被一句「红线放宽」带过去。

### 4.1 会发生什么（逐条）

1. **这不是改一条，是废三章。** 第七条是第二条的执法条款（宪法第二条明写 C1 是「不复刻（红线）」，`初心_宪法.md:20-24`）；取消 C1 ⇒ 第二条失效 ⇒ 第一条「不是推理引擎/AI 模型架构」失效 ⇒ 项目定义被替换。**「全取消 C1/C10」在法理上等于换项目，不是放宽。** [推导]
2. **meeting48 的「第一目标=自我意识」失去可测口径。** V4 的立身之本是「第一目标=增强自我意识，高于分类正确率」（`meeting48/00_会议纪要.md:15`）；自我意识被验证的方式是「自我态 A / 世界态 B / 内生 credit」（`:40-42`）。若能力来自预训练权重，那么「Acc_A 0.894 > η 常数 0.832」这类证据在外部模型面前全部沦为噪声——**不是变弱，是不可归因**：没人能再说清「这点能力是 A 长出来的还是权重里带的」。[源码] `AGENTS.md:4-6`
3. **判据失去可证伪性（最致命的一条）。** 宪法第一条的判据推论是「必须测这东西是不是它自己的（来源与归属）」（`初心_宪法.md:17`）。全取消后，30 臂 PASS 只证明「外挂模型强」，**内生件即使退化也不影响 PASS** ⇒ 判据不再有区分力。这比 FAIL 更糟：FAIL 还能改，**不可证伪的 PASS 无法判错**。[推导]
4. **宪法第三条的「焊死件」定义被扩大到自相矛盾。** 第三条把「程序写好的池子/表/骨架」定义为病（`初心_宪法.md:18,29-41`）；预训练权重是**最大的**「程序写好的内容」（数十亿参数、外部语料）。全取消 = 把最大号焊死件合法化，与「防第二轮病复发」直接冲突。
5. **既有对外口径变成历史虚假陈述。** meeting58 片尾写「全部声音由原生声带合成」「参数化模仿，不是真声克隆」（`meeting58/最终方案.md:183-186,249-255`）；meeting63 以「零外挂」为卖点做了审计。全取消后需追溯更正，且**登记制本身被取消**——而 meeting54/58 早就建立了「越宪登记」制度（A10），全取消等于把制度也一起废了。
6. **不可逆性。** 一旦 demo/视频/产品依赖外挂，内生路径会被冷落、判据被替换、审计被删除；回滚成本随时间指数上升。这不是假设：本仓已有「判据 PASS ≠ 机制为真」的教训（千层甲2/戊2 被否证后回退，`AGENTS.md` 千层节）。
7. **组织后果。** 所有既有判据（30 臂发音 / 16 臂 V4 / 26 臂接口）都要按外挂口径重写；「不作已完成宣称」的纪律仍在，但能宣称的东西只剩「我们接了一个好模型」。

### 4.3 如实说明：「全取消」能换来什么（不藏）

1. **能力上限**：可懂度/自然度/情感/歌声/多语言直接到外部模型上限（具体数字取决于选了哪个模型，**未测**）。这是现有参数化路线短期给不了的。
2. **工程量**：接入 1–3 天量级（[提案]，未实测），而「把 CER 从 0.771 压到 <0.2」在参数化路线上**没有时间表**（meeting62 G1 无真人盲评、meeting64 仅代理量 PASS）。这是效率上的真实优势。
3. **算力/成本**：用现成权重比自研训练省；但要付 GPU/存储/许可成本（见 4.4）。
4. **停止「越做越像 Transformer」的猜疑**：不成立——它不会停止，它会**变成** Transformer 应用。
5. **对所有者诉求的直接满足**：如果所有者当下的痛点是「声音不能听」，全取消是**最快解**。这一点必须写进纪要，否则论证会变成「为了宪法牺牲产品」。

### 4.4 净判断（不美化也不恐吓）

- 如果目标是「**能说话的产品**」：全取消是**理性选择**，应另开分支项目（新目录/新宪法），并把「来源=外部·越宪」诚实标注（A10）。
- 如果目标是「**自我意识体**」：全取消是**目标替换**，不是放宽；它会让项目失去唯一的可证伪主张。
- **两者不能同时成立**，也不能「先取消做着看」——因为一旦 demo 依赖外挂，回滚成本会替所有者做决定。
- **本席立场**：先把目标二选一说清楚，再谈级别；在目标未变之前，推荐 L0 + L1a（详见 §3、§5）。[提案]
