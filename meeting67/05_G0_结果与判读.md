## 3. 机制判读（为什么 v0 器官不够；供 v1 设计）

按 meeting66/01 的六条根因对照，本次读数把「哪一层不够」钉在**激励层**：

1. **噪声源没有「部位/谱形」**：v0 的清擦/送气噪声 = 白噪 × 帧增益，再经 LPC 声道滤波 ⇒ 噪声被**元音共振峰**成形，而不是在收缩点后成形。普通话 s/sh/x、z/c/zh/ch/j/q 的部位差（谱重心）在 v0 里**没有表示**——与 v8.1 的 ①③ 同型。样本 12（禁止脑瓜包容禁止）全臂 1.0 正是这类密集擦/塞擦段。
2. **爆破/塞擦的亚帧瞬态没有位置**：10 ms LPC 帧 + 单脉冲 ⇒ 1–3 ms 除阻瞬态被量化掉（v8.1 死因④原样保留在 v0 等价类里）；v0 的「声门源」也没有噪声猝发。
3. **声门源谱倾斜/开商不可调**：Rosenberg 脉冲固定开商 0.6、气声固定 0.25 ⇒ 无法表达送气/气声/紧喉，也解释了为何 P2 不稳定地差于 P1。
4. **F0/清浊用 10 ms 自相关**：清擦段与低能量段的 F0 倍频/清浊误判会直接摧毁可懂度（样本 43 的 `ok o ok` 被转成 `ok 我 OK 我 OKI` 是典型）。
5. **LPC 全极点 18 阶/10 ms**：对鼻化、擦音零点、宽带噪声谱只做极点在拟合，**过平滑**；真 mel→GL（0.0585）证明同一套 ASR 下只要谱包络够准就可懂 ⇒ 差距在 `mel(80×10ms) → LPC(18×10ms) → 简化激励` 这两步。

> **判读的重要性**：这不是「物理器官路线不行」，而是「**v0 等价类（LPC 声码器 + 单一激励）不行**」。v1 物理器官（LF 可微主源 + 两类噪声源 + 亚帧瞬态 + 面积函数波导）正是针对上述 1–4 的明确设计；G0-v2 将只换激励/瞬态/分辨率，判据不变。

## 5. 下一步（G0-v2，预注册后再跑；不在本件声称）

按声学席 R1 与本次失败位置，v1 改进的最小清单（每条都配可测判据）：

1. **噪声源部位化**：送气（声门后）与摩擦（收缩点后）两类独立噪声源，各自经对应谱形（而不是元音共振峰）——判据：擦音/塞擦样本（如样本 12）CER 下降 ≥0.20；
2. **亚帧瞬态**：1–3 ms 爆破/塞擦除阻事件，输出帧 5 ms（内部 ≤0.25 ms）——判据：塞音/塞擦样本 CER 下降 ≥0.10；
3. **F0/清浊稳健化**：八度校正 + 清浊能量/谱平坦度判据，10 ms → 5 ms——判据：F0 倍频错误率、清浊错误率各下降 ≥50%（相对 v0）；
4. **声门源可调**：LF 谱倾斜/开商/气声增益（送气段）——判据：P2 类臂均值 ≤ P1，且样本 43/56 不再退化；
5. **LPC/波导保真**：18 阶 → 22–24 阶或 5 ms 帧；KL 波导重做映射并用「冲激响应 vs 1/A(z)」标定（共振峰偏差 ≤100 Hz）——判据：单帧谱距离下降，且 G0-v2 主臂 CER ≤0.20（PASS 线）。

**G0-v2 预注册要求**：同口径（8 条 4 s、同片段表、同 ASR、同 T_h、同护栏 0.15）、同判据（P2 主臂 0.20/0.35）、**先写预注册再跑**；若 G0-v2 仍 >0.35 ⇒ 按「器官路线判死」上报所有者，回 v13 路线并如实登记。

## 6. 诚实边界

1. 本次是 **v0 等价类**（LPC 声码器式），**不等于** v1 物理器官（LF 可调源 + 2 质量校准臂 + KL 波导 + 噪声部位 + 亚帧瞬态）；G0-v2 才是对物理器官的判定；
2. oracle 控制本身也是从音频分析的「上限」，它失败只说明**表示/激励层**不足，不说明「控制学不出来」；
3. 4 s 片段口径（ASR 上下文比整句少）与 meeting66 整句读数不可直接相减；本件只做同段对照；
4. 单说话人（SpeakerA 7 代语料）；片段来自**口语对话**，含口头语（ok/哎/哦），CER 受 ASR 对口语的处理影响；
5. P3 的 0.97 是**实现错误**的证据，不是波导不可行的证据；v1 必须重做并标定；
6. 本件读数只有 n=8、单次遍历；G0-v2 应保持 n=8 以便逐条比较。
