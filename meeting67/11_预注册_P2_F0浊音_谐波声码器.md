## 0. 为什么做（与 G0/器官线无关）

当前 v13 的声码器是 **Griffin-Lim**：只由 log-mel 恢复波形，**音高（F0）与相位未被显式建模**（mel 丢 F0）。这是与「核心表达」正交的一轴——不保证解决可懂度，但可能改善韵律/自然度，且**不需要新数据**（meeting66 结论：无新数据时唯一还可做的正交轴）。

**非目标**：不换生成范式（AR/flow 已否证，`meeting66/11` P4）；不扩数据；不改 v13 的 mel 预测主干口径；不宣称「会说」。

## 1. 三臂 + 阳性对照（先定后跑）

| 臂 | 内容 | 判据用途 |
|---|---|---|
| **A0 基线** | v13 + Griffin-Lim（v13 `ckpt_e0150`，4轮/阻尼0.5；`ckpt_e0100`，7轮/阻尼0.5） | 对照（已有同仪器复评读数） |
| **A1 阳性对照** | **真** log-mel + **真** F0/浊音（离线提取）→ 谐波声码器 → ASR | 护栏：谐波声码器/仪器可用性（CER ≤0.15） |
| **A2 主臂** | v13 预测 mel + **预测** F0/浊音 → 谐波声码器 → ASR | 主判据（双集 CER） |
| **A3 只测头** | v13 预测 mel + 预测 F0/浊音 → 仅算 F0 相关/浊音准确率（不出波形） | 头质量判据 |

> 说明：F0/浊音头本身不改变 Griffin-Lim 波形（GL 不吃 F0），所以 **A2 必须换成谐波声码器**才可能影响 CER；A3 单独报告头质量，避免「头很好但波形无效」被误读。

## 2. 实现口径（最小参考实现，确定性）

### 2.1 数据侧：F0/浊音提取（离线仪器，C10）

- 对 167 条训练 wav 与 S1–S12/S13–S18 参考句：**离线**提取帧级 log-F0 与浊音标志；
- 工具优先级：① `pyworld`（DIO + StoneMask，确定性参数固定）；② 若环境无 pyworld → `librosa.pyin`（固定参数）；③ 若均不可用 → **自写确定性 YIN/自相关**（固定阈值/窗长，记录实现与参数）；
- 帧率 10 ms（与 mel 同 hop）、F0 范围 60–500 Hz、清音帧 F0=0 且浊音标志 0；
- **定位**：仅训练/分析信号，**不得进入生成路径**（不 import 到推理闭包；C10）；产物落盘 `产物/P2/f0/<split>.npz` + 参数/版本/`sha256` 记录。

### 2.2 模型侧：F0/浊音头

- 在 v13 编码器（Conv1D 残差堆）后接**两个输出头**：`logF0`（只在浊音帧计 L1/Huber）+ `voicing`（二分类 BCE，类别加权）；
- **冻结 v13 主干**（防漂移、省算力），只训两个头的 2 层 MLP（≤64k 参数）；
- 训练 10–20 min（单卡），数据 = 训练集（同 167 条），验证 = 训练内留出（不碰 S1–S12/S13–S18）；
- 输出做确定性后处理：浊音概率 <0.5 ⇒ F0=0；F0 夹到 [60,500] Hz，10 ms 帧对齐。

### 2.3 声码器侧：谐波声码器（自写，确定性）

- 输入：80 维 log-mel（帧级）+ 帧级 F0/浊音；
- 合成：每个 10 ms 帧内，浊音段用**谐波叠加**（基频 F0，幅度取该帧 mel 的谐波峰/谱包络），清音段用**带限噪声**（谱形取 mel 包络），帧间相位按 f0 累积（固定初相/确定性）；
- 输出 22.05 kHz、峰值归一 0.9；与 GL 同长度；
- **自检**：长度正确 / 两趟 sha256 逐位同 / 读回格式 / 全 finite；
- 定位：本项目自研 DSP 声码器（非外部模型/预训练权重；C1/C10 合规）。

## 3. 判据（先定后跑）

### 3.1 主判据（A2）

1. **双集 CER 不退化**：历史 ≤ A0 历史 + 0.01 **且** 留出 ≤ A0 留出 + 0.01；
2. **至少一集改善**：历史或留出相对 A0 下降 **> 0.01**；
3. 两集必须同时给出；**禁止各取优合并宣称**；
4. 若 1/2 只满足其一 ⇒ 判「无有效增益」，只登记为可选模块，不设为默认。

### 3.2 头质量（A3）

| 指标 | 门槛 | 口径 |
|---|---|---|
| F0 相关（浊音帧） | ≥ 0.80 | 对训练留出集（未见句），逐帧 Pearson |
| 浊音准确率 | ≥ 0.90 | 二分类 accuracy |
| 浊音 F1（清音类） | ≥ 0.80 | 防「全判浊音」混过 |

### 3.3 护栏（缺一即「未完成」/该臂作废）

| # | 护栏 | 口径 |
|---|---|---|
| P2-1 | A1 阳性对照 | 真 mel + 真 F0 → 谐波声码器 → ASR **CER ≤0.15**；否则声码器/仪器不可用 |
| P2-2 | sham | 白噪 / 静音 CER ≥0.9 |

## 5. 诚实边界（预注册时声明）

1. **F0/浊音与可懂度正交**：即使头很好、谐波声码器可用，CER 也可能不改善；「改善 >0.01」是判据不是承诺；
2. **Griffin-Lim 的相位问题仍在**：谐波声码器只解决「有声码器侧的音高」，不解决 mel 预测本身的平滑/过平滑；
3. 单说话人（SpeakerA）、2.7 h、对话语料 vs 书面报告句的文体域差不变；
4. F0 提取工具（pyworld/librosa）是**离线分析仪器**，不进入生成路径；若用自写 YIN，参数固定、可复现；
5. 本点**不与 G0/器官线合并**；器官线已归档（`09`），本点也不复活它；
6. 改口径 = 新预注册；读数不可合并；空着=未测。
