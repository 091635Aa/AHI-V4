## 1. 事实

1. **G0（v0 等价类，as shipped）FAIL 成立**：P2 主臂均值 CER **0.4922** > 0.35（n=8，sd≈0.30，95%CI≈[0.240,0.744]）；护栏（真 mel→GL 0.0585）PASS，仪器可用。
2. 声学席纯 DSP 诊断（`诊断_G0v0失败.json`，n=6）定位到**三个「接线级/工程级」缺陷**（非器官类的本质缺陷）：
   - **气声是死参数**：气声贡献仅 **0.005 dB**（等于没接线）；
   - **P2 比 P1 差的根因**：声门源陡倾斜（≈−12 dB/oct）吃掉高频，而清帧 2–8k/0–2k 比 P2 为 **−14.95 dB**（GL +0.53 dB）；
   - **归一化/失稳 bug**：全局峰值归一化遇单帧滤波器局部失稳 ⇒ 整段被压死、ASR 空输出（52 s 片段实测复现；GL 同段 0.0442）；
   - 另有：4 s 片段口径偏悲观（同引擎 48 s 片段 P1 实测 **0.0988**，远好于 8×4 s 均值）；清浊二值 + 10 ms 粒度 ⇒ 19%「浊帧」实为半浊/气声。
3. 因此 G0-FAIL 的**方向可信**（v0 表示/激励确实不够），但**幅度不可全归因于器官类**——其中约一部分来自上述可实现缺陷。

## 2. 裁决

| # | 裁决 |
|---|---|
| **R-1** | **G0-FAIL 对「v0 as shipped」保持成立**，不改判、不撤销；`03` 的判据与读数继续作为历史事实。 |
| **R-2** | **授权一次 G0-v2 复测机会**（仅一次），理由：已定位的三个缺陷是**接线/工程级**（死参数 + 归一化 bug + 片段口径），修它们**不改变器官类**；这不是"再试试看"，而是"把没接上的线接上"。 |
| **R-3** | **G0-v2 必须另立新预注册**（`07_预注册_G0v2.md`，先于任何读数），沿用同一主判据（P2′ 主臂 ≤0.20 PASS / (0.20,0.35] / >0.35 FAIL）与同一护栏（真 mel→GL ≤0.15）；**不得复用 v0 读数**，两组并列登记、不合并。 |
| **R-4** | **G0-v2 必须带消融臂**（归属证据）：P2′ 主臂 + P1 + **三消融**（关噪声源 / 关源倾斜可调 / 关亚帧瞬态）+ P3′（若 KL 修好）；**n≥16**（降低方差）；片段口径建议 4 s 与 8–12 s 各 8 条（回应"4 s 偏悲观"）；**≤40 次 ASR、≤20 min、单进程**。 |
| **R-5** | **G0-v2 若仍 >0.35** ⇒ 按「器官类（当前可实现水平）判死」上报所有者，回 v13 路线；不再给第三次机会（除非所有者明确要求）。 |
| **R-6** | **G0-v2 通过（≤0.20）之前，学习阶段仍挂起**（W/A/C/D/B 不启动）；通过后按 `02` 的 S1 启动 W/A。 |
| **R-7** | **T-1 口径**：G0-v2 修复清单（声学席 §5 的 8 条）中，只有**第 1 条（归一化/失稳）与第 2 条（气声接线）**属于"修实现 bug"，可视为同一器官类的修正；**第 3–8 条属于器官升级**，必须在 G0-v2 里作为**臂的差异**登记，不能混着改完再报一个数（否则无法归因）。为避免混淆：本次 G0-v2 **只允许改第 1、2 条 + 第 4 条连续清浊/5 ms（工程修复类）**；第 3 条（源倾斜可调）与第 5、6 条（瞬态/LPC 阶）列为 G0-v3 候选，不得在 v2 同时上线。 |
| **R-8** | 所有 G0-v2 读数、脚本 sha256、片段表、消融臂结果落盘 `团队/声学_物理建模/产物/G0v2_*`；写进 `07` 与本目录；**不改 `03` 历史读数**。 |

> 说明：R-7 的收紧是为了守住"可归因"——如果一次改 8 条然后 CER 变好，我们无法知道是哪条起的作用；先只修"死参数 + 归一化 + 清浊粒度"三项接线缺陷，若仍 FAIL，再按 G0-v3 逐条升级。
