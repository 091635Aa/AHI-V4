## 0. 结论先行（可直接落进统一方案的 6 条）

| # | 结论 | 一句话理由 |
|---|---|---|
| R1-1 | 人体发声 = **气源（肺）→ 声源（喉/声带）→ 滤波器（咽/口/鼻）**三段串联 + **两条并联**（噪声源：摩擦/送气；鼻分支）。脑只给**肌肉激活度**，不直接给频率/振幅。 | 声带是被动自激振子（肌弹性-气动力），F0/振幅是**涌现量**。 |

## 2. 机理：肌弹性-气动力学 + 伯努利（写清"伯努利的边界"）

1. **源-滤波器**：声门体积速度 Ug(t) 是声源，声道是滤波器，唇辐射是最后一级（Fant 1960）。
2. **伯努利**：`p + ½ρv² = 常数`。声门窄缝处流速高 → 局部压力低 → 声带被"吸"向中线；跨声门压差 `Psub − p_g` 是驱动力。
   **但伯努利单独不足以产生自激振荡**，还需：①组织黏弹性回复；②声带上下缘**相位差**（黏膜波）；③出口射流/气流分离（Titze 1988；Story & Titze 1995）。⇒ 统一方案若只写"伯努利 = 发声"，是科普级简化，不是可仿真机理。
3. **弦/梁近似**：`F0 ≈ (1/2L)·√(T/ρ_l)`。⇒ 脑无法"直接设 F0"，只能设环甲肌（拉长/增张）与甲杓肌（缩短/增厚）的激活度，**F0 随之涌现**。经验：Psub 每升 1 cmH₂O，F0 约升 2–6 Hz「文献量级/待核」。
4. **声源谱**：声门波形 → 声源谱（常态约 −12 dB/oct 量级）→ 声道传递函数（F1–F5 极点 + 鼻/侧腔零点）→ 唇辐射（+6 dB/oct）。
5. **黏膜波**：cover 相对 body 的滑动/表面波，速度量级 0.5–1 m/s「文献量级/待核」。它使声门不是"硬门"而是"行波门"，这是人声与蜂鸣器的物理区别，也是**气声/紧喉可连续调**的来源。
6. **时间常数对照**：声门周期 3–12 ms（F0 85–350 Hz）；除阻 burst 1–3 ms；VOT 0–100 ms；鼻化起效 20–40 ms。**⇒ 瞬态比神经控制带宽快**（见 §3.4）。

## 3. 脑→器官最小控制通道表（本席位核心交付）

### 3.1 接口定义：脑侧只给「肌肉激活度」

脑侧最小抽象：发声运动皮层 → 皮质延髓束 → 疑核（喉肌 IX/X）、舌下神经核（XII）→ 颅神经/脊神经 → 肌肉。
本线**不建模神经动力学**，器官接口取 **肌肉激活度 a_m(t) ∈ [0,1]**，带宽按 EMG 包络 ~10–20 Hz「文献」⇒ **控制更新 5–20 ms 足够**。
**关键推论**：控制带宽不是瓶颈；**快速瞬态由"两个慢通道的精确相对时序 + 器官动力学（弹簧回弹、气流惯性）"产生**。v8.1 的病不是控制太慢，是表示层没有瞬态位置（meeting66/01 ④）。

### 3.3 所有者三词 → 物理量（逐字对应）

| 所有者原话 | 医学/物理对应 | 生理范围 | 声学结果 | 本席位裁决 |
|---|---|---|---|---|
| **转动频率** | 声带振动的基频 **F0** | 85–350 Hz（言语） | 声调、语调、音高 | **= C1**。它不是"电机转速"，是**张力与压差下的涌现频率**；控制量建议取 CT/TA 激活度，或"给 F0 目标 + 2 维解张力" |
| **发生概率** | 逐帧"有声/无声"门控 = 声门内收程度 × Psub 跨阈 | p ∈ [0,1] 连续 | 清浊、送气、气声、起音 | **= C2**。两种读法都保留：(a) 清浊/发声概率（连续实变量）；(b) 音段起音概率（事件）。(b) 是 (a) 的阈值化，不必设两个通道 |

### 3.4 为什么「控制帧率」不是瓶颈（写给神经控制席）

EMG 包络带宽 ~10–20 Hz ⇒ 肌肉激活度 5–20 ms 更新足够；而 VOT/爆破/塞擦的可听差异在 1–3 ms 尺度。二者不矛盾：**快速瞬态由"慢通道的精确相对时序 + 器官自身动力学"产生**，不是由"更快地发指令"产生。⇒ 学习目标应是**事件时刻精度**（回归 onset/offset 时间戳，误差 ≤2 ms），不是把帧率提到 0.1 ms。

## 5. 可复刻 / 可简化 / 不可复刻 + 最小必控集

### 5.1 三张清单

**可复刻**（物理+生理站得住，工程可做）
- 2–3 质量块 body-cover 声带（含 cover 相位差 → 黏膜波）；
- 1D 声道波导 / 级联共振峰（4–8 段面积函数）；两类噪声源（摩擦湍流 = 收缩点后；送气 = 声门）；鼻分支（1 极点+1 零点）；唇辐射 1 阶高通；
- 确定性数值积分（Euler/RK4，步长 ≤0.25 ms）。

**可简化**（保留功能，砍精度）
- 20+ 喉内肌 → 3–4 个激活度（CT、TA+内收、PCA、呼吸）；
- 3D 有限元/MRI 几何 → 4–8 控制点面积函数；黏膜波 3D 传播 → 1D 表面波/单相位差；
- 鼻窦多腔 → 单零极点；肺力学 → 1 维 Psub 包络；组织非线性黏弹性 → 线性 + 有限幅饱和。

**不可复刻**（或在本项目数据/预算下不可复刻）
- 个体真实组织材料参数（需离体/超声弹性成像）；个体声道 MRI 几何（无法从音频唯一反演）；
- 神经肌肉精确放电时序（EMG 级；本线只到激活度）；黏膜波真实 3D 传播与病理声带（息肉/麻痹）；湍流噪声精确谱（需 CFD）；
- **说话人身份的完整音色**：只能"参数化模仿"，不是克隆（与 meeting58 口径一致）；
- 听觉反馈回路的真实延迟/增益（神经 ~几十 ms；本项目暂为离线闭环）。

| 版本 | 通道 | 每帧标量数 | 预期能发什么 | 预期缺什么 |

| 2 通道（最低） | C1 + C2 | 2 | 不同音高的元音、清浊交替、哼鸣/气声 | 所有元音同音（无 filter）⇒ 不可懂 |
| **3 通道（推荐最小必控）** | C1 + C2 + C5（含 C6） | 4–6 | 元音、鼻韵母、塞音/擦音方式、部分部位 | 送气 VOT / 塞擦精度（需 C7 时序精度） |
| 4 通道（工程推荐） | C1 + C2 + C5 + C7（时序显式化） | 5–8 | 普通话声母方式 + 部位 + 送气 | 音色个体差异、病理嗓音 |
| 5 通道（研究上限） | + C4 Psub / C8 喉位 | 7–10 | 更自然的强弱/声区 | 仍需真实组织参数 |

**裁决**：统一方案的控制向量建议定为 **u(t) = [F0, g, θ(4), n]**（5–7 维/帧，5 ms 帧）；**Psub 与振幅为器官内部解出的量**（不是脑给的通道）。这既尊重所有者"三个量"的直觉（F0 = 转动频率、g = 发生概率、包络 = 振幅），又补上医学上不可省的 filter（θ、n）。

## 6. 与 v8.1 的区别：为什么「物理器官 + 学习控制」不是重走

| 维度 | v8.1 | 本线（物理器官 + 学习控制） |
|---|---|---|
| 音素 → 声学 | 手写表（表内构造性重复） | 音素只给目标/上下文，声学由器官方程产生 |
| 控制参数 | 9 个全局旋钮坐标上升（2 个是死参数） | 逐帧低维控制轨迹 u(t)，反演/自监督学出来 |
| 表示时间分辨率 | 10 ms 帧，瞬态量化掉（sha256 逐位同） | 内部 ≤0.25 ms，输出 2–5 ms |
| 辅音 | 擦/塞擦同参数；送气部位无表示 | 收缩部位(C5) 与 门控(C2)/时序(C7) 独立 |
| 协同发音 | 死常数（过渡 0.03 s、终点混合 0.30） | 由声道惯性与控制平滑自然产生（或学习） |
| 声源 | 查表脉冲 + 周期流表 | 自激振子（body-cover），气声/紧喉连续可调 |
| 评价 | 内部保号判据 29/30 饱和 | 双集 CER + 人耳 + 通道消融 + 阳性对照 |

**三条"重走"红线（自检用）**
1. 若"音素 → 器官参数"仍是查表/常数 ⇒ 重走；
2. 若控制只靠全局旋钮调参、无逐帧学习 ⇒ 重走；
3. 若输出帧 >5 ms 且无亚帧瞬态机制 ⇒ 重走（④ 死因原样保留）。

## 7. 给统一方案的具体建议（可执行 5 条）

1. **器官最低规格**：2 质量块 cover-body + 1D 声道 6–8 段 + 2 噪声源 + 鼻分支；内部步长 ≤0.25 ms；输出 5 ms 帧（mel/谱包络）。
2. **控制向量统一命名**：`F0`、`g_voice`、`theta[4]`、`n_nasal`（+ 可选 `Psub`）；帧长 5 ms；接口 = 肌肉激活度/等效控制量，**不直接给"振幅"**。
3. **首要探针**（与声学席共用）：**oracle 控制 → 渲染 → ASR CER**。这是"器官渲染上限"，**必须先测**，否则无法区分"器官不行"与"学习不行"（meeting66 十六轮全是后者的一种）。
4. **通道消融判据**：对每个通道做"冻结/置乱"消融看 CER 退化；预期 C5 退化最大、C1 次之、C2 再次——若不如此，说明模型没用到该通道，不代表通道不重要。
5. **数据侧最小需求**（交语料席）：除文本外，至少需要**音节边界时刻**（用于 C7/VOT）与 **F0/清浊**（可由音频自监督抽取）；**不需要** MRI/EMG（不可得）。

## 8. 诚实边界 / 待验

- **本件没有任何本项目测量/仿真数据**；所有数值是文献范围/量级，**未在本项目复测**；带「待核」者尤需实测。
- 生理范围是**成人普通话发音人**典型值；本项目说话人（SpeakerA，年龄段/性别）**未标定**，F0/OQ/Psub 范围需重测。
- 伯努利/弦振动是**简化机理**；完整声带振动需组织黏弹性 + 射流 + 声学反馈耦合。本线 2–3 质量块近似，**近似误差未测**。
- 「可学性」栏是**基于可观测性的先验判断**，不是实验结果；C5 反演一对多，可能比预期难。
- 文献链接可点（题录/可获取性已核对），但本席位**未逐篇全文精读**；文献只作参考，**不当器官、不当判据门（C10）**。
- **最大风险不在医学侧**：meeting66 十六轮证据显示 2.7 h 数据下所有生成范式都卡住——器官模型可能还没成为瓶颈。⇒ 建议把"器官渲染上限探针"放在**数据扩容之前**做，先确认这条线值不值得投。
- 对**病态嗓音/情绪嗓音**（紧喉、哭腔、耳语）覆盖不足；情绪外显若要接声带，需另做（本件不含）。
- 合规：只新增 `meeting67/团队/医学生_发声解剖/`（C14）；器官模型 = ODE/波导，非 Transformer（C1）；文献不当器官（C10）；确定性积分可复现（C13）。
