## 0. 结论先行（5 条）

1. **推荐组合 = 分段面积函数（低维声道形状控制）× Kelly-Lochbaum 数字波导（实现层）× LF 声门流（可微主源）× 两质量模型（物理真值/校准臂）× 三类噪声源（送气/摩擦/亚帧爆破瞬态）× 一阶唇辐射。**
   理由：v8.1 的根因是**表示层**（声源/声道过简 + 10ms 栅格吃瞬态 + 噪声只有 1–2 个二阶节），不是「物理建模」本身错；上述组合在**样本级**（45.4µs）给瞬态留位置、把噪声源拆成**可选部位**、并把声道形状压到 3–6 维低维控制量，正好对上所有者的「转动频率 / 发生概率 / 振幅」。
2. **声带源：训练用 LF（可微、8 参数、可反演），校准用两质量（含碰撞/黏膜波，非线性、不可微点）。** 两质量的碰撞事件是**不连续**的，直接放进梯度链会把反演带偏；它的价值是**当"器官真值"给出 LF 拟合误差上界**（两质量合成 → 拟合 LF 参数 → 报误差），而不是当可训练层。
3. **工程口径（可落地）**：主链 **SR 22 050**（与既有 mel/GL/ASR 链路逐参数同，才能与 0.0345 对照）、声门/波导步长 **= 1/SR ≈ 45.4µs**（1–3ms 瞬态 = 22–66 步，够）、两质量若启用子步 **4×（11.3µs）**；**全 float64 + 固定种子噪声 + 两趟 sha256 逐位同**（实测已过）；CPU 实测实时率 **0.011–0.014**（≈70–90× 实时，纯 numpy/python，未优化）。
4. **与 meeting58 声带契约兼容（只读，未改）**：我这一层必须**藏在 `声带.发声 / 合成波形_快` 之后**当「渲染后端」替换 `合成波形_快` 的振铃器部分，控制量用契约里已有的 `基频 / 幅度 / 气声度 / 紧喉度 / 粗糙度 / 送气量 / 声区 + 共振峰缩放(3) / 带宽缩放 / 谱倾斜 / 增益` 映射，不新增协议、不改 `接口契约_角色声线.py`。**注意采样率冲突：既有 `声带.FS = 16000`，我的器官链建议 22050**（见 §3）。
5. **step0 探针已实测（Lead 真实录音口径 n=8）：真mel→GL 0.0585（护栏过）／P1 0.3693／P2 0.4922／P3 0.9739 ⇒ G0-FAIL。**

## 1. 候选模型对比（②③④⑤ 逐项）

### 1.1 声带源

| 候选 | 物理内容 | 参数 | 可微 | 数值风险 | 判 |
|---|---|---|---|---|---|
| **① 两质量 / 多质量（Ishizaka-Flanagan）** | 上下两质量 + 弹簧/阻尼/耦合，含**声带碰撞**与**黏膜波**（相位差） | 质量 2 + 刚度 3 + 阻尼 3 + 几何 3 + 耦合 2 ≈ **13–20**，控制量 F0/声门下压 2 | 除碰撞点外可微（事件不连续） | 中高：碰撞需子步（≤11µs）+ 限幅；参数不可辨识（多组参数同谱） | **当"器官真值/校准臂"**，不做训练主层 |
| **② LF / LF-model 声门流** | 声门流导数分段解析（开相/返回相/闭合相），带 **Oq、Rp、Ra、Rk** 谱倾斜 | **8**（F0, Ee, Tp, Te, Ta, Oq…），控制量 F0/幅度/清浊 3 | ✅ 解析可微（除相位跳变） | 低 | **✅ 训练/推理主源**（可反演的第一选择） |
| ③ 脉冲串（LPC-10 口径） | 无源形状，只留情期 | 2 | ✅ | 低 | 只作**表示上限对照臂**（P1） |

> 关键判断：**声源形状不是可懂度的主承重**（探针 P1 vs P2 的 CER 差即为代价读数），但**声源是音色身份的承重**（气声/紧喉/粗糙都落在源上）。所以源必须可微、可参数化，且要能被 meeting58 的音色键驱动。

### 1.2 声道

| 候选 | 实现 | 参数 | 波导/物理一致性 | 判 |
|---|---|---|---|---|
| **Klatt 级联** | 5–6 个二阶共振峰串联 + 鼻零极点 | 峰 5×(F,B) = **10–12** | 现象学（不是波导） | ✅ **推理期最快**；与既有 `引擎_v7` 同族，但**必须**把「每 10ms 一组常数」换成「每帧由学习器给」 |
| **Kelly-Lochbaum 数字波导** | 分段无损管 + 结点散射，每段 1 样本延迟 | p 段 → p−1 个 k；p=18 ⇒ 段长 **7.94 mm**、总长 **14.3 cm** | 真物理（可注入部位噪声、可做面积函数） | ✅ **推荐实现层**：噪声可**在指定部位注入**（这是 v8.1 做不到的"部位"），但**等价映射要重做**（§4.3 实测不等价） |
| 分段面积函数 | A(x) 用 3–6 个控制点（如 4 个面积比）参数化 | **3–6 维控制**（+ 全局长度） | 物理可解释、低维 ⇒ **可学** | ✅ **推荐控制层**（所有者的「声道形状」精确对应物） |
| Klatt 并联 | 浊/清分支并行 + 独立噪声支路 | 多 6–10 | 现象学 | ⚠️ 只在需要"清浊同时存在"（浊擦音、气声）时开并联支路 |

### 1.3 噪声源（v8.1 的死穴，必须单列）

| 源 | 物理 | 实现要点 | 参数 |
|---|---|---|---|
| **送气（aspiration）** | 声门未完全闭合的湍流，经声道成形 | 白噪 → 声门处注入 → 走**整条**声道 | 幅度、谱倾斜 2 |
| **摩擦（frication）** | 收缩点下游湍流 | 白噪 → **在收缩部位注入**（要用部位索引，v8.1 缺的正是这个） | 部位 (0–1)、带宽、幅度、谱形 4–6 |
| **爆破瞬态（plosive burst）** | 除阻 1–3ms 的脉冲 + 后接送气 | **样本级**脉冲（1–3ms = 22–66 样本）+ 部位相关谱形 | 时刻(样本级)、幅度、谱形 3–4 |
| 鼻/侧 | 旁路共振 | 并联零极点 | 3–4 |

> 结论：**噪声源必须"部位可选 + 谱形可学"**，这是普通话 s/sh/x、z/zh/j、p/t/k 可分的最小条件；只要噪声还是"单/双二阶谐振器 + 一条频带"，就会重演 v8.1 的「部位不缺、方式缺」。

### 1.4 唇辐射

- **一阶差分（+6dB/oct）+ 一阶低通**（`(1−z⁻¹)` 再补 3–5kHz 以上滚降）就够；用 `唇圆度` 1 个参数调高频。**不要**用高阶辐射滤波器（不可辨识，且与声道极点混在一起）。

### 1.5 推荐组合（可直接写进统一口径）

```
神经控制量（5–8 维）：
  F0(t)            1      ← 所有者「转动频率」
  清浊/周期度(t)    1      ← 所有者「发生概率」
  幅度/声门下压(t)  1      ← 所有者「特殊振幅」
  声道形状(t)       3–6    ← 面积函数控制点（低维）
  （可选）噪声部位+强度 2
          ↓
[LF 声门源] + [送气/摩擦/爆破三类噪声，按部位注入] → [KL 波导（分段面积函数）] → [一阶唇辐射] → 波形
          ↑ 训练时用可微等价：LF → 级联共振峰（由面积函数拟合）
```

### 4.2 oracle 控制与三条臂

每 10ms 帧：F0/清浊 = `librosa.pyin(fmin=60,fmax=500,frame_length=1024,hop=220)`；LPC 包络 = 25ms hamming + 自相关 + Levinson-Durbin（**阶 18**，白噪修正 1e-5，|k| 截 0.97）；幅度 = 真帧 RMS（合成后逐帧对齐 ⇒ **幅度不进探针，只测谱/源/激励**）。

| 臂 | 含义 | 测什么 |
|---|---|---|
| **P1** 脉冲串 × LPC 全极点 | 经典 LPC-10 口径 | **表示上限**：LPC 包络 + F0 + 清浊能到多低 |

限一轮器官改进后复测（G0-v2）。n=8 方差大（P2 sd≈0.30，95% CI≈[0.240,0.744]）⇒ 方向可信、**边界不可过度解读**。

**机制（纯 DSP 诊断 `诊断_G0v0失败.py` → `产物/诊断_G0v0失败.json`，n=6）**：
| 量（中位） | GL 参照 | P1 | P2 | P2 干（气声=0） |
|---|---|---|---|---|
| 全带 LTAS 斜率（dB/oct） | −3.82 | −2.89 | −3.72 | −3.75 |
| **清帧 2–8k/0–2k（dB）** | **+0.53** | −0.31 | **−14.95** | −14.94 |
| 气声贡献（4–8k 比差） | — | — | **+0.005 dB** | — |
| F0 八度跳率 | — | **0.000** | — | — |
| 清浊冲突率 | — | **0.188** | — | — |

⇒ ① **P2<P1 的原因是声门源陡倾斜（−12dB/oct）吃掉高频，而"气声"是死参数（贡献 0.005 dB）**，
不是全局倾斜错（P2 全带斜率 −3.72 已接近 GL −3.82），也不是 F0 倍频错（八度跳率 0）；
② 失败样本集中在**清擦/送气/清音起音**密集段；③ 清浊二值 + 10ms 粒度与真实 19% 的"半浊帧"冲突；
④ **P3 的 0.97 是等价映射 bug 的读数**（实测所有端点口径的 IR 误差 ≥0.99、共振峰偏 1.2–4.3 kHz），**不能**当"波导代价"。

**详细判读、v1 改进清单（8 条，含判据）与 G0-v2 预注册草案见 `G0_判读_v0失败.md`。**

**判读预案（读数量级 → 结论）**：

| oracle 器官 CER | 判读 |
|---|---|
| **< 0.15** | 器官类**不设上限**：包络+F0+清浊已承载绝大部分可懂信息 ⇒ 瓶颈在**控制学习**（反演/自监督），不在声学层 ⇒ 神经控制席位可放心把「最小控制量」压到 5–8 维 |
| 0.15–0.40 | 器官类**可用但需补 2–3 个自由度**（源谱倾斜/噪声部位/瞬态），且**学习器必须学出这些自由度**；v8.1 的手写表若只给 5 个共振峰必落在这一段更差处 |
| 0.40–0.70 | 参数化重合成本身丢太多（LPC 阶/清浊判别/瞬态），⇒ 先修**表示**（阶、清浊、亚帧瞬态），再谈学习 |
| **> 0.70** | 说明「最小器官 + oracle 控制」这条路**本身不足以可懂**，必须提高表示（更高阶/更多噪声源/44.1k）或退回 mel+声码器 —— 这是本线能否成立的**go/no-go 读数** |
| P2−P1 > 0.15 | 声源形状是承重项 ⇒ 源必须**学**（不能手写一个固定脉冲）；P2−P1 小 ⇒ 源可简化，省参数 |
| P3−P2 > 0.15 | 波导实现有额外损失（含等价性 bug）⇒ 先修等价映射，否则别上波导 |

## 5. 关键风险与诚实边界

| # | 风险 | 具体表现（已知/已测） | 缓解 |
|---|---|---|---|
| R1 | **数值不稳定** | 波导段数×k 接近 ±1 时反射放大；两质量碰撞会让 ODE 发散 | 面积比 clamp（正面积 softplus）、段损耗、子步 4×、限幅；实测 |k| 命中上限仅 0.28% |
| R2 | **参数不可辨识** | 两质量模型多组 (m,k,d) 给同一谱；LPC→面积反推不唯一（长度/端点假设） | 只把**低维控制**当可学量，器官常数**按人标定后冻结**；用「多解集」报告而非单点 |
| R3 | **波导 ≠ LPC（已实测）** | 朴素映射共振峰偏 1.2–4.3 kHz | 重做映射（段数/端点反射/延迟口径），或用「面积函数 → 极点」正向拟合再验证 |
| R4 | **8kHz 以上细节缺失** | 22.05k ⇒ 上限 11.025kHz；f/s 的摩擦能量集中在 4–8kHz，尚可；但**送气/齿音高频细节**肯定不如 44.1k；且既有 ASR 是 16k 模型，>8kHz 信息对 CER 本来就不计 | 先做 22.05k（可比 0.0345）；若 CER 卡在摩擦音，再上 44.1k 重定 mel/GL 口径 |
| R5 | **与 Griffin-Lim 的公平对照** | 0.0345 是「真 mel → GL」，相位是迭代造的；我的器官用**参数化相位**（周期脉冲），两件事不同类。且 GL 拿到的是**真 mel（含全部 80 带细节）**，我的器官只拿到 **LPC 18 阶包络** ⇒ 若我 CER 高，**不能全归因于器官**，也含"包络表示更粗" | 报告里必须并列 P1（同 LPC 包络的表示上限）；并用 **P0 对照 = 真 mel→GL** 卡住仪器漂移；两者之差才是「物理器官 vs 声码器」的真实差距 |
| R6 | **噪声源/瞬态本轮未单独做臂** | 探针只有"清帧白噪"，**没有**部位相关摩擦/亚帧爆破瞬态 ⇒ 摩擦/塞音可懂度会被系统性低估 | 明确标注：本轮读数 = **下限**；R2 加「瞬态注入 on/off」臂 |
| R7 | **oracle 控制是作弊上界** | F0/清浊/LPC 都取自真音频，学习器实际做不到 | 所以本探针只回答「器官类有没有上限」，**不能**外推成系统可懂度 |
| R8 | 幅度被 oracle 对齐 | 逐帧 RMS 对齐真波形 ⇒ 幅度/重音信息不进探针 | 报告里写明；幅度分辨率另测 |

**诚实边界**：本席**没有**训练任何东西，**没有**接 AHI4 内核，**没有**做人耳盲评；ASR 只当离线仪器（C10 不违）。探针只覆盖 8 条片段 × 4.0s，**不覆盖** S1–S12 文本内容；`产物/` 下的 wav 是**探针副产物**，不是交付声音。
