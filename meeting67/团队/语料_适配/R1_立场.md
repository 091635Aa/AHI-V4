## 0. 结论先行

1. **现有 167×60s 是「剪好的定长对话语料」，不是原始长录音**：原始 2.77 h、44.1k/立体声/16bit；对齐产物 22.05k/mono、162.2 min 训练帧、30927 音节、3.179 音节/秒。**没有任何 >60 s 的文件**，所以「适配 >1 h 与更短」是**新增能力**，现有数据只能验证「短片段侧」。
2. **变长适配的最小改动不是改模型，是改数据入口**：`片段 = 确定性 VAD + 自然停顿切分`，单片段 2–60 s（与既有 24 帧/音节口径自洽），长文件流式分块；对齐管线（ASR 字符时间戳）可原样复用，因为它天然以**片段**为单位。本件给出规范与伪代码，**切分器未实现**（本席位不写既有权重/模型，也不越界写 meeting66）。
3. **最小子集实测可行**：贪心覆盖率排序 + 质量门后，**≤5 min = 5 片段 / 1130 音节 / 336 音节型(42.2%)，声母 22/22、韵母 38/38、调 5/5 全覆盖**；≤30 min 达 **83.4% 音节型**。⇒ 若目标是「音素表覆盖」，5 min 已够；若目标是「音节型覆盖」，需要 30 min 量级。
4. **数据量档位按训练时长的 1/16→全量**（9.96 / 20.88 / 41.66 / 82.80 / 162.16 min），每档固定算力复评 v13 一次；**选择集 S13–S18 只选不报，报告集 S1–S12 只报一次**。泄漏核查 0 条，但存在**书面朗读句 vs 口语对话**的文体域差（诚实边界）。
5. **不改既有代码的做法**：`模型_学说话.py::数据集(数据路, 前N=...)` 已支持任意数据目录 + 前 N；把 `选子集.json` 物化成一个**新数据目录**（meta.json 的样本顺序＝贪心序 + 软链/复制既有 npz）即可，**meeting66 零改动**。

## 2. 变长录音适配规范（所有者「>1 h 与更短」）

### 2.1 设计原则

- **片段是唯一数据单元**（对齐、质量门、子集、档位都按片段算）——这样长文件和短文件走同一条路。
- **片段长度锚定既有训练口径**：既有样本 53–60 s ≈ 190–250 音节 × 24 帧/音节 × 10 ms；所以片段**目标 40–60 s、硬上限 60 s、下限 2 s 且 ≥10 音节**。
- **全部阈值确定性**（C13），同一输入两趟逐位同；不联网、不学阈值。

### 2.2 读入

1. 文件类型：wav（PCM16/24/32、float）/ flac；`soundfile` 读，`always_2d=True`。
2. 多声道 → 算术均值下混（与 `数据_SpeakerA.py::读音频` 同口径）。
3. 采样率 → **两条并行口径**：mel 用 **22.05 k**（`resample_poly`，gcd 约分）；ASR 仪器用 **16 k**（同法）。**不落盘转换后的整段 wav**（除 ASR 需要的临时 16 k 片段文件）。
4. 削波检测：`max|x| ≥ 0.999` 的采样占比 >0.1% ⇒ 标 `削波`（不删除，进台账；可选 `×0.9` 归一化，需预注册）。
5. 超长文件（>10 min）**不得整段常驻内存**：按 5 min（22050×300 采样）滑动块流式算帧能量；块间重叠 1 s 以免切在边界。

### 2.3 VAD / 静音切分（确定性阈值）

- 栅格：25 ms 窗 / 10 ms 跳（**与数据_SpeakerA完全同口径**，`窗长=551, 跳长=220`）。
- 帧能量：`E_db = 10log10(mean(x²)+1e-12)`。
- 静音阈：**`峰 − 35 dB`**（既有口径）；对 **>10 min** 文件改用 **`p99(E_db) − 35 dB`**，防单点爆音把门槛抬高（差别登记进 meta）。
- 连浊合并：浊帧之间 ≤**5 帧（50 ms）** 的间隙不切开（塞音/爆破的空隙）。
- 片段边界：浊段前后各留 **50 ms** 余量（与对齐管线的 ±0.05 s 一致）。
- 片段切分：若一个浊段 >60 s，在**能量最低的帧**处强制切开（并列取最早帧）；切点两侧各留 50 ms。
- 丢弃：<2 s 或 <10 音节 → 进失败台账（不静默丢）。

### 2.4 去重（两级，确定性）

1. **整文件级**：sha256（现有 167 条：唯一 167，重复 0）。
2. **片段级**：PCM int16 字节 sha256（完全重复）；再补**音频指纹**：`[p5,p25,p50,p75,p95](10log10(|x|²+1e-12))` 五维 + 时长 + 音节数；指纹欧氏距离 < **0.5 dB** 且相对时长差 <1% ⇒ 判近重复，保留先到者，后者进台账。
3. 跨文件重复（同一句被剪进两个文件）用指纹查，不用文本查（文本不可靠）。

### 2.5 失败样本隔离与台账

- 每条 `(源文件, 片段起止采样, 片段sha256)` 记一行 `失败台账.jsonl`：
  `{源文件, 起, 止, 原因∈{无浊帧, 片段过短<2s, 音节过少<10, 削波, SNRa低, ASR失败, 对齐匹配率低, 帧分配非法}, 处理∈{隔离}, 复现时间}`。
- **失败不进训练集**，但**计数必须进 meta**（`来源.异常数`，与既有产物字段对齐）；「挂着无效就跳」= 跳的是片段，不是文件。
- 隔离目录 `失败/` 只存指针（路径+sha256），**不拷贝音频**（只读数据源约束）。

### 2.6 切分器接口（伪代码；**未实现**，留给实施席位）

```
切分(源wav, 参数) -> [片段] , [失败台账项]
  参数 = {SR_mel=22050, SR_asr=16000, 窗=551, 跳=220, 静音dB=35,
          最小秒=2.0, 最大秒=60.0, 最小音节=10, 合并间隙帧=5, 边界余量=0.05}

  for 块 in 流式分块(源wav, 5min, 重叠1s):
      x22 = 重采样(下混(读块), SR_mel);  E_db = 帧能量(x22)          # 25/10
      峰 = E_db.max() if 时长<=10min else percentile(E_db,99)
      浊 = E_db > 峰 - 静音dB
      浊 = 合并短间隙(浊, 5)
      段s = 连续浊段(浊) → (起帧, 止帧) → 采样边界 ±0.05s
      for 段 in 段s:
          if 段长 > 最大秒: 在 min(E_db[段]) 帧强制切 → 递归
          if 段长 < 最小秒 or 估计音节数 < 最小音节: 记台账; continue
          yield 片段(采样区间, src_sha256, 指纹)
  # 片段编号 = (源文件sha256前8位, 起始采样) 字典序 → 全局确定
```

## 3. 片段级对齐流程（复用既有 ASR 时间戳管线，C10）

**结论：复用 `meeting66/实施/数据_SpeakerA_对齐.py` 的算法，但把「一文件一条」改成「一片段一条」；ASR 仍是离线仪器，只提供时间，不提供文本标签（N1「用 ASR 文本」不作为默认）。**

可执行步骤（每片段）：

1. 片段 22.05 k 波形 → 16 k → 临时 wav（`_tmp/片段.wav`）。
2. `funasr` Paraformer（16 k）`generate(return_timestamp=True)`，**按 ≤300 s 分批**；取单汉字 token 的 `(start_ms, end_ms)`。
3. 编辑距离把「ASR 字符序列」对齐到「**所有者转写**的汉字序列」；匹配字取 ASR 时间戳，未匹配字按邻字插值（既有 `编辑对齐` 实现）。
4. 音节边界 = 相邻字起点中点（既有 `边界` 算法）；首末修剪到 `首字起−50 ms / 末字止+50 ms`。
5. 每音节 `声母 25% / 韵母 75%`（声母 ≥2 帧），帧数 = 边界差；`Σ帧数 == T` 断言。
6. 输出：与 `数据_对齐asr` **同契约**的 npz + meta.json，**新增字段**：
   `来源文件, 片段起/止采样, 片段sha256, 源采样率, 对齐匹配率(匹配字/总字), ASR设备, 对齐版=r1|均分`。
7. 失败判定（进台账）：`无时间戳`、`匹配字 < max(3, 字数/2)`、`音节数≠字数`、`帧分配非法`。

> 与既有产物的差别只有「分组单位」；mel 口径、帧栅格、id 映射、划分种子（300）全部不变 ⇒ **下游训练零改动**。
> 判据：新管线在既有 167 条上重跑应与 `数据_对齐asr` 的 mel 口径逐位可比（**未验**，实施时须做两趟确定性与 mel 对照差 ≤2e-4）。

## 4. 最小数据子集（预注册、确定性规则；已实现 `选子集.py`）

### 4.1 规则

1. **质量门**（先定后跑）：语音时长 ≥3.0 s、音节数 ≥30、近似 SNR ≥15.0 dB、静音帧占比 ≤0.60。
2. **贪心排序**（全量算一次，排序即「档位骨架」）：
   `score(c) = 1.0×新音节型数 + 0.5×(新声母数+新韵母数) + 0.5×Σ_{新音节型} 1/(计数+1)`；
   并列 → 质量合格优先 → 音节数多 → 片段 id 小。**无随机**。
3. **档位生成**：绝对档 ≤5/15/30 min（按贪心序累加**训练时长**，末片按音节边界截断，截断须 ≥1.0 s 且 ≥3 音节，否则宁少不碎）；相对档 1/16…全量 = 排序前缀取 k。
4. **均衡修复**：某档若声母（再韵母）边际缺失，用「最短的能补者」替换末片，最多 3 次；仍缺即登记「不可达」。

## 5. 数据量档位协议（固定算力 → 数据量→可懂度曲线）

### 5.1 固定什么

| 固定项 | 值 |
|---|---|
| 模型/配方 | **v13 同口径**（K=4 前帧、320 通道、5 层、2.85M、计划采样、每音节 24 帧、Griffin-Lim） |
| 算力 | **固定训练墙钟 + 固定轮上限 + 固定 batch/lr/种子**（seed 300；见 `06_实验_v5v6.md` §11） |
| 选择 | 周期保存（每 50 轮）→ **S13–S18 选 ckpt（只选不报）**；两候选差 <0.02 取更早/更简单 |
| 报告 | **S1–S12（历史 S1–S6 / 留出 S7–S12）只报一次**，两趟转写（C13） |
| 仪器 | ASR 仅离线评测（C10）；真 mel→GL→ASR 阳性对照（历史 0.0345）必须同批复跑 |

### 5.2 档位表（每档至少一次 v13 复评）

| 档 | 片段 | 训练时长 | 与既有口径的关系 |
|---|---|---|---|
| D1/16 | 10 | 9.96 min | ≈ 所有者「更短」录音一档 |
| D1/8 | 21 | 20.88 min | |
| D1/4 | 42 | 41.66 min | |
| D1/2 | 84 | 82.80 min | ≈ 所有者「>1 h」录音一档 |
| D全 | 167 | 162.16 min | = meeting66 当前全量（基线 0.8327 / 0.7533） |

- 判据：**同一 ckpt 选择协议下**，双集 CER 随数据量单调下降才支持「数据是瓶颈」；出现平台 ⇒ 该平台读数即「最小有效数据量」的**下界证据**。
- 预注册（建议）：D1/16 若 CER ≥0.95（≈不可懂），仅登记为「不足」；D1/2 若 < 全量 >0.05，则「2.7 h 未饱和，需更多数据」。
- 预算：v13 一次完整训练+评测按 meeting66 记录约 **1–2 h GPU**；5 档 ×（训练+选择+报告）≈ **6–10 h**（估计，未测）。

### 5.3 训练/选择/报告 三分（防泄漏）

- **训练** = 档位内片段（全部用于训练；不再切 95/5 val，因为 meeting66 已证明 val 选模型会选错）。
- **选择** = S13–S18（6 句，合成文本，**无真实音频**，不参与训练/报告）。
- **报告** = S1–S12（12 句，合成文本，**只报一次**）。
