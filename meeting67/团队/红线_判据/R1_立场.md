## 0. 结论先行（本席 5 条硬立场）

1. **本方案在红线内可通过，但有 3 个「看似合规、实则踩线」的高危点**：①外部 ASR/声码器从「离线仪器」被悄悄挪进生成路径；②「自写听觉模型」实际 import 第三方预训练声学模型；③用内部判据（保号/保定义）当早停或选模型信号 —— 后者正是 v8.1 的病灶（`判据_发音_v8` 29/30 饱和，人耳「全部不可听，只听到几个字」）。
2. **C1 的口径是「框架/权重/推理栈」，不是「训练思路」**（meeting66 所有者裁决）：从零训练的非 Transformer 网络（Conv1D/GRU/MLP）+ 自写物理 ODE 器官 + 自写听觉模型 **允许**；attention/自注意力主干/Transformer block/第三方预训练权重/第三方推理栈 **禁止**。
3. **评价必须三分离，不可合并**：训练信号（内生，可含自监督）≠ 选择信号（S13–S18，**只选不报**）≠ 报告信号（S1–S12 双集，**只报一次，事后不得再调**）。
4. **报告门不可用单一 ASR CER**。每次报告必须同时给出：双集 CER + 逐句 + 两趟一致 + 阳性对照（真 mel→GL→ASR **0.0345**）+ sham must-fail（白噪/静音 ≥0.9）+ **人耳终判**。缺任一项 ⇒ 该轮判「未完成」，不得宣称。
5. **「无效即跳」必须量化到可触发**：本件给出 6 条触发条件（§3.3），命中即**停该点、登记负结果、不续投**——这是所有者「挂着无效就跳」的落地形态。

## 2. 评价协议（防重蹈 v8.1）

### 2.1 三分离总表（**核心**）

| 层次 | 数据 | 允许用途 | **禁止用途** |
|---|---|---|---|
| 训练 | 2.7h 语料（或新录音子集） | loss/梯度/自监督 | 不得按报告集/CER 反传 |
| 快速预筛 | 探针 P1–P3 | 粗筛候选（不写报告） | 不得定最终结论 |
| **选择** | **S13–S18** | 选 ckpt / 选推理设置（迭代轮数、阻尼、帧数） | **不进入任何对外报告**；不得报其 CER 作为成果 |
| **报告** | **S1–S12**（历史 S1–S6 / 留出 S7–S12） | **只报一次** | 报完后**不得**再用其调参/重选；不得报「探索性最好值」当结论 |
| 人耳 | S1–S12 的 12 个 wav | **终判** | 不得用 ASR 替代人耳下结论 |

### 2.2 必测项（每次报告缺一即「未完成」）

| # | 项 | 门槛 | 依据 |
|---|---|---|---|
| E1 | 仪器阳性对照：真 mel → GL → ASR | **CER ≈ 0.0345**（须 ≤0.10） | meeting66，仪器无罪 |
| E2 | sham 白噪 | CER **≥0.9**（must-fail） | `声码器与评测.py::_sham` 同种子 63051 |
| E3 | sham 静音 | CER **≥0.9** | 同上 |
| E4 | sham 随机控制 | 控制量同分布随机化 ⇒ 双集 CER **不得优于**「条件均值基线」，且 ≤0.9 | 本线新增（物理器官专有） |
| E5 | sham 打乱控制 | 把控制帧按时间打乱 ⇒ CER 明显劣化（Δ≥0.1）⇒ 证明控制**时序**承载信息 | 本线新增（防「控制没用也在出声」） |
| E6 | 两趟转写 | 逐字一致 | C13 |
| E7 | 两趟推理 | mel 逐位同 + wav sha256 同 | C13 |
| E8 | 人耳终判 | 所有者亲听 12 句，给「可懂/半可懂/不可听」三分 | 初心；ASR 只是代理 |
| E9 | 方向复核 | 见 §5.1：ASR Δ 与人耳 Δ 符号一致，否则以人耳为准并登记冲突 | 防「对 ASR 友好对人耳不友好」 |
| E10 | 双集同时报 | 历史 + 留出**分开报**，**不得**用一集好就宣称 | meeting66 §1 教训 |

### 2.3 三条禁令（直指 v8.1 病灶）

1. **内部判据不得当优化目标**：`判据_发音_v8` 式「保号保定义」护栏（29/30 饱和）**不得**进 loss、不得当早停信号、不得当选模型信号。v8.1 的失败链条就是「把护栏当目标 → 越按教科书修保真越差（+0.066/+0.076/+0.129）」。
2. **不得用 teacher-forced val 选模型**：meeting66 已实测它会选错（val 0.0216 对应 CER 0.9861）。选模型只能按**推理态 CER**，且在 S13–S18 上选。
3. **不得事后改口径**：句集、ASR、声码器、迭代/阻尼、帧数在预注册里冻结；任何改动 = 新预注册版本，旧读数作废。

### 4.1 `审计_红线静态.py` —— 静态合规审计（P-C1/C9/C10/C13/C14）

def 审计(根: Path, 仪器登记: Path) -> dict:
    报 = {"条款": [], "通过": None, "命中": []}
    for 文件 in 根.rglob("*.py"):
        树 = ast.parse(文件.read_text("utf-8"))
        报["条款"].append(查禁构(树, 文件))        # S-C1-1（禁构表：MultiheadAttention/Transformer/scaled_dot_product）
        报["条款"].append(查导入(树, 文件))        # S-C1-2（第三方ML包 = 0，或在仪器白名单内）
        报["条款"].append(查权重来源(树, 文件))    # S-C1-3（from_pretrained/torch.hub = 0）
    报["条款"].append(查生成路径纯度(根))          # S-C1-4：生成/ 闭包不含 asr/仪器/评测
    报["条款"].append(查仪器登记完整性(仪器登记))  # P-C10：每条有 sha256 且在生成路径=false
    报["条款"].append(查C14(仓库根))              # git status --porcelain 只允许 ?? meeting67/
    报["通过"] = all(条.通过 for 条 in 报["条款"])
    return 报

### 4.2 `判据_发声器官.py` —— 主判据（复用 meeting66 `声码器与评测.py` 口径）

def 跑(预注册: dict) -> dict:
    断言 预注册.时间戳 < min(产物.mtime)                  # 防事后补预注册
    器 = 载器官(预注册.ckpt)                              # 自训权重，C1 白名单校验
    自检 = 声码器自检(器)                                 # 长度/两趟sha256/读回
    阳  = 阳性对照_真mel_GL_ASR()                          # E1 门槛 ≤0.10

def 评一句(句) -> dict:

def 选(目录: Path, 网格: list, 持平=0.02) -> dict:

def 校验(预注册: dict) -> dict:
    必填 = [...§3.1 字段...]
