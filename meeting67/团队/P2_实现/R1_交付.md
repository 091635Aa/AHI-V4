## 3. ★关键修复：F0 target 与 mel 的对齐 bug（v1→v2）

**症状**：第一轮头 F0 相关 0.009/0.0148（近乎零）；真实上下文线性探针 0.569、预测上下文 0.084。Lead 判「像接线/对齐 bug」——**判断正确**。

**根因**：`meeting66/实施/数据_SpeakerA_对齐.py` 的 mel 不是整条 wav：
`起s = max(0, 首字ASR起点/1000 − 0.05)`，`止s = min(len/22050, 末字ASR终点/1000 + 0.05)`，
`x段 = x22[int(起s×22050):int(止s×22050)]`，`mel = 算mel(x段)`。
v1 直接对**整条 wav** 做 pyworld，再按帧数截断到 T ⇒ F0 与 mel **整体差一个起s**。

**修法（v2）**：
1. 用与 `数据_SpeakerA_对齐.py` **逐参数相同**的管线重算整条 wav 的 log-mel（`sf.read`→均值单声道→`resample_poly`→`librosa.feature.melspectrogram(hop=220,win=551,center=True,pad_mode='constant',norm='slaney',htk=False)`，`ln(S+1e-6)`）；
2. 搜索整数帧偏移 `off`：粗搜步长 8 帧 + ±8 帧细搜，使 `mel_full[off:off+T]` 与 npz mel 的 MAE 最小；
3. 对整条 wav 做 pyworld，取 `f0[off:off+T]`；残余误差 ≤ 半帧 5 ms（亚帧相位无法从 npz 完全恢复，已登记）。
4. 167 条全部重提（4 进程，201.9 s），**逐条 off/MAE 落 `产物/P2/对齐证据.json`**，并对 2 条做两趟提取逐位同自检（PASS）。

**对齐证据（汇总，全部 167 条达标，MAE 门槛 1.0）**：

| 项 | 实测 |
|---|---|
| 非零偏移条数 | **148 / 167（88.6%）** |
| 偏移范围 | 0 – **1193 帧**（0 – 11.93 s） |
| MAE 中位 / 均值 / 最大 | **0.0317 / 0.0735 / 0.499**（全部 < 1.0） |
| 对齐存疑 | **0** |
| 总帧 / 浊音帧 / 浊音比均值 | 972,981 / 655,369 / 0.6705 |
| F0 中位均值 / 范围 | 288.72 Hz / 238.8 – 344.9 Hz |
| 提取耗时 | 201.9 s（4 进程；v1 单进程 437.8 s） |
| v1 对照 | 同样的 167 条，但**未做偏移恢复**；v1 索引已保留于 `团队/P2_实现/日志_F0提取.txt` |

> 说明：`off` 为整数帧，残余 ≤半帧（5 ms，mel 段起点的亚帧相位不可从 npz 恢复）；这是**已登记的量化误差上限**，不是宣称精确对齐。

## 4. 谐波声码器：自检 PASS，但 A1 阳性对照 FAIL

### 4.1 自检（`自检_谐波声码器.json`，PASS=True）
- 输入 200 帧（浊 100 ms/清 100 ms 交替）；输出 **43,780 样本 = (200−1)×220**（长度正确）；
- **两趟 sha256 逐位同**（`f97faf2a…` 两次相同）；全 finite；峰值 **0.9**；
- wav 读回 **1ch / 16bit / 22050 Hz / 43780 帧（达标）**；随机 mel 回算余弦 **0.9359**；
- 边界：全清音有限、4 帧长度 660 正确、全静音 mel 峰值 0（无异常）；
- 真实 mel 保真（样本 0/1/2，真 mel+真 F0）：mel 回算余弦 **0.9835 / 0.9792 / 0.9674**（同样本 GL 为 0.9882 / 0.9902 / 0.9760）⇒ **谱包络保真接近 GL**；
- 每样本合成耗时 27–45 s（5,374–5,995 帧，Python 逐帧谐波叠加；未做向量化优化）。

## 7. 风险与诚实边界

1. **P2 按预注册判负结果**：A1 阳性对照 FAIL（0.3971>0.20）⇒ 谐波声码器「当前实现」不可用；不得表述为「P2 提升了韵律/自然度」。
