## 2. Lead 解读（**可被所有者纠正**；纠正后本件与方案同步修订）

| # | 解读 | 依据 |
|---|---|---|
| I-1 | **不再向所有者索要 ≥8–10h 录音**。现有数据 + 所有者手头「>1 小时、也有更短」的录音即视为预算上限；矛盾要由**方法**解决（更少数据学会），不是由数据解决。 | 第一段 + 第二段第一句 |
| I-2 | 数据管线必须**适配变长录音**：既有 167×60s 定长口径要升级为「变长原始录音 → 确定性切分/VAD → 片段级对齐」，既吃 >1h 长文件，也吃短片段。 | 「大于1小时的 但是有一些小于的 所以要适配」 |
| I-3 | **主线改为「仿人发声器官」**：以人体发声器官（肺/喉/声带/声道/鼻）的**物理与生理机理**为主，复刻其振动与发声逻辑；目标是**物理器官 + 少量神经控制量**（振动频率 F0、发声/清浊概率、振幅/声门下压、以及必要的声道形状低维量）即可发声。 | 「以人类器官为主，复刻一个一模一样的人类发生器官逻辑一样振动……只需要改变……转动频率、发生概率、特殊振幅」 |
| I-4 | 该器官**接入 AHI4 内核**（脑→神经→器官的控制通路），不是外挂 TTS；训练要保留，且「不同训练方法」按**独立点**分别预注册、分别判、无效即跳。 | 「通过脑神经进行连接……嵌入我们的一些这个核心」「训练肯定要训练的，但是用不同方法训练是一个一个点」 |
| I-5 | 本轮**先开会、先出统一口径方案**，再按方案分点实施；判据以「数据合理有用」为准，**有效读数落盘，无效即停**，不无限追投。 | 「最好开个会，来个统一口径方案」「测出有效数据记录，然后挂着无效就跳」 |
| I-6 | 「找医学生开会」＝本会议必须引入**医学/发声生理**席位（解剖、生理、神经控制、病理对照），其口径要能落地成参数表，不是科普。 | 「这个你可以找医学生开个会」 |

> 与 meeting66/01 的关系（必须写清，避免重走 v8.1）：v8.1 失败的不是「物理发声模型」本身，而是**手写音素→声学参数表**（无学习、表示层装不下辅音、10ms 栅格吃瞬态、协同发音死常数）。本线保留「物理器官」，但**控制必须学出来**（反演/自监督/模仿），且表示与时间分辨率要能承载瞬态。

## 3. 会议目标（唯一交付）

**一份统一口径方案**：回答「以人体发声器官为蓝本、接入脑神经控制，最少需要多少、什么样的数据，才能学会发出可懂的声音」——含：

1. 器官模型（解剖级拆分 + 物理方程 + 参数表 + 时间分辨率 + 确定性/实时性）；
2. 脑→器官控制通道表（哪些量必须由神经控制、范围、可学性），即所有者所说「转动频率 / 发生概率 / 振幅」的精确对应物；
3. 训练方法清单（每个方法独立预注册、独立判、无效即跳）：反演、自监督前向、模仿、闭环自我听觉、课程；
4. 数据适配规范（变长录音切分/对齐/最小子集/数据量档位）与「数据量→可懂度」曲线协议；
5. 评价与判据协议（S1–S12 / S13–S18、ASR 仅离线仪器、sham/阳性对照、两趟确定性、人耳终判）；
6. 阶段路线图（gate 条件，step0 先测「器官渲染上限」）、红线审计、接线到 AHI4 内核的方式、分工与预算；
7. 诚实边界：v8.1 教训、未验证假设、可能仍被数据卡死的风险。
