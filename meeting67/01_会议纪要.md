## 1. 席位 R1 结论摘要

### 1.1 医学生_发声解剖（`团队/医学生_发声解剖/R1_立场.md`，208 行）

- **R1-1** 人体发声 = 气源（肺）→ 声源（声带自激振子）→ 滤波器（咽/口/鼻）三段串联 + 两条并联（噪声源、鼻分支）；脑只给**肌肉激活度**，不直接给频率/振幅。
- **R1-2** 所有者三词：**转动频率 = F0**；**发生概率 = 声门门控/清浊-送气概率 g(t)**；**特殊振幅 = 声门振动幅度（状态量，不是独立控制量）**。
- **R1-3** 三词只覆盖**声源侧**；不加声道（filter）侧，所有元音会塌成同一个音 ⇒ **不可懂**。
- **R1-4** 最小必控集 = **F0 + 声源门控 g + 声道形状 θ（含鼻化 n）**，4–6 标量/帧；逐帧轨迹，不是全局旋钮。
- **R1-5** 普通话可懂的关键**不是参数数量，是时序分辨率**：内部步长 ≤0.25 ms、输出 ≤2–5 ms；VOT/爆破/塞擦=通道间相对时序（误差 ≤2 ms）。
- **R1-6** 「物理器官」不是免罪符：与 v8.1 的分界线只有两条——**(a) 音素→参数是否手写；(b) 表示能否装下瞬态**。

### 1.2 声学_物理建模（`团队/声学_物理建模/R1_立场.md` + `探针_渲染上限.py`）

- 推荐组合：**LF 声门流（可微主源，8 参）× 分段面积函数（3–6 维）× Kelly-Lochbaum 波导（实现层）× 三类噪声源（送气/摩擦/亚帧爆破）× 一阶唇辐射**；两质量块 body-cover 模型只作**校准臂**（碰撞不连续，不当可微层）。
- 工程口径：SR **22050**；声门/波导步长 45.4 µs（1–3 ms 瞬态 = 22–66 步）；两质量子步 11.3 µs；C13 两趟逐位同已测；CPU 实时率 **0.011–0.014**。
- **已测硬读数（无 ASR）**：Levinson 回估 AR(3) 真 [−1.2,0.5,−0.15] → 估 [−1.207,0.490,−0.128]；|k| 99% 分位 0.937；P1/P2/P3 全部有限、两趟 sha256 逐位同；与真波形 log-mel 逐带相关 P1 0.569 / P2 0.493 / P3 0.461。
- **自检暴露**：朴素映射的 KL 波导与 LPC 极点**不等价**（F1–F3：LPC [2078,3661,4802] vs KL [3295,7321,8097] Hz）⇒ P3 只作「波导实现代价」的负面信息。
- **契约硬缺口**：既有 `声带.FS=16000` vs 新器官 22050；meeting58 契约 13 个音色键里**没有声道形状低维量** ⇒ 需新增键（不在 R1 擅改）。

### 1.3 神经控制_少样本（`团队/神经控制_少样本/R1_立场.md`，238 行）

- **两个时钟**：内核一拍（100–250 ms）出 16 维指令；控制头（因果 Conv1D ≤0.3 M，无 attention）展开到 **200 Hz（5 ms）**；展开必须**学**，线性插值=死常数。
- **控制量 = 声线基线的偏移**（声线=谁在说，控制=说什么）；语速/时长必须由控制头给，不能留作声线常数。
- 接线零改既有件：只读 `状态源协议.快照()`；新增 `神经控制协议`/`控制渲染协议`；内生耳回写 `状态帧.遥测`。
- **训练点优先级**：W（接线，0 训练）→ A（反演，一切监督目标来源）→ C（模仿@30 min）→ D（闭环内生听觉）→ B（babbling 前向，机制项）。
- **反例臂最重要**：常数控制臂、**手写表臂**（v8.1 表驱动同器官）、控制置乱臂、同档 v13；若学到的控制器不显著优于手写表臂 ⇒ 「低维控制+学习」卖点为假，C 判无效。
- **诚实预期**：不是 20–30×，是 **2–4×**；**不认为 ≤5 min 可懂**；控制不可辨识/塌缩概率自评 >50%。

### 1.4 语料_适配（`团队/语料_适配/R1_立场.md`，234 行 + 实测 `盘点.*`/`选子集.*`）

- 167 条 = 44.1 kHz/2 ch/16 bit，**2.7669 h**；现有全是**已剪好的 ~60 s 定长切片**（>60 s 的 0 条）⇒「>1 h 与更短」是**新增的变长适配能力**。
- 对齐产物：167/167、**972 981 帧 / 162.16 min**、**30 927 音节 / 3.179 音节/秒**、声母 22/22、韵母 38、调 5/5、**音节型 796/4180（19%）**。
- 质量门：**161/167 合格**（拒 6：静音>0.6 或音节<30；不删既有，只降权）。
- 最小子集（确定性贪心，实测）：**≤5 min = 5 片段/1130 音节/336 音节型（42.2%）**；**≤15 min = 3237 / 544（68.3%）**；**≤30 min = 31 片段/6326 / 664（83.4%）**；相对档 1/16…全量 8 档表已落盘。
- 去重：L: 四个子目录 = 根目录副本（70/71/122/159），**不能扩数据**。
- 变长适配规范：片段为唯一单元（2–60 s）、25/10 ms 能量 VAD、±50 ms 边界、sha256+能量指纹去重、失败台账 jsonl；**切分器与「一片段一条」对齐未实现（只有规范+伪代码）**。
- 泄漏：S1–S12/S13–S18 命中训练语料 0 条；但**书面朗读 vs 口语对话**存在文体域差。

### 1.5 红线_判据（`团队/红线_判据/R1_立场.md`，229 行）

- C1 口径 = 禁框架/权重/推理栈，不禁训练思路；**本方案可通过**，但 3 个高危点：外部 ASR/声码器悄悄进生成路径；「自写听觉」实为 import 预训练；把内部判据（v8.1 是 29/30 饱和）当早停/选模型信号。
- **三分离不可合并**：训练信号 ≠ 选择信号（S13–S18 只选不报）≠ 报告信号（S1–S12 只报一次）。
- C9 本线风险：ASR 文本**回流进脑→器官控制回路** = 外部模型当耳；ASR 只离线评测。
- C13：物理 ODE **禁自适应步长**；固定子步数/线程数；同 ckpt 两趟逐位同。
- 预注册模板 15 字段 + 阶段门 G0–G5 + **6 条量化「无效即跳」触发（T1–T6）**。
- 报告必含：双集 CER + 逐句 + 两趟一致 + 阳性对照 + sham + 人耳；缺一即「未完成」。

2. 失败位置钉在**激励/瞬态/谱保真**，不在控制学习：
