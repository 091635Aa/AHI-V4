**一句话**：在这个合成任务与这个固定码叠加的窄状态载体上，**1024 叠加态的长程精确回查会退化，离散锚点/账本旁路能把关键信息原样留住并接近宽状态上界；sham 账本无效**。P1 上，隔离显著降低冲突后错误与事件锚定语义腐蚀、提高复合分；但**没有降低震荡**，且预注册的「sham 无效」不成立——post-hoc 诊断显示该失败很大程度来自 A′ 幻读自固化，不能把收益全部归给权限审判，也不能宣称「隔离解决自指」。这**不**证明「任何 1024 维 RNN 都致命」，也**不**证明「账本应替代内核」——详见 §4 诚实边界。

### 2.5 怎么读这个 FAIL（重要）

1. **P1-1 的 PASS 依赖口径，也依赖自省强度**：主口径是「稳定键报告 ≠ 本轮事件后权威真值」；预注册 §3.3 字面是「相对本轮事件后自身基线读」。严格同轮口径下三臂全为 0（自指回写是定点，轮内不改变自己的报告）⇒ **若严格按预注册字面，P1-1 会 FAIL（0 对 0）**。事件锚定口径下 A′ 的 0.855 表示「持续相信错值」，不是「轮内来回漂」。两个口径已并列登记在预注册 §3.6。**另：dev 自省强度扫描 0.1 时 A′ 漂移 0.1633 < 冻结门槛 0.20（P1-1 会 FAIL），0.5/1.0 为 0.8302，2.0 为 0.7083** ⇒ P1-1 PASS 依赖「自省回写与事件同权=1.0」这一跑前选择，不是对强度不敏感。
2. **P1-2 是结构性证伪，且冻结阈值低于指标分辨率**：A′ 的每轮自省是「读回→原值写回」，输出被锁死，所以震荡恰为 0；B′ 的 0.0013 全部来自合法更正。指标分辨率 = **1/753 ≈ 0.001328**（B′ 的实际值就是 1/753），冻结阈值 0.0005 低于分辨率；dev 已显示 A′−B′ = −0.001328（4/4）⇒ 该条开跑前即注定 FAIL。**仪器 oracle 的震荡也恰为 0.001328** ⇒ 指标把合法更正计为不稳定。**若剔除合法更新、只看无证据窗口，A′ 与 B′ 的震荡都为 0** ⇒ 该指标在本任务没有区分「连续自省」与「隔离」的能力。**「无审判的连续自省 ⇒ 震荡更高」在本任务不成立**；且与 A′ 的幻读无关（公平基线 A′_有据 的震荡仍为 0）。低震荡 ≠ 正确。
3. **P1-6 的失败主要由 A′ 幻读自固化驱动，但不能据此说权限审判不重要**：主判据用冻结的 A′（含对未写入键的幻读、且把幻读按同权写回），其崩塌使 S′（recency-only，但仍隔离）也显著优于 A′。post-hoc 公平基线 A′_有据（仅 dev 100–103，仅对已收到任务相关事件的键自省回写）把 A′ 的复合分从 0.5447 抬到 0.8010；此后 **S′ 反而更差**（复合 −0.0944、冲突错 −0.3929，4/4），dev 上 P1-6 会 PASS。⇒ 主判据 P1-6 的 FAIL **不能**解读为「权限审判的收益可疑」；P1-5 仍显示权限审判相对 sham 有 +0.786 冲突错、+0.012~0.015 震荡的稳定优势。但这是 dev n=4 的 post-hoc 诊断，不替换主判据；主判据仍按冻结口径 FAIL。
4. **支持到什么程度**：在本合成任务、本 D=2048 载体上，「事件触发 + 只读快照 + 受控写回」相对「连续自省」**显著降低冲突后错误率与事件锚定语义腐蚀、提高复合分**；但**没有**降低震荡（反而略高），且预注册的「sham 无效」不成立（隔离架构本身也显著优于 A′）。因此 P1 的合格结论是：**隔离是承重的（在冲突错/复合分上），权限审判在隔离之上还有可分离增益（P1-5），但本轮预注册的合取判据 FAIL**。不能外推为「隔离解决自指」「更深/更多自省更好」。
5. **A′ 的崩溃机制**：同一回读器对未写入键会幻读（P0 A 臂对干扰键同样 0 拒答）；A′ 无审判，把幻读按 1.0 权重写回，再被自指回路固化 ⇒ 稳定键永久错、查询正确率仅 0.35、更正延迟 63 步。这是「自报被当成证据」的机械后果，不是额外加码；但它构成 A′ 的强失败模式，公平化诊断已给出。

## 4. 诚实边界（必须与结论一起读）

1. **A 是特定窄状态载体，不是任意 1024 维 RNN 的上界**：A = 固定随机码叠加 + 步进衰减 + 状态幅归一化 + 解绑/吸引子回读；没有学习、没有正交化、没有门控写入。它的退化在本实验中随同时保留的事实数增加（容量扫描），但**不能外推**为「任何 1024 维可训练 RNN 都记不住 192 条 4-bit 事实」。
2. **C 是精确上界，不是目标架构**：C 每键独立槽位、精确回读；B≈C 只说明「在本任务、本容量下，离散账本已够到上界」，不说明有限容量账本在更大规模仍接近 C。
3. **B 的优势部分是设计使然，且 B/C 都内建了任务真值规则**：B 原样保存实体/目标/约束，并按 `(权限, 步, 序号)` 受控回读；C 的每键独立槽位也用同一规则覆盖；A 两者都没有。实验量化的是「载体 + 回读规则」的合成差，而不是单独发现「账本比向量更聪明」；P0-2 在 B=C=1.000 时恒真、无信息量。B 账本容量 4096、本任务未做 B 的容量压力扫描；B 的容量边界未测。
4. **任务规模是玩具级**：T≈293、192 细节、16 条矛盾、2 条干扰/步；D=1024/2048；不能外推到真实 V4 规模。
5. **真实系统未接**：本实验只跑合成任务，**没有**把 A/B/C/S 或 A′/B′/S′ 接到 V4 主程序/内核；真实系统上的效果**未测**。
6. **C1 自检是源码级**：禁词子串扫描 + 回读式审查（吸引子函数/无 QK^T/无全局归一化检索）是工程自检，不是形式化证明；不能证明「绝无注意力同构」。
7. **统计功效有限**：每集 6 种子，精确符号检验 6/6 时 p=1/64≈0.0156；两集都过是复制，不是大样本。阈值先冻结，未看留出集调参。
8. **CPU/内存口径**：CPU 为 `time.process_time()`；内存为 `tracemalloc` Python 分配峰值（P0 6.2 MB / P1 2.4 MB），**不是 RSS**；独立复核实测真实进程峰值 **RSS P0 40.9 MB / P1 34.9 MB**，仍 < 2 GB（D4）。
