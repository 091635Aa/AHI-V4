## 0. 动机

主判据里 A′（事件直接写入 + 每轮把读回写回 + 无独立审判）在 dev/判据集/留出集上表现为：
稳定键永久错、查询正确率仅 ~0.35。诊断下来，主因是**同一回读器对从未写入的键返回幻读**
（P0 A 臂对干扰键同样 0 拒答），A′ 无审判地把幻读按与事件同权写回、并被自指回路固化。
这会带来一个合理质疑：A′ 是不是被「幻读自固化」做成了稻草人，从而让 P1-6（sham 对照）
失真？本诊断构造**公平基线 A′_有据**回答这个问题。

## 1. 公平基线定义（与 A′ 唯一差别）

`A′_有据` = 与 A′ 同构（同一 `连续状态`、同一码本/吸引子回读、事件直接写入、每轮自省把读回
按同一强度 1.0 写回、无独立审判），**唯一区别**：自省回写只对「已收到过任务相关事件」的键
生效，不对从未写入的键写回幻读。这是键存在性簿记，不是权限/审判。

## 3. 解读（诊断结论）

1. **幻读自固化确实贡献了 A′ 崩溃的大头，但不是全部**：把 A′ 换成公平基线，复合分从
   0.5447 → 0.8010（+0.256，4/4 方向一致），漂移从 0.8302 → 0.2042（仍非 0），冲突错
   0.5357 → 0.3929。剩余 0.204 的漂移来自**自指回写把「新键首次读回」的互扰误读固化**
   （自强化把其他键的权重抬高，新键以 1.0 写入后可能被互扰读错、随后被自指回路锁死）。
   ⇒ 「A′ 崩溃全由幻读造成」的说法**不成立**；即使去掉幻读，无审判连续自省仍会漂移。
2. **B′ 相对公平基线仍全面占优**：漂移 +0.204、冲突错 +0.393、复合分 +0.199，均 4/4 方向一致
   （dev 不作显著性宣称）。但漂移差 0.204 已接近主判据冻结门槛 0.20，且逐种子有 0.159/0.163
   两个低于门槛 ⇒ 公平化后「漂移优势」会变得边缘，主判据的 P1-1 大差值主要来自幻读固化。
3. **震荡方向不受影响**：A′_有据 震荡仍为 0.0000；B′ 的 0.0013 仍来自合法更正。
   ⇒ **P1-2 的失败是结构性的（自指回写=定点，锁死 ⇒ 不震荡），不是幻读造成的。**
4. **P1-6 判断需要修正**：S′ 相对 A′_有据 复合分 **−0.094（4/4 更差）**、冲突错 −0.393，
   ⇒ 在 dev 上把主基线换成公平基线，**P1-6 会 PASS**（sham 不再优于 A′）。
   ⇒ 主判据里 P1-6 失败**主要由 A′ 的幻读自固化驱动**；这不能反过来说明权限审判的收益是假的
   （P1-5 仍显示 B′ 对 S′ 有 +0.7857 冲突错、+0.0173 震荡的稳定优势）。

## 4. 「严格同轮」口径对照（读自主判据结果 JSON，不重跑）

主判据 P1-1 的语义漂移率主口径 = 「报告 ≠ 本轮事件后**权威基线（真值）**」；
预注册字面「相对本轮事件后**自身基线读**」的严格同轮口径见结果 JSON 的 `语义漂移率_同轮`：

| 集 | A′ 严格同轮（均值/最大） | B′ | S′ | 事件锚定（主口径）A′/B′/S′ |
|---|---|---|---|---|
| 判据集 0–5 | 0.000000 / 0.000000 | 0.000000 / 0.000000 | 0.000000 / 0.000000 | 0.8554 / 0.0000 / 0.0547 |
| 留出集 6–11 | 0.000000 / 0.000000 | 0.000000 / 0.000000 | 0.000000 / 0.000000 | 0.8561 / 0.0000 / 0.0278 |

**结论：三臂在判据集/留出集所有 12 个种子上，严格同轮漂移都恰为 0.000000**（自指回写是
定点：写回=读回，轮内不会改变自己的报告）。因此：
- 若严格按预注册字面口径，**P1-1 判 FAIL**（0 对 0，无可检验差；不可能 6/6 显著）；
  主判据的 FAIL 名单会从 {P1-2, P1-6} 变成 {P1-1, P1-2, P1-6}（5/8 过）。
- 主判据实际采用事件锚定口径（报告相对事件权威基线的偏离），P1-1 在两集 6/6、p=0.0156 通过；
  该口径测的是「稳定内容是否在自省中偏离证据基线」，不是「轮内自己改自己」。
- **两口径并列上报；主判据判定按原冻结口径不变（FAIL）。**
