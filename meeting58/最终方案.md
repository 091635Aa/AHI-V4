### 1.3 运行时接口流


## 2. 两层解耦方案

### 2.1 行层（角色行为逻辑）——只产文本

- `实施/协议_角色逻辑.py`：`池角色逻辑`
  - 输入：`角色模板` + `状态帧`；输出：`文本产物`。
  - 修 R5：旧 `步=5` 与洛池 gcd=5 ⇒ 15 句只有 3 句可达；新实现「全池 sha256 选句 + 线性探测」⇒ 24 段内 **24 句可达**（池 31）。
  - 修「人设零通路」：模板的 `台词/腔调/角色包` 是显式输入；换模板 ⇒ 文本/腔调可测地变。
  - 不持声层对象；`模板.声线名` 只是引用。

### 2.2 声层（音色输出）——只产音频

- `实施/协议_音色渲染.py`：`声带渲染器`（纯函数式，无模块级可变态）
  - 输入：文本 + `声线档案` + 情绪 + `状态帧` + 腔调；输出：`渲染产物`。
  - `声带音色(声带.声带器官)` 子类覆盖两个缝（不改既有件）：
    - `音节帧()`：f1/f2/f3 × 三轴共振峰缩放；腔调降调（半音）；
    - `合成波形()`：谱倾斜（一阶预加重/去加重）→ 紧喉（tanh 驱动）→ 气声（高通噪声+包络门控）→ 粗糙（33Hz AM）→ 归一 → 增益/音量倍（后置，修复「幅度被归一化吃掉」）→ 软限幅。
  - 自检与 `声带.发声` 同口径：参数合法/数轴往返/无 NaN/跳变/峰值/实时率。
- `实施/声线库.py`：5 个内置档案 + 从参考录音估参（`从参考估`，只估参数、不复制波形）。

### 2.3 声线档案（14 维，不是 8 维）

| 维 | 字段 | 用途 |
|---|---|---|
| 1–8 | 基频/语速/幅度/气声/紧喉/粗糙/送气/声区 | 原生声带参数（紧喉/粗糙本轮**真的**进波形） |
| 9–11 | 共振峰缩放 (s1,s2,s3) | 声道尺度（男女/角色差异的主维度） |
| 12 | 谱倾斜 | 明亮/低沉 |
| 13 | 气声谱重心 | 气声色彩 |

## 3. 动态可插拔挂载架构

### 3.1 注册表（`实施/注册表_挂载.py`）

```python
表 = 注册表_挂载()
表.注册(类, 名, 工厂, 版本, 依赖, 元数据)      # 已登记
表.试跑(类, 名, 探针)                          # 已试跑（失败→已试跑(降级)）
表.切换(类, 名, 栅栏="句边界")                  # 当前（旧→历史）
表.回滚(类, 到版本=None)                        # 历史→当前
表.卸载(类, 名) / 表.调用(类, 方法, ...)        # 隔离调用
表.表现()                                       # 当前/已登记/历史/隔离/失败/台账/指纹
```

生命周期：`已登记 → 已试跑 → 当前 → 历史（可回滚）→ 已卸载`；连续失败 3 次 → `已隔离` 并返回降级产物（不抛穿）。

**隔离四道**：①每次调用 try/except→降级产物；②调用前查协议版本/依赖；③装载/切换前快照 `np.geterr()/sys.path/os.environ`，卸载还原；④内核只持指针+历史栈。

### 3.2 三个必答（实测）

| 问题 | 答案 | 实测 |
|---|---|---|
| 换音色要重启吗？ | **不要** | 声带构造 2.8–3.9ms；换档案 O(1)；波形不同、自检通过；两趟逐位同 |
| 热插拔角色模板要重建核吗？ | **不要** | 换 3 个角色包前后 `核.参数基线().W码` 恒为 `9cf8b366d15703f8`；头装载 10.5–22.4ms；状态轨迹指纹不变 |
| 切换时正在说的话？ | **句边界栅栏** | 当前句用旧声线走完，下一句新声线生效；禁止中途换律（旧 `当前律` 可变态的 bug 已从新路径消除） |
