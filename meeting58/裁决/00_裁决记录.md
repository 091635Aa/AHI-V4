## 0. 一句话裁决

**「角色复刻效果差」不是模型问题，是三个可测量的工程缺口叠在一起：**
① **音色层**——8 个音色参数只有 2 个真正进谱（紧喉/粗糙无出口、幅度被峰值归一化吃掉、共振峰零入口），4 档档案实际只差音高；
② **状态层**——内核 D核=64 的状态**从未进入**声带（声带要 1024，旧路径用 `rng(55)` 随机向量顶替）；
③ **契约层**——行层（角色逻辑）与声层（音色输出）没有契约，调用点直接串，未知音色静默回落。
**本轮落地**：三协议 + 注册表 + 冻结契约；音色层真接线（共振峰/谱倾斜/紧喉/粗糙/气声/后置增益）；状态确定性投影进声带；行/声两层解耦并用哨兵判据验收；判据 **26/26 PASS**；产出横屏+竖屏 demo 片。

## 2. 裁决清单（A1–A12，实施以此为准）

| # | 裁决 | 理由 / 边界 |

| A1 | **命名**：行层＝角色行为逻辑，声层＝音色输出；**不得**再用 A/B 指这两层（内核 A/B 已是自我态/世界态） | E1 §0 命名冲突 |

| A3 | **两层只传值不传对象**：状态帧（frozen bytes+指纹）→ 文本产物 → 渲染产物；行层不得 import 声层，声层不得 import 行层 | E3 §0 |

## 3. 被否的方案（不再讨论）

1. **给软限/B 通路加权实现「扮演」**：要改内核（C14），且 E1 实测现有 A 已压 B，加权是另一个机制；不采用。
2. **直接把 64 维状态喂 1024 声带**：实测 `ValueError`；也不做「截断/补零」——补零会丢状态；采用确定性投影。
3. **复制 `合成波形` 全量重写以接紧喉/粗糙**：维护成本高（E2 估 ~110 行）；先用后处理链（tanh/AM/谱倾斜）达到可测区分度，复制留作后续。
4. **用 RVC 音色克隆进内核做 demo**：C10 越宪、破坏确定性、GPU 被训练占用；本轮内核 demo 只用原生声带；RVC 若要用，只能外部控制层+登记（A10）。
5. **给「扮演」加 B 权重并宣称人设不崩**：与 E1 实测矛盾；不宣称。
