## 0. 结论（先给裁决口径）

1. **现状不是「解耦」，是「两层都还没接线」**：文本层与音色层的 import 图没有公共边，也没有任何接口契约文件；把「两层互不调用」当成解耦证据，等于把"没做"当"做对了"。[实测 import 图]
2. **所谓「角色复刻」= 句池查表 + 4 档 8 参数音色**：人设对输出**零影响**（改成人设「只说火星语」逐字不变）；可辨识的只是**谁的句池**。[实测]
3. **「扮演＝B 压制 A」在代码里没有实现**：`差=软限(A−B)` 是对称减法、没有 B 权重；门 `符(A,B)` 是重合度（同向/反向同权）；A 有效秩 = 2，且在角色复刻链路上**恒 0.5**（永不更新）。[实测]
4. 最便宜的三条 must-fail（<1.2s，纯 CPU）能直接杀掉现有 10 臂判据里的「A1/A2/A3/A8」类 PASS（见 §5）。

## 2. 攻击「扮演 vs 成为」

### 2.1 「B 压制 A」是过度简化（[实测]+[源码]）
- `前向_双区室` 的整合式就是 `差 = _归(软限(A−B列))`（`算子_两区室核.py:223`），对称减法，**代码里没有 B 的权重、没有可调压制系数**。
- 所谓"覆盖"实际是**幅度顶穿**：同向 B×1.0 ⇒ cos(差,A)=0.0；同向 ×1.5 ⇒ **−1.0**（被判"出戏"）；**反向 ×4 反而 cos=0.996（永不翻负）**[实测]。⇒ 现有「出戏率=⟨差,A⟩<0」度量的方向是**错的**：它抓的是"B 与 A 同向且超过 A"，不是"人设冲突"。
- 实跑 30 拍：B 在 A 方向投影比 **均值 0.25 / max 0.325**（标量 0.5）；标量 0.05 时 **≈0（max 0.05）**；标量 0.95 时 max 0.546[实测]。按该机制 B **永远顶不穿 A** ⇒ 「扮演会崩」在当前动力学的可测范围里根本不发生——不是稳，是**人设没进来**。

### 2.2 参考里在代码中找不到对应实现的 3 句话
1. **「人设文本/规则进 B」**：没有通路。`角色包.人设` 只被 `说话_连贯.py:83,99` 读进一个**死代码** `角色LM`；`V5._token列`（`:153-162`）只有 观测/成/败/上动作/消息/上词，**没有 人设→token 的映射**。[源码]
2. **「provenance 自源标记」**：`注入外源规则`（`算子_两区室核.py:259`）只在 `判据_挂载.py:169-170`、`判据_V5:511-513` 被判据调用；**挂载/说话/说 路径从不调用**，自我态上不存来源标签；角色记忆 `来源="外源·角色包"`，却被 `说()` 当第一人称念出。[源码]
3. **「内部仲裁 / ĝ 感到不一致」**：没有实现。门 `符` 对**同向与反向给同一个 credit 权 1.6348**（符号盲），学自我方向完全由外部老师标签决定（奖=0、ŷ=0 ⇒ 标量 0.5→0.3038）[实测]；`桥_自我态_自模型.py` 的 ε_self 未被 V5 import；A 名义 D=64、**SVD 有效秩=2**，任何注入的人设向量 1 次 `学自我` 后 cos 1.0→**0.0532**。[实测]

### 2.3 「扮演」必崩的可测预测（每条都可被推翻；[提案]）
- **B1（无扮演）**：改变人设文本（含规则句），输出逐字不变 ⇒ 现状链路上"扮演"恒为"无扮演"。反证：找出一条 `人设字符串→输出` 的依赖。[已实测支持]
- **B2（失败后更没扮演）**：连续失败 3 拍把自我标量压到下限 0.05（`探针_R1_扮演vs成为` P4：头 5 拍 `0.5,0.336,0.172,0.05,0.05`，成功率 0.133）⇒ 之后"人设 token"注入的边际效应≈0（投影比≈0）。反证：注入后 A 分量不降。
- **B3（未教场景必崩）**：角色包外的新句子输入时，输出仍 100% 落在句池（meeting54 实测池命中 100%），生成句占比=0 ⇒ 换角色=换池，不是"成为"。反证：出现 ≥30% 非池句。

## 3. 攻击「角色复刻」：假 PASS、RVC 越宪、参数化边界

### 3.1 只在自家文本/合成音上评测必然出现的假 PASS（[实测] 除注明）
| 假 PASS | 读数 | 为什么是送分题 | 必须失败对照 |
|---|---|---|---|
| 「三角色可辨识 1.0」 | 现状 **0.9667**（结果 JSON；`证据_说话.md:50` 写 1.0）；**同池只换人设 → 0.2667**；池 Jaccard 0.05/0.158/0.062 | 特征是词袋，三角色池互不相交 ⇒ 最近质心只是背池子；"机会 0.333" 的零假设本身错误 | 同池三人设臂（MF-0） |
| 「记忆召回正确率 1.0」 | 置乱记忆后仍 **10/10=1.0**；跨包串公式恒 0 | 召回只从 `self.记忆` 取；`本包∩全包−本包≡∅` 恒真式 | 置乱记忆臂 + 外部召回臂 |
| 「同状态换包改变率 1.0」 | 1.0 | 换包=换池，必然改 | 同池换包应≈0 |
| 「音色模仿 PASS」 | 4 档 F0 最小间隔 28.7Hz ⇒ F0 单参数 4/4；档案含语速 | 判别器可被单参数骗 | 只改 F0 / 只改语速臂（MF-2） |
| 「音色估计回环成功」 | 估出的参数再合成，仍是同一 8 参数空间 | 自己出题自己判卷 | 外部真人录音 / 回放臂（MF-3） |
| 声学身份 | 声纹不可分 0.667/0.556；共振峰固定表、无缩放（`声带.py:267`；meeting55 §4.4） | 换角色**听不出** | 同人≥0.85 且 异人≤0.55 双约束 |

**结论**：现有「角色复刻效果差」的根因次序（红队版）= ①人设无通路 ②语言=查表 ③音色只有 4×8 参数且无共振峰 ④两层无契约（接线时必崩 D=64↔1024）。

### 3.2 外部 RVC 路线会怎样污染纯血内核 / 越宪
- 越宪：**C10**（外挂模型当发声器官）、**C13**（GPU kernel/采样 ⇒ 两趟不可能逐位同）。按 meeting54 先例须登记 模型名/权重 sha256/种子/来源标签，且**输出不得说成 AHI 自己想/自己长**。
- 污染路径：① RVC 进闭环 ⇒ 非确定，C13 作废；② 用 RVC 训练集/参考 wav 评音色 ⇒ 训练集泄漏，指标全假；③ RVC 替换发声 ⇒ `声带.py` 的 8 参数与 `说_音色` 成死代码，"纯血内核"宣称失去证据；④ donor 声纹/IP（洛天依角色权、MOSS 影视形象）；⑤ demo 里 RVC 段与 AHI 段混剪 ⇒ 归因不可审计。
- 红队口径：RVC 只能待**外部控制层的内容层**，AHI 内核只出「状态+文本」，demo 必须标 `[外部模型内容层·越宪登记]`，且给 记录-重放 + sha256。

### 3.3 「参数化模仿」与「真声克隆」的边界 / 对外红线
- **可测边界（唯一诚实判据）**：输出能否被 `(8 参数, seed, 文本, 声带.py 版本)` **逐位重建**（wav sha256 相同）⇒ 能 = 参数化模仿；不能 = 克隆/回放 ⇒ 不得计入 AHI。
- **能力上界**：8 参数只动 F0/语速/幅度/气声/紧喉/粗糙/送气/声区；共振峰来自韵母固定表（`声带.py:249-266`）⇒ 改不了声道形状 ⇒ **不能宣称"像洛天依"**。
- **对外红线（建议写进裁决）**：不得说"洛天依本人 / 真声克隆 / 1:1 复刻"；不得把 4 档档案说成"角色音色"；不得把句池查表说成"角色扮演"；每条输出必须带来源标签（池/外源记忆/外部模型），缺标签即 VOID。
