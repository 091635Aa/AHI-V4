## 0. 结论先行

1. **「角色复刻效果差」在输出层有一个可量化的主因：有效音色维度只剩 2 个。** [实测] 8 个档案参数里
   `紧喉度`/`粗糙度` 大改后 wav **逐位同一**；`幅度`/`送气量` Δ能量 ≤0.07dB、包络余弦 1.0000（被峰值归一化吃掉）；
   共振峰轨迹对**全部**音色参数的敏感性 `max|Δ| = 0.0`。⇒ 4 档档案实际只差 `基频`（+弱 `气声度`）。
2. 因此现有 4 档在 17 维声纹代理下**两两不可分**：判别比 D=档间距离/同档跨文本波动 = **0.35–0.92（全 <1）** [实测]，
   与 meeting55 `H4 同人 0.667/异人 0.556`（`证据_听说话.md:15`）同向，**根因不在指标而在合成器参数面**。
3. **最高 ROI 是共振峰缩放**：它是唯一「文本无关、幅度大（F1/F2 跨元音差 250–1000Hz）、零 DSP 成本」的未用维度，
   且**不需要改 `声带.py`**——`发声()` 用 `self.音节帧`/`self.合成波形` 动态派发（`声带.py:485-486`），子类可整段接管。
4. 对外口径：现状只能宣称「**参数化模仿、档案间可分出男女**」，**不能**宣称像洛天依/初音/MOSS（§4）。

## 3. 可测音色区分度指标与阈值（含 must-fail）

**口径铁律**：成对比较必须固定 `文本 + 情绪 + 语速 + 向量`；否则情绪位移（2.40st）与文本噪声（2.72–5.76st）会吞掉档间信号。

| 指标 | 定义（增益不变） | 现状实测起点 | 过线阈值 [提案] |
|---|---|---|---|
| M-A F0 基线半音距 | 同文本同情绪 `12·log2(f0_A/f0_B)`，用**帧参数真值**（`音节帧` 输出）而非估计器 | 2.31 / 4.25 / 5.00 / 6.57 / 9.25 / 11.57 st | 任两档 ≥**3.0** st（现状 2.31 边缘不过） |
| M-B 7 带 log 包络余弦 | 帧 32ms/10ms，7 带相对能量 dB，逐帧减总能量（故对增益严格不变）；比 1−cos | 档间 0.9896–0.9975 vs 同档 0.9840–0.9970（**重叠**） | 档间 ≤**0.985**（现状全不达标） |
| M-C 共振峰位置 | 倒谱 lifter(30) 包络峰，F1/F2/F3，5 音节 `啊` 稳态段中位 | 4 档 F1 719–812（差 93Hz）、F3 全 2469 | 任两档 F1 或 F2 差 ≥**250Hz**（现状 0） |
| M-D 声纹代理 17 维 | 7 带包络均值 + 7 带帧间 std + F0 中位(半音) + F0 std(半音) + 谱倾斜；尺度=同档跨文本 pooled std；d=归一欧氏 | 档间 d=0.47–1.27；同档跨文本 d=0.92–1.87 | 档间 d ≥**1.5** 且 **判别比 D = 档间 d / 同档跨文本 d ≥ 2.0**（现状 0.35–0.92） |
| M-E 输出增益有效性 | `音量倍` 0.5 vs 1.0 的 RMS 比 | **恒为 1.000**（失效） | RMS 比 ∈ [0.45,0.55] 且包络余弦 ≥0.999 |

**must-fail（必须失败才算判据有效）**
1. **同档案同文本两趟** → sha256 逐位同。现状 **PASS**（[实测]）；若不过说明引入非确定性。
2. **换档案同文本** → M-A 必须 < 阈值 **或** M-B 必须 > 阈值（即「掉到线下」）。现状 **全 FAIL** ⇒ 这正是
   「角色复刻效果差」的可测量化；判据有效性的前提是**它现在必须失败**。
3. **只改音量** → M-D 距离 ≤0.1 且音色标签不变；**但**必须同时过 M-E，否则「不变」是因为音量根本没接上（当前陷阱）。
4. **只改情绪** → 音色标签不变。**现状不可能过关**：情绪位移 2.40st > 女声档间 2.31st；须先把 M-A 定义为
   「档案基线比」（文本/情绪无关）才可能通过。这是**接入前必须修的口径缺陷**。
5. **sham**：复制档案改名 → M-D=0 且判「同」；三档置乱（随机换档标签）→ 判别准确率 ≤ 机会+0.1。
6. **回放检测**（沿用 meeting55 V3）：把参考 wav 当输入/输出，互相关 >0.99 ⇒ 必须抓。

## 4. 防自证：哪些指标**不能**证明「像洛天依/初音/MOSS」

- **M-A F0**：只证明音高基线不同；任何参数化合成器都能调。不证明嗓音身份。
- **M-B 7 带包络 / M-C 共振峰**：只证明「频谱形状/声道尺度相近」。本合成器只有 3 个固定共振峰表 + 硬编码带宽，
  个体声道几何的**比例关系、带宽、鼻化**都不可控 ⇒ 结构性上界，不是调参能补的。
- **M-D 声纹代理**：自造量、无外部锚；只证明「**档案之间可分**」，不证明「与目标说话人同分布」。
- **任何在自家合成音上标定的阈值**：自证（meeting55 §5.1 已登记 [自证]）。
- **洛天依/初音**是**歌声**合成：需要音域/颤音/换气声/歌词对齐/长音稳定，本 16kHz 语音声带模型结构上不覆盖；
  **MOSS** 是真人演员音色（声克隆问题，C10 红线）。⇒ 三者都**不能**作为「像」的证据。

**诚实上界**：参数化模仿只能改「可听出的粗粒度差异」4 类——音高基线、语速、气声比例、声区亮度（+ 未来共振峰缩放/
谱倾斜）。不能改：个体声道几何、声门下压/开商、黏膜波微扰、鼻化、发音习惯/口音、协同发音细节。
⇒ 上界是「**能听出是不是同一音色族**」，**不是**「是某人」；且两女声之间现状连「同族」都不成立（D<1）。

**对外口径（三档）**：① 可说「原生声带合成，音色由 N 个可解释参数控制，确定性可复现」；
② 可说「**参数化模仿**：从参考录音估 F0/亮度并套用，非声克隆，未经真人盲评（未测）」；
③ **不得说**「复刻/还原/像 洛天依/初音/MOSS」，不得说「AHI 自己想出来的声音」。若 demo 用 RVC 做**内容**包装，
须按 meeting54 越宪登记（模型名/权重 sha256/种子/来源），且声线来源必须标注为外部。

## 5. 渲染层接口签名草案（交 E3 收进契约）

```python
# 新增文件，不改既有件；建议放在 meeting58/实施/ 或 挂载/ 下
@dataclass(frozen=True)
class 声线档案:
    名: str; 版本: str                      # 版本参与确定性指纹
    基频: float                            # 70..400（与 声带.py:34 一致）
    语速: float; 气声度: float; 紧喉度: float; 粗糙度: float
    送气量: float; 声区: float
    f缩放: tuple = (1.0, 1.0, 1.0)         # 新增：F1/F2/F3 比例（共振峰缩放）
    谱倾斜: float = 0.0                    # 新增：dB/oct 后置倾斜
    种子: int = 300

def 渲染(文本: str, 状态向量, 声线: 声线档案, 情绪: str = "平静", *,
        语速倍: float = 1.0, 输出增益: float = 1.0,
        输出目录: str = None, 采样率: int = 16000) -> dict:
    """返回（错误也返回同一 schema，不抛异常）：
    { "状态": int,                        # 0=OK，见错误码
      "wav": bytes | None,                # ★ 必须给 bytes：目录会被 FIFO 删（声带.py:505-510，上限 32）
      "wav路径": str | None, "采样率": 16000, "时长秒": float, "帧数": int,
      "指纹": "sha256(wav bytes)16",       # ★ 身份锚（文件名随 发声号 递增，不可作身份）
      "参数": {14 维实际生效值},           # 含 f缩放/谱倾斜/输出增益（后置）
      "溯源": {"声线名","声线版本","情绪","种子","文本sha256","向量sha256","渲染器版本","来源":"native"},
      "自检": {"参数合法","数轴往返","无NaN","跳变","峰值","实时率"},
      "告警": ["文本超64音节已截断"] }     # 现状静默截断（声带.py:252 [:64]），必须改为告警
    """
```

**错误码**：`0` OK｜`1001` 空文本（去标点后无音节）｜`1002` 文本超限（>64 音节）｜`1003` 声线档案非法
（基频越界/缺字段/版本不符）｜`1004` 状态向量维度不符｜`1005` 自检不过（参数非法/往返<1）｜`1006` 实时率超
预算（>0.5）｜`1007` 落盘失败｜`1008` 非确定性（两趟指纹不同，仅 `自检模式`）。

**确定性要求（逐条可测）**：① 同一 `(文本, 声线内容+版本, 情绪, 种子, 向量, 语速倍, 输出增益, 采样率)` ⇒
`指纹` 相同；② 随机只来自显式 `种子`（`声带.py:367` 每次用 `self.seed` 重播）——**禁止** `说_音色.py:110-111`
那种隐式默认向量；③ **禁止全局可变状态**：现状 `说_音色.py:93-100` 的 `_器` 单例 + `:104-108` 原地改
`器.当前律`，两路并发/热插拔会串味（E3 必须包一层，或每请求新实例）；④ 不得依赖 `发声号`/`wav` 文件名；
⑤ **情绪必须是显式入参，禁止写进声线档案**（否则 §1 的 2.40st 情绪位移会冒充音色）。
