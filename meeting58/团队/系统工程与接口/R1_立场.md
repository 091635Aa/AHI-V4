## 2 三组契约（可执行签名；错误码见 §2.4）
```python
# 协议_状态源.py —— 只读 A/B/内心；内核是唯一写者
@dataclass(frozen=True)
class 状态帧:                       # 不可变 ⇒ 可指纹、插件写不进去
    拍:int; 观测:int; D核:int; o用:bytes; 内心:bytes    # float64 小端
    自我标量:float; 惊喜:float; 遥测:Mapping[str,float]; 指纹:str  # sha256(...)前16
    def 数组(self, 名="o用") -> np.ndarray: ...        # np.frombuffer(...).reshape(D核)
class 状态源协议(Protocol):
    协议版本:str; D核:int
    def 快照(self, 拍:int|None=None) -> 状态帧: ...
    def 轨迹指纹(self) -> str: ...
    def 关(self) -> None: ...                          # 幂等
# 协议_角色逻辑.py —— load/unload/step/文本输出（只产文本+来源，不碰波形）
class 角色逻辑协议(Protocol):
    协议版本:str; 名:str; 依赖:tuple[str,...]          # ("状态源>=1.0","语料:角色包")
    def 装(self, 源:状态源协议, 种子:int=0) -> None: ...
    def 卸(self) -> None: ...
    def 步(self, 帧:状态帧) -> 文本产物: ...           # 一拍 → 一段文本
文本产物 = TypedDict("文本产物", {...})  # 文本/拍/句数/词列/记忆命中/头指纹/来源/降级/错
# 协议_音色渲染.py —— render(文本, 状态, 声线档案, 情绪) → 音频 + 溯源
@dataclass(frozen=True)
class 声线档案:                     # 参数化模仿，不是声克隆
    名:str; 版本:str; 来源:str; 参数:Mapping[str,float]; 指纹:str  # 8参数(声带.py:33)
class 音色渲染协议(Protocol):
    协议版本:str
    def 渲染(self, 文本:str, *, 声线:声线档案, 情绪:str="平静", 状态:状态帧|None=None,
             语速倍:float=1.0, 音量倍:float=1.0, 种子:int=300) -> 渲染产物: ...   # ★纯函数
    def 预热(self, 声线:声线档案) -> None: ...
    def 卸载(self) -> None: ...
渲染产物 = TypedDict(...)  # 通道/wav/采样率/样本数/时长秒/波形/参数/律/声线指纹/种子/自检/耗时毫秒/降级/错/溯源
```

## 3 注册表 + 生命周期 + 失败隔离
```python
# 注册表_挂载.py
class 注册表_挂载:
    def 注册(self, 名:str, 版本:str, 插件, *, 类:str, 依赖=(), 元数据=None) -> str
    def 试跑(self, 名:str, *, 状态列:list[状态帧], 拍数:int=8) -> dict   # 只读、不切
    def 切换(self, 名:str, *, 栅栏:str="句边界") -> dict                 # → 回执(旧,新)
    def 回滚(self, 到版本:str|None=None) -> dict                        # None=上一当前
    def 卸载(self, 名:str) -> None
    def 表现(self) -> dict                                              # 当前/历史/失败计数/隔离集
```
状态机：`已登记→已试跑→当前→历史(可回滚)→已卸载`；连续失败 3 次 → `隔离` 并自动回滚。
隔离四道：① 每次调用 `try/except` → 返回**降级产物**（`降级=True, 错=E1009`，绝不抛穿）；② 调用前查
`协议版本+依赖`，不符即拒（E1002/E1003）不调用；③ 装载前快照 `np.geterr()`/`sys.path`/`os.environ`，卸载还原
（治 挂载_角色.py:26）；④ 内核只持**当前指针+历史栈**，不持插件内部对象。既有先例直对齐：`统一输出.注册钩子/摘钩子`+异常降级（通用接口.py:201-205,213-214）。
**三个必答**：① **换音色要不要重启？不要**——[实测] 构造 2.8–3.9ms、换律 O(1) dict、波形不同且 `通过=True`、跨实例逐位同；只有超 8 参数域（换基线F0种子/共振峰表）才重建**渲染器**（仍不重启进程）。② **热插拔角色模板要不要重建核/重训？不要**——[实测] 3 包换挂前后 `核.参数基线().W码` 同为 `9cf8b366d15703f8`，头装载 10.5/13.7/22.4ms，每拍生成 0.17–0.24ms；唯一成本是状态列重跑 4.2ms/拍（缓存状态帧 ⇒ 换包零重跑）。③ **切换时正在说的话？句边界栅栏**——渲染是整句纯函数（声带.py:478），正在渲的句用旧声线走完、新声线下一句生效；`句边界`(默认)/`灌满`(含已排队句)/`立即`(丢弃未播帧重渲)；**禁止中途混律**（那正是 `当前律` 可变态的 bug）。

## 6 四件套（关键主张）
- **A 换音色/换模板都不需重启、不需重建核**。*证据*：[实测] 构造 3ms、切换 O(1)、波形不同且自检通过、核 `W码` 不变。*反证*：若某声线需改共振峰表/基线F0种子 ⇒ 现实例不能承载，须重建渲染器（但不重启进程）。*代价*：档案限 8 参数 + E2 的共振峰缩放系数域，越域返回 E1006（会拒掉一部分"更像"的档案）。
- **B 解耦前必先接上状态→音频真链路，否则音色优化都是换壳**。*证据*：[源码] 说_音色.py:110-111 随机向量、:103 仅(文本,音色名)；挂载_角色.py:73 的 D=64 状态无处可去。*反证*：若已有调用点把 `o用` 确定性投影进 `渲染(状态=…)` 且判据显示状态改变波形可分辨，本主张推翻。*代价*：需一层确定性投影 D核64→声带1024（复用 `_键整数`+`_投影阵`，通用接口.py:55-61,96-104），并把状态影响压在 `分位读数` 微韵律（声带.py:240-246）——**幅度小，这是本主张的真实上界**。
- **C 热切换不删可变态就不成立**。*证据*：[源码] 说_音色.py:106-108 渲染前写 `当前律`，声带.py:481 才读 `韵律` ⇒ 后写者赢。*反证*：改成 `渲染(…, 声线档案)` 纯函数签名后中途漂移不可能发生。*代价*：5 个 import 说_音色 的调用点要改签名（在新文件里做适配，既有件不动）。
