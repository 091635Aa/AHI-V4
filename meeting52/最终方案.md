## 0. 裁决摘要（先给结论）

1. **七项现状：0 项可宣称"达成"**。唯一有较强证据的是**确定性（纯计算部分）**；其余六项：3 项未证明（持久自模型/provenance/记忆连续性）、1 项 BLOCKED（潜在推理：未接线＋C1 红线）、1 项半闭环（工具调用）、1 项方法成立但争议轴待重跑（可消融证据）。
2. **第一公理 = F5「不可预演信息」**：目标信息若可由当前输入＋显式种子在确定世界重算／查表／确定性重放得到，该项一律按"未证明"处理。七项每项必须加"当前输入不含、只能由历史/自态提供"的信息臂与"清空跨拍状态"对照臂。
3. **结构选择（C1）**：**优先 (a) 逐元素动力学**（`门`/`归`/`叠`/`符`，不用 `读` 做跨维混合）；若必须 (b)（只在 M1 记忆钥匙上）——`读(k=1)` ≡ `softmax(β→∞)` ≡ Hopfield one-hot 极限，判**条件同构**，须过更新式判定＋P2 冻结索引臂＋M10 决策改变臂，否则 M1 出局。
4. **合并主干**：红队 P0–P4「可信化路线」为骨架 ＋ 蓝队「第一公理＋四链」为执行器 ＋ 绿队「五件候选」为机制候选 ＋ 黄队 G4 资源账为硬顶。
5. **资源紧线（G4 定案）**：CPU 峰值 **≤320MB**、均值 ≤128MB、GPU 峰值 **≤384MiB**；实测锚点 **180.2MB / 111.4MB**；`1GB/2GB` 是红线、**不是成就线**；"比 MOSS 省显存"**不可测、不得主张**。
6. **算力硬否**：全因子 2⁷@D=256 = **36.5h**（否）；9 种子（6h+/12h+）**算不起**；合并方案只带 **T3-min-6/10** 最小可判子集。

## 1. 方案摘要

### 1.1 第一公理：F5 不可预演信息（新增，候选）

> 任何"持久/记忆/闭环/自模型"主张，必须证明其目标信息**不能**由当前输入重算。

- **每项 +1 臂**：清空跨拍状态 / 只用当前输入＋种子重算 ⇒ 必须掉分 **≥0.10**，否则该项按"重算"处理（未证明）。
- **三条伪执行模板**（进 S3 注册表）：**伪执行**（不跑只报）、**伪重放**（不更新只记录）、**伪潜态**（不进输出）。三者都必须"伪 ≠ 真"，且逐位可区分。
- 来源：红队 M23、蓝队 C10/F5、绿队 §12、主控 C10。

### 1.2 结构选择：C1 合规动力学

| 选项 | 形态 | 判据 | 裁决 |
|---|---|---|---|
| **(a) 逐元素（首选）** | `门`/`归`/`叠`/`符`；禁 `读` 做跨维混合 | 更新式逐项判定为逐元素；不触发 F1/F2 | **主推**；代价：表达力上限须写进边界 |
| **(b)-限定（仅 M1）** | `读(k≥3)` 作硬 top-k 选择，且 `K` 固定、`Σg≠1`、逐候选独立门、残差进读出 | 更新式判定表 + P2 冻结索引臂（决策翻转 ≥0.20 近平局/≥0.15 全样本；<0.01 判装饰）+ M10（argmax 改变率 ≥0.15 或 TVD ≥0.10） | **条件保留**；缺一即出局 |
| (c) 移出链 | 思核不参与前向 | C1 源码级仍命中 ⇒ 只作过渡 | 仅过渡 |

- **禁止**：`读(k=1)`、`softmax`、top-k 后重归一化、logsumexp 能量函数、位置编码/序列主干、外挂预训练模型当器官。

## 3. 消融臂（联合矩阵）

1. **2×2 交互**：拆 A / 拆 B / 拆 A+B / 全 ⇒ `I_ij`；先做 **轴A（自我态）与 轴C（区室）**（争议轴），其余降为 1 seed 扫描。
2. **补回比** `R=(Y_补−Y_拆)/(Y_基−Y_拆)`；补回=参数逐位还原（非重训）；`R` 上界<0.90 才算"可被经历补偿"。
3. **阴性对照**：等容量 sham<0.03；真子集置乱 ≤0.05；无拆件续训 ≈1.00±0.02；**置乱/打乱行列/污染槽位/冻结自我态**四类 must-fail 必带。
4. **三种伪执行模板**（台账/重放/潜态）：伪 ≠ 真，逐位可区分。
5. **轴C 重跑协议**：统一协议 + **9 seeds 起步**（4 为绝对下限；轴C ≈15min、四轴 55–75min [推算]；黄队 4 seeds 79.5min/4.3h、8 seeds 2.65h/8.6h 为另一臂集口径）；**按基水平分层**；预注册；报 CI 而非点估计；轴B 需 ~87 seeds ⇒ 写不可判定。**四轴重判（H 后）**：A 结构性承重（R_DiD 0.052、TOST 0.121<0.90）、B 不可判定（−0.18）、C 条件性有害（拆C 平均 +0.143、CI 不含 0）、D 仅该模型内焊死（0.06）；原“A/B PASS、C 反向件、D 焊死”全部改写。
6. **最小可判子集 T3-min-6/10**：只跑"能改判"的 6–10 臂（轴A/轴C 交互 + 四项关键 must-fail），其余标"待算力"。

## 5. 诚实边界（必须随方案上报）

**证据分级（三分类，任何数字必须标）**：
- **[实测]**：本会话/盘上真跑（如 180.2MB、0.7775/0.785、0/988、`d66e08f4…`）。
- **[文献类比]**：只作设计动机，**不作证据/阈值**（C7；`cite:14`/`cite:15` 已判元数据错配）。
- **[未验证假设]**：如 F5 公理、320MB 紧线、M6 比较器有效性、绿队五件机制。

**宣称线**：
1. **不主张现象意识/人类级自我**；只说"功能子集可测"。
2. **Toy 规模**（D=256/64；任务为 2 阶布尔乘积等），**不得表述为通用能力**。
3. **不宣称"比 X 省显存"**（无同功能基线）；MOSS 为虚构对象，"比 MOSS 小"不可测。
4. **"15→3 秒"**只能写"构造性台阶"；**丙2**只能写"缓存+最近邻"；**V4 16/16**只能写"现口径 PASS（3 项恒真未修）"；**贯通 10/10**只能写"烟测"。
5. **"迭代次数=思考深度"** 禁用（F2）；`读(k=1)` 与 softmax 极限等价必须显式承认。
6. **空着=未测**：未跑项已单列（见各队 R2 §未测清单）；本轮**零可执行件**（无代码原型）。
