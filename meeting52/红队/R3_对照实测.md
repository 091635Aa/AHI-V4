## 1. M24 零执行伪台账（PASS）

- **输入**：不建世界、不执行技能，只把档位名义耗时喂调度。
- **操作**：`调 = 训练循环.造调度(15000.0, 种子=0)`；循环 `调.报一轮("合成_提交流程", [15000,10000,5000,3000,3000,3000])`；按真跑同口径算 `特征码([[最好,中位,档,反弹],...])`。对照：`训练循环.跑训练(种子=0, 轮数=6)`。
- **观测**：台帐特征码 / 档序列 / 最好毫秒。
- **阈值**：伪台账特征码 **必须 ≠** 真跑特征码。
- **实测**（[实测]，2026-10-17，并发期）：
  - 真跑：`d66e08f44e1f861b04bc058705751727f499db824288b1568c23621bad0804cf`，档序列 `[1,2,3,3,3,3]`，最好 3000.0ms；
  - 伪台账：**同一特征码**（前 16 位 `d66e08f44e1f861b`，与 red-loop R2 独立复跑一致），档序列同 `[1,2,3,3,3,3]`。
- **四态**：**PASS**（伪台账与真跑逐位同 ⇒ 原判据被否证）。
- **否证对象**：简报 §3「技能／操作」的 15→3 秒证据；主控 E1 措辞（本件补 **E1b：伪台账可复现 ⇒ 15→3 秒不得作学习/闭环证据**）。
- **备注**：2000 拍/轮训练在此不必要——伪台账 0 执行即可复现；这正是"该证据对主张零信息量"的定义。

## 2. M25 指纹含实际落点/参数（PASS）

- **输入**：同一技能、同一档 0；世界（a）静态 vs（b）执行前把全部元素偏移设为 `[11,0]`。
- **操作**：`技.执行(世, 拍钟())`；记录 `执行码`；另算"新指纹"= sha256(执行码 + 每步「计划点 vs 目标真实点」距离 + 终手位)；落点均距取所有 `移到` 核心步。
- **观测**：执行码是否相同；新指纹是否相同；落点均距；成功。
- **阈值**：执行码对 ≥1px 落点差**必须不同**（新指纹）；若执行码相同而新指纹不同 ⇒ 现指纹盲、新指纹有效。
- **实测**（[实测]）：
  - 执行码：静态 = 漂移 = `896f23e63f7a229f9b926915a513a25a1b68dc41f59791af1e7f8bc038da7359`（**相同**）；
  - 新指纹：`783a6bacef7d5758` vs `5e196275a325b289`（**不同**）；
  - 落点均距：静态 **0.0px** vs 漂移 **12.6786px**（漂移设为 11px；实测含不同元素/残差）；
  - 成功：两臂均 True（执行期 `复核` 原子会重读真点 ⇒ 观测进参数；**不进选择**，与 A5.9 同向）。
- **四态**：**PASS**（现执行码全盲；含落点的新指纹能看见）。
- **否证对象**："以执行码/特征码作闭环/观测因果证据"；确定性口径需补 **T5-L1'**（落点/参数入指纹）。
- **备注**：本臂只读运行 `AHI3/meeting41/实施` 的既有件，未改一行；漂移是**世界侧**偏移，不是改技能。

**结果解读（必须与实测同读）**：
- **M01 = FAIL（红队自纠）**：固定 EMA 臂**没有**通过 ε 判据（0.00015–0.00084 ≪0.005）⇒ 红队 A1.7「任意慢状态都能骗过 ε」的强表述**不成立**；该部分从"恒真"降级为「**未证明**」。仍成立的只有：① 大跳=答错（结构事实，已复算）；② **真 A 有效秩 3**（子代理独立复跑：与 3 维重建逐位同、最大差半定点格）⇒ "256 维高维自模型"叙事被证伪。
- **M04 = PASS（但削弱红队强表述）**：缓存/随机槽均 ≤0.05 ⇒ "缓存也能冒充冻结槽位"**不成立**；子代理补三条弱点：**ζ 门控是死的**（错配时 top-1 强仍≈1.0、通过率三臂全 1.0）、**40 拍延迟空转**（干扰只进回波不进槽，与无干扰对照逐位同）、半容量 40 模式召回 0.625（召回≈已存模式比例）。
- **M05 = PASS（条件）**：K=1024 两档 1.0；但 D=256 下 1024 个 ±1 模式的**噪声底 max|cos|=0.3125**，距 ζ=0.35 仅 0.0375（K=4096 余量 0.022）⇒ 1.0 是「ζ 高于码本伪重合底」的产物；真正断裂点约 **K≈4k–1e4**（[解析估计]，未跑）。要证容量必须把 ζ 设到噪声底之上并给 K 扫描曲线。
- **不过就写"未证明"**：M01 涉及的"持久自模型=装饰"不作为已证结论；A1.1/A1.3 的其余部分（1 维标量、K=1024 送分题、结构化任务）仍按原证据分级。
