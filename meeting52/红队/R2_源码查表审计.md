**整改**：C1 自扫范围=**全部链上 .py**（至少 `meeting38/实施/内核宿主.py`、`meeting39/实施/内核_*.py`、`meeting41/实施/算子_能力核.py`、`meeting49/50/51` 实施件）；每件必须写**一拍更新式**并填同构判定表；`_相对门` 不得保留全局 `exp` 归一。

### F7 自我态=1 维标量 + 手写 3 维特征基（**必须降级声明**）

1. **主张**：`自我态 A` 是单标量 `自我标量` 经手写基 `[x−0.5,(x−0.5)²,1]` 与固定随机投影得到；D=256 不含标量之外的信息 ⇒ "持久自模型"实为 1 维慢滤波；这是**预写表征骨架**而非学习到的自模型。
2. **证据**：`算子_两区室核.py:92-95`（手写基）、`:98-105`（固定投影）、`:154-156,174-175`（A=f(标量)）、`:184-186`（clamp）；`:232-245`（只更新 1 标量）；R1 A1.1 只读复算（A²⁵⁶→规则 0.7775 vs 3 维标量 0.7725）。
3. **反证**：若 3 维标量臂的 `A→规则` 解码显著低于 256 维臂（>0.05），则 256 维有独立贡献；当前复算**否证**之（差 0.5pp）。
   **必须失败对照**：固定 EMA 臂（A←0.8A+0.2，不学）在 ε 判据上必须 **≤0.005**；若它 ≥0.005 ⇒ ε 判据只测"状态会动"（R1 M01）。
4. **算力代价**：3 臂 × 400–800 拍（D=256）≈ **数分钟**（R1 §9 同量级）。

**整改**：把"持久自模型"降级为"1 维偏置跟踪器"直到出现学习出来的多维自状态；判据加入 3 维标量臂与固定 EMA 臂。

### F8 provenance = 布尔 `允许`（**必须改**）

1. **主张**：归属/外源防护是 Python 关键字参数的布尔开关，不是内容依赖的归属度；判据只检验这个布尔 ⇒ 对任何实现恒真。
2. **证据**：`算子_两区室核.py:259-266`；链上 `内核_自我回路.py:169-201`（`_来源标/_来源钉` 覆盖语义）＋ `贯通_多核心.py:86`（每拍设自源）；判据 `判据_V4_贯通.py:88-92`（`自源>0 且 外源==0`）——**外源分支从未被执行**。
3. **反证**：若"与自源同分布的外源"注入后 `被塑造=False` 且"打乱 provenance 标签"能改变 `W_self` 指纹 ⇒ 归属是内容依赖的。**必须失败**：把 `注入外源规则` 的 `允许` 改成 `hash(向量)%2` 伪归属后判据仍 PASS ⇒ 判据无信息（预期 PASS）。
4. **算力代价**：1 臂 × 20 拍 ≈ 秒级。

**整改**：归属度 = f(来源统计、写入强度、内容一致性)，判据须含"标签打乱正控 + 同分布外源负控"；链上必须**真的注入一次外源**（现 `外源次数==0` 是构造）。

### F9 千层四轴：手写拓扑 + 区室三式 + τ 查表（**必须降级声明**）

1. **主张**：四轴是**手写索引坐标 + 手写连通规则 + 手写区室规则表 + 手写 τ 表**；"轴C 区室"没有学出来的分化（三条公式按 index 选），因此戊2"拆轴C 反升 ⇒ 区室装饰"只对手写三式成立，不能外推为"区室化无价值"。

3. **反证**：若把区室规则换成"同一式 + 可学参数/可学门控"后，拆轴C 仍先降后不回升 ⇒ 区室承重成立，本条降级。**必须失败**：sham 拆件（随机同参数量权重置零）必须 <0.03（R1 M07）。
4. **算力代价**：4 轴 × 4 对照 × 4 seed ≈ **20–30 min**（R1 A3.1 同量级，[未验证假设]）。

**整改**：把"轴C/轴D"承重结论改写为"手写规则表/手写 τ 表无独立收益"；补 sham 拆件与"无拆件续训"对照；区室/时间常数若要承重，必须由学习/自组织产生或明确声明为结构先验。

### F10 列表截断/读出选择（**必须登记**）
