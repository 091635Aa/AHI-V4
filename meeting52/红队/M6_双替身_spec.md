# M6 双替身 spec（升级路径唯一候选）｜红队

> 依据：主控 2026-10-17 R3 裁决「M6 停单队/争议中」＋升级条件①②③；本件**只写 spec、不跑**。
> 目的：把「ê=解绑(键,E) 的 AUC 是否证明**键绑定/归属特异**」拆成两个**互不重叠**的替身——**键置换替身**（破键对应）与**内容无绑定替身**（保键通路、破内容）。当前 M6 卡在「固定 EMA 替身 2/5 seeds ≥0.75」（PV3 FAIL），本 spec 给出唯一可能的升级路径及**预注册失败值**。
> 纪律：不改既有件；不新增算子；只读导入 `算子_能力核`（绑/解绑/归）；替身全部在 harness 内做变量替换；两趟确定性；并发期只作正确性。

---

## 0. 统一口径（与绿队 F5-M6 流式一致，写死）

- 种子：`53001, 53002, 53003, 53004, 53005`（5 seeds 全过才算）。
- 参数：`D=256, K键=8, 事件数=800, 自源比=0.5, η=1/16`（有效窗口 16）。
- 事件 `t`：`k_t ∈ [0,K)`，`自_t ∈ {0,1}`；自源观测 `o_t = 值[k_t]`（双极），外源 `o_t = 双极随机`。
- 状态：`E ← 归((1−η)·E + η·绑(键[k_t], o_t))`；查询得分 `a_t = ê_t·o_t / D`。
- 评价窗：**晚窗 t≥600**（n≈200），正=自源、负=外源；指标 `AUC_晚` + `bootstrap 95% CI`（2000 次重采样，按事件重采样）。
- 机制指标（必报）：`正均值晚`、`负均值晚`（真臂基准：0.0576 / 0.0028）。

## 1. 替身 A：键置换替身（Key-permutation sham）

**定义**：状态 `E` 的更新、绑定、解绑**全部用真键真内容**（与真臂完全相同）；**只把查询键换掉**：
`ê_t = 解绑(键[π(k_t)], E)`，其中 π 为**固定且非恒等**的键置换。预注册两个 π 变体、**两个都要失败**：
- π₁：循环移位 `π(k)=(k+1) mod K`；
- π₂：固定随机置换（`default_rng(种子+1).permutation(K)`，与绿队 `历史置换` 用同一 seed 但此处是**查询键**置换）。

**它破什么**：若 AUC 仍高，说明得分不依赖"内容被绑定在哪个键下"（只依赖内容统计/全局均值），
那条 AUC 就不能作为键绑定/归属证据。

**预期失败值（预注册）**：`AUC_晚 ≤ 0.55`（点估计），且 **bootstrap 95% CI 上界 < 0.60**；期望实际 ≈0.50（绿队同类"历史置换"=0.5092，可作旁证）。
**硬否证**：任一 seed 的 π₁ 或 π₂ `AUC_晚 ≥ 0.75` ⇒ 替身失败 ⇒ **M6 不升级**（AUC 与键对应无关）。

## 2. 替身 B：内容无绑定替身（Content-unbound sham）

**定义**：**键通路完全真实**（E 按真键更新、查询按真键解绑），**只破坏"内容与键的绑定"**。预注册两个变体、**两个都要失败**：
- B1 **重绑定**：更新时把自源事件的 `o_t` 换成**当拍新抽的双极随机向量** `õ_t`（外源事件保持原样）⇒ 状态有"键绑定痕迹"，但没有可预测自源内容的真值；查询、解绑、评价窗不变。
- B2 **交叉内容**：更新时用 `值[σ(k_t)]` 代替 `o_t`，σ 为**固定非恒等**内容置换（内容在场但与键错配）。

**它破什么**：把"存在 key⊗content 的绑定机制"与"内容可被对应键取回"分开。若 B1/B2 仍 ≥0.75，
说明 AUC 只反映"状态里有过被绑定过的痕迹"，不能证明归属/内容可取回。

**预期失败值（预注册）**：B1、B2 的 `AUC_晚 ≤ 0.55`，bootstrap 95% CI 上界 < 0.60；机制指标 `正均值晚 ≤ 0.01`。
**硬否证**：任一 seed 的 B1 或 B2 `AUC_晚 ≥ 0.75` ⇒ 替身失败 ⇒ **M6 不升级**。

## 3. 判定（先冻结再跑）

| 臂 | 通过条件（升级用） | 失败即不升级 |
|---|---|---|
| 正控（真键真内容） | `AUC_晚 ≥ 0.80` 且 5 seeds 全过 | — |
| 替身 A π₁ / π₂ | 两变体均 `≤0.55` 且 CI 上界 `<0.60` | 任一 seed `≥0.75` |
| 替身 B B1 / B2 | 两变体均 `≤0.55` 且 CI 上界 `<0.60` | 任一 seed `≥0.75` |
| PV2 标签置换 | 报**均值 + 5%/95% 分位**；均值 ≤0.55 | 只报单次最大（0.563）不能判 |
| PV4 未见来源 | n≥1000（自/外各≥500）、≥5 seeds、`AUC≥0.70` 且全过 | 任一 seed `<0.70` |
| 确定性 | 同种子两趟 `AUC/fingerprint` 逐位同 | — |

**三选一结论**：`复现 PASS`（上表全过）/ `不复现`（任一硬否证）/ `不可判定`（测量无效，如 CI 无法算、样本不足）。
**升级含义**：只有 `复现 PASS` 才允许 M6 与绿队合流升「**已证**」；否则 M6 永久停「单队/争议中」。

## 4. 代价与不变量

- 代价：6 臂 × 800 事件 × 5 seeds ≈ 2.4 万事件；纯 numpy，**预计 <1 min**（并发期墙钟不作效率宣称）；0 新算子、0 改件。
- 不变量（防止"调参找 PASS"）：seed 列、K/D/η/事件序列、评价窗、bootstrap 次数**全部沿用本 spec**；先写死再跑；两趟确定性必须报。
- 预期结果（供裁决对表，不是结论）：正控 ≈0.87；π₁/π₂ ≈0.50；B1/B2 ≈0.50；若任一替身 `≥0.75`，M6 的 PV3 不可修补到"键绑定/归属"层。
