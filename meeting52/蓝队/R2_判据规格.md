## 1. 统一口径（所有臂共用；单臂表只引用代号，细节在此）

### 1.1 统一 must-fail 执行器（唯一的判据执行入口）

- **唯一入口**：第二轮新建一个判据脚本（`判_七项_规格.py`，**新文件**，只读 import 既有件；不改任何既有件，C14）。本件只给口径，不给代码。
- **声明式臂配置**：每臂＝`dict(编号, 项, 输入流, 干预op, 读数fn, 阈值键, mustfail列表, 零分布, 两趟, 代价标签)`。禁止把"臂序号→结论"写成 if/elif 分支表（判据本身不得是焊死件）；op 名→纯函数的分发字典须显式声明为**判据侧**、不进系统边界。
- **唯一阈值来源**：`阈值表.json` 在跑前冻结，结果 JSON 记录其 **sha256**；任何臂不得用自己的读数反推阈值（唯一例外：预先声明的选参扫描，只在**选参种子族**上扫，§1.7）。
- **每臂必须同时跑三件**：主臂 ＋ must-fail 臂 ＋ 零分布臂。缺一 ⇒ 判定 `INVALID`（不产出 pass/fail）。**例外**：精确相等型臂（逐位同/bit 不等）以"恒等对照＋注入正控"代替零分布，表中标"无（精确）"，此时恒等对照必须给 0 差异、注入正控必须给非 0 差异。
- **四态判定**：`PASS`＝主臂过阈 ∧ must-fail 未过阈 ∧ 零分布分离 ∧ 两趟逐位同 ∧（适用时）C1 门过；`FAIL`＝主臂不过阈 或 must-fail 过阈；`UNDECIDABLE`＝命中 U 码（§1.6），并附"要判定需什么实验"；`INVALID`＝检测器失效（两趟不同／阳性对照未命中／null 未分／must-fail 落通过区）。
- **可失败性证明（准入条件）**：每臂须写出一个**合法实现变体**会使主臂读数落入失败区；每 must-fail 须写出一个**合法实现变体**会使该 must-fail 读数落入通过区。写不出 ⇒ 该臂/该控制是恒真断言，拒收（P1）。
- **判定记录 schema（结果 JSON 必含）**：`臂, 项, 种子族, 输入流指纹, 干预指纹(sha256), 主读数, CI, null分位[5/50/95], mustfail读数, 两趟指纹[4], 判定, 不可判定码, 代价, 阈值表sha256`。

### 1.2 统计与置信区间口径

| 量型 | 口径 | 通过/证伪规则 |
|---|---|---|
| 比例（Acc／召回率／成功率） | **Wilson 95% CI**（n 见各臂） | 主判定用**点估计**过阈；同时报 CI 与证据等级：**A**＝Wilson 下界≥阈；**B**＝点估计≥阈但下界<阈；**C**＝点估计<阈。只有 A/B 可写"达成"，B 须附扩样计划；C 写"未达成"。must-fail 的"≤"判据要求 **Wilson 上界≤阈**。 |
| 连续量（TV／ΔAcc／I_ij／漂移比） | **配对 bootstrap** 1000 次（种子 47106），报 2.5/97.5 分位；跨种子用 **sign test／Wilcoxon**（≥9 种子，逐种子方向须一致） | 效应须 **>2×SE_pooled** 才可作承重证据；CI 跨 0 则不可判定（U1）。 |
| 分辨率 | A 类 n=113 ⇒ SE≈0.029（Acc_A≈0.89），**δ_min=0.05**（点估计不可分辨线），**2×SE_pooled≈0.095**（沿用 R1 §3.2 [实测计算]，本件列为**待复核**） | `abs(效应)<0.05` 一律写"**未观测到/样本不足**"，不得写"证明无效应"；要写"无效应"须做 **TOST** 等价检验（等价界 ±0.10 [提案]）。 |
| 样本量算式 | 单比例 `n≈p(1−p)(z/δ)²`；两臂 `n≈2p(1−p)(z_{1−α/2}+z_{1−β})²/δ²`；配对用 McNemar（依不一致对比例） | 例：p=0.5、δ=0.10、α=0.05、power=0.8 ⇒ 两臂各 ≈525；配对若不一致对 20% ⇒ n≈120 对 [提案]。 |
| 多重比较 | 每项内 Holm；选参扫描次数计入 Bonferroni | 不校正 ⇒ 该臂只能写"探索性"（U9）。 |

## 2. 三处"不可失败臂"重做（专项；本件核心交付）

> 判定标准：**P1** 存在合法实现变体使该臂读数落到阈值之外；**P2** 判据工具能被故意注入的违规触发；**P3** 能区分"机制存在"与"机制必要"（R1 §0.1）。

### 2.1 NF-1 · provenance「`if 允许` 恒真」

**原臂**：`判据_V4_两区室核.py:258-266` 调 `注入外源规则(向量, 允许)`；读数为 `拒["被塑造"] is False and 允["被塑造"] is True`。实现 `算子_两区室核.py:259-266`：`若塑=bool(允许); if 若塑: 自我态=归(向量)`。

**为什么不可失败（P1 违例，证明）**：对**任何**合法实现，"允许=False"分支都不执行 ⇒ `被塑造` 按构造成 False；"允许=True"必然执行 ⇒ True。读数与机制无关，只复核了调用方布尔到赋值的接线。不存在使读数翻转的合法实现变体（除了删掉门），因此它不是判据，是**恒真断言**。且"来源"是调用方外部真值，不内生（宪法第一条推论：必须测"是不是它自己的"）。

### 2.2 NF-2 · ε_self「用真值当标签」

**原臂**：`判据_V4_两区室核.py:268-282` 在 3 个种子序列上比较 `大跳ε均值 − 小跳ε均值 ≥0.005`；分组由 `桥_自我态_自模型.py:66/94-95` 的 `|Δ自我标量|≥0.05` 定义，而自我标量由**生成器边界切换**（`算子_两区室核.py:108-126` 的切换点）经奖赏驱动 ⇒ 分组实质是**外部真值/外部事件**给出的标签。

**为什么不可失败（P1/P3 违例，证明）**：
1. **同义反复**：ε 是下一拍自我态的预测误差；"大跳"＝自我态变化大 ⇒ 误差天然大。任何有有限记忆的 ĝ 都会通过，只要 A 会动 ⇒ 它测的是"误差随变化幅度增"，不是"自我模型成立"。
2. **真值标签**：分组用生成器事件，不是系统自己可观测的量 ⇒ 即使通过也不证明"它对自己的意外程度"。
3. **无假阳性臂**：从未测"无切换平稳序列"上老臂是否仍通过（若仍通过，则老臂是噪声）。
4. **余量小**：实测差 0.0291，阈值 0.005（R1 §1.2 [实测]），但无 CI/置换，无法判断 0.0291 是否超出零分布。

## 6. 执行顺序与最小可判子集

1. **Phase 0（静态/预注册，分钟级）**：PR0 C1 门禁（`blue-c1`）、阈值表 sha256、种子三段切分、闭包扫描（T5）。
2. **Phase 1（最快否证，≈1 min）**：**PS1**（替换 A 输出必变——杀"装饰性 A"）、**PV2**（闭合/无门成对——杀"恒真归属"）、**MC4＋MF-MC-06**（冻结不广播＋槽广播正控——检测器灵敏度）、**DT1＋MF-DT-01/02/03**（C13 检测器灵敏度）。这四件任一失败即触发对应整项降级。
3. **Phase 2（主臂＋must-fail，≈10 min）**：PS2/PS3/PS4、PV1/PV3/PV4、MC1/MC2/MC2c、TL1/TL2/TL3/TL4、AB4、DT5。
4. **Phase 3（重臂，≈15–20 min）**：MC3/MC5、TL5/TL6、AB1/AB2/AB3/AB5、PR1–PR4（须 PR0 先过）。
5. **最小可判子集（≤6 min，算不起时的诚实下限）**：`PS1、PS2、PV1、PV2、MC1、MC2、PR0、TL1、TL2、DT1、AB4` —— 覆盖"替换 A／内生归属／补全/缓存之辨／C1 门禁／闭环 vs 查表／C13 检测器灵敏度／must-fail 零分布"七个最硬点。
6. **禁止**：只跑主臂不跑 must-fail；只报点估计不报 CI；在评估集上调阈值；用"未测"填"通过"。
