**L4 · 式级数值判定器（本件核心增补；把 R2_判据规格 §3.4-PR0 变成可执行）**

对任一"检索/加权/竞争"机制，取其**权重函数** `w(s)`（`s` = 键分数/相似度/历史强度向量）做三个签名：

| 签名 | 测法 | softmax 特征 | 说明 |
|---|---|---|---|
| **S1 尺度不变且 Σ=1** | 把输入 `s` 整体缩放 0.5，测 `|Σw(0.5s) − Σw(s)|` | ≈0（且 `Σw≡1`） | 有跨集归一化才会尺度不变 |
| **S2 交叉灵敏度** | 对每个键 `k` 加 `ε`，算 `J[:,k]=(w(s+εe_k)−w(s))/ε`；报 `offdiag/diag` | **>0.05**（连续、稠密） | softmax 的 `∂w_j/∂s_k ≠ 0 (j≠k)`；逐维门控/硬竞争为 0 |
| **S3 值域** | `min w`、`max w` | `min>0`（稠密） | 稀疏 top-k/硬竞争 `min=0` |

**判定规则**：`S1 通过 ∧ S2>0.05 ⇒ 是（softmax 同构，含 top-k 重归一化变体）`；
`S1 通过 ∧ S2≈0 ⇒ 条件`（硬 top-1 是 β→∞ 极限同族，须硬约束"禁温度化/禁加权和"）；
`S1 不通过（Σw 随尺度变） ⇒ 否`（逐维门控/可分能量下降）。
**阳性对照 / 阴性对照**：dummy softmax 必须判"是"；同一探针跑"硬 top-1/逐维门控"必须判"否/条件"（灵敏度双向，见 §1.5）。

## 2. 更新式级：七项各一拍更新式 + 同构判定表（②）

### 2.1 判定标准（三要件 + 数值签名）

设机制一拍更新 `x_{t+1}=F(x_t, 输入_t)`。**三要件**（任一不满足即"否"）：
(a) **键集**：存在被索引的键/记忆向量族 `𝒦={k_j}_{j=1..J}`；
(b) **跨集归一化**：`w_j = exp(s(q,k_j)) / Σ_l exp(s(q,k_l))`（或保留全局归一化的 top-k/温度/bias 变体）；
(c) **线性读出**：`输出 = Σ_j w_j v_j`，`v_j` 与 `k_j` 同索引集。
判定语义：三要件全满足 ⇒ **是**；在参数化极限下可退化到 (a)(b)(c)（如 `β→∞` 的 top-1） ⇒ **条件**；否则 **否**。
**数值复核（L4）**：`S1∧S2>0.05 ⇒ 是`；`S1∧S2≈0 ⇒ 条件`；`¬S1 ⇒ 否`。

## 3. 整改候选：各自的 C1 判定与代价（四选）

> 共同前提：任何整改**先备份**、需主控授权（C14）；**只改 `内核_相空间算子T.py:90-149` 的门/动力学**，不改键集与调用方；

### 3.1 候选 (i) 硬竞争（top-1，去 exp）

```
门_j = 1[ j = argmax_l ( 余弦_l − κ门'·h_l ) ]      # 或保留 β 的硬阈值；无跨集 exp
w    = γ共·共模 + g_{j*}·余弦_{j*}·ṽ_{j*}          # 单键读出
z_{t+1} = 单位( (1−惯性)·单位(w) + 惯性·z_{t−1} )
```
- **C1 判定：否（条件）**。三要件 (a)✓ (b)✗（无跨集归一化；one-hot 的 Σ=1 是平凡恒等，不是归一化运算）(c)✓ 但权重非归一化产物。数值签名：S1 通过（Σ=1）但 **S2=0.000** ⇒ 按 §2.1 判"条件"。
- **"条件"的硬约束**：禁止任何温度化/加权和/top-k 重归一化；否则立刻变"是"（§2.4 top-2 变体即是）。
- **代价**：每拍省去 **J=4 次 `exp`**（[实测] J=4）；乘加数 ≈ 同量级（cos J·D 不变）；墙钟**未测**（预计不升）。
- **风险**：不连续选择可能让轨迹退化/锁死。离线数值示例（`[提案·数值示例]`，同一 `竞争表/共模/惯性/自排斥`，30 步）：换站 **6 次**（softmax 基线 7 次）——**未见锁死**，但这不是实测证据，须按 §4 复核。
- **验证要点**：S1/S2 + 轨迹换站率 + §4 三档因果。

### 3.2 候选 (ii) 逐维门控（推荐首选，但 θ 必须内生/预注册）

```
a_j  = 软限( 余弦_j − θ_j, 1.0 )_+ ∈ [0,1)          # 逐键独立门；**不对 j 归一化**
w    = γ共·共模 + Σ_j g_j·a_j·余弦_j·ṽ_j             # 逐元素加权求和（无跨集分母）
```
- **C1 判定：否（条件：θ 不得人挑）**。三要件 (b)✗；数值签名 **S1 不通过**（Σw 随输入尺度变）⇒ 否。
- **θ 口径（关键，防"新焊死件"）**：宪法第三条禁止人挑阈值。三条可选：①`θ_j` = 该键自身历史分位（per-key 自归一，**不引入跨键耦合**）；
  ②预注册常数（须在阈值表冻结并披露"人挑"成本）；③`θ=mean(全场)` —— **不推荐**：S2 实测 0.333，会把"共享阈值"伪造成交叉耦合，判定器会把它当"准 softmax"。
- **代价**：把 J 次 `exp` 换成 J 次算术 `软限`（4 乘加/键），乘加数同量级；无新增状态（per-key 分位需 +J 标量）。
- **风险**：门过稀（`a_j` 全 0）⇒ 轨迹退化；须报"非零门键数/拍"。
- **验证要点**：S1 必须**不通过**（尺度改变 Σw 明显）；S2≈0；非零门数≥2 的拍占比 ≥0.9（[提案]）。

### 3.3 候选 (iii) 移出链（`思核开关=False` / 摘 import）

- **C1 判定：否（执行级）——但不足以保住"潜在推理"子集**。
- **两种做法与代价**：
  - (iii-a) 仅运行时开关关：`内核宿主.py:53` 已可设 `思核开关=False`（配置级，零改文件）。但 **import 闭包仍含 T**，静态式级命中仍在 ⇒ 按 §1 的"代码式命中"口径**仍判链上违规候选**，只能按"执行覆盖=0"降级豁免（弱保证）。
  - (iii-b) 摘 import/文件移出：须改 `内核_真学习.py:33`、`内核_顿悟涌现.py:56`、`内核宿主.py:48`（既有件，C14 备份 + 主控授权）。代价 = **1 次改动申请**；收益 = 闭包与执行都干净。
- **代价（运行时）**：0（少一路执行）；**代价（子集）**：潜在推理**直接为空**，七项变六项。
- **若用，必须同时**给出替代容器：`迭代` 算子 `s ← 归((1−λ)s + λ·软限(W迭⊙s+d))`（`算子_能力核.py:249-266`，收缩映射，判"否"）。但**丙1 已实测"迭代=单次投影"**（`证据_千层.md:67`；共同简报 §2 历史教训 3）⇒ 替代容器必须先证明"迭代改变决策"，否则只是把装饰换个名字。
- **结论**：只作过渡/门禁（PR0 判"是"时先把执行降到 0，让潜在推理项 BLOCKED），**不作为最终方案**。

### 3.4 候选 (iv) 改能量下降迭代（可分势；**严禁 log-sum-exp**）

```
E(z) = ½‖z‖² + Σ_j V(余弦_j),  V 凸、光滑、可分（例：V(c)=−c 或 V(c)=½c²）
∇E  = z + Σ_j V'(余弦_j)·( ṽ_j − 余弦_j·z )        # 单位球面上的梯度（∂cos/∂z = ṽ − cos·z）
z_{t+1} = 单位( z_t − λ·∇E(z_t) + 惯性·(z_t − z_{t−1} ) )
```
- **C1 判定：否（条件）**；**条件 = 能量不含 `log-sum-exp` 项**。
  理由：`∇_s logsumexp(s) = softmax(s)`——若写 `E = −logsumexp(β cos + bias)`，则一步下降**精确复现 softmax 门**，判"是"。这正是"能量下降"最容易踩的陷阱，必须在方案里明写"势函数为逐键可分、无 logsumexp / 无 -log Σ exp"。
- **数值签名**：可分 `V(c)=½c²` ⇒ 权重 `cos`（可负）；`V(c)=(c+1)/2` ⇒ 权重 ≥0；两者 **S1 不通过**、**S2=0** ⇒ 否。
- **代价**：每拍多 **J·D 乘加**（J=4,D=1024 ⇒ 4096），相对现有 T 每步（cos J·D + 共振 J·D = 8192）**+50% 同量级**；无 `exp`；墙钟**未测**。
- **风险/验证成本最高**：需证收敛/极限环（不塌缩）、单位球投影的确定性（C13）、以及"迭代≠单次投影"（丙1 反例）。作为"唯一能同时解决装饰性"的方向，建议列为**第二优先**。
- **离线数值示例 [提案]**：同一 30 步口径下 6 次换站、无锁死；仅为风险指示，非证据。
