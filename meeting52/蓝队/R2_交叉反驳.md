### 2.2 反驳 / 限缩（4 条）

**R-1 · C10② 的"K=1024、±1 损坏 0.8 仍 1.0"无法复现（结论可保留，数值不可引用）**
本队按同一层协议（`记忆容器(256, K)` + 千层`符` + 解冻 argmax，n=30）复算 [实测]：

| 损坏率 (flip) | K=64 召回 | K=1024 召回 | 迭代 1 vs 3 |
|---|---|---|---|
| 0.00 / 0.10 / 0.20 / 0.25 / 0.30 | 1.000 | 1.000 | **逐位同** |
| 0.40 | 0.700 | 0.533 | 逐位同 |
| 0.50 | 0.033 | 0.000 | 逐位同 |
| **0.80** | **0.000** | **0.000** | 逐位同 |

⇒ 红队的 "0.8 → 1.0" 极可能是**"保留率 0.8"（= 损坏 0.2）**的误标（该点确实 1.0）。
**可引用的正确结论**：①召回在 **ρ*≈0.3–0.4** 处相变；②**迭代 1 vs 3 在全档逐位同** ⇒ 无补全动力学；③`K=1024=4D` 仍 1.0 是**近正交码本的线性代数必然**（串扰 ~1/√D）。结论"记忆=高维查表"**仍成立**，但证据需换成本表。

**R-2 · "确定性只作门槛、不计入达成项"——反对**
C13 是铁律（宪法第七条），不是可选项。**不达成 ⇒ 该项整体 FAIL**，不能"不计入七项达成"。本队坚持：确定性可与行为项**分开报**，但**不可从达成条件里移除**。

**R-3 · "3D 替身 Acc≥0.80 ⇒ 判 256 维无信息"——阈值口径错**
0.80 是绝对线；真正该判的是 **256D 与 3D 的差值是否显著**。本队实测 0.7775 vs 0.785（差 −0.0075，远小于 1 SE≈0.029）⇒ **差值不显著** ⇒ 判"无信息"；用 0.80 绝对线会把"两臂都没过 0.80"误判成"256 维有信息"。

**R-4 · "漂移世界切断观测掉≥0.20"——接受要求，但红队未给生成器 spec**
本队补 spec（可直接执行）：目标位置每 5 拍无条件漂移 ±(3–10)px；起点均匀随机于可点区；观测含 σ=1px 高斯噪声；成功判定由**系统自己下一拍观测**给出（不由脚本）。缺 spec 时该臂不可复跑，故红队该条**目前是设计不是证据**。

### 3.2 反驳 / 限缩

**G-1 · "8 算子仅 `读` 带跨维混合 ⇒ 非逐元素动力学必借 `读`=硬注意力 ⇒ '迭代=深度'被堵死"——接受形式化，限缩结论**

**G-2 · 命名降级不能把"持久自模型"降成只剩"选择性损伤"**
降级措辞本队接受，但要求**同时保留 F5 臂**："该慢态由历史提供当前输入不含的信息"。若降级后只剩"扰动→掉分"，那与"1 维锁存器"不可区分，等于删除该项。**降级 + F5 臂** 才是诚实的中间态。

**G-3 · "思核仅留痕 ⇒ 只需登记、不需整改"——反对**
C1 是**源码级红线**（禁注意力主干），不是"执行率"判据。代码在 import 闭包内、且**一执行即违规**（`想一拍`/思考态触发 +1 次/拍）⇒ 必须 (ii) 逐维门控 / (iv) 可分能量 整改，或 (iii) 移出链。**"登记了事"不成立**——否则任何违规代码都可用"默认不跑"豁免，C1 会被架空。

**G-4 · 我队与绿队 D8 的误读澄清**：绿队摘要把本队口径读成"用记录-重放绕过=作弊"。**本队立场**：记录-重放**允许**（且是外部工具唯一可行的 C13 路径），但**必须**把"实时臂"单列、不计入 C13 通过。不是"作弊"，是**分账**。

**G-5 · 观测面**：绿队要"决策统计量三件套（argmax/TVD/margin），只报准确率=丙1 重演"——**部分接受**：本队 Acc 是**任务成功**主判据，机制判据（TVD/argmax 改变率/margin）是**因果介导**判据；两者都报，**不互相替代**。故不是"以 Acc 为主判决"就够，本队 §6.1 已把两类都写进每行。
