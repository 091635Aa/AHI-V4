## 0. 本队立场一句话 + 三个可失败性公理

**一句话立场**：本轮真正稀缺的不是"新机制"，而是**能让主张被判死的实验**。七项子集里，当前只有 3 项（记忆冻结、确定性、联合消融的少数轴）具备"必须失败"结构；**其余四项（持久自模型、provenance、潜在推理、工具闭环）的现有臂在设计上不可失败或未接因果链**，必须按下面的公理重做口径，否则任何"成立"都只是修辞。

### 0.1 三条可失败性公理（本队所有判据的准入条件）

| 公理 | 内容 | 反例（当前盘上就有） |
|---|---|---|
| **P1 可失败性** | 存在至少一个**合法实现变体**使该臂读数落到阈值之外；否则该臂不是判据 | `判据_V4_两区室核.py:258-266` 归属臂：`允许=False` 时 `if 允许:` 不执行 ⇒ `被塑造=False` **恒真**，无法失败 |
| **P2 阳性对照** | 判据工具本身必须能被一次**故意注入的违规**触发（扫描器/指纹/阈值三者都要） | C1 禁词自扫只扫 3 个文件（`:287`），链上真 softmax 未被覆盖（见 §7.4）⇒ 扫描器"命中 0"与"扫描器坏了"不可区分 |
| **P3 分离性** | 判据必须能区分"机制存在"与"机制必要"：**拆掉**与**换成更弱替身**要给出不同读数 | 丙2 的 40 拍召回 1.00 与"缓存＋最近邻"不可区分（丙1 已证迭代=单次投影，`证据_千层.md:67`） |

### 0.2 四件套模板（本件每节强制）

> **主张**（一句可证伪）→ **证据**（文件+行号 / JSON 键+数值 / 实验 spec）→ **反证**（什么结果推翻它 + 必须失败对照 + 上限）→ **代价**（显存/内存/每拍乘加/墙钟；未测则写测量方案）。

### 0.3 防御矩阵的行格式（全文统一）

`攻击` → `反证臂（可执行）` → `阈值（先冻结）` → `必须失败的对照（含预期失败值与上限）` → `代价`。

### 1.4 逐项四件套（口径冻结用；每项给输入/操作/观测/阈值/must-fail）

**（1）持久自模型 · 达成 = 干预敏感 + 迁移**
- 【主张】自我态 A 是主循环的**因果中介**，不是读出侧装饰：扰动 A 必须选择性损伤规则依赖（A 类）试次。
- 【证据】现有 Δ消融 0.4690、自指退化 0.469 / 世界退化 0.014 [实测]（`meeting49/证据 §二`）；这证明"拆掉会掉"，**未证明"轻微扰动会变"**。
- 【反证】若 `A←归(A+0.1·幅·u)` 后 A 类掉 <0.05、或替换 A 后输出逐位不同率 <0.5 ⇒ A 不是中介，是恒等旁路。
- 【代价】3 臂 ≈ 0.4 s；0 新算子；**未测**：全链（六内核贯通 D=1024）下单臂墙钟。

**（2）provenance 归属 · 达成 = 内生归属度可分离**
- 【主张】"外源不可塑造我"当前**不是判据**（`允许=False` 分支恒真，`:259-266`）；必须改成系统**自己**从预测误差推断来源，且该推断在打乱标签后失效。
- 【证据】[实测/静态] `注入外源规则` 的 拒/允 由调用方布尔决定；[实测] 归属臂读数"拒绝✅/正控✅"是**构造**出来的。
- 【反证】若内生 `g` 在外源流上 `ḡ≥0.8`，或打乱标签后 AUC 仍 ≥0.75 ⇒ 归属度是标签泄漏／装饰。
- 【代价】+1 标量判定/拍；4 臂 ≈ 4 s；**未测**：阈值的方差（需 3 种子）。

**（3）记忆连续性 · 达成 = 延迟召回 + 相变 + 干预**
- 【主张】本实现当前只能主张"**缓存＋最近邻**"；"吸引子补全"**不可主张**（丙1 迭代与单次投影逐点同值 [实测]，`证据_千层.md:67`）。
- 【证据】丙2 1.00 vs 0.00 [实测]；丙5 冻结期改槽读出逐位不变 [实测]；丙1/丙3 FAIL [实测]。
- 【反证】若 K=4 与 K=1 的召回曲线**至少 1 点差 <0.10**，或损坏率曲线无相变 ⇒ 判"无补全动力学"，不得加阈值糊过去（见 §11 U2）。
- 【代价】32 次召回，估 <2 s（**未测**）。

**（4）潜在推理 · 达成 = 因果敏感 + 难度调度**（**前置**：先过 C1 预检 §7，否则整项不参与裁决）
- 【主张】潜在循环若触 C1（§7.2 M4 = **是**），则必须先改动力学；改后必须给出"z 在因果链上"的三档证据。
- 【证据】因果反证见研究报告 §4.2（[文献类比]：仅看准确率无法区分"真想"与"装饰"）；本地无臂。
- 【反证】见 T1-4 矩阵行。
- 【代价】**未测**：思核每拍代价；需黄队补。

**（5）工具调用闭环 · 达成 = 观测进决策 + 失败恢复 + 可重放**
- 【主张】闭环的最小可判形式是"**切断观测 ⇒ 行为退化到脚本基线**"＋"**扰动观测 ⇒ 动作跟着改**"；两者缺一即为开环。
- 【证据】`技能原子.py:191`（"看一眼"取真实点）、`:205/530`（核对整屏）、`:418/431`（打空触发复核）—— 结构上**存在**回流路径 [实测/静态]；但判据从未做因果检验。
- 【反证】见 T1-5 矩阵行。
- 【代价】**未测**：沙箱拍预算；工具子进程的资源须单列（T2）。

**（6）确定性 · 达成 = 跨进程逐位同 + 阳性对照** → 见 §8 全节。

## 2. T2 · 资源账战："更小显存"的可测定义与预算分项

### 2.1 主张

**在 toy 规模与纯 numpy CPU 引擎下，"全链路常驻 ≤1GB / 显存 ≤2GB"是几乎没有判别力的判据；本轮必须把它改成"每拍墙钟 + 每个功能子集的峰值增量 + 是否引入 GPU 外挂件"，否则任何方案都能"通过"资源账。**

### 2.2 证据（本轮只读探针实测；非设计值）

**测量协议（可复跑，两趟口径见 §8）**：进程内 `GetProcessMemoryInfo`（`kernel32.K32GetProcessMemoryInfo`）取 `WorkingSetSize` 与 **`PeakWorkingSetSize`**；显存用 `nvidia-smi --query-gpu=memory.used --format=csv -lms 50` 取 max；**均值不得用于 pass**，只作参考列；外部子进程（浏览器/工具）单独成行。

| 阶段 | RSS MB [实测] | 峰值 MB [实测] |
|---|---|---|
| 空解释器（python 3.10.11） | 12.81 | 12.81 |
| import numpy 2.2.6 | 24.42 | 24.42 |
| import `算子_两区室核`（含能力核） | 25.25 | 25.25 |
| `两区室核(D=256)` 实例 + 一次 `前向_双区室` | 28.57 | 28.57 |

## 3. T3 · 联合消融矩阵战：七项耦合下如何真归因

### 3.1 主张

**单点删除在七项耦合下不可归因；必须报二阶交互项 `I_ij`，并用"先降后回升比 + 双分离 + 置乱阴性对照"三件套锁死归因。可判的只有 4 组高风险对；其余 3 对必须诚实登记为"不可分离"。**

### 3.2 判据定义（先冻结）

设 `M0`＝完整模型指标，`M_i`＝只拆第 i 项，`M_ij`＝同时拆 i、j，`M_i^续`＝拆后**续训 N 拍**（N ≥ 训练长一半，即 ≥200）的指标，`M_i^置`＝把第 i 项参数在同形状内**随机置换**的指标。指标统一取 **A 类准确率**（n=113）与"规则依赖准确率"，两者都报。

| 量 | 定义 | 判据 |
|---|---|---|
| 拆损 `Δ_i` | `M0 − M_i` | — |
| **回升比 `R_i`** | `(M_i^续 − M_i) / (M0 − M_i)`（`Δ_i>0` 时） | `R_i ≥ 0.80`＝可补偿（真承重）；`0.50 < R_i < 0.80`＝半焊死；**`R_i ≤ 0.50`＝焊死（应回退）**；**`Δ_i < 0`（拆后反升）＝装饰/反向件，删除** |
| **双分离 `D_i`** | `Δ_i(自身指标) − max_{j≠i} Δ_i(他项指标)` | **≥0.10** 且自身指标过阈值 ⇒ 分离成立 |
| **二阶交互 `I_ij`** | `M0 − M_i − M_j + M_ij` | `\|I_ij\| > 0.10` ⇒ **不可加**，单点归因无效，必须报交互项（阈值按 2×SE_pooled≈0.095 定） |
| **置乱阴性 `S_i`** | `\|M_i^置 − M0\|` | 须 **≤0.05**；否则"拆件实现"引入了新机制，不是真子集 |

> 2×SE 依据：A 类 n=113，`SE≈0.029`，两臂 pooled `2×SE≈0.095` [实测计算]。**任何 |效应| <0.05 的量在本样本量下不可分辨**，不得作为承重证据（这条直接适用于千层 甲2 −0.004、乙5 −0.032、丙3 +0.027 —— 见 §11 U4）。

### 3.3 矩阵骨架（覆盖 7 项两两中的高风险对）

行＝拆件；列＝行为指标（A 类准确率 / 规则依赖准确率 / 迁移准确率）与机制指标（A 解码规则率 / 冻结槽召回 / z 因果 TV / 观测→动作不同率）。

| 拆件 \ 指标 | A 类 Acc | 规则依赖 Acc | 迁移 Acc | A 解码规则 | 槽召回 | z→输出 TV | 观测→动作 | 预期方向 / 阈值 |
|---|---|---|---|---|---|---|---|---|
| ¬持久自模型 | ↓ ≥0.10 | ↓ ≥0.10 | ↓ ≥0.05 | ↓ ≥0.15 | 0 | 0 | 0 | Δ消融 0.469 已证↓；迁移需新测 |
| ¬provenance | 0 | 0 | 0 | 0 | 0 | **外源注入接受率 ↑ 到 ≥0.8** | 0 | 现有读数恒真 ⇒ 换内生 `g` 后重判 |
| ¬记忆（槽置零） | 0 | 0 | ↓ ≥0.05 | 0 | **1.00→0.00** | 0 | 0 | 丙2 口径 |
| ¬潜在推理（z 置零/冻结） | **↓ ≥0.05** | ↓ | ↓ | 0 | 0 | **=0（定义）** | 0 | 若 Acc 不掉 ⇒ 装饰 |
| ¬工具闭环（切断观测） | 0 | 0 | 0 | 0 | 0 | 0 | **退化到脚本基线 +0.05** | 沙箱第二臂 |
| ¬确定性 | — | — | — | — | — | — | — | 非行为轴；用 §8 判据 |
| ¬消融能力（无判据） | — | — | — | — | — | — | — | 元层，不拆 |

**高风险对（必须做双拆）**：①自模型 × 记忆（A 的慢率与槽解冻阀同尺度，`λ_e`/`ζ` 会串）②记忆 × 潜在推理（都走 `符`，`算子_千层骨.py:474` 与 `:305` 同一个双线性门）③潜在推理 × 工具闭环（步数预算 vs 拍预算互斥）④持久自模型 × provenance（两者都改"谁能写 A"）。

**登记为不可分离（诚实，不加阈值糊）**：
- **确定性 × 其余六项**：确定性是**测量元层**，拆它会同时改变所有臂的读数（不是行为件）；
- **可消融能力 × 其余六项**：同上，元层；
- **记忆 × 自模型**：两者共享同一 `符` 与同一慢尺度，**在当前实现下不可分离**；若主控要求分离，必须先改实现（例如槽用余弦不用 `符`），属第二轮改动申请，本轮不做。

### 3.4 反证（什么结果推翻本队 T3 主张）

- 若 `|I_ij| ≥ 0.10` 出现在本队"可分离"4 组里 ⇒ 本队的可分离清单被推翻；
- 若置乱对照 `S_i > 0.05` ⇒ 拆件实现不等价（拆件≠原件的真子集），该行结论作废；
- **必须失败的对照**：①**拆件置乱臂**（参数同形状随机置换，须与 `M0` 不可分）；②**假拆臂**（把某项参数置零后**立刻还原**，指标须与 `M0` 逐位同，证明没有隐蔽副作用）；③**恒定预测臂**（A 类恒报 0，实测 **0.4779** [实测]）—— 任何"must-fail"臂都必须报它，防止把"比常数还差"当成机制失败。

### 3.5 为什么必须报零分布

sham 三臂 0.566 / 0.460 / 0.522 对阈值 0.60 [实测]。但 `0.460 < 常数预测 0.4779` ⇒ 无区室 sham **比不做还差**；且 0.566 的 Wilson 95% CI 上界 **0.654 > 0.60** ⇒ **"sham ≤0.60"在 95% 水平上并未被证实** [实测计算]。因此 sham 判据必须补：**零分布 = 标签置换后同管线准确率**（期望 ≈0.5），要求 `sham − null ≤ 0.03`，并把阈值写成"≤ min(0.60, null+0.03)"。

### 3.6 代价

单拆 7 ＋ 双拆 4 ＋ 置乱 4 = **15 臂**；按千层"21 臂 ≈ 8 分钟" [实测] 线性外推 ≈ **6 分钟**；V4 单臂 0.12 s ⇒ 若只做 V4 口径则 **<10 s**。最小可判子集（算不起时）：**`T3-min` = 4 单拆（自模型/记忆/潜在推理/工具闭环）＋ 2 双拆（自模型×记忆、记忆×潜在推理）＋ 2 置乱 = 8 臂**。

- 若把 `思核开关=False` 并证明潜在推理容器另有实现（如 `迭代` 算子）⇒ 该子集可保住，但**必须重新给更新式**。
- **必须失败的对照（判定器阳性对照）**：故意构造一个 `softmax(QKᵀ)` 的 dummy 模块加入判定流程 ⇒ 判定表**必须**判"是"。若判定表把 dummy 判"否"，判定器失效（P2）。

### 4.4 结论（诚实边界）

**若"潜在推理"在本轮的运行载体是思核 T，则它当前不满足 C1，必须先在四条修复路线中选一（§7.2 M4 的 i/ii/iii/iv）并实测"迭代真的改变决策"，否则不得写入方案。** 本队**不接受**三种规避：改名（把 softmax 叫"相对门"/"竞争"）、降阈值、把 `exp` 换成 top-k 但保留跨集归一化（议题已点名的同构变体）。

**R2 回填的两条补充（本队采纳）**：
1. **排序**：`(ii) 逐维门控（θ 须内生/per-key）> (iv) 可分能量下降 > (i) 硬竞争 > (iii) 移出链`（详见 `R2_C1同构预检.md §3.5`）；
2. **"能量下降"不是自动安全**：`∇_s logsumexp(s) = softmax(s)` 是数学恒等 ⇒ 若势函数写成 `−logsumexp(β cos + bias)`，一步下降**精确复现 softmax 门**。方案里必须明写"势函数逐键可分、无 log-sum-exp"，否则判"是"。[文献类比 + 数学恒等]
3. **θ 陷阱**：逐维门控若用**全场均值**当共享阈值 `θ=mean(全场)`，会伪造出交叉耦合（队员实测 S2=0.333），判定器会把它当"准 softmax" ⇒ θ 必须 per-key 内生或预注册，否则是新的焊死件候选（宪法第三条）。

### 4.5 代价

改造路线 (i) 硬竞争：每拍 softmax 指数运算替换为 argmax ⇒ **降低成本**（少 J 次 exp）；(ii) 逐维门控：`Σ_j 软限(cos_j−θ_j)_+ ⊙ ṽ_j` 与现有同量级（exp→算术，4 乘加/键，per-key θ 需 +J 标量）；(iii) 移出链：**0 运行时成本**（少一路）；(iv) 可分能量下降：+**J·D 乘加/拍**（J=4,D=1024 ⇒ +4096，相对现有 T 步 ≈ +50%）。三档因果干预：3 臂 × 0.12 s（V4 口径）。**未测**：思核在贯通 D=1024 下的每拍墙钟；执行覆盖实测（造桥 25.83 s + 120 拍 29.89 s）[实测]。

### 5.4 失败恢复判据（单独列出，因为议题点名"未测"）

**输入**：沙箱任务 + 注入故障（3px 外落点、越界、目标移位）。**操作**：执行技能原子链。**观测**：从故障发生到恢复成功的拍数、恢复后成功率、是否触发 `核对整屏`。**阈值**：恢复率 ≥0.80、恢复拍数 ≤ 复核开销 + 1 档。**must-fail**：禁用复核路径后恢复率须 ≤0.30（否则复核是装饰）。**代价**：每故障 1 次运行。

### 5.5 反证

### 5.6 代价与边界

### 8.3 跨进程与跨硬件边界（诚实）

- **可主张**：`{同机, 同 numpy 版本(2.2.6), 同 OMP_NUM_THREADS, 同 CPU 指令集}` 下逐位同；**已实测**（§8.2）。
- **不可主张（本队明确写"未测"）**：
  - **跨硬件**：x86 AVX2 vs AVX512、不同 BLAS 后端的**规约顺序**差异可产生 ULP 级差异；2^-20 量化**只在差值不落在舍入边界时**吸收差异，**无保证**。`P @ φ` 是 float64 matmul（`算子_两区室核.py:100`），是唯一新增风险点；`读/叠` 走 int64 精确（`算子_能力核.py:234-237`），是全树唯一**跨硬件可证**的部分。
  - **跨 numpy 版本**：`np.mean` 的 pairwise summation 分组可能随版本变。
  - **含外部工具**：实时键鼠不可重放；只允许"同输入流下动作序列同"，且单列为非-C13 臂。
- **若要跨硬件逐位**：唯一干净路径 = **整数化**（把 `P @ φ` 与池化改成 int64 定点乘加）。代价：+约 D×3 次整数乘加/拍（D=256 ⇒ +768 乘加/拍，相对 V4 核心每拍 O(1e3) 量级，估 **+30%~50%** [未验证假设]）；收益：跨硬件逐位可证。列为 **P1 候选**。

### 8.4 两趟方案的阳性对照（P2；必须补）
