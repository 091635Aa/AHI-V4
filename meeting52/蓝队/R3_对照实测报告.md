## 4. 本轮 5 条最硬的新证据

1. **must-fail 失效实证（判据层）**：常数慢滤波替身的 A/B 选择性 **J=0.483** ≥ 真臂的 0.050 ⇒ 沿用"自指消融掉分"作为持久自模型证据**不成立**（与红队 C10① 独立同向）。
2. **PS 与 PV 不可分离**：2×2 交互 **I=0.478**；关掉 provenance 门（外源可塑）与冻结自我态给出几乎相同的损伤（0.416 vs 0.425）⇒ 当前"归属"与"自态"是同一条通路，**不能各记一项**。
3. **provenance 比较器被直流淹没**：原口径 AUC 0.472、a_self **−0.040** vs a_ext **+0.120**（方向反）；**去直流修订**后 AUC **0.7499**（差 0.0001 未达 0.75）、g_self 0.875 ✓、但 g_ext **0.333**（3/9 外源误开 ⇒ 污染级联）⇒ 修订只救回方向、门槛仍差；机制"未证明"。
4. **潜在推理：不是幅度锁死，是信息为空**（C 组两因素分解，诊断臂非承重）：正常接线 z 幅 0.025 ⇒ 门控偏离仅 2.5%，替换 TV 5.5e-4；**放大 16×（门控偏离 0.39）后替换 z 与随机 decoy 的 TV 几乎相同（0.357 vs 0.360）、Acc 都 0.83 不动、z 单独解码 0.550≈随机** ⇒ **z 不携带 x 的信息**。因此：既有主路径 **0/120 执行**（BLOCKED）之外，原型层已给出"**装饰性中间量**"的证据；**不得**用"幅度不够"解释掉。
5. **F5 三条的诚实边界**：F5-b 支持"**不可预演**"（重算器 0.522 vs 主臂 0.894）；F5-c 的 must-fail **未触发**（随机历史仅掉 0.009）⇒ 承重的是**时序结构**，不是"具体历史内容"——这削弱了"记忆内容"的主张，但保住"历史不可省"。

### 4.5 M6 跨队口径定位（最高优先任务，主控指定；落件 `蓝队/实测/M6_口径对照.json`）

**三选一结论：既"绿队口径下复现 PASS"，又"实现差异定位到具体项"——两者测的不是同一量。**
- **绿队复现**（只读 import 其 `跑F5_M6`，同 K=64/D=256/±1 双极/归一化捆绑/dot）：**0.8972 / 0.9367 / 0.9226**（种子 52101/2/3）⇒ **M6 PASS 可复现，绿队数据没问题**。
- **逐因子替换（绿队数据上做）**：绿基线 0.8972 → 只换 cos（C2）**0.8972（不变）**；只换 Hebbian 记忆（C3）**0.6149**；只加直流 DC（C5）**0.5272**；Hebbian+cos+DC（C7）**0.5028**；DC 后去直流恢复（C8）**0.9012**；Hebbian+cos+DC+去直流（C9）**0.6219**。
- **归因**：①**DC 淹没是主因**（+常数 ⇒ 0.897→0.527，去直流可回 0.901）；②**记忆构造是第二独立缺陷**（归一化捆绑→泄漏 Hebbian ⇒ 掉到 0.615，去直流也只到 0.622）；③`dot vs cos` 在双极数据上**无差别**；④时间流 AUC 结构（351 vs 9）与绿队（64×63 平衡）不同 ⇒ 方差/污染不可比。
- **诚实限定**：本定位在绿队数据上做因子替换，**并未逐位复现我队 A6 的 0.472/0.7499**（我的独立流式重实现给出 a 自源 0.997 vs 外源 0.999 的饱和态）⇒ **A6 的 gate/更新时序细节仍需 A6 作者复核**；本定位只支撑"DC+Hebbian 两个口径差异是主因"这一层面的结论。
- **处置建议（主控已裁，2026-10-17）**：**M6 维持「争议中」，本轮不再跑 M6**。定性和解成立：绿 PASS 与蓝 FAIL **不是同一量对撞，是口径差**。但**即便绿口径 PASS 也证明不了键绑定/归属特异**——红队已给 **PV3 硬反例：固定 EMA 替身 5 seeds 中 2/5 ≥0.75**。**升级为结论必须同时满足**：①**统一口径**（去 DC + 归一化捆绑 + 平衡 AUC + 统一任务）；②**红队双替身通过**（键置换替身 / 内容无绑定替身）。两条缺一，M6 只能写"争议中/未证明"。窗口由主控在红队双替身 spec 落地后统一开。
