## 3. 采纳的**新冻结口径建议**（交主控写入 `冻结槽位.md`）

1. **墙钟口径**：任何「每拍」必须报 **median / min / p90 + 并发状态**；会议并发期**不得**当独占基线；预算按 **×1.5（轻度）～×3.2（会议并发）** 取最坏值。
2. **常驻口径**：引擎常驻必须同时报 **对象图 nbytes 合计** 与 **跑满一拍后的 RSS**（防 `np.zeros` 零页漏报 ≥12 MB）。
3. **全链路口径**：必须显式标注 **宿主链维度**（当前实测 D=1024）与 **千层设计维度**（D=256）**不同**；两者未接线前，七项叠加只能标 **[估计]**（F15）。
4. **紧线口径（主控 G4 已定案）**：CPU 峰值 **≤320 MB**、均值 ≤128 MB（哨兵）；GPU 峰值 **≤384 MiB**；**256 MB 禁用**（仅 3–6% 余量）；1 GB / 2 GB 仅作红线，**不作成就**。
5. **矩阵口径**：一律「**D=64 行为探针 + 3 种子 + 顺序两趟 + 独占会话**」；**会议并发期不跑矩阵**；缺「A单拆/B单拆/A+B/复苏」四格之一 ⇒ 该对不可归因。
6. **精度降级拆两级**：`int32 定点打包`（安全，须先证两趟逐位同）与 `float32 算术`（高危，触及 C13）**分开**；后者排在 U↓/D↓ 之后。
7. **观测级**：降级阶梯新增 **D0 观测级**（全屏→局部→差分→合成帧输入流）；这是当前唯一能砍"拍预算"的级，R1 完全漏掉。

## 4. 降级阶序列（采纳审计 §5.3，替代 R1 §7）

**D0 观测** → **D1 离线账** → **D2 分块** → **D3 U↓** → **D4 稀疏** → **D5 D↓（含宿主链 1024→256）** → **D6 精度·打包** → **D7 精度·算术（高危）** → **D8 功能子集** → **D9 判据规格（结果不得进最终宣称）**

> 关键修正：① 精度内部拆安全/高危；② U↓ 提到稀疏之前（U↓ 省 ÷4 且甲2 已证层档无收益，稀疏不省内存）；③ 新增 D0 观测级与 D9 判据规格级；④ D5 必须同时砍宿主链 D=1024（R1 只砍千层，砍不到主导项）。
