## 0. 一句话立场

**三队方案在"机制"上可以争，但在"账"上有一处共同的结构性错误：把"拍"当同一个单位。** 实测三种载体每拍差 **50–500×**——V4 两区室核 **0.15–0.285 ms/拍**、千层 D=64 **14.58 ms（空闲）/47.19（并发）**、宿主链 D=1024 **34–38 ms**。因此：蓝队"41 臂 25–35 min"、绿队"40 次运行 8–10 min"、红队"3 对 ×4 格 ≈10 min"**都不是错的算术，而是没绑定载体与乘子**。本队给统一预算式，并要求所有臂价**标注载体 + 种子 + 三件套 + 并发状态**；会议并发期**不跑矩阵**。

本队最优方案 ＝ **四列口径（peak_wset/PrivateUsage × 分配器/整卡）+ 双读（nbytes/跑满一拍 RSS）+ 紧线 320 MB/128 MB/384 MiB + 18 臂最小矩阵（D=64、3 种子、顺序两趟、独占 ≈59.6 min）+ D0–D9 降级序**。

## 1. 本队最优方案（资源账版，R2 修正后）

### 1.1 测量口径（已被审计算实）

| 口径 | 规定 | 依据 |
|---|---|---|
| CPU 峰值 | **双读**：`peak_wset`（OS 峰值）+ `PrivateUsage`（自有页，防共享 DLL 重复计） | 红队 A2.1 要求 `PrivateUsage`，本队采纳 |
| CPU 均值 | 预热后采样中位数；**只作"均值掩盖峰值"哨兵，不作达成线** | R1 §3.3 |
| 常驻 | **对象图 nbytes 合计** 与 **跑满一拍后的 RSS** 双读（防 `np.zeros` 零页漏报 ≥12.5 MB） | T-e |
| 全链路 | 主进程 + Σ子进程（`PrivateUsage` 之和）+ 设备显存，**取 max 不相加** | 审计 §3.1 |
| 设备显存 | 四列并列：`max_memory_allocated` / `nvidia-smi` 整卡 / host 侧 / 桌面基线 54 MiB | R1 §3.1 P3 |
| 墙钟 | **median / min / p90 + 并发状态**；并发放大 **1.57×（D=256）/3.24×（D=64）** | T-f/T-g |
| 两趟 | 顺序两趟（指纹 32 B，峰值 +0）；`C13 验证 ≈6–8× 单趟` 须**单列**，不摊入功能判据预算 | 蓝队 R2_确定性协议；本队采纳 |

### 1.2 阈值（**主控 G4 已定案**）

| 层 | 指标 | 值 | 说明 |
|---|---|---|---|
| L0 红线 | CPU 全链路 / GPU | **≤1 GB / ≤2 GB** | 所有者 Q2；实测余量 5.7×，**不作成就** |
| **L1 紧线** | CPU 峰值 | **≤320 MB** | 180.2（D=1024）+ 27.0（子进程）+ 5.93（帧）+ 安全 ×1.15 ≈ 253 → 320（含 scratch/工作缓冲余量） |
| L1 | CPU 均值 | ≤128 MB | 哨兵 |
| L1 | GPU 峰值 | ≤384 MiB | 上下文 142–168 + 引擎 24.13 + 两趟 24.13 + scratch ≈238–265 ×1.5 |
| L2 零线 | 纯 numpy、DEV=0 | 当前满足 | 回归守卫 |

> **G4 定案**：CPU 峰值 **≤320 MB**、均值 **≤128 MB**、GPU **≤384 MiB** 已冻结；**256 MB 禁用**（仅作 R1 历史值/对手主张引用，**不得**出现在合并建议口径中）。

### 1.3 成本预算（R2 权威式）

```
总墙钟 = 臂数 × 种子数 × 趟数 × Σ(单拍载体 × 拍/运行) × 竞争因子
拍/运行：千层类 T_arm 1,570（训 900+测 300+预热等）+ 复苏 700 = 2,270
竞争因子：独占 1.0；会议并发 D=64 3.24 / D=256 1.57
```

| 项 | 独占（D=64、3 种子、两趟） | 会议并发 | 备注 |
|---|---|---|---|
| 18 臂最小矩阵 | **59.6 min** | **3.2 h** | 唯一"算得起"的完整矩阵 |
| 蓝队 41 臂（修正） | **≈1–2.5 h** | **≈3–5 h** | 见 §2；蓝队自估 25–35 min 未含乘子 |
| C10/F5 不可预演臂（7 子集 +1 臂） | **≈23 min** | **≈75 min** | 7×3×2×2270×14.58 ms |
| C3 轴C/D 重跑 4 seeds | **1.33 h** | **4.3 h** | 8 seeds → 2.65 h / 8.6 h |
| C13 两趟（全部臂） | **×2.0** | ×2.0 | 单列 |

### 1.4 降级序（D0–D9，替代 R1 §7）

**D0 观测**（全屏→局部/差分→合成帧：帧 5.93→≤1 MB，观测 45→≤5 ms [未测]）→ **D1 离线账** → **D2 分块** → **D3 U↓**（1296→324，÷4）→ **D4 稀疏**（不省内存）→ **D5 D↓**（千层 256→64 **且宿主链 1024→256**）→ **D6 精度·打包**（安全，须先证两趟逐位同）→ **D7 精度·算术**（float32，高危，触 C13）→ **D8 功能子集** → **D9 判据规格**（降臂/种子/趟，**结果不得进最终宣称**）

## 3. 三队成本主张的复算（本件核心）

### 3.1 蓝队 41 臂

蓝队自估（`R2_判据规格.md` §5）：PS 9 臂≈3.5 s｜PV 4≈1.0 s｜MC 7≈1–30 s｜PR 5≈2 s｜TL 6≈6 min｜DT 5≈3 s｜AB 5≈5.6 min；合计 **25–35 min**（含回归 35–45 min）。其 §1.1 又规定"每臂必须同时跑**主臂 + must-fail + 零分布**"。

| 复算口径 | 计算 | 结果 |
|---|---|---|
| 单次执行（蓝队原口径） | 组和 ≈12.3 min + 相位/IO 开销 ×2–2.8 | **25–35 min** ✓ |
| +3 种子 +2 趟（must-fail/零分布按后处理计） | 非 AB 组 4 min + TL 6 min + AB 5.6×3×2=33.6 min | **≈44 min** |
| +并发 3.24× | 44 ×3.24 | **≈2.4 h** |
| +三件套**全量重跑**（缺一 INVALID） | AB 5.6×3×3×2=100.8 min；其余 ×18 后 ≈2.2 h | **≈2–2.5 h 独占 / 7 h 并发** |
| 若 ≥9 种子 | ×3 | **6–7 h 独占 / 12–15 h 并发 ⇒ 算不起** |

**结论**：蓝队 25–35 min **不是错数，是"单次执行"价**。按蓝队自己的规则 + 会议并发，诚实价 **≈1–2.5 h 独占 / 3–5 h 并发**；最小子集 11 臂 **≈30 min 独占 / 1.5 h 并发**。**接受 41 臂规格，但不接受其 25–35 min 作为预算依据。**

### 3.2 绿队 40 次运行

绿队（`R2_消融设计.md` §7.2）用 **0.285 ms/拍**，M1 13 + M6 9 + M7 11 + 交互 12 格 ≈40 次运行 ≈8–10 min。

| 载体 | 同 40 次 ×8,000 拍（800×5×2） | 结果 |
|---|---|---|
| 两区室核 0.285 ms/拍 | 40×8,000×0.285 ms | **1.5 min**（绿队 8–10 min 含 IO，自洽） |
| 千层 D=64 14.58 ms/拍 | 40×8,000×14.58 ms | **78 min 独占 / 4.2 h 并发** |
| 宿主链 D=1024 34 ms/拍 | 40×8,000×34 ms | **3 h 独占 / 9.8 h 并发** |

**结论**：绿队"算得起"只在**核**上成立；若判据要跑在目标载体（千层/宿主链），**必须重标价**。绿队自己也承认"千层级 2–3 次运行 ≈+8–12 min"与 75.42 ms/拍×1500×2×5 种子（单次≈18.9 min）不自洽——本队以实测为准。

### 3.3 红队最小子集

红队 R1 A3.5：3 高风险对 ×4 格 ×2 种子 ≈24 次 ≈10 min（V4 级 0.12 s/800 拍）。复算：24×0.12 s=2.9 s；加 must-fail/零分布后处理与两趟仍 <2 min；**红队 10 min 是保守上界，可接受**。但"4 格 ×2 种子"**不满足 3 种子达成线**（F5），且未含并发；按本队乘子 **≈25–40 min 独占 / 1.5–2 h 并发**。

### 3.4 "拍"口径对照（本件最重要的一张表）

| 载体 | 每拍 [实测] | 来源 | 用它的队 |
|---|---|---|---|
| 核.前向_双区室（D=256） | **2.56–4.25 ms** | T-j | 蓝队"≤5 ms/拍"、绿队 0.285 ms/拍 |
| V4 单臂（800 拍） | **0.15 ms/拍**（0.12 s/800） | 红队 R2c §3；蓝队 R1 §8.2 | 红队、蓝队 PS/PV |
| 千层 D=64 H=1 | **14.58 ms**（空闲）/ **47.19**（并发） | 本队/t-f | 本队 18 臂、蓝队 AB |
| 千层 D=256 H=1 | **75.42** / **118.29** | 本队/t-g | 本队 D=256 预算 |
| 宿主链 桥.步_向量（D=1024） | **34.36–37.72 ms** | T-j | 蓝队贯通、绿队若跑全链 |
| 全链路每拍（贯通） | **32.21 ms 隔离 / 67.60–74.69 并发** | T-i | 集成判据 |

> **规则（已进主控 G4 定案）**：任何"臂/次/运行"的墙钟必须写成 `载体@维度(H=?) × 拍 × 种子 × 趟 × 状态(独占/并发)`。缺任一项 ⇒ 该预算不得用于裁决。

## 6. 对 C1–C10 / F1–F5 的明确立场

> 说明：`C1` 在本队一律指**宪法铁律 C1**；主控裁决记录里的 C1–C10 用「裁决-Cn」区分。

| 裁决项 | 黄队立场（只从账出发） |
|---|---|
| **裁决-C1**（链上 softmax） | 非本队领域。**算力影响**：整改增 ≈(2J+1)D/步，绝对量级 ≈千层 0.28% ⇒ **预算上不否决**；成本是**工程人日级**（蓝队 R2_C1同构预检亦称"人日级"）。若走 (ii)/(i) 路线省 exp，反而**降**每拍成本。 |

| **裁决-C6**（技能 15→3 秒＝构造性） | **采纳红队 E1**：100 ms/拍是**模型拍时口径**，非真机。工具闭环成本：实时臂**不可做**；C13 只能固定输入流/记录-重放；原始帧 534 MB **否**。 |
