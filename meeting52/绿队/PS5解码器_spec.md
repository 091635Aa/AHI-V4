# PS5 解码器重装 spec（≤1 页 · 只 spec、不跑）

> 依据：`蓝队/R3_对照实测报告.md` PS5 口径（"切换后 1..R 拍从 A 解码上一规则；t50；lag-1≥0.90；重置臂 t50=0；若重置臂也 ≥10 ⇒ 解码泄漏"）＋ 本队 `实测/J-arm_报告.md` 的**决定性负发现**：**有状态对照 t50 也全 0**（0.667/0.333/0.571≈chance）⇒ 现"网格最近邻解码 + 15 拍窗"**无效**，`t50=0` 只能作构造证据。
> 目的：把 PS-B 从"构造性成立、度量未执行"升级为"可执行判据"；**本 spec 本身不是证据**，跑通 validity gate 才算。
> 纪律：只 spec、不跑、不改件；阈值 `[提案]`；空着＝未测。

---

## 1. 重装要点（相对旧版改三处）

| # | 旧版（无效） | 重装版 |
|---|---|---|
| D1 | 解码器＝对 `A(z)=P@特征(z)` 网格做**最近邻** | **训练型规则解码器**：`A_t → 上一规则标签`（ridge/logistic），**只用切换前数据训练**，按切换点 **leave-one-switch-out** 交叉验证；推理只读 `A` 向量 |
| D2 | 窗口 15 拍、单点 | 窗口 **R∈{30,60}**；曲线 `a(k)` 对 k=0..R−1 取"切换点×种子"均值 + Wilson/2SE |
| D3 | 无对照门 | **Validity gate（INVALID 规则）**：有状态对照必须 `t50≥10`，否则解码器无效（本队 J-arm 已实证旧解码器在此项失败） |

---

## 2. 任务与测量（预注册）

- 载体：`AHI4/meeting49/实施/算子_两区室核.py`（**只读**）；`生成序列(种子, 400, 边界训练)` 自带隐藏切换（每 20–60 拍），切换点已知。
- 每切换点 `s`：上一规则边界 `b_prev=边界[s−1]`、新规则 `b_new=边界[s]`；在 `t∈[s, s+R)` 从 `A_t` 解码"上一规则"，对/错＝解码标签是否＝`b_prev`。
- **训练/测试隔离**：训练集只用 `s` 之前 ≥100 拍的 `(A_t, 规则标签)`；测试只用 `t≥s`；解码器不含 `x/B/奖赏` 输入（源码级检查：推理函数签名只收 `A`）。
- 观测：`a(k)` 曲线、**t50＝首个 k 使 `a(k) ≤ chance + 2SE`**（chance=0.5；SE 由窗口内二项方差给）、`A` 的 lag-1 自相关。
- 种子/窗：5 seeds × R∈{30,60}；**慢率**在 `{0.04, 0.08, 0.12}` 扫描（V4 既有 `慢率列`），选"有状态对照 t50 最大"的慢率作为测试配置（**选择只用有状态对照，不看 J-arm**，防选参泄漏）。

## 3. Validity gate（缺一 = INVALID，不得读作机制证据）

| 门 | 预期 | 不满足时 |
|---|---|---|
| **G1 有状态对照** | `t50 ≥10` 且 lag-1 ≥0.90 | 解码器无效（**INVALID**）⇒ 回到 D1/D2 重装，**不得降低门槛** |
| **G2 重置臂（J-arm）** | `t50 = 0` | 解码泄漏（`B`/`x`/奖赏含规则信息）⇒ **INVALID** |
| **G3 标签置换臂** | 准确率 ≤chance+2SE | 解码器记忆了顺序/泄漏 ⇒ INVALID |
| **G4 只读 A** | 推理函数签名/源码扫描不含 `B`、`x`、`奖` | 违反 ⇒ INVALID |

## 4. 判据通过与升级路径

- **PS-B 可执行** ⇔ 同时满足：G1–G4 ＋ J-arm `t50=0` ＋ 有状态 `t50≥10`；此时 PS-B 生效，`t50` 门限为 **≥10 拍**（提案）。
- **未通过 G1** ⇒ PS-B 维持 **"构造性成立、度量为未执行"**（J-arm 的 `t50=0` 不升级为判据读数；写在方案里时必须带此限定）。
- 若最慢率（0.04）仍有状态 `t50<10` ⇒ 判"任务/窗口不足"（U7 换任务或加 R），**不得下修阈值**。

## 5. 诚实边界

- 本 spec **零实验**；`t50≥10`、`lag-1≥0.90`、窗口/慢率为提案，须主控/蓝队冻结。
- 蓝队 R3 PS5 读数"保留 A 0.788 vs 重置 1.0"本身提示**重置臂反而更好**（可能泄漏），故 G2 必须实测、不得引用旧读数。
- 未测：训练型解码器在 D=64 的可分性、R=60 的样本量（切换点×种子）、慢率扫描的算力。
- 与 J-arm 的关系：J-arm 关闭；本 spec 是"把 PS-B 半边变可执行"的**前置**，不是新实验申请。
