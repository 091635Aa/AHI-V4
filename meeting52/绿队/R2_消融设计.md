### 0.2 六条判读规则（本件所有臂共用；也是对 R1 的补强）

1. **决策统计量三件套**：`argmax 改变率` / `得分分布 TVD` / `top-2 margin`。**只报准确率＝丙1 重演**（准确率对"内部量变了而决策没变"不敏感；本轮已实测到这种分离，见 §1.2）。
2. **计算匹配对照（α 臂）**：任何"迭代有用"的臂必须配一个**同算力、不同读出**的对照（算 T 步但读第 1 步）。否则"多算几步"本身就是混淆。
3. **分辨率规则**：效应点估计 `< 2×SE` 或 95% CI 跨 0 ⇒ 判「**不可判定**」，不写"有趋势"、不上调阈值、不改任务（蓝队 U 系列同精神）。
4. **must-fail 三件**：每个 must-fail 臂必须同时报 **null 臂**（标签/行列置换，期望≈0.5）、**常数臂**（恒报 0，V4 实测 0.4779 [实测/转引 蓝队 §3.4]）、**声明上限**；阈值写成 `min(声明值, null+0.03)`。
5. **预注册**：种子、序列、损坏率网格、阈值、选参规则**跑前写死**；禁 selection-on-test（蓝队 A-自1）与 selection-on-seed（本件 A8）。
6. **两趟口径**：同机跨进程 + `PYTHONHASHSEED∈{0,12345}` × `OMP_NUM_THREADS∈{1,4}`；指纹＝全状态 float64 `tobytes()` sha256 + 定点格断言 `x·2^20∈ℤ`（蓝队 §8.2 已实测该路径逐位同；本件每臂必报）。**跨硬件不可主张**（蓝队 §8.3）。

## 1. M1 · 记忆钥匙：迭代必须改变**决策**，不是只改变内部量

### 1.1 四件套

**① 主张** `[未验证假设]`：M1 的"补全"只有在**迭代产物进入决策统计量**时才算机制。现有实现（top-1 补全 + `x←0.5x+0.5槽[argmax]`）在决策层**实测幂等**（结构上近似：latch 到 top-1 后残差只拉向该槽），因此"迭代有增益"在现有件上不可成立；下一版必须换成**多候选 `叠` + 逐候选独立门 + 残差进读出**，并用 α/β/γ 三臂分离"算几步"与"读哪步"来证明。

**② 证据**
- `[源码读]` `meeting51/实施/算子_千层骨.py:308-324`：每轮 `强=重合强度(x)`；`选=强≥ζ`（**ζ 只限制候选集**）；`k*=argmax(强[选])`（**仍取单槽**）；`x←归(0.5x+0.5槽[k*])`。`[实测/转引 green-iso R2 §3.1]`：这是 **β→∞ 硬 top-1 注意力一步 + 残差迭代 T 次**（**不是"top-1 快照"**）；决策统计量 `argmax(强(x_final))` 对迭代不敏感（x 只向已选槽移动）⇒ **这才是丙1 逐点同的真因**。本轮 988 次比较中 argmax **均未换槽** `[实测]`（严格证明见 green-iso 更新式审查）。

### 1.2 为什么"内部量变了"不能当证据（本件的核心区分）

### 1.4 禁止参数区 `R_forbid`（M1 的 C1 阳性对照）

定义（**这就是"它绝不能变成什么"的参数化**，与 `green-iso` 的判定表对齐）：

```
R_forbid = { 候选数 k = 1（β→∞ 硬 top-1 选择）      ← 现状「解冻」就在这一区
             或 k = K（全槽）,
             逐候选权重 g_m ← exp(β·s_m) / Σ_l exp(β·s_l)   （跨候选归一 Σ=1）,
             τ_补 → 0 使 g 饱和比例 >0.9,  ζ_补 → −∞,
             读出 = Σ_m g_m · 槽_m                （一步全局加权求和；或读出丢 g 只用 argmax）,
             键中含 f(t) 的绝对时间/序号字段（τ_t/ℓ_t）,
             码本行数 / K 随拍数增长 }
```

- 在 `R_forbid` 上，M1 的"迭代补全"退化为 **softmax 检索**或 **T 层硬注意力**（现代 Hopfield 一步 ↔ 注意力同构，`[文献类比] 报告 §5.2`；`green-iso R2 §3.1/§3.5` 判定表）。**它不是可调参数范围，是禁止区**：进入即等同 C1 违规，改名不算规避。**现状 `解冻` 的 `k=1` 分支已在区内**——这解释了丙1 为什么必然逐点同。
- **must-fail 方式**：M1-A7 必须被 C1 判定器判"是"（阳性对照）；同时行为上必须与显式 `softmax(强/τ)·槽` 参照臂**统计不可区分**（\|Δcurve\|≤0.05）；另用 **A9 P2 冻结索引臂**区分"离散重选 vs 连续门"。任一不成立 ⇒ 参数区定义有洞或判定器失效，回 `green-iso`。
- 条件性同构的**边界**：`k≪K` + 逐候选独立阈值门（Σ≠1）+ 硬稀疏 + **残差进读出** + **键无 t 依赖** 五件同时在，才判"否"；缺"残差进读出"这一件就是装饰（丙1 教训），缺"键无 t 依赖"则与延迟恢复自相矛盾（C-5）。

## 2. M6 · provenance：归属度必须内生、内容依赖、可被解耦打坏

### 2.1 四件套

**① 主张** `[未验证假设]`：provenance 的达成＝**归属度由"预测-实际"比较器在结果前算出**——`ê←解绑(绑(a,s), E_效果)`（HDC 取值用 `解绑`，**不用 `读`**，见 C8/green-iso C-6），`a_归属 = clip(归一化内积(ê, o_{t+1}),0,1)`；且在**解耦污染 / 标签置换 / 全局统一低可塑 / 奖赏置乱 / 重复同键熟悉度 / 来源随机化**下必须失败。现有实现的"外源不可塑造我"只是 `允许` 布尔，**不能作为 provenance 证据**。

**② 证据**
- `[源码读]` `meeting49/实施/算子_两区室核.py:259-266`：`若塑=bool(允许); if 若塑: 自我态=_归(向量); 变 = not array_equal(前,自我态)`。**没有任何来源计算**。

  - 新建核后注入**与当前自态完全相同**的向量且 `允许=True` ⇒ `被塑造=**False**`、`变化元素=0`。
  ⇒ 判据实质是"**目标向量变没变**"，与内容、标签、来源均无关。

### 2.2 为什么现有"归属臂"必须重写（与蓝队 §1.2 对齐）

蓝队 P1 公理：存在**合法实现变体**使臂读数落到阈值之外才算判据。现臂连"变体"都不需要——**改 `允许` 关键字就改结果**。本件把现臂降级为**校准对照**（M6-P0），达成只认 **P1+P2+P3**（内生 + 假归属率 + 解耦污染），另加 P4/P5/P6/P7/P8/P9/P10/P11 八个 must-fail/迁移/工程约束。

**与 C9 的并列实现关系**：C9 的 `g=ε_self 分位门` 与本件的 `a_归属=cos(ê,o)` 比较器**互不替代、共用判据**。本件主方案用后者（HDC 解绑取值 + 余弦比较，直接对应"传出拷贝"）；若主控以 C9 为准，则把 P1 的 `a_归属` 换成 ε_self 分位（已删真值分组），**P6 奖赏置乱与 P8/P9 仍是必跑**——它们判的是"是否拿结果标签/熟悉度冒充来源"，与实现无关。

**与 M3 记忆的分工**：M6 的 `g` 决定"谁可以写慢件/槽"；M1 的槽是"写什么"。两者在"外源写入是否进槽"上耦合——见 §4 的 I-16，**不能单点拆**。

### 2.4 假归属率：定义、阈值与样本量

- 定义：`假归属率 = #{外源事件中 a_归属 ≥ ε_慢基线} / #外源事件`（**越高越坏**）。同时报"漏归属率"（自源被误判外源）。
- `ε_慢基线` **按自归一规则由 `a_归属` 自身慢平均生成**（C8-2：零人挑，不扫、不按结果调；沿用 `内核_真学习.驱动_ε` 的 `ε>ε_slow` 口径）。**主统计量用无阈值 AUC**；二值假归属率只作次级读数。
- 样本量：外源 400 事件/种子 → 假归属率 Wilson CI 半宽 ≈0.04（p=0.2 处）；基线 0.20 vs 污染 0.30 的差 0.10 ≈ 3.5×SE，可判。
- 判读：基线假归属率 ≤0.20 且污染后 ≥0.30 **两者同时**才算"归属度可被解耦打坏"；只有一个成立 ⇒ 不可判定。
- **AUC 优先规则**（C8-2）：若 PASS 依赖 `ε_慢基线` 的具体取值（阈值敏感性臂）⇒ 判"阈值制造的标签" FAIL；P8 的熟悉度上升 / P9 的来源随机化任一不过 ⇒ 归属只能称"熟悉度/门控"，不得称 provenance。

## 3. M7 · 潜态进读出：潜态必须在输出里，步数必须随难度

### 3.1 四件套

**① 主张** `[未验证假设]`：M7 的达成必须**同时**满足（a）**因果**：替换/扰动/冻结潜态 `L` ⇒ 输出分布必变；（b）**读出**：`L` 必须进入 `o_t`（不是只进返回字典/迹）；（c）**收敛被排除**：T=32 与 T=8 决策逐位同 ⇒ 只是收敛，不是"想更久"（green-iso C-4）。现实现三条全不满足，且"迭代步数"参数被基类主循环共用，**直接扫步数会产生假阳性**。**定位（C8-3）**：即使改造完成，本项也只主张「**潜态读出通路**」，**不称"潜在推理/思考深度"**；若要主张真推理，须走 green-iso 路 B（驱动依赖状态、多不动点）并跑 P2 分解臂。

**② 证据**
- `[源码读]` `meeting49/实施/算子_两区室核.py:218-229`：`输出=软限(A−B)`；`终态=迭代(叠(差), A, 迭代步数)` **只进返回字典**；`前向_试次`（`:196-215`）无迭代路径。
- `[源码读]` `meeting41/实施/算子_能力核.py:269-304`：基类 `前向` 的 `迭代步数` 用于**逐令牌推进状态**（`:277,300`），而 `前向_双区室` 把这个参数**同时**传给它和 `终态`（`:218,226`）。
- `[实测]` 本轮只读探针（`两区室核(D=256, 种子=47001)`；`生成码本(8,256,47001)`；`前向_双区室(码本, 迭代步数=st)`）：
  - `st∈{1,2,4,8,16}` ⇒ **输出哈希 5/5 全不同**；
  - `终态` 相对 st=1 的最大差：`0 / 2.951 / 6.008 / 8.220 / 10.024`；
  - `前向_试次` 两遍逐位同（无潜态路径）。
- `[实测/转引]` 红队 R1 A4.2 的**代码结论**（终态不进输出）成立，但其**观测预期**"改步数 ⇒ 输出哈希 5/5 全同"与实测**相反**：输出变化来自**基类深度**（B 变了），不是潜态。⇒ 红队该 must-fail 臂若不改，会得到"潜态有因果"的**假阳性**；本件 §6 登记此交叉检查。
- `[源码读]` `meeting39/实施/内核_相空间算子T.py:90-103`：`_相对门` 是跨集 `softmax` 归一（蓝队 §4/§7.2 判"是"）⇒ **M7 不得用 `思核` 承载潜态**；只能用 `迭代`（收缩映射，`算子_能力核.py:249-266`）承载，或先按蓝队修复三选一。
- `[实测/转引]` `meeting51/实施/证据_千层.md` 丙1：迭代在现有件上无决策增益（同 §1）。

**③ 反证**
- 若 M7-L1 的 `β vs α` 改变率 **<0.10** 且 TVD <1SE ⇒ 潜态仍是装饰（即使已接读出），M7 FAIL。
- 若 `β vs α ≥0.15` 但 **M7-L2 替换潜态改变率 <0.90** ⇒ 读出被"叠"稀释/存在旁路，需重设读出（不得声称因果）。
- 若 M7-L6 固定步数臂 **ρ≥0.4** ⇒ 难度代理与时间/序列位置混淆，须换外部难度定义（任务阶），否则"难度→步数"不可判。
- 若 M7-L7 同分布随机轨迹臂与真潜态准确率差 **<1SE** ⇒ 不可判定（不得写"有"也不得写"无"）。
- 若 M7-L8 上界臂−固定步数 **<2SE** ⇒ 任务饱和，调度无可测收益（不是机制失败）。
- 若 M7-L9（T=32 vs T=8）**不逐位同** ⇒ green-iso 的"唯一不动点/投影等价"证明被否，必须查是否有 `读` 进驱动（跨维混合）并把该臂结果单列；若 L10 置换 `L₀` 后决策相同率 **<0.95** ⇒ 潜态确实携带历史信息（好事），但要查来源是否合法（不得来自当前输入重算）。
- **必须失败**：M7-L0 现状臂必须"终态不进输出"（输出哈希不因**只改潜态步数**而变；本件用基类深度固定的分离臂验证）；若做不到分离 ⇒ 测的是基类不是潜态。

**④ 算力代价**：见 §7。[实测] `迭代(T=4,D=256)` **0.19 ms**；`前向_双区室`（8 令牌，T=4，D=256）**8.10 ms/次**；行为面单拍 **0.285 ms**。M7 全部臂 ≈ **1.5–2 min**（D=256，两趟）。

### 3.2 M7 的混淆：参数共用（本件独立发现的测量陷阱）

```
前向_双区室(令牌列, 上下文, 迭代步数=st):
    B列 = 基类.前向(令牌列, ..., 迭代步数=st)   ← st 改 B（世界态）
    输出 = 软限(A − B列)                        ← 只含 B
    终态 = 迭代(叠(差), A, st)                  ← 只进返回字典
```

- **错误臂**：`st: 1→16` 看输出哈希 ⇒ 5/5 不同 ⇒ 误判"潜态因果"。
- **正确臂（L1 的分离要求）**：把"基类深度"固定为 1，只改**潜态步数**；且读出必须改为 `o_t←归(叠([L_{t*}, B_t]))`。此时若 `β vs α` 仍 ≡0（现状）⇒ 潜态装饰；若改造后 `β≠α` 且替换 L 改变率 ≥0.90 ⇒ 因果成立。
- 因此 M7-L0 的 must-fail 值要写成：**基类深度固定时，只改潜态步数 ⇒ 输出逐位同**（现状预期"同"；若不同说明潜态已被接线，可进入 L1 判定）。

### 3.4 M7 的四道因果判据（与议题 T4 + green-iso C-4 对齐）

1. **读出存在性**：源码/更新式级证明 `L` 进 `o_t`；没有更新式文本的臂不参与裁决（议题 T4 原文）。
2. **干预敏感性**：替换/扰动/冻结三档，输出分布改变；配"同分布随机轨迹"阴性对照（防"随机换当然掉分"的假阳性）。
3. **投影排除**（green-iso C-4，**新增、必跑**）：`T=32` vs `T=8` 决策逐位同 ⇒ 迭代只是收敛到唯一不动点；置换 `L₀` 后决策相同率 ≥0.95 ⇒ 初值被抹平。两条同时成立时，**只能定位为"读出侧潜态 / 单次投影的数值求解"**，不得称"潜在推理/思考深度"；"4 步 vs 1 步翻转率"**单独不构成诊断量**。
4. **调度内生性**：`n_t` 与**外部难度（任务阶）**相关（`ρ₁/ε_self` 只作诊断，不作判据），且固定步数臂必须失败；用 oracle 上界判断任务是否有调度空间。

四道缺一：只有 1 ⇒ "接线了但没影响"；只有 2 ⇒ 可能是扰动损坏；只有 3 ⇒ 固定深度/收敛伪装；只有 4 ⇒ 难度代理混淆。

### 3.5 M7 统计检验

- L1：配对 McNemar（β vs α、α vs γ）；TVD bootstrap CI。
- L2/L3/L4：TVD 均值±SD（5 种子），三档干预方向一致要求 ≥4/5。
- L5：Spearman（主用任务阶，次用 ρ₁）；固定步数臂作为 null。
- L7：`ΔAcc` 的 95% CI 若含 0 且 |ΔAcc|<1SE ⇒ 写"不可判定"（不写"无因果"）。
- 所有臂两趟全状态指纹一致才计入。

### 4.1 三对 2×2 骨架（行=拆件，列=指标；格=预期方向）

|---|---|---|---|---|---|
| **I-16** M1×M6 | ¬M1=槽→随机槽（同 K）；¬M6=`g≡1`（全判自源） | ①假归属率 ②污染后召回下降 | 完整：假归属率低、召回高；¬M6：假归属率高、召回被污染；¬M1：召回=随机；双拆：召回=随机且假归属率不再上升 ⇒ **\|I\| 大（地面效应，需反正弦变换）** | 外源事件是否**写进槽**由 `g` 决定；槽又是 M1 的载体 → 任一单拆都会把另一项的作用通道拆掉 | n=800/格；\|I\|>零分布95分位（主），>0.10（次） |

- **主判据（零人挑，green-iso M11）**：`|I|` 的**置换零分布 95 分位**（100 次，固定种子）；真拆 `|I|` 必须超过该分位 ⇒ 不可加；否则"不可判定"。

### 4.3 补回臂与置换零分布（必要性/充分性/阴性三件）

- **补回臂**（两件，green-iso M11 + 蓝队 §3）：
  - **充分性（逐位还原）**：把拆件参数**逐位还原**到拆前快照，指标必须与 `M0` 逐位同（不得用重训冒充）；逐位还原失败 ⇒ 该拆件不是真子集。
  - **可补偿性（续训回升比）**：拆后**继续经历 400 拍**（≥蓝队 N≥200），`R=(Y补−Y拆)/(Y基−Y拆)`：`R≥0.90`＝可补偿（真承重）；`0.5–0.9`＝半焊死；`<0.5`＝焊死（应回退）；`Y基−Y拆<0`（拆后反升）＝装饰/或任务不匹配（须报 95% CI + 第二个任务族复核，蓝队 A-自6）。
- **置换零分布**（阴性）：100 次固定种子（`44001–44100`），打乱拆件参数/分区标签；`I` 的 null 均值应 ≈0（\|mean\|≤0.02）；真拆的 `|I|` 必须超过 null 95 分位，否则"不可判定"。
- **拆件置乱臂**（拆件≠真子集检查）：参数同形状随机置换后与完整 `M0` 的 `|Δ|≤0.05`（蓝队 S_i）；**假拆臂**（置零后立刻还原）必须与 `M0` 逐位同。

### 4.4 双分离（逐项，防"拆了掉分=承重"的伪归因）

| 项 | 损伤 A | 功能甲（应掉） | 功能乙（应几乎不动） | 阈值 `[提案]` |
|---|---|---|---|---|
| M1 | 槽→随机槽（同 K） | 召回 | 主任务 Acc | 召回掉 ≥0.15 且主任务掉 ≤0.05 |
| M6 | g→常数 / 解耦 ê | AUC、假归属率 | 任务 Acc | AUC 掉 ≥0.20 且 Acc 掉 ≤0.05 |
| M7 | 替换/冻结 L | **难例子集**（阶≥3）Acc、TVD | **易例子集**（阶=2）Acc | 难例掉 ≥0.05 或 TVD ≥0.10，且易例 Acc 变化 ≤1SE（难度选择性） |

### 4.5 交互项样本量与功效（对蓝队阈值的**统计修正建议**）

蓝队 §3.2 写"2×SE≈0.095，所以 `|I|>0.10`"。本件认为该口径把**两个臂之差**与**四格交互**的方差混了：

- 单臂比例的标准误：`SE_cell = √(p(1−p)/n)`；`n=113, p≈0.5 ⇒ 0.047`。
- **两臂差**的 SE：`√2·SE_cell ≈ 0.066`；`2×`≈0.13。
- **交互 `I`** 是 4 个格的和：`SE_I = 2·SE_cell ≈ 0.094`（n=113）；`2·SE_I ≈ 0.19` ⇒ 在 n=113 下 `|I|>0.10` 只有约 **18%** 功效（真 `I=0.10` 时）。
- **本件提案**：交互格 **n=800/格**，`p=0.5 ⇒ SE_cell=0.0177`，`SE_I=0.035`，2SE≈0.07；在真 `I=0.10` 时功效 ≈**0.81**（`n≈4(z_{α/2}+z_β)²p(1−p)/δ² = 4×7.84×0.25/0.01 ≈ 784`）。故**主判据用置换零分布 95 分位（green-iso M11，零人挑）**，`|I|>0.10` 只作**严格次判据**；两者都要求**样本量到 800/格**，否则蓝队 0.10 阈值在自己的样本量下不可判。
- 比例类指标在 0/1 附近做**反正弦变换**再算 `I`（防地面效应，见 I-16）。
