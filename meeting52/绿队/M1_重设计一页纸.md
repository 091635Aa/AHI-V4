## 2. 候选设计（只列候选；按"是否能改变决策统计量"排序）

### C1 · 残差门控式（推荐先试）：只在"残差大"时更新，禁止常量驱动
```
ρ_t = ‖m_t − s_t‖∞
u_t = clip((ρ_t − δ0)/δ1, 0, 1)                     # 内生门：残差小 ⇒ 不更新
s_{t+1} = 归(s_t + η·门(u_t, m_t − s_t, 0))         # 增量式，不是凸组合
```
- 要点：**驱动是差值 `m−s`**（→0 时自动停），不注入 cue/ones；`u` 内生、零人挑阈值（δ0/δ1 预注册扫描）。
- 为什么可能改变决策：它把 s 拉向"多候选记忆的平均"，拉动力随差异衰减；若 `m` 与 `s` 无关则 u≈0 ⇒ 退回单次投影（**可证伪**）。

### C2 · 逐元素差异门（避免叠加偏移）
```
门用于混合而非选择：m_t = 叠([门(g_m, Z_{idx[m]}, s_t) for m])   # 与当前态混合，非 0
s_{t+1} = 归((1−λ)s_t + λ·m_t)
```
- 要点：`门(g, Z_i, s)` 的 y 用 `s` 而非 `0`，避免"未命中项变 0"造成的整体偏移；λ 扫描。

### C3 · 决策统计量换口径（与 C1/C2 正交，可单独测）
```
score_j = 归一化内积(符(s, Z_j), cue)      # 或：重合强度口径（千层式）
decision = argmax_j score_j
```
- 要点：现口径 `内积(s,Z_j)` 对 s 的整体缩放/偏移不敏感；"与 cue 的重合"更贴近"这条记忆解释了多少线索"。
- **必须同时报**：决策翻转率（β vs α）与 margin 变化，否则又回到"状态变了当证据"。

### C4 · 绑定键补全（HDC 正确用法，与 M6 同法）
```
存储：e = 绑(键, 内容)   （键=绑(对象,位置)，内容=槽内容）
补全：ê = 解绑(键_残缺, E)     # 内容条件期望，不是值的均值
读出：score_j = 归一化内积(ê, 内容_j)
```
- 要点：**不用 `读` 取内容**（R3/M6-P10 已证 `读` 取值≈chance）；容量受 D-1 约束（≤16@D=256 或升 D）。
- 这是把"补全"从"最近邻检索"变成"内容条件期望"的唯一正路。

### C5 · 迭代若有跨维混合，必须过 P2（否则承认只是一次性检索）
- 8 算子内唯一跨维混合是 `读`（green-iso T1″）；若 C1–C4 都只做逐元素，则迭代**结构上等价单次投影** ⇒ 只能称"一次性 top-k 检索"，**不得称补全**（C8/F2/F3）。
- 若坚持"多步选择"，唯一合规方向：把 `读` 的**逐候选独立门**放进驱动（非 argmax），且必须跑 **P2 冻结索引臂**：`完整 vs 冻结` 翻转 **≥0.10** 才放行；否则判"T 层硬注意力/装饰"。

## 3. 预注册判据（重设计实现后必须全过，缺一不进候选）

| 判据 | 阈值 | must-fail |
|---|---|---|
| 决策翻转 β vs α | 全样本 ≥0.15；近平局 ≥0.20 | <0.01 ⇒ 装饰 FAIL |
| P2 连续门贡献 | `完整 vs 冻结索引` ≥0.10 | ≤0.02 且 完整vs单步≥0.15 ⇒ T 层硬注意力 FAIL |
| 召回不得劣于直接检索 | ≥ 直接检索 **+0.05** | 若 ≤ 直接检索 ⇒ 机制无价值（本轮 0.457/0.717 即此情形） |
| K-差（蓝队 MC2 口径） | ≥0.10 且 `R(1)∈[0.15,0.85]` | 全点<0.10 ⇒ 只能主张"缓存+最近邻"（U2） |
| 无门臂 | `g≡0` 时决策必须改变（否则门是装饰） | — |
| 随机槽臂 | 召回 ≤0.25 | 与真槽差<0.15 ⇒ 召回对索引不对内容 |
| C1 自检 | `k≥3`、`K` 固定、`Σg≠1`、键无绝对时间/位置 | `k=1` 或 `Σg=1` ⇒ 同构 FAIL |

## 5. 它绝不能变成什么（重设计的红线）

- 不得变成 **softmax/Hopfield 一步**（`k=1` 全禁；`k=K`+Σ归一 全禁）；
- 不得变成**查表**（一记忆一槽、精确键匹配、动作序列预写）；
- 不得用**位置/绝对时间**进键（时间只进优先级 `π`）；
- 不得把**迭代步数**当思考深度（C8/F2）；
- 不得用"状态变了"当证据——**唯一观测面是决策统计量**（R3 结论）。
