## 2. C8 正面回答（主控要求二选一）

### 2.1 结论

**绿队选 (b)-限定；同时撤回 (a) 能力主张。**

- **(b)-限定**：只在 **M1 记忆钥匙的补全**上主张"`读` 是**硬 top-k 非 softmax 选择**"，并**必须过更新式级同构判定 + P2 分解臂**（§2.3）。理由：8 算子内唯一跨维混合是 `读`（定理 T1″），若连它都不用，"补全"无从谈起；不用 `读` 就只能做逐元素门控 ⇒ 等价单次投影（T1′）。
- **(a) 撤回**：**"潜在推理"能力主张撤回**。M7 降级为**"读出侧潜态（单次投影的数值求解）"**；不再声称"想更久/思考深度/难度→步数"，也不再引用 `思核` 的 softmax 门。

### 2.2 对 F1–F4 的逐条回答

| 约束 | 绿队回答 |
|---|---|
| **F1 只有 `读` 带跨维混合** | **成立且被接受**。因此：①任何"记忆补全/选择"必须显式写 `读`，并配 (b) 论证；②任何"动力学"若想多不动点，必须借 `读` 进驱动 ⇒ 直接踩 F2/C8 ⇒ **绿队放弃该路线**（不硬撑）。 |

### 2.3 (b) 的论证义务（放行条件，缺一不放行）

1. **形式**：读出＝`Σ_m g_m·Z_{idx[m]}`，**不除 Σg、不做跨候选归一、不用指数族**；`g_m=clip((sim_m−ζ)/τ,0,1)` 逐候选独立。
2. **稀疏固定**：`k∈{3,4}` 且 `K` 固定，**`K` 与码本行数不随拍数增长**；键**不含绝对时间/序号/位置编码**（时间只进 `π`）。
3. **P2 分解臂**（必须真跑、必须能失败）：
   - 臂①`T=1`；臂②**冻结 `n=1` 的索引集、只让 `g` 继续演化**；臂③完整 `T=4`。
   - 判：`完整 vs 冻结索引` 的决策翻转率 **≥0.10** ⇒ 连续门真的改决策，**(b) 成立**；若 `≤0.02` 且 `完整 vs T=1 ≥0.15` ⇒ 翻转全来自**离散重选** ⇒ 实为 **T 层硬注意力** ⇒ **(b) 失败**，M1 降级为一次性检索。
4. **P3/P4**：`T=32` vs `T=8` 逐位同 ⇒ 判"只是收敛"；完整 vs 切断在**同一决策统计量**上逐点差 `<0.01` ⇒ 判装饰 FAIL（丙1 口径）。

### 2.4 若 (b) 失败，绿队的退路（预先写死，不许事后找补）

- M1 → "一次性 top-k 检索（非补全）"，只保留"分布式绑定存储 + 长期保持"；
- M3 → 只剩"**样本选择**"这一机制变量（重放本身被线性性消解）；
- M6/M8 → `ê` 用 `解绑`，与 `读` 解耦，不受 (b) 影响；
- M7 → 读出侧潜态（弱主张）；
- 记忆连续性判据 → 只剩"冻结槽位 + 延迟恢复"（丙2 已有 `[实测]` 1.00 vs 0.00）。

## 4. 关键机制的整改版（v2 更新式，供蓝队/红队复核）

### 4.1 M1 记忆钥匙 v2

```
κ    = 绑(绑(o_t, 内容位置ℓ), 实体e)                 # ★无绝对时间 τ；时间只进 π
s_0  = c                                              # 线索（可残缺）
for n = 1..T (T=4):
    R     = 读(Z, s_{n−1}, k=3)                       # 硬 top-3；k=1 禁止
    g_m   = clip((sim_m − ζ_补)/τ_补, 0, 1)           # 逐候选独立；Σg≠1；线性阈值
    m_n   = 叠([门(g_m, Z_{R.索引[m]}, 0)])
    s_n   = 归((1−λ_s)s_{n−1} + λ_s·叠([m_n, 符(s_{n−1}, c)]))
    直到 ‖s_n − s_{n−1}‖∞ < δ 或 n=T
读出 = 叠([门(g_m, Z_{R.索引[m]}, 0)])                # 不除 Σg
```
**禁止参数区**：`k=1`；`g` 跨候选归一；`τ_补≤1e-3`（饱和>0.9）；键含 `t/序号`；`K` 随 `t` 增长。
**必跑**：P2（冻结索引臂）、`k=K`+归一 sham（输出 cos>0.999 判同构）、完整 vs `T=1`（差<0.01 判装饰）。
**代价**：≈141k 乘加/拍（D=256, K=32, T=4，解析，`[未验证假设]`）；`Z`=32KB。

### 4.2 M6 provenance v2

```
键_t   = 绑(a_t, s_t)
e_t    = 绑(键_t, o_{t+1})                            # 存"键⊙值"
E     ← 归((1−η_E)·E + η_E·e_t)                       # 分布式叠加
ê_t    = 解绑(键_t, E)                                 # ★HDC 取值＝解绑；读只用于选槽
a_t    = clip(归一化内积(ê_t, o_{t+1}), 0, 1)          # 连续量，不二值化上报
ζ_源   ← 慢基线(a_t)                                   # 自归一，零人挑
W_self ← 归(W_self + η·门(自归一门,1,0)·外积(À,À))
主统计量 = AUC(a; 自源/外源)                            # 无阈值
```
**必须失败臂（5 条，缺一不报）**：①重复同键+i.i.d.结果 ⇒ `a` 随重复升 ≥0.30 ⇒ 判"归属=熟悉度" FAIL；②来源随机化（宿主随机、比较器不知情）⇒ AUC≤0.60 ⇒ 无 provenance FAIL；③解耦 `ê↔o` 配对 ⇒ 归属降 <0.05 ⇒ 查表 FAIL；④检索正确性：`读` 版取回准确率≈chance、`解绑` 版 ≥0.95；⑤阈值敏感性：PASS 不得依赖 `ζ_源` 具体取值。
**证据纪律**：`注入外源(允许=False)⇒0 变化` **不再作 provenance 证据**（结构平凡通过，`[源码读]`）。
**资源**：`E` 64KB；`W_self` D²（D=256: 256KB int32；D=1024: 4MB int32）+ O(D²)/自源步——**R1 T2 漏账，已补**。

### 4.3 M5 元认知 v2（解耦置信）

```
决策：ŷ = argmax(读出 @ o)            margin m = 得分(1) − 得分(2)
监控通道：c_t = f(内生标量)            # ★不是 m：用 预测误差 ε_t / 潜态残差 ρ / 双通道冲突度
主统计量：type-2 AUC(c; 是否正确)      # 无阈值、非参
辅助：meta-d′（只在 c 与 m 解耦时才有辨识力；若 c≡m ⇒ 声明 meta-d′≡d′，本判据不成立）
双分离 → 改"选择性损伤"：抑制 A ⇒ 一阶 Acc 降 ≤0.10 且 type-2 AUC 降 ≥0.10
```
**必须失败臂**：常数置信 ⇒ AUC≈0.5；打乱 `(c, 正确)` 配对 ⇒ meta-d′∈[−0.1,0.1]；oracle 上界必须显著 >0.5。
**诚实边界**：`[未验证假设]`——解耦置信是否真能与一阶表现分离，**未测**。

### 4.4 M7 潜态 v2（撤回能力主张）

```
L_0 = 归(符(A_t, B_t));  d = 叠([符(A_t,B_t), z_潜])
L_* = 迭代(L_0, d, T)                  # T 足够大；数值求解唯一不动点（定理 T1）
o_t = 归(叠([L_*, B_t])); 决策 = argmax(读出 @ o_t)
```
**保留的唯一主张（L3 因果）**：替换/扰动 `L_*` ⇒ 决策改变 ≥0.10（潜态在读出侧有因果地位）。
**明确不做**：不报 `n_t` 为"想了多久"；不用 `ρ_1`/`ε_self` 当难度代理（构造性同源）；不复用 `思核`。
**证伪三臂**：`T=32` vs `T=8` 逐位同（预期同）；置换 `L_0` 后决策相同率 ≥0.95（预期高）；外部难度 vs `n_t` 的 ρ<0.20（预期低）。
