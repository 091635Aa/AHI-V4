## 0. 旧判据为什么必须重做（先把无效性写死）

### 0.1 裁① 的形式化：旧 must-fail 的两条款互斥

旧 must-fail（蓝队 R2 PS2 口径）：*常数慢滤波臂须同时满足 `Acc_A≤0.62` 且 `J<0.10`*，其中 `J=ΔA−ΔB`（A 试次准确率降幅 − B 试次降幅）。

**蓝队 R3 实测**：常数慢滤波 `Acc_A=0.425≤0.62` ✓，但 `J=0.483>0.10` ✗ ⇒ 旧 must-fail 不被命中。

**为什么这是结构性的（合法实现变体分析）**：慢滤波族 `A_t=(1−λ)A_{t−1}+λc`（c=0.5 常数）中，`λ` 是唯一自由量：
- `λ→0`（A≈常数）：`Acc_A≈chance≤0.62` ✓；但 **A 是 A 类试次的唯一规则载体**，"扰动 A"对 A 类就等价于"扰动规则"，对 B 类则不是 ⇒ `J=ΔA−ΔB` 必然大（实测 0.483）⇒ 第二条款 `J<0.10` ✗。
- `λ` 增大（A 跟奖赏走）：`Acc_A>0.62` ⇒ 第一条款 ✗。
⇒ **不存在 λ 同时满足两条款**；即"用一条 must-fail 臂同时要求‘机制无效（Acc 低）’与‘机制无选择性（J 低）’"，在合法实现族里没有落点。**判据无效（不是机制失败）**——与蓝队裁①一致。

**结论**：改为 **两条独立臂**（各自单条款 + 各自 must-fail），再加一个 **单臂联合失败区**（一个合法变体同时让 PS 与 PV 两项不过）。**不允许再用"单臂双条款"的 must-fail。**

### 0.2 PS×PV 不可分离（蓝队 R3 实测，`[实测]`）

| 量 | 值 |
|---|---|
| 2×2 交互 | **I=0.478（>0.10，不可加）** |
| PV 关 / PS 冻 的损伤 | **0.416 ≈ 0.425** |
| PS 效应（PV 开 / PV 关） | 0.469 / **−0.009** |
| PV 效应（PS 活 / PS 冻） | 0.478 / **0** |

⇒ 两效应互为条件、共享同一通路 ⇒ **本轮只能报复合判据**（裁④）。

### 0.3 红队结构事实（必须写进判据，否则重蹈"高维自模型"叙事）

- **A 有效秩=3**：σ=[181.96, 34.49, 9.23, 1.06e-5, …]；`σ₄` 为量化噪声（`[实测]`，红队 R3）。
- **A 与 `P@[s−.5,(s−.5)²,1]` 最大差 4.77e-7 ＝ 半个 2⁻²⁰ 定点格**；3 维重建与真 A **逐位同**（`[实测]`）。
⇒ **256 维 A 实为"1 标量参数化的 3 维曲线"**。任何以"256 维/高维"为据的 PS 判据一律无效；`ε_self` 只能作这条曲线方向变化的读数（红队 M01 已降级为"未证明"）。

## 1. 持久自模型判据重做（两条独立臂 + 联合失败区）

> 全部用既有 V4 API 可测（`设自我态向量` / `模式="消融"` / `前向_双区室`），**不改件**；观测量都不含"256 维"前提。

### 1.1 臂 PS-A：中介/替换臂（必要性，单条款）

- **主判据**：`A←A′`（另一条轨迹的终端 A，同分布、逐元差 ≥2 格）后：
  `D_o`（拍级输出不同率，沿用裁②：拍级 1.0 与 L1∧L2 逐位同）**≥0.90**；决策翻转 `F ≥0.50`。
- **must-fail（常数 A 臂）**：合法实现变体＝既有 `模式="消融"`（`A=P@特征(0.5)` 常数，一行参数，不改件）。该变体的 A 与 x/t 无关 ⇒ 同分布取样只能取到**同一个常数** ⇒ "替换 A′"退化为**恒等** ⇒ `D_o=0.00`（精确）、`F=0` ⇒ **落入失败区**。
- **可失败性证明（P1 公理）**：存在合法实现变体（`模式="消融"`）使读数落到阈值外，且原因可证（常数分布的支撑为单点；任何 A′ 都等于 A）。**注意**：这不是同义反复——若有人把"替换"实现为"加噪声"，则不是本臂定义；本臂要求"同分布轨迹终端"。
- **阴性对照（防检测器虚高）**：`A←P@特征重建` 必须给出 `D_o≤1 元素` 且 `F≤0.02`（因 4.77e-7 ≤ 半格）。若重建导致大规模输出变化 ⇒ 检测器分辨率/实现有噪声 ⇒ 本臂 **INVALID**，不得用其读数判机制。

### 1.2 臂 PS-B：跨任务持久臂（充分性/F5，单条款）

- **主判据**：任务在 t0 切换后，从 `A_t`（t>t0）线性解码**切换前规则**；半衰拍 `t50` **≥10 拍**，且 A 的 lag-1 自相关 **≥0.90**。
- **must-fail（A 可重算臂）**：合法实现变体＝每拍 `设自我态向量(P@特征(x_t))`（仅调既有 API）。该变体的 A_t 是当前输入的确定函数 ⇒ 切换后立即只编码新规则 ⇒ 解码旧规则 ≤chance ⇒ **`t50=0`** ⇒ 落入失败区。
- **可失败性证明**：该变体无跨试次状态（构造性）⇒ 任何依赖历史的信息为零 ⇒ t50 必为 0；且它与 PS-A 不冲突（它可能通过 PS-A：A 变则输出变），这正是**需要两条独立臂**的原因。
- **F5 内建**：同表跑 F5 三臂——有状态 / 可重算（上式）/ 历史置换（打乱 A 的时间序）；PASS 需"有状态 − 可重算 ≥0.10"。

### 1.3 单臂联合失败区（PS 与 PV 同时不过）

**J-arm「历史清零」**（一个合法实现变体，同时清掉 A 与 E 的历史）：
```
每拍：A_t ← P@特征(x_t)          # 既有 设自我态向量，无历史
每拍：E_t ← 绑(键_t, o_t)       # 单事件，不叠加（=R3 的 可重算 臂）
```
预期与证明：
- **PS 项不过**：A_t 无历史 ⇒ PS-B 的 `t50=0`（**构造性证明**）；PS-A 可能过（不矛盾，见 §1.2）。
- **PV 项不过**：E_t 只含当前事件 ⇒ `ê=解绑(键_t,E_t)=o_t` ⇒ `a=cos(o_t,o_{t+1})≈0`（独立观测）⇒ PV 的 `AUC≈0.5 ≤0.55`。**此半边目前是「结构预期」，不是构造性证明**——它依赖"o_t 与 o_{t+1} 独立 ⇒ cos≈0"这一分布假设；**必须由 J-arm 实跑确认**（主控 P0-3 收口要求）。若实跑 AUC 不≈0.5，则 J-arm 的 PV 半失效，需改用"来源随机化臂"补联合失败区。
- ⇒ **单臂同时让 PS 与 PV 失败**（PS 半＝构造性；PV 半＝结构预期待实跑），且它是**合法实现**（只用既有 API，不改件、不新增算子）。
- **与 F5 的关系**：J-arm 就是 F5 的"可重算"联合版；F5 要求"有状态 − 可重算 ≥0.10"在**两个分量上都成立**，J-arm 若通过任一分量 ⇒ F5 被违反 ⇒ 联合判据 FAIL。

### 1.4 PS 重做后的四态

| 状态 | 条件 |
|---|---|
| **PASS** | PS-A 与 PS-B 都过，且阴性对照（重建）通过、F5 两条都过 |
| **FAIL** | 任一臂落入失败区（常数 A / A 可重算 / J-arm） |
| **UNDECIDABLE** | CI 跨阈值（bootstrap 下界 < 阈值 ≤ 上界），按 U 码登记 |
| **INVALID** | 阴性对照失败（重建引起大改）或 must-fail 未按预期命中（臂本身可失败性不成立） |

## 2. PS×PV 复合判据

### 2.1 2×2 设计与联合读数

- 行：PS 状态 `{活, 冻}`（冻＝`模式="消融"`，合法变体）；列：PV 状态 `{开, 关}`（关＝外源可塑/统一低可塑，合法变体）。
- 每格联合读数（**预注册**）：
  `Y = ΔA_sel + (AUC_PV − 0.5)`，其中 `ΔA_sel = Acc_A(主) − Acc_A(A 扰动)`，`AUC_PV` = PV 归属 AUC。
  （`ΔA_sel∈[0,1]`、`AUC−0.5∈[−0.5,0.5]`，同量纲；也可换成 z 分和，但**跑前一经选定不得改**。）
- 交互：`I = (Y11 − Y10) − (Y01 − Y00)`；**阈值** `I0 = max(0.10, 置换零分布 q95)`（提案）。
- 蓝队实测 `I=0.478` ⇒ 超过 I0 ⇒ **不可分离登记**。

### 2.2 复合主判据（只有联合 PASS 一个出口）

| 分量 | 观测量 | 阈值（`[提案]`，全部用 CI 下界，不用点估计） |
|---|---|---|
| 自模型（PS） | `ΔA_sel` / `ΔB` / `t50` | `ΔA_sel` 下界 ≥0.15；`ΔB` 上界 ≤0.05；`t50` ≥10 |
| 归属（PV） | `AUC`（去直流修订口径，见裁③） | AUC 下界 ≥0.75；标签置换上界 ≤0.55；统一低可塑臂 ≤0.55；`g_ext` ≤0.20 |
| 复合 | `I` 与联合失败区 | `|I|>I0` ⇒ 只能报联合；J-arm 必须同时低于两分量阈值（见 §1.3） |
| CI | 配对 bootstrap 1000 次（固定种子）；AUC 用 Wilson | 所有 PASS 用**下界** |

**联合 PASS** ＝ PS 两臂 ∧ PV 四臂 ∧ F5 两条 ∧ J-arm 双失败，且 `I` 已登记（不可分离）。缺一＝联合未证明。

### 2.3 禁止分项报 PASS 的硬写法（裁判可直接引用）

1. `|I|>I0` 时，**禁止**出现"PS PASS"或"PV PASS"的单列表述；只能写 **"PS×PV 联合通过/未通过（I=…，不可分离登记）"**。
2. **禁止**用一分量的 PASS 支撑另一分量（例如"PV AUC 0.9 ⇒ PS 成立"）；两分量必须同表报。
3. 必须同表报：`ΔA_sel / ΔB / t50 / AUC / J-arm 结果 / I 的 CI`；缺任一列不得判 PASS。
4. 只有一分量过 ⇒ 写 **"联合未证明"**，不写单项 PASS。
5. `|I|≤I0`（可分）才允许分项报——本轮实测 0.478，**不适用**。
6. 报告措辞模板（唯一允许）：`PS×PV 联合：{通过|未通过}；I={值}（{>|≤}I0）；PS 分量 {…}；PV 分量 {…}；J-arm {失败|未失败}；F5 {过|不过}。`

### 2.4 可失败性证明（两条分量 + 联合，逐条给"哪个合法实现变体落到失败区"）

| 臂 | 合法实现变体（不改件） | 预期读数 | 落失败区的证明 |
|---|---|---|---|
| PS-A must-fail | `模式="消融"`（常数 A） | `D_o=0.00`、`F=0` | 常数分布支撑为单点 ⇒ "同分布 A′"只能是自身 ⇒ 替换恒等（§1.1） |
| PS-B must-fail | 每拍 `设自我态向量(P@特征(x_t))` | `t50=0` | A_t 无跨试次状态（构造性，§1.2） |
| PV must-fail① | 统一低可塑（外源/自源同塑） | AUC≤0.55 | 来源不可分（no source signal） |
| PV must-fail② | 重复同键 + i.i.d. 结果 | `a` 随重复上升 ⇒ 判"归属=熟悉度" | E 叠加 ⇒ ê→历史均值 ⇒ 重复越多 a 越高 |
| PV 阴性对照 | 无门臂（g≡1） | `W_self` 必须改变（否则 INVALID） | closed=0 与无门=1.00 必须成对 |
| **J-arm** | A 重算 + E 单事件（§1.3） | PS-B t50=0；PV AUC≈0.5 | **PS 半＝构造性**（无历史 ⇒ t50=0）；**PV 半＝结构预期**（依赖 cos(o_t,o_{t+1})≈0，**待 J-arm 实跑确认**；不成立则换"来源随机化臂"补） |

> 三公理核对：以上每条都满足 **P1**（存在合法变体使读数越界）、**P2**（判据工具能被注入违规触发）、**P3**（区分机制存在 vs 必要——PS-A/PS-B 分别管必要/充分，J-arm 管联合）。

## 3. 与 F5 不可预演臂的关系（写死）

1. **F5 是复合判据的第三维**，不是旁证：PS-B 与 PV 都必须出"有状态 / 可重算 / 历史置换"三臂；联合 PASS 要求"有状态 − 可重算 ≥0.10"在**两个分量都成立**。
2. **J-arm 就是 F5 的联合可重算臂**（§1.3）；J-arm 若通过任一分量 ⇒ F5 违反 ⇒ 联合 FAIL。
3. 历史置换臂的阴性读数（`I` 不降）⇒ 判"共享通路"而非"两个独立机制"⇒ 仍只能报联合。
4. 红线：**不得**用"重算/查表/重放"通过任一分量（C10）；"常数状态"不作能力（S1）。
