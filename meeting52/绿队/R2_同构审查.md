## 1. 审查框架：什么叫"换个名字的注意力"

### 1.1 四级判据（L0–L3）

| 级 | 判据 | 能抓住什么 | 抓不住什么 |
|---|---|---|---|
| **L0 源码级** | 禁词子串 + AST + 导入白名单，扫描范围＝**引擎前向因果链的 import 闭包**（不是"本文件自扫"） | 真 exp/softmax/名字 | 改名；算子组合后的等价形态 |
| **L1 更新式级** | 写出一拍更新式 `f(s,X)`，问：∃`W_Q,W_K,W_V` 使 `f=softmax(sW_Q(XW_K)ᵀ)(XW_V)` 对任意 `X` 成立？分三档：**一般同构／极限同构（β→∞、硬 top-1）／非同构** | 形式等价 | "迭代但决策不变" |
| **L2 动力学级** | 把迭代的**离散部件**（跨候选选择/排序）与**连续部件**（逐候选独立门、残差系数）分离；比较 完整臂 / 冻结离散部件臂 / 单次臂 的**决策统计量** | 装饰性迭代；T 层硬注意力堆叠 | 读出侧因果地位 |
| **L3 因果级** | 替换/扰动/冻结内部态 ⇒ 输出分布是否改变；切断输入 ⇒ 行为是否退化 | 装饰性内部态 | 机制"是什么" |

**本件只做 L0–L2；L3 属蓝队/红队，不在本件越权。** `[纪律]`

### 1.2 三个必查守恒量（对应 T4 的攻击面）

1. **全局归一化**：是否存在跨候选的 `Σw=1`／`softmax`／可调温度 `β`（含 `β→∞` 的硬 top-1、硬 top-k）。
   —— 判据不是"有没有写 exp"：**任意正权重和都可由某个 softmax 重写**，所以真正要查的是①权重是不是**跨候选归一**、②权重的**函数形状**是不是指数族、③输出是不是候选集的**凸组合**。
2. **投影等价**：迭代结果是否只是"某个一次映射的数值求解"（见 §1.3 的 P1–P4）。
3. **位置编码 / 序列级 KV**：是否把 `t`、槽序、位置写成**键或特征**；是否有**随序列长度增长**的存储参与读出（固定码本是允许的，增长的不行）。

### 1.3 投影等价判据 P1–P4（可执行）

| 编号 | 判据 | 操作 | 通过线（提案，未测） |
|---|---|---|---|
| **P1 结构判定** | 若更新式中所有算子对状态都是**逐元素（对角）**的、且驱动与状态无关 ⇒ 唯一不动点 ⇒ **结构上等价单次投影** | 写更新式，逐项标"是否跨维混合" | 全逐元素 + 驱动不含状态 ⇒ 判 P1=是 |
| **P2 冻结离散件** | 冻结 t=1 的候选索引集，仅让连续门继续演化；比较 3 臂：`T=1` / `冻结索引` / `完整 T` | 同一输入集上算**决策**（argmax 读出）与 **margin** 的逐点对 | 若 `冻结索引 ≈ T=1` 且 `完整 ≫ 冻结索引` ⇒ 翻转全来自**离散重选** ⇒ 判"T 层硬注意力" |

> 千层丙1 已给出一次 P4 实例：完整（迭代=3、门控=ζ）与切断（迭代=1、门控=−1e9）**曲线逐点相同、最大斜率同为 2.656** `[实测]`（`meeting51/实施/证据_千层.md:67`；判据脚本 `判据_千层骨架.py:661-662`）。
> **但要注意丙1 测的是"召回判定（决策）"，不是状态**：`召回判定` 取 `argmax(重合强度(x_final))`（`算子_千层骨.py:640-643`）⇒ "逐点同"的准确含义是**决策对迭代不敏感**，不是"状态没变"。R1 把它读成"top-1 快照"，方向对但归因偏了——真正的病是"**决策统计量对迭代不动**"。`[源码读·解析]`

### 1.4 结构定理：为什么"迭代"在现算子集内不能造出"思考深度"

**定理 T1（逐元素-唯一不动点）** `[源码读·解析]` `[未验证假设]`（解析证明，未跑）
若一拍更新可写成 `s_{n+1} = 归((1−λ)s_n + λ·软限(W⊙s_n + d_n))`，且
(i) `软限` 逐元素、严格增、1-Lipschitz（`σ'∈(0,1]`）；
(ii) `W` 的各分量 = 1（默认 `W迭=ones`，`算子_能力核.py:139`）；
(iii) 驱动 `d_n ≡ d` 与 `s` 无关；
则每一维 `f_i(s) = (1−λ)s + λσ(s+d_i)` 严格增、`f_i(s)−s` 严格减、两端异号 ⇒ **唯一不动点 `s*`**，迭代单调收敛到 `s*`（定点量化下最多退化为 ≤2⁻²⁰ 的 1–2 格极限环，不影响决策）。
⇒ **没有多吸引子、没有分岔、没有路径依赖**：T 只决定"离 s\* 多远"，不决定"想出什么"。

**推论 T1′**：只用逐元素算子 + 固定驱动的"想更久"，其渐近决策 = 驱动的一个固定函数 ⇒ **等价单次投影**。任何把"迭代次数/思考拍数"当"思考深度"的说法，在这条路径上**不成立**。

**推论 T1″（二难）**：8 算子中，`绑/解绑/门/叠/归/迭代/符` **全部是逐元素**（`叠` 是"逐元素求和再逐元素缩放"，无跨维混合）；**唯一带跨维混合的是 `读`**（int64 内积 + 排名 + 选择）。
⇒ 要在迭代里产生"多不动点/路径依赖"，必须把 `读` 放进驱动；
⇒ 而 `读` 在 `k=1` 时就是 `β→∞` 的注意力/Hopfield 一步（C-1）；
⇒ **在现算子集内，"非逐元素动力学"与"非硬注意力"不可兼得。**

> 这条二难是本次审查最重的结构性结论。它把 M7 的正当定位限制为"读出侧潜态"（§3.7），也解释了为什么 R1 用"多候选叠加 + 残差迭代"给 M1 找出路——那正是唯一可能两边都不踩的窄路，但**必须用 P2 臂证明翻转不是由离散重选单独贡献的**。
> **诚实边界**：引擎里还有 `投影P`（D×D 固定随机阵）与 `读出`（2×D）这类容器矩阵，它们是**固定单次投影**（储层式，M10 引 Jaeger 2001 的正是这一族），不在 8 算子内，也不产生迭代竞争——本定理只约束"8 算子构成的迭代更新式"。

## 3. 逐条详审（实写更新式 → 判定 → 触发 → 禁止区 → must-fail → 整改）

### 3.1 M1 记忆钥匙（最重之一）

**实写一拍更新式（把 R1 的伪代码落到算子级）**

```
κ    = 绑(绑(o_t, ℓ_t), τ_t)                        # 键
s_0  = c                                             # 线索（可残缺）
循环 n=1..T (T≤4):
    R        = 读(Z, s_{n−1}, k=3)                   # 硬 top-3（argsort）
    sim_m    = R.相似度[m]  (m=1..3)
    g_m      = clip((sim_m − ζ_补)/τ_补, 0, 1)       # 逐候选独立线性阈值门，Σg ≠ 1
    m_n      = 叠([ 门(g_m, Z_{R.索引[m]}, 0) ])     # = W叠⊙Σ g_m·Z_idx
    s_n      = 归((1−λ_s)·s_{n−1} + λ_s·叠([m_n, 符(s_{n−1}, c)]))
    （停机：‖s_n − s_{n−1}‖∞ < δ）
记忆读出 = 叠([ 门(g_m, Z_{R.索引[m]}, 0) ])          # 用最后一轮的 g 与索引集
```

**L1 判定：条件（非同构只在窄区间成立）**
- `g` 是**截断线性**函数（不是指数族）、**逐候选独立**（无跨候选归一）、读出**不除 Σg** ⇒ 输出不是候选集的凸组合 ⇒ **不落在 `softmax(QKᵀ)V` 族**。这一点 R1 判对了。
- **但** `读` 的 `k=1` 分支是 `argmax` ⇒ 输出 = 单行 ⇒ **精确等于 `softmax(β⟨C,p⟩)C` 的 β→∞ 极限**（＝现代 Hopfield 一步，`[cite:13]` 红线形态）。R1 直接把 `读` 判"否"，漏了这一行（C-1）。
- 若 `k=K` 且 `g` 归一化，则一步 = 对所有存储模式做归一化加权求和 = **现代 Hopfield 一步**，无歧义。
- 迭代维：循环内 `读` 会**重新选索引**（argsort）⇒ 离散部件存在。若连续门 `g` 的贡献可忽略、翻转全来自索引集变化 ⇒ **T 步 = T 层共享参数的硬注意力堆叠**（比一步更明确地踩 C1）。

**L2 判定：条件（投影等价，未测）** — 必须靠 P2 分解臂判（§1.3）。千层丙1 的"逐点同"已给出一个**同形先例**：那里的迭代**只改状态不改决策**（`召回判定` 取 `argmax(重合强度(x_final))`，x 向已选槽移动 ⇒ argmax 不变 ⇒ 曲线逐点同）`[源码读·解析]`。

**触发条件**：见主表。**禁止参数区**：`k=1`；`g` 归一化；`τ_补` 使饱和 >0.9；键含绝对时间/序号；码本随拍增长。
**必须失败对照**：四条（主表）。
**整改接法**：①读出 `Σg_m Z_idx` 不归一；②保留线性阈值门；③**键去时间戳**（这是 M1 与"任意延迟恢复"自洽的前提——见下）；④必跑 P2；⑤把 `Σg` 分布与索引改写次数落盘，作为"到底改了什么"的证据。

**额外交付点（R1 未提）**：`κ=绑(绑(o_t,ℓ_t),τ_t)` 把**时间戳写进键**，与 M1 声称的"延迟 40/200/1000 拍凭线索恢复"**自相矛盾**：延迟后线索时刻变了，键里的 `τ` 就不同，检索不到同一槽。这不是小瑕疵，而是"记忆钥匙"能否成立的**设计级矛盾**。整改：键只保留内容字段（对象、看到的地点），时间只进优先级 `π`（"多久没被想起"），**不进键**。
**算力代价**：M1 新增 ≈4×(4·32·256+10·256)≈141k 乘加/拍（D=256，解析，`[未验证假设]`）；`Z`=32KB。**验证臂**：完整/冻结索引/T=1/`k=K`+归一 sham 共 4 臂 × 破坏率 6 档 × 2 种子 ≈ 48 次小运行（墙钟**未测**，远小于千层 8 分钟量级）。

### 3.2 M2 冻结槽位

**实写更新式**
```
写：z_j ← 归(λ_z·z_j + (1−λ_z)·S_t)，π_j ← 归(β·π_j + (1−β)·意外度_t)
解冻门：u_j = clip((归一化内积(线索, z_j) − ζ_解)/τ_解, 0, 1)   # 逐槽独立
广播：o_t ← 叠([o_t, 门(u_j, z_j, 0) for u_j>0])                # 项数可变，Σu 不归一
```
**判定：条件**。`u_j` 逐槽独立、无竞争、无归一 ⇒ **非同构**。但 `τ_解→0` 时 `u` 二元化 ⇒ 对"过阈槽集合"做**等权硬选择**＝ top-k 硬注意力（β→∞）。定点格 2⁻²⁰≈9.5e-7 ⇒ `τ_解 ≤ 1e-3` 区间内饱和风险高（提案禁止区）。
**投影等价**：不涉及（无迭代；单步门控）。
**触发条件**：槽间归一化；`τ_解→0` 饱和；只取 `argmax` 槽。
**必须失败对照**：归一竞争臂（差 <0.10 判同构变体）；饱和比例 >0.95 判硬选择；FIFO 对照（差 <0.10 判"缓存"）。
**整改接法**：广播 `叠([u_j z_j])` 不除 `Σu`；`K` 固定、禁止随 `t` 增长；延迟判据必须**同表**放 FIFO 臂（这是"槽 vs 最近 N 步缓存"的唯一可判方式）。
**可证伪预测**：`u` 饱和比例（默认参数下预期 0.1–0.4；>0.95 ⇒ 判硬选择）。**绝不能变成**：多槽归一化竞争；FIFO 广播；用槽容量当记忆能力。
**代价**：写 `O(D)`/拍，读 `4KD`（K=32）≈32k；存储 32KB（R1 数，`[未验证假设]`）。验证 2 臂。

### 3.3 M3 记忆连续性 / 优先级重放

**实写更新式**
```
π_j ← 归(β·π_j + (1−β)·意外度_t)
离线（无外部输入，按 π 降序取前 B 槽，重跑 T_replay 拍）：
E ← 归((1−η_E)·E + η_E·绑(φ_t, φ_{t+1}))
参考系：η_u = η_0·(1 − pro_u)
```
**判定：否（非同构）／是（**线性写入的代数等价**）**。
关键代数事实：`E` 的更新是**线性**的（`叠` 是线性叠加、限幅未触发时严格线性）⇒ 对同一事件重放 n 次 = 一次写入 `η_eff = η·Σ_{k<n}(1−η)^k` ⇒ **"重放"本身不产生新机制**；唯一的机制变量是**选哪些事件**（`π`）。所以：丙3 的 +0.027（`[实测]`）在结构上可解释为"均匀/无优先级 ⇒ 选样本≈随机 ⇒ 与无重放无差"。
**触发条件**：重放缓冲随 `t` 增长（序列级存储）；用次数/时长当自变量；重放接输出。
**必须失败对照**：均匀重放−无 ≤0.03；**同事件重放 n 次 vs 一次写 `η_eff`：`E` 逐位同**（若逐位同 ⇒ 我的线性分析成立，重放不是机制）；重放接输出 ⇒ 在线掉分。
**整改接法**：报告 `η_eff`；把"优先级选择"作为唯一自变量；离线账单列；`B` 固定。
**可证伪预测**：同事件重放 n 次与一次写 `η_eff` 逐位同（限幅未触发时）。**绝不能变成**：最近 N 步缓存回放；重放次数当巩固证据；重放改变在线输出。
**代价**：离线 32 拍量级（千层已单列）；`E` K=64×256≈64KB。验证 3 臂。

### 3.4 M4 持久自模型（慢态 + 二阶意外）

**实写更新式**
```
已有：A 慢态；o = 归(软限(A−B) + 符(A,B))；ε_t = 1 − cos(ĝ(S_{t−1},a_{t−1}), S_t)   （ĝ 是零梯度 NLMS 局部 delta 更新）
新增（旁挂）：ε̄ ← 归((1−α)ε̄ + αε_t)；ε²_t = |ε_t − ε̄|
```
**判定：否（非同构）／不涉及投影等价**。
**但本件要对 R1 的"EMA 冒充"提法做一处修正**：`ε_t` 来自**在学的 ĝ**（NLMS），不是滤波，所以"EMA 冒充自模型"这个罪名**打不到 `ε`**；能被 EMA 冒充的是 **`ε²`**——它按定义就是 `ε` 的 EMA 残差，**无法用"与常数 EMA 不同"来证明自模型**（那是同一个对象）。真正的自模型证据只有两条：(a) **冻结 ĝ 的 `W`（不学）** vs 完整；(b) **拷贝预测器** vs ĝ（文件头记载 ĝ ε≈0.58–0.64 优于拷贝 0.768 `[源码读]`，本队未复跑）。
**触发条件**：用 `ε²` 当自模型证据；抑制 A 同时压低全局活动。
**必须失败对照**：冻结 ĝ ⇒ `ε` 差 <5% ⇒ 装饰 FAIL；拷贝臂 ⇒ `ε_ĝ` 不优于拷贝 ⇒ FAIL；抑制臂只让一切掉 ⇒ 非选择性 FAIL。
**整改接法**：`ε²` 降级为"突变检测特征"；自模型证据用 (a)(b) 两臂；二阶量用**相对自身慢基线**；抑制臂同时报 `Acc_A/Acc_B`。另：`内核_真学习` 已有 `ε_self→b[1],b[3]` 的**内生偏置因果通路**（`AHI4/meeting39/实施/内核_真学习.py:89-96`）`[源码读]`，V4 的"扰动自我态⇒输出必变"臂可直接挂在这条既有通路上，无需新算子。
**可证伪预测**：冻结 ĝ ⇒ `max|Δε| ≥0.10`。**绝不能变成**：常数慢滤波冒充；独立"我"分类器；把 `ε_self` 当意识指标。
**代价**：`O(D)` 标量运算；验证 3 臂。

### 3.5 M5 元认知签名（type-2 ROC / meta-d′）

**判定：不涉及（测量件，不进更新式）**。唯一的"同构式"风险是**统计口径**：把连续 margin 用**人挑阈值**切成"高/低置信"再算准确率 = 人为阈值后的标签。
**整改接法**：主统计量用 **type-2 AUC（无阈值、非参）**，meta-d′ 辅助；**打乱 `(margin, 正确)` 配对臂**必跑（预期 `meta-d′∈[−0.1,0.1]`；若 >0.3 ⇒ 泄漏）；oracle 置信上界臂必须显著 >0；报告 2⁻²⁰ 量化对 margin 分辨率的影响。
**可证伪预测**：打乱配对后 `meta-d′` 落到 `[−0.1,0.1]`。**绝不能变成**：独立元认知分类器；调阈值至 PASS；一阶准确率冒充元认知。
**代价**：离线统计，零在线；存 `(m_t, 正确)` ≈8B/拍。验证 3 臂（常数/打乱/oracle）。

### 3.6 M6 provenance 比较器（最重之二）——"是不是人为阈值后的标签"

**实写更新式（R1 形态）**
```
ê  = 读(E_效果, 绑(a_t, s_t))                       # ★本件判：HDC 取值用错算子
a_归属 = clip(归一化内积(ê, o_{t+1}), 0, 1)          # 连续量
塑性门：W_self ← 归(W_self + η·门(a_归属,1,0)·外积(À,À))，仅当 a_归属 ≥ ζ_源
pro_u = 慢平均(a_归属)
```
**① 判定（注意力同构）：条件。** 比较器本体（余弦 + 阈值）**不是**注意力；但 `ê` 的检索用了 `读`，而 `读` 在 `k=1` 时是 β→∞ 硬选择（C-1）。若 `E_效果` 只有少量行，`读` 退化为"取最像的一行"＝硬注意力/最近邻查表。

**② 判定（"只是人为阈值后的标签"）：是——按当前写法，成立。** 四问逐条：
| 问 | 现状（R1 写法） | 判定 |
|---|---|---|
| Q1 `a_归属` 是内生的吗？ | 数值上由 `cos(ê, o)` 生成——形式上内生 | 形式内生，但见 Q2/Q3 |
| Q2 `ê` 真的是"预期"吗？ | **否**。`读(键, E)` 与"键⊙值"的行的内积 ≈ `Σ(W绑⊙键²⊙值)` = `Σ(W绑⊙值)`——**基本是值的均值（偏置）**，不是"该键条件下的期望" | **退化**。正确取值是 `解绑(键, E)` |
| Q3 来源标签由谁产生？ | 由**人挑阈值 `ζ_源`** 对连续量做二值化；且 `门(a_归属,1,0)=a_归属` 是连续增益，所以"外源 ⇒ W_self 逐位不变"**只在硬阈值打开时成立** ⇒ 不变性由阈值制造 | **是人挑阈值后的标签** |
| Q4 既有"外源 0 变化"能当证据吗？ | **不能**。`注入外源规则(允许=False)` 的实现是 `若塑=False` 直接跳过赋值（`AHI4/meeting49/实施/算子_两区室核.py:259-266`）⇒ "变化元素 0" **由代码结构恒真**，与比较器无关 | **结构平凡通过，须从证据表移除** |

**③ 判定（是否熟悉度伪装）：高度可疑** `[源码读·解析]`。因 `E` 是**叠加**（`E ← (1−η)E + η·绑(...)`），同一 `(a,s)` 键反复出现时 `ê` → 该键历史结果的**均值**；`a_归属 = cos(均值, 本次)` ⇒ **重复越多次，归属度越高**，与实际"是不是我做的"无关。这是"归属=familiarity"的标准伪造路径。

**④ 必须失败对照（5 臂）**
1. **重复同键 + i.i.d. 结果臂**：`a_归属` 随重复次数上升 ≥0.30 ⇒ 判"归属=熟悉度" FAIL（本件预测**会上升**）。
2. **来源随机化臂**（宿主随机决定自源/外源、**不给比较器标签**）：AUC ≤0.60 ⇒ 无 provenance FAIL。
3. **解耦 `ê` 臂**（用别的片段的 `o` 当预期，同样边际分布）：归属降 <0.05 ⇒ 比较器是查表 FAIL。
4. **检索正确性臂**：`读` 版 vs `解绑` 版取回"该键对应的 `o_{t+1}`"的准确率 —— 预测 `读` ≈ chance、`解绑` ≥0.95。
5. **阈值敏感性臂**：报 AUC（无阈值）；若 PASS 依赖 `ζ_源` 的具体取值 ⇒ 判"阈值制造的标签" FAIL。

**⑤ 整改接法**
1. `ê` 取值改 **`解绑(键, E)`**（标准 HDC：存 `e=绑(键,值)`，取 `解绑(键,e)≈值`）；`读` 只用于"选哪个槽/哪一行"，**不用于取值**。
2. 阈值改**自归一**：`ζ_源` 用 `a_归属` 的**自身慢基线**（与 `内核_自我回路` 的"相对自身基线"、`内核_真学习` 的 `ε>ε_slow` 同口径，零人挑）。
3. 主统计量用 **AUC**；报告 `a_归属` 的分布（双峰度）而不是只报二值门控。
4. **资源记账修正**：`W_self` 是 `D×D`（D=1024 时 8MB float64 / 4MB int32；D=256 时 512KB/256KB），且 Hebbian 写是 **`O(D²)`/自源步**（D=1024 ≈1.05M 乘加，约为该核每令牌基线 293k 的 **3.6 倍**）——R1 的 T2"新增状态 <200KB"**漏了这一项**。
5. 把 `注入外源(允许=False)` 从证据表移除或标注"仅证明分支结构"。

**可证伪预测**：重复同键 i.i.d. 结果 ⇒ `a_归属` 从 ~0.2 升到 >0.8（预测"上升"；不升则我的 HDC 分析被部分否证）。
**它绝不能变成什么**：由宿主/语义阈值产生"来源"标签；把重复出现当归属；只报阈值化二元结果；把"外源 0 变化"当 provenance 证据。
**代价**：`ê` 读码本 ≈4·64·256=65k 乘加/拍（可与 M8 共读）；归属度 `O(D)`；`E` 64KB；`W_self` `D²`（**R1 漏账**）。验证 5 臂。

### 3.7 M7 潜在推理（最重之三）——"潜态进读出"够不够

**实写更新式（R1 §M7）**
```
L_0 = 归(符(A_t, B_t))
d_t = 叠([符(A_t,B_t), z_潜])          # ★注意：d_t 不含 L_{t−1}
L_n = 迭代(L_{n−1}, d_t, 1)            # s ← 归((1−λ)s + λ·软限(W⊙s + d_t))
ρ_n = max|L_n − L_{n−1}|；ρ_n < δ 或 n = T_max(≤8) 停；记 n_t
o_t = 归(叠([L_{t*}, B_t]))；决策 = argmax(读出 @ o_t)
z_潜 ← 归(λ_q·z_潜 + (1−λ_q)·L_{t*})
```
**① 注意力同构：否。** 驱动是固定向量、更新全逐元素、无跨候选归一 ⇒ 不落在 `softmax(QKᵀ)V` 族。R1 判对了。

**② 投影等价：是（条件）——R1 完全漏了这一维（C-4）。**
由定理 T1：驱动 `d_t` **与 `L` 无关**、`W迭=1` 默认、`软限` 逐元素严格增且 1-Lipschitz ⇒ 唯一不动点 `s*(d_t)`，`L_n` 单调收敛。所以：
- `L_{t*}` 是 `(L_0, d_t)` 的确定性函数；**`t*` 只决定"离不动点多远"**；
- 决策 = `argmax(读出 @ 叠([L_{t*}, B_t]))` ⇒ 渐近上是 `d_t` 的**一次固定映射** ⇒ **等价单次投影**；
- 因此 R1 的预测"4 步 vs 1 步决策翻转率 ≥0.15"**可以被满足，但它不是诊断量**——它只证明"前几步有瞬态"，不证明"潜态在为推理服务"。
- 更糟：R1 的"步数-难度 ρ≥0.5"用了 `ρ_1 = max|L_1−L_0|` 作难度代理。`ρ_1` 就是**初值到不动点的距离**的度量；`n_t`（收敛步数）也是同一件事的函数 ⇒ **两者构造性同源 ⇒ ρ≥0.5 必然成立，毫无诊断力**。这是本件指出的**预测混淆**。

**③ 正确的判据（三条臂，替代"翻转率"）**
1. **收敛臂**：`T=32` 与 `T=8` 决策逐位比 —— 预期**逐位同**（⇒ 迭代只是收敛）。
2. **置换 `L_0` 臂**（同一 `d`、不同初值）：足够步数后决策相同率 —— 预期 ≥0.95（⇒ 思考被抹平，结果与起点无关）。
3. **外部难度臂**：`n_t` 与 **held-out 难度**（规则复杂度/边界距离，系统外定义）的 Spearman —— 预期 ρ < 0.20（⇒ "难度→步数"不成立）。
若三条都按预期 ⇒ **M7 不能声称"潜在推理"**，只能声称"读出侧潜态（单次投影的数值求解）"。

**④ 整改接法（诚实的两条路）**
- **路 A（推荐，退回诚实定位）**：保留 `o_t=叠([L_{t*},B_t])` 作为**读出侧潜态**（有 L3 干预臂即可，属"潜态进读出"的正当实现），把"潜在推理"这个**能力主张**撤掉，改称"潜态读出通路"。
- **路 B（要真动力学）**：必须让驱动依赖状态并产生**多不动点**。按定理 T1″，唯一可用的跨维混合算子是 `读` ⇒ 只能把 `读` 的**逐候选独立门**（非 argmax）放进驱动；**而且必须同时跑 P2 冻结索引分解臂**，否则就是"T 层硬注意力"。若做不到，M7 就停在路 A。
**⑤ 可证伪预测**：收敛臂逐位同（差 0）。**⑥ 绝不能变成**：固定深度堆层；渐近收敛步数当"想了多久"；用 `ρ_1`/`ε_self` 当难度代理；复用 `思核` 的 softmax 门。
**代价**：+T·10D（T=8,D=256 ⇒ +20.5k 乘加/拍）；`z_潜` 1KB。验证 4 臂（T=1/8/32 + 置换）。

### 3.8 M8 工具闭环

**实写更新式**：`e=绑(绑(a_k,s_t),o_{t+1})`；`E←(1−η_E)E+η_E e`；`ê=读(E, 绑(a_k,s_t))`；`ε_tool=1−cos(ê,o_{t+1})`；`得分_k = 读出_任务@ê − λ_ε·ε_tool + 探索项`。
**判定：条件（`ê` 检索同 M6 的缺陷）／不涉及投影等价。**
**触发条件**：`E` 一动作一槽（查表）；观测只进日志（开环）；预写序列/流程树；外部时间戳/焦点进状态；动作次数当证据。
**必须失败对照**：切断观测 ⇒ KL <0.05 判开环；置乱观测 ⇒ 动作改变率 <0.50；预写序列臂 held-out ≤ random+0.10；**抑制 `ε_tool` 臂**：若抑制后仍重规划 ⇒ "误差驱动"为假。
**整改接法**：`ê` 改 `解绑`；`E` 必须分布式叠加；闭环口径只认"观测进入下一动作**条件分布**"；"失败即回退上一冻结槽位"是**固定控制律**⇒登记为待替换的焊死件（不是学习）；外部件进 C13 用记录-重放并计入资源账。
**可证伪预测**：切断观测 KL ≥0.20（否则开环）。**绝不能变成**：写死流程树；把回退当学习；动作次数当证据。**代价**：`读(E)` 65k + `O(动作数·D)`；`E` 64KB。验证 3 臂。

### 3.9 M9 确定性（记录-重放）

## 4. 专项 A：全局归一化审计（Σw=1 / softmax / 温度 / 硬 top-1）

> 判据：**不是"有没有 exp"，而是①跨候选归一、②权重函数是否指数族、③输出是否凸组合**。三问全"否"才算逃出归一化红线。

| M2 解冻门 | 否 | 否 | 否（项数可变） | **非同构**；`τ_解→0` ⇒ 硬选择极限 |
| M3 重放 | 不涉及 | 否 | 不涉及 | **否** |
| M4 慢态 | 不涉及 | 否 | 不涉及 | **否** |
| M5 元认知 | 不涉及（离线统计） | 否 | 不涉及 | **否** |
| M6 比较器 | 否（单对余弦） | 否 | 不涉及 | **否**；但 `ê` 的 `读` 是 β→∞ 选择 |

**两条现状件的处理**：
1. **千层 `解冻()`**：`算子_千层骨.py:308-324` —— 阈值 `ζ` 只用于**限制候选集**，随后 `k = argmax(强[选])` 取**单槽**、`x ← 0.5x + 0.5·Z_k`。这就是 β→∞ 的硬注意力一步 + 残差，迭代 T 次。**这解释了丙1 为什么逐点同**：决策统计量是 `argmax(强(x_final))`，而 `x` 是向**已选槽**移动 ⇒ argmax 不变 ⇒ 决策对迭代不敏感（注意：这是"决策不变"，不是"状态不变"）。⇒ R1 的 C-2 修正：改成"多候选叠加 + 逐候选门"是**正确方向**，但必须用 P2 分解臂证明连续门确实在改决策。
2. **思核 `_相对门()`**：`内核_相空间算子T.py:90-111` —— `权重 = exp(β(cos−c̄) − κh)/Σ`，`β门控=4.0`（有限温度）。这是**真 softmax、Σ=1**；共振场 = `γ共·共模 + Σ_j g_j·门_j·cos_j·v_j` ⇒ "softmax 门控 × 固定方向向量"的一步。**不构成序列注意力**（方向集是固定的动作自由度，不是序列 KV），但**保留了 T4 明列的全局归一化**，且默认开关全开（`内核宿主.py:53`）时它在跑。**它到输出的路径是"措辞级旁挂"而非"判据级因果"**：`z` 只 `迹.append`（`内核_相空间算子T.py:237`）；`迹` 的**条数**被 `输出层.py:307` 当措辞条件、`内核态()` 报 `最近站` 供展示，`z` 不进动作决策。⇒ 判定仍是"是（条件）"，但**不必**以"它在跑=已违规"来处理；必须登记的是"**它一旦被接进读出/动作就是一步 softmax 注意力**"。
3. **判定口径**：**是（条件）**——方向集为固定动作基时不算序列注意力；方向集换成记忆模式集即 = 现代 Hopfield 一步。C1 源码级口径必须覆盖"默认开启 + import 闭包"，否则 `算子_能力核.py` 的**按文件自扫**会报命中 0 而漏掉这一处（`禁词自检(路径=__file__)`，`算子_能力核.py:415-423`）。

**四件套 A**
- **主张**：R1 的同构判定表在"极限/归一化"两处有系统性漏判（C-1、C-3），且现状件已有两处实际踩线。`[源码读·解析]`
- **证据**：`算子_千层骨.py:308-324`、`算子_相空间算子T.py:90-111`、`算子_能力核.py:214-247`、`内核宿主.py:53,67-75`；`证据_千层.md:67`（丙1 逐点同、斜率 2.656）。
