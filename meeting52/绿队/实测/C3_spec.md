# C3 spec · M1 决策统计量候选（只写定义与预注册；不实现驱动）

> 依据：主控 2026-10-17 批准（C1 排除后，M1 重设计顺序改为 **C3 优先**）。
> 事实基础（R3）：C1 测试段 **状态差 0.516** 而 **决策翻转 5.5%**；无门臂与直接检索同值 ⇒ **决策统计量对 s 演化不敏感**。
> 本 spec 只定义“观测面”；驱动（C1/C2/C4）不动。落盘：本文件；单臂结果另存 `C3_结果.json`。

## 0. 一条先写死的定理（决定候选边界）

**若 `score_j = f(⟨s, Z_j⟩)`，其中 `f` 严格递增且不依赖 `j`，则 `argmax_j score_j ≡ argmax_j ⟨s, Z_j⟩`。**
⇒ **“去归一化 / 尺度归一 / 绝对值缩放”单独使用是恒等变换，不可能改变任何决策**；把它们列为候选只能得到“与 S0 逐位同”的阴性结果。
⇒ C3 的候选必须是**跨候选非线性**（把 `s` 与 `cue`/候选模式绑定/残差/门控），否则 C3 在数学上被排除。

## 1. 候选定义（S0＝现行基线）

| 代号 | 定义 | 为什么可能改变决策 | 预期失败值（先写死） |
|---|---|---|---|
| **S0 基线** | `argmax_j ⟨s, Z_j⟩/D` | —（对照） | — |
| **S1 与 cue 重合** | `score_j = ⟨符(s, Z_j), cue⟩ / D`（符=逐元素乘；= `⟨s, Z_j⊙cue⟩/D`） | 分数几何从“s 与模式的相似”换成“s 经模式过滤后还能解释多少 cue” | 若 `翻转(S1,S0) <0.02` ⇒ S1 与 S0 等价 ⇒ 该统计量无效 |
| **S2 残差读出** | `score_j = ⟨s − cue, Z_j⟩ / D` | 只读“补全相对 cue 的增量”，对 s 的移动方向敏感 | 若 `翻转(S2,S0) <0.02` ⇒ 增量不可读 ⇒ 无效 |
| **S3 margin 门控回退** | `margin = score_(1)−score_(2)`；`margin<θ` ⇒ 回退到“cue 直接检索”，否则用 S0 | 低置信时换观测面；**保证**在低 margin 子集改变决策 | 这是**组合器不是机制**（只是两个现成读数之间切换）；不得据此宣称补全 |
| **S4 绝对相似度+阈值** | `score_j=|⟨s,Z_j⟩|/D`；`max score<τ_s` ⇒ 弃权/回退 | 符号不敏感 + 低相似时弃权 | 对双极模式 `|·|` 会折叠正负 ⇒ 预期召回下降；若召回不降 ⇒ 任务无符号信息（U7） |

## 2. 预注册判据（任一候选要 PASS 必须全过）

1. **召回**：`S_x` 召回 ≥ `S0` 召回 **+0.05**，且 ≥ **直接检索 + 0.05**；
2. **迭代可见**：在 `S_x` 下，**翻转 β vs α ≥0.15**（全样本）／**≥0.20**（近平局，γ margin 最低 10%）——统计量必须让“多步状态”进入决策；
3. **统计量真改**：`翻转(S_x, S0) ≥0.15`（否则只是换名）；
4. **随机槽**：`S_x` 召回 ≤0.25；
5. **尺度不变自查**：`s→2s` 后决策必须**逐位同**（若变 ⇒ 实现 bug，非机制）；
6. **must-fail**：随机统计量臂（每 j 随机分）召回 ≈ chance（K=8 ⇒ 0.125±0.05）；**不得用“无门臂”**做门控 must-fail（方向型统计量对缩放不变，见 §0；C1 已证该臂 INVALID）。

**四态**：全过＝PASS；`翻转(S_x,S0)<0.02` 或召回 ≤直接检索 ⇒ FAIL（该候选排除）；其余＝UNDECIDABLE。**不做“调参到过”**：S_x 无参数；S3/S4 的 θ/τ_s 只在验证段选。

## 4. 它绝不能变成什么

- 不得变成“对 `s` 的任意单调变换”（数学上无效，§0）；
- 不得用 S3 的“低置信回退”冒充补全（组合器≠机制）；
- 不得把“换了统计量后决策变了”当“补全有效”——必须同时过召回与迭代可见两条；
- 不碰 softmax/归一化权重（C1 红线不变）。
