# S2-A 听测包（无视频 · 音频独臂）· 听测说明

> **这不是「像人」验收，也不是可懂度验收**——是给耳朵的原始材料。按 `meeting67/08` 人耳标准，人耳终判要盲听 + 真人基线 + ≥2 听者；这里只备材料。

## 该听什么（按顺序问自己）

1. **能不能听出这是一句完整的话**（有起有落、有音节串），还是只听到噪声/嗡声？
2. **能不能听出是哪几个字**？能听出几个？
3. **平静/高兴/低落** 三档听起来是否真的不同（快慢/高低/亮暗）？
4. 自声 vs 最后那条**真人参考**：差在哪（音色/清晰度/自然度/节奏）？
5. 多句那条里，3 条新句子是不是比第一句差？（仪器读数：第一句 ASR CER 0.14，另 3 条 0.79/0.92/0.86——**第一句是运气好的个例**，别被它带偏。）

## 仪器读数（只作参考，不替代耳朵）

- ASR（Paraformer-seaco-large，离线仪器；C10）：自声-平静 第一句 CER **0.14**（几乎全对）；高兴 **0.62**、低落 **0.24**、加噪 5 dB **0.52**；另 3 条新句 **0.79 / 0.92 / 0.86**。
- ⇒ **一句话能说清、三句话说不清**：这说明当前音频线**句子依赖极强**，不是「已经会说」。
- 诚实边界：ASR 是代理，不当可懂度结论；真人盲听才算人耳终判。

## 边界

- 本包**不涉及视频**，也不能替代 S2-B（A-6 视听联动 / McGurk / 唇读）；那些**仍然未测**。
- 音频线 v0 是 `meeting66/67/68` 的既有件（v13 只读 ckpt → log-mel → Griffin-Lim），本次**未改**它，只调用。
