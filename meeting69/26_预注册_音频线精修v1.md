# meeting69 · 26 预注册：音频线精修 v1（去「电音」与「沙哑」）

> 写于 **2026-10-22 07:4x**（**先于任何精修读数**）｜ 母本：`24`/`25`（S2-A）、`meeting68/音频线_v0`
> 所有者 2026-10-22 听测反馈（逐字要点）：「前3段还是4段听得出来是什么声音，应该是我自己声音之类的。但是**第一电音很严重**，**第二沙哑非常严重**。这两个需要修复，并且**基本很难听出来**，要很难分辨。但是**后段需要精修**。」
> 本件把反馈翻译成可判读的修法：**电音 = 声码器（Griffin-Lim）相位伪影**；**沙哑 = 时域移调（librosa pitch_shift，相位声码器）伪影**；**难听出来 = 可懂度**（ASR 仅代理）；**后段 = 尾帧 padding/收尾**。

---

## 0. 目标（按所有者反馈定，不扩张）

1. **去电音**：电音来自 `mel→GL` 的相位重建，帧率 100 Hz（跳长 220 @ 22.05 kHz）处有强调制伪影。
2. **去沙哑**：沙哑来自 `librosa.effects.pitch_shift`（time-stretch 相位声码器 + 重采样）；**改为纯重采样移调（chipmunk）**，时长随率变化（高兴变快、低落变慢），彻底绕开相位声码器。
3. **提高可懂（方向）**：GL 迭代/momentum/时间分辨率 + 收尾处理；ASR 只作代理，**以耳朵为准**。
4. **后段精修**：GL 传 `length` 精确长度、尾部去静音、5 ms 淡入淡出。

## 1. 臂（全部确定性、CPU、只读 v13 ckpt；新件 `音频线_v1_精修.py`，不改 `音频线_v0`）

| 臂 | GL | 时间分辨 | 其它 |
|---|---|---|---|
| **A0** 对照 | 64 迭代 / momentum 0.99 / 固定种子 0 | 跳 220 | = v0 复现（应逐位复现 `产物/S2A/自声/平静.wav` 的 sha256） |
| **A1** | **256 迭代 / momentum 0.99** | 跳 220 | + `length` 精确长度 |
| **A2** | **256 / 0.99** | **mel 时间 ×2 上采样、跳 110** | + `length` |
| **A3** | **256 / 0.99** | ×2、跳 110 | A2 + **mel 3 帧中值平滑** + 尾静音裁掉 + 5 ms 淡入淡出 |

移调臂（只对高兴/低落）：
- **P0** = v0 `librosa pitch_shift`（对照，沙哑源）；
- **P1** = 纯 `scipy.resample_poly` 移调 ±3 半音（时长随率变化，无相位声码器）；
- **P2** = 不移调（只保留 快/亮/响），作兜底。

句子：原句（`今天天气很好我听见了自己的声音我想再说一遍`）+ 3 条多句（`早上起来我先看了看窗外的光` / `我不太确定这句话你听清了没有` / `如果听不清也没关系我再说一遍`）。

## 2. 判据（先写死）

| # | 判据 | 门槛 | 口径 |
|---|---|---|---|
| **F1** | 去电音 | 帧率调制比（90–110 Hz + 190–210 Hz 占 1–400 Hz 调制能量）**≤ 0.70 × A0** | 对 4 句平均 |
| **F2** | 去沙哑/更干净 | 浊帧 HNR 中位 **≥ A0 + 1.0 dB** | 自研 F0 轨迹 + 40 ms 归一自相关 |
| **F3** | 不伤可懂 | ASR CER **≤ A0 + 0.03** 且至少 1 句改善 ≥0.03 | ASR 仅离线仪器（C10） |
| **F4** | 决定性 | 两趟 wav sha256 **逐位同** | C13 |
| **F5** | 不破既有 | A0 与 `产物/S2A/自声/平静.wav` sha256 **相同**（复现 v0） | C14 |
| **F6** | 移调 | P1 的 F0 中位比 ∈ **[1.12, 1.26]**（+3 半音 ≈ 1.189）且 HNR **≥ P0 + 1 dB** 且 CER **≤ P0 + 0.05** | 高兴臂 |

**选择规则**：A1–A3 中取「满足 F1–F3」且**电音比最低**者为 v1 主臂；移调取满足 F6 的 P1，否则 P2 并在证据里写明「本版牺牲音高换干净」。
**判死（先写死）**：A1–A3 **全部** CER 劣化 > 0.10，或 HNR 全部低于 A0 ⇒ 停，回 v0，登记负结果，不调参硬凑。

## 3. 边界

- 本件只修**声码器与移调**，**不训练模型、不改 v13**；不宣称可懂/像人/人耳。
- ASR 只作代理；**最终以所有者耳朵为准**（听测包见 `产物/精修v1/听测说明.md`）。
- 「后段精修」只能修 GL 收尾与尾静音；若尾段退化来自模型 mel 本身，登记为**未修**并另立预注册。
