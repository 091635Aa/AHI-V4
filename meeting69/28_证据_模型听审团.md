## 0. 一句话

**四个独立模型一致判 v13 的输出「不是像人说话」**：Qwen3-Omni 直接说「像猪叫的怪叫声、明显电音和沙哑、像机器人」；CAM++ 判它与本人相似度只有 **0.13–0.23**（真人-真人基线 0.654）。
**决定性对照**：把**真人 mel** 送进**同一个声码器** → CAM++ 相似度 **0.9285**、Paraformer CER **0.0**、Qwen3-Omni 判「真人、正常童声、内容全对」 ⇒ **声码器无罪，病灶在 v13 声学模型输出的 mel**。
**已给出一条不外星人的路**：用真人录音的音节拼接 ⇒ Qwen3-Omni 判「**真人、声音没有不自然**」（电音/沙哑消失），CAM++ 相似度 **0.56/0.68**；但**内容还是乱**（Paraformer CER 0.76）——下一仗是拼接的选段与韵律。

**必须一起读的三件事**：
1. **Paraformer 会给假阳性**：它能从 v13 音频里解出字（CER 0.14），但 Whisper 全空、Omni 听成猪叫 ⇒ **单靠一个 ASR 判可懂会骗人**；上一轮「第一句 CER 0.14 不错」的判断，被听审团纠正了。
2. **CAM++ 是这次的硬指标**：真人-真人 0.654；v13 输出 0.13–0.23（≈不同人）；真人 mel→GL 0.93（同一人）。⇒ **模型 mel 丢了说话人身份**。
3. **v1 精修（A4/jitter）救不了**：CAM++ 从 0.145→0.145（没变），Omni 仍判猪叫 ⇒ 上一轮「电音候选」方向**被否证**，登记为负结果。

## 2. 决定性诊断：声码器无罪、模型 mel 有罪（`诊断_声码器保真.json`）

| 项 | 实测 | 含义 |
|---|---|---|
| 真人 mel → GL64 → wav：CAM++ vs 真人 | **0.9285** | 声码器保得住音色 |
| 真人 mel → GL2048 → wav：CAM++ vs 真人 | 0.7262 | 同上（A4 也不毁音色） |
| 真人 mel → GL64 → ASR CER（vs 原声） | **0.0** | 声码器保得住可懂 |
| 真人-真人 CAM++ 基线 | 0.654 | 0.93 高于基线，不是巧合 |
| 生成 mel vs 真人 mel：帧间变化比 | **0.376** | 模型 mel 只有真人 38% 的时间细节 |
| 生成 mel vs 真人 mel：时间方差比 | **0.184** | 只有真人 18% 的能量起伏 |
| 生成 mel vs 真人 mel：带均值谱差 | +1.2 dB（低 +2.0） | 偏亮/偏热，但不是主因 |

**结论**：v13 的 mel 是「被抹平的包络」——没有谐波、没有说话人细节、没有时间起伏。GL 只能把它渲染成「咕噜/哼哼」；这就是「外星人」的物理来源。

## 3. 顺手否证的三条捷径（负结果，照登）

1. **推理端 mel 增强**（逐带统计匹配 + 时间锐化，`实验_mel增强.json`）：CAM++ 0.145（原）→ 0.198（统计匹配）→ 0.148（+锐化）；仍远低于 0.65 ⇒ **事后修 mel 不够**。
2. **换 ckpt / 迭代轮数**（`扫_声学配置.json`）：v13 各 ckpt、v12、v6 的 CAM++ 相似度全在 **0.03–0.05** 量级；没有「换个权重就好」的配置。
3. **v1 精修（A4/jitter 15×↓）**：听审团判「仍像猪叫」⇒ **jitter 改善 ≠ 音色改善**。

## 4. 已走通的替代路线：真人音节拼接（`拼接声_v0.py`）

做法：用 `meeting66/产物/数据_对齐asr`（167 条、30 927 音节、逐音节 声母/韵母/调/帧数）+ `meeting67/产物/P2/对齐证据.json`（逐条 mel↔整条 wav 的整数帧偏移）→ 把真人 wav 按音节切开 → 对输入句逐音节检索（同调优先）→ 交叉淡化拼接。
**帧映射已证明正确**：按 npz 音节帧数重建整条 wav，与原音 **相关系数 1.0**。
**读数**：Qwen3-Omni 判「**真人、声音没有不自然**」（电音/沙哑消失）；CAM++ 相似度 **0.558/0.676**（≈真人基线）；Paraformer CER **0.762**（内容仍乱）。
**结论**：**音色/自然度这条路已经不掉进外星人**；现在还差「选段 + 韵律」——同调覆盖率、切点、能量/音高连续性。
