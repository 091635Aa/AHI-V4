## 2. 失败位置与根因（实现级诊断，不是「调参」）

**A-4（主臂 9.48%）**：焦点窗由 725 个候选窗的 `mean(ε)` 最大者选出；上一拍 **单格** max-ε 常是孤立尖峰，而 max-mean 窗落在「误差面较宽」的另一处。随机覆盖基线 = 窗面积/1024 = 3.125%，实测只有 9.48% ⇒ 窗口均值评分与 A-4 的「覆盖单格」定义**结构性不匹配**。
**A-2 突变（0/4）**：突变刺激在 1.0 s 同时含爆破（12 ms）、送气（20 ms）、元音起振（1.032 s 起）。100 ms 拍窗 [0.94,1.1) 内，元音起振的能量跃升使 max-ε 落在**低带**，爆破带的高频瞬态被淹没 ⇒ 焦点按规则去低带，不覆盖爆破带。**这是刺激设计与 A-2 定义的时间分辨率冲突。**
**A-5（信息臂）**：固定预测器 + 运行归一化下，重复音节的起始 s 全部饱和到 2.0 —— 零训练没有预测可塑（D7 的局部可塑在 S3），与 09 v1.1 的「降为信息臂」判断一致。

## 4. 诚实边界

1. S1 v1 用**合成 + 真实语音**，只判采样链结构/轨迹；**不测可懂、不测人耳、不测像人**；
2. A-4 的 9.48% 与随机 2.4% 均不含「每拍聚焦面积」假设差异（窗 32 格 = 3.125%）；主臂未超 sham 是 H0 的直接证据；
3. H6 的「每流 ε < 0.6×混合 ε」在同一 ε 场上按子集取均值，**数学上难以 <0.6**（本次 0.822）⇒ 该口径需在 S2 前重定义，本轮只登记；
