## 3. J4 修正：F0 估计器 v1（YIN 型；先写死，后跑）

| 项 | 值 |
|---|---|
| 输入 | **原始波形**（与 S0 同源；按 `03` §6.3「F0 靶在原始波形/合成真值上算」，不走 mel/场对齐，避开 meeting67/13 的 148/167 帧偏移坑） |
| 前置滤波 | 4 阶 Butterworth 低通 **1200 Hz**（因果 `sosfilt`，确定性） |
| 分帧 | 帧长 **40 ms**（85 Hz 时 ≥3.4 周期，S0 的 25 ms 只有 2.1 周期）、帧移 **2.5 ms**、**帧时刻 = 窗中心**（S0 用窗起点，斜坡段引系统偏置） |
| 预处理 | 每帧去均值；**不加窗**（YIN 差分函数加窗会因窗形失配抬高谷底） |
| 差分函数 | d(τ)=Σⱼ(xⱼ−xⱼ₊τ)²，τ∈[⌊SR/500⌋, ⌊SR/60⌋]=[44,367]（60–500 Hz），FFT 自相关实现（= E0+E1−2R，数值稳定） |
| CMNDF | d′(τ)=d(τ)·τ / Σ_{k=1..τ}d(k) |
| 选峰 | **第一个 < θ=0.15 的局部极小**；无则取 d′ 全局最小 |
| 细化 | 抛物线插值，δ 夹在 ±0.5 内 |
| 浊音判决 | 帧 RMS > max(1e-4, **0.05 × 该文件最大帧 RMS**) **且** d′(τ\*) < **0.35**；否则 f0=0（S0 的能量门 0.02×max 太宽，把起振/止振半静音帧判成浊音，是 6.93% 的主因） |
| 输出 | `t`（窗中心，秒）、`f0`（Hz，0=清音/静音） |
| 与 S0 件关系 | **只替换 `F0轨迹`**；滤波组/包络/压缩/事件层/场全部沿用 S0（保证 J1/J2/J3/J5 可比） |
| 确定性 | 固定 FFT/浮点路径；两趟 sha256 逐位同（G5） |

**为什么是这组参数**：θ=0.15、40 ms、CMNDF、抛物线插值是 YIN 的教科书默认组合，**未按 S0 真值逐个调参**；40 ms 与窗中心是「低至 60–85 Hz」与「斜坡段无系统偏置」的直接要求，不是拟合。

**已试并否决的替代**（写入 07 证据，不作通过路径）：**低带包络自相关**（S0 预注册 J4 字面写法）。设计期实测在冻结声调上相对 MAE **20–150%**、覆盖率 0.06–0.57：窄低频带半波整流后包络按 **2×载频**振荡（130 Hz 载频→260 Hz 包络），不携带 F0 包络周期性；把多带包络求和后 F0 周期性进一步被不同载频打散。故 F0 估计走波形 YIN，**表示是否保留 F0 由「场→F0 线性探针 R²」判**（S0 已 0.55，S0.1 不改该探针）。

## 4. J6 修正：三变体（先写死，后跑）

**J6 判据口径不变**（`03` §3 + S0 实现）：稳态元音 2 s（起于 0.2 s），`比 = mean(场[1500:1800]) / mean(场[200:300]) ≤ 0.5`。**窗口不改、阈值不改。**

| 变体 | 组合规则 | 时间常数 | 说明 |
|---|---|---|---|
| **V1 除式 5/100** | out = c / (a_f + a_s + h0)，h0 = 0.1·median(c)（按带） | τ_f=5 ms, τ_s=100 ms | **S0 现状**（对照组，不算新方案） |
| **V2 除式 5/200** | 同 V1 | τ_f=5 ms, τ_s=200 ms | 只变慢时常数（S0 `05` §3 列出的候选） |
| **V3 减式（v0 同形）** | out = max(c − (0.6·a_f + 0.4·a_s), 0) | τ_f=5 ms, τ_s=100 ms | v0 原形的组合规则（v0 原参数 10/200，此处按 D2 固定 5/100，**只换组合规则**，单因子比较；0.6/0.4 权重沿用 v0） |

**选择规则（先于读数写死）**：三变体全跑全报，按序筛：
1. **J6 比 ≤0.5**；
2. 选中变体重跑 **J1–J3/J5/J7 全 PASS**（J1 的 A2 MAE ≤5 且优于 A0 ≥3；J2 ≥0.90；J3 ≥0.75 且 ≥A0+0.05；J5 中位 ≤5、p90 ≤15；J7 两趟同且 RTF ≤0.5）；
3. 若多个满足，按 D2 亲和度 **V1 > V2 > V3** 选（越接近 S0/D2 原口径越优先）；
4. 若均不满足，取 J6 比最小者**登记 FAIL**，**不追加第四变体、不改参数**。

**信息登记（不作门槛）**：`稳态残余比 = 晚段均值 / 未适应压缩稳态均值`。若 V3 被选中且残余比 <5%，在 07 证据中明确标注「场在稳态段接近饱和适应（听而不闻）；S1 须以暂态/事件为主，稳态场不作主要载体」——这是**设计约束的诚实登记**，不是判死。

## 10. 设计期诊断披露（先于正式读数）

为把估计器与三变体**定型**（S0 的同一方法学边界：「估计器在实现期定型，判据阈值与判死预注册先行」），在写本预注册前用**冻结的 S0 刺激**做了设计期诊断：
- 件：`临时/诊断_S0失败模式.py` → `产物/S0.1/诊断_设计期.json`；
- 复现 S0 逐条误差：T1/T2/T3/T4 相对 MAE = **0.266 / 2.939 / 16.754 / 7.769%**（均值 6.93%）；误差集中在 0.287–0.33 s **起振帧**（25 ms 窗含半静音 → 估出 174–177 Hz）与 85 Hz 段 **173 Hz 倍频帧**；
- 三变体 J6 比：V1 **0.6517**、V2 **0.5929**、V3 **0.0807**（同 J6 窗口）；
- YIN 粗扫 30/40/50 ms：40 ms 无窗 θ=0.15 时冻结集 MAE ≈0.17%、覆盖 ≈0.63（正式值以 `判据_S0_1.py` 为准）。
**这些是设计期读数，不是 S0.1 正式读数**；正式读数只由 `判据_S0_1.py` 一次性产出（J4-G 刺激在其后生成、跑前未见读数）。

> **更正（2026-10-21T20:51，见 `11_更正_复核发现与S1前置.md` §2）**：上句「YIN 粗扫 40 ms 无窗 ≈0.17%」**不可核**——仓库内唯一存档的 `临时/诊断_S0失败模式.py` 给帧加了 Hann 窗，其 `产物/S0.1/诊断_设计期.json` 的 40 ms 中心逐条 MAE = 1.0108/1.4550/1.4850/1.0215%（均值 **1.24%**）。0.17% 来自**未落盘的交互式无窗扫描**，且与正式实现（无窗）一致、复核已独立复现。**本更正不改判据、不改 §4 变体选择规则**；后续只以 `判据_S0_1.py`/S0.2 的正式读数为准。
