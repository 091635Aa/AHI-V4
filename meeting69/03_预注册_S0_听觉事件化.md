## 4. 判死（无效即跳，不追加调参）

| 触发 | 动作 |
|---|---|
| J1 VOT MAE >10 ms，或 A2 不比 A0 好 | **停**：事件化在时间线索上不成立，回退「前端扩展 v0」 |
| J2 <0.80 | 停：事件层无法分开塞擦 |
| J5 边界中位 >10 ms | 停 |
| J7 非确定或 RTF>0.5 | 停：工程不可用 |
| G1 A0 全面不差于 A2 | **判「换表示」证伪**，登记并停（这比主臂过不过更重要） |
| G4 出现外部模型 | 停，作废 |

**灰区**：J1 5–10 ms 或 J5 5–10 ms → 限**一轮**事件重定位改进（不改门槛）；仍不过即停。

## 6. 诚实边界（预注册时声明）

1. S0 用**合成刺激**，只能判前端性质，**不等于自然语音可懂**；J3 的分类器是闭合式线性探针，不是「听见了」；
2. 合成刺激的声学参数是工程近似（源-滤波），与真实普通话有差；
3. F0 靶在原始波形/合成真值上算（不走 mel 对齐，避开 meeting67/13 的 148/167 帧偏移坑）；
4. 适应/掩蔽项是「方向与形状」判据，不是人耳阈值的精确复刻；
5. **不测人耳**（S0 PASS 后才按 `meeting67/08` 排 S2）；
