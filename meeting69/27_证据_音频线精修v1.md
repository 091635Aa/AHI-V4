## 0. 一句话

**三条可确证的缺陷已定位并修掉**（句中 50 ms 空洞、高兴 +3 半音的相位声码器沙哑、GL 收尾/长度）；**「电音」换了一个候选（A4：n_fft 2048）**，客观代理「浊帧周期性抖动」从 **0.147 → 0.0099（15×↓）**、ASR 持平或更好，**但「听起来是不是不电了」我判不了，只能由所有者耳朵判**。可懂度（多句 0.71–0.92）未改善——那在 v13 mel 层，声码器修不动。

**负结果（照登）**：
1. **GL 迭代 64→256 + momentum 不解决电音**：A1 与 A0 的 CER/jitter 无可测差别（句0 .191/.1493 vs .191/.1467；句3 反而 .857 vs .786）。
2. **mel 时间 ×2 上采样不稳**：句1 A2/A3 的 F0 中位掉到 **104.6 Hz**（应为 ~268 Hz，YIN 倍频错），说明波形出现次谐波结构，**不采纳**。
3. **谐波重合成 H 判死**：全部 4 句 + 高兴/低落 **CER = 1.0（ASR 空串/单字）**，jitter 虽低（0.048–0.080）但不可懂；按「不以判据好看替代可懂」原则**不采纳**。

## 3. F5（预注册的复现条款）——如实记 FAIL，附解释

预注册 F5 要求 A0 与 v0 平静 wav **sha256 相同**。实测 **不同**：`v0 32777c7d…` vs `A0 66171249…`；
**但**：长度相同（111 983 样本）、**最大样本差 1 LSB（1/32768）** ⇒ 同一波形，仅 16-bit 量化路径差 1 个最小量化级。**严格口径记 FAIL，实质为数值等价。**

## 4. v1 候选（听测包已备）

- **默认主臂 = A4**（n_fft 2048/窗 1024、256 迭代、momentum 0.99、精确 length、删错误停顿、尾裁+5 ms 淡入淡出）；
- **情绪移调**：默认 **P2（不升/不降调）**——高兴用 快/亮/响，低落用 慢/暗/轻；**P±1.5 备选**（CER 0.33 / 0.24），**P±3 保留但不建议**（CER 0.52 / 0.29）。
- **电音判断只能靠耳朵**：jitter 是「相位/周期性稳定」的代理，不是音色判据；A4 也可能被听成「更机器人」。听测包 A/B 就是为这个准备的。

## 5. 诚实边界

1. **不宣称「电音已修好」**——只宣称「换了一个在周期性稳定性上显著更好的声码器配置，且可懂不降」，音色好坏**待所有者耳朵**。
2. 可懂度（多句 0.71–0.92）**未修**：根因在 v13 mel 过度平滑（meeting66 已诊断），属声学模型层，需另立预注册（从零训练非 Transformer 声码器 / 改声学模型）。
3. ASR 只作离线仪器（C10），不回流；jitter/shimmer 是自研 YIN 仪器的读数，非听感判据。
4. v13 ckpt 与 `音频线_v0` 只读；新件无 torch/transformers 训练、无外部模型；C1/C9/C10/C13/C14 有效。
5. 若所有者听完判「A4 更电/更闷」：下一轮 P0 = **从零训练非 Transformer 神经声码器**（Conv1D 上采样 + 多分辨率 STFT 损失，2.7 h 语料；GPU 30–60 min 量级），或 **PSOLA/相位锁定重合成**；两条都必须先预注册。
