## 6. J4：GT 对齐、覆盖口径、以及「R² 到底测的是哪个场」

### 6.1 GT 对齐（配套，无错位）

- `F0轨迹` 输出 `t=(i·hop+W/2)/SR`（**窗中心**，W=882）；`J4_评估` 用 `np.interp(t−0.3, linspace(0,0.5,len(轮廓)), 轮廓)`，而刺激是 `静默(0.3)+元音(0.5)` ⇒ **窗中心 ↔ 元音内部时刻，配套正确**，S0 「窗起点 + 延迟 12.5 ms」的系统偏置已被消除（这正是 `06` §3 声明要修的）。
- 两处**残余小偏置**（都不影响判定）：① 场探针用 `arange(nf)*0.001−0.3`，而 1 ms 帧的真实中心是 `i·0.000998+0.0005`（偏 0.5 ms）；② manifest 的 220 点轮廓实际只跨 **0.4966 s**（末点 `50·219/22050`），却被 `linspace(0,0.5,220)` 映射到 0.5 s（**0.68% 时间轴拉伸**）。我把 ② 校正后重算：均值 MAE **0.168% → 0.220%**（略差，不是略好）⇒ **该偏置没有替估计器「美化」，结论不受影响**。

### 6.3 **实质问题：`R²=0.55` 测的是 `场未适`，不是选中的 V3 `场`**

| `场` **V3（选中工作点）** | **−0.6661** | [0.000, −0.932, −2.024, 0.292] |
| `场` V1 | −1.5652 | [0.000, −0.993, −4.472, −0.796] |

## 13. 风险、保留意见与 S1 前置条件

### 13.1 保留意见（必须在 S1 预注册里落字）

1. **`场` 不能当稳态谱/F0 载体**：V3 下稳态场 ~0（47.7% 恰为零）、F0 线性可读性 R²=−0.67。S1 若照 `07` §4① 写「并用 `场未适` 与 `场`」，必须明确 `场未适` 是**谱/身份**通道、`场` 只是**变化/惊讶**通道，并且给 `场` 的贡献设上限（否则 Ψ 会被 V3 的清零主导）。
2. **包络跨带泄漏**使「64 带」这一数字**名不副实**（等效谱分辨率被 22 带的一阶滞后抹掉，1 kHz 峰移到 1254 Hz）。修它会改变 A2 的**全部**读数（J1/J2/J3/J5 都可能动），因此只能**新预注册 + 重跑 S0/S0.1**，不能顺手改；修好前**不要**在任何对外表述里说「64 带 ERB 耳蜗场」。
3. **RTF 余量是噪声级**：同机同代码 0.337–0.48。S1 必须（a）固定 CPU 负载/固定重复次数取中位，（b）把门设成有余量（≥0.1）或（c）先优化 Python 侧的 `包络`/`适应` 循环（`包络` 现在还有一个 64 次的 Python 循环，可向量化）。
4. **J4 的语义**：F0 是**波形仪器**（S0 起就是），J4 的 PASS 只证明「同一波形估计器换实现后变准」；表示层的唯一证据是 `场未适` 的 R²=0.55，且它**不含任何场内部 F0 估计**。S1 若要「场内有 F0」，必须另立预注册（多带包络拍频/谐波梳），不能引用本 J4。
5. **J4-G 只覆盖同合成器轮廓/电平**（0.49% 很好，但不能外推到噪声/说话人/自然语音）。
6. **J6 判据在 V3 下退化**：建议 S1 前的任何复测都给 J6 加一条「场信息量下限」（如晚窗非零占比 ≥50% 或整体残余比 ≥20%），否则「减到零」就能过。

| §4 A-8「每拍增量耗时 P95≤33 ms，不含前端一次性分析」 | 与 J7 的 RTF 门解耦，**丙条对 S1 不阻塞**（但前端 60 s 批处理总时长仍受 0.46 的 RTF 影响） |
| §8 文件清单 | 纯新增，符合 C14 |

> **因此给出一条排期建议（不是判据）**：**先定包络，再跑 S1**。理由：修包络改 `场未适` ⇒ 改 Ψ ⇒ 改 S1 的每一个读数；若先用现状跑 S1 再修，`10_证据_S1` 的全部数字将在修复后作废、且"保拓扑/32 临界带"的解释两头不靠。若出于进度必须先跑 S1，则 `09` §9 必须显式登记「本 S1 建在『跨带抹平场』上，A-3/A-4 的带心解释受限，修复后需重跑」。
