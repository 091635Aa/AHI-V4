## 0. 一句话立场

**听觉不需要新范式，只需要换坐标**：把 meeting38 已验收的三件组织原语（**场码 / 误差场 / 采样链**）从「屏幕空间格」搬到「时频事件轴」，落成与视场**同构**的听觉通路；学习只发生在三处**局部**（事件账本、稀疏可塑、事件驱动自适应），主干编码**永不训练**——该训练的东西已在 v13 那条线被证否两次（AR 触顶 0.9647、flow 塌缩 ≈1.0）。

## 1. 既有架构可借 / 不可借

### 1.1 能直接当「听觉通路」组织原语的（有实测出处，不是类比）

| 原语 | 出处 | 在听觉里的用法 | 已知代价 / 约束 |
|---|---|---|---|
| **绑 / 解绑 / 门 / 叠 / 归 / 读** | `meeting41/实施/算子_能力核.py`（七原语） | 全部组合运算：`绑(时频原子, 事件码)`、`门(惊讶, 上拍场, 本拍场)`、`读(码本, 探针, k)` | 零新数学；meeting51 已证「零新算子」撑 1296 单元 |
| **特征码**（固定随机投影，按输入维度缓存，永不训练） | `共存态.py:106` | 事件三元组 `[log f_e, log a_e, log d_e]` → 1024 双极码 | 同构于 V1 随机投影（meeting38 §4 张力 A 裁定），非「AI 式」 |
| **束**（多数表决）+ **IVF / `_topk序`** | `共存态.py:131`、`fsw_kernel.py` | 保拓扑听觉场 `Ψ`；账本/流分离的候选排序 | **1/√K 串扰上限（≤~40 项）**，已撞四次；超限必须配 IVF；top-k 确定性破平 |
| **数轴** | `meeting32/声带.py`（只读复用） | 时间原子（20 ms 档）、通道原子（ERB 档）、时长原子 | 连续量→二进制码，零手工特征 |
| **两区室核 A/B + 第八算子「符」** | `meeting49/实施/算子_两区室核.py` | `符(听觉场, 自我态A)` = 「我发的声 / 别人的声」重合门强度（**只出遥测**） | **不回写 A**；A 只走奖赏，动它=污染 16 臂 0.894 口径 |
| **槽契约** | `共存态.py:527` | 单写者 + 独立锁 + **锁内只赋值不计算**；遥测走 `状态帧` | A1「最长写 <50 ms」不破；遥测进指纹 ⇒ 新增键**改旧指纹**，须新开 profile |
| **meeting68 的 z 与「自模仿=恢复」** | `meeting68/05_证据`（R² 0.76–1.00、插值单调、两趟 sha256 同） | 「自己的声音」的标注/遥测；S2 的 z→解码回路 | L1 失败、课程输直训（M2 FAIL）⇒ 只借机制，不借结论 |

### 1.2 只能作索引组织、**不得承重**

- **千层四轴（12×6×3×6=1296）**：可作听觉事件码的四路索引（通道/层/流/时档），但 **meeting51 已否证深度承重**：甲2 六档−一档迁移差 −0.004（需 ≥0.10）、戊2 轴C 拆后反升 +0.138、乙5 α 实时化撤回。**听觉不得假设「层数=能力」**。
- **meeting57 的离散锚点账本旁路**：P0 延迟召回 B=1.000 / C=1.000 / A=0.399 / S=0.064（双集同向）——这正是 §3.1 的直接先例；但 A 是固定码叠加、不是可训练 RNN 上界，**不得外推**。
- **`meeting68/实施/内生耳.py`**：手工 DSP + librosa mel 的**特征工程耳**，只可当**离线探针/靶**（F0、能量、语速），**不得当前端**——它正是本会议要质疑的那一步。

### 1.3 明确禁止项（写死）

1. **attention / 自注意力主干 / Transformer block / 第三方预训练权重 / 推理栈**（C1；meeting66 新解释只放开训练思路，不放开框架应用）。
2. **预训练语音编码器**（HuBERT / wav2vec / Whisper 类）当耳或当特征源——**这就是「AI 架构眼中的语音编码器」，要其功能、不要其架构**（C1+C10 双撞）。
3. **外部 ASR 当耳或当判据门**（C9；只作离线仪器，文本不得回流进脑→声回路）。
4. **log-mel 80 带当「耳」的唯一表示**：可留作**对照腿 A0**，不得作前端（`meeting67/13`：v13 预测 mel 已丢 F0，线性探针 0.1388 vs 真 mel 0.6496）。
5. **meeting67 器官线（声门/声道物理）不复活**：那是「造嘴」不是「造耳」，`meeting67/09` 已判死归档，本席不引用其任何实现件。
6. **不许把听觉接成 v13 的 mel 输入改进项**：会重演 meeting66 十几次负结果，并把听觉降级为 TTS 附属。

## 2. 「像人一样听」的架构定义

### 2.1 听觉通路数据流（**与视觉同构**，一拍 = 100 ms / 10 Hz）

```
波形 16 kHz（块 100 ms）
 ① 耳蜗前端：ERB 间隔 24 通道 Gammatone（4 阶 biquad 级联，系数固定）→ 半波整流
              → 压缩 x^0.3 → 每通道双时标 AGC（τ快 10 / τ慢 300 ms）→ 包络 E[24, 10]（帧 10 ms）
 ② 事件化：每通道 Schmitt 双阈（θ_on=μ+1.2σ, θ_off=μ+0.5σ，μ/σ 取因果 2 s 定长窗）
              → 上/下交叉 = 候选；±15 ms 跨通道相干合并 → 事件 e=(t_e, f_e, a_e, d_e)
              → 每拍 k-WTA 至多 8 个（破平：t 升序、通道升序）
 ③ 层级预测：3 层事件账本（事件级 20–50 ms / 音节级 150–300 ms / 短语级 1–2 s）；
              键 = 束(最近 3 个同层事件码)，值 = 束(该键后继码)；预测码 = top-1 键的值；ε_ℓ = 1 − cos(预测, 实际)
 ④ 注意调制：焦点 f′ 上 argmax score = w1·ε + w2·显著度(能量/新异) + w3·意图偏置(谁在说/是不是我)
              − 抑制返回（按**时间不应期**衰减 0.97/拍，照视觉步3.6 修法）
 ⑤ 听觉场/惊讶：Ψ = 束_p( 绑(时频原子_p, 事件码_p) )（频率轴有序 ⇒ 保拓扑）；s = clamp(0.5·ε₁+0.3·ε₂+0.2·ε₃, 0, 2)
```

**每拍交出**：`(f′, s, Ψ)` + 事件增量表 = **（下一听觉焦点、惊讶、保拓扑听觉场）**，与视觉 `(g′, s, Φ)` 一一对应；**不是**「整段音频 → 音素/文字/embedding 列表」。

### 2.2 与视觉的逐项同构（「同级标准」的可操作含义）

| 维度 | 视觉（meeting38 已验收） | 听觉（本席方案） |
|---|---|---|
| 局部高分辨 | 中央凹 3×3 全分辨率 + 外周粗 | **焦点时窗 ±50 ms 全分辨率 + 焦点通道 ±2 通道细码**，其余粗 |
| 上行只传意外 | 误差场 `场_t ⊙ 场_{t-1}` | `ε_ℓ` 三层，只传超阈事件 |
| 主动采样 | 眼跳链（抑制返回 + 邻近偏好） | **焦点链**（时间不应期 + 频率邻近偏好），无变化不换点 |
| 适应/视而不见 | 视网膜光适应 + 注视保持律 | **AGC 增益 + 低惊讶不出事件**（事件率自然下降） |
| 保拓扑场 | `Φ ∈ R^1024`，位置绑定 | `Ψ ∈ R^1024`，**时频原子**绑定（频率序不丢） |
| 语义来源 | 亲历交互 + 可预测性 | 同：**能被预测 = 认得**；误差大 = 新异 → 投事件槽 |

### 2.3 「AI 式语音编码器」vs「内生听觉通路」

| 维度 | AI 式语音编码器（被否） | 内生听觉通路（本文） |
|---|---|---|
| 输入 | 整段 wav → 固定帧 mel（80×T） | 波形流 → 耳蜗包络 → **事件**（时刻+通道+强度，稀疏） |
| 采样 | 每 10 ms 均匀全帧，一视同仁 | **时频局部化、事件触发**；焦点加密、其余粗 |
| 上行 | 每帧 80 维全量上传 | **只传预测误差**；可预测段几乎不输出 |
| 时序 | 帧序列一次性编码 | **焦点链 + 事件链**（主动采样轨迹） |
| 表示 | 与任务无关的稠密向量 | 双极超向量（绑/束），**可解绑、可读出** |
| 语义来源 | 预训练标签 / 音素对齐 / 文本 | **亲历 + 可预测性**（零标签） |
| 学习 | 反向传播训主干（百万级参数） | **局部可塑 + 账本计数**（KB 级状态） |
| 产物 | 音素/文字/embedding 列表 | **（下一焦点, 惊讶, 场）** |
| 验收 | CER/WER 分数 | 冻结通道退化、跨说话人/语速、**未教组合**、sham、两趟逐位同 |

## 3. 学习机制（可执行、非 Transformer、零梯度主干）

### 3.1 预测编码：三层**事件账本**（纯绑/束/相似/读）

- 结构：`账本_ℓ = {键码: (值束, 计数, 最后拍)}`，`L=256 条/层`，3 层共 768 条；写：`值束 ← 束(旧值束, 新事件码)`、`计数 += 1`，满则按 `(计数↑, 最后拍↑, 键哈希↑)` 字典序淘汰（确定性）。
- 预测：top-1 键（相似度 argmax，破平 `(计数, 键哈希)`）→ `预测码 = 该键值束`；`ε = 1 − cos(预测码, 实际码)`。
- 读出：`读(账本值, 探针, k=4)` → 「这是什么」的候选（**不给人类可读标签**，只给相似度序）。
- 依据：meeting57 P0 的 B 臂（离散锚点账本）双集延迟召回 **1.000**、S sham **0.064** —— 账本本身有效，本席只把它放在听觉事件的键值上。

### 3.2 局部可塑：稀疏 **BCM**（新异时的后备预测器）

- `W` 稀疏字典（容量 16384 项 `{(i,j): w}`，初始空）；`y = sign(W·e)`。
- 更新（**只在 `s > 0.35` 时**，事件驱动）：`Δw_ij = η·e_i·y_j·(y_j − θ_j)`，`η=0.01`；`θ_j ← θ_j + (y_j² − θ_j)/2000`（滑动阈值 τ=2000 拍）。
- 归一化：每行 `‖w‖₁ ≤ 1`（乘性），`|w|` 截断 1.0。
- **不做三因子门控**：meeting50 已实测「门控不优于常数 η」（1.48e-4 vs 8.8e-5，唯一 FAIL 臂），不重踩。

### 3.3 事件驱动自适应（AGC / 阈值 / 稀疏度，非学习）

1. **AGC 增益**：`g_c ← g_c·(1 + (目标RMS/E_c − 1)·0.02)`，只在事件边界更新 → 稳定输入下事件率下降（=适应）。
2. **阈值自适应**：`μ_c, σ_c` 用因果 2 s **定长窗**滑动（定长 = 无自适应步长，C13 安全）；**稀疏度自适应**：`k` 由当前活跃事件数决定（≤8），保证束叠加永不超 40 项。

### 3.4 无监督聚类 / 流分离（零外部模型，照视觉 BFS 先例）

- 当前 200 ms 窗上取 `24 通道 × 20 帧` 二值活跃图（`E > θ_on`），做 **4-邻域 BFS 连通**（照 `视场前端.在场者` 的 48 格 BFS 写法）。
- 流指派：连通团按**频率质心连续性**（|Δ通道| ≤ 3/帧）匹配已有流，最小距离 + 确定性破平；无匹配 → 新流 id（首次出现序递增，**无语义标签**）。
- 流分裂：某流内 `ε` 持续 >0.5 且连通图断开 → 分裂（=「两人同时说话先当一个流，再用预测误差拆开」）。
- **前端不用 F0/谐波性**（那是手工特征）；F0 只在 H1/P1 作**离线靶**（直接在原始波形上算，见 §7.1 的对齐坑）。

### 3.5 停止条件（拍数/计数驱动，无收敛判据）

1. 惊讶中位数连续 200 拍 <0.05 ⇒ `η ← 0`（适应完成）；
2. 新账本条目率 <1%/1000 拍 ⇒ 停止写（记忆饱和）；硬上限 `18 000 拍`（30 min @10 Hz），到点即停，**不看损失曲线**（meeting66：教师强制 val 不能选模型）。

### 3.6 C13 与「没教过也会」的保证方式

- **固定种子** `6900`：所有随机投影 = `(种子, 输入维度)` 决定的 `standard_normal/√dim`（与 `共存态.特征码` 同规则）；W 初始为空 ⇒ 无初始化随机性。
- **无自适应数值积分步长**：帧 10 ms 固定、IIR 系数固定、top-k 固定、**无 ODE/flow/随机采样次数**（正是 meeting66 flow 与 meeting51 丙1 的失败位置）。
- **无浮点不确定源**：排序用 `(值 float64, 索引 int)` 字典序或 `kind="stable"`；不做并行归约。
- **两趟逐位同**：事件表、`Ψ`、账本快照（按键排序后序列化）、焦点链四者 `sha256` 逐位同 + 指纹同。
- **迁移**（宪法第三条强制）：学习期结束后**冻结账本与 W**，只在未教条件上测（跨说话人/跨语速/未教拼接）+ sham，见 §5 H2–H4。

## 4. 与既有内核 / 视觉的接线（只追加，不改旧契约）

### 4.1 听觉槽（新结构，两条落法，推荐 a）

**(a) 独立工作区（首选，零触碰）**：新件 `听觉工作区`，自带 `_听觉锁` + `写听觉/取听觉`；字段：`波形环 deque[320]`（2 s）、`事件表 deque[256]`、`听觉场 float32[1024]`、`焦点 (t帧, 通道, 流id, 停留拍)`、`误差场 float32[1024]`、`逐事件意外 float32[8]`、`意外度 float`、`流表 dict`、`焦点链 deque[64]`、`拍号 int`、`账本条目 int`。
**(b) 若要进共存态**：`class 听觉共存态(共存态)` 子类，只加 `_听觉锁` 与 `写听觉/取听觉`，父类**一行不改**（照 `规则表征核(两区室核)` 先例），`isinstance` 与七路契约不受影响。
两法都让 `听觉前端.一拍` 的返回字段名对齐 `视场前端.一拍`（同名字段：`场/焦点/误差场/意外度`）。

### 4.2 与视场槽 / 自我态 A / 符 / 语义

| 对象 | 关系 | 硬约束 |

| 视场槽 | **只读** `取视场()` 的 `意外度/注视/注视链` | 不写；15 Hz 与 10 Hz 用**拍号取整**对齐（听拍=⌊视拍×2/3⌋），不引入新时钟 |

## 5. 可判据（全部可失败；阈值=建议值）

| # | 判据 | 通过门槛（建议） | 失败意味着 |
|---|---|---|---|
| **H1** | **冻结单通道退化**：冻结后去掉 1 个耳蜗通道（或置噪） | `cos(Ψ, Ψ全通道) ≥ 0.80` 且惊讶上升 `≥0.20`；缺通道的预测误差由账本 `解绑` 补回 | cos <0.5 ⇒ 前端只是「mel 式并联求和」，事件化是假的 |
| **H2** | **跨说话人 / 跨语速迁移**（冻结后） | H2a 未见说话人：事件预测误差 ≤ **0.5×sham**；H2b 语速 0.75×/1.5×（不变调）：事件命中率 ≥0.6（±30 ms），焦点跳率 ≤0.3 次/秒 | 与 sham 相等或更差 ⇒ 账本记的是录音室，不是听觉 |
| **H3** | **未教组合**（宪法第三条迁移臂） | 学过 A、B 的词内序列，未教 A+B：拼接点惊讶峰 ≥0.5；`读` 出 A 或 B 的相似 ≥0.5；**对照** B 时间反转 → 惊讶也高但 `读` 相似 ≤0.3 | 拼接点无峰 ⇒ 只是复读；反转也「读得出」⇒ 相似是长度伪影 |
| **H4** | **sham / 打乱对照（必须失败）** | ①键置换：H2a 增益消失（相对 ≤0.1）；②时间置乱（保谱打乱序）：事件率不变但误差不降；③静音/白噪：惊讶与「内容」互信息 ≈0 | 任一 sham 也「学会」⇒ 学习来自统计伪影，整条线判死 |
| **H5** | **确定性与成本** | 两趟 `sha256` 逐位同（事件表/Ψ/账本/焦点链）+ 指纹同；单拍 P95 ≤30 ms（10 Hz 预算的 30%）；代码审计：无 while 收敛、无 ODE、无采样次数依赖输入 | 任一不过 ⇒ 不进 S1（C13 不是「尽量」） |
| **H6**（可选，不作本轮门） | 流分离 | 两流交错 vs 单流：流数=2 且分离后每流误差 < 混合的 0.6 | 人耳终判按 meeting67/08 协议另立，本会议不给可懂度结论 |

## 6. 风险 / 失败模式（含历史同型证据）

1. **预测塌缩**（最高概率）：账本预测退化成「平均事件」，误差恒定、惊讶失去区分度。历史同型：meeting66 条件 flow 零起点塌到条件均值（mel std 0.84 vs 真 3.49）。防线：top-1 而非全束平均 + H3 的 `读` + H4 键置换。
2. **表示退化为 mel**：若事件码实际是「8 段包络拼接」，就是换写法的 mel，H1 必 FAIL。防线：事件化必须**双阈滞回 + 跨通道相干 + k-WTA**，且 H1 的补值只能来自 `解绑`，不许插值。
3. **学习不稳定**：BCM 无界增长/振荡。防线：乘性行归一化 + 滑动阈值 + 只在惊讶超阈时学 + η 退火到 0；H5 两趟同。
4. **与 v13 重复**：把听觉做成「v13 的 mel 前端」= 重复一条已触顶的路（v13 预测 mel 已丢 F0：0.1388 vs 0.6496）。防线：听觉**不接 v13**；S0 先测「事件码是否保留 F0」，R² <0.5 即前端不合格。
5. **算力 / 净资源**：24 通道 ×100 帧/s，每拍仅 ~8 事件 × 数次 1024 维绑束（可忽略）；但账本 `3×256×1024×4B = 3 MB` + 稀疏 W 40 KB → 触及 meeting38「净增 ≤10 MB」预算。防线：值束 int8 量化（int8 dot 误差 <1%）、L 降到 256/层，并在证据里登记净资源。
6. **并发与过度声称**：听觉 10 Hz 与视觉 15 Hz 双线程可能破 A1（最长写 <50 ms）⇒ **S0/S1 单线程**、锁内只赋值，S2 才谈线程；本线交付「事件化预测编码的听觉通路」而**不交付可懂度**，不复活器官线，ASR 只作离线仪器，无人类听测就不写「像人」。

## 7. 最小 S0 探针（≤1 天、能判死）+ S1–S2 + 命名

### 7.1 S0：**「事件化 vs mel 帧」表示对照 + 冻结通道退化**（编码 ~4 h、跑 ~2 h）

- **数据**：meeting68 用的 167 条 60 s（只读），`种子=6900` 确定性抽 40 条 × 5 s 窗；不新采、不改既有数据。
- **臂**：`A0` mel 帧（80×10 ms，现状基线）｜`A1` 耳蜗包络（24 通道 + 压缩 + AGC，**不事件化**）｜`A2` 耳蜗 + 事件化｜`A3` A2 + 三层账本预测（§3.1）｜`S` sham（A3 + 键置换）｜`M` 时间置乱（A3 + 保谱打乱）。
- **测**：`P1` 事件码是否保留 F0（靶 = **原始波形上直接算**的 F0 轨迹，线性探针 R²；**不走 mel 对齐**——meeting67/13 已实测 148/167 条 F0 帧偏移最大 1193 帧）；`P2` 同一条 5 s 播 5 遍，第 5 遍误差 ≤ 第 1 遍 40%；`P3` 冻结去 1 通道（H1 缩水版）；`P4` 未见说话人（120/20 + 另 10 条未见）`A3` vs `S` 误差比 ≤0.5；`P5` 两趟 `sha256` 同 + 单拍 P95 ≤30 ms。
- **判死（缺一即死，不追加调参）**：`P2` 不过 **或** `P4` 的 A3/S <2× **或** `P1` 的 R² <0.5 ⇒ 判「事件化预测编码不是听觉通路的承重机制」，**不启动 S1**，只把 A1 前端作对照件登记。
- **判活**：P1–P5 全过（P4 的 2× 最硬）⇒ S1。预注册 `meeting69/03_预注册_S0_听觉事件化.md` 写死臂、种子、阈值、判死条件与「只报一次」的集合划分。
