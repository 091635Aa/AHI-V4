## 0. 一句话立场
**「人耳等价」不是一个 WAV 的分数，而是两端同时成立：耳朵端（输入）必须是一条受注意调制的、时频局部化的听觉焦点链（可自动代理，但代理必须有阳性对照与 sham），嘴巴端（输出）必须过 `meeting67/08` 的盲听+真人基线（只能真人）；`08` 只锁了嘴巴端，本会议不补耳朵端，就等于用「说话像人」冒充「听觉像人」。**

## 1. 「人类等价听觉」的判据体系
### 1.1 五维：金标准 / 可自动化代理 / 能否代理
| 维度 | 人类金标准 | 可自动化代理（本仓能跑） | 代理失效条件（必须让位人耳） |
|---|---|---|---|
| **可懂度·安静** | 听者逐句转写 → CER；0–4 逐句评分 → M（`08` §3.3） | ASR（Paraformer-seaco-large，离线仪器）逐句 CER，同 `量具_v9.CER` | 合成音色/带宽偏离训练域（过度平滑、机械音）；ASR 分不清「像人但错字」与「像噪声」 |
| **可懂度·噪声** | 固定 SNR 逐句转写；测 SRT（50% 正确的 SNR,dB） | ASR CER(SNR) 曲线，SNR ∈ {+10,+5,0,−5} dB | **ASR 噪声鲁棒性 ≠ 人耳掩蔽**（无听觉滤波/掩蔽释放/glimpsing）；只取同向趋势，绝对值不采信 |
| **掩蔽（能量/信息）** | 掩蔽阈值、掩蔽释放、信息掩蔽（异语言/异说话人干扰） | 能量掩蔽可用自研滤波器组能量比**部分**预测；信息掩蔽无代理 | 只要涉及语义/语音相似性干扰 ⇒ 必须真人 |
| **流分离·选择性注意** | 竞争说话人下报告目标句；注意切换代价 | 轨迹级「焦点链」指标（§2）；sham=随机焦点/固定焦点 | 把「能分离两源」等同于「能选择性地听」；切换与抑制返回只能行为测 |
| **视听整合** | McGurk 幻觉率；对口 vs 错口可懂度增益；异步容忍窗 | 对口/错口两组 CER 增益（半自动）；按帧注入延迟测 CER 变化 | 合成视频不自然（嘴型/人脸伪影）⇒ 幻觉率归因错误；McGurk 只作信息臂 |
| **自然度 MOS** | MOS 1–5（`08`：≥3.0 且与真人差 ≤1.0） | **无有效代理**；F0/能量/谱统计距离只能当回归护栏 | 把内部 DSP 距离当 MOS；把低 CER 当自然 |
| **偏好/ABX** | 同句合成 vs 真人二选一（允许「分不出」） | 无代理 | 任何「用分类器判真假」的做法（C10，且循环） |

**结论**：可代理的只有**安静可懂度 + 结构类轨迹指标**；噪声、掩蔽、流分离、视听整合、自然度、偏好**只能真人**。代理只做「筛掉明显死的」，不做「证明像人」。

### 1.2 `meeting67/08` 覆盖了什么、缺什么
已冻结、本席**完全沿用**：S1–S12 只报 / S13–S18 只选不报；22.05 kHz、峰值 0.9、固定种子随机顺序、文件不带真假标签；≥2 听者（所有者 + ≥1 未参与开发）；`M_s ≥ 0.8·M_h`、听者 CER ≤ 真人+0.10、`MOS ≥ 3.0` 且与真人差 ≤1.0、≥一半听者判「像人/分不出」；ASR 只是离线代理，**反向以人耳为准**（§3.4）；缺环节即「不作数」；每次 ≤10 分钟；记录不得事后修改。

三条缺口（本会议必须补）：

1. **只覆盖输出语音，不覆盖听觉输入**：`08` 没有任何一条问「它听见了什么、漏了什么、把什么当成了一个流」。⇒ 一个只会「整段音频 → 音素/文字列表」的系统可以满分通过 `08`，却完全不是「像人一样听」。
2. **只有安静朗读单条件**：12 句、单说话人（SpeakerA）、无噪声、无竞争说话人、无异步视听 ⇒ 人耳最特有的能力全在覆盖之外。
3. **只有结果没有轨迹**：句级分数，无时序/注意/适应条款 ⇒ 无法与 `meeting38` V1–V5 同构，无法回答所有者「和视觉一致」。

### 1.3 本席口径增量（与 `08` 并列，不覆盖）
`M-O-*`（输出侧）= `08` 原条款，一字不改；`M-I-*`（输入侧，新增）= §5.3 五条 + §2 的 A-1..A-8；两套同时报、不合并，任一缺 ⇒ 整次「未完成」。

## 2. 与视觉评价同构：听觉的轨迹级判据
视觉已裁决「像人一样看 = 受注意调制的、注视限制的采样轨迹」（`meeting38` §0）。听觉对应物必须同构，否则「和视觉一样」是空话。

### 2.1 数据结构（新增「听场槽」，纯追加，形状对齐视场槽）
```
听场    : float32[1024]     # 保拓扑时频图（对数频率 × 帧，位置绑定，非音素列表）
焦点    : (带心Hz, 带宽倍频程, 持续拍)   # 连续量，非「检测到语音」
误差场  : float32[1024]     # 场_t ⊙ 场_{t-1}
意外度  : float ∈[0,2]      # 可直接喂情感因子层唤醒 A（与视觉同刻度）
逐格意外: float32[48]       # 6 频带 × 8 时隙
焦点链  : deque[64]         # [(t, 带心, 带宽, 意外度, 场指纹)]
```

### 2.2 判据映射（视觉原型 → 听觉判据 → 可测形式与门槛）
| # | 视觉原型（`meeting38` §5） | 听觉判据 | 可测形式与门槛 |
|---|---|---|---|
| A-1 | 像人-1 单帧决定性（输出依赖注视状态） | 同段决定性：同段音频注入两种历史（前 2 s 不同上下文/注意目标） | 焦点链前 5 拍 Jaccard ≤0.6，或带心位移 ≥1/3 倍频程；两趟同历史逐位同 |
| A-2 | 像人-2 变化优先 + 适应 | 稳态（持续元音/稳态噪声）vs 突变（爆破/新说话人） | 稳态第 3 s 意外 ≤ 第 1 s 的 40%；突变意外峰 ≥0.5 且 1 拍内焦点命中 ≥0.8 |
| A-3 | 像人-3 不依赖物体列表 | 无标签仍非平凡：不给音素/文本/外部标签 | 意外序列方差 >0.01；焦点链熵 ≥1.0 bit；空标签条件下不退化 |
| A-4 | 像人-4 误差驱动命中率 ≥0.80 | 上一拍误差最大的时频格被下一拍选中的比例 | ≥0.80（随机 ≈ 焦点格占比 0.05–0.15）；高分辨采样面积 ≤15% 时频格 |
| A-5 | 像人-5 预测编码收敛 | 重复音节/重复句第 k 次 vs 第 1 次 | 第 3 次意外 ≤ 第 1 次 40%；新旧可分 AUC ≥0.90 |
| A-6 | 联动-1 自上而下注意调制 | 视听联动：视觉目标（唇/手）使听觉焦点偏向对应声源 | ≥60% 在 2 拍内偏向；异步 ±120 ms 内成立，>300 ms 失效（人耳时间窗） |
| A-7 | 知道-1 马赛克对照（禁 OCR） | 禁标签对照：ASR/文本通道全断 | 有/无标签两条件下焦点链与说话人分离聚类一致率 ≥0.90；`import` 闭包无仪器模块 |
| A-8 | 工程-1/2 延迟/确定性/净资源 | 同视觉工程口径 | 单拍 P95 ≤33 ms；波形+链 sha256 逐位同；新增 CPU ≤12 ms/拍、显存 ≤10 MB |

**注意**：A-1/A-3/A-4/A-5 是不需人耳就能判死的结构门（S0 用，§7）；A-2/A-6/A-8 是回归护栏；**A-4 必须先跑 sham**——没有 sham 的「命中率 0.8」，在 6 带小空间里可能只是「总选能量最大的带」。

### 3.2 判死门槛
- 输出侧（`M-O`）：`M_s < 0.8·M_h` 或 `CER > 真人+0.10` 或 `MOS < 3.0` ⇒ 该候选**不得作「像人」宣称**；
- 输入侧（`M-I`）：A-4 命中率 `≤ sham+0.10` ⇒ **判死「像人一样听」的采样机制**（退化为整段特征提取）；A-2 适应比 `>0.80` ⇒ **判死适应**（等于每帧重算）；
- 仪器护栏不过（§4 任一）⇒ 不是判死，是**「未完成」**，不得引用为任何结论。

## 4. 自动化仪器边界
### 4.1 三条硬边界
1. **ASR 只能离线**：Paraformer-seaco-large 单进程离线仪器（C10）；生成/听觉路径 `import` 闭包不得含仪器模块；ASR 文本**不得回流**进脑→耳回路（C9 类比：把外部转写当「听见的内容」）。
2. **耳蜗前端/听场的一致性不得用外部模型证明**：任何「我们的耳蜗 embedding 与 wav2vec/HuBERT/ECAPA 相似 ⇒ 像人耳」都是 C10 违规且循环。一致性只允许三种证据：① 可复现参数表（滤波器组中心频率/带宽/Q、适应时间常数、AGC、hair-cell 半波整流+压缩指数）；② **真人行为阈值**（同刺激下人的掩蔽/辨别/异步容忍，来自 `08` 式听测，不是模型）；③ 内部两趟逐位同。
3. **禁止内部保号判据当优化目标**（v8.1 病灶）：可懂度/自然度代理只能筛，不能训。

### 4.2 仪器自检 S-1..S-5（每批前必跑，任一不过 ⇒ 本批未完成）
| # | 自检 | 通过口径 |
|---|---|---|
| S-1 | 阳性对照 | 真 mel→GL→ASR 对原始转写均值 CER ≤0.15；留 `T_h`（同段真 wav 的 ASR 转写）作参考（`meeting67/03` G-2） |
| S-2 | 静音 | 全零输入 → ASR 空串/近空串；前端 < −60 dBFS；焦点链长 ≤2（不得凭空产生非平凡链） |
| S-3 | 白噪 | 平稳白噪 → 适应比 ≤0.40（同 A-2 式）；链熵 ≥0.8（不得锁死单点） |
| S-4 | 打乱 | 帧级时间打乱 → ASR CER ≥0.9 或空串，但能量/谱统计与原件同（证明指标真的依赖时间结构）；频带置换作第二 sham |
| S-5 | 两趟逐位同 | 同输入同种子两次：波形、听场、焦点链 sha256 相同；JSON 除时间戳外逐字段同 |

### 4.3 口径冻结（防「同一 wav 两次裁出不同长度」）
静音裁剪阈值（`top_db`，如 `librosa.effects.trim(top_db=40)`）、分析窗/跳（25 ms/10 ms，`meeting68/实施/内生耳.py` 已冻结 551/220）、重采样方法与滤波器、峰值归一 0.9、参考文本来源（原始转写，不用 ASR 自转写）——全部写进预注册字段 3/8。沿用 `meeting67/03` §2 做法，不另立口径。

## 5. 人耳终判流程（≤10 分钟/次）
### 5.1 材料与分批（单批 ≤10 min，超时分批，不压缩单句）
| 批 | 内容 | 时长 |
|---|---|---|
| A 输出侧 | 合成 12 句 + 真人同句基线（S1–S12）→ 转写 + 0–4 可懂 + MOS + A/B | 6–8 min |
| B 噪声/竞争 | 6 句 × {+5,0 dB 白噪} + 4 句竞争说话人（同说话人干扰 0 dB） | 8–10 min |
| C 视听/异步 | 6 段（对口/错口/延迟 0/120/300 ms）判「是否对口」+ 2 个 McGurk 试次（信息臂） | 6–8 min |

所有条目：22.05 kHz、峰值 0.9（或统一响度）、同耳机同音量、固定种子随机顺序、不带真假标签；同句每批只出现一次（防学习效应），跨批只重复 2 句作一致性检查。真人基线：同说话人（SpeakerA）同句优先；不可得则同说话人同长度片段，并登记「非同句」为弱化口径（`08` §3.1/§5）。

### 5.2 听者与盲法
≥2 名：所有者 + ≥1 名**未参与开发**的听者；不给答案键、不训练、不听者间讨论；只做「写听到的内容」+「打分」；记录身份类别、设备、音量、顺序种子；记录追加写，不得事后修改。

### 5.3 判据（`M-O` 沿用 + `M-I` 新增）
| 编号 | 项 | 判据 |
|---|---|---|
| M-O-1..4 | `08` 原四条（M_s、CER、MOS、A/B） | 一字不改 |
| **M-I-1** | 噪声下可懂度 | 合成/真人在 +5 dB 的 M 比 **≥0.7**（比安静宽——噪声下人自己也掉） |
| **M-I-2** | 竞争说话人 | 目标句可懂 ≥ 真人 −1.0 分（0–4 制） |
| **M-I-3** | 视听整合 | 对口型相对错口型增益 ≥ 真人增益 **50%**；McGurk 幻觉 ≥1/2 听者（**只作信息臂，不作门**） |
| **M-I-4** | 异步容忍 | 延迟 ≤120 ms「对口」≥80%；300 ms ≤40%（人耳约 ±100–200 ms 窗） |
| **M-I-5** | 错得像人 | 听者转写错误类型与真人错误类型的混淆对重叠 ≥0.5（防「错成噪声」冒充「错成人」） |

不作数条件：听者 <2、无真人基线、非盲、擅自改协议、缺任一批（可分批但须同协议同种子）。反向：ASR 与人耳冲突 ⇒ 人耳为准，ASR 读数保留不删。

## 6. 风险与失败模式（含缓解，不许只列风险）
| # | 失败模式 | 为什么会出现 | 缓解（可执行） |
|---|---|---|---|
| R1 | **听者偏差** | 所有者是开发者，期望效应；外部听者仅 1 人 | ≥1 名未参与开发者；无标签随机顺序；跨批重复 2 句，同听者同句分差 >1 ⇒ 标记「不稳定」并降权 |
| R2 | **小样本** | 12 句 × 2 听者，CI 极宽；一句翻车改均值 | 报逐句 + bootstrap CI（1000 次）；n<12 只作方向；选择集扩到 12–18 句 |
| R3 | **合成视频不真实** | TTS 驱动嘴型/人脸伪影 ⇒ McGurk 失败可能源于视频 | 登记视频来源（真人/合成）；McGurk 只作信息臂；主判据用「对口 vs 错口增益」 |
| R4 | **代理与人类反向** | ASR 偏好过度平滑语音，人耳嫌机械；或反之 | 人耳前先跑并存档 ASR；反向立即以人耳为准（T-6）；累计 ≥20 句后才谈相关性，之前不报相关系数 |
| R5 | **把 ASR 噪声鲁棒性当人耳掩蔽** | 都是「加噪后 CER」 | 噪声/掩蔽/流分离一律人耳；ASR 只筛「明显全错」 |
| R6 | **前端自证循环** | 用另一个模型证明「像耳蜗」 | 只允许参数表 + 真人阈值 + 两趟一致；代码出现外部听觉模型即 C10 审计失败 |
| R7 | **所有者疲劳/排期膨胀** | 每门 3 批 × 10 min × 多门 | 只在 trigger（CER ≤0.60 或 S0 PASS）排期；每次 ≤10 min 可分批；同种子可复现 |
| R8 | **域差偷换** | 训练口语对话 vs 报告句朗读（`meeting67` §13-6） | 预注册写明域差；朗读/对话分列，不混算均值 |

## 7. 最小 S0 探针的评价脚手架（≤1 天，能判死）
**定位**：S0 只回答「这条听觉链到底是受注意调制的采样轨迹，还是伪装的整段特征提取器」。S0 不做人耳（PASS 后按 §5 排期），不判可懂度（归 `08`）；**S0 PASS ≠ 好听/听懂**，只等于「结构像人」，必须与 `08` 并列读。

### 7.1 自动最小集（单脚本 `实施/判据_听觉S0.py`，只读输入，不改既有件）
| # | 项 | 刺激（全部可合成、确定性） | 判死条件 |
|---|---|---|---|
| 1 | 确定性两趟 | 同输入同种子跑两遍 | 波形/链/场 sha256 不一致 ⇒ 未完成（T-4） |
| 2 | 适应 A-2 | 1 kHz 稳态 2 s + 爆破 + 新基频段 | 适应比 >0.80 ⇒ FAIL |
| 3 | 焦点命中 A-4 | 同上 + 随机焦点 sham | 命中率 ≤ sham+0.10 ⇒ FAIL |
| 4 | 决定性 A-1 | 同段 + 两种前史（静音前史 vs 语音前史） | 焦点链 Jaccard >0.6 ⇒ FAIL |
| 5 | 无标签 A-3 | 抹掉全部文本/音素输入 | 链熵 <1.0 bit ⇒ FAIL |
| 6 | 静音/白噪 sham | 全零、白噪 | 静音链长 >2 或白噪适应比 >0.40 ⇒ FAIL |
| 附 | 仪器 S-1..S-5 | 见 §4.2 | 任一不过 ⇒ 未完成（不作判死） |

预算：实现 3–5 h，运行 ≤10 min（无 GPU）；ASR 只在 S-1/S-4 用，≤10 次调用。

### 7.3 判死与「未完成」必须分开（本席最在意的一条）
- **判死** = 链在跑、仪器健康，但结构不成立（命中率≈sham、适应比>0.8、Jaccard>0.6）⇒ 这条听觉路线不成立，回退或换前端；
