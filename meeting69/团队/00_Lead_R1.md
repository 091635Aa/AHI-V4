## 0. 一句话

**像人一样听 = 一条受注意调制的、事件驱动的时频采样链：每拍输出（下一听觉焦点、预测误差/惊讶、保拓扑听觉场），而不是「整段音频 → 音素/文字/声学特征列表」。**

## 1. 与视觉定义的同构

| 视觉（meeting38 已裁决） | 听觉（本席提案） |
|---|---|
| 注视限制的采样（中央凹高分辨 + 外周低分辨） | **时频局部化的采样**（听觉中央凹 = 被注意的时间×频率窗；外周 = 全频段低分辨背景） |
| 眼跳链（主动采样序列） | **听觉焦点链**（主动听：把「听哪里」从一个时频区挪到另一个；对应选择性注意/鸡尾酒会） |
| 只传预测误差/惊讶 | **只传预测误差**（可预测的背景声/稳态元音 → 适应、几乎不传出） |
| 保拓扑视觉场 Φ | **保拓扑听觉场**（tonotopic × time 的场码） |
| 产物 = 下一注视点 + 惊讶 + 场 | 产物 = **下一听觉焦点 + 预测误差 + 听觉场** |
| 对稳定世界：适应、视而不见 | 对稳定声：**听而不闻**（稳态元音/空调声被适应掉） |

## 2. 前端（耳，不是 mel）

1. **耳蜗滤波**：ERB/gammatone 滤波器组，**64–128 带**，中心频率 **80 Hz–8 kHz**（语音关键区加权），每带输出复包络；
2. **毛细胞转导**：半波整流 + 幂律压缩（≈0.3–0.5）+ **双时间常数适应**（快 ~5–20 ms、慢 ~100–500 ms），产生「对稳态适应、对变化敏感」的听神经样响应；
3. **事件化**： onset/offset、能量突增、频谱通量峰 → **事件流**（时间戳+时频区域+强度），作为听觉场里的「惊讶源」；
4. **拒绝** log-mel/STFT 作为「耳」：它们是 10 ms 栅格 + 固定窗的**一次性全帧解析**，天然吃掉 <10 ms 的爆破/VOT/塞擦瞬态（meeting66/67 已实测的硬缺口同型）。

## 3. 听觉场与预测通路

- **听觉场**：tonotopic×time 的二维场（比如 64 带 × 当前窗 100–300 ms），低层用稀疏编码/HDC 保拓扑；
- **层级预测编码**（非 Transformer）：每层自上而下预测下一拍场/下一事件，误差向上；**惊讶 = 误差幅度**，可喂情感唤醒；
- **适应**：可预测成分被抑制（听而不闻），只有意外上行 —— 输出天然稀疏、事件化；
- **焦点选择**：按「惊讶 × 任务相关」选下一时频焦点（例如：先盯住低频浊音段、切到高频擦音段；或盯住一个说话人 = 听觉流分离）。

## 4. 多模态与视觉一致

1. **绑定什么**：onset/能量包络/节律 ↔ 视觉事件（唇开合、注视变化、屏幕动作）；语音特异线索（送气/浊音/唇形）本来就需要视听整合；
2. **何时绑定**：**事件共现 + 预测误差**驱动；时间窗先验 ~±100–200 ms（[待核] 具体值由 S1 标定）；
3. **怎么学**：绑定权重/时延从共现统计/预测编码长出来（局部可塑），不用 Transformer/外挂模型；
4. **与视觉工程互操作**：视觉槽（视场/注视/误差场/惊讶）旁边**只追加**「听觉槽」（听觉场/听觉焦点/误差场/惊讶/事件链）；两槽通过共享时间戳与事件绑定器交互，**不改旧契约**（C14）。

## 5. 学习（内生）

- 预测编码（局部、无全局反传也可）+ 稀疏编码/Hebbian；
- 迁移判据：未见说话人/语速/噪声/未见视听组合仍可用（「没教过也会」）；
- C13：固定种子、固定步长、无自适应数值积分；同 ckpt 两趟逐位同。

## 6. 评价（人类等价）

- 轨迹级：听觉焦点链、惊讶序列、对稳定声的适应（听而不闻）；
- 人类级：临界带/掩蔽曲线方向、噪声下可懂度、听觉流分离、McGurk/唇读增益、ABX/MOS；
- **人耳终判**沿用 meeting67/08（盲听+真人基线+≥2 听者），但必须**扩到听觉输入侧**（噪声下、竞争说话人、异步视听），不能只测输出语音；
- ASR 只能离线代理（C9/C10）；耳的一致性不许用外部模型证明。
