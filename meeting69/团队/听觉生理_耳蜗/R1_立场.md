## 0. 一句话立场

**耳是受注意调制的时频事件流，不是频谱仪。**

展开：输入侧必须是**因果**的耳蜗式滤波器组 + 毛细胞转导 + 适应 + 确定性事件化；「像人一样听」= **时频局部化的注意力采样链**，不是「整段音频 → 音素/文字/谱特征列表」；与 meeting38「像人一样看 = 注视限制的采样轨迹」**同构**，且视听场同为 1024 维，可复用既有算子。

## 2. 对「像人一样听」的可操作定义

**2.1 定义（与 meeting38 同构）**：像人一样听 = **一条受注意调制的、时频局部化的事件采样链**；每拍输出 **(下一听觉焦点 g′_a, 预测误差/惊讶 s_a, 保拓扑听觉场 Φ_a)**，而**不是**「整段音频 → 音素/文字/声学特征列表」。听 =「带着预期去采一个时频窗 → 只把意外传上去 → 据此决定下一窗落在哪」。

视觉逐项对应：注视→听觉焦点（时频窗）；中央凹→焦点内全分辨带；外周→全带低分辨；眼跳链→焦点链；惊讶→意外度；保拓扑场→32×32 时频场（1024 维，与视场同宽）。

**2.2 三个时钟（缺一个就不像耳）**：

| 时钟 | 周期 | 承什么 |
|---|---|---|
| 耳蜗步 τ_c / 包络帧 | 62.5 µs（样本）/ 1 ms | 滤波、转导、适应、IF 发放；1 ms 包络是 S0 承重的一轨 |
| 注意拍 τ_a | **40 ms** | 焦点移动、场/误差/惊讶输出（音节率 4–8 Hz 的 5–10 倍过采样） |
| 事件拍 | 触发式（起音/瞬态可提前） | 不等 τ_a，这正是「事件驱动」 |

**2.3 每拍（τ_a=40 ms）输出四件**：① `g′_a` 下一听觉焦点 `(带中心 b∈[0,32), 带宽 w∈{1,2,4} 临界带, 起时 t, 时长 d∈{10,20,40} ms)`；② `s_a` 惊讶 ∈[0,2]（可直接喂情感因子层唤醒 A）+ 逐格意外 32×32；③ `Φ_a` 保拓扑听觉场 32 临界带 × 32 时槽（5 ms/槽，160 ms 窗）=1024 维 float32；④ 事件位：起音/清浊切换/双耳跳变，稀疏 `(t_µs, 带, 类型)`。

**2.4 「AI 式听 vs 像人一样听」对照表**：

| 维度 | AI 式听（被否） | 像人一样听（本稿） |
|---|---|---|
| 采样 | 整段音频一次性 STFT/80 带 log-mel，全帧同分辨 | **耳蜗带通 + 焦点时频窗全分辨 + 外周低分辨，逐拍移动** |
| 上行 | 全帧特征、音素后验、整段嵌入 | **只传预测误差（>θ 的格）+ 事件位** |
| 时序 | 固定 10 ms 帧、帧间独立 | **事件驱动（起音/瞬态）+ 40 ms 注意拍链** |
| 语义来源 | 外部 ASR/标签（C9/C10 边界） | **亲历共现（声↔视↔自身发声动作）+ 可预测性** |
| 产物 | 「音素序列 / 文字 / 谱特征矩阵」 | **「下一听觉焦点」+「这次和预期差多少」+ 保拓扑场** |
| 对稳定输入 | 每帧全量解析（照听不误） | **适应、事件率大幅下降（听而不闻）** |
| 双耳/空间 | 单声道、通道并列无空间 | **ITD/ILD 并列通道 → 「谁在说/在哪」** |

## 3. 具体前端设计（纯 numpy、确定性、可执行）

**3.1 为什么 log-mel/STFT 不能当「耳」**：

1. **丢相位与时序**：STFT 取幅度、log-mel 压成帧 → 爆破 VOT、擦音噪声谱、F0 谐波相位全丢；而可懂度关键线索正在这些瞬态里。
2. **无级依赖**：线性滤波+固定对数，小噪声与大声同权 → 近场/远场不分、稳态背景不过滤。
3. **带宽尺度不对**：线性 mel 低频过宽高频过窄，与 ERB 不匹配 → **临界带/掩蔽不可复现**。
4. **它是「别人给的特征」**：违反宪法第三条（焊死件）；耳蜗前端是可解释物理过程 + 少数可学参数。
5. **诚实让步**：log-mel 在 ASR 上很强（网络可补偿其失真）。我们不求赢 ASR，求**同源、因果、可解释、可判死**；故 C4 必做 log-mel 对照，输了就认。
6. **与 meeting68 `内生耳.py` 的区别**：那是 F0/能量/谱统计的**手工特征耳**（读侧遥测），不是听觉前端；本稿是「采样→上行→时序→产物」的整条链，两者可并存但不可互相替代。

**3.2 数据流（七步，一拍一拍走）**：波形 → 64 带 4 阶 gammatone 因果 IIR（行波/tonotopy 近似）→ 半波整流 → 立方根压缩 → 除法归一化适应 → 1 ms 包络 + 确定性 IF 发放 → 合成 32×32 时频场 + 逐格预测误差 + 焦点 argmax。

```
y[n] = x[n] + 2·r·cos(2π f_c/f_s)·y[n-1] − r²·y[n-2]，r = exp(−2π·b/f_s)，b = 1.019·ERB(f_c)
转导 c = (x⁺)^{1/3}；适应 m = c/(â_f+â_s+h0)（τ_f=5 ms, τ_s=100 ms）；包络低通 τ=1 ms
听神经（确定性 IF）：φ += r_max·m·dt；φ≥1 发一事件并 φ−=1（**无 RNG**）；4 纤维/带 × h0 乘子 [0.5,1,2,4]
```

**3.3 参数表（自由参数硬上限 8 个，其余固定）**：

| 参数 | 取值 | 性质 | 备注 |
|---|---|---|---|
| fs | 16000 Hz | 固定 | 与 v13 输出同源可改 22050（上限 11 kHz），登记为一档替换 |
| 包络帧 | 1 ms（62.5 µs 内部步长） | 固定 | ≤ 音节变化尺度 |
| 带数 × CF | 64 带，60–7800 Hz，ERB 等间距（ERB=24.7·(4.37 f/1000+1)，常数`[待核]`） | **自由**（带数、下限） | ≈2 带/ERB（过采样，便于合成临界带）；覆盖基频与擦音 |
| 滤波器 | 4 阶 gammatone，增益按单位冲激响应和=1 归一 | 固定 | 归一后确定性 |
| 压缩指数 | 1/3（可扫 0.25–0.5） | **自由** | 事实 2，指数`[待核]` |
| τ_f / τ_s | 5 / 100 ms | **自由×2** | 事实 6，数值`[待核]` |
| 半饱和 h0 | 该带 5 s 包络中位数 ×0.1 | **自由**（乘子） | 自适应基线 |
| 纤维 / 计数率 | 4 纤维/带（h0 乘子 [0.5,1,2,4]，初始相位 j/4）；r_max=1000 /s/纤维 | 固定 | 事实 8；IF 最多 1 发/ms |
| 起音门 θ | 20 ms 内上升 >0.15（带内归一） | **自由** | `[待核]` |

**3.4 数据结构**（`meeting69/实施/耳蜗前端.py` 唯一出口）：

```python
帧 = {  # 一拍 40 ms；纯 numpy，无 RNG，两趟逐位同
  "t_ms":   int64,              # 单调时钟，会话起点累计
  "包络":   float32[64, 40],    # 1 ms 分辨率包络（连续轨，S0 承重）
  "事件":   int32[N, 3],        # (t_µs, 带, 纤维)，按时序；每拍上限 256（确定性截断）
  "相位":   float32[N],         # 事件波形相位 ∈[0,1)（保留事实 7）
  "场":     float32[32, 32],    # 32 临界带 × 32 槽（5 ms/槽，160 ms 环缓冲）
  "意外":   float32[32, 32],    # 逐格预测误差 ε
  "意外度": float,              # ∈[0,2]，可直接喂唤醒 A
  "焦点":   (b, w, t0, d),      # 下一听觉焦点
  "保留_a": float32[32, 32],    # 预测器增益（局部可塑，跨拍持久）
  "指纹":   str,                # 全数组 sha256，两趟必须逐位同
}
```

**3.5 确定性与性能**：无随机数（IF 是确定性相位累积；若需泊松特性用固定查询表替代 RNG）｜浮点顺序固定（不做多线程归约、逐样本串行、带维显式循环）｜性能预算 64 带×4 节 IIR @16k ≈4.1 M 乘加/秒，纯 numpy 目标 **≤0.5× 实时**（1 s 音频 ≤0.5 s），超预算先降 32 带（登记为可接受降级）。

## 4. 与多模态/视觉一致的接口

**4.1 听觉焦点 = 时频窗**：焦点（听觉中央凹）= `w` 个相邻临界带 × `d` ms（默认 2 带 × 20 ms ≈1–2 ERB）；外周 = 全 64 带 × 200 ms 按 2× 降采样（10 ms、2 带合并）；焦点移动 = 一次听觉扫视，含抑制返回（刚采过的区 200 ms 内降权）。

**4.2 注意调制（同视场四项分数）**：

```
score(b,t) = w1·意外(b,t) + w2·显著(b,t) + w3·意图偏置(b,t) − w4·抑制返回(b,t)
显著 = 起音强度 + 谐波性(短时自相关峰) + 双耳一致性(若双耳)
```

w 初值 `[0.4, 0.3, 0.2, 0.5]`，**S0 不调**（预注册锁定）；tie 按 `(b,t)` 字典序 → 确定性。

**4.3 预测误差（局部可塑预测器，无梯度/无 attention）**：

```
Φ̂_t(b,s) = a·Φ_{t−1}(b,s) + (1−a)·mean(Φ_{t−1}(b±1,s))   # 带内惯性 + 邻带耦合
ε_t(b,s) = |Φ_t − Φ̂_t|                                     # 逐格意外（>θ 才上行）
a ← clip(a + η·ε·Φ_{t−1}, 0, 1),  η = 0.01                  # 局部 δ 规则
```

逐格独立 ⇒ 天然并行、可解释、可复现；这是 Q4「内生学习」第一类可学量，**不是反传**。

**4.4 与视觉注视/惊讶互操作**：

- **共享时钟**：单一 `t_ms`（int64）；两模态事件都带 `(t_ms, 模态 id)`。视觉拍 100 ms（meeting38 ~10 Hz），听觉拍 40 ms ⇒ 每视觉拍含 2–3 听觉拍。
- **绑定窗**：以视觉事件 `t_v` 为锚取听觉 `[t_v−150, t_v+50]` ms；「听落后于看」登记为假设 **H-bind-1 `[待核]`**（S2 才验）。
- **零新数学**：窗内听觉场时间池化 → 1024 维「听觉在场码」，与视场码同 D=1024 ⇒ 直接复用既有 `绑`/`相似`/`束`。
- **惊讶互操作**：跨模态残差 `ε_av = |ε_v − ε_a|`；「视觉高惊讶+听觉低」= 看到嘴动却没声音 → **缺失事件**（McGurk 类代理），这是「像人」最强可判据点。**诚实边界**：时间池化会丢场的时间拓扑，原始场必须留在听觉槽，绑定只用压缩版。

**4.5 内生学习（Q4）**：① 预测器增益 a → 逐格 δ 规则（4.3）；② 视听绑定 → Hebb 共现计数；③ 焦点权重 w → 「移动后误差是否下降」作局部奖赏 ±小步。**迁移判据**：留出说话人/语速上 ε 仍下降、未见配对仍绑定，否则判「只在教过时成立」。

## 5. 可判据（5 条，S0 全可测；阈值先注册后跑）

- **C1 临界带滤波形状**｜测法：探针 500/2000/4000 Hz + 陷波噪声掩蔽器扫 ±2 倍频程（1/8 倍频程步），可检=掩蔽器关断前后探针带包络差 >6 dB；拟合掩蔽调谐曲线取半高宽｜阈值：≥2/3 探针点落在 **1–3 ERB**｜失败：任一 >4 ERB 或 <0.5 ERB。
- **C2 掩蔽方向（上扩散）**｜测法：掩 500/探 2000 与反向，掩蔽器同谱级｜阈值：低频掩高频的阈值提升比反向 **≥6 dB**（`[待核]` 工程阈值，允许一次预注册修订）｜失败：方向反或差 <2 dB。
- **C3 适应（含「听而不闻」）**｜测法：CF=1 kHz 的 200 ms 阶跃（−30→−10 dBFS）双指数拟合 τf/τs｜阈值：峰值/稳态 **≥2.0**、τf∈[2,10] ms、τs∈[50,200] ms、1 s 稳态后事件率 ≤ 初始 30%｜失败：无过冲或 τ 越界 2 倍。
- **C4 噪声下可懂度代理**（**代理，不是人耳**；人耳终判按 meeting67/08 §3）｜测法：合成 /ba/ /da/ /ga/ 各 30 条 × SNR{∞,5,0} dB，特征=场 1024 维，分类器=最近类均值（零训练），**同数据 log-mel 80 带同分类器做对照**｜阈值：0 dB 下 **≥0.70** 且不低于 log-mel −0.05｜失败：<0.55 或比 log-mel 低 >0.10。
- **C5 响度压缩与等响形状**｜测法：1 kHz 纯音扫 −50…0 dBFS（5 dB 步）测总事件率/包络和；再测 1 kHz 与 4 kHz 可检阈值｜阈值：压缩斜率 **0.2–0.6**（显著 <1.0）、4 kHz 阈值比 1 kHz 低 **≥3 dB**｜失败：斜率 >0.8（线性）或两频差反向。

> 备选 **C6 双耳 ITD**：500 Hz 纯音 ITD ±0.5 ms，恢复误差 <50 µs、斜率 1±0.15；**仅在有真双耳数据时启用**，单声道登记「不可测」。

## 6. 风险 / 失败模式

| # | 风险 | 表现 | 对策 |
|---|---|---|---|
| R1 | 前端过重 | 64 带×4 节 IIR 慢于实时 | 降 32 带（预注册降级档）；FIR 近似做加速对照；先做 1 ms 包络抽取 |
| R2 | 事件化丢相位/瞬态 | ITD 与 VOT 恢复不出 | 事件携 `t_µs`+相位；**连续包络轨与事件轨并行**，S0 只认包络轨 |
| R3 | 确定性破 | 两趟 sha256 不同 | 无 RNG、固定归约顺序、逐样本串行；每拍写 `指纹` |
| R4 | 与 v13 不兼容 | v13 吃 80 带 log-mel | 本前端在**输入侧**，不改 v13；要接回「自听」只做 64 带→80 mel 确定性重采样桥，**登记为桥、不是耳** |
| R5 | C10 越界 | 顺手用 ASR/预训练模型做前端 | ASR 只作离线仪器；前端参数全部显式可读，审计可查 |
| R6 | 判据被调参伪过 | 预注册后反复调 | 阈值先写后跑 + 留出音色/语速 + sham（白噪/静音/带置乱）判死 |
| R7 | 过度生物学 | 堆 20 个不可测参数 | **自由参数硬上限 8 个**；其余固定并在参数表列明 |
| R8 | 「像耳」≠「可懂」 | C1–C5 过但语音仍不可懂 | 本稿只管**前端像耳**；可懂度归 meeting67/08 人耳终判，不越界宣称 |
| R9 | 双耳不可测 | 数据实为单声道 | C6 直接登记「不可测」，不用伪双耳凑数 |

## 7. 建议的 S0 探针（≤1 天、能判死）与 S1–S2 路线

**7.1 S0 只回答一件事**：这个前端有没有人耳的「形状」——C1/C2/C3 三条带内现象 + C4 一条信息量对照。

**7.2 两个半天探针**：

| 探针 | 输入 | 对照 | 判据 | 失败条件 |
|---|---|---|---|---|
| A（半天）形状 | 5 类合成：纯音阶跃/双音/陷波噪声/click/粉噪扫级 | 无（内部一致性） | C1、C2、C3 **≥2/3 过** | <2/3 ⇒ 滤波/转导形状错，停 |
| B（半天）信息量 | 音节 3 类 ×30 × SNR{∞,5,0} | **log-mel 80 带 + 同分类器** | C4 **≥0.70 @0 dB** 且不低于 log-mel −0.05；C5 同时测 | <0.55 或比 log-mel 低 >0.10 ⇒ 前端丢线索，停 |

**7.3 落盘（全部新增于 `meeting69/实施/`）**：`耳蜗前端.py`（gammatone+转导+适应+IF+场/意外/焦点，唯一出口 `帧`）｜`探针_S0.py`（A/B 两臂 + JSON + 图）｜`S0_预注册.md`（阈值先写后跑，含一次修订额度）｜`S0_证据.md`（读数+诚实边界，空=未测）。

**7.4 S0 边界**：不接 v13、不训练、不跑 ASR、不调参超预注册额度、不做视听绑定。

**7.5 S1（3–5 天）**：焦点链 + 场环缓冲 + 与视觉共用时钟（只对齐时间戳）；判据：稳定纯音 1 s 后事件率降 ≥70%、两趟 sha256 同。

**7.6 S2（1–2 周）**：Hebb 共现绑定 + 缺失事件 ε_av；`听觉槽`（场/焦点/误差场/意外度/焦点链）作为**新槽纯追加**并入共存态（照 meeting38 视场槽先例，视觉槽一键不动）；接回 v13 只做确定性 64 带→80 mel 重采样桥并标「桥非耳」。

**7.7 判死与回退**：S0 形状 <2/3 ⇒ 先降 32 带/线性相位 FIR 重试一次（预注册），仍不过 ⇒ 判「本前端方案不成立」，回 Lead。

**7.8 诚实边界**：§1 的 15 条现象有教科书/实验支持，但**参数取值几乎全是工程选择**（压缩指数、τ、带宽、θ 都是 `[待核]` 起点）；S0 不过先怀疑参数与实现，不先怀疑「生物学方向」。且本前端全过也只证明「像耳」，不证明「可懂」——后者归 meeting67/08 人耳终判。
