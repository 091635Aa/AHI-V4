## 0. 一句话立场
> **声音不是"第二个通道"，而是同一套绑定机制的另一半。**
> **像人一样听 = 一条受注意调制的、时频局部化的听焦点链；且每一次"听"都在和"看"做同源/异源的跨通道预测误差比较——绑定不是听完再拼，绑定就是听的产物。**

对所有者三句话的解读（可被纠正）：

| # | 所有者的话 | 我的解读 |
|---|---|---|
| 0-1 | 「他听的声音也是多模态」 | **双读，我两个都取**：①**通道外**——听语音时人几乎必然在看（嘴、脸、身体、场景）；②**通道内**——声音本身至少是四条不能压成一个向量的并行子流（**包络/节律、F0/音高、谱包络/音色-音位、瞬态/事件**）。压成 80 维 log-mel 展平向量，就是通道内"单模态化"，与"先各自识别再拼接"是同一种错。 |
| 0-2 | 「和人类视觉一致」 | **结构同构，不是精度等同**：注视→听焦点、误差场→误差场、保拓扑场→保拓扑场、眼跳链→焦点链、适应→听而不闻。同构点见 §2.3 表 B。 |
| 0-3 | 「AI 架构眼中的语音编码器」 | **功能上我们确实要一个语音编码器，但拒绝它的形态**：拒绝"整段波形 → 音素/文本序列"。我们的编码器输出是 **(焦点, 误差, 场, 绑定)**；**绑定量本身是编码的一部分**，不是后处理。这不是绕，是换编码目标。 |

## 1. 人类视听整合的事实清单（标注可信度；数值不确定处标 [待核]）
| # | 现象 | 内容（一句话） | 标注 | 对本工程的含义 |
|---|---|---|---|---|
| F1 | **McGurk 融合** | 听 /ba/ + 看 /ga/ 的嘴 → 多数人报 /da/；融合不是任一单通道 | **教科书级**（McGurk & MacDonald, *Nature* 1976） | 判据必须能出现**非任一单通道**的中间态，否则只是"两路都在场" |
| F2 | **可靠性加权** | 两通道按各自可靠性加权，不是固定视觉主导；噪声大时视觉权重升 | **有实验支持**（贝叶斯线索合并一类结果）；"视必主导"是过度简化 | 必须测**遮挡/静音下的权重翻转**，否则系统会焊成视觉霸权 |
| F3 | **时间绑定窗（语音）** | 语音视听同步的容忍窗约**几十 ms 到 ~200 ms 量级**，且**不对称**（视觉领先容忍更大） | **量级有实验支持**；上下界与不对称比 **[待核]** | 判据给**区间**而非点值；曲线形状比峰值更重要 |
| F4 | **语音特异性整合** | 语音的绑定窗比"闪光-蜂鸣"类非语音事件更宽，且受语音内容调制 | **方向有实验支持**；特异性强度 **[待核]** | 允许语音/非语音用**两组窗参数**，但同一机制、只参数不同 |
| F5 | **噪声下唇读增益** | 加视觉唇动可等效提升信噪比，人约 **3–6 dB** 量级 | **有实验支持**（Sumby & Pollack, *JASA* 1954 起）；精确值随材料/任务变 **[待核]** | 我们取保守门 **≥2 dB 等效**，先证明方向 |
| F6 | **注意与竞争** | 选择性注意可锁定一个说话人；跨通道线索（看谁在动嘴）引导听觉注意；非语音竞争中出现视觉反应优势 | **有实验支持**（Colavita 效应等） | 绑定必须**受注意调制**，且要有"抑制返回"，否则双声源必错 |
| F7 | **跨通道预测误差 / 同源推断** | 大脑倾向把时空一致的视听归为同一源；不一致时产生失匹配响应并触发重估 | **有实验支持**（因果推断框架，Körding 等 2007）；神经指标细节 **[待核]** | **本席位核心机制**：绑定 = 同源假设，惊讶 = 假设被否 |
| F8 | **发育顺序** | 婴儿期已能视听整合，但**绑定窗更宽**，随经验收窄 | **方向有实验支持**；收窄年龄曲线 **[待核]** | 机制上直接可用：**初始宽窗 → 共现锐化 → 窄窗**，让"发育"成为参数轨迹而非装饰 |
| F9 | **视听空间对齐（腹语效应）** | 视觉位置捕获听觉位置，并有后效（适应） | **教科书级**（ventriloquism / aftereffect） | 声源"在哪"可由绑定给出，不必靠声源定位算法 |
| F10 | **听觉场景分析** | 听觉按接近性（时间/频率/谐波）分组为"流"，流内连贯、流间竞争 | **教科书级**（Bregman 1990） | 听焦点链要有"流"的连续性先验，不能每拍从零 argmax |

**自证**：以上没有一条需要 Transformer、OCR、外挂模型或预训练权重；F3/F5/F8 的精确数值我**没有实测**，一律标 [待核]，不在本文件当结论用。

## 2. 「像人一样听」的可操作定义（多模态视角）
### 2.1 每拍输出什么（4 元组 = 视觉 3 元组同构 + 1 个绑定量）
```
每拍（建议 100 ms 一拍；拍内 10 ms 栅格）输出：
  f′ : 下一听焦点 = (t₀ 中心时刻, f_c 中心频率, Δf 带宽, 持续拍数)      ← 对应视觉 g′
  s  : 预测误差 = (s_a 单听, s_v 单视, s_av 跨通道, 各 ∈[0,2])          ← 对应视觉 s
  Ψ  : 保拓扑听觉场 = float32[1024]，由 24 带×16 帧（10 ms 帧，320 ms 窗）谱图块
       经既有 `特征码` 投影；保留 带×时间 二维邻接，不展平成特征串        ← 对应视觉 Φ
  β  : 绑定记录 = [(声源id, 视场槽.注视指纹, Δt, b, 存活拍, 证据计数)]   ← 本席位新增
```
**关键**：`β` 不是可选附加输出。**没有 β 的"听"是单通道 AI 式听**——能出音素/能量，但不知道"这声音是谁在发、和刚才看到的是不是一件事"。

### 2.2 表 A：「AI 式多模态」vs「像人一样」
| 维度 | AI 式多模态（先各自识别再拼接，被否） | 像人一样（跨通道预测误差驱动绑定） |
|---|---|---|
| 采样单元 | 整段音频→帧→特征；整帧视频→特征 | **听焦点窗**（时频局部）+ **注视窗**（空间局部），各自逐拍移动 |
| 时间基准 | 全局帧号；两路各自定长切窗 | **同一单调时钟打点**；绑定在 10 ms 栅格做，拍只做汇总 |
| 绑定判据 | 靠标注学一个融合层/注意力权重 | **同源假设**：时空一致 + 节律连续 + 互为预测（双向） |
| 融合位置 | 晚期融合（各自出类别后拼接/投票） | **早期**：绑定在"识别"之前，绑定结果才是识别的输入 |
| 异步处理 | 先对齐再融合（对齐失败→丢弃） | **异步本身是信号**：b(Δt) 曲线就是容忍窗，超窗=不同源 |
| 稳定输入 | 每帧照样输出全量结果 | **适应**：重复稳定→惊讶↓、输出↓（听而不闻/视而不见） |
| 出错时 | 置信度低，仍给标签 | **撤销同源**、双通道重采样、投事件槽 |
| 语义来源 | 外部标签/文本（对听=外部 ASR，即 C9 类比违例） | **能否被预测 + 能否被驱动**（meeting38 同款"知道"定义） |

### 2.3 表 B：与 meeting38 视觉定义的逐项同构（结构一致性检查表）
| 视觉机制（meeting38/步8） | 听觉对应物 | 同构 | 备注 |
|---|---|---|---|
| 注视点 g′（下一眼看哪） | 听焦点 f′（下一听哪段时频） | ✅ | 都由"显著度+意外+意图偏置−抑制返回"打分 argmax |

## 3. 可执行绑定机制
### 3.1 绑定什么（5 类，按可靠性排序；前 3 类不依赖人脸视频）
| 绑定量 | 视侧 | 听侧 | 精度 | S0/S1 可用 |
|---|---|---|---|---|
| **B1 onset/offset** | 注视区像素突变/运动能量峰 | 能量包络上升沿、谱通量峰 | 10 ms | ✅ |
| **B2 能量包络** | 注视区运动能量包络 | 音频包络（0–8 Hz 调制） | 10 ms | ✅ |
| **B3 节律/相位** | 周期性运动（点击、打字、点头） | 音节率 2–8 Hz、拍相位 | 10 ms | ✅ |
| **B4 唇形** | 张口度 a、圆唇度 r、闭唇 b（**低维几何量，非唇读模型、非 OCR**） | 谱包络低中频段（F1/F2 邻近带能量） | 20–40 ms | ❌ 需人脸视频 |
| **B5 注视时长/空间** | 同一注视目标持续 ≥3 拍 | 声源方位（由 B1+B3 共现赋给该目标） | 100 ms | ✅ |
**立场**：**声源不是在音频里"被分类"出来的对象，而是绑定过程的（近似）不动点**——一个声源 = 一组在时间上共现、在节律上连续、在空间上归属同一注视目标的事件集合。这样"是什么声源"不需要标签，符合初心第一条。

### 3.2 绑定时间窗参数（建议值，进预注册）
```
绑定栅格：10 ms；核范围 τ ∈ [−300, +300] ms（61 bin）
初始核 h₀(τ)：宽高斯 σ₀ = 150 ms（≈ 婴儿宽窗，F8 方向）
语音主窗（终态预期）：σ ≈ 50–70 ms，半高宽 ≈ 120–165 ms；不对称：
    负侧（视觉领先）σ⁻ = 90 ms，正侧 σ⁺ = 60 ms      ← 视觉领先容忍更大（F3 方向）
非语音事件窗：±80 ms，对称
拍率：100 ms/拍；**绑定不在拍上做，在 10 ms 栅格做，每拍只汇总 β**
```
**为什么必须亚拍**：若绑定只在 100 ms 拍上算，Δt 曲线只有 3–5 个可分辨点，**半高宽判据直接失效**（会把"没绑定"误判成"窗很宽"）。这是我认为最容易翻车、也最容易避免的工程点。

### 3.3 绑定如何被「惊讶」调制（3 条规则，可写成 20 行）
```
s_av = 归一化(实际音频包络 − 由唇形/注视运动预测的包络)   # 视→听
     + 归一化(实际嘴/运动时序 − 由音频 onset 预测的时序)   # 听→视（双向！）
b = w(Δt) · r_a · r_v · 同源证据比例                        # b ∈[0,1]
R1 强化（低惊讶）：s_av < 0.3 且持续 5 拍 → 同源确认，b→1，采样抑制（适应）
R2 撤销（高惊讶）：s_av > 1.0 且持续 3 拍 → 撤销同源（b 置 0.2），
                   听/视焦点分离重采样，投事件槽 {错配, 新源}
R3 重绑：撤销后在同窗内用 h(τ) 对其余 (注视目标 × 声源) 重新打分，取最高者；
         无过门者 → 判"无可见声源"（画外音），仍允许纯听焦点链前进
```
**注意 R2 是"惊讶既打开绑定、也撕开绑定"**：低惊讶让人**不再看**（适应），高惊讶让人**重看**。视觉侧 meeting38 的"惊讶→下一注视"是单向的；加入听觉后变成**双向、可撤销**——这是视听整合给视觉工程的**真实增量**，不是装饰。

## 4. 学习怎么内生（不用 Transformer、不用外挂模型、不用手设 200 ms）
### 4.1 机制：可塑绑定核 h(τ) + 反共现
```
对每对 (视特征 j ∈ 8, 听带 k ∈ 24)：维护 h_jk(τ)，τ ∈ 61 个 10 ms bin
更新（局部、无梯度、无注意力）：
  h ← (1−λ)·h + η·[ 共现_jk(τ) − γ·反共现_jk(τ) ]      λ=1e-3, η=0.05, γ=0.5
  共现：j 的 onset 与 k 的 onset 落在同一 τ bin；反共现：j 有事件而 k 静默（或反之）
  归一化：h ← h / Σ_τ h（每对独立）
读出：τ̂_jk = argmax h；绑定强度 = max h；有效 σ = h 的半高宽
```
**为什么这满足"内生"**：**时延 τ̂ 不是常数，是从共现统计里长出来的**；初始 σ₀=150 ms 是"婴儿宽窗"先验（F8），共现把 h 锐化到 ~60 ms 是**发育**，不是调参。**反共现项**是防"过绑"的必需项——没有它，任何运动都会绑任何声音，判据立刻被刷穿。成本：61×8×24 ≈ **1.17 万次乘加/拍**（一次 einsum），完全在预算内；固定遍历顺序/bin 边界/浮点累加顺序 ⇒ C13 两趟逐位同。

### 4.2 双向预测器（跨通道预测误差的来源，也是可塑的）
- **视→听**：用视侧 8 维（运动能量、onset 标记、节律相位 sin/cos、持续拍、注视位移）**线性**预测音频包络低频段（0–8 Hz）→ 残差 = s_av 的一半。
- **听→视**：用音频包络/onset 预测视侧运动时序 → 残差 = 另一半。
- 权重用**固定步长 LMS 式局部规则**更新（确定性、无梯度反传、无 Transformer）。
- 允许的替代：从零训练的非 Transformer 小网络（Conv1D/GRU）**仅当**与局部可塑做**消融对照**且不优于局部可塑才可保留；否则视为焊死件（初心第三条）。

### 4.3 怎么测「没教过的组合也会」（预注册迁移臂，写死）
| 臂 | 训练 | 测 | 过门（建议） |
|---|---|---|---|
| T1 同人新句 | 说话人 A × 句 1–10（同步 + 注入 +100 ms 两种） | A × 句 11–20 | τ̂ 误差 ≤ 20 ms |
| T2 跨说话人 | 同上 | **未见** 说话人 B × 句 1–10 | τ̂ 误差 ≤ 40 ms 且 b ≥ 0.6·b_train |
| T3 未教异步 | 只见过 Δt ∈ {0, +100} | Δt ∈ {+50, +150, −100} | b 随 \|Δt\| 单调降（Spearman ρ ≤ −0.7） |
| T4 交换（错配） | 同步配对 | **A 的嘴 + B 的声** | b ≤ 0.4 且 s_av ≥ 2× 同步臂 |
| T5 单通道撤除 | 双通道 | 静音 / 黑屏 | 焦点链非平凡（惊讶方差 >0.01），不崩 |
| sham | — | 随机打乱视听配对 | h 平坦度 >0.9，b ≤ 0.3 |

## 5. 可判据（5 条，给测法与建议阈值；**全部需预注册才算数**）

## 6. 风险与失败模式（按杀伤力排序）
1. **没有视听共现数据（最大风险）**：AHI4 视觉是"截屏-桌面"，**没有摄像头、没有人脸、没有唇动**。语音级整合（J1/J2）在当前硬件下**无法测**。对策：S0 用**参数级视通道**（程序化嘴形三参数），S1 用**桌面事件**（点击/键/提示音 + 界面变化）做非语音绑定，S2 才需人脸视频（须所有者提供素材或开摄像头）。
2. **时基不同源 + 抖动**：声卡时钟与屏幕捕获时钟不同源，jitter >50 ms 会把 b(Δt) 抹成平线，**看起来像"人没有绑定窗"**。对策：单调时钟打点 + 每拍互相关重估偏移；若漂移 >100 ms/min，判"采集不可用"，先修采集不修算法。
3. **拍率吃掉时间分辨率**：见 §3.2。只在 100 ms 拍上绑定，J3 一定过不了、且 FAIL 得没意义。
4. **单说话人**：现有 167 条 + 38 h 长录音**疑似同一人**（未做声纹）。跨说话人臂无数据。对策：用变调/共振峰扰动造"伪说话人"，但**必须登记为合成变体**，不得写成"跨说话人"。
5. **合成视频过干净 → 绑定量被高估**：程序化嘴形无头动/遮挡/光照；真人视频一上就掉。对策：判据**双源**（合成 + 真人小样本），只在合成上过的标"合成条件"。
6. **过绑 / 欠绑**：无反例，h 会收敛到"任何动↔任何声"。对策：反共现项（§4.1）+ T4 交换臂；**没有 T4 的绑定实验不算实验**。
7. **视觉霸权（Colavita 式）**：视觉可靠时把听觉压到 0，噪声下也不回升。对策：可靠性加权检查（F2），遮挡/静音臂必须看到**权重翻转**。
8. **C10 诱惑与 C13 破坏**：外部唇读/音视频同步/ASR 模型当绑定器 = 直接违例；局部可塑的遍历与浮点归约顺序不固定 = 两趟不同位。两者都当**代码评审硬门**。
9. **自听回路的归属污染**：它自己发声时，"自己的声 × 自己的嘴"应绑成**自我归属**（自我的感官基底）；但外部声也可能被误归自己。需单独一条"自他归属"臂，别和 J4 混。

## 7. 最小 S0 探针（≤1 天、能判死）与 S1–S2
### 7.1 S0：「可塑核能否从共现里长出时延」——半天写、半天跑
- **材料（零外部模型）**：① 音频：用**只读** v13 ckpt 生成 20 条短语音（不改任何既有件），或直接用既有 167 条 wav 的 20 条；② 视侧：**参数级**口形三通道 `a(t), r(t), b(t)`（张口/圆唇/闭唇），由音节表程序化生成，**人为注入已知延迟 Δt₀ ∈ {0, +80} ms**；③ 反例：静音+嘴动、有声+嘴不动各占 30%。
- **流程**：10 ms 帧化 → 视侧 8 维特征（含 onset）与听侧 24 带包络 + 谱通量 → 按 §4.1 更新 h(τ) 200 遍 → 读 τ̂、半高宽、b。
- **判死判据（任一不过即 FAIL）**：① τ̂ 与注入 Δt₀ 偏差 ≤20 ms；② 半高宽 ≤300 ms；③ 反例训练后"嘴动无声" 的 b ≤0.3×同步臂；④ sham（随机配对）h 平坦度 >0.9；⑤ 三随机种子 τ̂ 方差 ≤60 ms；⑥ 两趟逐位同（C13）。
- **失败即结论**：τ̂ 不收敛或曲线平 ⇒ **"局部可塑核不能从共现长出时延"** 判死，退到手设窗并**登记为焊死件**（不算通过）。这条判死的价值大于它通过。
- **落盘**：`meeting69/实施/探针_S0_视听绑定.py` + `meeting69/产物/S0/结果.json`（含 τ 曲线全量、种子、指纹）。**不改任何既有 `.py`。**

### 7.2 S1（1–2 天）：接真实音频 + 桌面事件
真实录音的音节 onset × 桌面视听事件（点击声↔光标/界面变化、提示音↔弹窗），做**非语音视听绑定**；加双"伪说话人"与 T4 交换臂；出完整 b(Δt) 曲线与 J4 初测。**这一层不需要人脸，是当前硬件下能交付的最强证据。**
### 7.3 S2（3–5 天，需人脸素材）：语音特异整合
唇形三参数（a/r/b）→ 谱包络绑定；J1（McGurk 型融合）、J2（噪声增益）、J6（适应）。**只有 S2 过，才能说"像人一样听的视听整合"成立**；S0/S1 过只说明"绑定机制成立"。
### 7.4 与「像人一样看」工程的接线点（逐条可执行）
1. **新增 `听场槽`**（纯追加、独立锁），照 `视场槽` 先例；不动 `视觉槽.元素s`、不动 `eye器`、不动七路契约。
2. **绑定表挂在 `听场槽` 内**，键 = `视场槽.注视` 的指纹 `(格x, 格y, 持续拍)`；值 = `(声源id, Δt, b, 存活, 证据)`。**只读** 视场槽，不写。
3. **意外度汇流**：`s_av` 作为**带权可关**的加项进"意外度→唤醒 A"；默认关闭，消融臂必须能一键断开（否则污染既有情感/V4 判据）。
4. **事件槽共用**：绑定撤销（R2）投 `{错配, 新源}`，与视觉"新结构"走同一通路到"我器"，不新开通道。
5. **时间基统一**：`拍_ts` 与音频帧 ts 用同一单调时钟；这是与步4"全屏实况演播台"直接对接的接口点。
6. **与步8 RPE/多巴胺**：`s_av` 可作"预测误差"的一股输入，但**先只做只读观测**，等 S1 有曲线再谈是否进 RPE；不预设它会改善任何既有指标。
