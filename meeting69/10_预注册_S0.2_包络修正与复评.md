## 1. 为什么有 S0.2（复核发现的实质问题）

`08` 独立复核（子代理，未参与实现）确认 S0.1 数字全部可复跑、阈值未改、S0 未被破坏；但发现两项**实质缺陷**（都不是 S0.1 越权，但都影响「S1 门」质量）：

**A（实现缺陷，S0 起既有）**：`耳蜗前端_S0.py` / `_S0_1.py` 的 `包络(x)` 写的是
```python
for i in range(len(x)):        # x 的形状是 (64 带, N 样本) ⇒ len(x)=64
    acc += (x[i] - acc) * α    # acc 是长度 N 的向量 ⇒ 递推沿「频带轴」
    y[i] = acc
```
即 **1 ms 因果低通作用在频带轴、不在时间轴**（时间方向只有随后的 22 点均值）。后果（复核实测）：
- 单带冲激沿带**单向泄漏**：带 40 → 带 45/55/63 响应 0.036/0.023/0.016，向下全 0；
- 1 kHz 纯音 **41/64 带 >10% 峰值**（正确实现 27 带），峰值带 **1254 Hz**（正确 1037 Hz）；
- 稳态元音相邻带相关 **0.888**（正确 0.700）、隔 10 带 **0.682**（正确 0.386）；
⇒ A2 的「64 带 ERB 场」**名不副实**；S1 的 32 临界带正建在这套场上的话解释力受损。

**B（选点问题，程序合规）**：J4 的表示证据 R²=0.55 测的是 `场未适`（适应前）；同一探针在**选中的 V3 `场`** 上 R²=**−0.67**（V1 −1.57 / V2 −1.64）；V3 场整体仅为未适应的 **3.9%**、J6 晚窗 **47.7% 恰为 0** ⇒ J6 的 PASS 是「减式把稳态场清零」，不是「场健康」。`07` 已登记 2.15% 残余但未报 −0.67。

**S0.2 只回答一个问题**：

> **把 `包络` 修成真正的时间轴 1 ms 因果低通之后，S0/S0.1 的七条判据（阈值不动）是否仍然成立？「换表示」结论是否保持？**

同时执行复核 §13.2 的 **丁**（G1 J6 标签、A0 的 J6 实测、明细生成脚本、`06` §10 披露更正）与 **丙**（RTF 固定负载 ×3 取中位；阈值仍 0.5）。

## 3. 修正实现（先写死）

| 项 | 值 |
|---|---|
| `包络(x)` | `y = lfilter([α], [1, −(1−α)], maximum(x, 0), axis=1)`，**axis=1 = 时间轴**；`α = 1/(SR·0.001) = 0.045351…`（与逐样本递推 `acc += (rect−acc)·α` 逐位等价） |
| 与旧实现的差 | 旧：`for i in range(len(x))` 沿频带；新：沿时间。其余（滤波组/22 点均值/立方根/适应/F0/事件）**一字不改** |
| 确定性 | `lfilter` 固定路径；两趟 sha256 同（G5） |
| 速度 | 去掉 1.3M 次 Python 循环，RTF 预期下降（见 §4.5） |

**为什么用 `lfilter`**：与逐样本递推是同一个差分方程，只是把 Python 循环换成 scipy 的 C 实现（C13 确定性；且旧实现的低频带累加本就不是设计意图）。若 `lfilter` 与逐样本递推在 64×N 输入上有任何不一致，以逐样本递推为准（本件以 `包络自检` 的「冲激响应」逐位校验）。

### 4.3 修正正确性自检（必须先过；不过 = 修正失败，停）
| # | 检验 | 通过条件 |
|---|---|---|
| 修-1 | 单带冲激（只在带 40 放 1，其余 0，400 样本） | 带 40 响应 >0、**其余 63 带响应 <1e-9** |
| 修-2 | 1 kHz 纯音 0.4 s → 带廓 | `>10% 峰值带数` **≤30**（正确实现 27；旧实现 41）；峰值带中心 **在 950–1150 Hz**（旧 1254 Hz） |
| 修-3 | 稳态元音相邻带相关 | **≤0.75**（正确 0.700；旧 0.888） |
| 修-4 | `lfilter` vs 逐样本递推（(2×6) 小输入） | **最大差 ≤1e-12**（同一差分方程、浮点舍入允许；不是逐位 0） |

> 注（20:53 跑前细化）：修-4 原写「逐位同」。`lfilter`（直接 II 型转置）与逐样本递推 `acc += (x−acc)·α` 在浮点舍入上不保证逐位 0；故门槛改为**最大差 ≤1e-12**（仍能证明是同一差分方程）。此改动**在读数前**、不影响任何判据阈值。
>
> 注（20:44 首跑后、正式复评前）：首跑修-4 报 5.28e-9 不过——原因是比较对象错配：`前.包络` 返回 **float32**，而对照递推用 float64；5.28e-9 正是 float32 舍入级（不是不同方程）。**修-4 规格更正为「float64 lfilter vs float64 逐样本递推 ≤1e-12」，另登记前端 float32 差**（预期 ~1e-8 级）。首跑结果留档 `产物/S0.2/结果_首跑_修4规格误判.json`；判据阈值未动。

### 4.4 J6-信息（**登记护栏**，不翻转 J6 判据）
- 量：选中变体稳态场 `[1500:1800]` 中「场>0」的格占比；整体残余比（`场`/`场未适` 全局均值）。
- 门槛（先写死）：**非零占比 ≥50% 且整体残余比 ≥20%** ⇒「适应健康」；否则登记「**退化型通过**（场被减到零）」。
- 处理：**不改 J6 的程序判定**（J6 仍按 `06` §4 判 PASS/FAIL，避免事后翻转已冻结判据）；但若为「退化型通过」：(a) S1 的听场 Ψ **不得以该 `场` 为载体**（`09` §2.1 已写「以 `场未适` 为主」，此处把 47.7%/3.9% 写进 `09` §9）；(b) AGENTS/证据必须并列写「J6 通过方式 = 清零」；(c) 若需健康适应，另立预注册（不在本件调权重）。
- 这是复核 §13.1-6 的建议，采用其**登记**用途、不采用其「翻转已冻结判据」的用法。

### 4.5 丙：RTF 测量协议（阈值不动）

- 仍判 `RTF ≤ 0.5`（阈值未改）；证据里并列 3 趟与波动，**不再把 `0.403→0.463` 归因于 YIN**（`11` 更正）。
