### 2.2 听场 Ψ（1024）
| 项 | 值（先写死） |
|---|---|
| 频带 | 64 带 ERB（S0.2 已通过 `12`：修-1..4 全过）→ **32 临界带**（相邻 2 带合并：`(2i,2i+1)`；带心取几何均值） |
| 时槽 | **32 槽 × 5 ms = 160 ms**（最新 160 ms，按 1 ms `场未适` 每 5 ms 求均值；不足处补 0） |
| 归一化 | 先 `L = log(场未适 + 1e-3)`；每带用**截至当前拍的 2 s 历史**（最少 200 ms）求中位 `m_b` 与 IQR `q_b`；`z = (L − m_b) / max(q_b, 0.05)`；`Ψ = clip(z, −3, 3) / 3` ∈[−1,1] |
| 布局 | **band-major** flatten：`index = b·32 + slot`（保拓扑：邻带/邻槽相邻） |
| 输出 | `听场 float32[1024]` |

### 2.3 预测 / 误差 / 惊讶
- 预测（零训练、确定性）：`Ψ̂_t = clip(Ψ_{t−1} + 0.5·(Ψ_{t−1} − Ψ_{t−2}), −1, 1)`；`t<2` 时 `Ψ̂_t = Ψ_{t−1}`。
- 误差场：`ε_t = |Ψ_t − Ψ̂_t|`，`float32[1024]`。
- 惊讶：`e_t = mean(ε_t)`；**`s_t = clip(e_t / 0.05, 0, 2)`**（与视觉同刻度 0–2；0.05 为先写死常数，**不随数据自适应**——A-2 的「稳态第 3 s 意外 ≤ 第 1 s 40%」靠的是 Ψ 的滑动归一化在稳态收敛，不是靠惊讶归零）。
- 逐格意外：`float32[192]` = **6 频带组 × 32 时槽**（组边界先写死：`[0,6) [6,11) [11,16) [16,21) [21,26) [26,32)`），组内对 ε 取均值。

### 2.4 焦点（时频窗）与焦点链
| 项 | 值（先写死） |
|---|---|
| 焦点窗 | **4 临界带 × 8 时槽（40 ms）**；候选位置 `b∈[0,28]`、`slot∈[0,24]`（29×25=725 个窗） |
| 意外项 | `意外_norm(win) = mean(ε_win) / (max_win mean(ε) + 1e-9)` ∈[0,1] |
| 显著项 | `显著_norm(win) = mean(Ψ²_win) / (max_win mean(Ψ²) + 1e-9)` ∈[0,1] |
| 抑制返回 IOR | 对最近 **4 个**焦点：`ior_cell = max_f 0.5·exp(−Δt_拍/4)·1[|b−b_f|≤2 且 |slot−slot_f|≤4]`；`IOR_norm(win)=mean(ior_win)` ∈[0,0.5] |
| 总分 | **`score = 0.7·意外_norm + 0.3·显著_norm − 0.3·IOR_norm`**；意图偏置 S1 固定 0（无自上而下目标） |
| 选择 | 确定性 argmax；平局先取**更小带心**、再取**更早时槽**；一拍一个焦点 |
| 焦点链 | `deque[64]`，每条 `(拍号, 带心Hz, 带宽倍频程, s_t, sha256(Ψ_t)[:16])`；链满 64 后先进先出 |
| 高分辨面积 | 焦点窗 32/1024 = **3.125%** ≤ 15%（A-4 口径） |

### 2.5 流分离（H6 信息臂；先做确定性版本）
- 活跃图：`ε_cell > mean(ε) + 1.0·std(ε)` 的格；在 `(band, slot)` 上做 **4-邻域 BFS**（上/下/左/右），合并为连通块。
- 流匹配：与上一拍流表按**格重叠率 ≥0.5** 匹配，继承 `流id`；无匹配者按 `(最小时槽, 最小带)` 字典序开新流；流表 `dict[流id → (带范围, 时槽范围, 存活拍, 证据格数)]`，存活拍上限 20，超时删。
- H6 口径（信息臂）：合成两流交错，`流数=2` 且**每流内平均 ε < 混合平均 ε 的 0.6**。

### 2.6 遥测 / 工作区（C14：纯追加）
- 新件 `听觉工作区.py`：独立 `_听觉锁`（`threading.Lock`）+ `写听觉/取听觉`；字段：`听场[1024]`、`焦点(拍,带心,带宽,时槽)`、`误差场[1024]`、`意外度`、`逐格意外[192]`、`焦点链 deque[64]`、`流表`、`拍号`、`事件表 deque[256]`、`波形环 deque[320]`（S1 可空置）。
- 新件 `协议_听觉源.py`：`快照(区) -> dict`（新 profile **`听觉_S1_v1`**）：`听觉_意外度`、`听觉_事件率`、`听觉_流数`、`听觉_焦点停留`、`听觉_账本条目`（S1 固定 0）、`听觉_学习率`（固定 0）、`听觉_自他重合`（未测=空）、`拍号`、`指纹_听场/焦点链`。
