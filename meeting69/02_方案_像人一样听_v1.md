## 1. 架构（与视觉同构的听觉通路）

```text
波形 22.05 kHz
  │
  ▼
[前端 v0.1] 64 带 ERB 4 阶 gammatone（60–7800 Hz，因果）
  → 半波整流 → 立方根压缩 → 双适应（快 5 ms / 慢 100 ms）→ 1 ms 包络
  → 确定性事件检测（1 ms 定位；6 类：爆破/摩擦/浊音起/浊音止/元音核/静默）
  │
  ▼
[听觉场] Ψ：64 带 × 5 ms 帧（S0）→ 32 临界带 × 32 时槽 = 1024（S1，与视场同宽）
  │
  ▼
[预测/误差] 每拍：由上拍场/事件外推预测 → 误差场 ε、惊讶 s（∈[0,2]）
  │
  ▼
[听觉焦点链] f′ = 下一时频焦点（注意调制：显著度/意外/意图偏置 − 抑制返回）
  │
  ▼
[多模态绑定 β]（S1 桌面事件 / S2 人脸）：声事件 ↔ 视觉事件（onset/包络/节律/唇形），
               可塑核 h(τ) 从共现长（σ₀=150 ms → 收窄），绑定 = 听的产物
  │
  ▼
每拍输出：f′（下一听焦点）、s（惊讶）、Ψ（听场）、β（绑定记录） + 稀疏事件增量
```

**三个时钟**：耳蜗/包络 **1 ms**；听场帧 **5 ms**；注意拍 **S1 消融 40/50/100 ms**（S0 不依赖）。

## 2. 数据结构（纯追加，新 profile）

新「听觉工作区/听场槽」（独立锁）：

| 字段 | 形状/类型 | 含义 |
|---|---|---|
| `听场` | float32[1024] | 32 临界带 × 32 时槽（5 ms/槽，160 ms 窗），保拓扑 |
| `焦点` | (带心 b, 带宽 w, 起时 t, 持续 d) | 当前注意的时频窗 |
| `误差场` | float32[1024] | 场_t ⊙ 场_{t−1} 的向量形态 |
| `意外度` | float（0–2，与视觉同刻度） | 可喂情感唤醒（**带权可关**） |
| `逐格意外` | float32[192] | 6 带 × 32 时槽 |
| `焦点链` | deque[64] | (t, b, w, 意外度, 场指纹) |
| `事件账本` | 确定性结构（S1） | (事件键 → 后继事件键/计数)；零梯度 |
| `绑定表 β` | 列表 | (声源 id, 注视指纹, Δt, b, 存活拍, 证据计数) |

**接线纪律**：只读视场槽/意图槽；新增遥测键须**新开 profile**（禁跨 profile 比状态帧指纹）；不改七路契约/元素s/眼器。

## 3. 学习（S1 起；S0 零训练）

| 处 | 机制 | 约束 |
|---|---|---|
| 事件账本 | 束键 → 后继束（确定性淘汰）；相似=cos | 零梯度；照 meeting57 P0 先例但**不内建权限规则** |
| 稀疏 BCM | `Δw=η·e_i·y_j·(y_j−θ_j)`，η=0.01，θ 慢率 1/2000 | 只在 s>0.35 更新；行 L1≤1；防 meeting50「门控不优于常数」重演 |
| 事件驱动自适应 | AGC（带内增益/半饱和）、双阈值、稀疏度 | 无随机采样次数；固定种子 |
| 主干编码 | **不训练**（特征码固定随机投影，按维度缓存） | C13：两趟 sha256 逐位同 |

迁移判据（「没教过也会」）：H1 冻结单通道退化、H2 跨说话人/跨语速、H3 未教组合、H4 三 sham 必须失败、H5 确定性/延迟、H6 流分离；全部先写后跑。

## 4. 判据体系（与视觉同构）

1. **耳朵端（输入）**：A-1 决定性（同段焦点链 Jaccard ≤0.6）；A-2 适应（稳态第 3 s ≤ 第 1 s 的 40%；突变 1 拍命中 ≥0.8）；A-3 无标签非平凡（链熵 ≥1.0 bit）；A-4 误差驱动命中 ≥0.80 且 sham 随机焦点 0.05–0.15；A-5 重复收敛；A-6 视听联动（±120 ms ≥60%）；A-7 禁标签一致率 ≥0.90；A-8 P95 ≤33 ms + 两趟 sha256 同；
2. **嘴巴端（输出）**：`meeting67/08` 原文（M-O-*）**一字不改**；
3. **听觉特有（M-I-1..5，新增，并列不合并）**：+5 dB 噪声下 M 比 ≥0.7；竞争说话人 ≥真人−1.0；对口/错口增益 ≥真人 50%；异步 ≤120 ms「对口」≥80%、300 ms ≤40%；错得像人的混淆重叠 ≥0.5；
4. **S0 专用**：见 `03`（VOT/塞擦/擦音/声调/边界/适应/确定性）——**S0 不测可懂、不测像人**。

## 6. 风险与诚实边界

1. **预测塌缩**是最高概率失败点（meeting66 flow std 0.84 vs 真 3.49 同型）：S1 必须有 sham 与「误差驱动」判据；
2. **表示退化为 mel**：S0 的 log-mel 对照臂就是这条的否证点；
3. **无摄像头/人脸**：McGurk/唇读当前不可测（S2 待素材）；
4. **遥测改动**会改既有状态帧指纹：新键→新 profile，禁跨 profile 比；
5. 合成刺激 ≠ 自然语音；S0 只判前端性质，不判可懂/像人；
6. 不复活器官线；不宣称「像人一样听已实现」；空=未测。
