## 0. 结论先行（5 席 + Lead 独立收敛）

**「像人一样听」的可操作定义（全体收敛）：**

> **一条受注意调制的、时频局部化的、事件驱动的采样链。**
> 每拍输出 **(下一听觉焦点 f′, 预测误差/惊讶 s, 保拓扑听觉场 Ψ, 事件位/绑定 β)** ——
> **不是**「整段音频 → log-mel 80×10 ms → 音素/文字/特征列表」。

与 meeting38 视觉逐项同构：

| 视觉（已裁决） | 听觉（本会议） |
|---|---|
| 注视限制的采样（中央凹+外周） | **时频局部化采样**（焦点内全分辨、外周低分辨） |
| 眼跳链（主动看） | **听觉焦点链（主动听）**；静默/稳态不产生新拍 |
| 只传预测误差/惊讶 | **只传预测误差**；稳定声→适应（听而不闻） |
| 保拓扑视觉场 Φ（1024） | **保拓扑听觉场 Ψ（32×32=1024，tonotopic×time）** |
| 产物 = 下一注视点+惊讶+场 | 产物 = **下一听焦点+惊讶+听场+绑定** |
| 对稳定世界视而不见 | **对稳定声听而不闻** |

**最重要的三条裁决（详见 §3）**：
1. 丢的主要是**时间**，不是频率（语音学席纠偏：80 mel 的频率分辨≈临界带，别把「换更细滤波器组」当答案）；
2. **必须同跑 log-mel 对照臂**——对照臂无差 ⇒「换表示」主张被证伪（这比主臂过不过更重要）；
3. **绑定是听的产物**（多模态席）：每拍 4 元组含 β；但当前硬件**没有摄像头/人脸**，视听判据只能先做参数级口形 + 注入延迟，人脸臂标「未测」。

## 2. 交叉质询（Q1–Q9）与裁定

| # | 分歧/缺口 | 裁定 |
|---|---|---|
| Q1 | **定义**：3 元组 vs 4 元组（β） | **采纳 4 元组**（多模态席）：听焦点 f′、惊讶 s、听场 Ψ、绑定记录 β；β 可空（单听）但不省略字段 |
| Q2 | **前端频带**：64 带（生理席）vs 24 带（架构席） | **S0 主臂 64 带 ERB（60–7800 Hz）**；24 带作稀疏消融（S1）；log-mel 80 作对照 |
| Q3 | **采样率**：16 kHz（生理席）vs 22.05 kHz | **22.05 kHz（与 v13/meeting68 同源，便于对照）**；16 kHz 登记为消融档（S1） |
| Q4 | **时间精度/拍率**：1 ms 包络（生理/语音）vs 40 ms 拍（生理）vs 100 ms 拍（多模态/视觉同拍） | **事件/包络 1 ms、听场 5 ms、S0 不依赖注意拍**；注意拍率 S1 用 40/50/100 ms 三档消融再定（与视觉 100 ms 的对齐规则 S1 定，禁 S0 硬写） |
| Q5 | **事件层**：v0 全局阈值 + 50 ms 最小间隔 | **必须改**（语音学席）：异类 5 ms / 同类 8 ms 最小间隔、分通道自适应阈值、多类事件（爆破/摩擦/浊音起止/元音核/静默/重音）、1 ms 定位；S0 用 v0.1 |
| Q6 | **可懂度关键**：频率 vs 时间 | **采纳「时间为主」**：不追求更细滤波器组；S0 判据以 VOT/塞擦/边界/声调/F0 保留为主，**并跑 log-mel 对照臂** |
| Q7 | **学习**：端到端训练 vs 局部可塑 | **采纳内生架构席**：S0 不训练（只前端+事件+场）；S1 才做事件账本/稀疏 BCM/自适应，主干编码不训练；禁 Transformer/预训练/外挂模型 |
| Q8 | **多模态**：S0 做不做视听 | **S0 不做真实视听（硬件无摄像头/人脸）**；S0 可做「参数级口形三通道 + 注入延迟」的绑定核判死（半 write 半天 run）；人脸 McGurk 等 S2（需所有者提供 ≥5 min 正面视频） |
| Q9 | **评价**：S0 是否内嵌人耳；ASR 能不能当判据 | **S0 不内嵌人耳**（评价席）；ASR 只离线代理，不得当耳/判据门；人耳终判在 S0 PASS 后按 `meeting67/08` 排；**禁止**用 wav2vec/HuBERT/ECAPA 等外部模型证明前端「像人」（C10） |

## 3. 裁决（D1–D12，写入 AGENTS.md）

| # | 裁决 |
|---|---|
| **D1** | **定义统一**：像人一样听 = 受注意调制的、时频局部化的、事件驱动的采样链；每拍 4 元组（听焦点、惊讶、听场、绑定）；与 meeting38 视觉同构，产物不是音素/文字列表 |
| **D2** | **前端**：64 带 ERB 4 阶 gammatone（60–7800 Hz）+ 半波整流 + 立方根压缩 + 双适应（5/100 ms）+ 1 ms 包络 + 确定性 IF/事件；22.05 kHz；对照臂 log-mel 80/10 ms 必跑 |
| **D3** | **时间分辨率**：事件 1 ms 定位、听场 5 ms 帧；注意拍率 40/50/100 ms 三档留 S1 消融；与视觉慢层对齐规则 S1 定（S0 不写死） |
| **D4** | **事件层 v0.1**：异类 5 ms / 同类 8 ms 最小间隔、分通道自适应阈值、多类事件、1 ms 定位；**v0 的全局 50 ms 间隔缺陷作废** |
| **D5** | **S0 判据**：先写后跑；主判据 = VOT MAE / 塞擦双事件检出 / 擦音 5 类 / 声调 / 边界中位；**同跑 log-mel 对照臂**；对照臂无差 ⇒ 「换表示」主张被证伪，停 |
| **D6** | **多模态**：绑定是听的产物（β 进每拍输出）；绑定栅格 10 ms、可塑核 h(τ) 从共现长（σ₀=150 ms → 收窄），**人脸/真实视听 S2 前标未测**；S0 如需绑定只做参数级口形+注入延迟 |
| **D7** | **学习**：S0 零训练；S1 起用「事件账本 + 稀疏 BCM + 事件驱动自适应」，主干编码不训练；禁 Transformer/预训练/外挂模型；C13 两趟逐位同 |
| **D8** | **评价**：M-O（`meeting67/08`，一字不改）+ M-I-1..5 两套并列不合并；A-1..A-8 轨迹判据进预注册；ASR 只离线代理；外部模型不得作「像人」证据 |
| **D9** | **接线**：新增「听觉工作区/听场槽」（独立锁、纯追加）；只读视场槽/意图槽；遥测新增键须**新开 profile**（禁跨 profile 比指纹）；不改旧契约（C14） |
| **D10** | **v0 前端**：`耳蜗前端.py` v0 只作原型+自检证据（确定性/事件率/适应），其事件层缺陷按 D4 改；**S0 另开 `实施/耳蜗前端_S0.py`（不回改 v0）**；不因 v0 缺陷判死前端方向 |
| **D11** | **S0 预算/判死**：实现 ≤5 h + 跑 ≤1 h；判死门槛见 `03` §3；灰区限一轮重定位改进，不许改门槛 |
| **D12** | **诚实边界**：S0 只验前端是否值得替代 mel，**不验可懂/不验像人**；人耳终判在 S2；不复活器官线；不宣称「像人一样听已实现」 |

## 4. 未决 / 需所有者

1. **人脸/正面视频**：McGurk、唇读增益、真实视听绑定需要 ≥5 min 正面视频（S2）；没有则这些判据标「未测」；
2. **人耳排期**：S0 PASS 后按 `meeting67/08` 排 S2 人耳（≤10 min/批）；
3. **注意拍率 + 与视觉慢层对齐**：S1 消融后定，需所有者确认「听拍=视觉拍×N」的对齐规则；
4. **是否开放 16 kHz 消融档**（与旧声带 16 kHz 同源）——S1 再议。

## 6. 诚实边界（会议级）

1. 本会议**没有**产出「像人一样听」的系统；产出的是**统一口径 + 可执行方案 + 可判死 S0 预注册**；
2. 全部「人耳事实」带支持级别；精确阈值标 `[待核]`，必须在 S0/S1 实测，不当作已知；
3. S0 用**合成刺激**（VOT/塞擦/擦音/声调可控）+ 真实语音适应项；合成 ≠ 自然语音，只作前端性质判据；
4. 视听整合在无摄像头硬件下**不可测**（McGurk/唇读），只登记设计，不宣称；
5. 不复活 meeting67 器官线；不改 meeting66/67/68 既有件；C1/C9/C10/C13/C14 全程有效。
