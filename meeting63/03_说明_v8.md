### 8.2 根因（源码级）

- `韵律_v7.建帧()` 的 `末尾 = (j == n - 1)`（[韵律_v7.py](file:///<workspace>/03_AHI/AHI4/meeting62/实施/韵律_v7.py#L408-L429)），
  而鼻尾只在 `末尾` 时追加 ⇒ **只有短语最后一个音节有鼻尾**；句中 `-n/-ng` 只剩元音末 30% 的弱鼻化。
- 旧包络 `幅*(1-0.35k) if k<2 else 幅*0.30*(1-0.10k)` ⇒ 6 帧里只有前 2 帧有量（约 20ms），后 4 帧近无声。
- 这与 ASR 错误完全同形：`慢(màn)→辣(là)`、`今→七`、`很→哥`、`风→哥`、`轻→七`（全是鼻尾丢失）。

### 8.3 修法（只改 `韵律_v8.py`）

1. **鼻尾全音节化**：`if 鼻 is not None:`（不再看 `末尾`）；`N尾 = 8（短语末）/ 7（句中）`。
2. **借帧不拉长语速**：`帧数 = max(帧数 - N尾, 6)`，从元音段借帧给鼻尾，整句时长基本不变。
3. **持续包络**：`包 = A尾 * (0.92 - 0.22*(k+1)/N尾)`，`A尾 = 0.40（末）/ 0.36（句中）`，不再陡降。
4. 新增鼻零极点三列（`鼻增益/鼻极/鼻零`，默认 0 ⇒ 与 v5/v7 逐位同），供后续搜索；本轮的 `鼻增益=0.6` **实测变差，未采纳**。
5. 新增 `送气电平/不送气电平` 两个可搜参数（默认仍 0.80/0.32，本轮无增益）。
