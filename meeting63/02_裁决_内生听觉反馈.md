## 0. 结论先行

1. **撤掉外部 ASR 判官**：上一轮主控曾计划引入 `faster-whisper / funasr` 作「可懂度判据」——
   **这与 C10「禁外挂模型当器官/当判据门」冲突，所有者当场否决**。本轮已：
   - `pip uninstall faster-whisper ctranslate2 funasr av`（`[实测]` 已卸载，`find_spec` 全 False）；
   - 把上一轮取到的 ASR 读数**一律降级为「外部参考、非判据门」**（不落任何判据臂）。
2. **改用与所有者口径同构的三件内生件**（全部零外挂、纯 numpy/scipy ＋ 本仓 8 算子）：
   - `耳_内生.py`：**波形侧**确定性听觉前段（那对「脑子里的耳」）。
   - `皮层_音素格.py`：**HDC 谐振音素格**（内部深度学习模块的升级版）——学习/读出/诊断。
   - `学_咬字反馈.py`：**参考 ＋ 反馈学习**闭环（参考＝真人录音经耳量出的分布；反馈＝可分度误差）。
3. **判据回到内生**：可懂度用「**内生耳 ＋ HDC 皮层**」代理量（含三道 must-fail）；
   外部锚定只作**参考**（真人录音分布）与**准入门**（`ref44_*.wav` 人声正对照），**不作器官**。

## 1. 为什么 ASR 不能当判据（红线论证）

| 铁律 | 外部 ASR 方案 | 本轮内生方案 |
|---|---|---|
| **C1 禁 Transformer** | Whisper/Paraformer 都是 Transformer 系；作判据门＝把禁架构写进准入标准 | 只用本仓 8 算子（绑/解绑/门/叠/归/读/迭代）＋numpy，`禁词命中 0` `[实测]` |
| **C10 禁外挂模型当器官** | 需下载权重、运行第三方推理栈 ⇒ 判据依赖外挂模型 | 生成路径**零音频/零权重读入 0** `[实测]`；判据只读**本仓既有真人录音**作参考 |
| **C13 确定性可复现** | 神经 ASR 版本/权重漂移 ⇒ 判据不可复现 | 本仓算子走 2^-20 定点格；两趟 sha256 逐位同 `[实测]` |

## 2. 选路：内生耳 → 皮层 → 参考/反馈闭环

```
        ┌──────────── 说话 ────────────┐
        │  韵律_v8（参数 θ）/ 引擎_v7   │
        └──────────────┬───────────────┘
                       │ 波形
        ┌──────────────▼───────────────┐      参考（只读，真人录音）
        │  耳_内生（波形侧切段/感知量） │◀─────────── 耳量出辅音区统计
        └──────────────┬───────────────┘
                       │ 辅音区特征
        ┌──────────────▼───────────────┐
        │  皮层_音素格（HDC 谐振读出）  │── 可分度 / 混淆矩阵
        └──────────────┬───────────────┘
                       │ 误差（读出类 ≠ 意图类）
        ┌──────────────▼───────────────┐
        │  学_咬字反馈（坐标上升搜 θ）  │──▶ 回驱 韵律_v8.参数
        └──────────────────────────────┘
```

**为什么这是「参考＋反馈学习」而不是自证**：
- 反馈信号来自**波形侧**感知量（`耳`），**不是**生成器的内部帧 ⇒ 有真误差（见 §3 must-fail M1）。
- 参考来自**本仓既有真人录音**（外部真值），且**只作分布锚定**，不作器官。
- 搜索是**确定性坐标上升**（同种子两趟逐位同），目标＝可分度（主）＋ 参考距（次）。

## 3. 可证伪判据（本轮的「准入门」口径，含 must-fail）

| # | 判据 | 通过条件 | `[实测]` |
|---|---|---|---|
| P1 | 皮层留一音节可分度 | ≥ 3×chance（chance=0.2 ⇒ ≥0.6） | ✓ 0.857（种子0–2）/ 0.786（种子0–1） |
| P2 | 反馈学习不劣化 | 搜索后 ≥ 基线 | ✓ 0.7381→0.7857（种子0–1） |
| **M1** | **must-fail·波形敏感性** | 时间反转波形 ⇒ 特征必须变（≥80%） | ✓ **21/21 = 1.000**（真耳只认波形，没偷看帧） |
| **M2** | **must-fail·置乱标签** | 打乱意图标签后搜索仍近 chance（≤0.45） | ✓ 0.262 ≤ 0.45（真标签下 0.786） |
| **M3** | **must-fail·白噪/静音** | 白噪/静音喂同一管线必须 FAIL | ✓ 浊帧 0、不落窗 |
| **M4** | **零外挂三断言** | A 生成路径零音频/零权重读入；B 禁词/禁包 0；C 两趟逐位同 | ✓ 0/0/0 ＋ 逐位同 |
| 准入门 | 外部真人正对照 | 11 个 `ref44_*.wav` 须全 PASS | ✓ 11/11 |

> **M1 的意义**：若「耳」其实是在偷看生成器的内部帧，那么波形怎么改（例如时间反转）它的读数都不会变；
> 实测 21/21 全变 ⇒ **真耳只吃波形**。这条把「自听」从口号变成可证伪。

## 5. 追加裁决（同日后半段）：ASR 以「**外部评估仪器**」身份回归

所有者随后改口：「不是有 ASR 语音识别模型吗？…输出物送到这个模型，让它彻底一点，看看能不能输出和原来一样的」。
本裁决追加：

- **允许**把 ASR（ModelScope **Paraformer-seaco-large**，中文专用，离线）用作**可懂度评估仪器**
  （`实施/判据_可懂度_ASR.py`：合成音频 → ASR → 对**已知原文**算 **CER**）。
- **仍然禁止**把 ASR（或任何外挂模型）接入**生成路径**；`审计_零外挂.py` 的 A/B/C 三断言
  （生成路径音频/权重读入 0、禁词禁包 0、两趟逐位同）**照旧成立** ⇒ C10 不被突破。
- `[实测]` 结果：sham（白噪/静音）CER **1.000**（must-fail ✓）；v8 三角色 CER 均值 **0.771**，
  优于 v7 的 **0.812**（靠 `鼻尾 2帧→6帧` 的定向修复）。**绝对 CER 仍 ≈0.77 ⇒ 尚未「听清楚」**。
