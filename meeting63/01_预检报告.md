## 0. 一句话结论

**「咬字不清」在本轮被拆成两条可证伪的实测**：
① 波形侧**内生耳**（零外挂）显示 v7 的清/浊段时长**与真人参考同量级**（清段中位 60ms vs 真人 60–75ms）
  ⇒ **时长不是主因**（推翻了「辅音太短」的最初假设）。
② **HDC 谐振音素格**（内部深度学习模块，留一音节 63 样本）在 v7 产出上**可分度 0.873**（chance 0.20），
  残留混淆是 **「送气塞 p/t/k ↔ 塞擦 z/c/zh/ch/j/q」**（9 个送气塞里 4–5 个被读成塞擦）
  ⇒ **合成端「送气塞/塞擦」的除阻－摩擦对比不足**，这才是可测的「咬字」缺陷。

## 2. 波形侧内生耳 `耳_内生.py`（`[实测]`，零外挂，只读波形）

耳用确定性 DSP（20ms 帧/10ms 跳、能量门 + 自相关浊度门）在**波形**上切段，**不读任何内部帧**：

| 样本 | 清段中位 | 浊段中位 | 清总占比 | 清浊时长比 |
|---|---|---|---|---|
| 真人·EmoCompanion ref44_01 | 60.0 ms | 220 ms | 0.216 | 0.301 |
| 真人·SpeakerA ref44_01 | 75.0 ms | 190 ms | 0.089 | 0.114 |
| 真人·洛天依·清唱01 | 65.0 ms | 390 ms | 0.145 | 0.171 |
| **合成 v7·EmoCompanion** | **60.0 ms** | 165 ms | 0.204 | 0.292 |
| 合成 v7·SpeakerA | 60.0 ms | 165 ms | 0.204 | 0.290 |

⇒ `[实测]` **合成端清段时长/占比落在真人域内** ⇒ 「辅音太短」在**语流尺度上不成立**。
（帧侧的「偏短」主要来自**孤立音节 vs 语流**的口径差与文献采集口径差。）
**这一条推翻了本轮最初的「把辅音拉长」修法**。

## 3. 内部深度学习模块（HDC 谐振音素格）`皮层_音素格.py`（`[实测]`，零外挂）

- **表示**：辅音区感知特征（首类/区长/清长/静长/浊长/谱重心/谱峰/瞬态度）→ `role⊛value` 绑定 → `叠` 成类原型；
  `读(原型码本, 段向量)` 做谐振读出。只用本仓 8 算子（绑/解绑/门/叠/归/读/迭代）＋numpy。
- **协议**：**留一音节**交叉验证（每折以余全部音节训练、留出该音节测试；3 种子 × 21 音节 = 63 样本）。
- `[实测]` **v7 可分度 0.873**（chance 0.200 ⇒ 4.36×），混淆矩阵：

| 意图 ↓ / 读出 → | 不送气塞 | 送气塞 | 擦 | 塞擦 | 鼻边 |
|---|---|---|---|---|---|
| 不送气塞 | **9** | | | | |
| **送气塞** | 1 | 4 | | **4** | |
| 擦 | | 1 | **13** | 1 | |
| 塞擦 | | | 1 | **17** | |
| 鼻边 | | | | | **12** |

- must-fail `[实测]` 全过：置乱标签 0.095、直读 0.064、白噪 0.000（均近 chance）⇒ **不是自证**。
- `[实测]` **波形敏感性 21/21**（时间反转 ⇒ 特征 100% 变化）⇒ **真耳只认波形、没偷看内部帧**（可证伪）。

## 4. 结论：真问题 = 「送气塞 / 塞擦」的除阻－摩擦对比不足

- 合成端 `送气塞` 与 `塞擦` 都是「闭塞 + 一段噪声」，**除阻爆破的瞬态不显著**（v7 爆破固定 10ms 恒幅），
  摩擦段时长也接近（VOT p/t 40ms vs 塞擦擦时 z 37ms / c 50ms）⇒ 谐振格把它们读成同一类。
- 这是一个**具体、可测、可改**的缺陷（不是「整体模糊」这种不可操作的描述）。

## 5. 诚实边界（未测项）

1. **无真人盲评**（G1 仍在）：可分度/混淆是**内生代理量**，不等于人耳听感；本报告的结论**以耳与皮层为准**。
2. 皮层**只测辅音区 5 类**；声调/元音/韵律不在本件；F=1 类别的样本数少（送气塞训练件仅 3）。
3. 真人参考是**歌唱/朗读混合**且**无标注** ⇒ 只作**分布锚定**，不作逐音素对照。
4. 耳的分段阈值（静阈 30dB、浊阈 0.35）为 `[提案]`，未用第二套阈值复核。
