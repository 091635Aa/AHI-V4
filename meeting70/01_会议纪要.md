## 0. 一句话回答

**「原生声音输出」当然优于拼接——但项目自己的原生器官（v0 等价类）已经被测死：在 oracle 控制下 ASR CER 0.49/0.44。拼接不是目的，是绕过「v13 模型 mel 外星人」的临时桥；它解决了音色，没解决内容与韵律。**
**裁决：走器官 v2（物理发声器官）+ 小样本参数反演（零训练）；拼接降为对照臂；按 meeting67 `09` §6 新预注册后执行。**

## 1. 逐问回答

**Q1 原生声音输出为什么不行？**
不是「不行」，是**这一版器官太粗**。G0/G0-v2 判死的是 v0 等价类（18 阶 LPC + 单脉冲/固定气声 + 10 ms 栅格）：零训练、**oracle 控制**（等于控制全对）下 P2 CER **0.4922 / 0.4412**，失败位置在**激励/瞬态/清擦起音**（长句 0.02–0.22、短句 1.0）。同一条链上**真 mel→GL CER 0.05** ⇒ 评测链与文件格式无罪，**器官的激励不行**。v1 物理器官（LF 声门源 + KL 波导 + 三类噪声 + 亚帧瞬态）**从未建成**，所以「物理器官上限」没有被测过。

**Q2 为什么要拼接？**
因为 v13 的 mel 是外星人：CAM++ 0.13–0.23、Whisper 空、Qwen3-Omni「猪叫」。听审团同时证明**真人 mel→同一 GL = 真人、内容全对**（CAM 0.9285、CER 0.0），所以病灶在模型不在声码器。拼接 = **绕开模型、直接借真人录音**，换来了音色（CAM 0.56/0.68、Omni 判「真人、无不自然」），但**内容乱**（CER 0.76→0.86–1.0）。本轮新证据：**ASR 对齐的「音节帧边界」与谱通量无关（边界 flux ≈ 随机，比 1.00–1.04）⇒ 切点切在音节中间，拼接是半音节链**。拼接即使修好边界，**韵律仍是机械的**，达不到「像人类一样」。⇒ **降为对照臂**。

**Q3 像人类一样怎么做？**
人说话 = **发声器官 + 控制**。工程化、零训练的形式是：
① 先证明**器官渲染上限**（oracle 控制 → 器官 → 声学/听审）；
② 再从 ≤5 min 真人录音**反演出控制轨迹**（F0/清浊/共振峰/噪声/时长，解析提取，非训练）；
③ 让器官**重放老师的控制轨迹**（同句模仿），再推广到任意文本（用字表 + 韵律模板）。
**这就是「像人类一样」的最小可判版本。**

## 3. 裁决（D1–D10）

- **D1** 拼接**不是**「声音输出」，仅是**采样回放/对照臂**；不得作为主线，也不得作为「像人」证据。
- **D2** 「原生声音」= 项目自有**发声器官**（声门源 + 声道 + 噪声 + 唇辐射），由**控制参数**驱动；不是 v13 的 mel→GL。
- **D3** meeting67 的判死只对 **v0 等价类**成立；**物理器官 v2 从未被测**。按 `09` §6，**新预注册后重开**，版本号 v2，**不与 G0 旧读数混用**。
- **D4** 器官 v2 规格：22.05 kHz；LF 可微声门源（气声按 HNR 混合）+ Kelly-Lochbaum 波导（3–6 维面积函数）+ 清音/送气噪声 + 亚帧瞬态（1–3 ms）+ 鼻/唇辐射；控制帧 5 ms：`(logF0, 清浊, 共振峰 R⁴, 噪声比, 能量)`；内部步长 ≤0.25 ms。
- **D5** **零训练**：不更新任何权重、不拟合网络；参数提取用闭式/解析；参数检索只用坐标一格（≤5 个量），每步落盘。**不复用 meeting68 被否决的「强制旋钮」叙事**。
- **D6** 门 1 **G0v3（渲染上限）**：oracle 控制 → 器官 v2 → ASR+听审团；**≤0.20 PASS / (0.20,0.35] 限一轮 / >0.35 判死 v2**（沿用 meeting67 门）。
- **D7** 门 2 **A 反演**：≤5 min 真人 → 参数 → 器官重放；**自重建 CER ≤0.25 才续**。
- **D8** 门 3 **C 模仿**：任意句；**Qwen3-Omni 判「真人 + 内容基本对 + 无不自然」、CAM++ ≥0.55、Whisper 与 Paraformer 双 CER ≤0.35、两趟 sha 同**；M2 三条未参与调参的新句复现 ≥2/3。
- **D9** 评价：听审团四模型**只作仪器**（C10），必须含 must-fail 反例（静音/白噪/异说话人/乱序），人耳终判以所有者为准；**拼接必须先修音节边界（谱通量谷 + DTW 校验）才可进对照表**。
- **D10** 纪律与预算：新件全落 `meeting70/`（C14）；`meeting32/声带.py`、`meeting67/` 只读；先预注册再跑。里程碑：**S1 器官 v2 实现（≤2 天）→ S2 G0v3（≤1 天）→ S3 反演 A（≤1 天）→ S4 模仿 C（≤2 天）**；任一门判死即停、登记、上报。

## 4. 判死（先写死）

1. **G0v3 >0.35** ⇒ 物理器官 v2 判死（当前工程水平），**不再给第 3 次器官机会**；回拼接对照或另立新路线（须另立预注册）。
2. **A 自重建 >0.25** ⇒ 参数反演不可辨识，回器官席找原因（不是继续调参）。
3. **C 双 ASR >0.60 或 Omni 判「不像人」** ⇒ 模仿路线判死。
4. 任何臂只报最好句子、或 M2 复现失败 ⇒ 判为过拟合，不算达成。

## 5. 对所有者指令的落实

- 「**不要训练**」⇒ D5，全流程零梯度；只允许解析提取 + 坐标检索。
- 「**特别小的数据上模仿**」⇒ D7/D8：≤5 min（D0），反演 + 重放 + 跨句模仿。
- 「**像人类一样**」⇒ D2/D4：自己的发声器官驱动，而不是采样回放。
- 「**专家会议**」⇒ 5 席 + Lead 独立立场；本纪要 + `团队/*`。
