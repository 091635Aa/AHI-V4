# meeting70 · 发声器官_物理声学 R1

## 立场
**「原生声音」要成立，必须把发声器官从 v0 等价类升级到 v1 物理器官**；否则无论怎么调控制，出来的都是「带共振峰的嗡嗡声」。我同意回器官线，但**反对直接跳到「模仿」**——先证明器官的渲染上限，再谈控制。

## 依据（项目读数，不重述为结论）
- meeting67 G0/G0-v2 判死的是 **v0 等价类**：18 阶 LPC 全极点 + 单脉冲/固定气声 + 10 ms 栅格。零训练 oracle 控制下 **P2 CER 0.4922 / G0-v2 0.4412**。失败位置已被纯 DSP 诊断定位到**激励/瞬态/谱保真**（气声是死参数、清擦/清音起音段完全崩、长句 0.02–0.22 而短句 1.0）。
- 同一条 G0v2 里，**真 mel→GL 声码器阳性对照 CER 0.0585/0.0489** ⇒ 22.05k 管线、文件格式、评测链都没有问题；问题在**激励**。
- AHI3/meeting32 `声带.py`（16 kHz, v8.1）人耳「只听到几个字」，CER 0.53 ⇒ 老声带同样卡在激励与 10 ms 栅格。

## 方案（器官 v2，最小改动顺序）
1. **源**：LF 模型可微声门流（Open Quotient / 声门闭合速度可调）+ 气声噪声按 HNR 混合；清音/送气用噪声源 + 湍流滤波。
2. **声道**：Kelly-Lochbaum 波导（3–6 维面积函数）替代 LPC 全极点；共振峰由面积函数决定（可反演）。
3. **瞬态**：亚帧事件（爆破 1–3 ms 双脉冲、摩擦噪声起始斜坡），**不用 10 ms 栅格**；内部步长 ≤0.25 ms，输出 5 ms 帧。
4. **鼻/唇辐射**：一阶鼻分支 + 唇辐射微分；总 8–12 个可反演参数。

## 判据与风险
- **G0v3（零训练渲染上限）**：oracle 控制（从真人 F0/共振峰/清浊/噪声直接给）→ 器官 v2 → ASR+听审团；**≤0.20 PASS / (0.20,0.35] 限一轮 / >0.35 判死 v2**。
- 风险：v1 器官实现量（波导+可微源+瞬态）约 1–2 天；若 G0v3 仍 >0.35，说明「物理器官 + 手工控制」在当前工程水平不成立，必须回模型线或拼接。
- **我不承诺 v2 会过**；但这是唯一能回答「像人类一样」的诚实实验。
