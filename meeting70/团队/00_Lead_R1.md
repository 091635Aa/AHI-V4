# meeting70 · 团队/00_Lead_R1（独立立场，先于各席）

**立场一句话**：拼接是**绕开病灶的临时桥**，不是「声音输出」；「像人类一样」只能是**自己的发声器官 + 从少量真人语音反演出控制轨迹**。我建议会议裁定：**回器官线，开 v2（物理器官），以零训练渲染上限为第一道门；拼接降为对照臂。**

三条我坚持的判断：

1. **不要把「原生」和「v13 模型」混为一谈**。所有者说的「原生声音输出」是**声带/发声器官**，不是 v13 的 mel→GL。v13 已经被听审团判死（外星人）；而器官线被 meeting67 判死的是 **v0 等价类**（18 阶 LPC + 单脉冲 + 10 ms 栅格 + 固定气声），不是「器官路线」本身。两者都必须如实分开：一个是**模型病**，一个是**器官实现太粗**。
2. **拼接现在不能作为主线**。它确实立刻给出了「真人音色、无电音沙哑」（CAM 0.56/0.68，Omni 判「真人」），但**内容不可用**；本轮边界实测显示，ASR 对齐的「音节帧」与谱通量无关（边界 flux ≈ 随机），单元切点本身是错的。修边界可以试，但拼接的天花板是**机械韵律**，永远达不到「像人类一样」。结论：拼接只作对照。
3. **「像人类一样」的可判定形式**是：**发声器官被控制参数驱动 → 控制参数从 ≤5 min 真人录音里反演出来 → 器官渲染出的声音过听审团与 ASR 门**。这不是训练，是**分析-反演 + 参数检索**；这正是「模仿」的工程定义。

**我给的裁决草案（供各席攻）**：
- D-a 拼接降为对照臂，且必须先修音节边界（谱通量谷 + 强制对齐）才可作为证据。
- D-b 按 meeting67 `09` §6 **新预注册**重开器官线，版本号 **v2**（物理器官），**不与 G0 旧读数混用**。
- D-c 第一道门 = **零训练渲染上限 G0v3**：oracle 控制 → 器官 v2 → ASR+听审团；**≤0.20 PASS / (0.20,0.35] 限一轮 / >0.35 判死 v2**。
- D-d 第二道门 = **小样本反演 A**：≤5 min 真人录音 → 控制轨迹（F0/浊音/共振峰/噪声）→ 器官；**自重建 CER ≤0.25 才续**。
- D-e 第三道门 = **模仿 C**：反演出的控制轨迹说任意句；听审团判「真人/无不自然」、CAM ≥0.55、双 ASR CER ≤0.35。
- D-f 不训练：不更新权重、不拟合网络；只用闭式统计与坐标检索；C1/C10 不变。
