# meeting70 · 系统_红线与集成 R1

## 立场
**支持回器官线，但必须先过「重开条款」**：meeting67 `09` §6 明确「重开器官线须新预注册」。本会议纪要只能作为**裁决 + 预注册前置**，不能跳过预注册直接开跑。另：**不训练**是本轮的硬约束，必须写进每一张判据卡；任何「训练一下就好」的建议本席一律反对。

## 依据与红线
- 铁律：C1 禁 Transformer ｜ C9 禁 OCR ｜ C10 禁外挂模型当器官 ｜ C13 确定性 ｜ C14 不破既有。
- 本轮新增：听审团四模型**只作仪器**（Qwen3-Omni/CAM++/Whisper/Paraformer），**禁止进入生成路径**；`meeting32/声带.py`、`meeting67/实施/` 只读；新件全部落 `meeting70/`（C14）。
- 时间/预算纪律：先预注册 → 跑 → 落盘 → 判死；**不许先跑后补口径**；负结果照登。

## 集成与工程口径
1. **统一 22.05 kHz 内部口径**（旧声带 16 kHz 不改，仅作对照；新器官 22.05k），输出 5 ms 帧；内部步长 ≤0.25 ms。
2. **参数接口**：`控制帧 = (logF0, 清浊, 共振峰 R⁴, 噪声比, 能量)`，5–7 标量/5 ms；与 meeting69 的听觉链共用时间基（10 ms 拍对齐可行）。
3. **确定性**：固定种子、固定归约顺序、CPU 优先；两趟 sha256 同。
4. **评测链复用**：ASR/CAM++/Whisper/Omni 脚本已在 `meeting69/实施/判据_拼接声.py` 与 `产物/听审/` 探好，直接复用，不重造。

## 反对项
- 反对把拼接当主线：它是采样回放，不是器官；若继续，必须同时修边界（`meeting70/02`）。
- 反对「先训练再说」：与所有者指令冲突；若本轮器官 v2 判死，正确动作是登记负结果 + 提新方案，而不是偷偷训练。
- 反对跳过预注册：器官线已被判死一次，重开必须留档、可复核。

## 判据卡要求
每张卡必须含：预注册路径、数据档（≤5 min）、判据表、must-fail 反例、判死条款、读数路径、C14 备份记录、确定性两趟。
