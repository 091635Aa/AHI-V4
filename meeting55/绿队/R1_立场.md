## §0 五条结论

1. **耳朵已有现成的两通道，但缺第三通道（声纹）**：`耳朵.py:60-103` 帧特征（F0/能量/7 带/谱平坦度）、`:146-160` 8 维韵律指纹（情绪）、`:113-143` 声向量（内容/HDC）；**没有 speaker embedding**，且 `:197-205` 辨情绪用**未归一化**原始指纹 ⇒ 情绪会被说话人基线（F0/音色）混淆。
2. **T1 的三通道口径**：内容=`声向量`（含 F0 轮廓/7 带，`:113-143`）；韵律=`8 维指纹`+语速/停顿（`:146-160`）；音色/声纹=**新增** 7 带包络+F0 基线+平坦度（17 维，按说话人 z-score）；语调=**F0 轮廓形状**（陈述/疑问/感叹/强调，走 `读/相似`，与情绪的绝对量分开）。
3. **融合用「说话人条件归一 + 逐源加权」**：`p_e=normalize(0.6·p_voice+0.3·p_text+0.1·p_self)`（冲突时声音权重升到 0.75）——不引入 softmax 也行（各源已是概率向量，按分量加权后再归一）。
4. **T2 决策网络 =「符门控融合层 + 双策略头」**：输入 听觉态（32 维）+ V5 自我态/内心；`h=归(Σ_i 门_i⊙(W_i x_i))`，`门_i=符(A,x_i)` 逐元素；输出离散（回应类别/打断/动作）+ 连续（ΔF0/Δ语速/Δ能量/Δ气声/Δ紧喉/Δ声区/共振峰缩放）+ 文本风格偏置；接 `声带.发声`（`:478-526`）→ 扬声器 → 耳自听回环。
5. **T3 音色 = 9 参数档案（声带 8 + 新增共振峰缩放）+ 参数化模仿**：原生声带主线（确定性、可解释、`实时率≤0.5` 判据见 `:511-522`），TTS 只作对照且标外源；「原声输出」口径=**参数模仿，不是真声克隆**（禁 RVC/神经 TTS，见情感韵律专家铁律）。

## §1 T1 听觉：三通道 + 声纹 + 多源融合

### 1.1 可执行特征表（窗口：25ms 帧 / 10ms 移，`耳朵.py:44-45`；句子窗 1.5–3s）

| 通道 | 特征（维） | 现成/新增 | 用途 | 阈值位置 |
|---|---|---|---|---|
| 内容 | 声向量 D=1024（F0 轮廓+7 带槽绑定） | `耳朵.py:113-143` | 听清说什么（音高轮廓=声调） | 命中相似度（`读` 阈值） |
| 韵律/情绪 | F0 均值/std/十分位距、能量均值/std、谱平坦度均值/std、时长（8 维） | `耳朵.py:146-160` | 高兴/平静/低落/急促 | z-score 后最近原型；4 类 acc |
| **音色/声纹** | 7 带均值对数包络（7）+ F0 基线（1）+ 平坦度均值（1）= **17 维**（新增） | 耳朵未提供（`辨` 只比声向量，`:184-195`） | 认人/声纹接受拒绝 | 余弦距离；EER |
| 语调 | F0 轮廓折线（起/中/末半音）+ 末音升降（4 维） | 特征帧 F0 已有（`:60-103`） | 陈述/疑问/感叹/强调 | 4 原型最近邻 acc |
| 说话人归一 | 每人 F0 基线/能量基线（入档） | 新增；`:148` 已注明「需 z-score」 | 去说话人混淆 | 基线内 ±2σ |

### 1.2 更新式/伪代码（每句）

```
特征帧(n帧) → 8 槽聚合 → 指纹 p∈R^8；声纹 s=归(叠([7带对数, F0基线, 平坦度]))
p ← (p − μ_speaker) / σ_speaker                  # 说话人条件归一（关键：否则 F0 高=情绪"高"）
p_e = NN(韵律原型库, p)（4 类）；t = 读(语调码本, F0轮廓)（4 类）
p_e ← normalize(w_v·p_e + w_txt·p_text + w_self·p_self)  # w=(0.6,0.3,0.1)；声音/文本冲突时 w_v=0.75
输出 听觉态 = {情绪4, 语调4, 风格4轴(快慢/高低/强弱/停顿), 声纹 s+cos, 置信}
```
**与 T2 接口**：听觉态 32 维（4+4+4+17+3 置信/时长/信噪比）→ 决策网络。

### 1.3 四件套
- **主张**：三通道分离（内容/韵律/音色）后可同时读出情绪、语调、说话人；若不分离，F0/音色基线会把「谁在说」误判成「什么情绪」。
- **证据**（[实测] 只读源码）：`耳朵.py:146-160` 指纹用绝对 F0/能量，`:148` 自认需 z-score；`:197-205` 辨情绪做原始欧氏距离（跨说话人必混）；`:184-195` 辨只比声向量（内容相关，做声纹会受内容污染）；`听觉学院.py:86-111` 只有自适应起音门槛，无 VAD/端点/声纹（`:13` 判据 G1/G2/G3 仅起音）。
- **反证**：①标签置换/随机输入 ⇒ 情绪 acc 必须跌到 ≤0.35（否则判据无效）；②同人不同内容 vs 异人同内容：声纹余弦应「同人 > 异人」（否则声纹=内容）；③去掉说话人归一 ⇒ 换人后情绪判错率上升 ≥0.20；④换情绪输入但声纹不变 ⇒ 情绪读出必须变（vice versa）。
- **代价**：25/10ms 帧 + 8 槽聚合，纯 numpy CPU，[未验证假设] <5ms/句；采集 1.5–3s；不占 GPU。

## §2 T2 决策：听觉态 → 决策网络 → 声带

### 2.1 网络结构（小网络，CPU；D=128–256）
```
输入：x = [听觉态(32) | V5 自我态 A(64) | 世界态 B(64) | 内心 a_t(64)]     # 共 ~224 维
门控融合：h = 归( Σ_i 门_i ⊙ (W_i x_i) )，门_i = 符(A, x_i)（逐元素，无 softmax）
离散头：回应类别(安慰/回应/提问/沉默) / 是否打断 / 动作(点头式音量/键鼠) = argmax
连续头：ΔF0, Δ语速, Δ能量, Δ气声, Δ紧喉, Δ声区, 共振峰缩放（线性回归 → 声带 8/9 参数）
文本风格头：短/暖/正式 → 语言层选词偏置（meeting54 的语用门）
链路：耳.听 → 听觉态 → V5 核一拍（感觉=归(绑(音码,A)+绑(文本码,A))）→ 决策头 → 文本 + 声带参数 → 声带.发声(向量,文本,遥测) → 扬声器 → 耳.听（自听回环）
```
### 2.2 训练与因果
- **训练目标**：离散交叉熵 + 连续 MSE；teacher=所有者标注 50–100 条「听到 X→回应 Y」+ 规则冷启动（先验表只作 teacher，不进网络常量）；2 层、~10 万参数、CPU 训练 [未验证假设]。
- **因果判据**：换情绪输入 ⇒ 离散头 argmax 改变率 ≥0.30 且连续参数至少 2 项变化 ≥阈值；随机听觉输入 ⇒ 改变率 ≤0.30（must-fail）；**冻结 A** ⇒ 决策不变（若不变 ⇒ 决策与自我态无关，判「未接核」）；换声纹 ⇒ 称呼/亲密度类输出必变。
- **接 V5**：`声带.发声` 的向量输入可用 V5 的 `o用`/意图向量（`声带.py:478-486` 内部 `分位读数` 生成 qs，`:240-246`）；内心不直接进声带，只经决策的连续头。
- **四件套**：主张=听觉态经 V5 门控可因果驱动回应/声带；证据=V5 已有 A/B/内心接口（meeting53 `V5:190-213`）+ 声带已有 8 参数入口；反证=置换标签/随机输入/冻结 A 三臂；代价=每拍 <5ms（未测），训练 CPU 分钟级。

## §3 T3 说：音色档案 / 模仿 / 情感韵律

### 3.1 音色档案（9 参数 + 包络）
```
档案 = {基线F0, 语速, 气声, 紧喉, 粗糙, 送气, 声区, 共振峰缩放 k_f, 7带包络}
估计（3–5 句录音）：F0 中位数/范围→基线F0；音节/秒→语速；平坦度→气声；H1-H2(带比)→紧喉；F0 范围→声区；
                  7 带中心比→formant proxy→k_f（0.85–1.15）；包络→7 带均值
套用：覆盖 声带.韵律(遥测) 输出（`:220-237`）+ 基线F0（`:217`）+ 音节帧的 f1/f2/f3 × k_f（`:249-364`）
```
### 3.2 情感韵律映射（情绪→8 轴；先验表可测）
| 情绪 | ΔF0(半音) | Δ语速 | Δ能量 | Δ气声 | Δ紧喉 | 声区 |
|---|---|---|---|---|---|---|
| 高兴 | +2~+4 | +20% | +0.15 | −0.10 | +0.05 | +0.10 |
| 平静 | 0 | 0 | 0 | 0 | 0 | 0 |
| 低落 | −3 | −20% | −0.20 | +0.15 | −0.10 | −0.10 |
| 急促/紧张 | +1~+3 | +25% | +0.10 | +0.05 | +0.15 | +0.05 |
> 现成公式 `声带.韵律(遥测)`（`:220-237`）已把能量/新异/债/饱映射到 8 参数；本表把输入从「遥测」换成「情绪后验」，公式族保留。
### 3.3 相似度与边界
- 相似度：F0 分布 EMD ≤15% 基线；7 带包络余弦 ≥0.85；语速 ±20%；must-fail=用别人档案 ⇒ 三项至少两项掉线。
- **原生 vs TTS**：原生=确定性、参数可解释、C1 合规但机械；TTS=自然但外源（pyttsx3 `声带.py:557-581` 已有兜底）、情感不可控、采样不确定。**推荐原生主线**，TTS 只作对照并标「外源」。
- **「原声输出」口径**：参数化模仿（从本人录音估 9 参数→原生声带发声），**不是真声克隆**；不主张「所有者原声复现」。
- **四件套**：主张=9 参数档案可模仿音色且情感可驱动；证据=声带已有 8 参数+`发声` 自检（`:511-522`）；反证=换档案不降相似度 ⇒ 档案无效；代价=合成实时率≤0.5（既有判据），CPU。

## §4 T4 判据 / 资源 / 风险

| 判据 | 阈值（提案，未测） | 必须失败对照 |
|---|---|---|
| 情绪 4 类 acc（留一说话人） | ≥0.70（跨说话人 ≥0.60，机会 0.25） | 标签置换 ≤0.35；随机输入 ≤0.35 |
| 语调 4 类 acc | ≥0.70 | 同一轮廓置乱后 ≤0.35 |
| 声纹 EER | ≤10%（阈值取 EER 点） | 同人异内容 vs 异人同内容必须可分 |
| 音色相似 | F0 EMD ≤15%、包络 cos ≥0.85、语速 ±20% | 用别人档案 ⇒ ≥2 项掉 |
| 情感输出 | 高兴 vs 低落 ΔF0 ≥2 半音、Δ能量 ≥0.10、Δ语速 ≥15% | 固定参数臂 Δ=0（must-fail） |
| 因果：听觉→决策 | 换情绪输入 ⇒ 决策改变率 ≥0.30；随机输入 ≤0.30 | 冻结 A ⇒ 若不变判「未接核」 |
- **真机闭环**：麦→VAD/端点（300ms 静音）→ 特征 → 决策 → 声带 → 扬声器 → 麦自听；单探针 ≤30s、不长时间占声卡；麦克风输入**记录-重放**用于两趟。
- **风险**：隐私（录前知情、本地、删原始）；噪声（SNR≥15dB 才评）；延迟（原生实时率≤0.5 既有判据）；确定性（声卡输入非确定 ⇒ 测试用录制文件）；TTS 越宪须登记。
- **四件套**：主张=以上判据可判「听到/决策/说出」；证据=既有 `耳朵.py` 特征、`声带.py` 自检、`听觉学院.py` 声学环路（`:200-207`）；反证=must-fail 表；代价=采集 3–5s/句、合成实时率≤0.5、GPU 不用。

## §5 私有假设 + 大白话

**私有假设**：①声纹用 7 带包络+F0 基线代理即可（不引入外挂 speaker 模型）；②情绪先做 4 类（高兴/平静/低落/急促），不追求细粒度；③情感映射表是**先验 teacher**，最终由标注数据校准；④「原声」=参数模仿，不是克隆；⑤TTS 只作对照，不进主线宣称。
**大白话**：先给它三只耳朵：听内容、听语气、认是谁；先把「谁在说」扣掉，情绪才不串。按自己状态加权决定怎么回；说时每人一份声音档案，用原生声带照参数说——是模仿，不是克隆。
