## 0. 一句话

做成了「**听得见 → 决策 → 说得有情绪、可定制音色**」的最小闭环：麦克风采集 → 情绪/风格/语调/声纹 → 决策网络（回应情绪/语速/音量）→ 原生声带用对应音色与情绪说话 → 扬声器；12 臂 **10 PASS / 2 FAIL**（声纹、同时录放未成立，已如实登记）。

---

## 1. 架构

```
麦克风(WASAPI 17, 48k→16k) → 帧特征(25ms/10ms)
   ├─ 情绪通道：F0 半音 / 能量 dB（对说话人中性基线归一）→ 平静/高兴/低落
   ├─ 风格通道：语速(峰率)/音高/能量/停顿 → 快慢/高低/强弱/多少
   ├─ 语调通道：F0 轮廓 → 陈述/疑问/感叹
   └─ 声纹通道：绝对谱（7 带包络+谱重心/平坦+F0std）→ 说话人验证
        ↓ 听觉事件
决策网络（1 隐层 MLP，12 维输入 → 3 头：回应情绪3 / 语速档3 / 音量档3）
   teacher = 规则（低落→慢/低/平静；高兴→快/中/高兴；平静→中/中/平静）
        ↓ 决策
执行：回复文本（角色包/Qwen，标来源） + 音色档案 + 情绪 → 原生声带
   → 声带参数（F0/语速/幅度/气声/紧喉/粗糙/送气/声区）→ Rosenberg+Klatt → wav
   → 扬声器(WASAPI 14)（可选）→ 麦克风自听（闭环）
```

**音色档案（定制）**：`女声-明亮 / 女声-温柔 / 男声-低沉 / 男声-清亮`，存 `实施/音色档案/*.json`，可改 F0/语速/气声/紧喉/声区。
**音色模仿**：从参考录音估 F0 中位/能量/谱亮度/平坦度 → 套到档案 → 生成；**口径=参数化模仿，不是真声克隆**。
**情感韵律**：高兴 F0×1.15/语速×1.18；低落 F0×0.88/语速×0.82/气声+；急促 语速×1.35/紧喉+；平静基线。

## 3. 资源/设备（黄队实测口径）

- 设备：**WASAPI 17 入 / 14 出（48k）**；默认 MME 延迟 90ms 不用。
- 夜里底噪 **≈0.00078 RMS**；VAD 门限 0.0025、尾音 300ms。
- 声带实时率 **0.05**（本机），6 字 348ms/1.04s、18 字 794ms/2.69s；tracemalloc 15.25MB。
- TTS 兜底冷启动 **1.18s** ⇒ 只作降级，不作情感/音色主张。
- 音色注册 30s（3×10s）够估 F0（SE≈0.57%），但气声/紧喉/共振峰受房间影响。

## 4. 实测结果（摘要）

- **12 臂：10 PASS / 2 FAIL**
  - FAIL：声纹（H4）——合成三声纹谱形太近，同人 0.667/异人 0.556；
  - FAIL：同时录放（V4）——playrec 回录 0.0；但「麦克风采集」「扬声器播放」分别 PASS。
- **端到端**：4 个合成输入 → 听出 高兴/低落/平静/高兴 → 决策 高兴快中 / 平静慢低 / 平静中中 / 高兴快中 → 4 条回复与音频各异；扬声器**已播放**；真机麦克风录到 1.5s（夜里无声）。
- 实拍回复：低落 → 「我明白你现在感到有点失落，也许我们可以聊聊一些让你开心的事情？」；平静 → 「好的，我明白了。随时为您服务！」。

## 5. 诚实边界

1. **情绪是合成标定 [自证]**，真人未标定；只 3 类；跨说话人/抗噪未测。
2. **声纹不可分（FAIL）**：合成声纹谱形太近，需真人 30s 注册；真机未注册。
3. **同时录放未成立（FAIL）**：播放与采集分别可用，但「边说边听」环路未证。
4. **音色模仿=参数化**，不是真声克隆；相似度上界未测。
5. 回复文本用 Qwen（越宪，标来源）；决策网络 teacher 是规则，不证明最优策略。
6. 不主张自我意识；单机、D=1024 声带、无多模态融合。
