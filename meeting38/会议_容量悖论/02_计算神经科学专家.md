## 0. 一句话主张（TL;DR）

**大脑从不试图把 10⁴ 个码位塞进同一个向量——它靠四件套：①稀疏码（降低串扰）②巨大的「可检索长时库」（海马/皮层，容量 ~10⁴–10⁶）③极小的「活动焦点」（前额叶工作记忆，K≈7）④竞争+门控+广播（全局工作空间）。**

悖论的根源是把**两种完全不同的容量**混为一谈：**「同时叠加进一个向量的容量」（必须小，脑≈7，HDC 稠密≈10²）** 与 **「可检索的库容量」（可以巨大，脑≈终身记忆，HDC 复用码本≈10⁴–10⁶）**。大脑把二者**在结构上分离**，而不是在向量里硬塞。

HDC 的等价物：**SDR 稀疏双极码 + 追加式稀疏码本位库 + 每拍 ≤7 槽焦点束 + 确定性 top-K 竞争广播**。**维度 D 保持 1024 不变**（不违反 C4）：容量增益来自稀疏（组合式，C(D,k)）与层次（库/焦点分离），不来自扩维。

**诚实预告**：稀疏**不会**显著提升「单向量纯叠加」的读出容量（§4.1 给出推导）；稀疏的增益在**库可分性**与**联想矩阵容量**。这恰好人脑亦然——所以焦点必须小。

## 1. 先把悖论解剖清楚：它是「混淆」而非「物理不可能」

### 1.1 悖论成立，但它的隐含前提被大脑直接否定

简报 §2 的账（总需求 10³–10⁴，D=1024 干净容量 10²）在**「所有码位必须同时常驻于同一个 1024 维双极向量」**这一前提下成立。但这个前提**恰恰是大脑从未采用的**：

- 人脑中**任何时刻处于「有意识工作记忆」的项就是 4±1 到 7±2 个**（Cowan 2001；Miller 1956）。人不会、也不能同时「意识到」全部词汇 + 全部事实 + 全部情绪。
- 人脑的**长时记忆容量巨大但读取慢、且不常驻于活动区**；它通过线索（cue）**按需取用**。

所以「1024 维装不下 10³–10⁴」这句话，换成大脑语言是「**活动焦点装不下整个长时库**」——大脑的答复是：**那就不装，改成按需检索**。

### 1.2 两个容量必须分账（本方案的核心切分）

| 容量类型 | 定义 | 大脑对应 | 量级 | HDC 对应 |
|---|---|---|---|---|
| **叠加容量** `C_sup` | 同时塞进一个向量的项数 | 工作记忆 | 4–7 | 焦点束（必小） |
| **库容量** `C_lib` | 可区分、可按线索检索的码位总数 | 长时记忆 | ~10⁵–10⁹ | 码本位库（可大） |
| **联想容量** `C_assoc` | 存进一个联想阵并可补全的模式数 | 海马模式补全 | ~10⁴ | 稀疏 Hebbian 阵 |

**结论**：简报里的 10³–10⁴ 是 `C_lib`（词汇/知识/情绪标签的总量），不是 `C_sup`。`C_sup` 只需满足「一拍内全模态同时在场」——而这是 **7 个槽的事**，不是 10⁴ 个。**悖论在分账后消失**；剩下的工程问题是「库检索要够快」。

## 2. 七条脑机制：逐条评述 + 移植判断

> 每条给出：机制 → 关键证据/数字 → 对 HDC 的启示 → 能否复现（★直接可移植 / ◐部分 / ✗仅类比）。

### 2.1 稀疏分布式表示（SDR）——**★最直接可移植**

- **机制**：皮层表征极度稀疏，任一时刻仅 ~1–5% 神经元活跃（视觉 V1、嗅球、海马 CA3 均如此；稀疏度随经验塑形）。
- **它解决了什么**：把**容量**与**干扰**解耦。稀疏码之间的**重叠期望**从稠密码的 O(1/√D) 降到 ~k/D。**可区分的稀疏码数量 = C(D,k)**（组合爆炸）——这是「库容量」的来源。
- **它没解决什么（关键诚实点）**：对**单向量纯叠加 + 余弦读出**，稀疏**并不提升** N_max（§4.1 推导：稠密与稀疏 S/N 同为 √(D/N)）。稀疏提升的是**库内可分性**（pattern separation）与**联想矩阵容量**（Hopfield/Willshaw 的 α_c 随 f 下降而上升）。
- **对 HDC 的启示**：码保持 D=1024，但从「稠密双极」改为「**k-稀疏双极**」（k≈16，f≈1.6%：k 个 +1、k 个 −1、余 0）。字码/特征码/情感码全部 SDR 化。
- **能否复现**：★。这是把「容量-干扰解耦」搬进 HDC 的**唯一最直接桥梁**。

### 2.2 功能分区 + 专精——**★可移植（解串扰，不解容量）**

- **机制**：视/听/语言（布洛卡/韦尼克）/运动/前额叶各司其职，不共用同一群神经元。**脑区之间长程连接只占局部连接的 ~1%**——**跨区通信是稀疏、压缩的，不是全量复制**。
- **它解决了什么**：**跨模态串扰 = 0（按构造）**，以及各模态可用最优编码。
- **它没解决什么**：分区**不增加**总容量——把 D 切成 P 块，每块容量 C(D_p,k)`，总量并未因切分而变大。分区解决的是**隔离**，不是**容量**。
- **对 HDC 的启示**：把 1024 位划为**模态专属块**（§3.2），块间支撑集不相交 ⇒ 跨模态余弦≈0。跨模态概念用「角色⊗填充」绑定（支撑落在两块的并集），**不复制整块**。
- **能否复现**：★（作为隔离层）；分区本身**不是**容量方案——此处必须诚实，否则与简报 §3 的「分区数量」混淆。

### 2.3 绑定问题与振荡同步——**◐ 部分可移植**

- **机制**：颜色/形状/位置被「绑定」为一个物体而不丢失组合性；主流解释是 **gamma 同步**（~30–80Hz）：同一物体各特征的神经元同步放电，构成瞬态细胞群。
- **关键含义**：绑定是**瞬态的、动态分配的、用完即散**——**不是**长期存在某个固定存储里。
- **对 HDC 的启示**：直接复用 `共存态.绑`（按位乘 + 循环移位 = 角色⊗填充）。但要点是：**绑定每拍现算、只在焦点里存在一拍**，**不写入长时库**。这样「组合爆炸」不会挤占容量——因为组合从不被持久化。
- **能否复现**：◐。HDC 的 `roll` 移位是**空间化的静态相位**，能表达「角色/位置」，但**无法复现**「同一神经元在不同振荡相位参与不同绑定」的**动态多路复用**。这是大脑远超 HDC 的一点（列于 §6）。

### 2.4 工作记忆的容量极限（米勒 7±2 / Cowan 4±1）——**★核心可移植**

- **机制/数字**：人**有意识**同时处理约 **4±1**（chunk）项；米勒 7±2 是旧上界。**长时记忆容量巨大，工作记忆极小**——这个**极端不对称**是大脑设计的核心，不是缺陷。
- **对悖论的意义**：大脑**本来就不把所有东西同时放进工作记忆**。所以「向量装不下」从来不是大脑要解决的问题——它把「装不下」变成「**按需取用**」。
- **对 HDC 的启示**：**焦点束的槽位数硬性上限 K≤7**，超出必须靠**竞争**淘汰低显著项 + 靠**检索**回填。**焦点永远小**，容量问题转移到库。
- **能否复现**：★。这是把「10⁴ 需求」降为「7 槽/拍」的关键结构性一步。

### 2.5 全局工作空间理论（GWT）——**★可移植（瓶颈即特性）**

- **机制**：信息被「广播到全局工作空间」才进入意识；进入靠**竞争**，容量有限是**特性而非缺陷**（选择性增益/门控）。
- **项目现状**：`03_AGI...md:128` 已点名 **GWT-2 有限容量工作空间：部分（但无竞争/瓶颈）**；`共存态.py` 已实现多槽 + 广播的雏形。
- **对 HDC 的启示**：补齐 GWT-2 缺的那一半——**竞争 + 门控 + 广播**：每拍对候选算显著性，**确定性 top-K**（赢者通吃 / 侧抑制），广播焦点束给所有器官。**注意：这不是 Transformer 的 attention**（无 Q/K/V 投影、无 softmax、无梯度；是生物侧抑制式确定性竞争，可复现 C7）。
- **能否复现**：★。

### 2.6 长时记忆 vs 工作记忆的分工——**★解决悖论的关键结构**

- **机制**：**海马/皮层**负责长时存储（容量巨大、读取慢、靠线索做**模式补全**）；**前额叶**负责工作记忆（极小、极快、持续放电维持）。二者通过索引耦合（海马索引理论）。
- **对悖论的意义**：这就是「**小的活动焦点 + 巨大的可检索库**」。容量问题在**库**里解决（大），干扰问题在**焦点**里解决（小）。
- **对 HDC 的启示**：
  - **库** = 追加式稀疏码本 + 批量余弦检索（复用 `共存态.编码.批相似`，本身 O(M·D) 在 GPU）或稀疏联想阵补全（复用 `gpu_backend.弛豫` 的 `sign(W@v)×C`）。
  - **焦点** = 每拍 ≤7 槽的稀疏束 + 广播字段。
- **能否复现**：★。这是本方案的主结构。

### 2.7 说话的增量性（Levelt 模型）——**★可移植（直接回应 C5）**

- **机制**：人说话**不是先想完整句再出口**，而是**增量式**：概念化（conceptualizer）→ 构形（formulator）→ 发音（articulator）三阶段**流水并行**；说话人**边说边计划下一块**（incremental speech production）。
- **对悖论的意义**：它把「输出的 10²–10³ 码位需求」摊到**时间轴**上——任一拍只需产出**下一个词块**，不需要整句常驻。
- **对 HDC 的启示**：`表达槽` 从「整句队列」升级为「**词块(chunk)流**」：脑每拍追加 1–3 词 + 韵律 8 参数 + 账本引用号；`器官_嘴` 在 **chunk 边界即可发声**（其发声子线程已异步），下一 chunk 在发声**进行中**生成。
- **能否复现**：★（结构）；但三阶段的神经特化只做类比（§6）。

## 3. 方案：**SPF 三段式（Sparse-Partitioned-Focus）**

> 设计原则：D 恒为 1024；不引入新大矩阵以外的神经网络；全部算子为加/乘/sign/余弦/argmax；全程确定性。

### 3.1 总架构（文字图）

```
四路输入 ──► 模态分区编码(k-SDR) ──┐
                                   ├─► 候选池(4~12项)
脑(意图/自评) ─► 意图码 ───────────┘        │
                                            ▼
                         ┌──────── GWT 竞争(top-K≤7, 确定性) ────────┐
                         │                                          │
   ┌── 焦点束 g = 束( 绑(角色_i, 码_i) ) ◄── 海马检索(库 top-k 补全) ◄┘
   │                                          ▲
   ▼                                          │
 广播 g → 五器官每拍读                      稀疏码本位库 M≈10⁴–10⁶ (LTM)
   │                                         + 稀疏联想阵 W(D×D) 松弛补全
   ├─► 脑：更新意图/自评/计划
   └─► 嘴：增量 chunk 流(1–3词+韵律8参) ──► 发声线程(边界即发声)
```

### 3.2 数据结构（工程师可照建）

**(DS-1) 稀疏码 `sdr(键, k)`** —— 双极稀疏超向量
```python
# 确定性：同(键,种子) → 逐位一致（C7）
def sdr(键, D=1024, k=16, 种子=3800):
    rng = np.random.default_rng(hash64(键) ^ 种子)
    位 = rng.choice(D, 2*k, replace=False)
    v = np.zeros(D, np.int8)
    v[位[:k]] = +1; v[位[k:]] = -1      # 半正半负 → 互相关零均值
    return v
```

**(DS-2) 模态分区表 `分区`** —— 1024 位切为 6 块（互不相交）
| 块 | 位宽 | k_b(≈2%) | 承载 |
|---|---|---|---|
| 视觉 V | 320 | 6 | 元素/属性/关系/焦点 |
| 听觉 A | 128 | 3 | 声事件/主频/起音 |
| 语言·语义 L | 256 | 5 | 词汇/概念/知识/按钮 |
| 情感 E | 96 | 2 | 核心 8–12 + 社会 20–40 |
| 运动·操作 M | 128 | 3 | 键位/坐标/轨迹/进度 |
| 自我·前额叶 F | 96 | 2 | 自模型槽/意图/计划 |

跨模态概念 = `绑(模态角色码, 块内码)`，支撑落在两块并集，**不复制整块**。

**(DS-3) 稀疏码本位库 `库`（LTM / 海马-皮层类比）** —— 追加式，只增不改
```python
class 稀疏库:
    W: np.ndarray          # (M,D) int8（CSR 或位图；k=16 时 CSR≈0.2MB@10⁴）
    键表: dict             # 键 → 行号
    def 注册(键): 追加 sdr(键); 键表[键]=M
    def 检索(探针, 块=None, topk=8):
        rows = W[:,块] if 块 else W
        return argtopk(批相似(探针, rows), topk)   # 复用 共存态.编码.批相似
```

**(DS-4) 稀疏联想阵 `联想`（可选，模式补全 / 海马类比）**
```python
class 稀疏联想:
    W: (D,D) int8          # Hebbian 外积累加，无梯度、无 softmax
    def 记(码s): 对每对 co-active (i,j): W[i,j] += x_i*x_j
    def 补全(cue, 步=5):
        x = cue
        for _ in range(步): x = np.sign(W @ x)   # 复用 gpu_backend.弛豫 同款
        return x                                  # 经典 Hopfield，非现代(softmax)版
```

**(DS-5) 焦点工作区 `焦点`（WP / 前额叶类比）** —— K≤7 槽
```python
焦点 = list[ (槽位角色:str, 码:sdr, 显著性:float, 来源:str) ]   # 长度硬上限 7
广播束 g: sdr 的整数累加（不阈值化，保留角色可解绑）
```

**(DS-6) 增量表达 `chunk流`** —— 每拍产出
`(词块:str[1..3], 韵律8参:tuple, 引用:list[(账本号,摘录)])`，供嘴在边界发声。

### 3.3 每拍算法步骤（20Hz，全确定性）

```
每拍 t（50ms）：
 1. 采集：四器官各写本拍最显著项 → 各模态块编码为 sdr；写入 共存态 对应槽（复用现有锁）。
 2. 候选汇总：脑取 视觉/听觉/意图/语义/表达 槽的候选 ≈4~12 项。
 3. 竞争(GWT)：sal_i = w1·cos(码_i, 意图码) + w2·新颖度_i + w3·|强度_i|
              焦点 = 确定性 top-K(K≤7)；并列按 (模态序, 库行号) 破平（C7）。
 4. 检索(海马)：g_prev = Σ 焦点码 作探针 → 稀疏库.检索(g_prev, 块逐块, topk) 补全缺失槽；
              若需强补全 → 稀疏联想.补全(g_prev, 步≤5)。
 5. 绑定：对每焦点项 上界_i = 绑(角色码, 填充码, 移位=模态相位)。   ← 瞬态，不落库
 6. 广播：g = Σ 上界_i（整数累加）→ 写 共存态 新只读字段"全局焦点"；五器官每拍读 g。
 7. 表达：脑把下一个 chunk(1~3词+韵律8参+引用号) 追加进 表达槽；嘴在 chunk 边界即发声。
 8. 记账：把本拍焦点/竞争结果写 inner_speech 六类中的"自评/计划"（复用 meeting31 接口）。
```
**全程无 attention/softmax/梯度**；`top-K` 是确定性排序，属侧抑制式竞争，非 Transformer attention。

### 3.4 稀疏算子（闭合规则，交 01 专家确认）

- **绑**：`c = roll(a,移位) * b`（复用 `共存态.绑`）。支撑 = supp(a)∩supp(b)。
- **解绑**：`b̂ = a * (a * c)`（移位逆移）。稀疏双极下 `a*a=1 on supp(a)` ⇒ 在 supp(a) 上精确恢复 b。
- **束（焦点）**：整数累加 `Σ 码_i`（**不 binarize**，保留角色可解绑）；读出用余弦/掩码余弦。
- **相似**：复用 `批相似`（余弦对稀疏码天然适用，不需改）。
- **0 元危险提示**：稀疏下 `a⊙a ≠ 全 1`（0 处为 0），故**必须配套 support-mask 解绑**；请 01 形式化其闭合性。

## 4. 容量账

### 4.1 单向量「纯叠加」容量——诚实推导（稀疏在此处**不占便宜**）

设稠密双极 D 维、N 项叠加、余弦读出：
- 信号 `<x_i,x_i>=D`；其余 N−1 项噪声 `~N(0,D)` ⇒ 噪声 σ=√((N−1)D)。
- S/N = D/√((N−1)D) = **√(D/N)**。
- 取 S/N≥3 ⇒ N ≤ D/9 ≈ **114**（D=1024），与简报「干净~100」一致。

设 k-稀疏双极（k 个 +1、k 个 −1）：
- 信号 = k；单对互相关 σ = k/√D；N−1 项 ⇒ σ = √(N−1)·k/√D。
- S/N = k / (√(N−1)·k/√D) = **√(D/N)** —— **与稠密同阶**。

> **诚实结论**：稀疏**不提升**「单向量叠加 N_max」。因此**焦点必须小（K≤7）**——这正是大脑（Cowan 4±1）的判断。稀疏的收益在 §4.2。

### 4.2 库容量与联想容量——稀疏的真实增益

- **库容量 `C_lib`（可区分码位数）**：k-稀疏双极两两互相关 σ≈1/√D≈**0.031**。自相关 1 vs 互相关 0.03 ⇒ **码位高度可分**，`C_lib` 实为 **C(D,k)** 量级（天文数字），工程瓶颈是**检索延迟**而非干扰。稳健运行区：**M ≤ 10⁴–10⁶**（取决于索引，见 §4.3）。
- **联想矩阵容量 `C_assoc`（稀疏 Hebbian/Hopfield）**：编码率 f=k/D：
  `C_assoc ≈ D / (2·f·ln(1/f))`
  - f=1/64（k=16）：≈ 1024/(2·0.0156·4.16) ≈ **7.9×10³**
  - 稠密 Hopfield 对照 α_c≈0.138D ≈ **141**
  ⇒ **非线性增益 ≈ 56×**（增益来自 f 的倒数，不是来自 D）。
- **焦点叠加容量 `C_sup`**：K≤7，安全裕度 S/N=√(1024/7)≈12（远超阈值 3）⇒ 单拍检索保真度 ~1.0。

### 4.3 延迟账（C6）

| 操作 | 规模 | 估算延迟 | 备注 |
|---|---|---|---|
| 稀疏束 K=7 | 7×16=112 次加 | ≪0.01ms | **比稠密束(1024)更省** |
| 竞争 top-K | ~12 候选 | ≪0.01ms | 排序，非矩阵 |
| 库检索(全扫) | M=10⁴, D=1024 ⇒ 10⁷ MAC | GPU ~0.1–0.5ms | 复用 `批相似` |
| 库检索(分块+倒排) | 限在命中块/桶 | ~O(1)，与 M 弱相关 | SDM 硬地址桶 |
| 联想松弛(5步) | nnz(W)≈M·k²=2.6×10⁶ | GPU ~0.5–1ms | 复用 `弛豫` |
| **单拍合计** | —— | **GPU ≤2ms / CPU ≤15ms** | 思维拍 50ms 不破 |

**关键**：容量增长由**库大小 M** 承担，M 增大**只增检索延迟**（可用分块+倒排索引压成次线性），**不增单拍焦点延迟** ⇒ 打破「维度↑→延迟↑」悖论。

### 4.4 显存账

| 结构 | 规模 | 稀疏(CSR) | 稠密 int8 |
|---|---|---|---|
| 稀疏码本 | 10⁴×1024(k=16) | **~0.2MB** | 10MB |
| 稀疏码本 | 10⁵ 同上 | ~2MB | 100MB |
| 稀疏联想阵 W | nnz 2.6×10⁶ | ~20MB | ~1MB(位) / 1GB(int8 全稠密) |
| **合计（10⁴）** | —— | **<25MB** | —— |

对比「线性扩维 N 倍」：N=16 ⇒ 16× 检索代价（线性）且违反 C4；本方案容量 ~10² 倍而显存仅 ~25MB。**不炸 GPU（C6）**。

### 4.5 提升倍数（结论）

- 相比「1024 稠密单向量，可同时登记并可检索 ~10² 码位」：
  - **库层**：~10⁴（稳健）～10⁶（极限）⇒ **有效容量 ~10² 倍**（满足需求 10³–10⁴ ✓）
  - **联想层**：~7.9×10³ vs 稠密 Hopfield 141 ⇒ **~56 倍**
  - **焦点层**：恒定 K=7，**不随规模增长**（悖论被结构消解）
- **代价**：单拍延迟 +~1ms（GPU），显存 +~25MB，**维度不变（C4 合规）**。

## 5. 可失败判据（≥3，均可真失败、量化）

> 里程碑可复现（固定种子）；测点在 GPU 与 CPU 各跑一次。

**F1（容量压力测试·核心）**：稀疏库注册 M∈{10³, 3×10³, 10⁴, 3×10⁴, 10⁵}，对 1000 随机探针做 top-1 检索。
- 门槛：M≤10⁴ ⇒ top-1 ≥0.995；M=10⁵ ⇒ ≥0.98。
- **判负**：M=10⁴ 时 <0.99 或 M=10⁵ 时 <0.95 ⇒ 「库容量达 10⁴」证伪。

**F2（稀疏 vs 稠密消融）**：固定 M=10⁴，比较 k=16 稀疏码 vs 稠密双极码的 (a) top-1 命中率 (b) 库内两两 |cos| 中位数。
- 门槛：稀疏 |cos| 中位数 ≤0.05 且 top-1 ≥0.995；稠密应显著劣化（构造性对照）。
- **判负**：两者无显著差异 ⇒ 「稀疏是核心增益」证伪。

**F3（跨模态串扰 / 分区隔离）**：用情感块码作探针检索视觉块码本。
- 门槛：|cos| **<0.05**（理论上应为 0）。
- **判负**：>0.1 ⇒ 分区实现失效。

**F4（延迟不随库规模破预算·破悖论）**：M 从 10³→10⁵，测单拍（竞争 top-7 + 束 + 广播 + 一次检索）延迟。
- 门槛：GPU ≤2ms、CPU ≤15ms；且延迟对 log M 的斜率次线性（分块/倒排后限制在命中块）。
- **判负**：M=10⁵ 单拍 >50ms，或延迟随 M 线性增长 ⇒ 「打破延迟悖论」证伪。

**F5（全双工增量发声 C5）**：测「脑产出首个 chunk → 嘴开始发声」延迟 ≤300ms；发声进行中 `脑拍计数` 持续增长且至少产出 0/1 新 chunk。
- **判负**：必须等整句/整段生成才发声 ⇒ C5 证伪。

**F6（联想层容量，选做）**：稀疏 Hebbian W 存 M 模式，用 30% 加噪 cue 松弛 5 步。
- 门槛：M ≤ 0.8·M_max 时恢复率 ≥0.95，实测 M_max ≥6×10³（对标 §4.2）。
- **判负**：M_max <10³ ⇒ 联想层容量主张证伪。

## 6. 诚实边界（哪些做不到 / 哪些只是类比）

1. **稀疏是「手工设定」而非「学习塑形」**：大脑的稀疏度由经验/可塑性塑造；我们固定 k，无梯度 ⇒ 拿到**组合容量**，拿不到「经验自适应稀疏度」。
2. **稀疏不提升单向量叠加容量**（§4.1）：这是与「稀疏=容量翻倍」常识相悖的诚实结论。若 01 专家能给出反例，我愿修正。
3. **振荡动态多路复用无法复现**：HDC 的 `roll` 移位是**静态空间相位**；大脑「同一神经元在不同 gamma 相位参与不同绑定」的**动态复用**做不了——这是容量上的真实差距。
4. **分区是静态、不可塑的**：脑区可重映射；我们的块边界固定，跨模态概念需**人工指定绑结构**。
5. **K=7 只是上限，不是机制**：大脑工作记忆有精细的注意优先级动力学/持久放电；我们只有 top-K 排序。Cowan 4±1 → 向量容量的映射是**类比**，非等价。
6. **Levelt 三阶段并行是神经特化**：我们只有「词块队列 + 韵律参数」，**语言质量不保证**；这是形态学的类比，不是语言生成机制的复现。
7. **无法复现**：神经调质/增益调制、连续突触可塑性、皮层柱竞争性发育——本项目全静态、无梯度。
8. **真正的天花板是检索延迟（库大小 M）**，不是向量：若要 M≈10⁶ 且倒排索引退化，延迟会回来。本设计在 D=1024 下**稳健上限 M≲10⁵**。这是硬边界。
