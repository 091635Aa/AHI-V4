# 05 · 情感·韵律·原生发声专家 —— 情感-韵律码位如何原生驱动声带而不挤爆 1024 维

> 日期：2026-10-05 ｜ 议题（单一）：HDC「容量-延迟悖论」｜ 领域：情感编码 · 韵律生成 · 原生生带驱动
> **必须回答的唯一问题**：不用 RVC、不用 TTS，如何让「核心情感 + 社会情感 + 意图 + 韵调」原生驱动声带？
> 这套情感-韵律码位如何与语义共享表示空间而不挤爆 1024 维？
> **铁律**：禁 Transformer（attention/QKV/softmax/自注意力/位置编码/梯度）；禁 RVC（音参音）；禁神经 TTS。

## 0. 一句话结论（先给判断，再给账）

**把"给每个情绪/每个韵律组合分配一个独立正交码"这条死路，换成"少量共享因子轴 + 角色绑定 + 位置绑定"的因子化编码。**
情绪不是"码"，是**因子空间里的一个区域**（用现成 `数轴` 的双轴组合读出来），
韵律不是 `8×N` 个码，是 **8 条共享参数轴 + 一个 K 音节在飞窗口**，
发声动作不是 24576 个组合码，是 **5 条共享动作轴上的一个候选点**，
三者与语义**共用同一个 D=1024 空间、靠角色绑定软隔离**——
单拍 live 束 ≤ 20 对绑定，远低于 0.1·D=102 的干净容量线。
**关键账**：情感+韵律+意图+发声动作的"朴素独立码"下界 ≈ 2.5×10⁴（发声动作空间一项就 24576），
因子化后 = **固定基础设施 ~44 码（一次分配、永久复用）+ live ≤ 20 对**。
**原生驱动**：情感向量（内部双极码）→ 因子解码 → 韵律 8 参数 → `声带.音节帧` → `合成波形`，
全程**零参考音频、零神经推理、确定性逐位一致**——与 RVC 的"参考音频驱动"在机制上互斥。

### 1.2 项目既有 HDC 算子（`meeting38/共存态.py::编码器`）
`字码` / `文本码`（字袋，按位多数表决）/ `特征码`（随机投影）/ `绑`（按位乘 ⊕ 循环移位）/ `束`（多数表决）/ `相似` / `批相似`。
**本方案只用这些算子 + `数轴`，不引入任何新范式。** D默认=1024（第 34 行），τ=3/√D≈0.0938，噪声 σ=1/√D≈0.0313。

### 1.3 两个被算错的"容量炸弹"（本方案要拆的雷）
共同简报 §2 把两个通道**按朴素独立码计数**，这正是缺口被夸大到 1–2 个数量级的根因：
- **雷 A**：`出·语音流：韵律 8 参数 × 音节` → 被读作 `8×N` 码。**32 字句子 = 256 码**，长句直接爆。
- **雷 B**：所有者要的"发声即选动作"（发什么音/多强/多高/多长/什么音质）→ 若每个组合一个码，
  `6×8×8×8×8 = 24576` 码，**单独一项就是整个预算的 20 倍**。
两雷的共同错因：把"**一个连续量在因子轴上的取值**"当成"**一个必须独占的独立概念码**"。
因子化后：雷 A `8×N → 8 轴 + K 窗口`；雷 B `24576 → 5 轴`。

## 2. 方案总纲

```
                      ┌─ 角色绑定（把因子塞进同一个 D 维空间）─┐
情感因子 8 轴 ──┐
韵律因子 8 轴 ──┼──► 束( role_r ⊙ 轴_r(值) ) ──► live 超向量（≤20 对）──► 解码（无 softmax 的最近邻）
意图因子 4 轴 ──┘                                              │
                                                               ▼
        情感态 ─► 全局韵律(8) ─► 短语层增量 ─► 字层增量 ─► 韵律 8 参数序列(窗口 K)
                                                               ▼
                       声带.音节帧(text,律,qs) ─► [字级后处理] ─► 声带.合成波形(帧) ─► wav（原生）
                                                               ▲
                       发声动作空间(5 轴) ──EFE(argmin)──► 选中动作的(类型,强度,音高,时长,音质)
```

三条设计律：
1. **因子化**：绝不给"情绪/韵律组合/发声组合"各发一个正交码；只发**因子轴**，组合 = 轴取值的绑定束。
2. **角色绑定**：所有通道塞进**同一个** 1024 维空间，靠 `role_i ⊙ filler_i` 相互准正交隔离（复用 §1.2 的 `绑`）。
3. **可变向量**：任何概念（情绪/动作）**不占固定槽**，是"按需读出的区域"；只有**当前态**占 live 槽位——正合所有者要的"可变向量，而非固定定死向量"。

## 3. Q1 · 情感维度的编码（含社会情感）

### 3.1 为什么不能一个情绪一个码
核心 8–12 + 社会 20–40 = **最多 ~52 个独立码**，单看不算爆；但（a）它随社会情感扩充会线性增长，
（b）**摧毁泛化**：没见过的情绪（"又骄傲又内疚"）无法表示。因子化后情绪是**连续空间里的点**，
混合物是**中间点**，社会情感可**生成式扩展到数百**而不加一个码。

### 3.2 因子定义（评价理论 → 可计算轴）
**核心情感（3 轴，对齐 PAD/三维情感模型）：**
| 轴 | 记号 | 域 | 档数 | 医学/声学落点 |
|---|---|---|---|---|
| 效价 | V | [−1,1] | 16×16 | 决定 F0 升降、幅度、气声底 |
| 唤醒 | A | [0,1] | 16×16 | 决定语速、F0 摆幅、能量 CV |
| 支配 | P | [0,1] | 16×16 | 决定幅度、紧喉、起音陡缓 |

**社会情感（5 评价轴，对齐 Smith&Ellsworth / Scherer CPM）：**
| 轴 | 记号 | 域 | 档数 | 区分什么 |
|---|---|---|---|---|
| 归因主体 | G | 0=他人/环境, 1=自我 | 16×16 | 怒(他人) vs 内疚(自我) |
| 道德效价 | M | [−1,1] | 16×16 | 正/负评价（对己或对人） |
| 社会暴露 | X | 0=私密, 1=公开 | 16×16 | **羞耻 vs 内疚的唯一判别轴** |
| 关系威胁 | T | [0,1] | 16×16 | 嫉妒(关系威胁高) vs 羡慕(威胁低) |
| 预期违背 | Nv | [0,1] | 16×16 | 惊讶/顿悟（与声带已有 `新异` 同源） |

> 社交情绪还隐含"整体自我 vs 具体行为"（O vs B）一维——**先并入 X 的粗轴**（公开≈整体暴露），如实说明这是**降维近似**（见 §9 边界 2）。

### 3.3 编码公式（只用 `绑` + `束`）
```
# 固定基础设施（构造时一次生成，永不重算）：8 个因子角色码 + 8 条因子轴
role_emo[r]  = enc(r)                       # r ∈ {V,A,P,G,M,X,T,Nv}，8 个角色码（准正交）
轴[r]        = 数轴(键="情感|"+r, D, S1=16, S2=16)   # 复用 声带.数轴

# 每次情绪结算：把一个情绪点编成 live 束
情感态码 E = 束([ 绑(role_emo[r], 轴[r].编码向量(v_r))  for r in 8])   # 8 对绑定
```
- 8 对绑定 → 单束 N=8，回读 `绑(role_emo[r], E) ≈ 轴[r](v_r)`，
  `cos ≈ 1/√(1+(N−1)/D) = 1/√(1+7/1024) ≈ 0.9966`，**远高于 τ=0.094**。
- 概率化情绪（"60% 好奇 + 40% 困惑"）**不做**，改为在因子轴上取加权点（V/A/P 等按权重插值），
  再从点读最近的情绪标签——**没有 softmax，没有归一化指数**。

### 3.5 情感编码的码位账
- **固定基础设施**：8 角色码 + 8 因子轴（轴对象持 2×(S+1) 条原型链，`S=256` → 每轴 ~514 条 D 维向量；
  8 轴共 ~4112 条 ⇒ 若常驻显存约 `4112×1024×4B ≈ 16.8MB`，可 GPU 常驻；CPU 亦可）。
- **live**：情感态 = **1 束 / 8 对绑定**。
- **对比朴素**（52 独立码）：live 从 52 → 8 对（约 6.5×）；且朴素方案**无法泛化、无法混合、随扩充线性爆**。

## 4. Q2 · 韵律的原生驱动（扩到字级/短语级）

### 4.1 三层结构（在 `声带.韵律()` 之上叠加，不改其源码）
```
L0 全局层：声带.韵律(遥测)          → 8 参数基线（整句）        [现成，保留]
L1 短语层：情感态 E → Δ8 增量      → 每个短语的 8 参数偏移      [本方案新增]
L2 字层  ：分位读数 q + 字显著度 w → 每字 Δ8 微调 + 变调/停顿  [本方案新增/扩展]
最终：p_i[k] = clip( 基线k + Σ_e a_e·Δ_e[k]·s_{e,i} + w_i·g_k , 合法区间 )
```
- `a_e` = 该情绪因子组合的**激活量**（Gaussian 隶属：`exp(−‖v_emo−proto_e‖²/2σ²)`，**非 softmax**，取值 [0,1]）。
- `s_{e,i}` = 第 i 字对情绪 e 的**相关性**（情景点是否落在第 i 字/词上；由 §3.4 区域与句法焦点求交）。
- `w_i` = 字显著度（来自 `分位读数` 秩 q，扩展为对 8 参数的增益，原实现只用于 ΔF0）。
- `g_k` = 强调增益向量（重音时基频↑幅度↑时长↑）。

### 4.3 字级/短语级具体规则
1. **焦点重音**：`w_i` 前 20% 的字（意图向量该段 q 最高）取 `g_基频=+12Hz, g_幅度=+0.10, g_时长=×1.15`。
2. **三声连读变调**（在 `音节帧` 前改 pinyin 调号）：`3+3 → 2+3`；三连上声右向分组 `(3+(3+3)) → 2+3+3`。
3. **一/不变调**：一 + 4 声→yí(2)；一 + 1/2/3 声→yì(4)；序数→yī(1)；不 + 4 声→bú(2)。
4. **句读停顿**（插 `声源=−1` 静默帧）：`、`≈80ms，`,`≈150ms，`：`≈180ms，`。！？`≈300ms，`……`≈350ms。
5. **情绪对包络**：喜悦/急躁 = 起音陡（爬升段 0.15→0.06）；悲伤/困惑 = 起音缓 + 尾字拖长（+30% 时长）；
   愤怒 = 音节间停顿压缩（×0.7）。均在**嘴侧**对组合出的 `帧` 做乘性微调（**不改 `声带.py`**）。
6. **句末轮廓**：好奇/疑问=尾上扬 ~2 半音；悲伤/内疚=尾下沉 ~3 半音；愤怒=尾硬切（陡降 + 幅度末段 +0.05）。

## 5. Q3 · "发声即选动作"：EFE 在发声参数空间里选

### 5.1 发声动作空间：离散粗档 + 连续细档（与 `数轴` 双轴同构）
所有者的"四个方向、发什么音、什么音质多强、多高、多长"= 一个 5 轴的因子空间：
| 动作轴 | 档数（粗/细） | 对应 |
|---|---|---|
| 类型 T | 6（陈述/疑问/感叹/呼唤/强调/静默） | "发什么音"（语气类别） |
| 强度 I | 8（pianissimo…fortissimo） | "音质多强" |
| 音高 H | 8（低/中/高音区） | "多高" |
| 时长 D | 8（短促/正常/拖长） | "多长" |
| 音质 Q | 8（气声/正常/紧喉/粗糙…） | 音质色彩 |
- **离散档 = 粗轴（选动作，6 选 1）**；**连续残留 = 细轴（调参数）**——正是 `数轴` 的 `f_k1⊙c_k2` 结构。
- 动作码：`a = 束([ 绑(role_T, 类型轴(k1)), 绑(role_I, I轴(k)), ... ])`，5 对绑定。
- **朴素 24576 码 → 因子化 5 轴**（≈ 4900×减少）。这不是"省了点"，是**把整个动作空间从爆表拉进预算**。

### 5.2 EFE 打分（纯 HDC，无梯度、无 softmax，含前向模型）
EFE = 风险（pragmatic/risk）+ λ·模糊（epistemic/ambiguity）：
```
# 前向模型 O(a)：复用 声带.接综合体 的「自我听觉」一次写入联想记忆（耳.学）
O(a) = 联想记忆.读(a)              # a → 预期听到的听觉码（One-shot Hebbian 束，无梯度）
G    = 期望听感码                 # 由当前意图+情感态编出（§3.3 同法）
risk(a)      = 1 − cos( O(a), G )                    # 越接近"想被听到的样子"越低
ambiguity(a) = 1 − max_c cos( O(a), 结果码本[c] )    # 没见过的动作→预测不确定→高模糊
EFE(a)       = risk(a) + λ·ambiguity(a)              # λ 暂定 0.3（探索权重）
a*           = argmin_{a∈候选} EFE(a)                 # 纯 argmin；并列→动作轴索引小者（确定性）
```
- 候选集 = 对意图+情感态做**离散采样**（如 5 轴各取 2–3 档笛卡尔积 ≈ 数十个候选），逐候选 HDC 打分。
- 打分 = 点积，数十候选 × D 维 ≈ 数万 MAC，**<1ms**；无需 softmax/归一化。
- 前向模型随发声自我听觉**在线增长**（`耳.学`），无需离线训练、无梯度——合规。

### 5.3 与手的动作共享同一机制（"扩展互补空间"）
手的动作走**同一套**因子化 + EFE：
```
手动作码 h = 束([ 绑(role_器, 手), 绑(role_方向, 方向轴), 绑(role_距离, 距离轴), 绑(role_力度, 力轴) ])
候选集 A = 手候选 ∪ 嘴候选
选择   A* = argmin_{a∈A} [ risk(a; G) + λ·ambiguity(a) ]     # 同一 G、同一前向模型、同一打分器
```
- **效应器由 EFE 自动决出**：目标偏"告知/表达"→嘴候选 EFE 低；目标偏"点按钮/移动"→手候选低。
- "发什么音/多强/多高/多长"与"什么方向/多远/多快"是**同一参数化结构的两个 effector 实例**——
  这就是所有者说的"扩展互补空间"。**两者的动作码在同一 D 维空间共用角色绑定**，故可同拍竞争。
- **全双工**（C5）：动作选择与发声是一条"选中即执行"的并发拍，不做"先成句再想语气"，不进想象力串行。

## 6. Q4 · 容量账（本方案的核心交付）

### 6.1 朴素独立码 vs 因子化（对照表）
| 通道 | 朴素独立码 | 因子化固定基础设施 | 因子化 live（单拍束内） |
|---|---|---|---|
| 核心情感 12 | 12 | 3 轴（V/A/P） | 3 对绑定 |
| 社会情感 40 | 40 | +5 轴（G/M/X/T/Nv） | 5 对绑定 |
| 韵律 8 参数 × 16 档 | 128 | 8 轴 | 8 对绑定 |
| 韵律 × 音节（8×N） | **8N**（32 字=256） | （复用上面 8 轴） | K 音节在飞窗口（K≈6）位置绑定 |
| 意图/计划 | 数十~数百 | 4 轴（类别/强度/时限/来源） | 4 对绑定 |
| 发声动作空间 | **24576**（6×8×8×8×8） | 复用 5 轴 | 1（选中项的码） |
| **合计** | **≥ 2.5×10⁴（且随 N、组合线性爆）** | **8+8+4 轴 + ~24 角色码 ≈ 44 码（一次分配，永久复用）** | **≤ 20 对绑定** |

### 6.2 共享策略：**共用子空间 + 角色绑定软分区**（推荐），而非硬分区
| 策略 | 机制 | 容量代价 | 结论 |
|---|---|---|---|
| **硬分区** | 把 D 切成 语义512/情感128/韵律128/意图64/预留192 | 各子区独立容量 = 0.1×子区维：语义 51，情感 12.8，韵律 12.8，意图 6.4。**情感区一扩到"数百社会情绪"就爆；总容量被切碎且用不满** | ✗ 不取 |
| **共用子空间 + 角色绑定（软分区）** | 全部通道同居 1024 维，靠 `role⊙filler` 准正交隔离 | 单一 live 束上限 ≈ 0.1·D = 102；**弹性互补**：某拍语义少，情感/韵律可多用 | ✓ **取** |
- 隔离质量：不同角色的回读串扰 `~N(0, 1/√D)` = σ≈0.031，而目标回读 cos≈0.9966 → **串扰/信号 ≈ 0.03**，可忽略。
- 语义侧：字码天然准正交，语义 live 窗口 ~64 项即可；与情感/韵律/意图的 20 项相加 = **84 < 102**，**D=1024 刚好干净容纳全模态 live 束**。

### 6.3 与语义共存的 live 预算（一拍的账）
```
语义字袋窗口      ≤ 64
情感态            8 对绑定
韵律（含意图微调） 8+4 = 12 对
发声动作（选中+备选2） ≤ 3
────────────────────────────
合计              ≤ 87   < 0.1·D = 102   ✅ 干净容量内
```
- 若某拍需 >102，**不扩维**，改用先例 **L=4 四分块多级编码**（`gpu_backend.py:162`，C* #129–136 已验）：
  码丰富度 ×4，容量再获非线性增益；代价 = 每项存储 ×4（显存），解码仍 O(S·D)（**非 4× 延迟**）。
- **延迟**：我的解码层 = 每轴 257×D MAC。每拍解 情感8 + 韵律8 = 16 轴 ≈ 4.2×10⁶ MAC（numpy <10ms），
  远低于思维拍 50ms；**首字延迟瓶颈在 `合成波形` 逐样本循环（非本层）**，须由 03/04 专家做流式分块（见 §10）。

### 6.4 到底省了多少（诚实的三种口径）
1. **固定概念清单**（12+40+128=180 朴素）：因子化 44 固定码 → **~4×**。
2. **韵律×音节**（8N）：`N` 增长归零成本 → **从 O(N) 到 O(K)**，长句不再爆。
3. **发声动作空间**（24576）：→ 5 轴 → **~4900×**，这一项才是真正的"容量炸弹拆除"。
> 综合：相对朴素计数，**本方案的 live 容量代价下降 ≥ 2 个数量级**，且**保住了泛化与混合**。

态.写情绪(V=..., A=..., P=..., G=..., M=..., X=..., T=..., Nv=..., 强度=..., t=...)

## 8. Q6 · 可失败判据（≥3 条，均量化、可真失败）

> 门槛先定后测；任一条不满足即判**失败**。

### E1 · 情绪可辨性（因子化是否真把情绪分开了）
同一文本（如"这个按钮我点了一下"）以 12 情绪各合成 3 次，取 4 维听感特征 `F0均值/F0半音std/时长/能量CV`：
- **a**：核心 12 情绪两两 z-欧距最小值 `≥ 0.6`；Fisher 判别比 `≥ 2.0`；
- **b**：**羞耻 vs 内疚**（最难对）z-欧距 `≥ 0.4`（若 <0.4 即承认 §9 边界 2 成立并判 E1 局部失败）；
- **c**：同情绪重复 3 次，F0 均值组内 std `< 1.0 Hz`。
- **FAIL**：任一不满足 → 因子轴映射退化（例：X 轴被噪声淹没时 b 必 FAIL）。

### N1 · 原生性（可代码审计，无参考音频）
- **a**：发声路径命中禁式数 = 0（禁式：`win32com`/`SAPI.SpVoice`/`pyttsx3`/`transformers`/`torch`/`.softmax(`/`Attention`/`.pt`/`.onnx`/`.gguf`/读取 `wav|mp3|flac`）；
- **b**：运行时 trace——发声调用栈内**无音频文件打开**（仅标定用的离线脚本除外，且不在发声路径）；
- **c**：同一文本、**同一情感向量**、无任何外部音频输入 → 输出稳定，且改变情感向量 → 输出改变（证明"由内部向量驱动"）。
- **FAIL**：命中任一禁式 / 发声路径出现音频读取 → FAIL。

### C1 · 容量压力（塞满后检索保真度）
在单一 live 束中塞入 N 对绑定（含全部情感+韵律+意图+语义窗口），N ∈ {8, 20, 40, 80, 102, 200}：
- 目标项回读 `cos ≥ max(τ, 1/√(1+(N−1)/D))−0.05`；
- N ≤ 102 时 `cos ≥ 0.95`（干净）；102 < N ≤ 1024 允许降质但 `cos ≥ 0.70`（优雅退化，不雪崩）。
- **FAIL**：N ≤ 102 时 cos 跌破 0.95（说明角色码不独立/轴串扰过大）→ FAIL。

### D1 · 确定性逐位一致
同 `(seed, 向量, 文本, 情感态, 遥测)` 两次：`np.array_equal(波形1, 波形2)` 且 wav 字节一致。
- **FAIL**：任何随时间/随机变化（如情感层引入未固定 rng、EFE 并列未定序）→ FAIL。

### R1 · 实时与不阻塞
- **a**：情感+韵律解码层单拍（16 轴）`≤ 15ms`；EFE 选择 `≤ 3ms`；
- **b**：首字延迟 `≤ 300ms`（含合成，若超则须由流式分块补齐，非本层）；
- **c**：发声期间 `共存态.取度量()["最长写ms"] ≤ 20ms`，脑思维拍持续增长（不破 50ms）。
- **FAIL**：任一不满足 → FAIL。

### S1 · 共享不挤爆语义（共享策略的验收）
加入情感/韵律/意图 live 前后，语义字袋检索的 top-1 命中率**下降 ≤ 2%**；
总线 live 项 N ≤ 102 时语义 cos 不低于仅语义时的 `0.95×`。
- **FAIL**：语义保真下降 > 2%（说明软分区隔离不足）→ FAIL。

> **判据条数：6 条**（E1/N1/C1/D1/R1/S1），全可自动化、可真失败。
> 人耳盲测（12 情绪 × N 句，两位听者认同率 ≥ 75%）作**补充**，不计入自动判据。

## 9. Q7 · 诚实边界（哪些做不到，如实说）

1. **音色天花板**：`声带.py` = Rosenberg 单脉冲 + 3 谐振器级联，**缺 LF 声门流导数/唇辐射/鼻分支/微颤**。
   即使情感-韵律完美驱动，听感仍**偏电子/机器人**；它能承载**可辨的语气**，但**谈不上像真人嗓音**。
   要"更像人"的合规正道是**升级 DSP 本身**（不换架构），不是 RVC/TTS。
2. **HDC 下必然相似的情感对**（如实点名）：
   - **羞耻 vs 内疚**：仅靠 `X`（公开暴露）一轴区分。D=1024、S=16 时相邻档 `cos=0.9375`，
     噪声 σ=1/√D≈0.031；若两者 X 读数**差 0 档 → 必然混淆**，差 1 档 → cos 差 ≈0.06≈2σ（**临界可分**）。
     所以判据 E1-b 设为 0.4（而非核心情绪的 0.6），**承认它天然难分**。
   - **羡慕 vs 嫉妒**：仅靠 `T`（关系威胁）强度差；T 差 ≤1 档时不可辨。
   - **骄傲(真实) vs 傲慢**：仅靠 `M` 深浅 + `P`，同理临界。
   - **羞耻 vs 尴尬**：仅靠 `M` 深度；浅道德差会被噪声吃掉。
   > 这四对是**因子化降维的固有代价**，不是 bug；修法是引入 O/B（整体自我/具体行为）第 9 轴，但**会再加码位**——本方案选择**如实标注而非偷偷扩维**。
3. **"嘲讽/反语"这类语气**依赖语用/正反知识，**不是 8 个声学参数能独立表达的**——需上下文语义层配合，超出声音侧。
4. **EFE 前向模型的泛化有限**：无梯度、One-shot 联想记忆，未见过的"动作→听感"对估计不准；
   ambiguity 项只能缓解，不能根治。冷启动期 EFE 选择可靠性低。
5. **因子正交性假设**：真实情感维（如效价-唤醒）并非严格正交，因子化是**可计算近似**，会有模型误差。
6. **延迟瓶颈不在本层**：`合成波形` 逐样本循环是首字延迟主因；本层（解码+EFE）贡献 ≤ 18ms，**不能替它背锅，也不能替它解决**。
