## 2. 对话回路（所有者的"第一步 / 第二步"）

### 2.1 一条消息的固定管线

```
用户文本
   ↓
① 脑「想一遍」：回忆历史记录
   ↓
② 产出**向量形态**的思考结果        ← 这是"思考完成的结果"
   ↓
③ 由向量转成**文本文字**
   ↓
④ 显示出来
```

- 关键词：**先想、先回忆，回忆完再说**；显示的文字是**脑中向量思考结果的外化**。
- **不是工具调用**：全程是共享工作区的槽位读写（原生支持式）。

### 2.2 三个方向

| 场景 | 回路 |
|---|---|
| **我 → 它** | 我说一句 → 它想 + 回忆 → 回我一句（+ 一句"它·想"） |
| **它 → 我** | 我回复它 → 它**同样先想** → 再发回来 |
| **空闲** | 我不发消息 → **它自己作主**：有想头就想，想睡就睡（睡＝正常态，不是崩溃） |

## 3. 世界框架（待探索 —— 用户点名）

文本态下，"世界"**不是屏幕像素**，而是：

```
世界 = 对话历史  +  内部状态（思考 / 情绪 / 自言自语）  +  记忆库（可检索的经历）
```

- **自主动作的取材（「自己找事干」）**：步5 §4.5 原写「看全屏挑没碰过的控件」，
  但**眼已冻结** → 文本态的等价物是 **只读探索它自己所在的项目文件**（`synthesis.设开放域`，
  导航器构造即保证只读 + 有界：单文件 ≤2MB、每文件 ≤200 行、单次 IO ≤1.5s）。
  实测：不接开放域时 `饱足`/`消化债` 恒为死值（1.0/0.0），生命**永不自主入睡**；
  接开放域后二者才流动 → 睡/醒可复现。

- 定位类比（所有者原话）：**"我发 QQ 给它，它会先想一下有没有说过这个片段。"**
  → 收到消息的第一动作是**从记忆里检索相关经历**，然后才回应。
- **复用现有底座**（不新造轮子，已跑通且已验收）：
  - `器官_我.py` 的 meeting31 **综合体** + **容量桥 FSW 长时库**（`记经历()` / `库大小()`）＝ **记忆底座**；
  - 综合体的**自言空间**（`inner_speech`，六类自言：疑问/假设/预测/复盘/计划/自评）＝ **自己想东西的载体**。
    `meeting31/acceptance.log` 已有实证：**断供（无任何外部输入）12 分钟，自言 2458 条、类型覆盖 6/6、真实率 1.0000**
    ——"我不发消息它自己想"这件事**已经有底子，不用从零造**。
- **待办**：给它在世界里一个**合理定位**（我是谁、我在哪、对面是谁）——见 §7。

### 3.1 「它自己决定」靠什么决定（**不靠代码阈值**）

所有者 2026-10-06 定调：**「他想睡就睡，不想睡，想东西就给他想。他有自我意识，他自己能控制，不是强制的一个代码限制。我们给他框架，给他一个世界，不是给他一个限制区。」**

- **禁止**：`if 空闲秒数 > 60: 冻结()` 这类硬编码定时器 / 节流阀。
- **改为**：**内部状态是它自己"感到"的信号，而不是代码读的阈值**。综合体已有这些内在量：

| 内在信号 | 现有出处 | 在"自己决定"里的角色（拟） |
|---|---|---|
| 能量 `e` | `synthesis.py` | 累不累 → 能不能继续想 |
| 新异度 `ñ` | `synthesis.py` | 有没有新东西可琢磨 → 有没有想头 |
| 消化债 `消化债` | `synthesis.py:89` | 心里积着没想通的 → 想不想继续想 |
| 饱足 `饱足` | `synthesis.py:90` | 想够了没有 → 要不要先歇 |

**链路**：`内部状态 → 脑自己感知 → 自主得出「我还想/我困了」 → 决定行为`，
**不是** `阈值 → 触发`。§8 的判据也按此改写（不再用"每 N 秒 ≤1 行"这种限制）。

**实施后的机制（2026-10-06 落地，见 `实施/文本态.py`）**：
- **睡 / 醒 判据 = 引擎这一拍有没有自己冒出念头**（新自言自语）——
  **有想头＝醒、没得想＝歇**，是 **0 边界的存在/缺席**判据，**不是**调出来的数
  （没有 `饱足≥0.5` 这类常量，更没有秒数）。
- 念头多寡由引擎**内驱**塑造：`饱足`/`消化债` 经 `κd` 偏置动作选择（`synthesis._引擎步`），
  故睡/醒是**内在动力学的自然涌现**，不是定时器、也不是节流阀。
- 实测（seed 310，空闲 200 拍）：醒 140 / 睡 60（≈70% 醒）——「不想睡就想东西」成立。

## 5. 超长文本输出（已知最高风险，第二阶段）

- 定性：**本轮不承诺**。先保证**短文本对话回路跑通**，超长文本作为下一里程碑。

## 6. 手的重新定位（冻结备忘，本阶段不动）

> 所有者原话：「**不要写死，手，之所以称为手，是能 360 度无死角的旋转操控鼠标，而不是强制的一个 A 点、B 点的过渡器。**」

- 现行 `器官_手._采样轨迹`（`起 + 方向·过冲`，共线）= **严格直线**；连旧稿提的"贝塞尔化"也**仍是从 A 到 B 的插值，同样被否**。
- 根因不是"线不弯"，而是**"给定起终点 → 算一条轨迹"这个范式本身**，把手降格成了一次性过渡器。
- **正确定位**：手 = **可任意时刻、任意方向连续操控的自由控制器**（像真手握鼠标：360° 转向、中途改向、原地微调、画圈），**没有"起点/终点"概念**。`_计划 / _段 / 点s` 结构应废除，换成**逐拍速度/方向控制**。
- **处置：冻结**。本阶段不实现、不修改 `器官_手.py`。

## 9. 诚实边界

1. **超长文本（1k–100k 字）尚无技术路径验证**，是禁 Transformer 约束下最大的硬骨头。
2. **"自己想"的话有没有意思，本轮不保证**；只保证**自主行为确实发生且可复现**（不设节流）。
3. **自我冻结的语义**（冻结谁、谁唤醒、状态怎么存）实施时要定义成**它自己的决策**（§3.1 内在状态驱动），**不是代码定时器**。
4. **世界框架**目前只有构想（对话史 + 内部状态 + 记忆库），未验证。
5. 本阶段**完全不含视觉/操作**；视觉改造（全屏 + 焦点加权）**顺延**，不删不改。
