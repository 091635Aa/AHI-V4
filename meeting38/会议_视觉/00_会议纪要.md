## 0. 结论先行：「像人一样看」的可操作定义，两位独立收敛到同一个

所有者的三句话给的是**否证条件**（不是模型识别 / 不是 OCR / 不是 AI 世界的看），没给正例；
两位专家**各自独立**把它推导成了同一个可判据定义：

> **像人一样看 = 一条受注意调制的、注视限制的采样轨迹。**
> 每拍输出的是 **(下一注视点 g′, 惊讶/预测误差 s, 保拓扑的视觉场 Φ)**，
> 而**不是**单帧全域解析出的**离散物体列表**。
> 看 = 「带着预期去采样 → 只把"意外"传下去 → 据此决定下一眼看向哪里」。

两位各自给出的**划界判据**（措辞不同、实质同一）：

| 维度 | AI 式看（被否） | 像人一样看 |
|---|---|---|
| 采样 | 全帧、均匀、一次性 | **中央凹高分辨 + 外周低分辨，逐注视（眼跳）** |
| 上行 | 全帧内容 / 物体列表 | **预测误差**（只传"变的、意外的"） |
| 时序 | 单帧静态快照 | **注视链（主动采样序列）** |
| 语义来源 | 外部模型给的类别标签 | **亲历交互 + 可预测性** |
| 产物 | 「框 + 类别」 | 「我下一步看哪」+「这次和我的预期差多少」 |
| 对稳定世界 | 每帧全量解析（照看不误） | **适应、几乎不输出（视而不见）** |

**32 条人眼机制的逐条判定**（01 专家）：**11 条可完整复现、3 条部分、1 条不可**（双眼/深度），
其余为上述机制的子项。**没有任何一条需要 Transformer / OCR / 外挂模型 / 梯度。**

## 3. 合并方案（主持人合议版：FPS+GPV）

### 3.1 数据结构（**纯追加**）

```
共存态 新增「视场槽」（新锁 _视场锁 + 新 dict，照步3 自我槽先例，视觉槽一键不动）：
  视场   : float32[1024]      # 当前注视窗的位置绑定视网膜图（保拓扑）
  注视   : (格x, 格y, 持续拍)  # 连续量（数轴档）
  误差场 : float32[1024]      # 场_t ⊙ 场_{t-1}（预测误差的向量形态）
  意外度 : float              # 全局 ∈[0,2]，可直接喂 情感因子层 的唤醒 A
  逐格意外: float32[48]       # 每格精确意外度（无束串扰）
  眼跳数 : int
  注视链 : deque[64]          # [(t, 格x, 格y, 意外度, 场指纹)]

视觉槽「元素s」保留全部键与字段（读侧零改动），但**来源改写**：
  元素s = 视场里"预测持续失败 / 注视确认稳定"的结构涌现 → 句柄/框/心/主色/形状；字 = ""（C9）
```

### 3.2 三个组织原语（全由现有算子合成，**不新增数学**）

| 原语 | 做什么 | 由什么合成 | 代价 |
|---|---|---|---|
| **P1 视场码** | `束_p( 绑(位置原子_p, 特征码(原始像素块_p)) )`；位置原子 = `绑(数轴x档, 数轴y档)` | `特征码`（眼睛入口）+ `绑` + `束` + `数轴` | 投影阵 ≈7.5MB；单拍 ≈8–12ms |
| **P2 误差场** | 单格 `Δ=绑(块码_t, 块码_上)` → 精确意外；全局 `误差场=束_p(绑(位置原子_p, Δ_p))` | `绑` + `束` + `相似` | <0.5ms；缓存 196KB |
| **P3 眼跳链** | `分数 = w1·意外度 + w2·显著度 + w3·意图偏置 − 抑制返回` → argmax（tie 按格序） | `fsw_kernel._topk序`（确定性）+ deque | <0.2ms；300KB |

**注意 FSW 的复用**：视场码若堆 >40 块，`束` 的 1/√K 串扰会上升（项目第四次撞同一物理学）——
**必须配 IVF 寻址**（正好复用步 1 的 `fsw_kernel`，不裸束堆大场）。

### 3.3 一拍算法（约 10 Hz）

```
① 截屏 → 降采样视网膜图
② 按当前注视取中央凹 3×3 全分辨率 + 外周 39 格粗降采样      ← 中央凹/周边（人眼 #1）
③ 每格：原始像素块 → 态.编码.特征码 → 块码_p                ← 零手工特征（规避被否路线）
④ 场_t = P1.视场码(视网膜, 注视)                            ← 保拓扑场（非框列表）
⑤ (误差场, 逐格意外, 意外度) = P2.误差场(块码_t, 块码_上)     ← 预测编码（只传"意外"）
⑥ 下一注视 = P3.下一注视(逐格意外, 显著度, 意图偏置, 抑制返回) ← 主动采样 + 联动（读意图槽）
⑦ 元素s 涌现：逐格意外>阈值做 4-邻域 BFS 连通（48 格小图上做，非 cv2）
        + 注视稳定且低惊讶者确认 → 复用 _配句柄 贪心分配句柄 → 写视觉槽.元素s
⑧ 知道：预测签名 → FSW内核.检索内容 → 误差小=认得；误差大=新异 → 投事件槽 → 我器入库
⑨ 写视场槽 + 写视觉槽.元素s
```

### 3.4 谁写谁读（七路不破）

| 槽 | 写 | 读 | 变化 |
|---|---|---|---|
| **视场槽（新）** | 眼（单写） | 语义（预测签名）、脑（注意）、我（经事件槽） | 新增 |
| 视觉槽.元素s | 眼（单写） | 脑/手/语义（**零改动**） | 语义不变，**来源**改 |
| 意图槽.当前 | 脑 | 眼（作意图偏置，**新增只读**） | 不变 |
| 事件槽 | 眼（投"惊讶/新结构"） | 我 | 不变（复用既有通路） |

- 红线一合规：眼只读写共享工作区，**不调用/不 join 任何器官**。
- 锁：视场槽独立锁，**锁内只赋值不计算** → A1「最长写 <50ms」不破。
- 读侧零改动 → A2–A7 / W1–W6 输入不变，可复跑。

## 4. 对三个核心张力的最终裁定

**张力 A（范式）：`编码器.特征码`＝"投影成向量再算相似"，是不是被否的"AI 式看"？**
→ **不是。感知层保留该范式；不动编码器。** 两位独立给出同一分界（三条缺一不可）：
① **投影什么**（中央凹窗/保拓扑块 vs 整帧）；② **投影去干什么**（比上一拍预测得惊讶 vs 比类别码本得标签）；
③ **输出给谁用**（驱动下一步动作/注意 vs 世界的符号描述）。
神经学依据（两位都引）：人 V1 本就是随机投影 + Gabor + 群编码，与 `特征码` **同构**——
"编码成高维向量"不是 AI 式看的标志。

**张力 B（接口）：`元素s = 框列表`（离散、全帧、静态）是不是就是要否的"AI 式看"？**
→ **是，两位都判"是"。** 但**不动它**（动它会破七路契约）：
新增独立**视场槽**把"看"的本体搬进去；`元素s` **降级为派生物**（由视场涌现，字段签名不变）。
范式换掉、契约不破——这是唯一低风险落点。

**张力 C（"知道"）：不做分类/不打标签，"知道内容"如何产生？**
→ **`语义.py` 的功能签名是答案的一半（且是关键的一半），两位都判"方向完全正确"**：
"是什么"由**亲历点击后世界怎么变**决定，名字长相都不参与。
**缺的另一半 = 预测签名：知道 = 可预测**（每拍「我预期它这样变 ⊕ 它实际这样变」，误差小→认得/误差大→新异）。
合起来，**"知道"的可操作定义 = 能被预测（熟悉） + 能被驱动交互（能做什么）**，零分类、零标签。
> 注：两位都指出，禁 OCR 后功能签名的"文字变化项"恒空 → **签名退化为纯几何**，
> 但这与 `语义.py` 自己"名字长相都不参与"的设计意图**一致，非致命**。

## 6. 诚实边界（不粉饰，含 02 抓到的安全回归）

1. **字面"知道"做不到，且无预见路径**：C9+C10 下，从像素读出"这是汉字『确定』/这是猫"在纯 HDC 里没有可预见解法（与符号接地同量级）。**引擎应主动放弃这条路，不要绕**。
2. **能对齐的是"计算结构"，不是"规模与发育"**：人视皮层 ~5 亿神经元、多层预测编码、发育期数十亿次注视；AHI 是 1024 维单层随机投影。定位=**结构上像人、能力上是幼儿期极简版**。
3. **恒常性是涌现近似**：随机投影不保证平移/尺度/光照不变；靠"眼跳重采样 + FSW 长时库"得经验恒常，会漏会慢。
4. **束的 1/√K 极限**（本项目第四次实证）：视场叠加 ≤~40 块，**必须配 IVF**。
5. **深度/立体不可**（单屏单眼无第二视差源）；**学习性预测不可**（禁梯度）；**颜色恒常不可**；**gist 是弱 gist**。
6. **⚠ 安全回归（02 独有发现，必须配套）**：禁 OCR 后 `脑._注意` 的危词表（"钱包反射"安全闸）**失效**——需改由系统自报事实源或高风险窗口整体回避。这是本轮**唯一的非视觉改动**。
7. **冷启动"不认识"是设计要的诚实**（与 `语义.py` 叠加支配"未裁决=未知"同一种诚实），不是失败。
