## 0. 结论先行（一页纸）

1. **「投影成向量再算相似」不是罪。** 分界线不在「是否编码成高维向量」（人脑也是神经元群群编码，V1 本身就是随机投影＋Gabor 滤波，与 `特征码` 同构），而在**三件事**：**（a）是否主动采样（中央凹＋眼跳），（b）是否传「预测误差」而非「全帧内容」，（c）语义是否来自亲历都能否预测，而非外部标签**。AI 式看 = 一次性、全帧、静态、无预期、外向贴标签；像人一样看 = 逐注视、局部、时间性、预测驱动、亲历锚定。**现状病灶是 (a)(b) 缺失 + 语义入口外包给 YOLO/OCR，不是`特征码`这个算子。**

2. **现有表示原语承载力：够。** `特征码/绑/束/相似/数轴/FSW内核/语义功能签名` 六个原语零修改即可承载「像人一样看」的全部表示需求。**不需要更强的编码器，也不许拿 cv2 手工特征去补**（那是被否的「AI 世界的看」）。

3. **缺的不是「编码能力」，是三个「组织原语」**（全部由现有算子合成，不引模型）：
   - **P1 `视场码`**（位置绑定视网膜图，连续视觉场）——缺一个「空间组织原语」；
   - **P2 `误差场`**（`Δ = 场_t ⊙ 场_{t-1}`，预测误差的向量形态）——缺一个「预测原语」；
   - **P3 `眼跳链`**（状态化的主动采样序列，非表示原语）——缺一个「时间结构」。
   三者代价：**显存增量 < 10 MB（净减，因可下线 YOLO 视网膜）；单拍 CPU ≤ 12 ms；每拍确定性可复现。**

4. **接口裁决（张力 B）**：`视觉槽.元素s=框列表` 确实是 AI 式看的接口，**但不动它**——新增独立 **`视场槽`**（照步 3 `自我槽/事件槽` 先例，纯追加），把「看」的本体搬进去；`元素s` 降级为**视场误差场里「持续预测失败的结构」涌现出来的下游派生物**。→ 七路读侧**零改动**，A1–A13 / W1–W6 不失效。

5. **「知道」（张力 C）**：`语义.py` 功能签名 = 亲历点击结果、名字长相都不参与，**方向完全正确、是答案的一半**；但它是**被动、事后、单点**的。补另一半 = **`预测签名`：知道 = 可预测**（每拍「我预期它这样变 ⊕ 它实际这样变」，误差小→认得，误差大→新异）。**仍不打标签、不 OCR。**

6. **诚实边界**：引擎能对齐人的**计算结构**（中央凹/眼跳/预测/主动/亲历），**不能对齐人的「字面知道」与「规模/发育」**。开放词汇的「读出这是汉字/这是猫」在 C9+C10 下**没有可预见路径**，是真开放难题（与人语义接地同量级）。AHI 的天花板是**功能性/关系性/预测性「知道」**——而这恰好是所有者原话「要它知道内容，而不是框出来」所指的东西。

## 1. 先把「像人一样看」定义成可操作的工程判据

所有者无法自描述（默会知识），故由本专家推导出**三条可操作分界**（每一条都能写成判据，见 §6）。这里给的是**表示层**视角的定义，不是认知科学综述（那属 01 号专家）。

| 维度 | AI 式看（被否） | 像人一样看（本方案） | 对应引擎原语 |
|---|---|---|---|
| **采样** | 全帧、一次性、均匀 | **中央凹高分辨 + 外周低分辨**，逐注视（眼跳） | P1 视场码、P3 眼跳链 |
| **上行内容** | 全帧特征向量／物体列表 | **预测误差**（只传「变的、意外的」） | P2 误差场 |
| **时序** | 单帧静态快照 | 注视链（时间序列、主动采样轨迹） | P3 眼跳链 + FSW 长时库 |
| **语义来源** | 外部模型给的类别标签 | **亲历交互 + 可预测性**（误差收敛=认得） | 语义.功能签名 + 预测签名 |
| **产物** | 「框 + 类别」 | 「我下一步看哪」+「这次我看到和我预期差多少」 | 视场槽 |

**一句话工程判据**：**「看」由「我选择看哪里、以及我的预期失败了没有」定义，而不是由「我解析了整帧、给每块贴了类」定义。** 这条判据是后文一切设计的总纲，也是 §6 对照判据的依据。

### 审计总结论

- **承载「像人一样看」所需的表示能力早已齐备**：`特征码` 是眼睛入口，`绑/束/相似` 是算子，`数轴` 管连续，`FSW` 管记忆，`语义.功能签名` 管知道。
- **缺口只在「如何组织这些原语」**：缺一个**空间组织原语**（P1）、一个**预测原语**（P2）、一个**主动采样时间结构**（P3）。
- **不要新增**：更强的编码器（不需要）、cv2 手工特征（被否）、字/文本原语（入口问题非表示问题）、新的情感轴（可后补）。
- **不新增模型的承诺**：P1/P2/P3 **全部是 绑⊕束⊕相似⊕特征码⊕数轴 的组合**，不 import torch 之外任何东西（torch 仅用于既有 GPU 常驻余弦），全程零梯度。

## 3. 新原语规格（原因 / 接口签名 / 内存·延迟估算）

### P1 `视场码` —— 位置绑定视网膜图（连续视觉场）

**为什么非加不可**：现有原语都无法表示「一张有空间结构的连续场」——`特征码`把整帧塌成一个码（丢位置），`束`只是无位置的叠加。人眼交给大脑的是**视网膜拓扑图（retinotopy）**，不是物体列表。这是本方案唯一的**新表示原语**。

**接口签名**
```python
# 归属：新增前端模块（建议 实施/视场.py 或 器官_眼2.py 内部类），只读 态.编码，不改引擎
def 视场码(self, 视网膜: np.ndarray,            # HxWx3 uint8（已降采样）
               注视: tuple,                     # (格x, 格y) 当前注视格
               中央凹尺度: int = 1) -> np.ndarray:  # 返回 float32[D]
    """场 = 束_p( 绑(位置原子_p, 块码_p) )
       位置原子_p = 绑(数轴x.编码向量(格x), 数轴y.编码向量(格y))    # 复用 数轴，连续
       块码_p     = 态.编码.特征码(取块(视网膜,p,尺度))            # 复用 眼睛入口，作用在原始像素块上
       中央凹 = 注视邻域 3x3 用全分辨率；其余用粗降采样（人眼外周低分辨）
    """
```
- **位置轴**：`数轴("视场|x", D, 16, 16, 0, 7)`、`数轴("视场|y", D, 16, 16, 0, 5)`，动态导入 meeting32/声带.py（照 情感因子层.py:24-29 的做法，不改其文件）。
- **注视格**：8×6=48 格；中央凹 3×3=9 格全分辨率（24×24×3=1728 维），外周 39 格粗降采样（6×6×3=108 维）。
- **复用同一投影阵**：`特征码` 按输入维度缓存投影阵（共存态.py:110-115），故 1728 维块共用一张 P，108 维块共用一张 P——内存只两份。

**内存估算**：`1728×1024×4B ≈ 7.1 MB` + `108×1024×4B ≈ 0.44 MB` ≈ **7.5 MB**（投影阵）。视场码本身 1024×4B = 4 KB/条。

**延迟估算（CPU numpy，与既有 budget 对齐）**：1728 维一次 `P.T@v` ≈ 1.77 M MAC ≈ 0.5–1 ms ×9 中央凹 ≈ 5–9 ms；108 维 ≈ 0.11 M ×39 ≈ 1–2 ms。**合计 ≈ 8–12 ms/拍**（含符号化/归一化余量给到 15 ms）。既有 `器官_眼` 目标周期 1/6 s ≈ 167 ms，本前端可轻松跑到 **≥10 Hz**。

### P2 `误差场` —— 预测误差的向量形态

**为什么非加不可**：人眼看的是**变化与意外**（预测编码：上行的是「预期之外」）。引擎现有 `变化率`（器官_眼.py:126-141）只是 `absdiff>25` 的**标量占比**，丢掉了「**哪里**变了、变成了**什么**」。需要向量版误差。

**接口签名**
```python
def 误差场(self, 块码_t: list, 块码_上: list) -> tuple:
    """返回 (误差场: float32[D], 意外度_p: float32[48], 全局意外度: float)
       Δ_p       = 绑(块码_t[p], 块码_上[p])          # 全 +1 ⇒ 该格无变化（自逆：无变化=恒等）
       意外度_p   = 0.5*(1 - mean(Δ_p))  ∈[0,1]        # 每格精确、无串扰（保留上帧块码即可）
       误差场     = 束_p( 绑(位置原子_p, Δ_p) )         # 生成式表示，供长时库/语义/长时认
       全局意外度 = 1 - (误差场 @ 1⃗)/D  ∈[0,2]         # 可直接喂 情感因子层 的唤醒 A
    """
```
- **关键设计**：单格误差用「同一格两帧块码相绑」**精确计算**（无束串扰）；而**全局误差场**才用束合成，其串扰正好交给 FSW 的 IVF/检索去吸收。表示与检索解耦。

**内存/延迟**：48 次 1024 维逐位乘 + 一次束 ≈ `48×1024×2 ≈ 10^5 MAC < 0.5 ms`。缓存上帧块码 48×1024×4B ≈ 196 KB。

### P3 `眼跳链` —— 主动采样状态机（时间结构，非表示原语）

**为什么非加不可**：人眼是**主动**的——「看哪里」本身是被上一次结果驱动的序列。`器官_脑._注意`（器官_脑.py:120-145）是它的**粗版**（用「新异+有字」打分），但它**不是表示层原语**、也不由视觉误差驱动。这里把它升格为视觉前端的核心结构。

**接口签名**
```python
def 下一注视(self, 意外度_p: np.ndarray, 显著度_p: np.ndarray,
             意图偏置_p: np.ndarray, 抑制返回: np.ndarray) -> tuple:  # (格x, 格y)
    """分数 = w1*意外度_p + w2*显著度_p + w3*意图偏置_p - 抑制返回
       返回 argmax(分数)；ties 按格序升序（复用 fsw_kernel._topk序 的 stable 确定性约定）
       抑制返回：最近 K 次看过的格衰减掩膜（防抖动/防死盯）"""
```
- **意图偏置**：读 `态.取意图()` 的 `当前.目标点`（脑写）映射到格——这就是所有者要的**「联动式视觉」**：视觉由任务驱动，而非被动扫全屏。
- **状态**：`注视链 = deque(maxlen=64)[(t, 格x, 格y, 意外度, 场指纹)]`；`上帧块码s`；`抑制返回`。内存 < 300 KB。延迟 < 0.2 ms。

## 4. 具体方案：中央凹—预测—眼跳视觉前端（FPS）

> 可照实现。全程无模型、无 OCR、无梯度；新原语由 绑/束/相似/特征码/数轴 合成。

### 4.1 数据结构

**新增独立「视场槽」（不碰既有「视觉槽」任何一个键）**
```python
# 共存态 新增（照 步3 自我槽/事件槽 先例：新锁 + 新 dict + 新读写方法，纯追加）
_视场 = dict(
    视场   = None,          # float32[D]  当前注视窗的位置绑定视网膜图
    注视   = None,          # (格x, 格y, 持续拍数)  连续量（数轴档）
    误差场 = None,          # float32[D]  场_t ⊙ 场_{t-1} 的生成式表示
    意外度 = 0.0,           # float  全局意外度 ∈[0,2]
    逐格意外 = None,        # float32[48]  每格精确意外度
    眼跳数 = 0,             # int
    注视链 = deque(maxlen=64),  # [(t, 格x, 格y, 意外度, 场指纹)]
    更新t  = 0.0,
)

def 写视场(self, **kw):   # 单写者=眼；锁内只赋值不做计算（沿用既有纪律）
def 取视场(self) -> dict: # 深拷贝快照
```

**既有「视觉槽」不动**：`元素s` 仍在 `视觉槽`（下游零改动），但它的**来源**改变——从「YOLO/Canny 框」变为「视场误差场里持续预测失败的结构」（见 4.2 步 7）。

### 4.2 算法步骤（一拍，约 10 Hz）

```
① 截屏 → 降采样得「视网膜图」（外周低分辨率，供 P1 取块）
② 按当前注视 取中央凹 3×3 全分辨率 + 外周 39 格粗降采样
③ 每格：raw 像素块 → 态.编码.特征码 → 块码_p        （复用眼睛入口，无手工特征）
④ 场_t = P1.视场码(视网膜, 注视)
⑤ (误差场, 逐格意外, 意外度) = P2.误差场(块码_t, 块码_上)
⑥ 眼跳： 下一注视 = P3.下一注视(逐格意外, 显著度, 意图偏置, 抑制返回)
          （显著度=局部方差，可选；意图偏置来自 脑 写的 意图槽.当前.目标点）
⑦ 【结构涌现→元素表】把 逐格意外>阈值 的格做 4-邻域 BFS 连通（48 格小图上做，非 cv2）
          → 得「预测持续失败的区域」；与上帧 元素s 按重叠/近心贪心匹配（复用 器官_眼._配句柄 逻辑）
          → 跨 N 拍稳定者分配句柄；框=区域外接矩形，心=中心，字=""（禁 OCR）
          → 写 视觉槽.元素s（框/句柄/心齐备，供手/脑/语义零改动消费）
⑧ 【知道】预测签名 = 束(绑(位置原子, 预期块码) ⊕ 绑(位置原子, 实际块码))
          → FSW内核.检索内容 → 命中且误差小=认得；误差大=新异（投 事件槽 → 我器入库）
⑨ 写 视场槽（视场/注视/误差场/意外度/注视链/眼跳数）+ 写 视觉槽.元素s（向后兼容）
```

**「物体」是怎么来的（核心消歧）**：不是被模型**框**出来的，而是「**我盯着某个位置、预测一直失败 → 那里有个我没建模的东西 → 给它一个句柄、盯着它**」**涌现**出来的。变化优先、预测失败优先，正是人眼「看到动的东西/意外的东西」的机制。

**为什么这不是被否的「cv2 特征」、也不是「AI 式看」（三方对照）**
| | 被否的 cv2 特征 | AI 式看（YOLO/OCR） | 本方案 FPS |
|---|---|---|---|
| 低层算子 | **手工特征**（直方图/边缘/Hu矩/纹理） | 预训练卷积 | **引擎自己的 `特征码`（随机投影=感受野）作用在原始像素块上——无手工特征** |
| 采样 | 全帧均匀 | 全帧一次 | **中央凹+外周、逐注视** |
| 上行 | 特征向量→贴标签 | 框+类别 | **预测误差（变了什么）** |
| 时序 | 无 | 单帧静态 | **注视链（主动采样序列）** |
| 语义 | 无（交给下游） | 外部模型给 | **亲历+可预测，无标签** |

> 措辞澄清：V1 皮层**本身就做 Gabor 滤波**（经典 CV 的算子），所以「用了边缘/滤波」不是罪；被否的是**把手工特征当「看」的本体、并交给一次性的全帧贴标签流水线**。本方案连手工特征都不用——直接把原始像素块喂给引擎既有的随机投影入口，把「像人」做在**采样与预测**上，不做在特征工程上。

### 4.3 与既有原语的映射（谁直接复用、谁新增）

| 环节 | 复用（零修改） | 新增 |
|---|---|---|
| 眼睛入口 | `编码器.特征码` | — |
| 空间组织 | `绑`、`数轴`、`相似` | **P1 视场码** |
| 预测误差 | `绑`、`束`、`相似` | **P2 误差场** |
| 主动采样 | `fsw_kernel._topk序`（确定性） | **P3 眼跳链**（结构） |
| 记忆/检索 | `FSW内核`（IVF/E5） | — |
| 知道 | `语义.功能签名/容器树/叠加支配` | **预测签名**（复用同束/绑） |
| 长时入库 | `容量桥.记经历`（经 事件槽） | — |

## 5. 与既有七路运行时的对接（谁写谁读 / 锁并发 / 是否动视觉槽接口）

### 5.1 接口裁决

**要动 `共存态`，但只做「纯追加」**：
- **不改** 视觉槽（`_视觉` dict）**任何一个既有键、任何一个既有方法的语义**；
- **新增** 一个独立 **`视场槽`**（`_视场` dict + `_视场锁` + `写视场` / `取视场`），照步 3 追加 `自我槽/事件槽/计划槽` 的**同一先例**。

**理由**：`元素s=框列表` 这个接口确实是 AI 式看的接口（张力 B），但它是七路的下游契约；**直接替换会破 C14**。用「新增视场槽 + 元素s 降级为派生物」既把「看」的本体换成连续视觉场，又让读侧一行不改。这是「要改范式、但不破既有」的唯一低风险落点。

### 5.2 谁写谁读

| 槽/数据 | 写者 | 读者 | 变化 |
|---|---|---|---|
| **视场槽**（新） | **眼（单写）** | 语义（建预测签名）、脑（注视链/意外度做注意）、我（经事件槽入库） | 新增 |
| 视觉槽.元素s | **眼（单写）** | 脑、手、语义（**均零改动**） | **语义不变**（来源从模型框改为误差场涌现） |
| 视觉槽.焦点 | 脑（置焦点） | 眼（新的注视偏置可参考） | 不变 |
| 意图槽.当前.目标点 | 脑 | 眼（作**意图偏置**）、手 | 不变（眼新增只读） |
| 动作槽 | 手 | — | 不变 |
| 事件槽 | 眼（投「发现新结构/极度意外」）、手、耳 | 我（`容量桥.记经历`） | 不变（复用既有通路） |

**红线一合规**：眼读意图槽、写视场槽与视觉槽、投事件槽——**全是读/写共享工作区，不是调用/等待任何器官**。不新增任何 `join`/`call`。

### 5.3 锁与并发（A1–A13 / W1–W6 不许失效）

- **锁**：视场槽用**自己的锁**（`_视场锁`），与视觉槽锁独立——单路写不阻塞他路读（与既有「每槽一把锁」完全同构）。
- **锁内不计算**：特征码/视场/误差/眼跳**全部在锁外算好**，`写视场` 只做 dict 赋值（沿用 共存态.py 顶部纪律与 `_计` 度量）。→ **A1「最长写 ms < 50」不被破**。
- **读侧零改动**：`取视觉()` 返回的既有键（`元素s/帧号/变化率/焦点/屏幕`）**逐字段不变**；`找元素(句柄)` 不变 → **手的 A2/A3 中途纠偏不变**；脑 `_归因/_注意/_出招` 不变 → **A4/W1 不变**；语义 `运行()` 仍读 `取视觉()` → **A5/W4/W6 不变**（`元素s` 仍有 框/心/句柄）。
- **A7 确定性**：视场码/误差场/眼跳序列**全部由 `特征码`（固定投影）+ `绑/束/相似`（确定性）+ `_topk序`（stable）构成**，同种子同输入逐位一致。眼跳 ties 用格序升序（确定性）。
- **A6 非 Transformer 审计**：本方案不引入 `attention/QKV/softmax/transformers/nn.Linear`——`特征码` 内部是 `np.sign(P.T@v)`，`nn` 不参与；审计脚本（自检.py:219-237）扫的是代码结构，新代码同样干净。
- **A8–A13**：未在本文件列出（`自检.py` 实装 A1–A7，已逐条核对）；因本方案对**所有既有读侧输入零改动**、新增全部为**纯追加**，其判据输入不变，故不因本方案改变。**W1–W6**（生命体.py:169-186）同理：其输入 `元素s/语义/动作槽` 均不动，全活。

### 5.4 必须同时处理的两个既有耦合（诚实点名，非「破」但需配套）

1. **`语义._元素码` 的文字通道会消失**（禁 OCR 后 `e["字"]` 恒为 ""）：功能签名退化为「新增⊕消失」的纯几何版本。**这与 `语义.py` 自己「名字长相都不参与」的设计意图一致**（主持人报告 §6.3 已述），非致命；但需在语义侧接入「预测签名」以补回判别力。
2. **`脑._注意` 的「钱包反射」依赖 `e["字"]` 的危词表**（器官_脑.py:114-135）：`字` 恒空后，该安全闸**失效**。→ 建议配套：安全闸改由 `UIA 控件名`（辅助事实源，非主路）/ 位置历史 / 叠加支配驱动，或对高风险窗口整体回避。这是本方案**必须随附的一处非视觉改动**（不在本文范围内，登记为待办）。

## 6. 可失败判据（≥3 条，含量化门槛、像人 vs AI 对照、延迟/确定性）

> 每条都能**真失败**，给出门槛与「失败会长什么样」。

### V1 【像人 vs AI 对照判据：由「选看哪」定义「看」】
- 同一动态界面，注入 N≥50 次**局部**变化（如角落按钮变色）。
- **要求**：FPS 的「**误差驱动注视命中率**」＝「下一次注视落在真实变化区域」的比例 **≥ 0.80**（二项检验 p<0.01）。
- **可失败**：若误差场无位置分辨力，命中率会掉到**随机水平**（≈变化区面积/全屏 ≈ 0.05）。
- **对照意义**：AI 式前端**不产生「注视」**，无法定义此量——这正是「像人 vs AI」的可操作分界。辅：FPS 的高分辨采样面积占比 **≤ 15%**（AI 式 = 100%），证明「非全帧解析」。

### V2 【预测编码判据：知道 = 可预测】
- 对同一重复出现的结构反复注视 N≥20 次。
- **要求**：第 k 次见到的**意外度 ≤ 第 1 次的 40%**（收敛比 ≤0.4）；且注入**未见新结构**时 意外度 **≥ 3×** 已收敛基线，新旧可分 **AUC ≥ 0.90**。
- **可失败**：若视场码对「同一结构」不稳定（随机投影把位移/光照当变化），意外度不收敛 → 失败。

### V3 【「知道」不靠标签/OCR 判据】
- 全程**无 OCR、无模型**，把界面**文字全部涂成马赛克**（禁掉一切字形信息）。
- **要求**：语义功能聚类在「有字」与「马赛克」两种条件下**一致率 ≥ 0.90**；且仍满足 A5 已有门槛（同名异效 cos < 0.5、异名同效 cos ≥ 0.8，只是输入换成视场/预测签名）。
- **可失败**：若签名退化成依赖像素长相，马赛克后一致性暴跌。→ 正面兑现 C9（禁 OCR 下仍「知道」）。

### V4 【延迟/确定性/并发判据】
- **延迟**：单拍（截屏→视场→误差→眼跳→元素涌现）**P95 ≤ 33 ms**（目标 ≥30 Hz；允许下限 15 Hz → ≤67 ms）；60 s 连续跑 **`取度量()["最长写ms"] < 50`**（沿用 A1 既有阈值）。
- **确定性**：同种子同输入两次运行，视场码 / 误差场 / 眼跳序列**逐位一致**（`np.array_equal`）。
- **并发**：接入七路跑 `生命体.跑()` → **全线存活=True、W1 脑不阻塞率 ≥ 0.8、A1 最长写 <50 ms、A5/W4/W6 语义判据不退**。
- **可失败**：任何未播种随机 / 非确定聚合 / 锁内计算，都会让其中一项失败。

### V5 【净资源判据（防「贪心实现」）】
- 显存增量 **≤ 10 MB**（且因可下线 YOLO 视网膜而**净减**）；每拍新增 CPU **≤ 12 ms**。
- **可失败**：若对全帧所有格都做高维特征码 → 会超 budget（实测会）→ 证明「中央凹优先」不是装饰而是必需。

## 7. 诚实边界（做不到什么 / 天花板 / 是否同量级开放难题）

1. **字面「知道」做不到，且无预见路径。** C9 禁 OCR + C10 禁模型后，从像素读出「这是汉字『确定』/这是猫」在纯 HDC 里**没有可预见的解法**。这是真开放难题，与人类语义接地（symbol grounding）**同量级**——人靠一生多模态具身经验接地，AHI 没有。**引擎应主动放弃这条路**，不要试图绕。
2. **能对齐的是「计算结构」，不能对齐「规模与发育」。** 人视皮层 ~5 亿神经元、多层预测编码、发育期数十亿次注视训练；AHI 是 **1024 维单层随机投影 + 在线一次性学习**。对得上的是中央凹/眼跳/预测/主动/亲历这套**结构**；对不上的是**容量与发育史**。→ 定位应是「结构上像人、能力上是幼儿期极简版」，**不是同量级可补齐**。
3. **恒常性是「涌现的近似」，不是「解析的保证」。** 随机投影**不保证**平移/尺度/光照不变；FPS 靠「眼跳重采样 + FSW 长时库匹配」得到**经验恒常性**（见过的样子多就检索得住），会漏、会慢，且**不覆盖训练分布外的剧烈变换**。
4. **束的 1/√K 极限。** 视场叠加 ≤ ~40 块后串扰上升；**必须 IVF 寻址**，不能靠裸束堆成大场（fsw_kernel §9 的同一物理学）。
5. **「整帧大意(gist)」是弱 gist。** 1024 维随机投影**承载不了**一张复杂屏幕的整体语义（信息量不够）。只能靠**低分辨率外周场 + 长时库**近似，做不到人那种「一眼抓住全局」。
6. **禁 OCR 的连带代价（必须写进账）：** 文字通道消失 → 语义签名退化（§5.4-1）、钱包安全闸失效（§5.4-2）。前者非致命（设计本就名字不参与），后者是**安全性回归，需配套**。
7. **「不知道自己在看什么」的常态。** 在没亲历、没预测收敛前，AHI 就是「不认识」——这是**设计要的诚实**（语义.py 叠加支配「初始必须未知」的同一种诚实），不是失败。

## 8. 对三个核心张力的逐条表态

### 张力 A（范式）：`特征码`=「投影成向量再算相似」是不是就是被否的 AI 式看？

**明确表态：不是。感知层可以、也应该保留「投影成向量」范式；要动的不是 `编码器` 这一层。**

- **判据（分界线三条）**：① **主动采样**（中央凹+眼跳）vs 全帧一次；② **上行预测误差** vs 上行全帧内容；③ **语义来自亲历/可预测** vs 来自外部标签。三条同时满足=像人；缺任一条且语义外包=AI 式。现状病灶在 ① ② 与「语义入口=YOLO/OCR」，**不在 `特征码`**。
- **神经学依据**：人 V1 就是随机投影+Gabor+群编码；`特征码`（固定随机投影+符号化）与之**同构**。把「高维向量编码」本身当 AI 式，是把「表示」误当成「范式」。
- **边界：什么能投影、什么不能**：
  - **能投影**：任何**局部、有限窗口**的原始信号（像素块、音频帧、注视坐标）——因为它是「感受野采样」。
  - **不能/有损**：① 跨窗口的整体语义（单帧随机投影载不动，需时间束+长时库）；② 绝对不变性（随机投影不保证，恒常性只能涌现）；③ 任意长程依赖（束 1/√K 极限）；④ **文字字义**（禁 OCR，投影变不出字义）。
- **要动哪一层**：动 **`器官_眼`（写什么）** 与 **视觉槽（加视场槽）**，新增 P1/P2/P3；**不改编码器**（`特征码/绑/束/相似/数轴` 一字不改）。

### 张力 B（接口）：`元素s=框列表` 是不是就是要否的 AI 式看？改「连续视觉场」怎么做、成本多少？

**明确表态：这个接口本身是 AI 式看的接口（物体列表=AI 世界产物），但不动它，而是新增视场槽把它降格。**

- **人眼交给大脑的是「连续视网膜场 + 注视位置/时间 + 预测误差」**，物体列表是**下游构造物**，不是入口。
- **改法（具体）**：
  - **数据结构**：新增 `视场槽 = dict(视场:float32[1024], 注视:(格x,格y,持续), 误差场:float32[1024], 意外度:float, 逐格意外:float32[48], 眼跳数:int, 注视链:deque[64])`。
  - **谁写**：眼（单写，独立锁）。**谁读**：语义（预测签名）、脑（注意/注视链）、我（经事件槽入库）。**`元素s` 仍写视觉槽**，但其来源改为「误差场持续失败结构涌现」，供 手/脑/语义 **零改动**消费。
  - **代价**：显存 **< 10 MB**（净减，可下线 YOLO 视网膜）；单拍 CPU **≤ 12 ms**；锁与确定性见 §5。
- **为什么这样改最稳**：直接替换 `元素s` 会破 C14（手 `找元素`、脑差分、语义、W4/W6 全依赖它）。「新增视场槽 + `元素s` 降级」是**范式换掉、契约不破**的唯一低风险落点。

### 张力 C（「知道」）：不打标签怎么「知道内容」？语义.py 功能签名够不够？

**明确表态：功能签名方向完全正确、是答案的一半，但不够——缺「预测签名」，补齐后即为无标签「知道」的一般机制。**

- **够的部分**：`语义.功能签名 = 束(新增码⊕消失码⊕变化码)`，由**亲历点击结果**决定，名字长相都不参与——这正是「不打标签的知道」，**直接承担**「功能性知道」没问题（A5 已证同名异效分开、异名同效归并）。
- **不够的部分**：它只在**点击后**给一次差分，**被动、事后、单点**；人眼在第一眼（没交互前）就能「看懂」，靠的是**预测**而不是交互。
- **补什么**：**`预测签名`（知道 = 可预测）**——每次注视生成「我预期这块下一拍变成什么 ⊕ 它实际变成什么」；误差小→「我认得它」，误差大→「新东西/不认识」，并触发探索。语义.py 的点击差分是它的一个**特例**（点击=一次主动探查）。
- **缺的工程件**：① 把功能签名从「点击事件触发」泛化为「**每拍预测触发**」；② 把签名/预测签名**存入 FSW 长时库**做跨时间认（用 `检索内容`）；③ 把 `_重聚类` 的输入从「点击签名」扩为「点击签名 ⊕ 预测签名」。以上**全复用现有算子**，名字长相仍不参与。
