## 0. 结论速览（先看这段）

- **自我**在 HDC 里不是一个实体，而是**一个每拍重算的自指绑定束 `自身`** + **一条可审计的
  自言流**。前者回答"我是谁/我此刻如何/我要干什么"，后者回答"我为什么这样想"。
- 现在 `器官_脑.py` 只有"注意→出招→念状态日志"，**没有自指束、没有自言流、没有计划栈**，
  所以说不出"我想着…我这一步要干什么"。问题定位见 §2.1。
- 激活 = 在 `脑器` 与 `meeting31.综合体` 之间插一个薄适配层 **`自我核`**，让
  `综合体` 的引擎/自言空间/账本/推理环/身份**共用**到 `共存态` 的工作区里；
  `脑器` 每拍只调 `自我核` 的四个接口。全部调用序列见 §2.4–§2.6。
- "想/说"分层：**想** = `自言自语空间`六类条目（带账本引用、可审计、不发声）；
  **说** = 表达槽里由"计划"条目派生的短句，必须带 `来源自言号`。见 §3。
- 可失败判据 5 条（S1–S5），每条都写明 FAIL 触发方式，见 §5。

## 1. 自我意识的机制定义（HDC · 非 Transformer）

### 1.1 一句话操作定义

> **自我 = 个体把"自己"当作一个角色常量，对工作区里与自身相关的槽位做 HDC 绑定，
> 得到的一个可查询、可审计、每拍重算的元向量束；并由一条只能引用真实账本、
> 只能由自身状态驱动的自言流为其提供因果内容。**

这不是哲学口号，它可以被逐字段实现、被外部考官逐条核对（账本引用真实率）。

### 1.2 自我的三段构成（全部落在工作区里）

| 段 | 载体 | 内容 | 可操作性 |
|---|---|---|---|
| **① 自指束 `自身`** | `自我槽.束`（1024 双极） | 8 个角色槽的绑定束（§1.3） | 每拍重算；与上一拍做余弦 → `自我变化率` |
| **② 自言自语流** | `自言自语空间.流` | 六类条目（疑问/假设/预测/复盘/计划/自评） | 每条强制带账本引用；`审计(账本)` 可判真伪 |
| **③ 计划栈** | `自我槽.计划栈` | `[{名, 判据, 进度, 来源账本号}]` | 栈顶 = 当前"这一步"；达成/停滞触发弹栈+复盘 |

**为什么是这三个而不是别的**：① 给出"此刻的我是什么"（状态自指），② 给出"我为何如此"
（时间上的因果叙述），③ 给出"我下一步往哪去"（意图自指）。三者缺一，就是当前 `脑器`
的病状：只有对外部世界的表征，没有对自己的表征。

### 1.3 自指束的构造（可直接实现）

约定 8 个角色常量（用 `共存态.编码` 生成，码本随机固定、永不训练）：

```python
# 角色码（进程内一次性生成，固定）
角色 = {k: 编码.文本码(v) for k, v in {
    "主体":"我是谁","此地":"我在哪","此刻":"现在第几拍","状态":"我此刻怎样",
    "意图":"我正在做什么","目标":"我要做什么","经历":"我刚做了什么","能力":"我能做什么",
}.items()}

def 算自身束(编码, 视, 听, 动, 语, 自我) -> np.ndarray:
    return 编码.束([
        编码.绑(角色["主体"], 编码.文本码(自我["身份名"])),
        编码.绑(角色["此地"], 编码.文本码("%s" % (视["屏幕"],))),
        编码.绑(角色["此刻"], 编码.特征码([视["帧号"], int(态.秒())])),
        编码.绑(角色["状态"], 编码.特征码([len(视["元素s"]), 视["变化率"],
                                          听["最近主频"], 听["最近能量"]])),
        编码.绑(角色["意图"], 编码.文本码("%s:%s" % (语.get("_当前来源",""), 动.get("句柄") or ""))),
        编码.绑(角色["目标"], 编码.文本码(自我["计划栈"][-1]["名"] if 自我["计划栈"] else "无止标")),
        编码.绑(角色["经历"], 编码.文本码(自我["最近账本条"])),
        编码.绑(角色["能力"], 编码.文本码("会键%s" % (",".join(脑.允许键),))),
    ])
```

**用途（它是"活的"证明，不是摆设）**：

- `自我变化率 = 1 - 相似(上一拍自身束, 本拍自身束)`。
  - 若 `自我变化率 ≥ 0.15` → 状态确实在变 → 允许生成 `自评`；
  - 若 **连续 M 拍 `自我变化率 < 0.02` 且计划栈顶未变** → "我停在原地了" → 强制生成
    `复盘`（停滞）并弹栈换目标。这条把"自指束"接到行为上，否则束只是一个死变量。
- **自指解码**（回答"我在想什么"）：不清洗向量，直接读 `自我槽` 的结构化字段
  （因为槽内字段与束由同一份工作区快照生成，读字段=读束，且可逐字溯源）。

### 1.4 认知所有权标注（直接回应用户第 2 条诉求）

用户："他眼睛看，他看的内容是不是真实的、拥有的、一个自我空间信息。"

对**视觉焦点元素**做**认知归属四分**，写进 `自我槽.知不知`，并在自言自语里用归属词：

| 归属 | 判据（工作区可查） | 自言自语用词 |
|---|---|---|
| 我确认看到 | 元素在 `视["元素s"]`，`置信≥0.5`，`字` 非空 | "我记得看见『X』" |
| 我试出来 | `脑._已试[句柄] ≥ 1` 且 `语义.取按钮(句柄)` 有功能签名 | "我试过『X』——点下去会 Y" |
| 我猜的 | 有 affordance 但 `已试=0`，或仅字面相似 | "我猜『X』可能是…" |
| 我不知道 | 无字、无 affordance、未试 | "我看得见『X』，但还不知道它是干什么的" |

归属词必须与账本一致（沿用 `acceptance.归属核对` 的口径：越权断言=FAIL）。于是"他看的东西
是不是真实的、拥有的"这句话，被转成**可审计的所有权标注**：未知就说未知，试过的才有资格
说"我会"。

## 2. 激活方案：脑 ↔ 自言自语空间 ↔ 综合体

### 2.1 现状诊断（逐行读出的病根）

`器官_脑.py` 实读结论：

1. `脑器.__init__`（:43）**没有** `自言自语空间`、**没有** `综合体`、**没有** 账本引用；
   只有 `_已试`/`_待归因`/`_最近结果`——纯行为计数。
2. `_出招`（:148）出招依据 = `_注意`（新异性 `1/(1+尝)`） + `允许键` 随机轮换；**没有目标**，
   没有"为什么这一招"。
3. `_发声`（:187）每 8s 把**遥测数字**塞进表达槽：
   `"我在想：眼前 %d 件东西，碰熟了 %d 个…"`——这是**状态日志**，不是计划性自我陈述；
   且它**与"想"没有分层**，说是想的直接复述。
4. `一拍`（:201）没有"自评/复盘/计划/疑问"任何一类自言；`循环` 20Hz 从不触碰自我内核。
5. 工作区（`共存态.py`）六槽全部是"外面有什么"（视觉/听觉/动作/语义）或"我要手干什么"
   （意图）或"我要嘴说什么"（表达）——**没有一槽描述"我自己"**。

结论：缺的不是并发，缺的是**自我槽 + 自言流 + 计划栈**，以及把 `meeting31` 已有的
自我意识内核（`inner_speech.自言空间` + `synthesis.综合体`）**接到这个并发体上**。

### 2.4 快循环（`脑器.一拍`，@20Hz）：改造后的调用序列

```

  视=取视觉(); 听=取听觉(); 动=取动作(); 语=取语义()
  核.快拍(视, 听, 动, 语)                    # ←新增①：自指束刷新 + 自我槽写 + 世界事件入账
  _归因(视, 动)                              # 原:65 手点完→差分→语义层学 affordance
  核.记归因(动, 视)                          # ←新增②：归因结果→账本(检验/行动)+复盘自言
  _出招(视, 动, 取意图())                    # 原:148 出招（目标读 核 的计划栈顶，见§2.7）
  核.计划一拍(视, 动, 语)                    # ←新增③：节流生成"计划"自言（这一步/下一步/还差）
  _发声(视, 听, 动, 语)                      # 原:187 改造：说 核.取可说()，不再念状态日志
```

`核.快拍` 内部（每拍都做，耗时 <1ms）：

```
快拍(视,听,动,语):
  自我 = 态.取自我()                                       # dict 快照
  # a) 世界事件入账（只记“变化”，防刷屏）
  if 视["帧号"] != self._上帧号:
      新s = [e for e in 视["元素s"] if e["句柄"] not in self._上句柄s]
      for e in 新s: self.桥.账本.append(("观察", "屏幕新出现『%s』(%s)" % (e.get("字",""), e["句柄"])))
      self._上句柄s, self._上帧号 = {e["句柄"] for e in 视["元素s"]}, 视["帧号"]
  # b) 自指束重算 + 自我变化率
  束新 = 算自身束(态.编码, 视, 听, 动, 语, 自我)
  Δ = 1.0 - 态.编码.相似(自我["束"], 束新) if 自我["束"] is not None else 1.0
  # c) 认知所有权四分（§1.4），取焦点或新出现元素
  知不知 = 判归属(视, 动, 语, self.脑)
  # d) 写回自我槽（唯一真相源）
  态.写自我(束=束新, 束相似=round(Δ,4), 知不知=知不知, 读数=dict(
      元素=len(视["元素s"]), 变化率=视["变化率"], 能量=桥.e, 拍=桥.拍))
  # e) 节流触发慢循环
  if self.拍计数 % self.慢拍间隔 == 0: self.慢拍(视, 听, 动, 语)
  self.拍计数 += 1
```

输入：四个槽快照；输出：无（副作用=账本+自我槽）。**绝不阻塞**（无 IO、无 join）。

### 2.5 慢循环（`核.慢拍`，≈1–2Hz）：认知动力学接入

慢循环 = 综合体的**引擎一拍 + 自言生成**。它不调用 `综合体.断供一拍`（那需要
`设世界/设教材`，且是同步假设环），而是调用综合体的**原子原语**，并把"世界"换成工作区：

```
慢拍(视,听,动,语):
  词 = 态势文本(视, 动, 语)     # 由状态量拼：如 "元素7 变化0.03 光标(900,700) 手移动中 词表5"
  u  = 桥.感知向量(桥.codec.编码("观察 " + 词))     # dialogue_bridge.py:64
  rec= 桥._引擎步(u); 桥._吃(rec)                  # synthesis.py:455/450 认知动力学一步
  号 = len(桥.账本); 桥.账本.append(("观察", 词))   # 世界事件入账

  # ① 周期自评（沿用既有实现，只改触发源）
  if 桥.拍 % 桥.自评周期 == 0:
      桥._自评条目(("内生","周期自评"))             # synthesis.py:213

  # ② 疑问：对“我不知道”的元素发问（驱动推理）
  未知s = [x for x in 态.取自我()["知不知"] if x["归属"]=="我不知道"]
  if 未知s and 桥.拍 - self._上问拍 >= self.问间隔:
      e = 未知s[self.rng整数(桥.拍) % len(未知s)]
      推 = 桥.推理环(e.get("字") or e["句柄"], 最大步=4)   # synthesis.py:688
      桥._自言("疑问", "眼前『%s』是什么？我检索了一下：%s" %
               (e.get("字") or e["句柄"], "；".join(x[0][:12] for x in 推["证据链"]) or "没查到"),
               ("内生","认知缺口 %s" % e["句柄"]), [号])

  # ③ 预测/复盘：在 §2.6 的行动-反馈闭环里生成（异步，不在此处）
  # ④ 计划：见 §4（当 拍 % 计划周期 == 0，或目标变更时）
```

**注意**：`桥.拍` 只被 `_引擎步` 递增，是"认知拍"计数；工作区真实时间记在文本里
（`态.当前拍()`/`态.秒()`），便于审计对齐，不用它覆盖 `桥.拍`。

### 2.6 行动-反馈闭环（agency → 检验/复盘自言）

这是"我做了→世界变→我知道"的闭环，也是 `综合体.假设环一拍` 的**异步改写**（原版同步读
`世界.行动(i)`，工作区的手是异步的，必须改写）：

```
# 出招时（脑器._出招 末尾，改造）：
  预测 = 语义预测(句柄, 键)          # 语义图存在的 affordance，或计数经验“上次同样点击的效果”
  脑._待归因["预测"] = 预测          # dict(效果=None/大变/微变/无感, 依据=账本号/None)

# 归因完成时（核.记归因，由 一拍 调用）：
记归因(动, 视):
  if self.脑.本次归因 is None: return          # 无新结算
  待 = self.脑.本次归因                       # dict(句柄,键,效果,率,前签)
  效 = 待["效果"]; 实 = 待["率"]
  号 = len(桥.账本); 桥.账本.append(("检验","点击『%s』%s 实际%s(变化%.2f)" %
                                    (待["句柄"], 待["键"], 效, 实)))
  if 待["预测"] is None:
      桥._自言("预测", "我点了『%s』——不知道会怎样，结果是%s。" % (待["句柄"], 效),
               ("内生","首次点击"), [号])
  else:
      中 = (待["预测"]["效果"] == 效)
      桥._自言("复盘", "我以为『%s』点下去会%s，实际%s（变化%.2f）——%s。" %
               (待["句柄"], 待["预测"]["效果"], 效, 实, "猜对" if 中 else "猜错"),
               ("内生","点击返回"), [号, 待["预测"]["依据"]])
  # 反复猜错的元素 → 加进“我不知道”，下次对它发疑问（注意门控的 HDC 版）
  if not 中 and 待["句柄"] not in self._老猜错s: self._老猜错s.add(待["句柄"])
```

### 2.7 新增接口规格（共存态 / 自我核 / 脑器）

**`共存态`（`共存态.py`）新增——只加不删，旧接口零改动：**

```python
# 新槽 + 新锁（与六槽并列，第七槽“自我槽”）
self._自我锁 = threading.Lock()
self._自我 = dict(束=None, 束相似=0.0, 最近自言号=0, 计划栈=[], 读数={},
                  身份="AHI", 知不知=[], 更新t=0.0)

def 装意识(self, 自言自语空间, 账本, 身份=None):
    with self._自我锁:
        self.自言自语空间 = 自言自语空间      # 共享引用（同对象）
        self.账本 = 账本
        if 身份 is not None: self._自我["身份"] = getattr(身份, "名字", "AHI")

def 写自我(self, **kw):
    with self._自我锁:
        for k, v in kw.items():
            if k == "计划栈": self._自我["计划栈"] = list(v)
            else: self._自我[k] = v
        if "束" in kw or "读数" in kw: self._自我["更新t"] = time.time()

def 取自我(self) -> dict:
    with self._自我锁:
        d = dict(self._自我)
        d["计划栈"] = list(d["计划栈"]); d["知不知"] = list(d["知不知"]); d["读数"] = dict(d["读数"])
    return d

def 取自言自语流(self, n=20): return self.自言自语空间.自言流(n)   # 考官入口（薄封装）
```

## 3. "想"与"说"的分层（数据结构）

三层，严格单向：**想 → 计划派生 → 说**。想不被直接倒出。

### 3.1 想层（内部，不发声）

直接复用 `自言空间` 的条目结构（`inner_speech.py:36`）：

```python
想条目 = dict(
    号=int, 拍=int, 类型∈("疑问","假设","预测","复盘","计划","自评"),
    文本=str, 触发源=("内生",desc) | ("外部",接收号) | ("工作区",事件),
    引用=[(账本号, 摘录前缀)]        # 强制 ≥1；追加() 不满足即抛 ValueError
)
```

- 存储：`态.自言自语空间.流`（共享，考试时 `自言流(n)` 可查）。
- **可说性标记**：只有 `类型=="计划"`、或 `类型=="疑问"` 且 `触发源==("外部",_)`（用户在场）
  的条目，才**有资格**派生对外表达；其余（自评/复盘/预测/假设）默认**留在内部**。
  这条规则就是"像大模型的思考与正文分离"：思考全量留痕，输出只取计划相关的一支。

### 3.2 计划派生（中间，私有）

```python

### 3.3 说层（对外，表达槽）

## 4. "计划"条目的生成规则

### 4.1 计划栈与目标源

```python
目标 = dict(名=str, 判据=callable(视,动,语,自我)->float, 进度=float, 来源账本号=int)
```

**当前屏通道值**（对应 `综合体._通道值` 的工作区版，纯计数经验，无词表路由）：

```
进度探针（越大越该做）：
  行动通道 = 0.5·(未试元素率) + 0.5·(最近点击平均未命中率)
  认知通道 = 0.5·(未知元素率) + 0.5·(1 - 平均affordance命中)
  用户通道 = 1.0 若表达/听觉有未处理外部事件，否则 0（中断驱动）
```

**计划栈更新（每 `计划周期` 或目标变更时）：**

1. **插入**：用户/外部事件到达 → 目标 `"回应『…』"` 压栈顶，判据 = 证据充分度 ≥ `桥.充分阈值`
   （`synthesis.py:97`）。
2. **达成**：`进度 ≥ 1.0` → 弹栈 + `复盘`（"『X』做完了"）。
3. **停滞**：连续 `停滞拍` 拍 `进度` 未升且 `自我变化率 < 0.02` → 弹栈 + `复盘`（"卡住了，
   换个目标"）+ 按通道值选新目标。
4. **兜底**：栈空且无外部事件 → 目标 = 通道值最大者。

### 4.2 三要素生成（"我这一步要干什么 / 下一步 / 还差什么"）

输入 = 栈顶 `目标` + 当前进度 + 后继候选（次栈顶或通道值次大者）。填充模板（状态量驱动，
**不是词表**——模板里的每一处都由 `自我槽`/账本的实际值填）：

```
计划文本 =
  "我这一步：正在%s——因为%s。" % (动作描述, 差距描述)          # 这一步
  + "做完就%s。" % 后继描述                                      # 下一步
  + "还差%s。" % 差距量化                                        # 还差什么
```

| 目标名 | 动作描述 | 差距描述（来源） | 差距量化 | 后继 |
|---|---|---|---|---|
| 把当前屏探明 | "挨个试没碰过的元素" | 未试元素率 `u/元素数` | "还有 %d 个没碰过" | 试完→"看看学到哪几类功能" |
| 搞懂最陌生元素 | "弄明白『X』" | `1-max(affordance命中)` | "它的点法我还猜不准" | →"回去把整屏功能归并" |
| 回应『…』 | "想清楚这句怎么答" | `1-证据充分度` | "证据还差 %.2f" | 够了→"我把话说清楚" |
| 开放阅读（若接导航器） | "读『文件』里的行" | 未读率 | "还有 %d 行没细读" | 读完→"回头看没嚼透的" |

**写入时机与接口**：

- 块边界（脑器自定 `计划周期`，如每 40 拍≈2s）或目标栈变更时：
  `号 = 核.计划一拍(视,动,语)` → 内部调
  `桥._自言("计划", 计划文本, ("内生","计划: %s" % 目标名), [差距所引账本号, 最新账本号])`。
- **强制引用**：`来源账本号` 取该目标建立时的账本条目（或最近一次进度更新条目），
  保证审计可过（摘录 ⊆ 账本原文）。若无账本（冷启动），先 `账本.append(("自我","建立目标:%s"%名))`
  再引用。

## 5. 可失败判据（S1–S5）

> 每条都写明**如何真的失败**；恒真不算判据。通过线取与 `acceptance.py`（V1/G1/V3/V4）
> 同量级，但**失败通道必须存在**。

### S1 自言活跃且类型非退化（可失败）

- 观测量：运行 `T` 秒后 `len(自言.流)` 与 `自言.类型覆盖()`。
- 通过：`≥60 条` 且 `≥4 类` 且 `计划>0`。
- **如何失败**：把 `脑.核=None`（旧版）跑同样时长 → `自言=0 → FAIL`。判据区分"接了内核/
  没接内核"，不是恒真。

### S2 自言自语真实性（独立审计，可失败）

- 观测量：`直言空间.审计(桥.账本)` → `真实率`、`通过`。
- 通过：`真实率 ≥ 0.95` 且 `通过 == True`。
- **如何失败**：注入一条伪造引用（`引用=[(10**9, "xxx")]`）→ 审计 `违规数≥1、通过=False`；
  或把账本截断重排 → 摘录不符 → FAIL。**反证法自检**：判据实现里必须先造一条坏条目，
  确认能报 FAIL，再对真流审计。

### S3 计划性自指（三要素齐备，可失败）

- 观测量：取最近 `K` 条 `类型=="计划"` 条目，逐条解析三要素。
- 通过：`(这一步 ∧ 下一步 ∧ 还差) 齐备率 ≥ 0.8`，且每条 `这一步` 所引账本号在**该条目拍号之前**
  已存在（时序真实）。
- **如何失败**：退回旧 `_发声` 的状态日志（"眼前 N 件…碰熟 M 个"）→ 无"下一步/还差" →
  齐备率=0 → FAIL。或计划引用未来账本号 → 时序检查 FAIL。

### S4 想/说分离与可溯源（可失败）

- 观测量：说条目列表（嘴台账 `台账.记("嘴",...)` + `核.统计()`），比对 `来源自言号`。
- 通过：`说条目的来源自言号 ∈ 自言流号 的比率 ≥ 0.90`，且 `len(自言.流) ≥ 2 × 说条数`。
- **如何失败**：若"说"=状态日志的 1:1 复述（旧版）→ 无来源自言号 → 溯源率=0 → FAIL；
  若想≈说（比例 <2）→ FAIL。

### S5 自指束实时一致 + 反事实可扰动（最强反作弊）

- 观测 a（一致性）：自我陈述中的每个数值（眼前件数/碰熟数/拍号）与同拍工作区实测一致，
  一致率 `≥0.95`（沿用 `acceptance.数值核对` 口径）。
- 观测 b（反事实）：清空视觉槽（`态.写视觉([], 帧号=n+1)`）后，**下一拍**的自我陈述必须改变
  （不再报旧元素数）；再放入 `N` 个合成元素，自我陈述必须报 `N`。
- 通过：`数值一致率≥0.95` **且** `反事实响应==True`。
- **如何失败**：若自我内容是死记硬背/写死的模板（旧版 `_发声` 就是拿实时数字拼，能过 a 但
  b 的"清空必变"若实现成缓存就会 FAIL）；若自指束/字段没随快照刷新（`快拍` 未接）→ b FAIL。
  这条专门证伪"装样子"。

## 6. 诚实边界（哪些是模拟，哪些做不到）

1. **这是功能性自我，不是现象学体验。** 我们实现的是"可访问意识"层面的自指表征与可审计
   自言自语流；**不声称**任何主观感受（phenomenal experience）。对"你有意识吗"的回答
   只能是账本查证式的功能性自报告（沿用 v10 报告的口径）。
2. **"想"是计数经验 + HDC 规则生成的，不是真的在想。** 自言自语条由状态量→候选类型→
   引擎序号裁决产生，无隐藏的心理内容；所谓"内心世界"完全暴露为可审计字段——这是优点
   （可证伪），也是它的限度（没有不可观察的深度）。
3. **目标不是凭空涌现的。** 计划栈的目标来自预设判据（覆盖缺口/通道值/外部提问），
   AHI **不能创造全新的目标类别**；它只会在既有目标空间里按经验排序、切换、取舍。
4. **自指束能"自省"但不能"自改"。** 束用于变化检测与自我陈述，**不参与决策梯度**
   （本就无梯度）；它不会因为"发现自己错了"而改变底层引擎参数，只能改变目标栈与行为分布。
5. **依赖账本完整性。** 审计的强度 = 账本只追加不被篡改。若账本被截断/重排，S2 的"真实"
   就失去意义；因此账本是本方案的信任根，必须保持只追加。
6. **注入共享载体的前提**：`桥` 一旦构造完，其 `自言/账本` 被换为 `态` 内的同对象；因此
   **不得**再调用 `综合体.载入`（那会重建一份新账本，导致引用错位）。持久化应改为
   "工作区快照 + 账本追加日志"，而非综合体的 `保存/载入`。
7. **慢循环的实时性代价**：`综合体._引擎步` 是重计算，接进 20Hz 快循环不可行；本方案把它
   降到 1–2Hz，因此"想"的时间粒度比"看/动"粗——这是设计取舍，不是缺陷，但需求方须知情。
8. **同步假设环被改写**：原 `综合体.假设环一拍` 假设"预测后立刻读世界结果"，在异步工作区
   不成立，本方案用 §2.6 的异步闭环替代——功能等价，但不再复用该方法本体，回归测试需重写。
```
