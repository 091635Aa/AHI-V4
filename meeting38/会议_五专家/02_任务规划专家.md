# 02 · 任务规划专家 —— 从「乱按」到「有任务、有目的、有进度」

> 身份：目标导向行为 / 任务分解 / 进度研判。
> 纪律：本文**只做设计**，不改任何既有文件。全链路非 Transformer：HDC 双极超向量
> （`共存态.编码器`：字码 / 文本码 / 特征码 / 束 / 绑 / 相似 / 批相似）+ 随机投影

## 0. 诊断：病灶定位（引真代码，不臆测）

### 0.1 出招是抽签
`器官_脑.py::_出招()` 有三处随机（第 165–173 行）：

```python
if 尝 >= 3 and len([h for h, n in self._已试.items() if n == 0]) == 0:
    意图 = dict(..., 滚动=int(self.rng.choice(self.允许滚)), ...)
else:
    键 = str(self.rng.choice(self.允许键))          # ← 乱按来源之二
    意图 = dict(句柄=句柄, 目标点=..., 键=键, ...)
```

- `self.允许键 = ("左","左","左","右","中")`：点哪个键由抽签定，与"想干什么"无关。
- `self.允许滚 = (0,0,0,0,-3,3)`：翻页与否同样抽签。
- `语义.来源` 写死 `"探索"`，没有"任务/步骤"这两个概念。

### 0.2 注意只是"没碰过的更值得碰"
`器官_脑.py::_注意()` 第 137–142 行：

```python
尝 = self._已试.get(e.get("句柄"), 0)
新异 = 1.0 / (1.0 + 尝)                              # ← 无方向的新奇
有字 = 0.15 if 字 else 0.0
分 = 新异 + 有字                                     # ← 与"目的是什么"无关
```

这个打分**平均地**把所有没碰过的元素往外推，属于"无聊探索"，不是"为了弄清某个功能而碰"。

### 0.3 已有的"目的性素材"被闲置
- `语义.py`：`记点击()` 把"点击前→点击后"的世界差分聚成**功能词**（`按钮s[句柄]["功能词"]` "W1/W2…"、
  `词表[i]["码"]` 是该功能词的 HDC 束码）。**这已经是"这按钮是干什么的"**——但脑从没用它来选动作。
- `共存态.意图槽.目标栈`：槽位存在（`写意图(推目标=…)` / `弹目标=True`），**当前无人读写**。
- `meeting35/语义学院.py`：`搜链()`（BFS，深度≤3）+ `预测成败()`（使能前置）已经把
  "新建→键入→保存"这类复合链搜出来了（G4=0.90）。**这套机制没有接到 meeting38 的真机环里。**

**结论：手没问题，脑乱按。缺的是"任务"这一层：任务从哪来、怎么分解成步骤、每步成没成、
还差什么、下一步是什么。** 以下逐条给出。

## 1. 任务从哪来

### 1.1 任务的形式定义

一个**任务**是一张结构体（下文 §4.1 给完整字段），核心是：

```
任务 = {
  id,          类型: "认识按钮" | "查使能" | "达成",
  目标:        谓词 / 功能词,
  步骤s:       [步骤, ...],          # 由 §2 分解得到，长度 ≤ 3
  游标:        int,                  # 下一个未完成步骤的序号
  状态:        "进行中" | "完成" | "失败" | "需重搜" | "放弃",
  证据:        [步骤结算, ...],       # 每步 成/败 + 观测（复盘依据）
  ...
}
```

### 1.2 有指令时如何接收（接口）

人类指令**不解析自然语言**（脑不做 NLU）。指令走结构化入口，落进 `意图槽.目标栈`
（既有槽位，当前闲置）：

```python
# 生命体对外新增（设计接口；槽位复用，不改 共存态）
def 下任务(self, 目标: dict, 类型: str = "达成", 预算s: float = 60.0):
    任务 = 任务规划器.立任务(目标=目标, 类型=类型, 来源="人类", 预算s=预算s)
    self.态.写意图(推目标=任务)          # 压入目标栈，规划器每拍读栈顶
    self.态.排队说("收到任务：%s。我先分解一下要几步。" % 任务规划器.目标白话(目标))
```

- `目标` 是**可判定的谓词**，不是一句话。例：`{"谓词": [("出现","已保存")]}` 表示
  "屏幕上要出现字为『已保存』的元素"；`{"功能词":"W2"}` 表示"把 W2 的使能查清"。
- 嘴可以先复述（`排队说`），但复述文案由 §5 的模板生成，不含编造内容。
- 人类指令的"白话→谓词"翻译**不在本层**（本层不碰 NLU）；`下任务` 收的就是谓词。
  若未来要收白话，也必须是"关键词→键"的查表匹配（计数式），不许引入语言模型。

### 1.3 无指令时如何产生（内生选题）

断供（无人类指令）时的任务源 = **语义缺口**，与 `meeting31/synthesis.py` 的
`_通道值()` 同构（把"哪条通道缺口最大"换成"哪个任务价值最高"）：

| 候选任务 | 触发缺口 | 度量 |
|---|---|---|
| T1 `认识按钮(句柄)` | 该元素 `语义.取按钮(句柄)["功能词"] is None` | 该元素可点、安全（过危词/角区闸） |
| T2 `查使能(功能词W)` | `使能账[W]` 上的不同状态数 < K | 缺口 = `1 - min(状态数/K, 1)` |
| T3 `达成(谓词P)` | 从已学效果模板能搜出 P（§2.3 BFS 命中） | 链越短越优先 |

**选题规则（确定性，无 rng）**——对每个候选算价值，取 argmax：

```python
def 选题(语义, 视, and/or 计划簿):
    候选 = []
    for e in 视["元素s"]:
        if _安全(e) and 语义取按钮(e) is None or 功能词 is None:
            候选.append(T1(e, 价值 = 0.6 + 0.4 * 有字))     # 有字的更像按钮
    for W in 已知功能词:
        if 使能账[W].不同状态数 < K:
            候选.append(T2(W, 价值 = 1.0 - min(状态数/K, 1.0)))
    候选 += [T3(P, 价值 = 0.9 - 0.2*链长) for P in 可达谓词s]
    if not 候选: return None
    return max(候选, key=lambda t: (t.价值, -t.id))          # 平局按 id 升序，不抽签
```

> `_安全(e)`：复用 `脑器.危词` / `脑器.角区`（钱包反射 + 角区回避），保持既有身体级保护。

### 1.4 任务完成/失败后的流转

- 完成 → `任务簿.结案(任务, "完成")`，写证据；从目标栈 `弹目标=True`；选题下一条。
- 失败/放弃 → 同上但 `"失败"`；**该任务 id 进"冷却集"**，避免立刻重选同一个死任务
  （防"顿悟锁死"式的固着，参 `synthesis.py` #258 的教训：内压过强会锁死单一行为）。

## 2. 任务分解（HDC + BFS，深度 ≤ 3）

### 2.1 用于规划的三本账（新增，全部 HDC + 计数）

在 `语义图` 旁边增设（设计为新类 `任务规划器` 内部状态，不改 `语义.py`）：

```python
效果账: dict[功能词, Counter]        # 功能词 → {变化原子: 次数}     （"按下后世界怎么变"）
使能账: dict[功能词, dict[状态键, [成, 试]]]   # 功能词 → 前置条件真凭实据账
键维:   dict[功能词, Counter]        # 功能词 → {("左"|"右"|"中"): 次数}（键也是学出来的）
```

**变化原子**（把一次点击的前后差分离散成可组合的字母表）：

```python
原子 = ("出现", 特征) | ("消失", 特征) | ("字变", 前字, 后字)
特征 = 元素.字 若非空 else 元素.形状         # 只用 OCR 字/形状，名字长相不预设含义
```

- 一次点击的原子集由 `前签↔后签` 差分得到（复用 `器官_脑.py::_句柄签名` 的粒度）：
  句柄新增→`("出现",特征)`；消失→`("消失",特征)`；同句柄字变→`("字变",旧,新)`。
- `效果账[W]` 累加该功能词的原子计数（**这是 §2.3 BFS 的"效果模板"**）。
- **HDC 的使用**：功能词 W 本身已有双极码（`语义.词表[i]["码"]`，由 `编码器.束/绑` 得到）。
  两件事用余弦：①归词（既有 `语义._重聚类`）；②**未见状态的使能回退**——状态键未见时，
  用 `编码器.相似(当前状态码, 已见状态码)` 找最近已见状态（cos≥0.8）继承其使能账，
  与 `语义学院.预测成败()` "完整状态→逐维回溯"同构。
- `状态键` = 前签的整型元组（确定性、可逐位复现）；`状态码` = `编码器.特征码(前签展平)`。

### 2.2 使能预测（计数，非概率模型）

```python
def 使能预测(使能账, W, 状态键, 状态码, 编码) -> float:
    账 = 使能账.get(W, {})
    if 状态键 in 账 and 账[状态键][1] > 0:
        c = 账[状态键]; return (c[0] + 1) / (c[1] + 2)          # 拉普拉斯平滑
    # 未见状态：HDC 余弦找最近已见状态
    码s = list(账.keys()); 若空: return 0.5
    sims = 编码.批相似(状态码, np.stack([状态码s[k] for k in 码s]))
    k = argmax(sims)
    if sims[k] >= 0.8:
        c = 账[码s[k]]; return (c[0] + 1) / (c[1] + 2)
    return 0.5
```

### 2.3 BFS 搜链（迁移自 `语义学院.搜链`，深度 ≤ 3）

```python
def 搜链(起态, 目标谓词, 效果账, 使能账, 编码, 深=3):
    """BFS over 功能词；节点=状态键+历史；边=功能词（前置满足才走）。
       返回 [功能词, ...] 或 None。全程计数经验，无梯度、无抽样。"""
    q = deque([(起态, [])]); 看过 = {起态}
    while q:
        s, 链 = q.popleft()
        if len(链) >= 深: continue
        for W in 效果账:                                   # 已学功能词
            if 使能预测(使能账, W, s, 状态码(s), 编码) <= 0.5:
                continue                                   # 前置不满足：此状态下按了不动
            for 模板 in 效果账[W]:                          # 该功能词见过的原子集
                s2 = 应用模板(s, 模板)                       # 集合算术：加"出现"、减"消失"、换"字变"
                if s2 is None or s2 in 看过 or s2 == s: continue
                看过.add(s2)
                if 满足(s2, 目标谓词):
                    return 链 + [W]
                q.append((s2, 链 + [W]))
    return None
```

- 这条 BFS 就是"新建文档→键入内容→保存"的来源：`[W(新建), W(键入), W(保存)]`，
  深度 3 恰好够（`报告_meeting35` G4=0.90，超深 4 的链如实声明搜不出）。
- `应用模板` 在 meeting35 是 5 维整数向量加法；在 meeting38 真机是**句柄/字集合算术**。
  两者共用同一 BFS 骨架，只换"状态表示"。

### 2.4 步骤 → 手意图 编译

分解出的步骤是"功能词级"的；手的意图是"元素级"的。编译：

```python
def 编译(步, 视, 语义):
    if 步.类型 == "点击":
        元素 = 找实现(步.功能词, 视, 语义)     # 见 §3.1 L2
        if 元素 is None: return None
        return dict(句柄=元素.句柄, 目标点=tuple(元素.心),
                    键=键维.get(步.功能词, "左"),          # 键由计数决定，默认左
                    兜底=tuple(元素.心), 来源="任务",
                    任务id=..., 步骤i=...)                 # 手忽略未知键，安全
    if 步.类型 == "键入":                      # 手已支持 键入 字段
        编辑区 = 找编辑区(视, 语义)             # 见 §7 诚实边界
        if 编辑区 is None: return None
        return dict(句柄=编辑区.句柄, 目标点=tuple(编辑区.心),
                    键入=步.文本, 兜底=tuple(编辑区.心), 来源="任务", ...)
```

> 意图字段与 `器官_手.py::投喂意图` / `_建计划` 完全对齐：
> `{句柄,目标点,键,滚动,键入,拖到,兜底}`；多带的 `任务id/步骤i` 被手忽略。

## 3. 从随机到目的的改造：`_出招()` 怎么改

### 3.1 五级决策级联（**替换 `rng.choice` 的唯一规则**）

```python
def _出招(self, 视, 动, self_意):
    if self._待归因 is not None: return None       # 保留：等上一招结算
    if self._待发意图 is not None: return None     # 保留：不刷屏
    任务 = self.规划.任务簿.栈顶 or self.规划.选题(语义, 视)
    if 任务 is None:                                # 无事可做（L4）
        return self._兜底滚轮(视)
    if 任务.状态 == "需重搜":                        # L3：重规划
        任务.步骤s, 任务.游标 = self.规划.重搜(任务, 视, 语义)
    if 任务.步骤s and 任务.游标 < len(任务.步骤s) and not 步待验(任务):   # L1：执行下一步
        意图 = 编译(任务.步骤s[任务.游标], 视, self.语义)
        if 意图 is None:                             # L2：找不到实现该功能词的元素
            任务.步骤s[任务.游标].尝试数 += 1
            if 任务.步骤s[任务.游标].尝试数 >= 2:
                任务.状态 = "需重搜"                  # 两次不成 → 重搜链/换按钮
            # L2b：用"已学使能关系"挑一个前置满足、且推进当前任务的功能词按钮
            意图 = self.规划.按使能挑(任务, 视, self.语义)
            if 意图 is None: return None
        # —— 到这里才写意图槽 ——
        句柄 = 意图.get("句柄"); 尝 = self._已试.get(句柄, 0)
        self.态.写意图(当前=意图, 来源="任务", 强度=1.0)
        self._待发意图 = 意图
        self._待归因 = dict(句柄=句柄, 键=意图.get("键","滚"),
                            前签=_句柄签名(视["元素s"]), 前元素s=list(视["元素s"]),
                            t=time.time(), 任务id=任务.id, 步骤i=任务.游标,
                            功能词=self.语义.取按钮(句柄).功能词 if ... else None)
        self._记台账("出招[任务%d/步%d] 目标=%s 字=%s 键=%s 尝=%d 因为=%s"
                    % (任务.id, 任务.游标, 句柄, ..., 意图.get("键"), 尝, 任务.理由))
        return 意图
    return None
```

**替换规则一句话**：
> **当前任务的下一个未完成步骤 > 已学使能关系（前置满足且推进任务） > 任务驱动的
> 语义缺口探索 > 任务池选题 > 兜底滚轮；键/滚轮由该功能词的计数决定，无证据默认左键。
> 全程确定性 argmax，平局按句柄字典序，不再 `rng.choice`。**

对照原三处随机：
- `键 = rng.choice(允许键)` → `键 = 键维.get(功能词, "左")`（键是从点击经验里数出来的）。
- `滚动 = rng.choice(允许滚)` → 只在 L4（无事可做）且**当前屏光标区无未认识元素**时，
  按固定序 `(0, 0, 0, 0, -3, 3)` 中"上次制造了新元素"的方向轮换（仍是计数驱动，非抽签）。
- `来源="探索"` → `来源="任务"`，并携带 `任务id/步骤i`，可解释、可复盘。

### 3.2 `_注意()` 让位于任务

`_出招` 不再无条件调用 `_注意`。改造后：

```python
def 找实现(功能词, 视, 语义):
    """若功能词已归词：挑"已学该功能词"的可点元素（可含未见过的同类按钮，靠归词迁移）。"""
    候选 = [e for e in 视["元素s"] if _安全(e) and 语义.取按钮(e) and 功能词匹配]
    if 候选: return max(候选, key=lambda e: (-已试[e.句柄], e.句柄))   # 少试的优先，平局字典序
    """功能词未归词（认识型任务）：直接点在任务里的那个句柄。"""
    return 视.元素(任务.目标句柄)
```

`_注意` 只在 L4 兜底里保留（此刻确实没有任务，只能"找个新东西看看"），
且把它升级为 **"发现新元素即注册 T1 任务"**：`_注意` 挑到未见过元素后，不直接点，
而是返回该句柄给选题器立 T1 任务——**探索从此也是任务**。

### 3.3 保留探索性，但由任务驱动

| 旧行为 | 新行为 | 保留了什么 |
|---|---|---|
| 随机点未碰元素 | T1 任务"认识句柄 H" | 仍会碰新东西，但为了"弄清它是什么" |
| 碰够 3 次后随机滚轮 | L4 兜底滚轮制造新元素 → 注册新 T1 | 仍会翻页，但为了"找新东西可认识" |
| 随机左/右/中键 | 键维计数（右/中键只在某功能词被证实用过该键时出现） | 仍会试右键，但"因为上次右键对这类按钮有效" |
| 无方向新异性打分 | 缺口价值（功能词未知/使能不足） | 新奇偏好变成"信息增益"偏好 |

**探索不再与任务对立，而是任务的一种类型（T1/T2）。**

### 3.4 与既有死锁/看门狗机制的关系（不破坏）

- `_归因` 里的放弃信号、8s 超时看门狗、`_待发意图`/`_待归因` 释放逻辑**原样保留**。
- 任务相关的 `任务id/步骤i` 只**附加**在既有字段上，超时/放弃时同样清理并给任务记一次"败"。
- 规划器是**纯函数式决策**（输入视/语义/任务簿，输出意图），不新起线程、不阻塞，
  符合 `共存态.py` 红线一（只读写共享工作区，且只在脑这一路内被调用）。

## 4. 进度与复盘

### 4.1 数据结构

```python
任务 = {
  "id": int,                     # 单调递增
  "类型": "认识按钮"|"查使能"|"达成",
  "目标": {"句柄":h} | {"功能词":"W2"} | {"谓词":[("出现","已保存")]},
  "步骤s": [步骤, ...],           # ≤3
  "游标": 0,
  "状态": "进行中"|"完成"|"失败"|"需重搜"|"放弃",
  "起t": float, "预算s": float,
  "起始态": 状态键, "起始码": ndarray,
  "理由": str,                   # 为什么选它（供台账/嘴）
  "证据": [ 步骤结算, ... ],
}
步骤 = {
  "类型": "点击"|"键入",
  "功能词": "W1"|None,
  "预期谓词": [原子, ...],        # 本步"应该看到什么"
  "状态": "未做"|"待验"|"成"|"败",
  "尝试数": 0,
  "文本": None,                  # 键入步骤用
}
步骤结算 = {"步": i, "功能词": W, "预期":..., "实观测":..., "成": bool,
            "效果": "大变"/"微变"/"无感", "t": float}
```

### 4.2 更新规则（挂在 `_归因` 尾部）

```python
def 结算步骤(self, 待, 视, 语义):
    后签 = _句柄签名(视["元素s"]); 变化 = self.变化率(待["前签"], 后签)
    实原子 = 差分原子(待["前元素s"], 视["元素s"])
    任务 = self.规划.任务簿.按id(待["任务id"])
    步 = 任务.步骤s[待["步骤i"]]
    成 = 满足原子集(实原子, 步.预期谓词)         # 预期原子是否出现
    步.状态 = "成" if 成 else "败"
    任务.证据.append(dict(步=待["步骤i"], 功能词=步.功能词, 预期=步.预期谓词,
                          实观测=实原子, 成=成, 效果=效果词(变化), t=time.time()))
    # ① 学习（无论成败都学）：效果账 / 使能账 / 键维
    效果账[步.功能词].update(实原子)
    使能账[步.功能词].setdefault(待["前签"], [0,0])[0] += int(成)
    使能账[步.功能词].setdefault(待["前签"], [0,0])[1] += 1
    键维[步.功能词][待["键"]] += 1
    # ② 进度推进
    if 成:
        任务.游标 += 1
        if 任务.游标 >= len(任务.步骤s):
            任务.状态 = "完成"; self.规划.任务簿.结案(任务)
            self.态.排队说("任务完成了——%s。" % 任务白话(任务))
        else:
            self.态.排队说("这一步成了。下一步：%s。" % 步白话(任务.步骤s[任务.游标]))
    else:
        步.尝试数 += 1
        if 步.尝试数 >= 2:
            任务.状态 = "需重搜"                 # 交给 §3.1 L3 重搜
        elif 变化 < 0.05:
            任务.状态 = "需重搜"                 # 完全无感：说明按钮选错了，立刻重搜
```

### 4.3 三个问题的判据（"成没成/还差什么/下一步"）

```python
def 这一步成没成(任务):  return 任务.证据[-1]["成"] if 任务.证据 else None

def 还差什么(任务):
    未满足 = []
    for i in range(任务.游标, len(任务.步骤s)):
        步 = 任务.步骤s[i]
        if 步.状态 != "成":
            未满足.append(步.预期谓词)
    return 未满足                     # 空列表 = 马上完成

def 下一步是什么(任务):
    return 任务.步骤s[任务.游标] if 任务.游标 < len(任务.步骤s) else None
```

### 4.4 重规划与放弃

- `需重搜` → 用**当前**状态重跑 §2.3 BFS（世界变了，旧链可能失效）；
  若搜不出 → `换实现`：同一功能词换另一个已学按钮；再不行 → `失败`。
- 时间超 `预算s` 或失败 → `放弃`，该任务 id 进冷却集；如实说"这个我没做到"。

## 5. 可说出口的计划（供嘴器官朗读）

嘴（`器官_嘴.py`）只消费 `共存态.表达槽`；本层用 `态.排队说(文本)` 投递。
**所有名词都取自真实的结构**（元素.字 / 功能词标签 / 步骤谓词），不生成、不编造。

```python
def 目标白话(目标):       # 只做字段到中文的拼装
    if "句柄" in 目标:   return "把『%s』这个按钮是干什么的弄清楚" % 元素字(目标.句柄)
    if "功能词" in 目标: return "把 %s 这个功能在什么情况下管用查清" % 目标.功能词
    if "谓词" in 目标:   return "让屏幕上%s" % "、".join("出现『%s』"%a[1] for a in 目标.谓词)

def 步白话(步):
    if 步.功能词: return "点一个『%s』类的按钮（我还没见过就试一个）" % 步.功能词
    return "按计划做下一步"
```

**模板表**（触发点 → 例句，全部 k≤2 句、无嵌套）：

| 触发点 | 例句（`%s` 全来自真实字段） |
|---|---|
| 立任务 | "我现在要干的事：%s。先分成 %d 步。" |
| 每步前 | "我这一步要干什么：%s。" |
| 这一步成了 | "这一步成了——%s。下一步：%s。" |
| 这一步没成 | "这一步没成（%s）——%s。" |
| 中途对照 | "还差 %s，我接着来。" |
| 完成 | "任务完成了——%s。" |
| 失败 | "我试了两次都没成，这个先放下。" |
| 无事可做 | "眼前没有要弄明白的东西，我先翻翻看有没有新的。" |

接口：

```python
def 说计划(self, 任务, 视, 时点):     # 由 _出招 在"立任务/发步/结算"三处调用
    文本 = 模板表[时点] % 参数(任务, 视)
    self.态.排队说(文本)
    self._记台账("说计划", 文=文本, 任务=任务.id, 步=任务.游标)
```

口径：**说出口的 = 台账里有的**。任何一句都能在 `任务.证据` / `使能账` / `效果账` 里查到出处。

## 6. 可失败判据（含随机基线对照）

**随机基线（乱按基线）定义**：把 `下一意图` 整体替换为原版随机策略——
`句柄 = rng.choice(可点元素)`、`键 = rng.choice(允许键)`、`滚动 = rng.choice(允许滚)`，
**同种子、同拍数预算、同屏幕**。所有判据都要求"策略指标 ≥ 基线 + Δ"，且用 M 次重复的
均值±标准差做显著性（`Δ ≥ 3σ` 或 Welch t 检验 p<0.01）。基线掉不下来 = 判据失灵，视为不通过。

| # | 判据 | 量化口径 | 门槛 | 随机基线 | 仿真环境 |
|---|---|---|---|---|---|
| **F1** | **任务相关性** | 给定固定任务，`任务命中率 = #{动作的功能词∈任务链} / 总动作数`，N=200 步取均值 | ≥ **0.60** 且 ≥ 基线 + **0.40** | 乱按基线 ≈ 0.06（全屏随机点中链内按钮的比例） | `自检.py` 演练 + 语义学院五维往返 |
| **F2** | **策略稳定性（不抖动）** | 冻结同一屏幕状态+同一任务，连调 `下一意图` 100 次，统计输出意图的**去重数** | 去重数 **== 1**（≤2 允许平局句柄） | 乱按基线去重数 ≥ **3**（近均匀分布） | 纯离线，无需真屏 |
| **F3** | **任务达成率** | 五维世界随机出 M=50 个"深度≤3 可达成"的复合目标，搜链+执行，`达成率 = 成/50` | ≥ **0.60** 且 ≥ 基线 + **0.40** | 乱按基线：同预算下随机按按钮，达成率 ≈ **≤0.15** | `语义学院.py` 世界（可复用其 `搜链` 对照） |
| **F4** | **进度台账一致性（假报率）** | 抽 20 个任务：`假报率 = #{声称完成 但 末尾谓词实为假}/20`；`错放率 = #{声称失败 但 实可达}/20` | 假报率 **== 0**；错放率 ≤ **0.10** | 乱按无任务概念，不产进度——此项基线记为"不可比/N-A"，但其本身即可失败（只要有一次假报即败） | 台账 `生命体台账.jsonl` 复盘 |
| **F5** | **探索不塌缩** | N=500 拍内 `新发现功能词数`（首次归词的按钮数） | ≥ **0.6 ×** 随机探索发现数（防"只做任务、不再看新东西"的另一种锁死） | 随机探索发现数（同 N 同屏） | 演练模式 |

**判据设计要点（防自欺）**：
- F1/F2/F3 是**同一判据的两侧**：策略必须显著高于基线，若把 `_出招` 换回 rng，指标必须
  落回基线附近——**双向都测**，防止"判据把随机也判为通过"。
- F5 是反向约束：防止任务层把探索压死，形成新的固着（参 `synthesis.py` #258 动作熵塌缩实证）。
- F2 反抖动直接对应所有者指控"我看样子像随机逻辑"：同一屏幕同一任务，**输出必须稳定**。

## 7. 诚实边界（哪些做不到、骗不过去）

1. **"达成型"任务依赖使能账与效果账的覆盖**。这两本账是**亲历点击攒出来的**；
   没按过的地方搜不出链（`使能预测 ≤ 0.5` 直接剪枝）。冷启动时只有 T1（认识按钮）可做，
   复合链要等认识完才有。这不是 bug，是"没经历就没得推理"，**不假装能推**。
2. **真机"状态五维"未装**（`报告_meeting35` §四：G6 真机归词"位置留好了"）。
   meeting38 真机的"达成型"退化为**元素谓词满足**（出现/消失某字），状态键=句柄签名，
   遇 OCR 抖动或同名元素会被骗。相对于五维练习册（真值自洽），真机达成率必然更低。
3. **BFS 深度 ≤ 3**。更长的链（新建→键入→键入→保存，深度 4）**搜不出**——
   `报告_meeting35` 已如实声明，本层不掩盖。
4. **"键入"步骤的真机目标识别未做**。§2.4 的 `找编辑区` 目前只能靠"元素形状/已学该功能词
   点击后出现可编辑区"的弱证据；识别不出时该步编译失败 → 走 §3.1 L2 重搜/放弃。
   五维练习册里的"键入"是离散状态转移，不受此限。
5. **无人类指令且屏幕无新元素/功能全认识完** → 任务池空，只能 L4 滚轮空转。
   此时**如实说"没事可做，我翻翻看"**，绝不用随机动作冒充"在做任务"。
6. **骗不过去的一点**：所有判据都带**乱按基线对照**。若声称"有目的"，F1/F2/F3 必须显著
   高于基线；若做不到，"目的性"不成立——这是这套设计能被证伪的地方。
