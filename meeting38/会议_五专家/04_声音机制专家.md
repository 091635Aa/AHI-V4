# 04 · 声音机制专家 —— AHI「嘴」器官：带语气的原声声带输出方案

> 日期：2026-10-05 ｜ 领域：人声物理机制与情感韵律控制 ｜ 红线：禁 Transformer（认知内核与语言生成）、禁神经 TTS 作核心
> 目标：把 `meeting38/器官_嘴.py` 的 Windows SAPI 平板朗读，换成 `meeting32/声带.py` 的**确定性信号处理声门源+谐振器**输出，并让**语气可辨**（好奇/困惑/满意/急躁可听出差异）。
> 纪律：本文件仅为设计与调研，**未改动任何既有文件**。

---

## 0. 一句话结论（先给判断）

项目**已经有一副真声带**（`meeting32/声带.py`，五专家会议 #300 的产物），它做的是
「Rosenberg 声门源 + Klatt 级联谐振器 + 汉语音韵表 + HDC 韵律映射」，**完全合规、确定性逐位一致**。
但当前 AHI 听到的根本不是这副声带的输出——`器官_嘴.py` 走的是 `SAPI.SpVoice` / `pyttsx3`，
而 `声带.py` 自己的 `开外放()/播放()` 也是 `pyttsx3`。**那副真声带的 wav 只落盘、从没被播出来过**。
所以"廉价机器音"的第一根因是**接线错误（播放了 TTS，而不是播放了合成 wav）**，不是声带算法不行。
本方案 = ①把输出改成播放 `合成波形()` 的 wav；②在其上叠一层 HDC 情绪解码驱动韵律；③补齐声调变调/儿化/停顿。

## 1. 声带.py 现状评估（如实）

### 1.1 链路（源码实测）
```
内部状态向量 + 遥测(能量e/新异ñ/消化债/饱足)
  → 韵律() : 四号专家公式族 → 医学参数组 8 项
  → 分位读数(向量) : 意图向量切 K 段 → 秩 q∈[0,1]（ΔF0 微韵律源）
  → 音节帧(文本, 律, qs) : pypinyin(TONE3) → 声母方式/韵母共振峰/四声五度 → 100Hz 三轨帧
  → 合成波形(帧) : Rosenberg 脉冲 + Klatt 二级级联(3 谐振器) + 气声/抖动/段包络
  → 16bit 单声道 PCM wav @ 16kHz（固定 seed → 逐位一致）
```

### 1.2 公开接口（可直接复用，无需改动）
| 接口 | 签名 | 作用 |
|---|---|---|
| 构造 | `声带器官(seed=300, D=1024, 目录=None, 台账路径=None)` | `基线F0 = 110 + 100·U(seed)`，音色底由 seed 定 |
| 映射 | `韵律(遥测: dict) -> dict` | 四遥测 → 8 参数：基频/语速/幅度/气声度/紧喉度/粗糙度/送气量/声区 |
| 微韵律 | `分位读数(向量, K=None) -> np.ndarray` | 向量→q∈[0,1]，驱动 ΔF0（±40Hz 限幅） |
| 帧化 | `音节帧(文本, 律, qs) -> dict` | 文本→帧参数 `{f0,f1,f2,f3,幅,气声,声源,噪带,送气}` |
| 合成 | `合成波形(帧) -> (波形, 元信息)` | 帧→波形；返回 `f0样/峰值/样本数` |
| 主入口 | `发声(向量, 文本, 遥测=None) -> dict` | 全流程；写 wav+台账；返回 `波形/参数/时长秒/实时率/自检/通过` |
| 外放 | `开外放()` / `播放(文本)` | **pyttsx3**（=平板 TTS，本方案要绕开它） |
| 自检 | `台账流(n)` | 发声台账读取 |
| 挂载 | `接综合体(桥, 耳=None)` | 猴补 `桥.步`（meeting38 未用此挂载，走独立线程） |

### 1.3 能力
- **中文音系**：声母 21 个（塞/擦/塞擦/浊，VOT、噪带、送气齐备）；韵母表覆盖单/复/鼻韵母；四声五度轮廓 + 陈述句逐词下滑 + 是非问句尾上扬 ~2 半音。
- **七维医学参数 → 声学**：F0/振幅/气声/紧喉(CQ)/粗糙(jitter)/送气/声区，映射方向符合喉科常识。
- **确定性**：`合成波形` 内 `rng = default_rng(self.seed)` 固定；wav 显式 `<i2` 小端 → 同输入两次逐位一致（S1/D1 可达）。**这是必须保住的性质。**
- **自检齐全**：参数合法性、数轴往返、无 NaN、防咔哒 `数跳变`、实时率、峰值归一。

### 1.4 限制（问题清单，必须直说）
1. **没有把 wav 播出来**：`发声()` 只落盘；`开外放/播放` 用 pyttsx3 念文本。AHI 当前声音 = pyttsx3 = 平板机器音。**根因在此。**
2. **无流式**：`合成波形` 是"整句帧序列 → 整段 Python 逐样本循环"，必须先算完整句才能出音频；无帧块回调、无首包早出声。首字延迟 ≈ 整句合成耗时。
3. **逐样本 Python 循环 = 延迟瓶颈**：`合成波形` 有两个 O(总样本) 的 Python for 循环（相位累积、级联滤波）。16kHz 下一句 3s ≈ 48000 次迭代。会议纪要自称"25–40× 实时"，`probe_声带.py` 的 S6 判据只要求 `实时率 ≤ 0.5`（≥2× 实时）。**长句（60+ 字）会明显变慢，必须实测**；当前无"C++/向量化"加速。
4. **截断**：`音节s[:64]` 硬截断 64 音节；长句会被砍尾。
5. **情感维度贫瘠**：`韵律()` 只有 4 个输入（能量/新异/消化债/饱足），且是"全局单值"，**整句一个情绪**——没有字级/短语级情绪变化，没有"好奇/困惑/满意/急躁"的显式概念。当前 5 情绪两两可分（S8 欧距≥1.0）是**参数空间**可分，不等于**听感**可分亲和。
6. **声调变调缺失**：无三声连读变调（33→23）、无一/不变调、无儿化（`韵母表["er"]` 存在但无儿化合并规则）；停顿只有句末问句处理，逗号/顿号/分号**不插静默**。
7. **音色单一**：单一声门脉冲 + 3 谐振器级联，**无唇辐射、无鼻分支、无 LF 声门流导数、无呼吸/微颤**——即使播出来，音色也会偏"电子/合成"。
8. **`接综合体()` 绕开 work-area**：它读 `桥.e/桥.ñ/...`（对象属性），与 meeting38 的 `共存态` 工作区无关；meeting38 的脑/嘴也不产出这些遥测。

## 2. 情绪 → 韵律映射设计

### 2.1 AHI 的情绪从哪来（三档信息源，按可获得性排序）

**档 A（现状可算，零改动）——从 `共存态` 现有槽**（嘴每拍读最新值，天然并发）：
| 遥测 | 代理量（嘴侧计算） | 物理含义 |
|---|---|---|
| 能量 e | `视["变化率"]` 的 EMA，叠加动作计数增量 | 环境/自身活跃度 |
| 新异 ñ | 句柄集合的 Jaccard 新元素比（嘴维护上一拍句柄集） | 探索新异度 |
| 消化债 债 | 意图槽"当前"存在且手忙的**持续计时**累积（积压未结算） | 行动积压/卡住 |
| 饱足 饱 | 语义槽 `按钮s/词表` 增量的 EMA（学到新功能） | 知识饱足 |

**档 B（推荐，最小新增）——给 `共存态` 加一个独立锁的「情绪槽」**：脑每拍结算归因时写
`写情绪(成功=变化率, 新异=尝倒数, 积压=待归因时长, 饱足=认识类数)`，嘴只读。
这比档 A 的代理量更干净，且仍是"只经工作区耦合、不互相调用"。

**档 C（离线标定，不做核心）**：用 `style_prosody.py` 的 `extract_features` 对
`06_Qwen3TTS外挂` 的中性参考音频做**统计标定**（只取 pitch_std / energy_cv / rate 的**数值**，
不进任何神经推理），拿来给下方锚点定标（见 §6.2）。红线：不得把该管线接入运行时发声路径。

### 2.2 情绪判定：HDC 原型最近邻（禁 softmax，不用 Transformer）

在 4 维归一空间 `(e, ñ, 债̃, 饱)`（`债̃ = tanh(债/300)`，与声带内部一致）定义原型：

| 情绪 | e 能量 | ñ 新异 | 债 消化债(原始) | 债̃ | 饱 饱足 | 语义特征 |
|---|---|---|---|---|---|---|
| 好奇 | 0.65 | 0.85 | 0 | 0.00 | 0.30 | 新东西多、未积压、想试 |
| 困惑 | 0.35 | 0.70 | 300 | 0.76 | 0.50 | 试了很多次、无反馈、积压 |
| 满意 | 0.60 | 0.40 | 0 | 0.00 | 0.80 | 学到新功能、积压释放 |
| 急躁 | 0.90 | 0.80 | 600 | 0.96 | 0.10 | 长时间卡住、积压高、想快 |
| 平静 | 0.50 | 0.50 | 0 | 0.00 | 0.50 | 兜底基线 |

判定：`码 = 态.编码.特征码([e,ñ,债̃,饱])`，与 5 个原型码求余弦 `相似`，取 `argmax`。
若 `max < τ = 3/√D`（与声带同律），兜底「平静」。**平滑**取 top-2：`w1=s1/(s1+s2)`、
`w2=s2/(s1+s2)`（线性归一，**不引入 softmax**），得到混合遥测（避免情绪跳变）。

### 2.3 映射公式（两条路径，皆不改 `声带.py`）

**(A) 纯遥测锚点法（零改动，推荐起点）**：直接把判定得到的 `(e, ñ, 债, 饱)` 喂
`声带.韵律()`，由现成公式自然产生区分度。以 `基线F0=110` 为例：

| 情绪 | ΔF0(Hz) | 语速(音节/s) | 幅度 | 气声度 | 紧喉度 | 粗糙度 | 送气量 | 声区 |
|---|---|---|---|---|---|---|---|---|
| 好奇 | 68.0 | 6.25 | 0.73 | 0.04 | 0.43 | 0.00 | 0.24 | 0.47 |
| 满意 | 52.0 | 5.24 | 0.63 | 0.25 | 0.28 | 0.00 | 0.46 | 0.43 |
| 困惑 | 7.7 | 4.16 | 0.33 | 0.22 | 0.28 | 0.08 | 0.37 | 0.46 |
| 急躁 | 43.1 | 5.38 | 0.56 | 0.00 | 0.56 | 0.12 | 0.15 | 0.41 |

（数值为按 `韵律()` 公式手算，供定标参考；实际以运行值为准。）
可辨要点：**好奇=高起音+快+轻气**；**困惑=低平+慢+带气声+微糙**；**满意=中平+气声大+送气大**；
**急躁=高紧喉+糙+快**。困惑/急躁的语速接近，靠**紧喉(0.28 vs 0.56)+粗糙(0.08 vs 0.12)+F0(7.7 vs 43)** 拉开。

**(B) 韵律增量法（语气更锐利，仍只用 `声带` 公开方法）**：嘴自己调低层三步，
在 `韵律()` 结果上叠一份**情绪增量表**（对 8 参数叠加），再走 `音节帧()`+`合成波形()`：

| 情绪 | Δ基频 | Δ语速 | Δ幅度 | Δ气声 | Δ紧喉 | Δ粗糙 | Δ送气 | Δ声区 |
|---|---|---|---|---|---|---|---|---|
| 好奇 | +25 | +0.6 | +0.05 | −0.05 | 0 | 0 | 0 | +0.10 |
| 困惑 | −15 | −0.8 | −0.05 | +0.15 | −0.10 | +0.10 | +0.15 | 0 |
| 满意 | +5 | −0.3 | 0 | +0.10 | −0.10 | 0 | +0.10 | 0 |
| 急躁 | +40 | +1.0 | +0.10 | −0.10 | +0.25 | +0.15 | −0.10 | +0.15 |

（增量后统一 clamp 回 §1.2 合法区间；`_参数合法` 的区间是唯一准绳。）
(B) 的价值：让"急躁"必带紧喉+抖动、"困惑"必带气声+慢，**不依赖 4 遥测是否恰好区分开**。

**F0 曲线形状（除均值外，注意音高动态）**：
- 好奇：句内 F0 摆幅大（半音 std ↑），句末轻微上扬。
- 困惑：摆幅小、尾字拖长，是非问句式尾上扬仅在真疑问时触发。
- 满意：摆幅中等、句末平收（现成"陈述句下滑"即可）。
- 急躁：基频高 + 抖动大（`粗糙度` 驱动 ±0.5% 抖动）+ 音节间停顿压缩。

**幅度包络**：好奇/急躁 = 起音陡（包络 0.15→1 的爬升段缩短），困惑/满意 = 起音缓（爬升段拉长），
由嘴在帧层对 `帧["幅"]` 的首尾包络做乘性微调（不改 `声带.py`，在自己组合的帧上做）。

## 3. 接入方案：`器官_嘴.py` 从 SAPI 换成声带

### 3.1 保持并发（发声绝不阻塞其他五路）
现状 `嘴器` 已有 `_发声循环` 后台线程 + `_q` 队列——**这正是天然的合成长任务承载点**。
合成（CPU 重）与播放全部留在该子线程；`运行()` 10Hz 轮询只做"取表达槽→入队→记台账"，
**分毫不动**。改动只发生在 `_发声(文本)` 内部。

### 3.2 具体接口调用（伪代码，供后续实现）
```python
# __init__ 内（构造失败静默降级，绝不抛）
try:
    sys.path.insert(0, r"<workspace>/03_AHI\AHI2.1\meeting32")
    from 声带 import 声带器官, FS
    self.带 = 声带器官(seed=3840, D=self.态.编码.D,
                        目录=os.path.join(HERE, "嘴声"),
                        台账路径=os.path.join(HERE, "嘴发声台账.jsonl"))  # 独立台账，不扰生命体台账
except Exception:
    self.带 = None

# _发声(文本) 内替换 SAPI：
def _发声(self, 文本):
    说出 = False
    if self.带 is not None:
        try:
            向量 = self.态.编码.文本码(文本)          # 确定性 HDC 意图向量（无随机）
            遥测 = self._情绪遥测(文本)               # §2.1+§2.2 算得的 (e,ñ,债,饱)
            rec = self.带.发声(向量, 文本, 遥测)      # 合成 + 落 wav + 自检
            self._放wav(rec["wav"])                  # 播合成 wav（非 TTS）
            说出 = True
            self._回流(文本, rec)                    # 回流含 参数/时长/情绪，供眼/脑感知
        except Exception:
            说出 = False
    if not 说出:
        print(f"[嘴] {文本}")                         # 降级：纯文本+台账，**不回退 SAPI**
    self._回流(文本, None)
```

播放实现取一即可（都在**发声子线程**内同步，故顺序播放、不阻塞他路）：
- `winsound.PlaySound(path, SND_FILENAME)`（Windows 最稳，同步阻塞）；
- 或 `sounddevice`：`sd.play(rec["波形"], FS); sd.wait()`（耳已在用 sd，依赖已在）。

### 3.3 降级路径（**降级也不许回退到平板 SAPI 当主路径**）
| 层级 | 条件 | 行为 |
|---|---|---|
| L0 主路径 | `声带` 可用 + 声卡可用 | 合成 wav → 播放 |
| L1 | `声带` 可用 + 播放失败（无声卡） | **仍合成并存 wav**，打印路径 + 台账（声音不丢，只是不放） |
| L2 | `声带` 导入/合成异常 | 纯文本打印 + 台账；**不发 SAPI** |
| L3 应急（默认关） | 显式 `允许应急平板=True` 且 `声带` 全挂 | 才允许 SAPI，且**必须写台账标注"应急平板"**，默认永不启用 |

即：SAPI 从"主路径"降为"必须显式开启的应急兜底"，与红线一致、可代码审计。

### 3.4 不扰既有判据
- 声带**独立台账文件**（§3.2 的 `嘴发声台账.jsonl`），不写进 `生命体台账.jsonl` → 不破坏 V5 重放/`自检 A6/A7`。
- `嘴器` 仍只读 `共存态`，不新增对 `脑/手` 的调用；情绪遥测读取全部走现有槽位加锁读（`取视觉/取动作/取语义/取意图`），符合"只经工作区耦合"。
- 若采纳档 B「情绪槽」，用独立 `_情绪锁`（仿现有槽实现）→ 单路写不阻塞他路读。

## 4. 中文自然度方案

### 4.1 已有（`声带.py` 现状，保留）
声母方式/部位、韵母共振峰目标、鼻尾滑移、四声五度轮廓、陈述句下滑、是非问句尾上扬、轻声(调5)短化、声区间 F0 上移。

### 4.2 需补（在嘴侧或后续 `声带` 迭代；本文件只设计）
1. **三声连读变调**：连续上声 `3+3 → 2+3`（前字五度由 214 改为 35，帧目标 F0 单调升、末值高）；
   三连上声按语法分组：`(3+3)+3 → 2+2+3` 或 `3+(3+3) → 2+3+3`（先用"右向分组"默认）。
   实现点：在 `音节帧` 之前对 pinyin 串做前处理，把前字 `调3` 改 `调2` 轮廓。
2. **一/不变调**：`一` 在 4 声前读 yí(2)、在 1/2/3 声前读 yì(4)、序数/单念读 yī(1)；
   `不` 在 4 声前读 bú(2)。同理由嘴侧 pinyin 前处理完成。
3. **儿化**：识别词尾 `儿`（非独立音节）→ 与前字韵母合并，音节数 −1；
   加映射 `a/o/e/u → 卷舌`、`i/n → 卷舌`（共振峰 F3 下滑 + 卷舌档）；`韵母表` 已有 `er` 基座可复用。
4. **停顿与句读**：按标点插入 `声源=−1` 静默帧——`、` ≈ 80ms；`,` ≈ 150ms；`：` ≈ 180ms；
   `。！？` ≈ 300ms；`……` ≈ 350ms。感叹句：幅度 +、F0 摆幅 +。疑问句：保留现成尾上扬。
   实现点：嘴侧在帧序列里插静默帧段（`声源=-1`，`合成波形` 已支持静默分支）。
5. **协同发音**：现仅"下滑"，可加 50% 交叉淡化（相邻音节边界 F1/F2 线性过渡），减少"一顿一顿"。

### 4.3 可测量的自然度判据
| 维度 | 判据 | 门槛 |
|---|---|---|
| 声调准确 | 自相关测 F0 与该音节目标轮廓误差 | < 5%（复用 probe D1） |
| 变调正确 | 标注语料 `你好+你好`、`我很好` 等：前字 F0 轮廓呈 2 声(升)占比 | ≥ 95% |
| 停顿正确 | 逗号/句号处出现 `声源=−1` 静默段的比例 | ≥ 90%，且时长误差 < 60ms |
| 儿化合并 | 含"儿"词音节数 = 原−1 | ≥ 95% |
| 元音可懂 | 稳态段谱峰落在 F1±20% | 100%（复用 probe D2） |
| 连续自然 | 相邻音节边界最大跳变（`数跳变`）= 0 | 0 次真咔哒 |

## 5. 可失败判据（先定后测，能真失败）

> 所有判据须能在"映射退化/接错线/超时"时**真的 FAIL**，且给出量化门槛。

### E1 · 情绪可辨性（核心）
同一句话（如"这个按钮我点了一下"）以 **好奇/困惑/满意/急躁** 各合成 3 次，提取 4 维特征：
`F0均值(Hz)`、`F0半音std`、`时长(s)`、`能量CV`。
- **门槛 a**：四情绪两两 `|ΔF0均值| ≥ 8 Hz`；
- **门槛 b**：两两 `|ΔF0半音std| ≥ 0.5 半音`；
- **门槛 c**：两两 `|Δ时长|/基线时长 ≥ 0.08` 或 `|Δ能量CV| ≥ 0.10`（时长/动态至少一轴可分）；
- **门槛 d**：4 维特征 z-归一后，两两欧距最小值 `≥ 0.6`；Fisher 判别比 `≥ 2.0`；
- **门槛 e**：同情绪 3 次重复，F0均值的组内 std `< 1.0 Hz`（可复现）。
- **FAIL 条件**：任一门槛不满足 → 情绪映射退化，判失败。（例：若把四情绪都锚到同一遥测点，E1 必 FAIL。）

### N1 · 非 TTS 检测（可代码审计）
扫描运行时发声路径（`器官_嘴.py` + 其 `import 声带` 的调用）：
- **禁止出现在主路径**：`win32com` / `SAPI.SpVoice` / `pyttsx3` / `transformers` / `torch` / `.softmax(` / `Attention` / 加载 `.pt/.onnx/.gguf` 的推理。
- 允许：`numpy`、`pypinyin`、`wave`、`winsound`/`sounddevice`（纯播放）、`声带.py`（纯 DSP）。
- **门槛**：命中禁式数 = 0（tokenize 剥离注释/字符串后扫代码结构，复用 `自检.py::A6` 口径）。
- **FAIL 条件**：主路径出现任一禁式（尤其 `self._sapi.Speak` 仍主用 / 调用 `声带.开外放()` / `声带.播放()`）→ FAIL。
  （注意：`声带.py` 自身的 `开外放/播放` 含 pyttsx3，属"未接线"死代码，判据要求**发声路径不得调用它们**。）

### R1 · 实时性 + 不阻塞
- **门槛 a**：≤12 字句子 `合成耗时 ≤ 300 ms`（或等价 `实时率 ≤ 0.5`，复用 probe S6）；
- **门槛 b**：嘴连续发声期间，`共存态.取度量()["最长写ms"] ≤ 20 ms`（工作区写延迟不劣化）；
- **门槛 c**：嘴发声期间 `脑.思维拍` 持续增长、`运行()` 轮询拍频 `≥ 8 Hz`；
- **FAIL 条件**：任一不满足 → FAIL。（首字延迟超阈、或合成卡住工作区锁，都会 FAIL。）

### D1 · 确定性（必须保持）
- 同 `(seed, 向量, 文本, 遥测)` 两次合成：`np.array_equal(波形1, 波形2)` 为真，且 wav 文件字节一致。
- **FAIL 条件**：出现任何随时间/随机变化的样本（如误用 `seed=-1`、或情绪层引入未固定随机）→ FAIL。

### C1 · 并发不阻塞（架构铁证）
- 预置队列塞满 6 句长文本，同时手执行 1 次动作（`演练=True`）：
  - `手状态=移动中` 的采样点上，`说数` 递增（嘴在说）；`脑.思维拍` 递增（脑在想）；
  - 无死锁、`运行()` 线程存活。
- **FAIL 条件**：嘴的合成/播放把 `运行()` 或 `脑.循环` 卡住（说数在"手忙"期间不增）→ FAIL。

> 判据条数：**5 条**（E1/N1/R1/D1/C1），均为可失败、可量化的自动化项。
> 人耳盲测（4 情绪 × N 句，两位听者认同率 ≥ 75%）作为 **补充验收**，不计入自动判据（主观）。

## 6. 诚实边界

### 6.1 声带.py 现在听起来像不像人？——**不像**
如实说：它是一台 **1980 年代 Klatt 风格的共振峰合成器**，不是真人嗓子。原因：
- 声门源只有**单一 Rosenberg 脉冲**，缺 LF/声门流导数模型 → 缺少自然的"声门泄漏/谱倾斜"，谐波偏硬；
- 声道只有 **3 个二阶谐振器级联**，**无唇辐射、无鼻分支、无声道长度/性别差异**；
- 噪声是白噪+一阶差分高通，**不是处理过的气声/摩擦噪声**；无呼吸音、无微颤(vibrato)、无 shimmer。

**预期听感**：字正腔圆、四声可懂，但**音色偏"电子/机器人/老式合成器"**；
它**能承载可辨的语气**（因为语气=韵律，韵律是它的强项），但**音质谈不上"像真人"**。
所以本方案能解决"听得出来是廉价 SAPI + 没有语气"的**一半**（换成有语气的合规合成），
**不能**直接解决"像真人嗓音"。这是 DSP 路线的诚实上限。

### 6.2 在"禁 Transformer"下，ROC / 音色克隆能不能用？
- **标准 RVC 不能作核心**：其内容编码器是 HuBERT/ContentVec（Transformer），违反红线；
  且它本质是"神经声码器(Vocoder)+神经编解码"，属"神经 TTS/声音克隆"范畴 → **不得接入运行时发声路径**。
- **合规用法（唯一）**：把 `06_Qwen3TTS外挂` / 参考真人录音**当离线"韵律标尺"**——
  用 `style_prosody.extract_features` 提取目标 `pitch_std / energy_cv / rate_idx` 的**统计数值**，
  反向标定 §2.3 的情绪锚点与增量表，使 DSP 输出的**韵律统计**逼近真人。
  **只搬数字，不搬模型、不搬音频**；运行时零神经推理。这是不违红线又能"更像人一点"的路。
- **"更像真人"的合规正道**是升级 DSP 本身（不换架构）：
  LF 声门模型替代 Rosenberg；加唇辐射 `+6dB/oct`；多带噪声/气声整形；
  加鼻化分支与联合调音（鼻韵母）；微颤+shimmer；共振峰带宽按性别重标。
  这些都能在 `声带.py` 的框架内确定性实现，且完全不碰 Transformer。

### 6.3 本方案的能力边界（一句话）
**能**：把平板 SAPI 换成合规、确定性、带四情绪语气的原声声带输出，并量化证明可辨与不阻塞。
**不能**：一步到位做出"以假乱真的真人嗓音"——那需要 LF 声门模型等 DSP 升级，或（被红线禁止的）神经 TTS。
