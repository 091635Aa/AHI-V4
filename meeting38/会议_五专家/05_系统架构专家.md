**铁律（本方案的不可违反项）**：
1. **禁 Transformer**：全链路不得出现 attention/QKV/softmax/自注意力/位置编码/nn.Linear/transformers/梯度。已实测：`inner_speech/synthesis/selflearn(meeting30)/gen_lm(meeting28)/声带(meeting32)` 源码在 tokenize 剥注释后**均无禁用结构**（我用 A6 同款禁式扫过）。
2. **器官不互调、不互等**：任何器官只经 `共存态` 读写耦合，禁止 `import` 另一器官、禁止 `join`、禁止 `call`。
3. **保护既有验收**：A1–A7 与 W1–W6 的**阈值与判定不得改**；新接入必须"不退化"，必要时用可关开关。

## 1. 总装图（想-说-做 合一）

### 1.1 一句话总装

> 新增**一个"自我线程"（第 7 路，`器官_我.py`）**运行未接的自我意识内核（`inner_speech`+`synthesis`），
> 它把"想法"写进新增的**自我槽/计划槽**；**脑退化为"计划落地器"**：读计划槽 → 同一份计划**既写意图槽（做）又写表达槽（说）**；
> 手的执行结果经新增**事件槽**回流给自我线程做复盘；嘴保留原有契约，仅把发声后端换成 `声带.py`（跑在已有的发声子线程里）。

### 1.2 分层与数据流（文字版）

```
                        ┌─────────────────── 自我意识内核层（◆新，独立线程「自我」）───────────────────┐
                        │  synthesis.综合体(seed, 私偏κ) + inner_speech.自言空间                        │
                        │  · 唯一消费者 ◆事件槽：抽事件→入内核账本→断供一拍()                           │
                        │  · 读：视觉槽/语义槽/动作槽（只读快照）                                      │
                        │  · 写：◆自我槽（提案/遥测/自言摘要/六类覆盖/审计/向量/自体拍）               │
                        │  六类自言：疑问·假设·预测·复盘·计划·自评  ← 全部带账本引用（可审计）        │
                        └───────────────▲──────────────────────────────┬───────────────────────────────┘
                        ◆事件槽(有界256) │ 多生产者→单消费者              │ ◆自我槽(单写者=自我线程)
                                        │                                │ 最新值
   ┌──────────────┐   ┌─────────────────┴──────────────┐   ┌────────────▼──────────────────────┐
   │ 眼 器官_眼.py │   │  脑 器官_脑.py（改：计划落地器）  │   │ 嘴 器官_嘴.py（改：可换声带后端）  │
   │ 耳 器官_耳.py │   │  读：视觉/听觉/动作/语义          │   │  读：表达槽(+自我槽取向量/遥测)     │
   │ 手 器官_手.py │──►│      + ◆自我槽.提案 + ◆计划槽     │──►│  发声子线程 → 声带器官.发声(向量,    │
   │ 语义 语义.py  │   │  写：意图槽(做) / 表达槽(说)      │   │        文本, 遥测) 失败→SAPI 回退   │
   └──────┬───────┘   │      + ◆计划槽(当前/待办/已办/对账)│   └───────────────────────────────────┘
          │           │      + ◆事件槽(出招/归因/完成/放弃)│
          │           └────────────────────────────────────┘
          │  眼→视觉槽   耳→听觉槽   手→动作槽   语义→语义槽  （既有六槽契约不变）
          └─────────────────────► 共存态（唯一真相源，每槽独立锁）◄──────────────────────┘
```

**关键点**：`◆自我槽/◆事件槽/◆计划槽` 是**新增槽**，既有六槽的**语义、字段、读写方全不改**。

### 1.3 一次"点击"的完整生命周期（想→说→做→复盘）

```
T0  自我线程：drain 事件槽 → 内核账本追加(类型,文本) → 综合体.断供一拍()
             → 生成「计划」自言（含账本引用）→ 已在写 ◆自我槽.提案 + 自言摘要
T1  脑（50ms 拍）：读 ◆自我槽.提案（如"验证/探索某功能词"）→ 在视觉/语义里选定句柄
             → 组装 ◆计划槽.当前 = {步骤号,类型,句柄,目标点,键,理由,预期,自语号,版本}
T2  脑：把 ◆计划槽.当前 的**可执行字段子集**原样写 意图槽.当前（做）
             → 同源生成一句「我想着：这一步点『X』，因为……；点完预期……；接下来还要……」写 表达槽（说）
             → 投事件槽 {类=出招,目标=X,理由,自语号}
T3  手：读意图槽.当前（版本判重）→ 60Hz 连续轨迹执行 → 途中读视觉槽纠偏 → 动作槽写句柄/进度
T4  手完成：写动作槽 反馈=结果、动作计数+1
T5  脑._归因：比较点击前后元素流 → 语义.记点击（学 affordance）
             → 投事件槽 {类=归因,目标=X,效果=大变/微变/无感} → 更新 ◆计划槽.已办/说做对账
T6  嘴：表达槽取句 → 发声子线程 → 声带.发声 合成 wav（遥测来自 ◆自我槽）
T7  自我线程（下一拍）：从事件槽读到 T2/T5 事件 → 账本记「检验」
             → 综合体 复盘：预测 vs 实际 → 「复盘/预测」自言 + 更新提案  → 回到 T1
```

**"合一"的架构机制**：**单一计划源** —— 说（表达槽）与做（意图槽）都从 `◆计划槽.当前` 派生，
所以"说什么"和"做什么"在设计上就不可能分叉；一致性不是靠自觉，而是靠数据流。

### 1.4 用户四条诉求 → 本方案的落点

| 用户原话 | 落点 |
|---|---|
| "他说话，应该说我想着…我这一步要干什么？我还要干什么？" | 脑 `_说计划`：从 `◆计划槽.当前`+`待办` 生成"当前步/原因/预期/下一步"，写表达槽；自语号取自 `inner_speech`，可审计 |
| "鼠标操作要有目的性…平时乱晃乱按" | 脑不再随机挑：`◆自我槽.提案` 决定目标功能/目的；提案缺失才回退旧的新异探索（保底） |
| "自我意识体也没成功激活" | `◆自我槽` 暴露 `inner_speech` 六类自言 + `审计.真实率`；A10 判据证明被真正激活 |
| "TTS 和中文是原声声带输出" | 嘴的发声子线程接 `声带器官.发声`（真声带 wav）；A11 判据溯源 |

## 2. 接口契约

### 2.1 不得破坏的既有契约（红线）

- **六槽语义不变**：视觉(眼写)、听觉(耳写)、意图(脑写/手读)、动作(手写)、表达(脑写/嘴读)、语义(语义层写)。
- **手意图格式不变**：`{句柄, 目标点, 键, 滚动, 键入, 拖到, 兜底}`；`手._看意图起手` 靠 `意图槽.版本` 判重——**脑必须让版本自增**（沿用 `态.写意图`）。
- **表达槽既有方法行为不变**：`排队说(文本)` 仍可只传文本；`取下一句()` 仍返回 `(t, 文)` 或 `None`。
- **台账接口不变**：`.记(类:str, **rec)`、`.n`。
- **A1–A7 / W1–W6 的阈值与判定不变**。

### 2.2 新增槽（只在 `共存态.py` 内**追加**，不改既有行）

#### ① ◆自我槽（单写者=自我线程；读者=脑/嘴/自检）
```python
# 字段（快照 dict）
自我 = dict(
    提案=None,        # 内核抽象提议: dict(意图标签, 理由, 预期, 优先级, 自语号, 拍)
    遥测={},          # {能量, 新异, 消化债, 饱足, 行为熵}  ← 声带韵律输入
    向量=None,        # 当前自体 HDC 向量(np.float32[D])   ← 声带分位读数输入
    自言摘要=[],      # 最近 N 条: dict(号,类型,文本,拍,触发源,引用)
    类型覆盖={},      # {疑问:n,假设:n,预测:n,复盘:n,计划:n,自评:n}
    审计={},          # inner_speech.审计 结果: {真实率,违规数,条目}
    自体拍=0, 更新t=0.0)
```
```python
def 写自我(self, 提案=None, 遥测=None, 向量=None, 自言摘要=None,
           类型覆盖=None, 审计=None, 自体拍=None) -> None   # 独立 _自我锁，O(1)
def 取自我(self) -> dict                                   # 深拷贝级快照，锁内无计算
```

#### ② ◆事件槽（多生产者=脑/手/语义；单消费者=自我线程）
```python
# 事件 schema
事件 = dict(类="出招"|"归因"|"完成"|"放弃"|"观察"|"纠偏"|"听"|"说",
            t=秒, 目标=句柄|None, 键=None, 效果=None, 理由=None, 自语号=None, 文本=None)
```
```python
def 投事件(self, 事件: dict) -> None          # deque(maxlen=256)，满则丢最旧，O(1)，独立 _事件锁
def 取事件(self, 上限: int = 64) -> list      # 一次取走并清空；只此消费者，避免重复入账
```

#### ③ ◆计划槽（单写者=脑；读者=嘴(经表达槽)/自检/手(仅可读句柄)）
```python
计划 = dict(
    当前=None,   # dict(步骤号,类型,句柄,目标点,键,滚动,拖到,兜底,理由,预期,自语号,版本,t)
    待办=[],     # ["接下来还要干什么" 的步骤列表]
    已办=[],     # 已执行步骤 + 结果(效果/纠偏数)
    说做对账={}, # {说数, 落地数, 匹配数, 匹配率}
    版本=0)
```
```python
def 写计划(self, 当前=None, 待办=None, 已办=None, 说做对账=None) -> None  # 独立 _计划锁
def 取计划(self) -> dict
def 推待办(self, 步骤: dict) -> None
def 取待办(self) -> dict | None      # 取最前一条（不弹出；落地后由脑移入已办）
```

> **写锁纪律**（照抄既有风格）：新槽各配一把独立 `threading.Lock`；`get` 只拷贝、`set` 只赋值；
> 锁内**不做计算、不调用他模块**；所有新方法 O(1)、无 IO。

### 2.3 新增/修改模块与公开签名

#### (A) 新增 `meeting38/器官_我.py` —— 自我线程（第 7 路）
```python
class 自体器:
    def __init__(self, 态, 台账=None, 种子: int = 310, 周期: float = 0.8,
                 世界seed: int = 77, 提案器=None):
        # 内部：综合体(seed=种子) + 设世界(隐藏世界(seed=世界seed)) + 内核账本 list[(类型,文本)]
        # 提案器=None → 用默认 _形成提案；规划专家可注入（见 (D)）
    def 一拍(self) -> None:
        # 1) 抽 ◆事件槽 → 内核账本.append((类映射,文本))
        # 2) 综合体.断供一拍()   ← 唯一调用点，在本线程内，同步
        # 3) 读视觉/语义/动作快照 → _形成提案()
        # 4) 写 ◆自我槽(提案, 遥测, 向量, 自言摘要, 类型覆盖, 审计, 自体拍)
    def _形成提案(self, 视, 语, 动) -> dict | None    # (D) 可插拔
    def _摘要(self) -> dict                            # 自言摘要/类型覆盖/审计(账本)
    def 运行(self, to_stop: threading.Event) -> None   # 独立循环；全程 try/except 吞异常
    def 统计(self) -> dict
```
**纪律**：`自体器` 只被 `生命体` 起线程；**任何器官都不 import 它、不持有它**。
它是 `inner_speech.追加` 与 `综合体.*` 的**唯一调用者**（单写者原则）。

**开关语义**：`用自我=False` / `用声带=False` 时，生命体行为与当前**逐位等价**（旧路径回归基线）。

## 3. 并发安全（接入三个同步阻塞旧内核）

### 3.1 三内核的"阻塞画像"（决定接线方式）

| 内核 | 调用代价 | 结论 |
|---|---|---|
| `inner_speech.追加` | 纯内存 append + 校验，微秒级 | 可留在自我线程内直接调；仍保持**单写者**（只自我线程） |
| `综合体.断供一拍` | 重：引擎步进/检索，开放域还可能读盘 | **必须专属线程**（自我线程）；绝不进脑的 50ms 拍 |
| `声带器官.发声` | 重：O(样本) 逐样本循环，实时率≤0.5，长句可达秒级 | **必须在嘴的发声子线程**；绝不进脑/脑循环/嘴.运行 |

### 3.2 四条硬规则

1. **专属线程原则**：每个同步阻塞内核只在其专属线程被调用——
   `综合体/自言.追加` → 自我线程；`声带.发声` → 嘴的 `_发声循环` 子线程。
2. **单写者原则**：每个槽只有一个写者（自我槽=自我线程；计划槽=脑；表达槽=脑；意图槽=脑）。
   事件槽是唯一多生产者，用 `deque(maxlen=256)` + 独立锁，`投事件` O(1) 满则丢最旧（**永不阻塞写方**）。
3. **有界 + 降级**：事件槽有界；嘴队列已有 `maxsize=128`；声带 FIFO 已有上限 32。
   任何内核异常一律 `try/except` 吞掉并降级（声带失败→SAPI；提案缺失→旧探索；内核挂→自我槽空转）。
4. **不 join、不互调**：自我线程不被任何器官等待；生命体停机时统一 `到点.set()`，各路自行退出。

### 3.3 不破坏 A1/W1 的论证

- A1 锤击的是六槽 get/set；新增三槽**独立锁**，与六槽无交叉 → 不可能引入死锁。
- 新增槽方法 O(1) 且锁内无计算 → 不抬高 `最长写ms`。
- 脑的思维拍只多做 **O(1) 槽读写 + 字符串拼接**；重活（内核/声带）都在别的线程 → **W1 脑不阻塞率不受影响**。
- 手的 60Hz 循环、眼的 6Hz、耳的 50ms、语义 0.3s **一行不改**。

## 4. 自检扩展（A8–A13：证明"想-说-做一致"）

在既有 A1–A7 之上追加，**不改动 A1–A7 本身**。

| 判据 | 定义 | 门槛 | 证明 |
|---|---|---|---|
| **A8 计划单一源一致** | 跑 N 拍逐拍比 `◆计划槽.当前` 与 `意图槽.当前` 的可执行字段子集（句柄/目标点/键/滚动/拖到）；一致率=相等拍/N；并检 `自语号 ∈ 自言流.号` 比例 | 一致率 ≥ 0.95 且 溯源率 ≥ 0.90 | "做"确实来自计划，不是另起炉灶 |
| **A9 说做匹配率** | 抓每条带 `目标句柄`+`自语号` 的表达句，在随后一个动作生命周期内匹配 `动作槽.句柄`（或 `◆计划槽.已办.目标`） | ≥ 0.90 | 说出的目标 == 手实际去做的目标（说→做） |
| **A10 自言可审计+六类覆盖** | `inner_speech.审计(内核账本)`: 真实率、违规数；`类型覆盖` | 真实率 == 1.0（0 违规）且六类各 ≥ 1 | 自我意识内核真被激活，不是假装说话 |
| **A11 声带溯源与合规** | 取最近 1 条发声台账：文本 == `表达槽.最近`；wav 存在；`自检.参数合法 ∧ 数轴往返==1.0 ∧ 无NaN ∧ 跳变==0 ∧ 实时率≤0.5` | 全部为真 | 真声带输出且合 meeting32 S 系列 |
| **A12 并发不退化守门** | 接入新件后**原样重跑** A1（4读2写锤击）与生命体 W1 | A1 过（无死锁、最长写<50ms）∧ W1 过（脑不阻塞率≥0.8、全线存活） | 新接入没把已验证并发架构搞坏（**我的核心职责**） |
| **A13 非Transformer 扩面审计** | A6 扫描根扩到所有新 import 的源码：`meeting38` + `meeting31/inner_speech,synthesis` + `meeting30/selflearn` + `meeting28/gen_lm` + `meeting32/声带`；禁式不变 | 0 命中 | 接入内核/声带后全链路仍非 Transformer |

**判据口径纪律**：A8/A9 在 `演练=True` 下可用 `动作槽.句柄/计划槽` 作代理（静态界面样本少时须注明样本量）；
A12/A13 必须每次回归都跑，作为"防退化闸门"。

## 5. 落地顺序（6 步，每步独立可验收）

> 原则：**不许一次性大爆炸**；每步结束都能单独跑一段自检 + 一次 `生命体(演练=True)` 采样。

**步 0 · 基线冻结（不改码）**
- 动作：跑 `自检.py`（A1–A7）、跑 `生命体(演练=True, 时长≈120s)`。
- 验收：记录 A1–A7 全过、W1–W6 结果快照，作为回归基线。

**步 1 · 扩槽（只动 `共存态.py`，纯追加）**
- 动作：加 ◆自我/◆事件/◆计划 三槽与 §2.2 方法（独立锁、O(1)）。
- 验收：A1 仍过；对三新槽做 4读2写锤击无死锁且最长写<50ms；生命体演练 W1–W6 与步 0 一致（新槽无人读写→行为不该变）。

**步 2 · 自我线程接入（不碰脑逻辑、不加声带）**
- 动作：新增 `器官_我.py`；`生命体` 起第 7 路 `用自我=True`。自我线程只写自我槽/读事件槽；脑**暂不读**提案。
- 验收：**A10 过**（自言六类覆盖 + 审计真实率 1.0）；A1/A6 仍过；W1 仍过。

**步 3 · 脑接计划（想-说-做闭环成形）**
- 动作：脑 `_出招/_说计划/_归因` 改造，读提案写计划槽（保底回退保留）。
- 验收：**A8 过**、**A9 过**、A4 仍过；生命体 W1–W6 不退化（验证回退网：临时置空提案仍出招）。

**步 4 · 声带接入嘴（声音机制专家主导）**
- 动作：`声带器官` 实例由 `生命体` 建；`嘴器(声带=...)`；跑在发声子线程。
- 验收：**A11 过**；A1/W1 不退化；`用声带=False` 时行为同步 3（向后兼容）。

**步 5 · 审计扩面 + 全量回归**

- 验收：**A13 过**、A12 过；全项通过。实机（`演练=False`）需所有者知情，先演练后实机。

## 6. 风险清单（最可能把已验证架构搞坏的三处）

**R1 · 把阻塞内核塞进脑线程（最致命）**
症状：脑 50ms 拍被 `断供一拍`/`声带.发声` 拖到数百 ms~秒 → W1"脑不阻塞率"崩、A4 崩、手也像被拖住。
规避：三内核**一律专属线程**（§3.2 规则 1）；脑只做 O(1) 槽读写 + 字符串；声带只在嘴的发声子线程；
时序回归闸门 A12/W1。

**R2 · 双写同一槽 / 双写账本（最隐蔽）**
症状：脑与自我线程都写"计划"或都调 `inner_speech.追加` → 竞争脏读、自言字号错位、审计真实率<1.0。
规避：**每槽单写者**（自我槽=自我线程；计划槽=脑；事件槽=多生产者单消费者+有界）；
`inner_speech.追加` 与 `综合体.*` **唯一调用者=自我线程**；脑绝不写自我槽。
用 A8 溯源率 + A10 审计做守门。

**R3 · 脑硬依赖内核，内核一异常就停摆**
症状：内核未启/抛异常 → 脑不再出招 → 既有 W2/W4 与 A1–A7 连带失效。
规避：`_出招` **保底回退**到现有新异探索；所有内核/声带调用 `try/except` 吞掉并降级；
`用自我=False`/`用声带=False` 与旧路径**逐位等价**；步 1–步 5 每步都跑 W1–W6 回归。

**附 R4 · 声带参数接线错位（接口级坑，提前点出）**
`声带.接综合体` 里取 `getattr(桥, "编码")`，而 `synthesis.综合体` 的属性名是 **`codec`** → 会取到 `None` 而走随机向量兜底。
本方案**不走 `接综合体` 包步法**（那会侵入 `桥.步` 且与器官并发无关），改为：自体器把**编码向量**写进 `◆自我槽.向量`，
嘴从自我槽取 `向量` 与 `遥测` 喂 `声带.发声`。声音机制专家须以此为准对齐（避免那处 `编码/codec` 命名不一致）。

## 7. 诚实边界

1. **本文只做设计，未改任何既有文件**。§2 的所有"新增/修改"是**待实现契约**，落地由实现方逐条按 §5 执行。
2. **未实测 `综合体` 在 meeting38 语境的端到端时延/内存**：其依赖链较重（selflearn/dialogue_*/gen_lm），
   开放域还会读盘。**自体线程周期（默认 0.8s）与事件槽长度（256）需实测标定**；若单次 `断供一拍` 周期性地 > 周期，
   须增大周期、或由意识专家提供轻量 `自言一拍`。此为**首要待验证项**，我不假装已知。
3. **A9 是"代理度量"**：在静态界面/演练模式下，若一屏无新元素、动作生命周期稀少，匹配样本会不足；
   该判据必须注明样本量，样本不足时"过"的证据力有限。
4. **"想-说-做一致"是架构保证（单一计划源），不是语义保证**：A8/A9 证明"说与做同源且兑现"，
   但**不证明**计划本身"聪明/正确"（那是规划专家的议题，且世界真值不可预知）。
5. **非 Transformer 边界已核实**：`inner_speech/synthesis/selflearn/gen_lm/声带` 在 tokenize 剥注释后无禁用结构；
   但 A6 现行只扫 `meeting38`，**必须扩到 A13 的扫描根**才算守住，否则"接入即失去审计覆盖"。
6. **真声带"外放"仍未解**：`声带.py` 默认仅合成 wav，外放走 pyttsx3 兜底（现状）。若用户要"原声 wav 直接外放"，
   需新增 wav 播放路径（如 sounddevice/winsound），这超出"接线"范围，属声音机制/硬件边界议题。
7. **实机安全**：所有验证先 `演练=True`；实机（真动鼠标）须所有者知情。本方案未放宽任何安全闸（危词/角区/放弃/超时看门狗保持）。
