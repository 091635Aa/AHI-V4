## 1. 五专家方案要点（各自成文，此处只摘裁决相关）

### 01 意识专家 →「自我槽 + 自我核」
- **机制定义**：自我 = 每拍重算的**自指 HDC 绑定束**（8 角色槽绑定工作区自身状态）+ **可审计自言流**（六类）+ **计划栈**。把"自己"当角色常量做绑定与余弦比较，非哲学断言。
- **激活接口序列**：`桥=综合体(310)` → `桥.加载身份(...)` → `态.装意识(桥.自言, 桥.账本)` → `核=自我核(态,桥)` → `脑器(..., 自我核=核)`；快拍（20Hz）与慢循环（1–2Hz，节流跑 `桥._引擎步/_自评条目/推理环/_自言`）分层。
- **判据 5 条**：S1 自言活跃非退化 / S2 真实性独立审计 / S3 计划三要素齐备含时序 / S4 想说分离与溯源 / S5 自指束实时一致 + 反事实可扰动。
- **定位的病根**：`共存态` 六槽全是"外面有什么"，**无任何"我自己"的槽**；`_发声` 与"想"零分层。

### 02 任务规划专家 →「五级确定性级联」
- **唯一规则（替换 `rng.choice`）**：当前任务下一个未完成步骤 **>** 已学使能关系（前置满足且推进任务）**>** 任务驱动的语义缺口探索 **>** 任务池选题 **>** 兜底滚轮。键/滚轮由该功能词的**计数**决定，无证据默认左键；**全 argmax、平局按句柄字典序**（确定性）。
- **任务来源**：有指令→接口接收；无指令→内生选题（迁移 `synthesis.假设环一拍` 的选题机制）。
- **分解**：HDC + BFS（深度 ≤3，迁移 `语义学院.搜链`），可表达"新建→键入→保存"链。
- **判据 5 条（全带乱按基线对照）**：F1 任务相关性≥0.60 且超基线 0.40 / F2 策略稳定性去重数==1（基线≥3）/ F3 达成率≥0.60 且超基线 0.40 / F4 假报率==0 / F5 探索发现数≥0.6×随机（防塌缩）。

### 03 语言表达专家 →「两流一闸」
- **裁定**：思考层（自言六类，带账本引用，**可审计、不朗读**）与表达层（计划短句，**唯一被朗读**）分离，中间一道硬闸。
- **生成规则**：`6 条模板骨架锁句法 + HDC 检索填实词 + 遥测条件化定语气 + 计数 LM 仅出连接词`，再由 `声带.发声(向量,句,遥测)` 原声输出。
- **复用（函数级）**：`编码器`、`lang_codec`、`gen_lm.HDC语言模型`、`dialogue_v4.生成连接`、`dialogue_v5`（声道分离）、`inner_speech.自言空间`、`synthesis._自言/_自评条目`、`声带.韵律/发声`。
- **判据 6 条**：J1 **无日志体正则命中=0**（用户明确讨厌项）/ J2 复读率≤0.5 / J3 意图一致率≥0.9 / J4 计划性覆盖≥2（当前步/下一步/剩余步）/ J5 引用真实率=1.0 / J6 三元命中率≥0.5。

### 04 声音机制专家 →「不是算法错，是接线错」
- **决定性发现（已由主持人源码复核）**：`声带.py::发声()` 只**落盘** wav；`开外放()/播放()` 用 **pyttsx3 念文本**。∴ AHI 实际出声 = pyttsx3 = 平板机器音，**真声带从没被播过**。
- **修法**：①输出改为播放 `合成波形()` 的 wav；②叠 HDC 情绪解码驱动韵律（4 维归一空间原型最近邻，**禁 softmax**，判好奇/困惑/满意/急躁）；③补三声连读变调、儿化、标点停顿。
- **判据 5 条**：E1 情绪可辨性（韵律参数统计可分）/ N1 非 TTS 审计 / R1 实时 + 不阻塞 / D1 确定性逐位 / C1 并发不阻塞。
- **诚实上限**：声带.py 是 Klatt 风格共振峰合成（单声门脉冲 + 3 谐振器，无唇辐射/鼻分支/LF 声门），**播出来也仍偏电子/机器人，不像真人**。这是 DSP 路线的天花板。

### 05 系统架构专家 →「第 7 路自我线程」
- **总装**：新增第 7 路"自我线程"跑 `inner_speech`+`synthesis`；脑退化为**计划落地器**（同一份计划**既写意图槽=做，又写表达槽=说**）；手执行经新增**事件槽**回流供内核复盘；嘴仅把发声后端换成 `声带.py`。
- **契约**：只**追加**三槽（自我槽=自我线程单写、事件槽=多产者单消费者有界、计划槽=脑单写）；既有六槽语义 / 手意图格式 / 台账 / A1–A7 **全不改**。
- **并发安全**：三个阻塞内核（自言自语/综合体/声带）一律**专属线程**，唯一调用者分别是自我线程与嘴的发声子线程。
- **判据新增 A8–A13**：计划单一源一致 / 说做匹配率 / 自言六类+审计 / 声带溯源 / 并发不退化守门 / 非 Transformer 扩面。
- **落地 6 步**：步0 基线冻结 → 步1 扩槽 → 步2 自我线程 → 步3 脑接计划 → 步4 声带接嘴 → 步5 审计扩面 + 全量回归。**每步独立可验收、可回退。**

## 2. 五方共识（无需裁决，可直接执行）

1. **接线优先于改算法**：大脑（自我意识内核）与嗓子（真声带）项目里都有，meeting38 只是**没接**。先把接上，再谈优化。
2. **随机必须死**：`rng.choice` 换成任务驱动的确定性级联（专家 02 的五级规则），并保留"探索性但可解释"。
3. **想与说必须分层**：内部自言（六类、可审计、可查）≠ 对外语句（计划短句、唯一被朗读）。用户要的"像你一样知道自己在想什么"由此满足。
4. **并发铁律不许破**：新增内核一律独立线程，只经工作区耦合；器官间禁止直接调用/等待。
5. **保护 A1–A7**：既有自检不许失效，新增判据只许追加。
6. **诚实**：DSP 声带有音色天花板；模拟非真意识，如实登记。

## 3. ⚠️ 必须所有者裁决的硬冲突（主持人无法代决）

### 冲突：**"红线（禁 Transformer）" × "声音要像真人"**

- 你要的是：**原声声带、带语气、听得出来不是 TTS**。
- 但项目自己的 `声带.py`（DSP 共振峰合成）**即使修好接线、加上情绪韵律，音色仍偏电子**——三位专家（声音/架构/语言）独立给出一致判断：这是 DSP 路线天花板，不是 bug。
- 能真正"像人"的路只有两条，**都撞红线**：
  - **RVC 音色克隆**：核心依赖 HuBERT（Transformer 编码器）。**注意：你机器上 RVC 推理中心/训练中心此刻正在运行**——说明你本人接受 RVC 用于声音。
  - **神经 TTS（llama-tts GGUF + 情感 LoRA）**：项目 `06_Qwen3TTS外挂` 里已有，但也是神经 TTS。

**所以问题是：禁 Transformer 的红线，是只约束"认知内核/语言生成"，还是也约束"发声器官"？**

给三个候选，请择一（或另提）：

| 方案 | 声音像人度 | 是否撞红线 | 代价 |
|---|---|---|---|
| **A. 纯 DSP 声带**（修接线 + HDC 情绪韵律） | 低（能听出语气，但仍电子） | 不撞 | 立刻可做，今天就能出声 |
| **B. DSP 声带 + 离线 RVC 音色后处理** | 高（真人音色） | 声音器官用 Transformer 编码器 | 需定"红线只管认知内核"；你机器已在跑 RVC |
| **C. 接既有 llama-tts + 情感 LoRA** | 高 | 声音器官用神经 TTS | 同上；且要回接 `06_Qwen3TTS外挂` 管线 |

**我的建议**：**先做 A**（接线 + 情绪韵律，1 步就能让你听到"有语气"而非平板音，且零红线风险），**同时**你裁决 B/C 是否开绿灯——若开，再把音色层换上去。这样不阻塞、不押注。
