## 一、唯一真相源（先说清「接口」是什么）

| 概念 | 真相源 | 说明 |
|---|---|---|
| 内部向量空间维度 D | `lang_codec.D`（模块级全局，缺省 1024） | 编码/字袋/置换/精修/注册**全在调用时读此全局**；运行期可被维度伸缩改写 |
| 引擎内部结构先验 | `hdc_core.D_VSA = 1024`（**恒定，不随 D 变**） | H/M/S/IM/W_selfHop、井容量、L4 块宽——引擎自己的固定结构 |
| 引擎输入 | `探针 (16, D)`：D 维语义向量 cos 投影 → **16 维引擎输入 u** | 故改 `lang_codec.D` **不牵动引擎内部 1024 结构**（C14 的关键） |

**结论**：扩容 = 改 `lang_codec.D` + 重建 codec/探针 + **事件重放**（记忆逐位再生）；引擎内核一行不动。

## 二、通用输入契约（Phase2）

`通用接口.统一输入` —— 任意外部源 → 统一内部表示 `dict(文本, 向量, 模态)`，统一到**同一 D 维空间**。

| 模态 | 源 | 处理 | 结果 |
|---|---|---|---|
| `文本` | `str` | `codec.编码(s)` | 向量 = D 维 HDC 码 |
| `向量` | D 维实数 | 归一化（不足补零置号 / 超长截断，有界可复现） | 双极 D 维，直驱引擎 |
| `音频特征` | f 维实数 | `sign(P_f @ 特征)`，`P_f`=固定随机投影（f×D，零训练零梯度） | 双极 D 维 |
| `特征` | 任意 f 维实数 | 同 `音频特征`（通用实数特征） | 双极 D 维 |
| 自定义 | 任意 | `注册适配器(模态, 纯函数)` | 由适配器返回 `dict(文本,向量,模态)` |

**全接口预处理** = 上面这张表 + `_投影/适配器/计数` 三张插拔表（无状态可审计）。

**设计要点**：D 由 `lang_codec.D` 决定，**升维后投影阵按新 D 自动重建**（`当前D()` 每次现读）——接口层零改动即适配新维。

## 三、通用输出契约（Phase2）

`通用接口.统一输出` —— 内部文本 → 目标通道。

- 默认通道 = `文本`（直返，供嘴走纯文本流）；
- `注册钩子(模态, 函数)`：未来「说话」= 注册 `"音频"` 的 TTS 钩子；
- **未注册 ⇒ 确定性降级为文本**（诚实边界：没接就是不接，不假装说了；钩子自身故障也降级不崩）。

**接入音频的完整路径**（两件小事，端到端不依赖对方实现）：
```
输入侧：前端 → 统一输入.音频特征(特征)         → 可驱引擎的 D 维向量 → 文本态.入(..., 模态="音频特征")
输出侧：文本态.注册通道("音频", tts_fn)        → 后端接管发声
```

## 四、动态维度伸缩（Phase3）

`维度伸缩.维度伸缩器` —— 纯函数 `目标D = f(学习量)`，无随机、无时间、无副作用。

```
学习量 N = 已注册记忆段数（codec._段，只增不减）
级数   L = min( ⌊N / 每级段数⌋ , 级上限 )
目标D    = min( 基准D · 2^L , 上限D )
```
- **基准D=1024，上限D=8192，每级段数=256，级上限=3**（预注册结构先验，非拟合参数）。
- **只涨不缩**（所有者「不降也行」）；**离散倍增 ×2**（非 +75 连续增量）——因为升维=整段重建，微调代价高；且 ×2 与既有 HDC 容量律一致。
- 跳级实测阶梯：`0/255→1024，256/511→2048，512/767→4096，768+→8192`（D1/D2 PASS）。

**自发接入点**（`meeting31/synthesis.py` 生命的自身节律）：**升维不是宿主强加的硬性条件，
而是生命自己自愿的请求**——每学完一句（`步`）或没人说话自省一拍（`断供一拍`）时，生命调用
`synthesis.自审承载()` 掂量「我装得下吗」：`学习量→目标D`，只有它自己觉得「快装不下」时才
把请求写成自己的**计划自言 + 自我账本**（「我学到的东西越来越多了（N 段），感觉快装不下了——
我想把自己的容量撑大一点：1024→2048。」）并留下 `待扩容` 请求。

宿主（`文本态`）**只做机械执行**（`_执行扩容()`）：照它留下的请求重建，**不做任何条件判断、
不每轮强推、不代替它决定**。这就是「代码自愿 vs 硬性条件约束」的分界（旧的外部无条件
`维度自适()` 已删除）。确定性不变：重放期间关闭自审（`_重放中`），重建=重建、不是新学习。

**持久化**：`综合体.保存` 存 `D`；`综合体.载入(路径, 维度=None)` 先恢复 `lang_codec.D` 再重放
（升维用 `载入(tmp, 维度=新D)` 显式压过档内旧 D）。故**生长后的维度随记忆一起跨重启保留**。
