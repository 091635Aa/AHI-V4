# 07 · 步 2 规格 —— 情感/韵律/意图因子化编码层（拆两个容量炸弹）

> 日期：2026-10-05 ｜ 依据：05 专家方案 §3/§4/§6/§8 + 06 合并规格（复用 FSW 内核算子）
> 范围：05 §10.2 落地顺序的 **1–3 项**（建轴 + 情感态编解码往返 + 容量压力）。
> 4–6 项（EFE/发声动作/声带对接）属步 2b/步 4，本步不做。
> 纪律：纯新增模块 + 纯新增测试；零引擎改动；无 softmax/无梯度/无 Transformer（C1）。

## 1. 结构（复用 05 §3，角色键并入 FSW 内核命名空间）

```
8 因子轴：V 效价[-1,1] / A 唤醒[0,1] / P 支配[0,1] / G 归因{0,1} /
          M 道德效价[-1,1] / X 社会暴露{0,1} / T 关系威胁[0,1] / Nv 预期违背[0,1]
轴实现    = 声带.数轴(键="情感|<因子>", D=1024, S1=16, S2=16)   # 动态导入，不改其文件
角色码    = FSW内核.原子("角色|情感V") 等（并入内核原子表 ⇒ 与语义/意图同空间软隔离）
情感态码  E = 束([ 绑(role_r, 轴_r.编码向量(v_r)) for r in 8 ])     # live 8 对绑定
回读      v̂_r = 轴_r.解码档位( 绑(role_r, E) )                     # 自逆解绑 → 档位最近邻
```

## 2. 韵律/意图层（本步只建轴与编码 API，不做增量表驱动——那是步 4 嘴侧）

- 韵律 8 轴：基频/幅度/气声/紧喉/粗糙/送气/声区/语速（键="韵律|<参数>"），同构数轴。
- 意图 4 轴：类别(6)/强度/时限/来源（键="意图|<因子>"）。
- live 预算（05 §6.3）：语义窗口 ≤64 + 情感 8 + 韵律 8 + 意图 4 + 动作 ≤3 = **≤87 < 102**。

## 3. 情绪区域表（05 §3.4 的 20 项，编码为 8 轴区间点）

- 区域 → 点：区间取代表值（"高"=0.85，"中"=0.5，"低"=0.15，"—"=不设（编码用 0.5 中性），
  "他人"=0，"自我"=1，"+/−"=±0.85）；新增情绪只加表行，码位成本 0。
- **判别口径**：两情绪编码束的 cos 距离；已知临界对（羞耻/内疚仅 X 一轴之差）按 05 §9.2
  **预期临界可分**（档差 1 → cos 差 ≈0.06≈2σ），判据线单独放宽并如实登记。

## 4. 判据（步 2 部分；E1 听感判据属步 4，需合成）

| # | 判据 | 门槛 |
|---|---|---|
| S2-C1 | live 束塞满回读保真：N ∈ {8,20,40,87,102} 全因子回读档位正确率 | ≥0.99（N≤102 干净区） |
| S2-C2 | N=200 优雅退化 | 回读 cos ≥0.70，不雪崩 |
| S2-R | 20 情绪区域编码束两两区分（同区域重复编码 cos=1） | 非临界对 cos 距 ≥0.06（≈2σ）；羞耻/内疚、羡慕/嫉妒单轴对 ≥0.03（1σ 临界，如实登记） |
| S2-D | 确定性 | 同输入双实例编码束逐位一致 |
| S2-T | 延迟 | 情感态编码+16 轴回读 ≤15ms（05 §8 R1-a 口径，CPU） |

失败处置：回规格重推，不调阈值；S2-R 的临界对若连 0.03 都不达 ⇒ X/T 轴设计失败，须加 O/B 第 9 轴（05 §9.2 预案）。

## 6. 实施期修正（步 2 判据实测，2026-10-05）：05 §6.3/§8 C1 的解绑保真公式证伪

**实测**：live 平铺束逐对解绑的回读 cos = **1/√N**（N=200 实测 0.079；N=8 实测 0.277），
不是 05 §3.3 声称的 `1/√(1+(N−1)/D) ≈ 0.9966`——05 把"捆绑成员识别"的 SNR（那确实
随 1/√D 衰减）错用到了"逐对解绑读档位"上。后者还要在**同轴 257 个强相关档位原型**
（相邻 cos=0.9375）之间竞争，余量仅 0.0625/√N：N=8 时 0.71σ ⇒ 精确档位率 ~0.79、
±2 档 ~0.865。**平铺束逐对精确读值在原理上不可行**（与步 1 目录树证伪同类的"信号
被聚合噪声淹没"，且 05 §9.2 自己预告的临界对问题比其保真公式所示严重得多）。

**裁决（C1 重钉到架构真实用途）**：
1. **live 束 = 粗读广播**（区域分类 / 韵律粗控）：20 情绪区域分类 20/20（S2-R），
   这是它干得了也只该干的活；
2. **精确读值走库路径**：情绪态作为 8 字段记录写入库 → IVF 检索 → 元数据精确读——
   top-1 ≥0.99（步 1 F2 已证机制）+ 命中即精确；
3. 平铺束逐对精确解绑从方案中**删除**，能力包络（N=8：精确 0.79 / ±2 档 0.865）如实登记。

live 容量账随之修正：live 束承载的是**粗态广播**（≤20 对），逐对精确并读的需求
本就不存在——"干净容量 102" 的口径回到步 1 修正后的成员识别语义。
