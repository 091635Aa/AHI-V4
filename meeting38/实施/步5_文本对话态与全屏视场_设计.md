## 1. 五条决定

- **D1 视野全局化**：废除 `器官_眼.区域` 硬裁剪与 `器官_手.偏移`，恢复全屏采集。
- **D2 焦点 = 权重**：焦点只抬高该区在评分中的优先级（1.0 → 1.2），**不减信息**。
- **D3 思考分层**：思考槽加「层」；深度回响不外显，只外显「做什么／点哪里／预期／下一步」。
- **D4 文本优先**：先做纯文本对话态，**声音不用**；眼仍全屏看，手先不动。
- **D5 轨迹曲线化**：`_采样轨迹` 从直线 → 贝塞尔曲线（速度剖面不变）。

注：原话 6「跳太快」**不修**——已定性为硅基特性，仅登记，不改节拍。

## 2. 视野全局化（回退裁剪）

### 2.1 现行错误路径（代码证据）

| 位置 | 症状 |
|---|---|
| [器官_眼.py](../器官_眼.py) `self.区域 = ...`（:80）、`_裁()`（:89） | 取帧后**硬裁**到区域，视场只剩那一块 |
| [器官_眼.py](../器官_眼.py) `一轮()`（:240-241） | `img, 屏幕 = _截屏()` 后立刻 `_裁`，屏幕尺寸即区域尺寸 |
| [器官_手.py](../器官_手.py) `_映()`（:134） | 区域系 → 屏幕系偏移，配合裁剪 |
| [演示_看想点.py](演示_看想点.py) `区域=量区域()` | 把世界截成 tkinter 窗（1080×720） |

**根因**：演示把「世界窗口」当成了视野，眼睛只看那一块 → 正是所有者说的「视野范围太小」。

### 2.2 目标

- 眼：DDA **全屏**取帧；`区域=None`；网格覆盖全屏（沿用 16×9）。
- 手：全屏坐标；`偏移=(0,0)`。
- 焦点仍存在，但只进**评分公式**，不进采集范围。

### 2.3 焦点 = 乘性权重（贴合「1.0 → 1.2」）

现行 `下一注视()`：

```
s = W意外·逐格意外 + W显著·显著度 + W意图·意图偏置 − 抑制返回系数·抑制 + W邻近·邻近场
```

改为：

```
增益 = 1.0 + 0.2·exp(−d² / 2σ²)      # d=格到焦点的距离；焦点处 1.2，远处 → 1.0
s    = 增益 ⊙ (W意外·逐格意外 + W显著·显著度 + W意图·意图偏置 − 抑制返回系数·抑制 + W邻近·邻近场)
```

- **只抬优先级，不减信息**：周边格照常产生意外、照常进候选与元素表。
- 中央凹**细节通道保留**（焦点处看得更清），但它不再是「世界只有那一块」。
- σ 先取 1.5 格，可预检择优。

### 2.4 成本证据：全屏完全够用，裁剪毫无必要

`预检_网格成本.json` 实测（合成 1920×1080，15Hz 节拍预算 67ms/拍）：

| 网格 | 格数 | 全屏均 / P95 |
|---|---|---|
| 8×6 | 48 | 19.9 / 22.0 ms |
| 12×8 | 96 | 22.9 / 23.6 ms |
| **16×9** | **144** | **27.1 / 27.9 ms** |
| 20×12 | 240 | 40.3 / 44.8 ms |

→ **全屏 16×9 仅 27ms**（预算的 40%）。步3.6 当初为省成本而裁，现证明是**错误权衡**。

### 2.5 代价与登记

- 全屏后候选/元素数上升，脑的挑选策略需再平衡（继续「没碰过的优先」）。
- 真机分辨率若 **> 1920×1080**，需重测（见 §8-1）。

## 3. 思考分层：朝外正文 vs 内部回响

### 3.1 现状问题

[器官_脑.py](../器官_脑.py) 六类（看/想/招/预/果/路）**全部外显**到演播台与日志。其中「看」（*眼前 6 件东西；注视格(6,6)……*）是**内部回响**，所有者不该盯着它看。

### 3.2 分层定义

| 层 | 内容 | 是否外显 |
|---|---|---|
| **内**（回响） | 感知汇总、联想、回忆、权衡、自我评估 | 否（只留档） |
| **外**（正文） | ① 我要干什么 ② 我该点哪里 ③ 点了可能怎样 ④ 下一步 | 是 |

### 3.3 落地

- `共存态.写思考(类, 文, 层="外"｜"内")`；`取思考(上限, 只要外=True)`。
- 器官_脑：`_叙述看` → `层="内"`；`想 / 招 / 预 / 果 / 路` → `层="外"`。
- 演播台、文本流只渲染「外」。

## 4. 文本对话态（本轮主线；先文本，声音不用）

> **⚠ 2026-10-06 纠偏（以 `../00_置顶_纯文本对话态.md` 为准，本节旧稿的"计时/节流"作废）**
> - §4.4「空闲 ≥ N 秒 → 进入自主循环」**作废**：**禁止任何秒数阈值**。
> - §4.5「节流：空闲输出 ≤ 每 N 秒 1 行」**作废**：**不设节流阀**（"跳太快"已登记为硅基特性，不修）。
> - §4.5 的"取材 = 眼（全屏）"**作废**：**眼已冻结**；文本态的"自己找事干"= **只读探索自己的项目**（开放域）。
> - §4.5 的"临时冻结"**改为它自己作主**：**这一拍冒出念头（有想头）就醒、没冒出（没得想）就歇**
>   ——0 边界的存在/缺席判据，非调出来的数（无 `饱足≥0.5`、无秒数）。余下 §4.4/§4.5 文字仅存史。

### 4.1 目标形态

像隔手机／QQ 的两个人：

- 我发一句 → **它回一句 + 写一句「内心想」**
- 我不发 → 它继续**自己想 / 自己找事干 / 自己推演 / 或把自己临时冻结**

### 4.2 与七路的关系（复用，不推翻）

| 器官 | 文本态职责 |
|---|---|
| 嘴 | `用语音=False`，走纯文本降级（声音先不用） |
| 脑 | 主循环不变，新增「对话驱动」 |
| 眼 | 仍**全屏**看（供「自己找事干」取材） |
| 手 | 默认**不动手**；文本态先说打算（是否真动手待定，见 §8-4） |
| 耳 / 语义 / 我 | 不动 |

### 4.3 新槽位：对话槽（原生支持式，非工具调用）

```
写用户说(文)          用户消息入箱
取用户说()            脑取走（取走即清）
写它说(文)            它回的那一句
写它想(文)            它的「内心想」那一句（朝外正文，外显）
取对话(上限)          文本流（时间序）
状态: 等待 / 回合 / 空闲
计时: 上次用户消息时刻、空闲秒数
```

### 4.4 两态

- **回合态**：inbox 有用户消息 → 生成 `[它说]` + `[它想]` 各一句 → 清 inbox。
- **空闲态**：空闲 ≥ N 秒 → 进入自主循环。

### 4.5 空闲态四行为（所有者点名）

| # | 行为 | 取材 |
|---|---|---|
| 1 | **自己想**：内省、复述、推演（外显一行独白） | 语义槽 / 思考槽历史 |
| 2 | **自己找事干**：看全屏 → 挑没碰过的控件 → 说打算 | 视觉槽 元素s |
| 3 | **自我推演**：推「我若点它可能怎样」 | 脑自身 `_预测` 经验 |
| 4 | **临时冻结**：反复无事可做 → 自己挂起思考线程；收到用户消息唤醒 | 空闲计数 |

**节流**：空闲输出 ≤ 每 N 秒 1 行，禁止刷屏。

### 4.6 文本流格式（拟）

```
[我    10:02:11] 你在干什么
[它    10:02:12] 我在看这块屏幕……左边那块按钮我还没碰过。
[它·想 10:02:12] 该点左上那个方块试试；它要是变了，就说明能用。
```

「它·想」= **外显的朝外正文一句**；深度回响（§3 内层）**不外显**。

### 4.7 「原生支持式，不是工具调用」如何落实

- **无** function calling、**无** prompt 编排、**无**工具清单驱动。
- 一切是**共享工作区槽位读写**：脑每拍读对话槽 / 视觉槽 → 生成 —— 思考链是器官内部状态的自然外化，不是被外部工具表选出来的。

## 5. 手的重新定位（**冻结备忘**，本阶段不动）

### 5.1 所有者原话（2026-10-06）

> 「**不要写死，手，之所以称为手，是能 360 度无死角的旋转操控鼠标，而不是强制的一个 A 点、B 点的过渡器。**」

### 5.2 判读：连"贝塞尔化"也是错的

- 现行实现（[器官_手.py](../器官_手.py) `_采样轨迹` :105-118）：`p = 起 + (过冲点−起)·s`，起/过冲点/终共线 → **严格直线**。
- 本文旧稿提出的"贝塞尔曲线"——**仍是从 A 到 B 的插值**，只是把直线弯成曲线，**同样被否**。
- 根因不是"线不弯"，而是**整个"给定起终点→算一条轨迹"的范式**：把连续的手降格成了一次性过渡器。

### 5.3 正确定位（解除冻结时按此重做）

手 = **可任意时刻、任意方向连续操控的自由控制器**——像一只真手握着鼠标：能 360° 转向、能中途任意改向、能原地微调、能画圈，**没有"起点/终点"这个概念**。

- 现有 `_计划 / _段 / 点s`（步骤表 + 预采样点列）是过渡器的结构，**应废除**。
- 替换为：**逐拍速度/方向控制**（每拍决定"往哪个方向、多快、按不按键"），由意图与视觉实时驱动。

### 5.4 处置

**冻结**。本阶段（纯文本）不实现、不修改 `器官_手.py`。解除冻结时按 §5.3 重新设计。
