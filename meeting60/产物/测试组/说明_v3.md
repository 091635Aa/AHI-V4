# 修复版 v3 · 多组测试说明（meeting60）

> 背景：所有者反馈 v2 测试音频「音色严重失真、非常模糊」。
> 这次不是打补丁，而是把发声引擎整个换掉 + 保留人类化韵律 + 给 7 组可听对照。
> 口径仍然是：**参数化模仿，不是声克隆、不是角色本人**；未做真人盲评。

## 0. 先听这一个（主修复版）

**`修复版v3_三角色.wav`**（44.1kHz/16bit）：EmoCompanion → SpeakerA → 洛天依 → 同句三声。
单角色：`修复版v3_角色_EmoCompanion.wav`、`修复版v3_角色_SpeakerA.wav`、`修复版v3_角色_洛天依.wav`。
参考 A/B：`参考A_B_对照.wav`（每角色：参考原声 → 合成，交替）。

## 1. v2 为什么失真/模糊（实测根因）

| 根因 | v2 实测 |
|---|---|
| 输出 16kHz（8kHz 带宽上限） | 8–16k 恒 0；4–8k 仅 0.6–2.5% |
| 合成器只有 F1–F3 三个谐振器 | 95% 滚降只有 1055–2627Hz（参考 2578–3666Hz） |
| 为凑参考 LTAS 用了 ±8dB 静态 EQ（低切 7dB、中频 +8dB） | 谱重心 762–947Hz，听着又闷又染色 |
| 峰值归一后过 tanh 饱和 + 紧喉/粗糙加工 | 峰因 15–17dB，有压缩/金属感 |
| 共振峰缩放被拟合推到 1.18 | 声道缩短 15%，卡通化 |

## 2. v3 改了什么（纯 numpy/scipy，无 TTS/RVC/外部模型）

1. **换引擎**：新写 `引擎_44k.py` —— 44.1kHz 源-滤波器：Rosenberg/KLGLOTT 声门源 → **F1–F5 五级级联** + F4/F5 并联支路 → **唇辐射**；**无 tanh/硬削波**（只整体缩放）；确定性。
2. **呼吸/擦音重新标定**：气声改带限噪声（原一阶差分把 8–16k 拉到 23%）；擦音/齿音单独控制，噪声帧比浊音低约 10–15dB；8–16k 只加在清辅音帧（补齿音质感）。
3. **谱平衡**：浊音段一阶低通（约 4.2k，自然滚降），清辅音保留亮度；**不再用 ±8dB EQ 去硬凑参考**。
4. **保留人类化韵律**（停顿/换气/句调/三声变调/重音/句末延长/微颤/句界音高重置）+ 五共振峰目标（新增 F4/F5）。
5. **拟合约束**：共振峰缩放 [0.85,1.10]（不再 1.18），F0 按帧真值对中参考。

## 5. 诚实边界

- 参考源本身有带宽上限（EmoCompanion 24k 源=12k 上限、SpeakerA 40k、洛天依清唱 44.1k）；**8–16k 我们只补到 0.14–0.20%，低于参考的 0.48–1.07%**，齿音仍偏弱。
- 组 C 比参考略亮（谱重心 +200~400Hz），是刻意保留清晰度；若想更贴参考可听组 D（低频校正版）。
- 三个参考源声学上接近（旧版实测EmoCompanion|SpeakerA F0 仅差 0.19 半音），三条声线可分辨性有数据上界。
- 组 B 的擦音未重标定（保留旧标定）所以偏亮，只作引擎隔离对照，不是交付候选。
- **未做真人盲评/MOS**；组 G 含参考原声，仅本机 A/B，不再分发。
- 参数化模仿，不是声克隆；EmoCompanion源疑似 TTS/VC 拼接产物、SpeakerA是分离 stem、洛天依是第三方 AI 干声。
