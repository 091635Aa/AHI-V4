## 2. v3 修复（`实施/引擎_44k.py` + `韵律_44k.py` + `拟合_44k.py`）

- **新引擎 44.1kHz**：Rosenberg/KLGLOTT 声门源（流导数）→ F1–F5 级联 + F4/F5 并联 → 唇辐射；
  声源低通 3.8k（2 阶）+ 浊音一阶低通 4.2k 形成自然滚降；**无 tanh/硬削波**，峰值只整体缩放。
- **呼吸/擦音重标定**：气声改带限噪声（6k 低通+180Hz 高通），擦音噪声比浊音低约 15dB，
  8–16k 只加在清辅音帧（补齿音）；修复了「8–16k 一度 23%」的嘶嘶声。
- **韵律**：保留 v2 的人类化韵律并扩展到 F4/F5（停顿/换气/句调/三声变调/重音/句末 1.45×+140ms 尾音/
  微抖/微颤/句界音高重置）。
- **拟合**：探针走 44.1k 新引擎 → 16k 下采样同口径比对；共振峰缩放约束 [0.85,1.10]；
  F0 按帧真值对中参考；包络目标 **250–8k 六带**（剔除参考 0–250Hz 隆隆带，避免 v2 式低切/闷）。
- **EQ**：主修复版 **不用**参考匹配 EQ；组D 只做 250–2000Hz ≤±2dB 轻校正（>2k 不动）。

## 6. 诚实边界

1. 参考源本身带宽受限（EmoCompanion 24k 源、SpeakerA 40k、洛天依清唱 44.1k），**8–16k 只补到 0.14–0.20%**，

2. 组C 比参考略亮（谱重心 +200~400Hz），是为清晰度刻意保留；组D 是更贴参考低中频的变体。
3. 三个参考源声学上接近（v2 实测EmoCompanion|SpeakerA F0 差 0.19 半音），三条声线可分辨性有数据上界；
   组E 只降 F0、共振峰未同步 ⇒ 会更偏离参考，仅供「更像日常说话」的听感试验。
4. 组B 擦音未重标定，偏亮，仅引擎隔离对照，不是交付候选。
5. **未做真人盲评/MOS**；客观指标 ≠ 听感。
6. 参数化模仿，不是声克隆；EmoCompanion源疑似 TTS/VC 拼接产物、SpeakerA为分离 stem、洛天依为第三方 AI 干声。
