## 0. 旧版实测根因（只读诊断，已确认）

| 指标 | 旧交付（v2） | EmoCompanion参考源（24k） | 结论 |
|---|---|---|---|
| 谱重心 | 762–947 Hz | 974 Hz | 旧输出偏暗 |
| 95% 滚降 | **1055–2627 Hz** | **3539 Hz** | 旧输出高频几乎缺失 |
| 4–8kHz 能量占比 | **0.6%–2.5%** | 2.9% | 高频塌陷 |
| 8–16kHz | 0（16k 采样上限） | 0.5% | 输出被 16k 截断 |

四个结构性原因：
1. **合成器只有 F1/F2/F3 三个谐振器**（`声带.py` 原生链路），3.5kHz 以上没有谱包络 ⇒ 天然闷；
2. **输出固定 16kHz**（8kHz 带宽）⇒ 天生模糊；
3. 为了把 16k 合成器凑近参考 LTA，用了 **±8dB 静态 EQ**（低切 −7dB、中频 +8dB）⇒ 听感失衡/染色；
4. `合成波形_快` 峰值归一后过 **tanh 饱和** + 紧喉/粗糙加工 ⇒ 失真；共振峰缩放被拟合推到 **1.18**（声道缩短 15%）⇒ 卡通化。

## 1. 修复目标（v3）

| 目标 | 验收口径 |
|---|---|
| 不再闷 | 44.1kHz 输出；1–4k / 4–8k / 8–16k 能量占比接近参考源，95% 滚降 ≥3.2kHz（EmoCompanion参考 3.54k） |
| 不失真 | 无 tanh 硬饱和、无 ±8dB EQ（最多 ±3dB 轻校）；峰值 ≤0.95、无 NaN、无削波；共振峰缩放 ∈[0.85,1.10] |
| 像人 | 保留 v2 人类化韵律（停顿/换气/句调/变调/重音/句末/微颤），并补 F4/F5 高频共振峰 |
| 原生 | 纯 numpy/scipy 自研 DSP；**无 TTS / RVC / 神经声码器 / 外部模型**（C1/C10） |
| 多组测试 | 至少 5 组可听对照（旧版 / 新裸声 / 新+韵律 / 新+韵律+轻EQ / 自然音高变体 / 同句三声 / 参考 A/B） |
