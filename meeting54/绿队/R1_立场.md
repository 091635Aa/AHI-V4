## §0 五条结论

1. **重复的根因不是「池小」，是「生成器=检索器」**：`说()` 从 `句子池()` 整句选（`说话_连贯.py:149-176`），句数/桶/步/索引全是周期性取模（`:160-170`）；字符 LM 的 `候选()`（`:118-128`）**从未被 `说()` 调用**；`流式()`（`:178-182`）只是把已选好的字符串按字摊开 ⇒「自回归逐 token」是文档声明，不是实现（`:2-7`）。
2. **判据在奖励检索、惩罚生成**：`判据_说话.py:145-159` 的 S5「每句必须来自角色包」把「生成新句」判为来源错误（证据：320/320=100%）；S2 的「四字重复 0.0152」只测**段内**，不测跨轮；S6 只抓「固定池」（状态无关），抓不到**旋转池**。⇒ 现系统在现判据下最优策略就是继续背句子。
3. **池小只是容量上限**：8–20 句池决定了「最多 20 种整段」；但即使池 ×10，选句机制的周期=池长，跨轮重复仍结构性存在（预测：重复率只降 ≤30%，[未验证假设]）。
4. **修复方向 = 组合生成 + 工作记忆去重 + 双系统仲裁 + 语用条件**（§2 五机制）；生成空间从「池大小」换成「槽×词义张量积」，重复率由 1/|池| 变成 1/(V^L)。
5. **T4 推荐混合且可拔**：AHI 核出状态/记忆/骨架与词选择（内生），本地 LLM 只做「措辞表面变化」；判据=**拔掉 LLM 仍能说**（流畅度降、重复率不升）⇒ 外挂不是拐杖。

## §1 T1 诊断：池小 vs 选句机制 vs 身份/记忆受限

**主张**：三者可分离——**池小=上限（容量）**；**选句机制=周期性（结构性）**；**身份/记忆受限=话题单一（内容）**。当前重复主因是第二者，且被判据 S5 强化。

**证据（[实测] 源码/证据件）**
- 选句路径：`说话_连贯.py:157` 取 `句子池()`；`:160` `n=min(句数,len(池))`；`:161` `桶=int(abs(sum|o用|)*1000)%len(池)`（**状态只压成一个桶号**）；`:162` `步=5`；`:166` `idx=(桶+i*步+拍)%len(池)` ⇒ 每轮整段是池的一个**旋转**，`拍+1` 整段平移 1 格 ⇒ **周期=池长**，相邻轮 3–5 句里大量重合。
- 生成器空转：`字符LM`（`:58-79`）只在 `候选()`（`:118-128`）里用；`候选()` 无调用点 ⇒ 自由续写从未进输出（自认见 `证据_说话.md:70-72`）。
- 假流式：`流式()`（`:178-182`）先调 `说()` 再 `enumerate(文)` ⇒ 时间轴是事后摊开，不是逐 token 生成。
- 判据偏置：S5（`判据_说话.py:145-159`）奖励「句句来自记忆」；S6（`:161-177`）只构造「固定池」must-fail ⇒ **旋转池**这个真实病未被抓（[实测] 源码）。
- 反证/鉴别实验（可执行，未跑）：同一角色、同状态序列跑 200 轮，记「跨轮重复句率 / distinct-4 / self-BLEU」：①池×10（复制记忆）⇒ 若重复率降到 ≤10% 则池小是主因；②池不变、换成组合生成（§2a）⇒ 若重复率降 ≥50% 而 distinct-4 升 ⇒ 选句机制是主因；③身份/记忆受限：换角色包但同机制 ⇒ 重复率应恒定（若大变则是身份内容问题）。
- 代价：200 轮 × 3 条件 × 2 种子，纯文本生成（现件 ~ms/段），[未验证假设] <2min CPU；两趟需固定种子。

## §2 T2 人脑式语言架构：五个机制候选

> 所有机制共用「两区室核」接口：`A`=慢自我/角色态、`B`=世界态、`a_t`=内心潜态（V5:190-213 可接）、`o用`=当前条件。非越宪路线只用 8 算子：绑/解绑/门/叠/归/读/迭代/符。

### (a) 语义组合 / 概念绑定生成句
**输入**：自态 A、内心 a_t、情景向量 J_t、角色码 r、词义码本 W（V×D，词义由经历累积）。**输出**：词序列（每槽一个词）。
```
句义：J_t = 叠([绑(r_k, 义_{w_k}) for k in 槽])          # 结构=角色×词义的绑定
更新：义_w ← 归(义_w + η·解绑(r_w, J_听见))              # 从听见句反推词义（不是抄句）
生成：for k: q_k=解绑(槽码_k, J_t)；w_k=读(W, q_k)；J_t←归(J_t+绑(槽码_k, 义_{w_k}))
```
**为什么消除重复**：输出空间=槽数×词义张量积（L≤6、V=24 ⇒ 组合数 ~2×10⁸ ≫ 池 8–20）；同状态可由不同绑定路径出不同句；重复率由 1/|池| 变为 1/(V^L)。**接核**：A/内心→J_t 条件；只用 绑/解绑/叠/归/读，零新算子。

### (b) 句法骨架 + 词汇填充（不是查表）
**输入**：听见序列的槽位转移、话题码 c。**输出**：槽序列→词序列。
```
学骨架：S ← 归(λS + (1−λ)·绑(槽码_{t-1}, 槽码_t))      # 骨架住在 D 维分布里，不是常量表
槽激活：g_k = 符(S, 槽码_k)；填词：w_k = 读(W, 归(g_k⊙c + 解绑(槽码_k, J_t)))
```
**为什么消除重复**：骨架是概率分布（同一骨架可填不同词），且骨架由听见统计长出来 ⇒ 结构有限、组合无限。**边界**：源码出现常量槽位表/模板树即判焊死（可检测）。**接核**：绑/叠/归/符/读；S 可放区室 A 的慢通道。

### (c) 工作记忆 / 情景缓冲（多轮不重复）
**输入**：最近 K 轮句义 {J_{t−k}}、已说词集。**输出**：重复抑制后的词分。
```
更新：M_t = 归(γ·M_{t−1} + Σ_k 绑(轮次码_k, J_{t−k}))     # 衰减+时间绑定
生成：score_w ← 符(义_w, J_t) − α·符(义_w, M_t)             # 已说⇒被抑制
若 novelty<θ：强制换槽/换话题（或触发创造性档 (e)）
```
**为什么消除重复**：跨轮内容进 M_t ⇒ 同一句再出现被扣分；清空 M ⇒ 重复率回升（T3 臂）。**接核**：叠/绑/符/归；M 可作区室 A 的"情景快通道"，与 V5 上下文并列。

### (d) 语用 / 受众调节
**输入**：受众码 u（观众/对话者/独白）、场合码 c、自态 A。**输出**：同语义不同措辞/详略。
```
门：g_u=符(u,A)；g_c=符(c,A)
生成：score_w ← score_w + β_u·符(义_w,g_u) + β_c·符(义_w,g_c)   # 同一 J 换受众⇒换选词
```
**为什么消除重复**：重复常来自「同一内容同一说法」；语用门按受众/场合重述同一 J ⇒ 表面形式变化，不是换池。**接核**：符/门/归；u/c 作为 B 的一部分输入。

### (e) 公式化语言 vs 创造性语言（双系统）
**输入**：预测误差 ε_t、情境新异。**输出**：整段（或逐词）门控混合。
```
g = 软限(γ·(ε_t−θ), 1) ∈ (0,1)                      # 想不通/新情境 ⇒ 偏创造性
公式化档：输出=检索(短语句库, 状态)                    # 快、安全、高频
创造性档：输出=(a)/(b) 组合生成
最终：门(g, 公式化句, 组合句)（整段级，必要时逐词）
θ ← 慢自适应：公式化档被判重复则上调 θ
```
**为什么消除重复**：重复被限制在「高把握/固定场合」的公式化档，且受 ε/句数上限；新情境自动切创造性档。**接核**：门/软限/符/归；ε_t 可用 V5 的「惊讶/新异」（V5:191-194）。

**T2 四件套**：主张=组合空间替代池；证据=源码根因（§1）+ 现有判据测不到跨轮；反证=若「池×100 仍高重复」⇒组合非必需；若「组合臂重复率不降」⇒机制不成立；代价=CPU 文本级 ms～几十 ms/段（未测），无需 GPU（非越宪路线）。

## §3 T3 机制级可失败臂（每条给阈值 + must-fail；[未验证假设]）

| # | 臂 | 输入/操作 | 观测 | 阈值 | 必须失败对照 |
|---|---|---|---|---|---|
| A1 | 组合 vs 固定骨架 | 同状态/同词表；两臂只换生成器 | 200 轮跨轮重复句率、distinct-4、self-BLEU(3) | 组合臂重复 ≤0.20 且 distinct-4 ≥0.60；fixed ≥0.60 | 固定骨架臂必须**高重复**（若它低 ⇒ 判据无效） |
| A2 | 工作记忆清空 | 有 M vs M≡0；其余同 | 跨轮重复句率差 | 差 ≥0.15（有 M 更低） | 清空后不升 ⇒ WM 未接线（FAIL） |
| A3 | 语用消融 | 同状态同话题，换受众 u；门控开/关 | 文本改变率 | 开 ≥0.30；关 ≤0.05 | 关后不变 ⇒ 语用门不存在 |
| A4 | 池×10 诊断 | 复制记忆 ×10，仍用选句 | 跨轮重复率 | 若降 >70% ⇒ 池小为主因；≤30% ⇒ 选句机制 | 两解释必须被这条分开，否则 T1 诊断 INVALID |
| A5 | 身份/记忆受限 | 换角色包（同机制）/空记忆 | 重复率与来源正确率 | 换包重复率近似不变；空记忆→常数句 | 换包后重复率大变 ⇒ 身份内容问题，不是机制 |
| A6 | 长时稳定 | 连续 500 轮 | distinct-4 斜率、崩点、两种子 | 斜率 ≥−0.02、无崩点、两种子同向 | 若 100 轮后重复率升 ≥0.15 ⇒ 判「不稳定」 |

## §4 T4 越宪取舍：本地 LLM 当语言器官时怎么保留「内生」

**三个方案（代价为设计估算，未测）**
1. **L 越宪外挂**：Qwen2.5-1.5B-Instruct（或 RWKV7-1.5B）当**措辞层**：核出角色/状态/记忆/骨架 → 条件 prompt → 生成 → 归属标记。破 C1/C10/C13（采样），必须记权重哈希+种子+温度；温度=0 尝试可复现；风险=身份漂移/幻觉记忆/不可拔。
2. **E 内生自研**：把 (a)(b)(c) 用到 `V5_双通道` 核上（VSA 组合 + 听见序列骨架 + 工作记忆），D=256、词表 24–200、纯 CPU；语料=角色包+EmoCompanion日记（23.6MB，外采但显式记录）。判据=状态/记忆/角色/重复四臂。**这条不靠外挂，是「内生」的主路线**。
3. **M 混合可拔（推荐）**：核出内容（J_t/骨架/槽）→ 词选择由核读 W 完成 → LLM **只做同义改写**；判据：**拔掉 LLM 仍能说**（重复率不升、流畅度可降）、LLM 输出必须带「外源措辞」标记。
**四件套**：主张=「内容内生、措辞可外挂」；证据=V5 已有状态/内心接口、说话_连贯 未用 LM；反证=若拔掉 LLM 后重复率飙升 ⇒ 外挂成了拐杖（不接受）；代价：Qwen1.5B 约 3–4GB 显存/0.5–2s 每段（未测），E 路线 CPU ms 级、无 GPU。

## §5 越宪登记 + 私有假设 + 大白话

**越宪登记**：仅 T4 的 L/M 方案越 C1/C10/C13；记录 `模型名/权重哈希/种子/温度`；只作语言层对照，不改 AHI4 主线断言；M 方案以「可拔」为验收前提。
