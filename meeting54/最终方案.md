# meeting54 · 最终方案：语言底层重建（检索式 → 生成式）

> 依据：四队 R1（红 114 / 蓝 100 / 绿 103 / 黄 114 行）＋ 主控裁决 ＋ 实测 `实施/产物/判据_语言结果.json`。
> **越宪实验**：所有者 2026-10-18 授权可破 C1/C9/C10/C13/C14；本方案不混入 AHI4 主线宣称；外挂输出一律标来源。

---

## 0. 一句话

**重复不是身份受限，是语言层一直是「选句子」而不是「生成句子」**；修复 = 换生成式语言核（状态/记忆条件 + 工作记忆去重），并用「重复 ∧ 状态相关 ∧ F5 ∧ 结构」四联合取判据。本轮用本地 Qwen2.5-1.5B 做**越宪对照**，旧层重复 69–96% → 新层 0–9%。

---

## 1. 诊断（实测）

| 结论 | 数 |
|---|---|
| 旧层=检索式选句，池 14–37 句 | 红队按 `说话_连贯.py:157-176` 36/36 段逐字复现；逐句出自池 100% |
| 跨段重复句率（旧） | 洛 0.92 / MOSS 0.96 / 日记 0.69（主控 12 段口径） |
| 三条解释排序 | 池小=主因；选句机制=第二因（相邻段句集重叠 0.467）；**身份受限=排除**（`说()` 不读人设） |
| 换大池 | 数学上可刷重复率（P=65,309,N=2000→1.5%），但语料自身 86% 重复、N=10万回到 48.9% ⇒ 不是解 |
| 生成器 | `字符LM`/`候选()`/`选种子()` 已写但是**死代码**；`流式()` 只把已选串摊开 |
| 判据 | 旧判据无跨段重复阈值、S5 恒真 ⇒ 系统被奖励去背句子 |

## 2. 新架构（三层，主路线 P0 + 对照 P1）

```
AHI 核（V5：自我态/世界态/内心）
        │  状态摘要 + 角色记忆（外源，带来源）
        ▼
语义/记忆层：角色包（人设/记忆/词） → 状态选内容（不是选整句）
        ▼
生成核（P0 主路线，零越宪）：
   字符级自回归 LM（上下文窗口 5 字，计数回退）
   + 复述抑制（最近 K 段 n-gram 降权）
   + 状态条件（o用/内心 → 条件向量）
   + 工作记忆去重（已说句/短语压制）
        ▼
语用层：受众/场景/长度/标点（2–6 句、句末标点）
        ▼
输出：连续一段话（逐 token 流式，与拍钟解耦）
```

**P1 越宪对照（本轮实测用）**：AHI 核状态/记忆 → 条件 prompt → `Qwen2.5-1.5B-Instruct` 生成；每条标 `qwen@权重sha256/T/seed`；**只作上限对照与过渡**，不作终点。
**P2 自研可用 LLM**：算不起·数据约束（5.3M tokens vs 需 2B，缺 376×）。
**P3 RWKV7-1.5B**：长时备选（状态 12.2MB O(1)；LoRA 54–87min/epoch）。

---

## 3. 判据（四联主判，禁止单指标）

1. 跨段重复句率 ≤0.10
2. distinct-2 ≥0.30
3. self-BLEU4 ≤0.35
4. 状态敏感度 ≥0.30
＋结构（2–6 句、句长 8–60、标点 1.0）、角色辨识 ≥0.80、稳定性（长时斜率 ≤0；短样本 n<100 判 UNDECIDABLE）、溯源/编造、模型/权重/种子/温度登记。
**必须失败**：固定池（重复 ≥0.90、状态敏感 0）、随机字（结构崩）、**语料检索臂**（重复可低但状态敏感 ≤0.10、F5 不成立）。

## 5. 诚实边界

1. **Qwen 是越宪技术债**：违反 C1/C10/C13；不是 AHI 自己想出来的，必须标来源；不进主线宣称；不是终点。
2. **自研生成式语言核还没接**：P0 是主路线，本轮只给了对照；下一步必须把死代码 `字符LM` 接成 `说()` 并过同一判据。
3. **语料是瓶颈**：5.3M tokens，100M 参数需 2B（缺 376×）⇒ 自研「算得起、学不出」；先蒸馏/扩语料。
4. **自我意识不做宣称**：本轮只修语言；「自我意识体现不出来」按所有者口径视为正常，不测、不主张。
5. 稳定性只测了 12 段；长时崩溃/记忆编造未测。

---

## 6. 下一步（P0 优先）

1. **接活 P0 生成器**：`说()` = 字符 LM 自回归 + 复述抑制 + 状态条件；同判据跑旧/新（零越宪）。
2. **工作记忆去重**：最近 K 段 n-gram 降权；长时 400 段重复率斜率 ≤0。
3. **P1 可拔验证**：拔掉 Qwen 后 P0 仍能说、重复率不升，才允许保留 P1。
4. **数据/蒸馏**：Qwen 词义蒸馏回 V5 `W词/C2`；或扩语料到 ≥2B tokens 再谈自研 LLM。
5. **长时稳定性**：400/2000 段、不崩、不编造记忆、来源可标。
