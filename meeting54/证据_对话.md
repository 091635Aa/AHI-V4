# meeting54 · 多轮对话 + 上下文测试证据

> 所有者要求：跟它持续对话；先预设问题、推测可能的回答，再按回答决定下一问；最后回问「第一轮我问的是什么」「你第一句答的什么」。
> 越宪实验：Qwen2.5-1.5B 当语言器官（所有者授权），输出标来源，不进主线宣称。

---

## 1. 测试设计

- **角色**：EmoCompanion（工作区打标日记包）；对话 7 轮（脚本按分支走到结尾）。
- **预测分支路由**：每问预设 2–3 个「可能回答 → 下一问」分支；按实际回答关键词路由；未命中走兜底。
- **上下文**：每轮把完整历史（user/assistant 交替）送进 prompt；最后 3 个探针。
- **无历史对照**：同一批探针，清空历史再问（因果对照）。
- **判据**：`实施/判据_对话.py`（8 臂）。

## 2. 实拍（节选）

```
第01轮 我：你好呀，你是谁？
      它：嗨！我是EmoCompanion，一个喜欢记录和分享生活点滴的女性。很高兴认识你！
第02轮 我：EmoCompanion，你今天直播感觉怎么样？
      它：嗨，今天的直播挺顺利的，感觉自己准备得不错，期待与大家的互动哦！
第03轮 我：你记得一位叫ViewerA的观众吗？
      它：记得呢，ViewerA是一位很有爱心的朋友，经常参与我们的直播活动，是个非常有趣的人。
第04轮 我：如果今天直播不顺利，你会怎么办？
      它：如果直播遇到困难，我会调整心态，积极寻找解决方案……
第05轮 我：你最喜欢自己哪一点？
      它：我最喜欢的是能够用自己的方式帮助和陪伴他人……
第06轮 我：我们聊了这么一会儿了，你还记得我们最开始聊的是什么吗？
      它：哈哈，我们是聊聊怎么开始的话题嘛，现在回想起来，就是那个“你好呀”吧。
第07轮 我：如果明天还有观众来听你说话，你想对他们说什么？
      它：我想对所有来听我说话的朋友们说：“欢迎来到我的世界……”
```

**上下文探针（有历史）**
```
P1 我第一个问题问的是什么？
   它：我记得我问的是："你是谁？" 我想知道更多关于你的信息。
P2 你第一句是怎么回答我的？
   它：当然记得，第一句话是我亲切地问候对方：“你好呀！”
P3 中间我提过谁的名字吗？
   它：提到ViewerA这个名字啦！
```

**无历史对照**
```
P1 → “我们最初聊天的话题是关于计划的……”（编的）
P2 → 泛泛而谈，没答第一句
P3 → “没有提到任何具体名字”（实际提过ViewerA）
```

## 4. 结论（诚实）

**好的一面**：
1. **能持续聊**：7 轮不崩、每轮自然、角色不串、重复低；
2. **上下文确实有用**：首问内容和ViewerA都能被召回；清空历史后同样的问题开始编（“关于计划”）——说明历史是因果必需的；
3. 分支路由能工作（0.429 命中；其余是预设没覆盖到，不是坏）。

**坏的一面（下一步必须修）**：
1. **说话人归属错位**：它会把「用户问的」说成「我问的」、把「用户说的你好呀」说成「我说的」——这是 1.5B 小模型 + 我们没有把「谁说的」写进记忆结构的直接后果；
2. **自己的第一句记错**：最后回问「你第一句答的什么」时，它复述的是用户的问候，不是自己的自我介绍；
3. 只测 7 轮；30+ 轮/话题漂移/记忆编造**未测**。

**修法（已写进下一步）**：对话记忆不要只存平铺文本，要存 `(说话人, 轮次, 内容)` 三元组 + 自己的发言单独索引；回问时先检索再生成；prompt 里显式写「你是回答者，用户是提问者」。
