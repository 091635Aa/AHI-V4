## 0. 五条结论（数字先行）

1. **「加大句池」在数学上必然失败，但能把「重复率」这个指标刷过去**：有限池 P、输出 N 句，重复率 = 1 − P(1−(1−1/P)^N)/N ⇒ 现状 **P=20、N=100 就有 80.1% 重复**；把 P 拉到语料全量 **65,309 句**，N=2000 时重复率只有 **1.5%** ⇒ **单看重复率，检索式能过**。所以判据必须是「重复率 **且** 状态相关 **且** 来源不可重放」。
2. **语料自己就是 86% 重复**：23.67MB / 8,000,160 字 / 466,729 句，**去重后只剩 65,309 句（重复句占比 0.86）** ⇒ 「把日记当池」= 把 86% 的车轱辘话搬进来。这直接证明**换池不是解**，根因是「检索」而不是「池小」。
3. **本地 Qwen2.5-1.5B 是唯一「现在就能说人话」的件**：权重 **2.94GB**，bf16 常驻显存 ≈**3.3–3.6GiB**，本机 3080 Laptop **16384MiB / 实测空 15,267MiB** ⇒ **余量 4.2×**；解码下限 **6.6ms/token**（2.94GB÷448GB/s），实测 fp16 稠密 **36.21 TFLOPS** ⇒ 30–50 token 的句子 **0.3–0.7s** [推算]。
4. **自研小模型「算得起但学不出」——瓶颈是数据不是算力**：语料仅 **≈5.3M tokens**（8.0M 字÷1.5），而 100M 参数按 Chinchilla 需 **2B tokens ⇒ 缺口 376×**；10M 参数 char 级模型 1 epoch 只要 **8.9s**（算力便宜到忽略），但它不会说中文 ⇒ **只能当玩具对照，不能当语言器官**。
5. **RWKV7-1.5B 的价值在「状态常驻」不在「质量」**：权重 2,913.9MB，**会话状态仅 12.2MB 且 O(1) 不随轮次涨**（Qwen 的 KV 则 **≈28.7KB/token × 28 层**，4k 上下文 112MB、16k 459MB）；但 LoRA 一 epoch **54–87min**（理想 21.7min）[推算]，且中文指令质量须先证明 ≥Qwen 的 0.7 倍。

## 1. T1 · 「加大句池」上界证明（回答：为什么换池不解决）

**四件套**
- **主张**：在**检索/选句**架构下，重复率是池大的函数、与「说话是否关于当下」无关；且 **固定 P 时 N→∞ 重复率→100%**。「把池换大」最多把车轱辘推迟到第 P 句。
- **证据**：公式（均匀独立抽取）`重复率(N,P) = 1 − P(1−(1−1/P)^N)/N`；代入本机实测 [实测] 语料 **去重句 65,309**：
  | P（池） | N=100 | N=2,000 | N=100,000 |
  |---|---|---|---|
  | **20（现状 8–20）[实测]** | **80.1%** | **99.0%** | 100% |
  | 2,000 | 4.9% | 36.8% | 86.2% |
  | **65,309（语料全量）** | 0.08% | **1.5%** | **48.9%** |
  ⇒ ①现状 100 句就 80% 重复，与「池小」完全吻合；②换到语料全量确能把 2000 句压到 1.5%——**所以这个指标会被换池刷过**；③即便洗满语料，10 万句仍回到 48.9%，且**语料自身重复率 86%**（466,729 句→65,309 句）⇒ 长期就是「背日记」。
- **反证（必须失败对照）**：**「语料检索臂」**——从 65,309 句里按状态关键词检索（不改架构）。该臂**预期重复率 ≤2%（过线）**，但**预期状态相关性 ≤0.10、且清空经历后输出不变（F5 可重放）**。**若该臂同时过了状态相关与 F5 ⇒ 我们整节结论作废**（说明检索式就够了，不需要生成式）。
- **代价**：65,309 句入库 = 65,309×17.1 字×3B ≈ **3.4MB**（int32 索引另 <1MB）[推算]；检索 1 次 O(P·D) 或倒排 O(log P) ⇒ **<1ms**；**成本几乎为零 ⇒ 所以不能用成本当挡箭牌**。

> **给主控的一句**：T1 判据的**主指标不能是重复率**（可被换池刷过），必须是 **重复率 + 状态相关（置换状态改文本 ≥0.30）+ F5（清空经历掉分 ≥0.10）三件合取**，且**必须带「语料检索臂」当 must-fail**。

## 2. T3 · LLM 采样下的稳定性/确定性怎么测（+ 资源五元组）

**四件套**
- **主张**：LLM 路径的「确定性」只有四档，必须**分档报**，不能笼统说「可复现」：**A 贪心+单流+确定性开关**（同进程两趟应逐位同）、**B 固定 seed+T=0**（≡A）、**C 固定 seed+T>0 批=1**（单进程可复现）、**D 无 seed 或批>1**（不可复现）。**越宪后 C13 本来就不是硬约束，但"同一句话每次都不一样"会让"自我感/人格"不可测** ⇒ 仍要给 A 档并单列差异。
- **证据**：四档的实现条件——`torch.use_deterministic_algorithms(True)`、`CUBLAS_WORKSPACE_CONFIG=:4096:8`、`torch.Generator` 显式传入、batch=1、固定 `CUDA_VISIBLE_DEVICES`；已知风险：bf16 累加序 + 原子 kernel 会让**跨进程/跨驱动**不同，**同进程通常同**（[未验证假设]，本机未跑生成 ⇒ **未测**）。
- **反证 / 必须失败对照**：①**无 seed + T=0.7 臂必须 <100% 逐位同**（若也 100% 同 ⇒ 采样没生效，判据无效）；②**T=0.7+seed 两趟若 <99% 同** ⇒ 判「C 档不成立」，只能退 A 档；③**长时稳定性**：连续 2000 轮，**重复率每 200 轮斜率 ≥+0.02/200轮** 或**记忆编造率 ≥5%（与角色包冲突）** ⇒ 判「崩」。
- **资源五元组（必须按这个报，缺一判 VOID）**：
  | 口径 | Qwen2.5-1.5B 预算 | 标记 |
  |---|---|---|
  | 权重常驻（device allocated） | **2.94GB**（bf16，实测文件 2,944.44MB） | [实测] |
  | KV/上下文 | **≈28.7KB/token**（28 层×2 KV头×128×2×2B）⇒ 4k **112MB**、16k **459MB** | [推算] |
  | device 峰值 | 3.3–3.6GiB（权重+KV+激活） | [推算] |
  | host WS/commit/RSS | 未测（LLM 路径 host 侧主要是权重映射，mmap 口径另记） | 未测 |
  | 延迟 | 6.6ms/token 下限、9–13ms 实际；30–50 token 句 = **0.3–0.7s** | [推算] |
  | 并发实例上限 | **≤4**（3.3GiB×4=13.2 ≤ 15.27GiB 空闲；5 份破） | [推算] |

## 3. T4 · 三路线对账（本队主责）

| 路线 | 体积/显存 [实测/推算] | 延迟/吞吐 | 训练代价 | 确定性 | 判 |
|---|---|---|---|---|---|
| **(a) Qwen2.5-1.5B-Instruct** | 权重 **2,944.44MB**；bf16 常驻 **3.3–3.6GiB**（余量 **4.2×**） | **6.6ms/token** 下限 / 9–13ms 实际 ⇒ 30–50 tok = **0.3–0.7s**；≈75–110 tok/s | 无需训练（可直接用）；LoRA 可选：1 epoch **54–87min** | A 档可用；C 档需 Generator+批=1 | **能跑，首选** |
| **(b) RWKV7-1.5B + EmoCompanion LoRA** | 权重 **2,913.9MB**；**状态 12.2MB 常驻、O(1) 不随轮次涨** | O(1)/token（无 KV 增长）⇒ 长时更稳 | **LoRA 1 epoch 54–87min**（理想 21.7min）；2–4h 可出可用件 | RNN 式解码更易复现 | **能跑，长时备选** |

**四件套（T4）**
- **主张**：三路线里**只有 (a) 现在就能说人话**；(c) 不是算力不够而是**数据差 376×**，不可当语言器官；(b) 只在「长时常驻/O(1) 状态」场景值得，且必须先证明中文质量 ≥Qwen 的 0.7 倍。
- **证据**：上表（[实测] 权重 2,944.44/2,913.9MB、空闲显存 15,267MiB、fp16 36.21 TFLOPS；[推算] 3.3–3.6GiB、0.3–0.7s、376×、54–87min/epoch、28.7KB/token）。
- **反证（必须失败对照）**：若 (c) 的 10M 模型在 **5.3M tokens 上训练到**「留出 200 句重复率 ≤5% **且** 状态敏感度 ≥0.30 **且** 人工可读率 ≥0.8」，则本队「学不出」结论被推翻；若 (b) 在**同一批 200 句**上中文可读率 ≥0.7×(a)，则推荐顺序须改写为 b>a。
- **代价**：见下表「能跑/算不起」——首选路线单实验 **≈2min**，长时稳定性 **≈17min 独占**，LoRA 出可用件 **2–4h 独占**。

**「能跑」清单（含预算）**：①Qwen bf16 单实例（3.3–3.6GiB，余 4.2×）②Qwen 贪心 20×40token 两趟 **≈35s**（含装载 8–15s）③RWKV 推理 + 12.2MB 状态（常驻不涨）④LoRA 1–3 epoch（**2–4h 独占**）⑤自研 10M char 玩具（9s/epoch，**只作对照**）。
**「算不起」清单**：①**自研 ≥100M 到可用**——不是钱，是**数据缺 376×**（5.3M vs 2B tokens）⇒ 判「算不起·数据约束」②**并发 >4 实例**（3.3GiB×5=16.5 > 15.27GiB）③**CPU fp32 回退**（5.88GB RAM > 当时空闲 4.3GB）⇒ 只能 Q4 GGUF 量化，约 8–15 tok/s、单句 2–4s **[未验证]** ④**2000 轮 × 3 路线 × 2 趟** = **102min 独占**（能跑但要排期）⑤**跨硬件两趟逐位同**（越宪后不作主张）⑥9 种子 × 全 prompt 集（贪心不需要种子；仅采样臂 ×3 种子即可）。

## 4. 最小可判实验预算（可立即跑）

**一个最该先做的实验：Qwen 基线一页纸（≈2min）**
- **输入**：从 V5 状态/角色包生成 **20 条条件 prompt**（状态向量→自然语言条件，冻结模板）；种子 **54001–54003**；温度 **0（贪心）**、T=0.7+seed、T=0.7 无 seed 三条件。
- **操作**：单实例 bf16、batch=1、`use_deterministic_algorithms`、每条件 20 prompt × ≤48 token；两趟（独立进程）。
- **观测**：①p50/p95 单句延迟 ②device peak（`max_memory_allocated` + `mem_get_info`）③两趟逐位同率 ④distinct-1/2、重复句率 ⑤**状态敏感度**（置换状态向量后正文变化率）⑥**来源**（每条输出标 `qwen@sha256:dd924a11…/T/seed`）。
- **阈值**：贪心两趟逐位同率 **≥0.99**；T=0.7 无 seed **必须 <1.0**；状态敏感度 **≥0.30**；重复句率 **≤5%**（20 句太短，用 200 句版）。
- **必须失败对照**：**「语料检索臂」**（从 65,309 句按关键词抽）⇒ 预期重复率 ≤2% 但**状态敏感度 ≤0.10、清空经历后不变**；若它两项都过 ⇒ 生成式路线不必要，本方案作废。
- **成本**：装载 8–15s + 3 条件×2 趟×20 句×0.7s ≈ **2min**（≪30s/单探针的上限是"单次生成"，整体一次实验 2min 可接受；超则拆两次）。长时稳定性（2000 轮）另算 **≈17min 独占**。

## 6. 私有假设登记

1. **「重复」以句级去重率为主指标**（句号切分、去空白）；若主控改用 char-ngram/distinct-n，我 §1 的公式与表需重算（P 会变小、重复率更高）。
2. **令牌数按 1.5 字/token 估**（Qwen 中文）；若实测 tokenizer 后是 2 字/token，则 5.3M→4M tokens，数据缺口从 376× 变 500×，结论不变。
3. **`448GB/s` 带宽按 3080 Laptop 规格**；实测未测带宽，延迟为下限估计，真值只会更慢。
4. **CPU 回退只考虑量化**（fp32 5.88GB 超出当时可用内存）；Q4 速度 8–15 tok/s 是 [未验证] 类比，**未跑**。
5. **越宪 ≠ 主线**：本队所有数字归 `meeting54`，不进 meeting53 的任何宣称。

**大白话**：现在的"说话"是从一个小抽屉里挑句子，抽屉只有二十句，说一百句就有八十句重复；就算把整个日记（六万五千句不重复）塞进抽屉，也能把重复率压到 1.5%——**所以"重复率"这个指标会被"换大抽屉"骗过去**，得同时看"说的内容跟当下状态有没有关系"。真正能说人话的是本地那个 29 亿字节的 Qwen，它占 3 点几个 G 显存、说一句不到一秒，本机装得下四份。自己从零训一个不行——我们只有 530 万个词的料，而训一个像样的要 20 亿词的料，差 376 倍，这不是钱的问题。所以推荐：**大脑还是 AHI，只把"嘴"临时换成 Qwen，并且每句话都标来源**，同时定好把词义慢慢搬回自己家的路线。
