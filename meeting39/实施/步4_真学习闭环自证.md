## 2. 机制：ε_self 怎么"改自己"（与 κd 同构，零新超参）

**唯一合法写入口 = 既有 `内生偏置 b[]`**（`synthesis.py:519-545`）。本步做法：

- `顶覆盖_综合体L` 在**构造后**把 `self.drv`（既有 `内生驱动器`，meeting17）**状态原样搬入**
  `驱动_ε`——**不改 synthesis 一行**；关时 `self.drv` 保持原类 ⇒ 逐位恒等。
- `驱动_ε.偏置()` 在既有 novelty 偏置上**再加一项**：

  ```
  项 = κ_ε · max(0, ε_self(t−1) − ε_slow(t−1))          # 高于自身慢基线才算"异常"
  b[1] += 项 · ε同构系数      # 提问位→停下想/反刍（与 κd 同构）
  b[3] += 项 · ε同构系数      # 转移话题位→联想检索（与 κd 同构）
  ```

- **零人挑阈值**（专家01 §3.3）：门限 = ε_self **自身的慢 EMA**（`α=ALPHA_SLOW=0.005`，与
  `内生驱动器` 同款），"高于自己平时的水平才算异常"——**自归一**，不引入 0.8/0.5 类常数。
- **零新超参**：增益 `κ_ε=KAPPA=50.0` 复用 `内生驱动器` 既有预注册常数（ε_self∈[0,2] 与 ê 同量纲）；
  加项系数 `0.6` 与 `synthesis._引擎步` 的 κd 加项**同构**（非新数值）。
- **时间因果**：`偏置()` 只消费 **t−1 及之前** 的 ε（吸收发生在"本拍动作选择完成后"，同 `内生驱动器`
  纪律：先偏置后动作，可对账）。

**记忆 ≠ 学习（物理分离）**：记忆 = `codec._段`（记着）；学习 = ĝ 参数 + ε史（变会）。
`驱动_ε.ε史` 与 `自模型.迹` 均为**独立存储**，本步**不写 `codec._段` 一个字节**（D10 已证）。

## 4. ⚠ 诚实边界（必须保留的判据不对称性）

- **A4 的 sham 取"零异常"而非"随机注入"**：随机 ε 经 `max(0, ε−慢基线)` 后**仍含正偏置均值**
  （实测分化度 0.2500，已在 JSON 如实登记）——故随机**不是**有效 sham。有效 sham 必须是
  "**有 ε 信号但不高于自身基线**"（项≡0）。这条不对称性正面证明：**分化来自 ε 的"自指结构"
  （高于自己的平时水平），不是"有信号注入"**。
- 本步只证明 ε_self **能**驱动行为（A4）且与记忆**分离**（A3）；**不声称**"对话质量提升"——
  那需 §5 判据（J5 留出任务）另立，当前无结论。
- `κ_ε` 取 `KAPPA`（与既有 novelty 偏置同量级）。**未**做增益扫参；若后续实测发现饱和/退化，
  按"以实测为准"在其上修订（登记为结构事件），不在此处预先宣称最优。
