## 2. 机制（判据 = 动力学形态，非阈值）

| 设计源（专家01 §4.2 / 纪要 §2） | 本步落地 | 位置 |
|---|---|---|
| 顿悟 = **自模型失配的一阶相变**（形态，非单点值） | (a) **失配峰→回落**：前窗 ε 极差 > 后窗极差 ∧ 后窗 ε 均值 < 前窗均值 | `内核_顿悟涌现.py:140` |
| 内部状态重构 | (b) **主导站固化**：后窗「主导站占比」> 前窗占比 | `:141` |
| 后续变稳 | (c) **预测变稳**：后窗 ε 方差 < 前窗方差 | `:142` |
| 三者**同拍共现** ⇒ 一条顿悟事件（可失败、不恒真） | `if a and b and c: return dict(...)` | `:143-151` |
| 去抖 = 结构规则（非时间阈值） | 事件后 `窗`(=12) 拍内抑制（滑窗长度，非判据阈值） | `:117` |
| 以临界跃迁对齐理论① λ≈0 | F2c：以**每个事件各自的自态 z** 作轨初值估有限时间 λ，登记与临界带 `|λ|<0.05` 的接近度 | `步6_顿悟涌现自证.py:185-197` |

**零预注册阈值**：所有门限都是**窗口内比较**（极差/均值/方差/占比），无任何 `>=0.8` 式常量阈值；
`窗=12` 是结构尺度（滑窗长度 + 去抖），`λ临界容差=0.05` 仅用于 F2c **关联登记**（非本内核判据）。

⚠ **与专家01 §4.2 的一处经实测纠正的偏离**：§4.2.2 建议的「极限环换站相变 = 换站数从 0 跳到 >0」
在**真机文本态不成立**——实测引擎主导站换站率 ≈ **0.68**（近随机，无「锁死→跳增」）。故本实现把该通道
**落地为「主导站占比上升（固化）」**（可测的状态重构相变），而非沿用不成立的「锁死→跳增」。

## 4. ⚠ 关键修正 / 诚实边界（必须带到后续步）

1. **F2 只能否证、不能正面证明"真涌现"**：低 Jaccard 只**排除**「顿悟=单点常量阈值同构」这一程序性；
   **不声称**事件即"真涌现"。这是**可证伪的不对称性**，如实登记。
2. **λ 只是关联登记**：F2c 只测「事件附近有限时间 λ 与临界带（|λ|<0.05）的接近程度」，**不声称**因果
   （对齐理论① L4 的否证性质）。
3. **一处经实测纠正的偏离**（§2 末）：(b) 由「换站相变」改为「主导站固化」，因真机换站率≈0.68 近随机；
   理论① 的 T₂ itinerancy 属思核 `z` 轨迹（步3，思考态），本步不重复其测法。
4. **本步只替换顿悟判据**：`_思考一拍` 的常数 `0.45/0.6/128` 的动力学化（专家01 §4.3）**留待后续**，
   本文件不动它（避免越界、避免破 V2–V5）。
5. **事件 `z` 逐条入账本**（约 4KB/事件，仅事件拍存，非每拍）：仅供 F2c 判据；默认关，长程内存不在本步范围。
