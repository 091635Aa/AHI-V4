## 4. ⚠ 本步实测得到的**关键修正**（必须带到后续步，勿重犯）

**步1 `判活` 的「归一化方差 < 1e-3」门是 D=256 标定的，在 D=1024 单位球面上会「把活判死」。**

- 步1 该门为**合成体系 D=256** 预注册；本相空间 M=**1024 维单位球面**上，逐维方差 ~ O(1/D)
  （活着的轨迹方差 0.000695 < 1e-3 ⇒ 步1 口径误判为"塌缩"）。
- 本步改用**尺度不变**口径 `判活_轨迹`（脚本内）：**活动量 A = mean‖z_{k+1}−z_k‖**（理论① L1，
  单位球面上 ∈[0,2]，与 D 无关）∧ 站点数≥2 ∧ 相邻cos 不≈0/1。
- 复核一致性：步1 口径的 **λ 判据**（|λ|<0.05）与本步一致——主臂 λ=0.0409（临界），sham λ=−1.69
  （强收缩⇒死）。**唯有方差门是维度劫持**。

结论：**「生命性」判据须尺度不变**；步7 全量回归时须以本口径替换/并记，避免步1 门在 D≠256 上失效。
