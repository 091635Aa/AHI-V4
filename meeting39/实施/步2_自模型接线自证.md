## 3. A1/A2 真机自模型可学习性（PASS）与 ⚠ 实测修正

### 3.1 ⚠ 关键修正：**放弃"动作绑定"键**（照设计会失效，实测裁决）

专家01 §3.2 原设计键 `k_t = S_t ⊛ a_t`（动作条件化）。**离线最小二乘可达性实测**（`_诊断_自模型.py`，真机、176 拍、8 句循环）：

| 键 → 目标 | 逐维命中 | ε |
|---|---|---|
| `x_t → x_{t+1}` | **1.000** | 0.0000 |
| `S_t⊛a_t → x_{t+1}`（**原设计**） | **0.600** | **0.8000** |
| `H双极_t → H双极_{t+1}` | **1.000** | 0.0002 |
| `H双极⊛a → H双极_{t+1}` | 0.754 | 0.4914 |

**根因**：本引擎 `x_{t+1}=编码u(u_{t+1})` 由**外感输入**决定，动作 `a_t` 对未来状态是**纯噪**——绑进键后同一自态裂成多键、记忆互相抵消。
**修正**：自态取引擎**带记忆的内部态** `H双极=sign(H)`（`hdc_core.py:412/484`，1024 维母语空间态），**键 = 自态本身**（去动作绑定）。
（对齐 05 专家"不照抄设计、可学习性由实测裁决"的纪律。）
