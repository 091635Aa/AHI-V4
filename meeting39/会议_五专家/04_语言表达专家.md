## 0. 一句话裁定

现状对外说出去的三样东西，**没有一样是思想外化**：

1. **打分**：`实施/文本态.py:L156-168 _回忆()` 直接输出 `我回忆起来一段：『%s』（相似 %.2f）。`——把标量相似度**念给用户听**。这正是所有者否定的「以一个得分的形式」。
2. **日志体**：`实施/文本态.py:L141-154 _自评()` 输出 `先掂量一下自己：第 %d 拍，能量 %s，记忆 %d 段，账本 %d 条，消化债 %.2f，饱足 %.2f。`——遥测数字堆砌，是内部审计，**本不该进对外流**。
3. **复述**：`meeting31/synthesis.py::_答问`（L966-1041）最终形态是 `连接 + 归属 + 『子句』`，其中 `『子句』` 由 `_凝练`（L901-923）按关键词从记忆段里**挑出原文子句**塞进引号。它说的不是"它想说的"，是"它检索到的"。

**裁定**：出口要从 **`query → IDF 打分 → argmax 子句 → 塞引号`** 改为 **`内部思想态 S_t → 沿内在轨迹/终态装配 → 外化句序列`**；分数与阈值一律**退出对外语言**（转入思考层审计）。

## 1. 诊断（逐条亲核的源码证据）

### 诊断 A —— 出口范式 = 检索 + 打分（落地证据）

| # | 位置 | 亲核到的实情 | 为什么是「检索复述/打分选段」 |
|---|---|---|---|
| A1 | `文本态.py:L156-168 _回忆()` | `return "我回忆起来一段：『%s』（相似 %.2f）。" % (str(段)[:48], float(分))`；`分` 来自 `self.桥._检索(文, k=2)` | **把检索得分直接朗读**；内容 = 检索段截断（`段[:48]`）塞引号。**"得分形式"的字面实现。** |
| A2 | `synthesis.py:L901-923 _凝练()` | `选 = max(子句, key=lambda x: len(_关键词集(x) & q集))`——按"与 query 的关键字集交集大小"挑子句；过长再按 query 命中位开窗 | 输出仍是**原段子句**，选择依据是**query 与段的字符重叠打分**。是"打分选段"，只是从整段缩成子句（注释自称"不再整段复述"，但复述的本质——引原文——未变）。 |
| A3 | `synthesis.py:L1028-1041 _答问()` 主出口 | `引1 = self._凝练(段1, q)`；`return "%s%s『%s』。" % (连接, 归属, 引1)`；次级 `"还有一条相关的『%s』"` | 对外句 = **模板封套（连接+归属）+ 检索段子句**。实词、宾语、主要内容**全部来自检索段**，思想不参与。 |
| A4 | `synthesis.py:L966-1041` 决策 | `计 = self._应答计划(q)`；`k=计["k"]`、门 `计["门"]`；`hits = self._检索(q, k=...)`；`if s1 < 计["门"]: ...` | "说哪条/说不说"= **拿检索分与默认阈值比大小**（`dialogue_v2` th≈0.30）。整条出口链以"分"为轴。 |
| A5 | `synthesis.py:L935-952 _回执()` | `核 = max(合, key=len)`（最长实义子句，来自用户原话）；`return "「%s」——嗯，记下了。" % 核` | 陈述回执仍是**引用机**：把用户原话塞 `「」`，只是缩短。 |
| A6 | `synthesis.py:L564-617 _思考一拍()` | 作答 = 证据链拼接 `"…" + "；由此，" % (归属 + 『清洁块(段)』)`；对每段 `账引 += [k for k,(t,x) in enumerate(账本) if x==段]` | "深度思考的结果" = **检索到的段原文列表**（`『段』`）加归属词。思考的产物就是复述。 |

**小结 A**：出口链是 `query → _关键词集 → IDF 2-gram 覆盖率打分 → argmax 段 → 挑子句 → 塞引号`。整条链的驱动力是 **query 与库的打分**，不是内部状态。所有者否定的是**这条链的范式本身**。

### 诊断 B —— 数值门/打分遍布决策层（"得分"不只在表面，在决策里）

| 位置 | 亲核数值 | 作用 |
|---|---|---|
| `synthesis.py:L681-720 _检索()` | `分 = Σ idf(g)·[g∈段] / Σ idf(g)` | 检索打分主体（IDF 加权 2-gram 覆盖率）。 |
| `synthesis.py:L876-881 _应答计划()` | `k = 3 + int(round(min(max(债,0),1.5)*2))`；`门 = 阈值*(1-0.3·min(债,1))`；`体裁 = "简" if 饱>0.8 else "详"` | "看多少/多松/多长"= **调 k、调门、比 0.8**。 |
| `synthesis.py:L596-597 _思考一拍()` | `充分 >= self.充分阈值`（`充分阈值=0.45`，构造器 L122）；`充分 >= 0.6`；`思["拍数"] >= 128` | "想够了没"= **比阈值**。 |
| `synthesis.py:L1044-1059 _条件开场()` | `τ = 0.7 + 0.5·ñ`；`s.endswith("。")`、`三元命中率(s) >= 0.5`、`len 4..20` | 连接语由采样+多重阈值守卫。 |

**小结 B**：连"说多少 / 说不说 / 想够了没"都由**标量门**裁决。这正是所有者说的「以一个得分的形式」。**替代方案必须让这些标量门退出对外语言**（见 §3「零参数·自我调控」）。

### 诊断 C —— 思考层与表达层**没有真正分家**（meeting38「两流一闸」未落到出口）

- `文本态.py:L171-191 回合()`：把 `_自评()`（日志体）、`_回忆()`（含 `相似 %.2f` 得分）**先 `写它想`**，再走 `桥.步()` 产出 `响应` 排队说。
  - `写它想` 目标虽是"脑内"通道，但 `_回忆` 的"得分"与 `_自评` 的"数字堆砌"**本身就是表达层内容的材料**，且用户在界面看得到。**没有硬闸拒收"非外化句"**。
- `inner_speech.自言空间`（`inner_speech.py:L30-38 追加`、`L52-73 审计`）只存**六类内部条目**（疑问/假设/预测/复盘/计划/自评），带账本引用——**天生是"内部可审计、永不朗读"的**。但出口（`_答问`）**根本不读它**：出口只读 `_检索` 结果。→ **思考层（自言）与表达层（对外句）不共享状态**，两者是断开的两条路。
- 结论：meeting38 定的是"思考写自言、表达只放计划句"，但 meeting39 面对的现实是——**表达层把检索段当成了唯一素材**，思考层（含引擎向量态）与它对不上。

### 诊断 D —— 输出表面 = 有限模板封套（组合，非外化）

- 归属映射写死：`synthesis.py:L1022-1024` `{"用户":"你之前跟我说过","自我":"我自己记着","教材":"我从资料里读到过"}`；跨窗口 `L1026-1027 "%s那边跟我提过"`；次级 `L1040 "还有一条相关的『%s』"`。
- 变化只来自"检索到哪条段"——**句法恒定、实词来自库**。所谓"它自己的话"，实为**检索内容套进固定封套**。

**诊断总结（供其余专家引用）**：语言表达这一环的问题**不是 IDF 不准**，而是**入口错了**——出口的输入应当是**内部思想态 S_t**（引擎向量 + 相空间轨迹 + 自模型），现在是**用户 query + 库段打分**。这恰好与理论①（内在思想）已经跑通的"非传统回复通路"**错位**：AHI 有内在终态，却没用它说话。

## 2. 定义：什么是「思想 → 语言外化」

### 2.1 可操作定义

> **思想外化**：存在一个**确定性映射 Φ**，把内部思想态 `S_t` 直接送进语句装配，
> 使得每句对外文本的**取材（说什么）、长度（说多少）、确定度（多愿意认）**都能**唯一回溯到 `S_t` 的某一个可测量分量**；
> 而**用户 query 不作为检索键**——它只是**扰动 `S_t`** 的一个外部输入（`S_t` 变 → 路径变 → 句子变），不直接决定选哪条记忆。

对照现状：现状是 `句 = 封套(query→段argmax)`；外化是 `句 = Φ(S_t)`，且 `query` 只经由 `S_t` 间接影响。

**可操作化判据（定义自带可证伪点）**：
- **可回溯**：句的每个实词能指到 `S_t` 的一个分量（落点/地标/角色绑定）。
- **可分离**：把 `query` 换成**语义无关**但同样改变 `S_t` 的扰动，句子应随之变化（证明句子受 `S_t` 驱动）；把 `S_t` 固定、只改 query 的**表面**（同义改写），句子应基本稳定（证明句子不由 query 表面字面决定）。

### 2.2 思考层 / 表达层的边界（继承 meeting38「两流一闸」，本轮把闸门补硬）

| 层 | 载体 | 内容 | 是否朗读 | 本轮要求 |
|---|---|---|---|---|
| **思考层** | `inner_speech.自言空间`（六类，L30-38）＋ **内在轨迹** z_0..z_n（理论① 相空间算子 T）＋ **自模型误差** ε_self（理论② S2） | 原始遥测、账本引用、证据链、`相似 0.xx`、`能量/债` 数字、轨迹、预测误差 | **否**（可查、可审计） | **得分/阈值全部下沉到此层**：检索分、门限、k 都只做内部审计，**不再进对外句**。 |
| **表达层** | 对外流（`共存态.排队说` / 文本态对话流） | 只放**外化句**；每条携带 `支撑轨迹点(z_t)` + `支撑思考号` + `角色` | **是** | **硬闸**：不含数字遥测、不含 `相似 %.2f`、不含 `『引号段』`当主句；无 `支撑` → 拒收。 |

**"闸"的判据化**：表达层条目必须满足 `可回溯（有 z_t/思考号） ∧ 无日志体（J1 正则=0） ∧ 无得分小数`。任一不满足 → 退回思考层，不进对外流。（这一条直接消灭诊断 C 的泄漏。）

### 2.3 语言如何受内部思想状态驱动（三个内在量 → 三个语言维度）

| 语言维度 | 由哪个内部状态驱动 | 机制（零参数·连续调制，非阈值） | 依据 |
|---|---|---|---|
| **说什么**（取材） | **内在终态 e_t** → 落点/地标 | 沿 e_t 的 TopK 落点（`批相似(e_t, 码本)`），每句取"与角色绑定后解出的填充" | 理论①§五 通路①落点装配（零自回归） |
| **说多少**（长度/一口气多长） | **轨迹活跃度 A / 相位剩余** | 长度 ∝ 轨迹在地标图上**访问的不同地标数**（非退化度量，实测 27 个）；相位钟 T₃ 给节律 | 理论① T₂/T₃、L1 自维持、§五 通路②地标漫游 |
| **多愿意认**（确定/犹豫） | **自模型误差 ε_self** | ε_self 小 → 断言；ε_self 大 → 外化"我不太确定"（连续，不写"相似 0.30"） | 理论② S1/S2：`ε_self=‖ĝ(S_t,a_t)−S_{t+1}‖` 大=它预测不了自己 |

> 关键：这三个量**全部是连续内在量**，"说多少/多深/多愿认"由它们**连续塑造**，而非 `if 债>0.1`。这才落实所有者「给世界，不给限制区」。

## 3. 替代架构：从内部思想状态外化（纯 HDC · 零梯度 · 确定性 · 顶覆盖）

### 3.0 约束与接口位置（C14 不破既有）

- **不动基链**：`_检索`（L681-720）、`_引擎步`（L519-545）、编码器/记忆内核**一行不改**。
- **顶覆盖**：新增「**思想外化器**」`thinking_to_speech.py`（新文件），在 **`synthesis.py` 顶**（`_凝练/_回执/_答问` 调用点处）覆盖出口形态——与 meeting38"顶覆盖、基链不动"同律。
- **复用既有 HDC 原语（函数名级）**：
  - `meeting38/共存态.py::编码器`：`字码`(L88)、`文本码`(L96)、`特征码`(L106)、`绑`(L121)、`束`(L131)、`相似`(L140)、`批相似`(L147)。
  - `meeting28/lang_codec.py`：`编码`(L53)、`注册段`(L69)、`解码`(L85)（字符 bigram 位置绑定，确定性）。
  - `meeting38/实施/fsw_kernel.py`：`束`(L57)、`绑`(L67)、`相似`(L74)（长时库寻址；粗码 D_C=1024 恒定）。
  - `meeting31/inner_speech.py::自言空间`：`追加`(L30)、`审计`(L52)——思考层存储与审计原样复用。
  - `meeting28/gen_lm.py` / `dialogue_v4.生成连接`(L51)：**仅供连接/语气词**（不承担主句）。

### 3.1 思想态 S_t 的装配（外部只喂"内在量"，不喂 query）

```
S_t = 束( [ 引擎拍向量 最近候选ê , 感官输入向量 , 上一拍轨迹点 z_{t-1} ] )   # 1024 双极超向量
      │                                         ├─ 来源: synthesis._吃(L514-516) 最近候选ê
      │                                         ├─ 来源: 感知向量 span (codec.编码)
      │                                         └─ 来源: 理论① 相空间算子 T 的当前轨迹点
      └─ ε_self = ‖ĝ(S_t, a_t) − S_{t+1}‖        # 理论② S1：自预测误差（无标签、无外部奖励）
      └─ A      = 尾窗轨迹活跃量（或极限环相位剩余）  # 理论① L1/L2：说多少的依据
```

- `ĝ` 沿用理论② S1 的**线性自模型**（最小二乘闭式/增量，AUC=1.0 已证）；输入必须是**丰富状态**（器官/引擎向量，≥256 维），**不得**用 5 维摘要（理论② §4.2：ELD 5 维 AUC=0.5263=瞎猜）。
- **不引入任何可训练权重、无 attention/QKV/softmax**；`ĝ` 的更新是 `ε_self` 驱动的自监督，符合 C1/C10/C13。

### 3.2 外化两条通路（直接搬用理论①，替换"打分选段"）

**通路① 落点装配**（对应理论①§五·通路①）：
```
落点 = 码本[ argsort( -批相似(S_t, 码本) )[:K] ]     # 码本 = 记忆段/开放域行的编码
                                                        # 检索键 = S_t（内在终态），不是 query
```
- 与现状的**唯一但根本**差别：键从 `query`（`_检索` 的 IDF）换成 `S_t`（引擎内在终态）。
- 落点**只做取材**，**不直接朗读**（← 这是与现状 A1/A3 的分水岭）。

**通路② 地标漫游**（对应理论①§五·通路②）：
```
z_0..z_n = 沿内在轨迹迭代算子 T(S_t)        # T₂ 自排斥 itinerancy：非周期、A≈0.63、换站 62/128
每拍: ℓ_t = 地标码本[ argmax 批相似(z_t, 地标码本) ]   # 沿轨迹逐步取语义最近邻地标
```
- **外化长度/节律**由轨迹（或 T₃ 相位钟 p=32）给出——**一口气说多长有了内在依据**（呼应置顶目标"1,000~100,000 字"：长度由轨迹非退化访问展开，而非外部阈值）。

### 3.3 外化装配（替换 `_凝练` / `_回执` / `_答问` 的输出形态）

**核心手法：角色绑定（role⊗filler）——"这是我回忆的 / 这是我猜的 / 这是我确信的"作为角色原子。**

```
R_回忆 = 编码器.文本码("回忆")        # 角色原子（固定，非人设权重表）
R_猜   = 编码器.文本码("猜想")
R_确信 = 编码器.文本码("确信")
角色码 = 束([ R_role ⊙ ℓ码 for ℓ in 落点/地标序列 ])     # ⊙ = 编码器.绑(L121)，自逆可解绑
```
外化一个句子：
1. **取填充**：从落点/地标 ℓ（取材，见 3.2）解出的实义词——不再是"与 query 交集最大的子句"，而是"构成 S_t 的那批落点的语义核心"。
2. **定角色**：由驱动量选角色原子（`ε_self` 小→`R_确信`；`ε_self` 大→`R_猜`/`R_回忆`）——**这是"多愿意认"的直接外化，取代 `相似 0.30`**。
3. **定语气/连接**：`gen_lm`/`生成连接` 仅提供连接词（保留 meeting38 §3.1 分工铁律：骨架锁句法、检索填实词、状态定语气）。
4. **可回溯**：句条目携带 `支撑轨迹点 z_t`、`支撑思考号`（`inner_speech.追加` 返回号）、`角色`。

**示例（机制，非承诺效果）**：
- 现状（诊断 A1/A3）：`我回忆起来一段：『…原文子句…』（相似 0.42）。` / `你之前跟我说过『…子句…』。`
- 外化：`我想起你提过的那个东西——它这会儿在我心里很沉。` / `我不敢咬定，可我好像在哪见过它。`
  —— 取材来自 `S_t` 的落点，角色来自 `ε_self`，**没有分数、没有原文引号、没有测试数字**。

## 4. 可失败判据（均给出量化口径 + sham/对照）

> 判据在**对外流**与**思考流**分别取样。建议实现为 `言语外化自检.py`（新文件，可选；不改既有文件）。

### J1 无日志体（沿用 meeting38 J1，用户明确讨厌项）
- **检测**：对外句跑正则 `r"眼前\s*\d+\s*件|第\s*\d+\s*拍|能量\s*[\d.]+|消化债\s*[\d.]+|饱足\s*[\d.]+|记忆\s*\d+\s*段|相似\s*[\d.]+"`。
- **口径**：命中数 / 对外句数 **== 0**。
- **能真失败**：现状 `文本态.py:_回忆/_自评`（L141-168）**必命中**（"相似 %.2f""能量…债…饱足…"）→ 现状 J1≈1.0 **必失败**；外化+下沉后应为 0。最硬回归闸。

### J2 复述率（替代"检索复述"的核心判据）
- **检测**：对外句与（其可回溯的）落点/检索段求**最长公共子串长度 / 句长**；窗口均值 `r_rec`。
- **口径**：`r_rec ≤ 0.5`。
- **sham 区分**：同输入跑**旧路径**（`_凝练`+引号，L901-923/L1028-1041）→ `r_rec` 显著更高（≥0.8）→ 判据能**区分范式**，不是恒过。

### J3 模板率（消灭"固定封套"）
- **检测**：抹掉句子实词位（保留骨架/连接），若多条对外句归一化后**同串** → 计入模板句；`r_tpl = 模板句/总句`。
- **口径**：`r_tpl ≤ 0.5`。
- **能真失败**：若外化退化成只剩 `归属+『段』`（现状 L1023-1040 的封套）→ `r_tpl→1` → 失败。

### J4 唯一率（长跑不复读）
- **检测**：窗口 W=20 内句归一化（去标点/连接词）后众数占比 `r_top`；相邻全等次数 `n_adj`。
- **口径**：`r_top ≤ 0.5` 且 `n_adj ≤ 1`。 **能真失败**：关掉轨迹/角色调制 → 长跑 `r_top→1`。

### J5 引用真实率（沿用 meeting38 J5，硬 1.0）
- **检测**：`inner_speech.审计(账本镜像)`（L52-73）。
- **口径**：`真实率 == 1.0`（违规=0）且思考条数 > 0。
- **能真失败**：任一句外化的 `支撑思考号` 无引用/摘录不符 → 违规 > 0 → 失败（虚假自言=FAIL，#242 规格）。

### J6 思想-表达一致率（本席新增，验"是不是它自己想说的"）
- **检测**：对外句的落点/地标集合 与 该拍 `S_t` 的 TopK 落点集合求 Jaccard；`r_align`。
- **口径**：`r_align ≥ 门`（建议先测基线再定门；**不得**由人拍一个数）。
- **sham 对照（能真失败）**：① 把 `S_t` 换成**随机向量**重跑 → `r_align` 必须骤降（证明句子真由 `S_t` 驱动）；② 把 `S_t` 固定、只改 query 表面（同义改写）→ 句子应基本稳定（证明句子不由 query 字面决定）。用理论① 已测的"随输入变化"（三输入终态余弦 0.80/−0.17/−0.15，§四）作"`S_t` 承载输入差异"的既有对照。

### J7（附加）确定性/可复现（C13）
- **检测**：同 seed 同事件序列重放，对外句**逐位一致**（复用 `synthesis` 事件重放式持久化口径）。
- **能真失败**：任何引入非确定性（未 seed 的 rng / GPU 浮点扩散）→ 不一致 → 失败。

> **全部判据的"能真失败"证据**已在各条给出；其中 J1 在**现状代码上实测必然失败**（诊断 A/C），这是本轮最锋利的回归闸。

## 5. 诚实边界（必须如实登记）

1. **语言表面仍是 HDC 装配，不是生成式理解。** 外化句的取材来自 `批相似` 落点、句法由角色绑定/骨架锁定、连接词由计数 LM 提供。它**不懂**"回忆"的含义——它只是把 `S_t` 的落点按角色绑定再套进句子。**"外化"是"由内部状态决定取材与形态"，不是"产生了语义新意"。**
2. **落点装配的语义相关性偏低（既有实测，不可夸大）。** 理论① §六-4 实测 TopK 余弦仅 **0.17–0.58**，原因是语义池同质 + 在末层残差空间检索。本方案**不承诺**外化句比现状"更相关"，只承诺**范式从"打分选段"变为"内在状态外化"**，并把相关性作为后续独立课题。
3. **器官/引擎向量跨运行不确定（理论① §六-1：同脚本两次运行 `cos(感受,记忆)`=0.9798/0.9908）。** 故外化结果**必须固定种子**才可复现（C13）；跨运行参数不可复用。
4. **"深度"仍是轨迹层面的。** 轨迹的 `λ≈0` 临界性、`A≈0.63`、换站 62/128 是**动力学**意义上的"活"，**不等于**语义深度/顿悟（顿悟见 02 深度思考专家；学习见 01；本席只负责出口）。
5. **自模型 ε_self 的可判别性来自理论② 的线性自模型实验（AUC=1.0），但那是离线重实现**（理论②§附录：未做端到端运行时）。落地时须在**本生命自己的状态史**上重测，不得直接引用 1.0。
6. **超长文本（1k–100k 字）不承诺。** 置顶 §5 已定"本轮不承诺"；本方案只给"长度由轨迹非退化展开驱动"的**机制方向**（3.2 通路②），**未验证**逐句拼接在 10^4~10^5 字尺度上是否退化/复读。
7. **未解决项（继承 meeting38 §6）**：同义/近义（"宠物↔猫"）受 #221 字符集重叠局限，本方案不声称解决；`声带/嘴` 分层沿用既有降级路径，不改并发骨架。
8. **不引入 LLM 的承诺**：全链路无 attention/QKV/softmax/Transformer；严禁为"更自然"引入预训练语言模型或神经 TTS。
