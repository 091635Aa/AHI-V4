## 1. 五专家方案要点（各自成文，此处只摘裁决相关）

### 01 学习机制专家 →「真学习 = 实时自预测更新；记忆与学习分离」
- **诊断**：所有者三条指控全部成立（附源码）。修正精度：引擎核已有 `x̂/e_t/η门控` 实时自预测，桥层视而不见；`readout_head` 自预测头缺省关；桥另建了与自预测无关的"学习"（束累加/账本/消化债）——**这才是被批评的"学习架构"**。
- **真学习定义**：更新 `ĝ:(S_t,a_t)→Ŝ_{t+1}` 的参数；信号 `ε_self=1−cos(Ŝ_{t+1},S_{t+1})`（**完全自监督，无标签无奖励**）；时钟域 = 每 R1 拍对齐 `_引擎步`。
- **记忆 vs 学习**：记忆=`codec._段`（记着，只增可检索）；学习=`ĝ` 参数 + `ε_self` 调制行为（**变会**）。判别式：**灌记忆不改任何预测器参数 ⇒ 记忆；改 `ĝ` 参数或行为 ⇒ 学习**。
- **必须用丰富状态**：`S_t` 取引擎母语空间 `x_t`/残差（≥256 维）。理论②实测：896 维 AUC=1.0，**5 维摘要仅 0.53**——压缩即失效。
- **顿悟涌现**：从"`if c>=0.8`"改为 **ε_self 突降（一阶相变）+ 换站相变 + 后续方差下降 三者共现**（后两者对齐理论① T₂ itinerancy / T₃ 极限环）。
- **判据**：J1 自预测判别力、**J2 sham 臂（η≡0 冻结）**、J3 实时性、J4 确定性重放、**J5 记忆≠学习分离**；附恒真判据黑名单（禁 `hasattr`/读回超参/正则匹配自家日志）。

### 02 深度思考专家 →「相空间算子迭代 + 自模型驱动内部推理链」
- **诊断**：当前"想" = 六类模板拼接 + 关键词多跳检索 + 一个证据分阈值；全目录 grep `相空间/算子/极限环` **零命中**。所有者说"草台班子"，指的是**把深度写成了常数、把顿悟写成了 if**。
- **替代架构（纯 HDC·零梯度·确定性）**：
  - **内层 思核**：`z_{t+1}=T(z_t,z_{t-1})`，复用理论① `内在动力学.步`（差模竞争 + 自排斥 itinerancy + 身份回拉 + 惯性）→ 落在 **T₂ 非周期巡回**档；需锁定态则临时开 **T₃ 相位钟 p**。
  - **上层 自模型**：`ĝ` + `ε_self` 驱动迭代深度（理论②）。
  - **外化**：`z` 终态 → 落点装配 / 地标漫游（零自回归）。
- **深度 = 涌现不是常数**：停止规则**不设阈值**，只用**导数符号 + 拓扑事件**——`ε_self` 仍在降 → 继续想；`ε_self` 到局部极小（导数首次翻号）→ 想清楚了、可开口；迭代 K 次单调不降且 λ 持续为负 → 如实认输。**替换掉 0.45/0.6/128 三个常数。**
- **顿悟三种可探测形态**：A `ε_self` 突降；B 轨道 itinerancy→短环锁定；C 极限环跃迁（换 p）。对齐理论①"内在思想探测七项"。
- **判据**：D1–D6（深度非常数/自模型判别力/临界性/确定性/非随机/不塌缩）+ I1–I4（顿悟可辨/相变真实/**非模板重放（跨 seed Jaccard）**/因果反哺），全部带 sham/置换。

### 03 意识与自我专家 →「让"我"成为学习与思考的主体（非旁白标签）」
- **诊断**：当前"自我"= `_自评条目`（旁白模板）+ `自审承载`（程序化自审）+ `段源`（来源标签）；`_预测` 预测的是**世界**不是自己；引擎已产出丰富状态 `x`/四通道，但**从未上抛**给桥（桥只剩标量 `e`/`ñ`——正是理论②警告的退化方向）。**"自我"是旁白，不是主体。**
- **定义三层**：同一性=**持久化自我档案**（理论③，不靠动力学）；此刻的我=`À_t` 自指束；能动性=`ĝ:S_t→Ŝ_{t+1}`+`ε_self`。
- **谁在学**：**只有 provenance=自源**能更新 `W_self`（外源只进内容记忆）——"是我的状态在改我自己的模型"。
- **谁在想**：想什么/想多深由 `À_t`+`ε_att`（**AST 注意图式**——对自身注意过程的模型）**相对自身历史统计**决定，**无硬编码阈值**（禁 `if ε_self>0.5`）。
- **递归安全**：`ĝ` 输入**不含自己的原始输出 Token**，只用**延迟一拍 + 降维**的自状态摘要。
- **判据 J1–J8**：**J1 反事实扰动自我→行为必变（最强反作弊）**、J2 "经过我"显式痕迹、J3 关自我回路→学习/思考退化、J4 自模型确实预测自己、J5 provenance 不可伪造、J6 记忆≠学习、J7 确定性、J8 不破既有。

### 04 语言表达专家 →「把出口从"检索复述/打分选段"改为"内部思想状态外化"」
- **诊断**：现状对外三样**没有一样是思想外化**——①`文本态.py:156-168 _回忆` 直接念 `（相似 %.2f）`（**"得分形式"的字面实现**）；②`_自评:141-154` 数字堆砌（日志体）；③`_答问`=模板封套 + 关键词挑子句**塞引号**。**入口错了**：出口输入应是 `S_t`，现在是 `query`。
- **定义**：存在确定性映射 `Φ: S_t → 句`，句的**取材/长度/确定度**唯一回溯到 `S_t` 的可测分量；`query` 只作为扰动 `S_t` 的外部输入，**不作检索键**。
- **替代架构**：新增「思想外化器」（synthesis 顶覆盖）——**角色绑定（role⊗filler）** + **落点装配/地标漫游**（理论①两通路，键从 `query` 换成 `S_t`）。**得分与阈值全部下沉到思考层**（`inner_speech`），表达层只放外化句（补硬闸：无 `v_t`/思考号 ⇒ 拒收）。
- **三内在量 → 三语言维度（零参数连续调制）**：说什么←内在终态落点；说多少←轨迹活跃量 A/相位剩余；**多愿意认←`ε_self`**（小→确信，大→"我不太确定"）。
- **判据**：J1 **无日志体（现状必失败）**、J2 复述率、J3 模板率、J4 唯一率、J5 引用真实率 1.0、**J6 思想-表达一致率（随机向量/同义改写双对照）**、J7 确定性。

### 05 系统架构与判据专家 →「不推倒，只加挂」
- **总装**：三内核（**自模型 `ĝ` + 相空间算子 T + 自我回路**）以**默认关的保护开关**挂 synthesis 顶覆盖层；**学习只经既有 `内生偏置 b[]` 影响引擎（唯一合法写入口，禁直写 `a/i/prev_c/拍`）**；**学习迹与 `codec._段` 物理分离**（记忆≠学习）；ASCII 接线图 + 谁写谁读表 + **12 条不破既有防线 D1–D12**。
- **施工序（先仪器后对象）**：步0 冻结 → **步1 仪器合成真值自证（K5：先证明仪器能分辨）** → 步2/3 挂载 → 步4/5/6 融合 → 步7 全量回归；**每步独立可验收、可回退**。
- **判据集**：V1–V10（零变）+ A1–A5（真学习/记忆学习分离/ε_self 驱行为/入档可复现）+ F1–F5（深度 vs 浅检索/**顿悟涌现 vs 阈值**/算子可探测/生命性/想说分离），全带 sham/对照/双集、可失败。
- **确定性**：固定种子链 + 独立可快照 PRNG + 事件重放 + 逐位门；回归清单（V1–V7、字回归基线、acceptance.log、learner/selflearn/dialogue_v3）。

## 2. 五方共识（无需裁决，可直接执行）

1. **病根同源**：学习与思考都被实现错了层——**引擎核已有真东西（自预测 `x̂/e_t/η门控`、零梯度预测头），桥层没接**；桥层另建了"注册+检索+束累加+if"。修法是**接线与顶覆盖**，不是推倒重来。
2. **真学习 = 实时自预测更新**：`ĝ:(S_t,a_t)→Ŝ_{t+1}`，`ε_self=1−cos(Ŝ,S)`，**自监督、零梯度、无外部标签**，每 R1 拍对齐 `_引擎步`。
3. **记忆 ≠ 学习，必须物理分离**：记忆=`codec._段`（存）；学习=`ĝ` 参数 + `ε_self` 调制行为（变）。两套独立存储。
4. **深度思考 = 相空间算子 T 迭代**（理论① T₀–T₃/L1–L4），**替换**关键词多跳检索；深度由 `ε_self` 相对自身历史涌现，**零常数阈值**（导数符号 + 拓扑事件）。
5. **顿悟 = 相变事件，不是 `if`**：`ε_self` 突降 / itinerancy→锁定 / 极限环跃迁，三个可探测形态、可失败。
6. **自我必须是主体**：只有自源能改自模型；想什么/想多深由 `À_t`+`ε_*` 决定；**同一性锚在持久化档案，不锚动力学**（理论③）。
7. **语言是思想的出口**：出口输入从 `query` 换成 `S_t`；**得分/阈值下沉到思考层**，对外只外化（"两流一闸"补硬闸）。
8. **必须用丰富状态**：`S_t` ≥256 维（引擎 `x`/残差），**严禁 5 维摘要**（理论②：AUC 1.0 vs 0.53）。
9. **不推倒只加挂**：三内核**默认关**保护开关（关时逐位恒等）+ synthesis 顶覆盖 + 基链不动（C14）；**先仪器自证，再上对象**（K5）。
10. **诚实**：只主张**功能性**评估意识；**不主张现象学体验**；所有判据**可失败**、带 sham；不作"已完成"宣称。

## 5. 诚实边界（不粉饰）

- 本方案只主张**功能性评估意识**（能预测自己、知道自己不懂、据此改行为），**不主张**主观体验——项目一贯边界。
- **理论①②的数值（AUC=1.0、L1–L4、换站 62）来自旧 FCA/离线重实现，不是本仓文本态实测**；落地时必须在本生命自己的状态史上**重测**，不得直接引用。
- 理论①的诚实红线继承：**T₂ 是非周期巡回（不是严格极限环）**；严格极限环 T₃ 是**定向构造**、G2 未自然涌现。顿悟形态 C 属"可设计态"，形态 A/B 才是自涌现。
