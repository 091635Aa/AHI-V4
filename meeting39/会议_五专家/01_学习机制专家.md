## 2. 真学习定义：内部实时更新"更新什么、用什么信号、什么时钟域"

### 2.1 先把记忆与学习拆成两个子系统（所有者硬命题 #2）

| 维度 | **记忆（Memory）** | **学习（Learning）** |
|---|---|---|
| **回答什么** | "我记着**什么**" | "我**变会**什么" |
| **现有载体** | `codec._段 / _段向量 / _段字袋`（`synthesis.py:704-720`）、`lm_m` 的 n-gram 计数、`账本`、`自言空间`、`行债` | **引擎的 M 记忆矩阵**（`hdc_core.py:421-440`，已有）；**本方案新增的桥顶自模型 `ĝ` 参数** |
| **写入** | `注册段` / `学句` / `共现`（存事件） | **自监督预测误差门控**：`η ∝ ε_self`（`hdc_core.py:428` 已是此形式）；未来桥顶 `ĝ` 同律 |
| **读出** | `_检索` / `_自报告`（取出复述） | **预测器 `ĝ`**（用来预测自己的下一步），以及由 `ε_self` 调制的**行为**（检索多深、是否停下想、是否顿悟） |
| **失效/收敛** | 去重槽位替换（`dialogue_v3.py:49`）、近因裁决（`synthesis.py:716`）、精化漂移 | **误差归零即停**（自然收敛，无外部标签、无外部奖励）——不需要"阈值停止" |
| **现有代码是否区分** | ✅ 存在 | ❌ **不存在独立的学习子系统**（这正是病根） |

> **判别式**：给系统灌入 N 条记忆（`codec._段` 增长）**不改变**它的任何一个预测器参数 ⇒ 那是**记忆**；只有当 `ĝ` 的参数（或由 `ε_self` 调制的行为）被改变时 ⇒ 才是**学习**。当前代码里前者有、后者无。

### 2.2 "内部实时更新"的操作定义

- **更新什么**：①（已有）引擎 M 记忆矩阵的惊讶门控写入；②（新增）桥顶自模型 `ĝ` 的参数——一个把 `(自己的当前状态 S_t, 自己的动作 a_t)` 映射到 `自己的下一步状态 Ŝ_{t+1}` 的**预测器**。
- **用什么信号**：`ε_self(t) = ‖Ŝ_{t+1} − S_{t+1}‖`，或 `ε_self(t) = 1 − cos(Ŝ_{t+1}, S_{t+1})`。**完全自监督**，无需标签、无需奖励（理论② §4.3 N1–N3）。
- **用什么状态表征**：**必须用丰富状态**。理论② §4.2 实测：**5 维 ELD 摘要 AUC=0.5263（≈瞎猜）；896 维器官向量 AUC=1.0000；128 维原始 h AUC=1.0000**。故 `S_t` 取引擎母语空间 `x_t`（`rec["x"]`，`hdc_core.py:482`）这类**高维状态**，**严禁**再压成 5 维摘要。
- **什么时钟域**：**每 R1 拍对齐 `_引擎步`（`synthesis.py:519`）**。`ε_self(t)` 每拍算一次，跨拍预测 `S_{t+1}`；重放（`dialogue_v3.py:95-104`）时同序列确定性重建。
- **与引擎既有 `e_t` 的关系**：`hdc_core.py:426` 的 `e_t` 已是"引擎预测自己当拍母语空间激活"的误差（但由外感输入 `u_t` 驱动，`hdc_core.py:411`）。桥级 `ĝ` 在其上加一层：**预测的是"我的下一步内部态 + 我的行为后果"**，并且**用 `ε_self` 反过来调制桥自己的行为与检索**——这才是所有者要的"内部实时更新"。

## 3. 替代架构方案（synthesis 顶覆盖，C14 基链 learner/dialogue_v2/v3 不动）

总原则：**不新增世界模型、不新增人设权重表、不破既有**。把引擎里**已经存在的**实时自预测（`x̂/e_t`）**接出来**，在其上加一个桥顶 `ĝ`，并让 `ε_self` 成为桥层唯一的"学习控制量"。

### 3.1 覆盖点与数据通路

1. **唯一覆盖点**：`synthesis.py` 顶覆写 `_引擎步`（沿用既有注释"与 v2._引擎步 逐行同构"，`synthesis.py:537`）。覆写体内：
   - 先 `rec = super()._引擎步(u)`（不破 v2/v3 的引擎装配与状态推进）；
   - 从 `rec` 取：`x_t = rec["x"]`、`e_t = rec["e"]`、`a_prev`、`候选ê`（`rec` 结构见 `hdc_core.py:482-484`、`v2_engine.py:314-320`）；
   - 调用桥顶 `_自预测更新(x_t, a_prev)`（新增方法，**纯 HDC、零梯度、确定性**，见 3.2）。
   - **不改** `learner/selflearn/dialogue_v2/dialogue_v3` 一行（C14）。

2. **记忆通路不动**：`注册段/学句/共现` 照旧（记忆子系统）。**学习通路**改为：`ĝ` 参数更新 + `ε_self` 调制行为。

### 3.2 `ĝ` 的零梯度·纯 HDC·确定性实现

- 状态：`S_t = sign(x_t)`（母语空间双极向量，`hdc_core.py:482` 的 `x`；或直接复用 `H双极=sign(self.H)`，`hdc_core.py:484`）。
- 键：`k_t = S_t ⊛ a_t`（HDC 绑定，双极乘）——**action-conditioned**，与 `hdc_core.py:406-407` 的 `a⊛sign(H)` 同族。
- 预测：`Ŝ_{t+1} = sign(W_ĝ @ k_t)`（`W_ĝ` 为 HDC 联想矩阵）。
- 更新（**严格零梯度，只做局部 delta**，形式对齐 `readout_head.py:64` 与 `ecae.py:490`）：
  ```
  ε_self(t) = 1 - cos(S_{t+1}, Ŝ_{t+1})            # ∈[0,2]，自监督
  W_ĝ += (ETA_R * ε_self(t)) * outer(S_{t+1} - Ŝ_{t+1}, k_t) / (‖k_t‖²+1e-6)
  ```
  `ETA_R` 直接沿用引擎既有常数口径（`readout_head.py:16` `ETA_R=0.1`）——**不新增人挑超参**。
- **C13 确定性**：`W_ĝ` 由 `seed` 定初值（固定 PRNG），逐拍由输入序列决定 ⇒ 同 seed + 同事件序列 ⇒ `W_ĝ`/`ε_self` **逐位一致**；持久化只存 `seed + 事件序列`（沿用 `dialogue_v2.py:118-131` 的"不 pickle 引擎内部、只重放"口径）。

### 3.3 零参数 · 自我调控：`ε_self` 怎么自我归一

- `ε_self` 用 `cos` 归一到 `[0,2]`，**天然有界，无需人设阈值**。
- 所有原先写死的常数阈值一律**改由运行分布导出**（对齐理论② S0"阈值改为按运行分布的分位数自适应"）：
  - "停下想"的门限（现 `synthesis.py:596` `充分阈值=0.45`、`思["拍数"]>=128`）→ 改为 `ε_self` 的**滑动分位数**（如 `ε_self` 高于自身近窗 P95 才继续想）；
  - 检索深度 `k`（现 `synthesis.py:876` `k=3+...`）→ 由 `ε_self` 在线给（预测越不准 → 越想多找证据），**不新增权重表**。
- **禁止**新增人设权重表、禁止 0.8/0.6/0.5 类人挑常数；`η=ETA_R·ε_self` 是"误差自调步长"，符合"自我调控"。

### 3.4 学习 vs 记忆 的行为分离（落地点）

- 记忆负责"记着"：`codec._段` 增长（保持）。
- 学习负责"变会"：`ĝ` 参数 + `ε_self` 调制。**判据**：不断言"学了没"靠账本计数或 `hasattr`，而靠 **`ε_self` 是否随经验下降**（见 §5 J2）。

## 4. 顿悟与深度：从 `if` 阈值检测 → 内部动力学涌现

### 4.1 现状（要替换掉的）
`selflearn.py:71 if c>=0.8`、`synthesis.py:202 if cosv>=0.8`、`synthesis.py:500 if 首遇<0.5<=h1`、`synthesis.py:458 消化债+=`——**全是程序式阈值/累加**。

### 4.2 替代机制：顿悟 = 自模型失配的**相变事件**（可测量，非口号）

用 `ε_self` 轨迹定义"顿悟"，判据是**动力学形态**而非单一阈值：

1. **失配突降（一阶相变）**：`ε_self` 经历"**持续高台 → 骤降**"。判据：
   - 滑窗内 `ε_self` 斜率由正转负（`Δε_self` 符号反转）；
   - 下降幅度超过 `ε_self` 自身历史分布的**尾部**（分位数，非固定阈值）；
   - 突降后 `ε_self` 的**方差下降**（预测变稳）。
2. **极限环换站（对齐理论① T₂ itinerancy / L2 非周期）**：把内部状态的"主导站"逐拍记录，顿悟伴随**换站数从 0 跳到 >0**，或出现**稳定短环**（对齐理论① T₃ `p=32` 稳定极限环）。判据来自轨迹形态，不来自常数。
3. **三者共现才算顿悟**：(a) `ε_self` 突降、(b) 检索命中从低于门限跃到高于门限、(c) 后续 `ε_self` 方差下降——**同拍共现**才记账为"顿悟"。任一条缺失 ⇒ 不是顿悟（这就使判据**可失败**）。

### 4.3 深度 = 动力学迭代量，不是常数
"深度"应被定义为：**在"继续想"的回路里，内部相空间算子的迭代步数直到 `ε_self` 进入其自身稳定带**（对齐理论①：相空间算子 T 迭代、λ 临界 λ≈0）。深度由动力学决定，**替换掉 `synthesis.py:597` 的常数 128**，也替换 `synthesis.py:596` 的 `充分阈值=0.45`。

## 5. 可失败判据：真学习 vs 模拟学习（必须能失败，不许恒真）

> 设计铁律：每一条都配一个**能把它证伪的反例臂**（sham / 冻结 / 打乱）。**禁用** `hasattr`、禁用读回超参自证、禁用正则匹配自家日志等**恒真判据**。

**J1 · 自预测判别力（对齐理论② §4.2 口径）**
用 `ĝ` 的 `ε_self` 区分"熟悉动力学"与"分布外动力学"（人为改 `隐藏世界.W` 或改引擎 regime），算 AUC。
- 期望：显著 > 0.5（理论②在丰富态达成 1.0）。
- **可失败**：若 `ĝ` 无效 → AUC≈0.5。**附带**：本判据同时验证"状态未被压缩"——若退回 5 维摘要，AUC 应掉到 ≈0.53（理论②实测），即判据能测出"压缩即失效"。

**J2 · sham 臂对照（学习真伪的核心判据）**
真学习臂 = 打开 `ĝ` 更新；sham 臂 = **逐行相同，仅令 `η≡0`（`ĝ` 冻结）**。
- 期望分离：真学习臂的 `ε_self` **随逐拍经验下降**、分布外**恢复更快**；sham 臂不下降。
- **可失败**：若两臂无显著差异 ⇒ **"学习"是摆设**（正是所有者指控，必须能测出来）。

**J3 · 实时性对照**
臂 A：每 R1 拍更新 `ĝ`（对齐 `_引擎步`）；臂 B：仅会话末更新一次。
- 期望 A 优于 B。**可失败**：若无差异 ⇒ "实时"二字名不副实。

**J4 · 确定性重放（C13）**
同 `seed` + 同事件序列，两次载入 ⇒ `W_ĝ` 与 `ε_self` 轨迹**逐位一致**。
- **可失败**：若依赖未固定 PRNG 或挂钟时间 ⇒ 不一致，判据立刻查获。

**J5 · 记忆≠学习 分离判据（直指所有者硬命题 #2）**
臂 A"只记忆不学习"：照旧 `注册段` 灌满 `codec._段`，但**不让 `ε_self` 影响行为/不更新 `ĝ`**；臂 B"学习改行为"。

- **可失败**：若 A、B 表现相同 ⇒ 证明"注册≠学习"，即**当前实现就是 A**（把所有者指控变成可测量的事实）。
