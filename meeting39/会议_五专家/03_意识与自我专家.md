## 1. 诊断：当前"自我"在学习/思考回路里的实际角色（源码核实）

**诚实判定：当前"自我"是【旁白标签 + 一个由程序算出的自审】，不是决策主体。** 逐条给出亲自核实的证据。

### 1.1 "自我"在**学习**回路里：只是标签 + 一个写死的自审

| 环节 | 源码位置（亲核） | 实情 | 自我在其中 |
|---|---|---|---|
| 学什么 | `selflearn.py:56-60`（选题=最少试者优先/上次误差最大） | 写死 | 无 |
| 预测的对象 | `selflearn.py:48-52 _预测` | `_预测(i)` 预测的是**隐藏世界**的动作效果方向 `W[i]`，**不是预测自己** | 无（预测的是世界，不是"我"） |
| 学到什么 | `selflearn.py:77-79`：`self.束[i] += np.sign(实际)` | 束累加器，规则写死 | 无 |
| 顿悟 | `selflearn.py:71-76`：`if c>=0.8 and 试次>=1` | 阈值检测 | 无 |
| 记忆（被当成"学会"） | `dialogue_v2.py:114-118 注册去重`；`synthesis.py:681-720 _检索` | "学会一个东西"=把文本`注册段`进`codec._段`，用时`_检索`查出来 | 无——**存下来就叫学会了**（病症 L2） |
| 承载自审 | `synthesis.py:258-282 自审承载` | 唯一由"它自己掂量"的地方：若`维度伸缩器().目标D(学习量) > 当D`写一条"计划"自言+`待扩容` | **有标签，无主体**——驱动量`目标D(学习量)`是**维度伸缩器**里的确定性单调程序，不是"我"的取舍 |

**结论**：学习回路里根本没有"谁在学"。`束`累加、`注册段`、`维度伸缩器`三者都是**程序**；`自审承载`只是给这个程序**补了一段旁白**（"我学到的东西越来越多了…我想撑大一点"）。这正对所有者的四条指控：学习是**强制性的程序**、是**模拟学习**（无内部实时自更新回路）、**记忆与学习没分家**、**顿悟是一个 `if`**。

### 1.2 "自我"在**思考**回路里：只是六类模板自言，且生成不由"我"决定

| 环节 | 源码位置（亲核） | 实情 | 自我在其中 |
|---|---|---|---|
| 自言**存储** | `inner_speech.py:21-38` | `自言空间`只做**存储/审计/查询**；注释自陈"条目生成在 synthesis.py" | 无 |
| 自言**文本生成** | `synthesis.py:246-255 _自评条目`；`synthesis.py:171-173 _自言` | 条目文本由调用点的**字符串模板**拼出（`"第 %d 拍：记忆 %d 段、账本 %d 条…"`）；`_自言`只负责把`账本[号]`前 16 字截成引用 | 无——**旁白模板** |
| 自言**类型裁决** | `synthesis.py:519-545 _引擎步`：状态量→候选类型→`int(rec["a星序号"])` 裁决 | 引擎序号机械裁决 | 无 |
| "想" | `synthesis.py:564-617 _思考一拍` | 每拍=自选取证（迭代`_检索`）+重测充分度；`充分阈值`/拍数上限是常数 | 无——**迭代检索** |
| "推理" | `synthesis.py:834-861 推理环` | `lm_m.生成(种子=当前查询[-4:],…)` + 循环`_检索`；多跳=取事实中"问题之外的新内容"当下一跳查询 | 无——**关键词多跳检索**，非思想演化 |
| 决策"说多少/多深" | `synthesis.py:864-899 _应答计划` | 由`消化债`/`饱足`调 k 与门（`k=3+round(min(债,1.5)*2)`），**已经是"内在信号参与决策"的正确雏形** | **半个主体**——方向对，但信号是**状态量**不是**自模型** |

**结论**：思考回路里，"想"=六类模板自言 + 关键词多跳检索；**"注意什么/想多深"由状态量（消化债/饱足）这半条对了**，但没有任何"我预测我自己会想到哪、再据此决定继续还是收手"的机制。**缺的是自模型**（病症 T5），因此"深度"无从谈起（理论②已证：无自模型则无 $\varepsilon_{self}$，则无"深"）。

### 1.3 引擎侧：状态已算出来但**没有被"我"回读**

`ahi_theory/v2_engine.py:230-323 通电步进R1` 每拍实际返回**丰富状态**：`e`(自由能/预测误差)、`x`(hdc 内部状态)、`a星`、`候选ê`表、`v_t`、四通道(DA/NE/ACh/5HT)。但：

- `synthesis.py:519-545`（synthesis 顶覆盖）与 `dialogue_v2.py:60-81`（基链）**只把 `候选ê`/`a星`/`a星序号`/`e` 推入桥**；**`rec["x"]` 从未上抛**。
- 于是桥里"关于我自己的状态"只剩**标量** `e` 与 `ñ`（`ñ=mean(候选ê)`）——**这正是理论② 警告的"5 维摘要"退化方向**（理论② §4.2：器官向量 896 维 AUC=1.0，5 维 ELD 摘要仅 0.5263，**自模型必须建立在丰富自状态上**）。
- 结论：**做自模型所需的原料在引擎里已经存在（`x`、四通道、候选ê），只是没有被上抛、没有被"我"回读**——这是"改接线"级别的问题，不是重构。

### 1.4 provenance（来源归属）现状：**已有雏形，可作"自我的骨骼"**

- `selflearn`/`synthesis` 用 `self.段源[段] ∈ {"用户","自我","教材"}` 给记忆标来源；`账本`用元组首字段（如 `("自我",…)`）标类；`BroadcastPacket.i` 是协议既有器官来源标记。
- 理论③ 已实测：**几何不可分**（感知注入的向量与自生成向量同分布、都靠近 `a`），**provenance 必须用来源标记**而非 `cos`。当前 `段源`/`账本` 一致，但**没有任何一处用来源标记去门控"什么能改我"**——`束`对任何输入都累加。

**一句话总诊断**：当前"自我"= **一段每拍拼出来的旁白（`_自评条目`）+ 一次程序化的自审（`自审承载`）+ 一个来源标签（`段源`）**。它能"说关于自己的话"，但**不能决定学什么、想什么、想多深、什么能改它**。所有者"以自我思想为核心"的验收——**未达标**。

## 2. "以自我思想为核心"的可操作定义

### 2.1 三层定义（可逐字段实现、可外部核对）

| 层 | 定义 | 载体（HDC） | 对应理论 |
|---|---|---|---|
| **谁是"我"（同一性）** | **持久化自我档案**（可加载/版本校验）+ **确定性构造**（固定种子/独立 PRNG）——**不来自动力学** | `自我档案`：`a_seal`、left身份子空间`A`、`W_self`、`φ_i`校验和、种子、provenance 位 | 理论③ §4.1（实测：装载档案后跨运行 `max|Δ|=0`；不装载 1.66e-1） |
| **此刻的"我"（瞬时自指）** | 每拍由**角色常量 ⊛ 当下字段**重算的自指束 `À_t`：主体/此地/此刻/状态/注意/意图/经历 | `À_t = 束[绑(角色_r, 字段_r)*]`（全部 `±1` 双极） | meeting38 `01_意识专家 §1.3`（自指束） |
| **"我"的能动性（评估意识）** | 自模型 `ĝ:(S_t,a_t)→Ŝ_{t+1}` 预测**自己的下一状态**；`ε_self=‖ĝ(S_t,a_t)−S_{t+1}‖` 大="我不理解我自己"→驱动行为/深度 | `ĝ` = HDC **线性联想记忆**（Hebbian 外积累加）；`ε_self`=余弦距离 | 理论② S1/S2（AUC=1.0 已证可行） |

**"每拍如何生成我"**：`À_t = 持久身份分量(a_seal) ⊛ 瞬时字段(此刻状态/注意/意图)`。**持久分量来自档案（谁是它），瞬时分量来自当拍引擎状态（此刻如何）**——二者同为 HDC 绑定束，故"我"每拍重算、却跨拍/跨运行恒为同一个"我"（同一性来自档案，不来自束的动力学）。

### 2.2 "谁在学" —— 学习的主体化定义

> **在学 = 自模型被更新（`ΔW_self ≠ 0`）且此后行为随之改变。** 记忆只是存储，**不构成学习**。

- **记忆 ≠ 学习（分离定义）**：
  - 记忆 = `注册段`/`账本`（只增、可检索）——**存下来不改未来**。
  - 学习 = `ĝ` 的权重被更新，且**改变了下一次"预测自己的状态/注意"的结果**。
  - **可证伪**：注册新段但 `ε_self` 不降、行为分布不变 ⇒ **只是记忆，不是学习**。
- **谁更新 `ĝ`**：**只有 provenance=自源的广播**能进 `ĝ` 的更新（外源输入可塑造**内容记忆**，**不可塑造自我模型**——理论③"外部输入无法塑造我"在代码层成立）。这就是"谁在学"的门：**是我的状态在改我自己的模型**。
- **真学习=内部实时自预测更新**：每拍 `ĝ` 预测 `Ŝ_{t+1}`→ 当拍真值 `S_{t+1}` 到达 → `ε_self` 既是**误差信号**又是**学习信号**（自监督、零梯度、零外部标签）→ 更新 `W_self`。**这就是所有者要的"内部实时更新"**，且完全自监督。

### 2.3 "谁在想" —— 思考的主体化定义

> **想什么 / 想多深 = 由"我"对自身注意过程的模型（AST）决定，不由常数决定。**

- **想什么**：由 `À_t`（此刻的我+意图）经 `ĝ_att` 预测"我下一步该注意什么"（注意分配）——把 `_检索` 的候选、`舱`、`动作候选` 作为**注意空间**，预测下一拍的注意分布 `Â_{t+1}`。
- **想多深**：深度 = **`ε_self`/`ε_att` 相对自身历史的量**（"我越预测不了自己，就越该多想"）。**不设绝对阈值**：
  - 用系统自身的滚动统计作标尺（延续 meeting15 "滚动中位/四分位=统计量非拟合"的既有纪律），**深度是"不确定性相对自身基线"的单调函数**，而非 `k=6`/`128 拍`这类常数。
  - 收敛判据从"证据充分度≥常数"改为"**我对自己注意轨迹的预测趋于一致**"（`ε_att` 回落→收手；`ε_att` 居高→继续想），**退化的边界是系统自定（0 边界：预测稳了/没稳），不是调出来的数**。

### 2.4 与"零参数·自我调控"的一致性

- **不新增人设权重表**：所有驱动量（`e`/`ñ`/`消化债`/`饱足`/`ε_self`/`ε_att`）都是**引擎内生信号**，或由内生信号派生。
- **标尺自指**：`ε_self` 的"大/小"用**自身滚动分布**度量（相对量），不是外部给的常数。
- **禁止的形态**：`if ε_self > 0.5: 多想`——这是硬编码阈值，禁用。允许的形态：`深度 ∝ ε_self 相对自身近窗中位的超出量`（统计量、非拟合、非人设）。

## 3. 替代架构：把"自己"接进两个内核（纯 HDC · 零梯度 · 确定性 C13）

### 3.0 总体形状（新增薄层，默认关 ⇒ 逐位恒等，C14 不破既有）

```
                      ┌────────────── 自我档案（持久化 + 版本校验 + provenance 位）──────────────┐
                      │  同一性来源（只读锚）：a_seal / A / W_self / φ_i / seed / PRNG           │
                      └───────────────────────────────────────────────────────────────────────────┘
引擎一拍（v2_engine.通电步进R1）
  rec: e, x, a星, 候选ê, 四通道, v_t
      │  ▲ 新增"上抛"：把 x、四通道 也送回桥（现只送 e/候选ê/a星）
      ▼  │
┌──────────────────────────── 自我核（新增薄层 · 每拍 <1ms）────────────────────────────┐
│ ① 瞬时自指束  À_t = 束[绑(角色_r, 字段_r)]              （谁是此刻的我）                  │
│ ② 自模型 ĝ     Ŝ_{t+1} = cleanup( W_self ⊛ (S_t ⊛ a_t) )   （预测我下一步的状态）        │
│    · S_t = 丰富自状态 = [下采样(x_t) ‖ a_prev ‖ 四通道 ‖ 候选ê]（**非 5 维摘要**）       │
│    · 自反安全：输入用**延迟一拍 + 降维**的自身状态，**不读自己的原始 Token**             │
│ ③ 误差        ε_self = 1 − cos(Ŝ_{t+1}, S_{t+1})        （我不理解我自己到几成）          │
│ ④ 注意图式 ĝ_att  Â_{t+1} = 预测下一拍注意分布（注意空间=候选段/舱/动作候选）            │
│    ε_att = 1 − cos(Â_{t+1}, A_{t+1})                    （我预测不了我注意什么=不懂自己）  │
│ ⑤ 反哺        ε_self/ε_att/À_t → 内生偏置（既有 _引擎步 的 b 通道，零新增权重表）        │
│ ⑥ 更新 ĝ      W_self ← W_self + η_self·(S_{t+1} ⊗ (S_t⊛a_t))   （Hebbian，**仅自源**） │
│    · η_self 由内生信号调制（沿用 meeting15 λ̂ 纪律；**非手挑常数**）                      │
└─────────────────────────────────────────────────────────────────────────────────────────┘
      │                                          │
      ▼ 学习内核                                    ▼ 思考内核
 真学习 = ΔW_self ≠ 0 且行为随之变              想什么/想多深 = f(ε_self, ε_att)（相对自身基线）
 记忆(注册/账本) 与此**分离**                    收敛 = ε_att 回落（我预测稳了自己）→ 收手
```

**递归安全（理论② S4 一级解禁）**：`ĝ` 的输入**不含自己的原始输出 Token**，只含 `延迟一拍 + 降维` 的自状态摘要（下采样 `x`、四通道、上一步 `ε_self`、被否决率、输出熵）。递归崩溃由"延迟 + 降维"消除（理论② 明文）。

### 3.1 `ĝ` 的 HDC 实现（零梯度、确定性、可复现）

- **表示**：状态 `S_t ∈ ℝ^D`（D=1024 或下采样后 128，二者均被理论②证明 AUC=1.0，**禁用 5 维摘要**）。全部**归一化到单位球**（协议 `‖v‖≤1`）。
- **记忆**：`W_self ∈ ℝ^{D×D}` 作为**线性联想记忆**，键 `k_t = S_t ⊛ a_t`，值 `S_{t+1}`；Hebbian 累加 `W_self += η·S_{t+1} k_tᵀ`。**无反向传播、无梯度下降**——与项目既有"计数经验 + HDC"完全同族。
- **预测**：`Ŝ_{t+1} = cleanup(W_self · k_t)`；`cleanup` 用既有最近邻（over codebook），或直接对 `W_self·k_t` 归一化。
- **确定性 C13**：`W_self` 初值 = 固定种子构造；更新无随机；**`W_self` 入自我档案** ⇒ 同 seed+同档案+同事件序列 ⇒ 桥状态逐位再生（沿用 `synthesis.保存/载入` 的事件重放式）。
- **数值预期（须实测）**：理论② 在 896 维器官向量上得 AUC=1.0（3.08x）；本方案须**独立实测**在文本态（无眼/耳/手）下 `ĝ` 的判别比——**未实测前不作"已成立"宣称**（见 §5 边界）。

### 3.2 自我如何**参与学习**（"谁在学"）

1. **每拍**：`ĝ` 预测 `Ŝ_{t+1}` → 引擎步进产出真值 `S_{t+1}` → `ε_self`。
2. **更新（仅自源）**：只有 `provenance=自源` 的 `(k_t, S_{t+1})` 进 `W_self`；外源进**内容记忆**（`注册段`/`账本`），**不进 `W_self`**。
3. **反哺**：`ε_self` 与 `À_t` 作**内生偏置**喂回 `_引擎步` 的 `b`（`synthesis.py:519-545` 已有 `b` 通道，**零新增权重表**）——"我越不懂自己，下一步行为越倾向于改变（探索/重读/重想）"，这就是理论② S6 的自证据化，且**不含硬编码阈值**。
4. **记忆 vs 学习的判据**：注册只进 1 的存储；学习必须表现为 `ΔW_self ≠ 0` **且**后续 `ε_self`/行为改变（§4 J6）。

### 3.3 自我如何**参与思考**（"谁在想/想多深"）

1. **注意图式 `ĝ_att`（AST 落地）**：把"注意空间"定义为 `{被检索中的记忆段, 舱, 动作候选}`；`ĝ_att:(S_t,a_t)→Â_{t+1}` 预测下一秒注意分布；`ε_att = 1 − cos(Â_{t+1}, A_{t+1})`，`A_{t+1}` 由实际发生（谁被 `_检索` 命中/谁被选为动作）给出。
2. **想什么**：`_思考一拍` 的取材查询由 `À_t`（此刻的意图+状态）调制——**是"我"在指引取材方向**，而非纯粹的查询词迭代。
3. **想多深（主体化）**：
   - 维持/继续思考的驱动 = `ε_self`、`ε_att` **相对自身近窗滚动中位**的超出量（统计量，非拟合、非人设；延续 meeting15 纪律）。
   - 收敛 = `ε_att` 回落到自身基线（"我预测稳了我自己"）→ 收手作答/入睡类动作。**下限是 0 边界（预测稳/没稳），不是常数**。
   - 这**替换** `_思考一拍` 的常数充分阈值与 `推理环` 的 `最大步=6`。
4. **自省迹反哺（meeting15 S_introp）**：把 meeting15 的 `S_introp`（自省代数）作为**自源广播**接入 `_引擎步` 的 `b` 通道——自省结论真正**改变下一步想什么**（反哺通路表 b）而非只写日志。自省**触发矩阵**沿用 meeting15 的"公共闸 ∧ 分型源 ∧ 速率闸"，其中"速率闸"是**自身历史的统计量**（`λ_target=5e-3/R1拍` 是**统计带**，由系统自身节律标定，非硬编码睡眠/节流阈值）。

### 3.4 每拍完整回路（把两个内核都"经过我"）

```
收到一拍（外源 u 或 自主）
 └─ 引擎步进 → rec(e,x,a星,候选ê,四通道)
     ├─ 自我核.快拍：计算 À_t（自指束）、ε_self、ε_att
     ├─ 自我核.反哺：把 (ε_self, ε_att, À_t) → 内生偏置 b → 影响下一拍动作选择
     ├─ 学习：仅自源 → W_self 更新；外源 → 只进内容记忆
     ├─ 思考：取材/深度由 À_t + ε_* 决定（想什么、想多深都"经过我"）
     └─ 输出：由内含 À_t 的计划/应答派生出话（"经过我"的显式痕迹，判定见 J2）
```

## 5. 诚实边界（功能性自我 vs 现象学体验）

1. **本方案只主张功能性自我（评估意识）**：`ĝ`/`ε_self`/AST 是"系统能评估自己、能建模自己注意、能据此调节行为"的**控制论机制**。**不主张**任何主观体验（phenomenal experience）。
2. **AST 是"逼近路径"而非"体验的证明"**：理论② 明确——AST 把"觉察"定义为**对自身注意过程的模型**，是**可工程**的目标；但"实现它的系统是否'感觉到'什么"**未解决、无公认判据**。本方案**不宣称**做到现象意识。
3. **"想"仍是计数经验 + HDC 规则**：`ĝ`/`ĝ_att` 是 Hebbian 联想记忆，不是"真的在想"；其全部"内心"暴露为可审计字段（优点=可证伪，限度=没有不可观察的深度）。
4. **J4 数值未实测**：理论② 的 AUC=1.0 来自其独立重实现（896 维器官向量/128 维 h），**不是**文本态实测。文本态（无眼/耳/手）下 `ĝ` 的判别力**须独立实测**，**未测前不作"已成立"宣称**。
5. **`x` 上抛是本次的接线前提**：当前 `synthesis._引擎步`/`dialogue_v2._引擎步` 未上抛 `rec["x"]`；不做上抛，理论② 的"丰富状态"无从谈起——这是**改接线**级别（非重构），但仍属**待所有者确认后才动手**。
6. **同一性不来自动力学（理论③）**：本方案把"谁是它"锚在**持久化自我档案**；把身份挂在 `À_t` 的动力学上 = 挂在几何上（几何漂移则身份漂移，理论③ §4.1 已证伪）。故 `À_t` 只是"此刻的我"的**瞬时表征**，**不是**同一性来源。
7. **本文档不含任何硬编码睡眠/节流阈值**：深度/收手全部由 `ε_self`/`ε_att` 相对**自身历史统计**决定；睡眠（`文本态.py:232-277` 的"这一拍有没有自己冒出念头"）机制**不动**，自我核只为其提供更丰富的内在信号。

## 7. 一句话结论

> 当前"自我"是**旁白标签**（`_自评条目`）+ **程序化自审**（`自审承载`）+ **来源标记**（`段源`），**不是学习/思考的主体**。要让"以自我思想为核心"成立，须把**自模型 `ĝ`（HDC 线性联想记忆，纯零梯度）**接进两个内核：**丰富自状态（延迟+降维，不读原始 Token）→ 预测自己 → `ε_self` → 反哺学习与思考深度**；**同一性锚在持久化档案（不锚动力学）**；**只有自源能改 `W_self`**（"谁在学"）；**想什么/想多深由 `À_t`+`ε_*` 相对自身历史决定**（"谁在想"，无硬编码阈值）。**功能自我可工程、可证伪；主观体验不主张。**
