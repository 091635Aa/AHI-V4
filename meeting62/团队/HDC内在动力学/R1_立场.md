## 0. 结论先行

1. **「规模化学习→内部网格」能落到 HDC，且零外挂可证**：音素格 = F 个属性码本的**乘积/束**，分解用**谐振器网络**——本仓既有 8 算子（绑/解绑/读/叠/迭代）**已足够**，无需新依赖。`[实测]` D=1024、每因子 4/8/16/32 时，谐振**恢复率 100%**；置乱熵源跌 **20.8%**；产品向量直读仅 **16.7%**（chance）；两趟逐位同。→ 探针 PASS。
2. **「原生自发声（无参考）」的骨架 = 自激声门源 × 谐振字典**：声门流由**引擎内自激振荡器**（两质量模型 / 自波动流表）产生；声道滤波系数由**内部网格格子状态**选。声学帧由内部动力学＋私有熵源 `default_rng(显式种子)` 生成。`[源码]` v6 已有声门流表/谐振器/噪声道可直接当"字典原子"。
3. **HDC 只保证"符号结构层"内生，不替代 v6 物理源-滤波层**：正确分工是 **HDC 出声素/韵律的符号序列 → v6 出声学帧 → 波形**。v6 残缺陷（E5/F2 滚降/鼻音无零极点）属 HP 层，HDC 不救。
4. **建议先走 A+B（网格+谐振），再 C（自激源），最后 D（SOM 自组织，最贵）**；这条与"现行参数化修到可用"**不冲突**（④ 是上层）。
5. **最大缺口（未测）**：符号格 → 声学帧的**字典映射**（格子→F1..F5/气声/紧喉）。HDC 给结构，不给连续声学数值——这层必须显式建。

## 1. 题面④：内部网格（发音格）的 HDC 可执行设计

**主张 A**：一个音素向量 = `叠( 角色键 ⊛ 属性值 )`（键⊙值 = 本仓 `绑`，Hadamard 双极自逆）；F 个属性轴 → 组合空间 = `Π 每轴基数`，即"发音格"的字号；稀疏块码（GSBC）可提高容量。
- 证据：`[源码]` `算子_能力核.py` 七原语（绑=键⊙值、读=码本检索、叠=束、迭代=定点推进）＋`算子_两区室核.py` 第八算子`符`。`[P0]` Hersche 等 GSBC（绑定/束/ℓ∞ 相似度）。
- 反证：若 **F≥3 或含噪感知输入**下恢复率崩塌 ⇒ 换 SBC/更大 D/多谐振器堆叠。
- 代价：N×N=1024 格，读 O(码本数·D)；内存 ∝ D×码本数；延迟 = 迭代步数×读。

**主张 B**：**谐振器网络 = 既有算子可搭的因子分解**（Frady 等 2020 与本仓 迭代/解绑/读 同构）。
- 证据：`[实测]` 探针 P1 恢复率 100%（N=4/8/16/32）；P2 直读 16.7%（must-fail：乘积向量非原子）；P3 置乱熵源 20.8%（动力学真在起作用）；P4 记录两趟逐位同（C13）。
- 反证：**F=3、非双极稀疏块码、或加噪**时若恢复率掉 ⇒ 容量边界（本探针 F=2、双极、无噪，**已标未测**）。
- 代价：每迭代 2 次 unbind＋2 次码本检索；实测 12 步×24 组 CPU < 数秒。

**主张 C**：**原生自发声（无参考）**＝自激声门源 × 谐振字典。
- 技术路线：① 声门源改**自激两质量振荡器**（Ishizaka–Flanagan）或引擎内自波动流表，周期由内部振荡器自己产生，**不喂参考 F0**；② 声道滤波系数 = `读(谐振字典, 网格格态)` 得到的原子组合 → 喂 `引擎_v6.合成` 的 f1..f5/BW；③ 幅度/气声/紧喉由内部态（如两区室核 `自我态 A`/`符(A,B)` 重合门）驱动。
- 证据：`[源码]` 引擎_v6（声门流表/谐振器系数/噪声道）；`[P1]` 自激声门模型综述（Cummings 1995）、ARIS 玻璃盒源-滤波合成。
- 反证：若声门源**必须喂参考 F0/波形**才能在 v6 判据达标 ⇒ "无参考"不成立。
- 代价：两质量模型需数值积分（时潜延迟↑）；内存小；工程量中（替换现有流表）。

**主张 D**：**规模化学习→网格**两条可执行路线。
- 路线1（SOM）：发音参数向量 × 声学帧 → 拓扑映射，BMU 邻域更新形成"发音格"；对应 Kohonen 1988 神经音素打字机（pseudo-phoneme）、Oudeyer 感知图↔运动图耦合、Babbling 自组织。
- 路线2（VSA 谐振字典）：`(发音束 ⊛ 声学束)` 存进叠加记忆，谐振反查（= 主张 B 的直接应用）。
- 证据：`[P1]` SOM 语言习得/语音产出发育模型；`[实测]` 谐振可分解。
- 反证：若"仅内部自激、无外部稳定信号"时 SOM 格子**漂移/塌缩** ⇒ 需结构先验或稳态信号。
- 代价：SOM 内存 O(格子数×D)；需自激探索循环（工程量最大）。

## 2. 「零外挂」证明与可证伪判据（含 must-fail）

**断言 A（不读参考）**：运行期无音频读入（审计：源码不得出现 `wave.open(...,'rb')`、`librosa`、`torchaudio`、`soundfile`）——审计脚本扫 import ＋ 文件读取调用。
**断言 B（不载模型）**：参数只来自 `default_rng(显式种子)` ＋ 2^-20 定点算术；无权重/checkpoint 加载；不 `import torch/transformers/rwkv`（C1/C10）。
**断言 C（确定性）**：同种子两趟逐位同。`[实测]` 探针 P4 命中记录逐位同；v6 自检已有"两趟同"。

**must-fail 对照（先跑最便宜的）**：
- `Sham-直达`（最便宜）：**去掉谐振迭代、只读乘积向量** ⇒ 探针 P2 已证 16.7%（chance）⇒ 若谁声称"网格直达"就必须掉。
- `Sham-置乱`：把内部熵源/格态**置乱或冻结为常数** ⇒ 探针 P3 20.8%（vs 主臂 100%）⇒ 若输出不退化说明网格没在用。
- `Sham-参考`：把熵源换成"从参考音频估出" ⇒ 指纹应依赖该参考；若两趟仍逐位同则"无参考"确认。
- `Sham-单参数`：只改 F0 或只改一个共振峰 ⇒ 应只动对应声学属性，**不得**整句同变（防"参数化模拟"冒充原生）。

## 3. 与裁决问题（§6）的关系

- §6-1「真问题」：④ 的立场是**分层判**——听感层是 v6 物理层残缺陷（E5/音色），**路线层**（模拟 vs 原生）由 ④ 的符号层内生性回答；两者不可混为一谈。
- §6-3「先走哪条」：建议 **HDC 网格+谐振先行**（1 周内可跑且零外挂可审计），**自激源**次之，**SOM** 最后；与"现行参数化修到可用"并行不冲突。
- §6-4「代价排序」：B（谐振，最省）< A（网格，省）< C（自激源，中）< D（SOM，最贵）。

## 4. 未测项（诚实边界）

- 符号格 → 声学帧的**字典映射**（格子→f1..f5/气声/紧喉）——**未测**（本路最大缺口）。
- F≥3 因子、多音素序列、**含噪感知输入**下的谐振恢复率——未测。
- SOM 在"仅内部自激、无外部稳态信号"下能否收敛成可用拓扑网格——未测。
- "原生自发声"波形能否通过 v6 现有听感判据（F1 落位等）——未测（需接 v6 实跑）。
- 是否引入人耳主观盲评——未测（G1 缺口仍在）。
