## 0. 结论先行

1. **真问题是"路线问题"的一半在此路成立**：现行"情绪"＝`说_音色.情绪律` 里 **4 个离散名字的乘性模板**（高兴/低落/急促/平静）[源码: 说_音色.py:41-75]，**没有唤醒轴、没有效价轴、不可内插** ⇒ 所有者说"靠声控模拟"在本路属实。
2. **因果链必须是两级、且 V 与 A 走不同通道**（P0/P1 证据）：**唤醒 A** 稳定驱动 **F0 / 能量 / 语速 / 紧喉 / 粗糙**（交感激活→声门下压↑、声带张力↑）；**效价 V** 在 F0 上本征弱可分（高 F0 既见愤怒又见高兴，F0↔效价关系弱且不一致），只能落到**声质轴**（气声 / 谱倾斜 / 送气）。**故"V→F0 单射"必失败，V 必须走声质。**
3. **可机械化的链（本路答案）**：`情感态(V,A,P,强度) →[确定性解析映射]→ 生理中间量(呼吸激发/声带张力/声门靠拢平衡) →[增益]→ 8 声学参数`。**不需要查表、不需要外挂模型、不需要 HDC 码位**；代价 ≈ 一次算术。
4. **最小实验已跑** [实测]：提案映射在 5×5 网格产 25 个互异输出（模板只 4 个，无内插）；A 单调驱动 F0/幅度/语速（已验证）；V 的声质差 0.36–0.62（>0.10 门槛）；v6 后端实测 高兴 vs 低落 F0 中位差 **121.8 Hz**、RMS 差 2.8×、两趟逐位同。

| E10 | 高兴=高宽F0/快/响/清亮；悲伤=低窄/慢/软/气声；愤怒=高变/快/响/紧嘶 | 科普表 | P3 | ✓ 与 E1–E5 一致但仅作定性 |

**筛出的可机械化因果链（由 E1–E5/E9 合成）**：
```
A(唤醒) → 交感↑ → 呼吸激发(声门下压)↑ + 声带张力↑
        → F0↑、能量↑、语速↑、紧喉↑、粗糙↑、气声↓
V(效价) → 声门靠拢平衡/谱质：
         V−低唤醒 → 气声↑(松弛/叹息，E5 的悲伤)
         V−高唤醒 → 紧喉↑粗糙↑(挤压/嘶，E10 的愤怒)
         V+      → 气声↓、清晰共鸣(E5/E10 的高兴)
P(支配) → 声门下压/起音 → 幅度↑、紧喉↑
```
> **关键**：A 可对 F0/能量做**单调**映射（证据强）；V **不能**对 F0 单调映射——这是 must-fail 的靶点。

## 3. 提案（[提案]）：两级驱动链（已验证形态）

```
半音 = 3.0·A + 0.7·V + 1.0·P           # A 主导
F0   = 190·2^(半音/12)      ∈[70,400]
幅度 = 0.45·(1 + 0.55·A + 0.20·P)
语速 = 3.2 ·(1 + 0.30·A + 0.08·P)
紧喉 = 0.30 + 0.35·A + 0.15·max(−V,0)max(A,0) − 0.15·max(V,0) + 0.10·P
气声 = 0.10 + 0.35·max(−V,0)(1−A) + 0.10·max(−A,0)max(−V,0)
粗糙 = 0.03 + 0.20·max(A,0)max(−V,0) + 0.10·max(A,0)
送气 = 0.20 + 0.40·气声       声区 = 0.05 + 0.30·max(A,0) + 0.20·max(V,0)max(A,0)
```
- **确定性**：纯闭式算术，无 rng，无查表（C13 ✓）；无 audio 输入、无 torch/TTS/RVC（C1/C9/C10 ✓）。
- **"由内在状态而非模板"**：输入是**连续 (V,A,P)**，输出是**连续剖面**；内在情感向量（或 meeting38 的 8 因子 HDC 解码）→ 本链 → 剖面。**与"4 个名字"显示区分**。
- **代价**：8 参数 × 常数级算术，**每句 <0.1 ms**；零新增码位；零内存。可选升级（meeting38 因子轴 HDC 解码）≈16.8 MB，**非必需**。

## 4. 可测判据 + must-fail（[实测]，探针 T1–T7）

| 判据 | 门槛 | 本轮实测 | 判 |
|---|---|---|---|
| **T1 换情绪⇒参数必变** | ≥6/8 参数变且归一距>1.0 | 8/8 参数变，归一距 **3.40** | PASS |
| **T2 唤醒单调** | F0/幅度/语速 随 A 单调非减 | F0 159.8→225.9、幅度 .202→.698、语速 2.24→4.16 全单调 | PASS |
| **T3 效价可分（must-fail 靶）** | 同唤醒下 V− vs V+ 声质差 >0.10 | 紧喉+粗糙差 **0.36**；气声差 **0.62** | PASS |

| **T7 音频级（v6 44.1k）** | 高兴 vs 低落 F0 差 ≥10 Hz、能量≥2 档 | F0 中位 **290.1 vs 168.3（差 121.8 Hz）**；RMS **.0186 vs .0066（2.8×）**；两趟逐位同 | PASS |

**must-fail 清单（先跑最便宜的在前）**：
1. **[已跑·参数层]** 置乱(交换 V/A) ⇒ 输出必变（已 PASS）；置零 ⇒ 必落中性（PASS，非档案基线）。
2. **[该先扩·音频层]** 5×5(V×A) 网格 → synth → 每格的 F0/能量/RMS 与参数层**同序**；置乱对照波形必变。**≤40 s，CPU-only**（本探针 T7 已证单点可行）。
3. **[最关键·未测]** **同唤醒下 V−/V+ 可辨**：高唤醒(V−欣喜?→应为愤怒)与高唤醒(V+ 高兴)在 F0/能量上**接近**——须靠声质（紧喉/粗糙/气声）在**人耳或代理指标**上分开。**这是最大风险的验证靶**。
4. **[未测]** 单参数 sham：只改音色档不改 (V,A) ⇒ 情感相关参数不变（证明驱动来自情感态非音色模板）。

## 5. 回答 §5② 与 §6 相关裁决问题

- **② 题面**：因果链＝**两级**（情感态→生理中间量→8 参数），V/A 分道（A→F0/能量/语速/紧喉/粗糙；V→气声/谱倾斜/送气）。"有情绪地说/唱"由**内在连续 (V,A,P)** 驱动，**不是外部模板**（T4 量化区分：25 vs 4）。判据=§4；must-fail=§4。
- **§6-1**：本路"声音有问题"的**真问题 = 路线问题**（4 档离散模板＝模拟）**且叠加** wiring 缺陷（旧路径紧喉/粗糙死参数）。
- **§6-2**：md 谱"亚版本"对本路的最小形态＝**情感/韵律层剖面**（(V,A,P)→8 参数）；**可先于乐谱管线落地**，因为它与"怎么发声"正交。
- **§6-3**：本路建议 **先走"现行参数化修"里的情感驱动链**（代价≈0、可测），**不必等**"原生自发声"或"HDC 内部网格"——后者解决"参数怎么发声/从哪来"，本路解决"发什么情绪"。

## 6. 诚实边界 / 未测
- **未测**：真人盲评（G1 缺口）；跨说话人；效价在**同唤醒**下的**人耳**可辨（最大风险）；V 的谱倾斜接线（v6 支持，探针未接）；连续网格音频级批量；"有情绪地唱"（长音/颤音属 ③ 路）。
- E5 与 E2 存在张力（气声=正 vs 悲伤气声）→ **V 不是单轴声质可完全承载**，需 A 联合；本路如实用**象限联合**而非单射。
- 不主张自我意识/现象学；口径＝**参数化模仿**。
