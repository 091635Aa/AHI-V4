## 0. 结论先行（一句话）

**v6 在物理层只有两件真缺陷：（a）源谱倾斜过陡 —— 缺 Klatt `tl`（源谱平坦化）这一自由度；（b）鼻音没有独立极/零点。
E5 冲突、`/i//ü/` F2 低 17–21dB 是判据/测量口径问题（同一元音只换 F0 就摆动 11dB），不是引擎物理缺陷。**
唱歌（颤音/音准/换声区）当前**没有做在物理模型里**：颤音给了 7 音分且落在幅度上，`声区` 只是把 F0 ×1.5。

## 1. E5 冲突的物理解法：换判据，不改引擎

- **主张**：带分布 L1 不是「正确发音」的稳定属性，不能作门限。
- **证据**：`[实测]` v6 自己的 11 个参考文件 0–500Hz 占比 12.1%–56.9%（差 4.7×）、1–2k 7.6%–51.5%（差 6.8×）（出处 `判据_发音_v6.py._参考范围` + `说明_v6.md §5`）。`[源码]` E5 定义＝`重比≤0.25 and 带距≤0.25`（`判据_发音_v6.py:503`），且把整句锚到**歌唱/清唱录音**的均值。LTAS 直方图主要由**源谱倾斜（声质/力度/F0）+ 录音链 + 文本**决定，与构音身份弱相关。
- **`[提案]` 三条替代臂（保号保定义，只换测什么）**：
  - **E5a 逐韵母共振峰落位**：对参考的**同韵母段**做倒谱/LPC 包络 → F1/F2/F3，门限 **ERB 距离 ≤1.5 且频率相对误差 ≤15%**。
  - **E5b 源/滤波分离**：**H1−H2、H1−A3**（声质倾斜量），参考−合成差 **≤4dB**（UCLA VoiceSAP 口径：tilt 与开商/闭合速度绑定）。
  - **E5c 若必须留「谱形贴近」**：两边先各自按 **−6dB/oct 参考线归一**（减掉 1/f），比**残差（纯滤波器形状）**，门限 L1 ≤0.25。
- **反证**：若 E5a/E5b 通过而耳朵仍说「听不出说什么」→ 「判据问题」的诊断被推翻，真因在声道/唇辐射链。
- **代价**：E5a 需对 11 个参考文件离线跑一次 LPC（秒级）；E5b/E5c 纯 FFT，运行期零代价。

## 2. `/i/ /ü/` F2 低于 F1 的物理解法

- **主张**：那条 17–21dB 是**谐波采样口径**，且**源谱是主项**（滤波器也有份，不是「已健康」）。
- **证据**：
  - `[实测]` 同一 `/i/`（F=(330,2349,3132,3967,5011)，BW=默认），只改 F0：
    F0=120→**−23.7dB**；200→**−17.0**；300→**−25.8**；367→**−28.1**；440→**−18.1**。摆动 11dB ⇒ 不是稳定物理量。
  - `[实测]` **纯滤波器**（无源）F2−F1：`/i/ −6.0`、`/ü/ −3.0`、`/a/ −3.5`、`/u/ −7.5` dB（对照 `说明_v6 §5` 的 −3.5/−4.8：同量级，复算成立）。
  - `[实测]` 源谱账：在 2.35kHz 要把 `/i/` 抬回 F1 需 **+23.7dB** ⇒ 源占 −16〜−18dB，是主项。
- **`[提案]` 三条合法提升路（都不是输出端 EQ）**：
  - **P-a 元音相关带宽**：`/i//ü/` 取 `b1 70→50、b2 90→55`（Klatt 默认 b1=60/b2=90，范围 30–1000/40–1000 `[P0]`）→ `[实测]` F2 抬 **+0.5〜+1.9dB**。作用小、纯物理、零代价。
  - **P-b 源谱平坦化（Klatt `tl` 口径，反号）**：在 1–5kHz 抬平 **14–18dB@3kHz** → `[实测]` `/i/` F2−F1 **−23.7→−13.4/−10.5dB**，`/ü/ →−10.5/−8.6dB`。
    （Klatt `tl`＝「源谱在 3kHz 处额外下倾 dB」，默认 0，范围 0–34 `[P0]`；本引擎的脉冲源**比 Klatt 零倾基准更陡**，故需等效负值。）
  - **P-c F2 并联支路 a2**（Klatt 并联支路的**独立幅度 a2**）：HP 在 F1 上裙（`F1+2·b1`）× F2 谐振。`[实测]` a2=0.60 → `/i/` F2−F1 **−8.2dB**、`/ü/ −5.4dB`；a2=1.20 → −1.3/+1.1dB；**低频(<480Hz) 一直 0.0dB，无平台**。物理正当性：Klatt 并联支路本就是为「级联无法表达高次共振峰幅度」而设，a2 对应**声门下游湍流源对窄腔的再激励 + 源-滤波非线性**。
- **反证**：P-c 打开后若 `/a/ /o/` 的 F2 被相对抬 >+3dB，或 F1 突出度（现 **+9.9dB**）掉到 <3dB ⇒ P-c 不适定（应只对 `/i//ü/` 帧启用且 a2≤0.5）。
- **代价**：P-a 零；P-b 需一次重标定 `_源标定`（与 v6 同法）；P-c +1 路二阶/帧 ⇒ 实时率约 +0.01。

## 3. F3–F5 串联滚降：v6 的支路「把 F4 抬到高于 F3」，破了单调包络

- **主张**：不该用「逐峰手调增益」补滚降；应让**源谱先变平**，让包络自然单调。
- **证据**：`[实测]` 无支路 `/a/` F3/F4/F5 = **−32.4/−46.7/−70.5dB**；v6 现状（高支 0.55、高增 0.30/0.70/0.40）= **−25.2/−23.8/−31.9**（抬 **+7.2/+22.9/+38.6dB**，且 **F4>F3 ⇒ 非单调**）。源谱 3kHz 压平 18dB 且去支路 = **−16.6/−23.3/−37.7**（**单调 ✓，合真人**）。
- **`[提案]` 二选一（都不新增滤波）**：
  - **甲（最小改动）**：保留支路，高增改**单调递减** `(0.30, 0.24, 0.16)` → `[实测]` −26.9/−32.5/−40.1（单调 ✓）。
  - **乙（推荐，一并解 §2）**：走 P-b 源谱压平 12–18dB@3k，`_高频支路 0.55→0.15〜0.25` 或 0。
- **门限**：**F3>F4>F5** 且 **F3 ≥ −20dB**（当前 −25.2 偏低，与「偏暗/偏闷」听感一致）。
- **反证**：若单调化后 `/o//e/` 的主谱峰跳到 F3（`说明_v6 §5` 已警告高支 >0.8 会如此）⇒ 门限要加「F3 峰位 ≠ 谱包络主峰」。
- **代价**：零（全部是常数）。

## 4. 鼻音：加独立极/零点（现在完全没有）

- **主张**：`m/n/l/r` 与 `-n/-ng` 当前是「浊音 + 共振峰目标 + 电平补偿」的**近似**，缺鼻支路的**反谐振**，这就是「鼻音不鼻」的物理根因。
- **证据**：`[源码]` v6 无鼻支路；`韵律_v6.浊声母增益={m:1.63,n:1.84,l:2.17,r:1.85}`；`音韵_v5.鼻尾目标={n:(300,1600,2500), ng:(300,1100,2300)}`（只给 F2）。`说明_v6 §5` 自承「没有独立鼻零极点」。
- **外部参数**：
  - `[P0]` Klatt 参数表：鼻极 `fp` 默认 **280Hz**（范围 180–500）；鼻零 `fz` 默认 **280Hz**（范围 180–800）；带宽默认 **90Hz**；**fp=fz 时互相抵消＝不鼻化**。
  - `[P1/P2]` 鼻辅音的反谐振（口腔封闭腔 1/4 波）：**[m] 750–1250Hz；[n] 1450–2200Hz；[ŋ] >2000Hz**（uni-koeln 声学语音表 / Oxford consonant acoustics）。鼻杂音 **N1(≈F1) 250–300Hz**，鼻音共振峰整体比元音弱（`[P2]`）。
- **`[提案]` 帧字典加 3 字段 `鼻极Hz / 鼻零Hz(+BW) / 鼻增益 g`，引擎加一条并联鼻支路**：
  `鼻支路 = 声门源 × 谐振(鼻极, BW≈120) × 反谐振(鼻零, BW≈200) × g`；反谐振用二阶 biquad（分子 `1−2r cosθ z⁻¹+r²z⁻²`，`r→1` 得近纯零，DC 归一）；口腔径 ×`(1−0.5g)`（口鼻分流近似）。
  取值：**m → 极270 / 零950 / g0.45**；**n → 270 / 1750 / 0.40**；**鼻韵尾 -n → 270 / 1650 / 0.35**；**-ng → 270 / 2600 / 0.35**；**鼻化元音 → 270 / 350 / g 0.20–0.35**。
- **门限**：鼻音段 2–4kHz 能量占比高于元音段**且 F1 峰位仍落 250–300Hz**；`-n` vs `-ng` 的零位差（1650 vs 2600）可被 1/3 倍频带谱差检出（≥3dB）。
- **反证**：加了零极点后若 B3（浊声母电平 −12.87/−12.17/−14.62dB）分离度反而变差 ⇒ 分流口径取错（要用「加法」而非「衰减口腔」）。
- **代价**：+2 个二阶节 × 浊帧 ≈ 实时率 +0.01；**只碰 m/n/l/r 与鼻韵尾帧**，清辅音逐位同 v5 的 C14 护栏不动。

## 5. 协同发音（locus/过渡）：现状已合物理，只补两条

- `[源码]` `终点 = 轨 + (目−轨)×0.45`、30ms 平滑（`韵律_v6._声母`）；轨迹 (250,800,2100)/(250,1700,2600)/(300,2000,2400) 与 **locus 理论口径一致**（唇 ~800 / 龈 ~1700 / 软腭 ~2000 Hz）`[P1/P2]`。
- `[提案]` ① `0.45` 改**部位相关**：唇 **0.55** / 龈 **0.45** / 软腭 **0.35**（软腭 F2 locus 最不稳定、欠冲最大）；② 未重音音节欠冲再 ×0.85。
- **门限（locus equation）**：F2起步 = a·F2中心 + b 回归，**a ∈ [0.4, 0.9]**（唇偏低、软腭偏高），**b ≈ locus 频**（唇 700–900 / 龈 1600–1900 / 软腭 1900–2300）。
- **反证**：若 a 全 <0.3（过渡被平滑吃掉）或 >1.2（过渡过量）⇒ 口径不适定。**代价**：零（常数）。

## 6. 唱歌：颤音 / 音准 / 换声区 / 长音（物理模型怎么加）

- **`[源码]` 两处实缺陷**：① `韵律_v6._f0` 的长音「微颤」只有 **0.07 半音＝7 音分**（t∈[0.28,0.86]，4.8Hz）；② `引擎_v6._微颤深=0.012` 乘在**源周期波形**上 ⇒ 那是**幅度颤音**，不是 F0 颤音。⇒ 现在**听不出歌唱**。
- **颤音 `[P1/P2]`**：速率 **5–7Hz**（Leydon/Bauer/Larson 2003；Lester-Smith 2020）；幅度 **0.41–1.58 半音**（BYU/Seashore；均值 ≈**1.04 半音=104 音分**、SD 56、范围 15–231 `[P3]`）；**起始延迟均值 ≈0.81s**（SD 0.78，0.18–3.66s `[P3]`）；幅度调制滞后 F0 调制约 60–90°。
- **`[提案]` 帧字典加** `颤音Hz(5.8) / 颤音半音(1.0) / 颤音起延迟(0.5s) / 颤音抖动(6%)`，且**必须做在 F0 上**：`f0样 = f0·2^(Δ/12)`，`Δ = 颤音半音·sin(2π·Hz·t+相)·斜坡(t−延迟)`，再进相位累加（`引擎_v6` 已有 `相位=cumsum(f0样/FS)` 通路）。
  **门限**：F0 去颤后**中心音准误差 ≤25 音分**（合格 ≤15）；速率落 **5–7Hz**、速率抖动 CV ≤10%；幅度 **0.4–1.6 半音**。
  **反证**：若「去颤后中心误差」随颤音幅度单调上升（＝漂移不是 FM），或速率估计 ≤3Hz ⇒ 实现错。
- **换声区 `[P1]`**：女高音**第一换声点约 E4–F4 ≈ 330–350Hz**（Garnier JASA 2012）；标准实验滑音 **A3(220)→A4(440)**、**A4(440)→A5(880)**（PLOS One 2017 研究第一/第二 passaggio）。M2(假声) 的物理标志：**开商 OQ 近乎 1**（声门缝全程不闭合，Kyushu 多参数研究）、**H1−H2 显著增大**、源谱 tilt 变陡。
  **`[提案]`** 加 `声区∈[0,1]`（M2 占比）+ `换声点F0`（女 345 / 男 165）：M2 时 **OQ 0.5→0.85**、`tl` 额外 **−6〜−10dB@3k**、**H1−H2 +4〜7dB**、抖动 0.5%→1.5%、SPL **−1〜−3dB**，并给**迟滞**（上行/下行切换点差 3–5%）＝换声「断」的可听签名。
  **门限**：跨换声点时 (a) H1−H2 跳变 ≥4dB；(b) 出现 1–3dB 电平谷；(c) jitter 有 2× 台阶；(d) 上行/下行切换点有迟滞。
  **反证**：若换声只做成「F0 连续、无跳变」⇒ 假声区判据失败（**现在 v6 正是如此**）。
- **`[源码]` 缺陷定位**：`声区` 现状＝`基准F0 ×(1+0.5·声区)`（`韵律_v6._f0` 末）⇒ **只是抬高 F0 50%，不是换声**。要拆成「F0 抬升」与「声区机制（OQ/tl/H1H2）」两个独立自由度。
- **长音 `[P2]`**：门限 ① 2s 长音含 **≥8 个颤音周期**；② SPL 缓降 **1.5–4dB/s**（声门下压衰减）；③ 后 1/3 与中 1/3 的 **LTAS L1 ≤2dB**（谱平稳）；④ 共振峰漂移 **<3%**（否则母音变）。
- **代价**：颤音/换声都是 F0 与 (OQ,tl) 的**确定性函数** ⇒ 无新增滤波，实时率不变（只多表查询）。

## 8. 反证汇总（什么结果会推翻我）

1. E5a 通过而真人仍说「听不出说什么」→「判据问题」诊断错，应查声道/唇辐射链。
2. §4 加零极点后 m/n 听辨变差 → 反谐振方向取反（应放鼻支路而非口腔）。
