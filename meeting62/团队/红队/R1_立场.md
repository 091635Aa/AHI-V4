## 0. 结论先行

1. **判据体系的主要缺陷是「目标自证」**：F1/D1/D2/F2/F3 臂的「期望值」**全部取自引擎自己的输入表**（`音韵_v5.韵母表`），A1–A3 直接测表本身（不测波形）。⇒ **判据测的是「输出≡输入」，不是「说得对」**。`[源码]`+`[实测]`
2. **「23/24 PASS」衡量的主要是「内部一致性 + C14 护栏」，不是「耳朵满意」**：两者同时为真**不矛盾**，因为它们测的是不同的量。与所有者「还是有问题」并不互斥。`[实测]`
3. **一条已跑出的硬证据**：F1 臂的「落位窗」**互相包含**——7 个单元音**全部**同时落入**别人的窗**；`/i/ /u/ /ü/` 实测峰 **325.0 / 333.3 / 325.0 Hz**（几乎同值），即「13/13 落位」里 **i/u/v 三条是同一个读数被记了三次**。`[实测]`（探针 B 段）
4. **越宪不是假想**：pyttsx3/SAPI **就是既有件**（`meeting32/声带.py:817`、`meeting38/器官_嘴.py:79`），且 `meeting55 §3` 记「TTS 兜底 1.18s」。现有静态 import 审计**只扫 `meeting59/**` 的 `ast.Import`**，漏动态 import / 其他目录 / 进程·DLL·权重加载。`[源码]`
5. **最该先跑的最便宜 must-fail**：**白噪+静音 sham + 窗交叉 sham**（零合成、秒级、可完全离线）——本探针已跑出一半；其中**杀伤力最大、次便宜**的是**外部真人正对照**（把判据同量跑在 `素材/ref44_*.wav` 上，要求真人必须 PASS）。`[提案]`

## 1. 自证攻击：用自己合成数据测自己，会出现哪些**假 PASS**

**主张**：现行 24 臂中至少 6 类臂可被「自证」制造假 PASS。`[源码]`（`判据_发音_v6.py`）+`[实测]`（探针）。

| 臂 | 假 PASS 机制（`[源码]`） | 反证（什么结果会推翻我） | 代价 |
|---|---|---|---|
| **A1/A2/A3 音韵映射** | 只 `assert Y.解析音节(k)["韵"] == 硬编码期望`（L275–294），**完全不读波形** ⇒ 测的是查表器自己 | 若把这些臂改成读**波形**仍 PASS，则不成立 | 改量法，小 |
| **F1/F2/F3 元音峰位** | 窗 `[min(F1目标)*0.85, max(F2目标)*1.15]` **由 `音韵_v5` 目标算出**（L549–590）＝引擎的**输入** | 若**外部真人参考**在同一窗下也 PASS（正对照成立），则不成立 | 读 11 wav + FFT，秒级 |
| **D1/D2 元音空间** | 期望硬编码 `(825,1305)/(330,2349)…`（L394–413），且用**派生 120Hz 声线**测 | 若交付声线（367–428Hz）下同量读数与 120Hz 一致，则不成立 | 需重合成，小 |
| **E6 确定性** | 「两趟逐位同」对**任何**确定性程序恒真，与可懂度无关 | 若某确定性但不可懂的输出 FAIL 该臂，则不成立 | 无 |
| **E5 谱形贴近参考** | 唯一的**外部锚**，却只取每角色**第 1 个**录音，且 11 文件同带差 **4.7–6.8 倍** ⇒ 锚不可靠 | 若参考自身离散度 <1.5× 仍 FAIL，则不成立 | 无 |

**替代方案（自证的三条出路）**：
- **外部参考（正对照）**：判据同量跑**真人** `素材/ref44_*.wav`，要求**真人必须 PASS**；否则判据作废。`[提案]`
- **must-fail（负对照）**：喂白噪/静音/置乱，要求相应臂**必须 FAIL**。`[提案]`
- **置乱（标签置换）**：把 `音韵_v5.韵母表` 的 `a1↔i1` 目标对调后重合成，引擎照新表产出、判据照新表算窗 ⇒ **判据仍 PASS**（结构上不可能察觉映射错）。`[提案]`（逻辑已由 `[源码]` 证明）

**探针 `[实测]`（`产物_探针.json`）**：单元音判据窗互相包含 —— `a1[701,1501] / o1[449,1021] / e1[486,1501] / i1[281,2701] / u1[299,864] / v1[281,2221] / er2[468,1681]`；实测峰 `a1 885.7 落6窗 / o1 775.0 落7窗 / e1 708.3 落7窗 / i1 325.0 / u1 333.3 / v1 325.0（三者落同一组窗）/ er2 1641.7 落3窗`。**交叉落位元音 7/7** ⇒ 该臂**不能**证明元音身份。**诚实反证**：白噪峰 266.7Hz **落 0 窗** ⇒ 该臂对噪声**有**判别力（不是全然空洞）。

## 3. 「判据 PASS ≠ 耳朵满意」的结构性缺陷（v6 标称 23/24，所有者仍说有问题）

**主张**：不是「判据写错」，是**判据体系的 7 项结构性缺陷**让它**在原理上**无法覆盖耳朵。`[实测]`+`[源码]`+联网

1. **目标自证**（§1）——期望取自引擎输入表 ⇒ 测「输出≡输入」。`[源码]`
2. **窗宽买通**——探针 `[实测]`：7/7 元音交叉落窗；i/u/v 峰同值 ⇒ PASS 数被窗宽复数化。
3. **只有幅度谱，无相位/时域包络**——`[P0]` Broussard 2017：**相位谱**去相关比幅度谱**更伤**可懂度；判据全程 magnitude/envelope ⇒ 结构性盲区。
4. **量法在高 F0 失效**——`[P0]` Klatt 1986（PMC9374483）**harmonic attraction**：共振峰估计被强谐波吸引，**人耳不会**；判据 D 用 **120Hz 派生声线**规避（L393–394），但交付声线 **367–428Hz** ⇒ 判据测的**不是交付物**。
5. **无 must-fail 臂、无真人锚**——24 臂无一条「必须失败」设计；无 MOS/盲评（G1）⇒ **不可证伪**。
6. **判据集自相矛盾**——E5 与 F1 方向对调（v5：E5 PASS/F1 8-13；v6：E5 FAIL/F1 13-13）⇒ **「PASS 数」不是单调的「更好」**。
7. **AGI 级缺失**：音色身份（G3 14 维 7 维恒同）、唱歌、情感→声带（G8/G9）**根本不在 24 臂内** ⇒ 「PASS」覆盖不到耳朵最在意的维度。

**反证**：若把**真人盲评**加入后，23/24 PASS 的样本被判「可懂且自然」，则本主张（判据必然不够）被推翻。**未测**。
**代价**：真人是唯一彻底解法但需要人；**次优**是加「外部真人正对照 + must-fail + 相位谱量」三件，工程量中。

## 4. 必须失败对照（must-fail）清单 · 阈值 · 最便宜先跑哪个

| 序 | 对照 | 要求（必须满足才可采信） | 阈值 | 代价 |
|---|---|---|---|---|
| **1** | **白噪/静音 sham** | 各臂喂白噪+静音 + 纯音 | 相应臂**必须 FAIL** | **最低**（无合成，秒级） |
| **2** | **窗交叉 sham** | 每个元音峰与**全部**元音窗比对 | 交叉落窗率须**显著低于**自身（≤1 个） | **最低**（探针已跑：现为 7/7 ⇒ **不合格**） |
| **3** | **外部真人正对照** | 判据同量跑 `素材/ref44_*.wav` | 真人**必须 PASS**；否则判据作废 | 低（读 11 wav + FFT） |
| 4 | **回放对照** | 交付 wav vs 参考原声互相关 | `>0.99` 即抓回放（`meeting55` 已有此臂） | 低 |
| 5 | **置乱（标签置换）** | 置乱 `韵母表` 后重跑 | 判据须**至少一臂 FAIL**；现结构上**必 PASS** ⇒ 不合格 | 中（1 次合成） |

## 5. 与裁决问题（§6）的关系

- **§6-1「真问题」**：红队判为**两层同时坏**——**听感层**是 v6 物理残缺陷（E5/G3/G7/G8/G9），**判据层**是自证+无对照（§1–§3）；「路线问题（模拟 vs 原生）」是第三层。三者**不可用同一句「PASS」代替**。`[实测]`
- **§6-3「先走哪条」**：红队不选路线，只提**先决条件**——**任何路线（含 HDC/自激源）落地前，must-fail 套件（§4 #1–#3）必须先可跑**；否则新路线的「PASS」只是换了一套自证。`[提案]`
- **§6-4「代价排序」**：#1≈#2（秒级）< #3（秒级）< #4（低）< #5（中）< #6（中）< #7（中）。
- **§6-5「下一步最小实验」**：**跑 §4 #1–#3**（红队最小实验，与①脑神经「自激源最小实验」并行不冲突）。
