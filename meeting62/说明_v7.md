## 2. 三项修：采纳 / 否决（逐条，带实测）

### 修① 颤音从「幅度」搬到「F0 路径」—— **采纳**

- `[源码]` 缺陷：`韵律_v6._f0` 长音「微颤」只有 **0.07 半音＝7 音分**；`引擎_v6._微颤深=0.012` 乘在**源周期波形**上＝**幅度颤音**。
- `[源码]` v7 改法：`韵律_v7` 在 **f0 序列**上加 `Δ(半音) = 颤音半音·sin(2π·颤音Hz·秒 + 相)·斜坡(秒−起延迟)·(1+速率抖动·sin(...))`，
  参数＝发声生理 R1 §6：**颤音Hz=5.8 / 颤音半音=1.0 / 起延迟=0.5s / 速率抖动=6%**；`引擎_v7._微颤深=0.0`（去掉幅度颤音）。
- `[实测]` 2.4s 长音（`小谱_长音.json`，`产物\谱管线_v7\长音\长音_v7_小谱.wav`）：
  **去颤中心音准 3.9 音分**（门限 ≤25，合格 ≤15）、**去趋势幅度 0.743 半音**（门限 0.4–1.6）、**速率 6.25 Hz**（门限 5–7Hz 附近）⇒ N5 **PASS**。
- 代价：零新增滤波；实时率不变（`[实测]` 唱 3.79s 音频实时率 0.026）。
- **注意（如实登记）**：说话态短元音（<0.45s）**不再触发**颤音（v6 原有的 7 音分微颤被移除）⇒ 说话更"平"；C3 四声轮廓臂仍 PASS。

### 修② `_高频支路增` 改**单调** `(0.30/0.24/0.16)` —— **采纳**

- `[实测]` `/a/` F3/F4/F5 谐波电平：v7 = **−23.2 / −32.0 / −38.0 dB**（**F3>F4>F5 单调 ✓**）；
  对照 v6 = **−23.3 / −22.6 / −30.1 dB**（**F4>F3 非单调 ✗**，违背真人谱包络）。
- `[实测]` 配套：单调化令浊音电平降 0.07dB 使 E2 出界（−3.96 越上界 −4.0）⇒ 把 **`_源标定` 0.304 → 0.3065** 补偿（只动浊音道，不动噪声道），E2 回到 **−4.04**（与 v6 −4.03 持平）。
- `[实测]` **否决的替代补偿**：把 `_高频支路` 0.55→0.95 曾使 E2 回 −4.03，但令 `/e/`（鹅）谱包络主峰从 717Hz 跳到 **2692Hz（F3 区）**，破 `F1_元音谱包络峰位`（12/13）⇒ **弃用**，改走上一条（源标定）。
- 代价：零新增滤波；常数级。

### 修③ Klatt 源谱平坦化 `tl` —— **已实现，默认不启用（不采纳）**

- `[源码]` `引擎_v7.设源平坦(dB)`：`级联入 = 源滤 + a·源高`（a=10^(dB/20)−1，1.6kHz 以上抬升），带解析增益补偿。
- `[实测]` `/a/` 随 tl：tl=0 → 谱峰 840Hz/F1突出 9.9dB；tl=8 → 谱峰 840Hz/F1突出 **8.0**/浊音RMS 0.0082→**0.0030**；**tl≥12 → 谱峰跳到 1320Hz（F2 区）**。
- 判定：tl≥12 直接**破 F1 落位**；tl=8 虽未破 F1 突出度门限，但**改变了清浊电平口径**（浊音 RMS 降 2.7 倍）且其目标（`/i//ü/` F2−F1）经发声生理 R1 §2 判为**测量/判据口径问题，非引擎物理缺陷**。
  ⇒ 按任务规则与 `[实测]`，**默认保持 `_源平坦dB3k=0.0`**（关闭＝逐位同 v6 的该通路），开关保留可复跑。**这不是"没做"，是"实测后不采纳"。**

### 可选④ 鼻零极点 —— **已实现，未启用**

- `[源码]` 帧可带 `鼻极/鼻零/鼻增益`（`引擎_v7._反谐振系数`＝二阶近纯零点；默认 `鼻增益=0` ⇒ **零贡献、逐位同 v6**）。
- `未测`：鼻音段 1/3 倍频带谱证据、`-n` vs `-ng` 零位差 ≥3dB 未取；故本轮**未开**（若开须先补该证据）。
