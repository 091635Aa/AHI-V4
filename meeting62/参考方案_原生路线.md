## 1. 路线② 原生自发声（无参考）

### 1.1 最小实验做了什么（真跑，CPU-only）

探针：`meeting62/产物/原生路线/探针_自激声门源.py`（单趟 ≈2.5s，**两趟 5.0s**，不占声卡/GPU）。

- **模型**：`[P0]` Ishizaka–Flanagan 两质量模型，按 Fulcher/Scherer/Waddle *JASA* 132(4):2582 (2012)
  = PMC3477191 的 Eq(4)–(9) 实现（[提案] 本件参数集标定到 F0≈100Hz）：
  `m1·ẍ1 + r1·ẋ1 + k1·x1 + kc(x1−x2) = F1`，`m2·ẍ2 + r2·ẋ2 + k2·x2 + kc(x2−x1) = F2 = 0`
  （该文取出口损失系数 k_ex = 0 ⇒ P2 = 0）；`F1 = P1·Lg·d1`，
  `P1 = Ps·(r²−1)/((k_ent−1)+r²)`，`r = A1/A2`，`Ai = Lg·(ξ0+xi)`。
- **自激机理**：`[P0]` PMC3477191 §"Small amplitude approximation" —— 入口损失使 `P1` 对几何的导数为负，
  流体-结构耦合给出**流致刚度**，与恢复力**反向** ⇒ 高压下平衡点失稳（Hopf）⇒ 极限环。
  `[推导]` 线性化：`φ(Ps) = 2·Lg·d1·Ps/(k_ent·ξ0)` ⇒ 解析阈值 `Ps = k1·k_ent·ξ0/(2·Lg·d1)`。
- **唯一外部输入**＝两个**标量**（声门下压 Ps、紧喉张力标量）；**无参考音频、无外部模型、无权重**。

### 1.7 零外挂证明（本路线的主张）

1. **输入面**：唯一的驱动量是 `(Ps, 紧喉)` 两个标量；`[源码]` v6 的 `声门流表` 是**相位查表**（外部给波形），
   本件把它换成**状态自持**的 ODE —— 即"目标来自**内部状态**，不来自任何参考音频/外部模型"
   （脑神经 R1 §C2 的关键区分：**「无参考」≠「无目标」**）。
2. **证明手段（可复核）**：① 静态 AST（框架/外挂/权重 API/检查点后缀/`open(...,'rb')`）；
   ② 运行期 `builtins.open` 钩子 → **读入 0**；③ 运行期 `sys.modules` 禁名单 → **命中 0**；
   ④ C13 两趟逐位同。
3. **诚实的反证**：若把 ODE 换成「读参考音频估出的激励」仍能 PASS，则本证明不成立 —— 本件**没有**这种输入路径
   （`[实测]` 读入 0）；若存在未登记的隐藏参数源，则上述 ② ⑷ 不覆盖，须由红队 §2 路径 5 的**溯源审计**补（未跑）。
